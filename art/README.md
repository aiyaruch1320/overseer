# art/ — สร้างภาพวาดด้วย ComfyUI (เฉพาะเครื่อง Linux ของเจ้าของโปรเจกต์)

## ขั้นที่ 0: ตรวจก่อนอ่านต่อ (บังคับ)

งานในโฟลเดอร์นี้ทำได้ **เฉพาะเครื่อง Linux ของเจ้าของโปรเจกต์** ที่มี ComfyUI รันอยู่ (Ubuntu, AMD RX 7900 XTX, Docker) รันคำสั่งนี้ก่อน:

```bash
python3 art/tools/gen.py check
```

| ผล | ทำอย่างไร |
| --- | --- |
| exit 0 และขึ้น `OK: ComfyUI ...` | อ่านต่อได้ |
| exit 1 ขึ้น `NOT AVAILABLE ...` (เช่น macOS, เครื่องอื่น, ComfyUI ไม่ขึ้น) | **หยุดอ่านไฟล์นี้ตรงนี้** ข้ามทุกอย่างใน `art/` ทำงานกับโค้ดเกมตามปกติ ห้ามเริ่ม ติดตั้ง หรือตั้งค่า ComfyUI และโมเดลบนเครื่องนั้น ห้ามสร้างภาพด้วยวิธีอื่นมาแทน |

ถ้าเจ้าของขอให้สร้างภาพแต่ `check` ไม่ผ่าน ให้ตอบว่าทำได้เฉพาะบนเครื่อง Linux ของเจ้าของที่มี ComfyUI รันอยู่ แล้วให้คำสั่งที่ต้องรันที่นั่น (เช่น `python3 art/tools/gen.py build icons-power --root /tmp/try --seed <เลข>`) อย่าลองทำเอง

เกมรันและพัฒนาได้โดยไม่ต้องใช้โฟลเดอร์นี้

## งาน → คำสั่ง

| ต้องการ | ทำ |
| --- | --- |
| ดูรายการภาพที่นิยามไว้ | `python3 art/tools/gen.py list` |
| ลองสร้างโดยไม่ทับของเดิม (หรือลองเมล็ดอื่น) | `python3 art/tools/gen.py build <id> --root /tmp/try --seed 34` |
| เก็บภาพกลางทาง (แผงดิบ แผงที่ตัดแล้ว) | เติม `--keep /tmp/sheets` |
| สร้างลง `public/art/` จริง | `python3 art/tools/gen.py build <id>` |
| เพิ่มภาพใหม่ | ดู "เพิ่มภาพใหม่" ด้านล่าง |

`<id>` ดูพร้อมคำอธิบายได้ด้วย `list`:
- `icons-power` = ไอคอนพลังเทพ 9 ชิ้น (bless, curse, weapon, dream, heal, globe, fate, faith, dread) ใช้เวลาราว 70 วินาที
- `cine-flood` = ฉากเหตุการณ์น้ำท่วม ภาพ 16:9 ราว 25 วินาที

รายละเอียดที่ควรรู้:
- ผลลัพธ์เขียนที่ `<root>/public/art/ui/...` (`--root` ค่าเริ่มต้นคือรากของ repo; โฟลเดอร์ `public/art/` ถูกสร้างตอน build ครั้งแรก)
- เมล็ด (`--seed`) เป็นเลขอะไรก็ได้ ต่างเลขได้ภาพต่างกัน
- `--keep` เก็บเฉพาะภาพกลางทางของรอบนั้น (ชื่อไฟล์ไม่มีเลขเมล็ด) ใช้โฟลเดอร์แยกต่อรอบ

## กติกา

ทำ:
- ลองสร้างลงโฟลเดอร์ชั่วคราวก่อน (`--root /tmp/try`) แล้วดูภาพด้วยตาทุกครั้งก่อนเขียนลง `public/art/`
- แก้พรอมต์ เมล็ด ขนาด ที่ `manifest.json` ไม่ใช่ในสคริปต์ มันคือต้นทางความจริงของภาพแต่ละชิ้น
- เรียก ComfyUI ผ่าน `tools/comfy.py` เท่านั้น (ใช้ API ตั้งที่อยู่ด้วย `COMFY_URL`)
- ใช้ workflow ในโฟลเดอร์ `workflows/` (สำเนาที่ปักไว้กับเกม)
- ให้เกมเล่นได้เสมอเมื่อไฟล์ภาพไม่มี (ถอยกลับเป็นของเดิมในโค้ด)

ห้าม:
- ห้ามสร้างภาพหรือต่อภาพเข้าโค้ดเกม ถ้าเจ้าของไม่ได้ขอ
- ห้ามเพิ่มไฟล์ของเกมลงในโฟลเดอร์ของ ComfyUI (`~/Workspace/comfyui/`) มันใช้ร่วมกับงานอื่นของเจ้าของ เกมเขียนได้เฉพาะ `input/overseer/` กับ `output/overseer/` ผ่าน API
- ห้ามให้โมเดลวาดตัวหนังสือในภาพ (ภาษาไทยออกมาเละ) ตัวอักษรเป็นฟอนต์เสมอ
- ห้าม commit หรือ push ถ้าเจ้าของไม่ได้สั่ง ห้ามใส่ co-author (ดู [../.agent/RULE.md](../.agent/RULE.md))
- ห้ามรัน Qwen-Image-Layered รุ่น fp8 (ดูตารางปัญหา)

## เตรียมเครื่อง (ผ่านขั้นที่ 0 แล้วแต่ยังรันไม่ได้)

- Python 3 + Pillow: `python3 -c "import PIL"` ถ้าไม่มีจะขึ้นข้อความตอน `build`
- ComfyUI ที่ `http://127.0.0.1:8188` (ตั้งด้วย `COMFY_URL`) ทดสอบกับ 0.40.0 บน ROCm, RAM 32 GB
- โมเดลตาม `models.json` (มี sha256 ตรวจได้) และ custom node `ComfyUI-GGUF`

| อาการ | สาเหตุ | ทำ |

| งานค้างนาน แรมเต็ม swap | รัน Qwen-Image-Layered fp8 (20 GB) | ยกเลิกงาน (`POST /interrupt`) ถ้าไม่ตอบ `docker restart comfyui` ไม่ใช้รุ่นนี้ |

## เพิ่มภาพใหม่

1. เขียนรายการใน `manifest.json` (พรอมต์ เมล็ด ขนาด workflow ที่เก็บผลลัพธ์) แล้ว `build <id> --root /tmp/try` ดูผลด้วยตา
2. ไอคอน: ใช้แผงตารางบนพื้นเทาเรียบ แล้วระบุวิธีตัดต่อช่อง `birefnet` สำหรับของแข็ง `matte` สำหรับของเรืองแสง
3. เมื่อพอใจและเจ้าของอนุมัติ: `build <id>` ลง `public/art/`

## ต่อภาพเข้าโค้ดเกม (เมื่อเจ้าของขอ)

โค้ดเกมไม่โหลดภาพจาก `public/art/` เอง ต้องเขียนเพิ่ม โดยมีเงื่อนไขเหล่านี้ (ที่ทดสอบแล้วว่าใช้ได้):

- **ไอคอน** (`ic()` ใน `src/ui/icons.ts` คืน `<img>`): ใช้ `.webp` แทนไอคอนพิกเซลที่ชื่อตรงกัน เฉพาะขนาดตั้งแต่ 18 px ขึ้นไป เล็กกว่านั้นอ่านไม่ออก ให้ใช้พิกเซลเดิม ใส่ `onerror` ให้ถอยกลับเป็นไอคอนพิกเซลเมื่อไฟล์โหลดไม่ได้ ใช้ `import.meta.env.BASE_URL` นำหน้าที่อยู่ไฟล์ และ CSS ต้องไม่ใช้ `image-rendering: pixelated` กับภาพวาด
- **ฉากสำคัญ** (`playScene()` ใน `src/ui/cine.ts` วาดลง canvas 320×180): ถ้ามี `.webp` 1280×720 ให้เปลี่ยน canvas เป็นขนาดนั้นแล้ววาดภาพ (เลื่อนกล้องช้า ๆ ได้ มีเอฟเฟกต์ที่โค้ดวาดทับ เช่น ฝน) ระหว่างรอโหลดและเมื่อโหลดไม่ได้ ให้เล่นฉากพิกเซลเดิม ต้องตั้ง `image-rendering` ของ canvas เป็น `auto` เมื่อใช้ภาพวาด
- **เซิร์ฟเวอร์ production** (`TYPES` ใน `server/main.ts`) ต้องมี `'.webp': 'image/webp'`

## ไฟล์ในโฟลเดอร์นี้

| ที่ | คืออะไร |
| --- | --- |
| `manifest.json` | นิยามภาพแต่ละชิ้น: พรอมต์ เมล็ด ขนาด workflow ที่เก็บผลลัพธ์ ใครใช้ในโค้ด |
| `models.json` | โมเดลที่ต้องใช้: ชื่อไฟล์ โฟลเดอร์ ขนาด sha256 ต้นทาง |
| `workflows/` | `qwen21_t2i` (ข้อความเป็นภาพ), `qwen21_edit` (ลงสี/แก้ภาพ อ้างภาพด้วย `<image1>`), `cutout_birefnet` (ตัดพื้นหลัง), `wan22_ti2v5b_i2v` (ภาพนิ่งเป็นวิดีโอสั้น) |
| `tools/comfy.py` | ตัวเรียก ComfyUI ผ่าน API |
| `tools/gen.py` | `check` / `list` / `build` |

## ข้อจำกัดด้านภาพที่รู้แล้ว

- ไอคอนต้องอ่านออกที่ขนาดเล็ก ดูที่ขนาดจริงก่อนใช้
- กรอบแผงและพื้นผิว UI ที่ลองสร้างมืดเกินและตรงกลางทึบ ต้องปรับพรอมต์ก่อนใช้
- แนวภาพ (สีหม่น จริงจัง ไม่ใช้สัดส่วนการ์ตูน) อ้างตาม [../docs/appearance/README.md](../docs/appearance/README.md)
