# src/core

แกนจำลองของเกม ไม่มีจอ ไม่มี DOM ไม่มี Phaser (docs/guide/code-plan.md หัวข้อ 2 และ 6)

| โฟลเดอร์ | ทำอะไร |
| --- | --- |
| `types.ts` | สัญญากลาง ผู้นำ session เป็นเจ้าของ |
| `rng/` | สายเมล็ดตามชื่อ (หัวข้อ 6.2) |
| `clock/` | ปีโลกและปีชีวิต (หัวข้อ 2.4) |
| `state/` | สถานะเริ่มต้น |
| `save/` | เซฟและรุ่นของข้อมูล |
| `log/` | บันทึกเหตุการณ์ |
| `data/` | ตัวโหลดข้อมูลใน `data/gen/` และชนิดของแต่ละกลุ่ม (`types-<กลุ่ม>.ts` เจ้าของคือผู้สร้างข้อมูลของกลุ่มนั้น) |

ระบบอื่น (world story character ...) เพิ่มเป็นโฟลเดอร์ตามหัวข้อ 7
