# งานภาพที่สร้างด้วยโมเดล (art/)

**ทำเฉพาะเครื่อง Linux ของเจ้าของโปรเจกต์ที่มี ComfyUI** ถ้าไม่ใช่ (เช่น macOS) ข้ามไฟล์นี้และโฟลเดอร์ `art/` ทั้งหมด ไม่ต้องอ่านต่อ ไม่ต้องทำอะไร

ตรวจว่าใช่เครื่องนั้นไหม: `python3 art/tools/gen.py check` (exit 0 = ใช่) ถ้าใช่ อ่าน [../art/README.md](../art/README.md)

- อย่าสร้างภาพหรือต่อภาพเข้าโค้ดเกมถ้าไม่ได้ถูกขอ
- ComfyUI ใช้ร่วมกับงานอื่นของเจ้าของ: อย่าเพิ่มไฟล์ของเกมลงในโฟลเดอร์ของมัน
