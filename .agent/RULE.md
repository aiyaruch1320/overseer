# Rules

## Git

- Commit เล็กแต่จัดกลุ่มตามบริบท: หนึ่ง commit ต่อหนึ่งงานที่ชัดเจน ไฟล์ที่เป็นเรื่องเดียวกันอยู่ใน commit เดียวกัน (เช่น โฟลเดอร์เอกสารชุดเดียวกัน การย้ายไฟล์พร้อมแก้ลิงก์) ไม่ใช่หนึ่งไฟล์ต่อหนึ่ง commit และไม่รวมหลายเรื่องที่ไม่เกี่ยวกันไว้ด้วยกัน
- ข้อความ commit เป็นภาษาอังกฤษ ประโยคคำสั่งสั้น ๆ เหมือนประวัติเดิม (`Add ...`, `Move ...`) ใส่เนื้อความสั้น ๆ ได้เมื่อมีประโยชน์
- commit และ push (ไป `main`) เมื่อผู้ใช้สั่งเท่านั้น
- ห้ามใส่ co-author หรือ attribution ใด ๆ ในข้อความ commit และคำอธิบาย PR (ไม่มีบรรทัด `Co-Authored-By` และไม่มีบรรทัด "Generated with")
