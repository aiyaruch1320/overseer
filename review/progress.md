## หมายเหตุสำหรับผู้นำ (วิธีทำงานที่เรียนรู้ระหว่างทาง)
- commit หลังด่านผ่านเท่านั้น: ต่อคำสั่งด้วย `&&` ไม่ใช่ `;` (เคย commit ทั้งที่เทสต์แดงหลายครั้ง) · รัน `UPDATE_GOLDEN=1 npm run test:golden` ทุกครั้งที่ค่า tuning เปลี่ยน
- รวมสาขา: ใช้ชื่อสาขาตรง `worktree-agent-<id>` (ตัวแปรจาก `git branch --list` เคยว่างจนรวมไม่เกิด) · ไฟล์ golden ชนกันให้ `git checkout --theirs tests/golden` แล้วสร้างใหม่ · `src/ui/screens.ts` ชนกันบ่อย: เขียนรวมทุกบรรทัด import
- vite: `optimizeDeps.noDiscovery` พร้อมรายการ deps ใน vite.config.ts · เพิ่ม dependency ใหม่ต้องเติมรายการ ไม่งั้น preact ถูกโหลดสองชุดจน hooks พัง ("reading '__H'") · ถ้าค้างให้ลบ `node_modules/.vite` แล้วเปิด server ใหม่
- เบราว์เซอร์ใช้ร่วมกับ agent: สร้างแท็บของตัวเองและส่ง tabId ทุกครั้ง · แท็บเต็มเพดานได้: ปิดแท็บเก่าก่อนส่งผู้ตรวจ · agent ใช้ vite พอร์ตของตัวเอง (5191–5199) · แท็บพื้นหลังทำให้นาฬิกาเกมหยุด
- เทสต์ที่อิงเมล็ด: หาเมล็ดตามรูปที่ต้องการ (`seedWhere` ใน tests/tools/lineage.test.ts) แทนเมล็ดตายตัว · ค่าที่แกว่งตามการสุ่มให้วัดหลายช่วงเมล็ด (story-core `STORY_CORE_FROM`, GV-19)
- worktree ของ agent แตกจาก `main` ไม่ใช่ `code-phase`: บอกให้ agent `git reset --hard code-phase` ก่อนเริ่มทุกครั้ง (ใส่ไว้ใน brief)
- agent ไม่มีเบราว์เซอร์: ใช้ `node scripts/tools/shot.mjs <url> <png>` (Chrome headless มี GPU) · แผงเบราว์เซอร์ที่ถูกซ่อนวัดความเร็วไม่ได้
- LLM: ไม่เคยเรียกผู้ให้บริการจริง (DeepSeek มีค่าใช้จ่าย) ใช้ `--llm=fake` เท่านั้น
- ผู้ใช้ให้ตอบเป็นภาษาไทย (brief ของ agent เป็นอังกฤษได้)
