ผู้เล่นทั้งสองบุคลิกอ่านและเล่นได้ไม่พัง ปัญหาหลักคือข้อความที่ผู้เล่นเห็น (รหัสรั่ว ทางเลือกแสดงแค่ a b c) ตอนจบที่ไม่ตรงกับความตาย และจังหวะที่ไม่สม่ำเสมอ

## บั๊ก (แก้ใน M1 ก่อนขึ้น M2)

| ข้อ | ระดับ | ที่มา | เจ้าของ |
| --- | --- | --- | --- |
| T1 รหัสและเศษแม่แบบรั่วในบันทึก (cv. WR- BIO- PR- MK-16 bd.b1 sign.day jobpath "หรือ หรือ" "ศึก:  ·" "(แม่แบบ )") | หนัก | ทั้งสอง | text (ตัวแปลงบันทึกเป็นข้อความ) |
| T2 พิธีของเผ่าและจุดบรรจบแสดงแค่ "→ a" | หนัก | ทั้งสอง | text + story (บันทึกต้องมีป้ายของทาง) |
| T3 ป้ายทางที่ก๊อปจากเซลล์ทั้งก้อน อ่านเป็นประโยคไม่ได้ | หนัก | ผู้อ่านเรื่อง | text (ตัดส่วนที่เป็นผลออกจากป้าย) |
| T4 อารมณ์ต่อสาย (สหาย คนรัก ศิษย์) ขึ้นทั้งที่ยังไม่มีคนนั้น | หนัก | ทั้งสอง | text: ไม่แสดงจนระบบพวกพ้อง (M3) มีคนจริง |
| T5 บรรทัดสืบตำแหน่งของ NPC ที่ตัวละครไม่รู้จักท่วมจอ | หนัก | ผู้มาใหม่ | text: แสดง NPC ที่พบแล้วหรือในถิ่นเท่านั้น ที่เหลือระดับ 0 |
| T6 ไม่มีคำถามของชีวิต ตอนเกิดไม่บอกว่าตัวละครเป็นใคร | หนัก | ผู้มาใหม่ | ตัวสร้างเส้นเรื่อง (ธีมและคำถามจากหัวข้อ 1 ของไฟล์เผ่า) + text (บรรทัดเกิด) |
| T7 status ไม่บอกนิสัย งาน ครอบครัว คนใกล้ตัว | หนัก | ผู้มาใหม่ | tools |
| T8 ตายเป็นบรรทัดเดียวไม่มีเหตุ (สไลม์ 26 ถูกทำร้าย ยักษ์ 33 โรคภัย) | หนัก | ทั้งสอง | text: บรรทัดตายบอกเหตุและที่ (ลางเป็นงาน M2 attention) |
| T9 ชนชั้นเปลี่ยนไม่มีบรรทัดบอก | เบา | ผู้มาใหม่ | character เขียนบันทึก + text |
| S1 ตอนจบไม่ตรงความตาย: ประกาศปลายทางหลายแบบ ตายชราทั้งที่เลือกตายในศึกหรือออกไปรับแสง | หนัก | ผู้อ่านเรื่อง | story + character: ปลายทางเลือกครั้งเดียวตอนตาย ทาง e2 ที่บอกตายทำให้ตายจริง |
| S2 ปีเดียวมีหลายสิบบรรทัด ศึกหกครั้ง | หนัก | ผู้มาใหม่ | story: เส้นซ้อนทับไม่เปิดพร้อมกันเกินที่กำหนด ศึกในช่องหมายเหตุไม่ซ้ำกับศึกของทาง |
| S3 จุดหักเหไม่มีผลตามมา (ติดตามผู้กล้า ชิงตำแหน่ง สัตว์คู่หูหาย) | กลาง | ผู้อ่านเรื่อง | ส่วนใหญ่เป็นระบบ M3 (พวกพ้อง สัตว์คู่หู) · story: ความทรงจำของผู้กำกับโยงกลับมากขึ้นได้ |
