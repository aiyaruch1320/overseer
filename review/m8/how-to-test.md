# M8 ทดสอบกับผู้เล่นจริง: รายการที่ต้องทำ

เครื่องมือพร้อมแล้ว (บันทึกการเล่นในเกม · แบ่งชีวิตเป็นสองกลุ่มของผู้กำกับ · ตัววิเคราะห์ `m8-report`) ไฟล์นี้บอกว่าผู้ทดสอบต้องทำอะไร ตัวเลขฐานจากผู้เล่นจำลองอยู่ใน [baseline.md](baseline.md)

## 1. เริ่ม

1. `npm run serve` (หน้าเกมพร้อมเซิร์ฟเวอร์ LLM ถ้าตั้งกุญแจไว้แล้ว) หรือ `npm run dev` เปิดเกมในเบราว์เซอร์
2. ก่อนกด เริ่มชีวิต ที่หน้าเริ่ม กดลิงก์ **ตั้งค่าการทดสอบ (บันทึกการเล่น · A/B)** ใต้รายการแบบเริ่มต้นทางซ้าย (บล็อกเดียวกับที่ท้ายแผง ตั้งค่า บนจอดูชีวิต ตั้งตรงไหนก็ได้ ค่าเดียวกัน) ต้องเปิดก่อนชีวิตแรกเริ่ม ไม่งั้นชีวิตแรกไม่อยู่ในบันทึก แล้วในบล็อกนั้น
   - เปิดสวิตช์ **บันทึกการเล่นของฉัน** (ปิดอยู่เป็นค่าเริ่มต้น เก็บในเบราว์เซอร์นี้เท่านั้น ไม่ส่งไปไหน ไม่เก็บคำที่พิมพ์)
   - เลือก **แบ่งชีวิตเป็นสองกลุ่ม** เป็น `สลับทีละชีวิต` (ชีวิตที่ 1 ของโลกตามความคู่คี่ของเมล็ด ชีวิตถัดไปสลับ) หรือ `ตามเมล็ดโลก` ถ้าอยากให้ทุกชีวิตของโลกเดียวอยู่กลุ่มเดียวกัน
   - แผงบอกกลุ่มของชีวิตที่เล่นอยู่ ("กลุ่ม: ผู้กำกับเปิด/ปิด") การแบ่งมีผลกับชีวิตถัดไป ถ้าตั้งหลังเริ่มชีวิตแล้ว ให้เริ่มโลกใหม่
3. การแบ่งกลุ่มมีความหมายเมื่อเซิร์ฟเวอร์ LLM เปิด (เส้น `/api/llm/status` ตอบ enabled) ถ้าไม่มี LLM ผู้กำกับตามกติกายังทำงานทั้งสองกลุ่มและตัวเลขสองกลุ่มจะเท่ากัน บันทึกเก็บ `llmServer` ของแต่ละชีวิตไว้ให้ตรวจ
4. อย่าสลับสวิตช์ผู้กำกับด้วยมือกลางชีวิต (ถ้าสลับ บันทึกทำเครื่องหมายว่ากลุ่มของชีวิตนั้นไม่สะอาด)

## 2. ให้ผู้ทดสอบเล่นอย่างไร

- เล่นอย่างน้อย 4 ชีวิตต่อคน (2 ชีวิตต่อกลุ่ม) ใช้ความเร็วปกติอย่างน้อยหนึ่งชีวิต เพื่อวัดเวลา 25–45 นาที
- เล่นตามใจ ไม่ต้องอ่านคู่มือ เลือกคำปฏิญาณได้ทุกข้อหรือไม่เลือก
- เมื่อจบ 2 ชีวิตที่อยู่ต่างกลุ่ม ถามผู้ทดสอบด้วยปากว่า "ชีวิตไหนรู้สึกเป็นเรื่องเดียวกันมากกว่า" (เกณฑ์ผ่านของ A/B ในเอกสาร: ชีวิตที่มี LLM ถูกเลือก 60% ขึ้นไป) คำตอบนี้ไม่อยู่ในบันทึก ให้จดแยก (ชื่อไฟล์บันทึกกับเลขชีวิตกับคำตอบ)
- จดสิ่งที่บันทึกไม่เห็น: ตรงไหนงง หยุดเกมแล้วอ่านนาน การ์ดไหนรบกวน เรื่องไหนจำได้ว่าโยงกลับ

## 3. ส่งออกบันทึก

ตั้งค่า > **ส่งออกเป็นไฟล์ JSON** ได้ไฟล์ `overseer-record-<รหัส>.json` ในโฟลเดอร์ดาวน์โหลด (บันทึกรอดการรีโหลดหน้า เปิดเกมต่อแล้วบันทึกต่อในไฟล์เดิม · ล้างบันทึกได้ในแผงเดียวกัน) ส่งออกก่อนเปลี่ยนเครื่องหรือล้างข้อมูลเบราว์เซอร์

## 4. อ่านตัวเลข

```
npx tsx scripts/tools/m8-report.ts ~/Downloads/overseer-record-*.json
npx tsx scripts/tools/m8-report.ts a.json b.json --out=review/m8/round1.md   # หลายไฟล์รวมกัน เขียนลงไฟล์
npx tsx scripts/tools/m8-report.ts a.json --json                            # ตัวเลขดิบ
```

ผลคือตารางมาร์กดาวน์: คำปฏิญาณ 19 ข้อ + ไม่ปฏิญาณ (เสนอ เลือก สำเร็จ ไม่สำเร็จ) · วิกฤตพวกพ้อง (เกิด ขึ้นการ์ด เรียก ตอบ ผู้เล่นขยับ) · เรื่องโยงกลับต่อชีวิตแยกกลุ่ม · หยุดกับการ์ดต่อชีวิต · เวลาต่อชีวิต · การแทรกแซงต่อชีวิต · วิธีที่ผู้ทดสอบใช้เกม (หยุด ความเร็ว หยุดค้างนานเท่าไร) · ตอนจบ

เทียบกับผู้เล่นจำลองได้โดยรวมตารางของ [baseline.md](baseline.md) หรือสั่ง `--sim=เมตตา,สุ่ม --seeds=1-20 --arms` ผสมกับไฟล์จริงในคำสั่งเดียวกัน (กลุ่มของผู้จำลองใช้ชื่อนโยบาย ผู้เล่นจริงใช้ `player`)

## 5. ผ่านเมื่อ (จากเอกสาร)

| เรื่อง | ผ่านเมื่อ | ที่ |
| --- | --- | --- |
| A/B ผู้กำกับ | เลือกชีวิตที่มี LLM 60% ขึ้นไป และเรื่องโยงกลับต่อชีวิตของกลุ่มเปิดเพิ่มอย่างน้อย 15% | `docs/systems/llm/04-story.md` §3.5 |
| คำปฏิญาณ | สำเร็จ 40–90% เมื่อเลือกตั้งใจ ไม่เกิน 25% เมื่อสุ่ม | `docs/systems/god/08-goals.md` §8 |
| ความถี่ที่เกมเรียก | หยุด p50 6–10 · การ์ด p50 12–22 · การ์ดที่ไม่ทันไม่เกิน 3 ต่อชีวิต | `docs/systems/experience/07-attention.md` §5 |
| ความยาวชีวิต | 25–45 นาทีที่ความเร็วปกติ | `docs/systems/experience/01-one-life.md` |

## 6. ส่งต่อให้ผู้นำ

ส่งไฟล์บันทึกกับคำตอบปากเปล่าของผู้ทดสอบ แล้วรัน `m8-report` ผลที่ต้องตัดสินต่อ: ปรับตัวคูณผู้กำกับถ้าไม่ผ่าน (ตั้ง `llm_director` เป็นปิด ผู้กำกับตามกติกาอยู่ต่อ) · ปรับเงื่อนไขคำปฏิญาณที่เกินเป้า · ปรับความถี่ที่เกมเรียกตามตัวเลขจริง
