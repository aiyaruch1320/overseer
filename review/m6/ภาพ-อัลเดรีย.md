# ผู้ตรวจภาพ M6 · อัลเดรีย (AL, ไฟล์ a และ b)

บุคลิก: ผู้ชมที่เห็นเกมครั้งแรก และผู้ตรวจที่ถือเอกสารรูปลักษณ์ (npcs/05, npcs/06, 02-races, 04-enemies, 19-ally-successors, 21-pixel-art, README ข้อ 5) · ภาพที่ใช้: npc-05-aldria-a.png, npc-06-aldria-b.png (ท่า idle ซูม 4), enemies-AL.png, successors.png, races.png และภาพที่ถ่ายเองใน /tmp/rev-al (ซูม 6 ท่า idle, ซูม 3 ท่า attack, walk, die ของทั้งสองไฟล์, beasts.html?id=...) · สิ่งที่ทำ: ไล่ดู NPC ทั้ง 117 ตัว (56 + 61) ทุกประเทศ AL-01 ถึง AL-28 เทียบกับเอกสารทีละตัว สุ่มดูท่าอื่น ดูศัตรูและผู้สืบของ AL

## สิ่งที่เห็น

เปิดแผ่นแรกมาเห็นคนตัวเล็กสีหม่นยืนเรียง โทนรวมเป็นโลกเดียวกันจริง สีฐานเทา น้ำเงินกรมท่า น้ำตาล เขียวโคลน มีสีสดโผล่ทีละจุด เช่นสีแดงทองของ AL05-3, ตะเกียงเหลืองของ AL20-1 / AL20-3 / AL25-1, นีออนฟ้าของ AL13-2, ชมพูของ AL13-1 อ่านแล้วรู้ว่าเป็นโลกดิบจริงจัง ไม่ใช่การ์ตูนน่ารัก

พอไล่ดูทีละตัวจะเห็นสามอย่างซ้ำกันตลอด

1. เอลฟ์ทุกตัวหัวเป็นหมวกแหลมสีเขียวสด หูเป็นเส้นเฉียงสีแดงขาวข้างเดียวคล้ายลูกธนูเสียบหัว ไม่เห็นสีผมตามเอกสารเลย
2. คนจำนวนมากยกของชิ้นเดียวกัน (ม้วนกระดาษ หรือกล่อง/แก้วสี่เหลี่ยม) ขึ้นมาข้างหน้าท่าทางเหมือนกำลังดื่มหรืออ่าน ไม่ว่าเอกสารจะให้ถือพัด ไม้ตีเกราะ สมุดบัญชี หรือโพเดียม
3. ชายผมเทาเสื้อน้ำเงินกรมท่าหน้าตาเหมือนกันหลายตัว

ตัวที่อ่านออกทันทีและตรงเอกสาร: AL02-1 (หมวกสูงขาวทอง ไม้เท้า เคราขาว), AL04-1 (มงกุฎใหญ่ ชุดน้ำเงินขาวทองคลุมยาว), AL09-1 (ม่วงทองถือคทา), AL05-3 (ชุดรำแดงทอง พัดทอง เท้าเปล่า), AL05-4 (เขียวมะกอก ขวดน้ำหอมฟ้า), AL08-3 (ขาวทองผมบลอนด์), AL11-1 (หมวกเหลี่ยม เคราขาวยาว น้ำเงิน), AL11-4 (ผมดำยุ่ง แว่น), AL13-2 (ผมฟ้านีออน หมวกครอบหู), AL13-4 (ผมขาวชี้ ปักด้ายเขียวเรือง), AL14-3 (แดงน้ำตาล ถือเหยือก), AL16-1 (ผมขาวฟู ถือแก้วเบียร์ เท้าเปล่า), AL20-1 / AL20-3 (ตะเกียง), AL23-4 (จิ้งจอกส้ม), AL25-1 (ตะเกียงเขียวหม่น), AL25-2 (กูลเทาเขียวถือจอบ), AL25-3 (ผีโปร่งแสงถือดาบหัก), AL27-3 (ผมแดงดัดลอน ม่วงทอง), AL28-3 (คนแคระเกราะ ประแจ)

ท่า die ของทั้งสองไฟล์ล้มนอนเรียบร้อย ไม่มีชิ้นส่วนลอยหรือชนขอบเฟรม ท่า walk และ attack ไม่แตกหัก คนที่ถือของมือเดียวมักท่า attack เหมือน idle (ดูเป็นข้อเสนอด้านล่าง)

## สิ่งที่รู้สึก

- สวย: ชุดสีของแต่ละประเทศอ่านง่ายระดับสีหลัก (ลูเมียร์ขาวทอง เวนทาเรียน้ำเงิน ฟอร์เทียน้ำเงินเข้ม ซอมเมอร์เรนเขียวโคลน ไวลด์มาร์กขนสัตว์ เกรฟฮอลล์ดำเทา) ตะเกียงแถวมิสต์วอตช์เป็นจุดสว่างจุดเดียวที่ทำงานดีมาก
- งง: เอลฟ์ครึ่งเลือดสาวเลดี้ AL03-2 ที่ควรผมบลอนด์ถักไข่มุก กลับเป็นคนหัวเขียวเหมือนเอลฟ์ AL22-x และชายหนุ่ม AL02-3 ที่ควรเป็นผู้กล้าเกราะขาวทองกลับเป็นเด็กใส่เสื้อขาวกางเกงดำถือดาบ เหมือนนักเรียนที่หยิบดาบมา
- ขัดตา: เส้นหูแดงขาวบนหมวกเขียวของเอลฟ์ทุกตัวอ่านเป็นลูกธนูหรือขนนกเสียบหัว พอดูหลายตัวติดกันสีเขียวสดนี้กลายเป็น "สีสดจุดเดียว" ที่ซ้ำเกินไป (ประมาณ 20 ตัวใน AL) จนไม่ใช่สีสดพิเศษอีกต่อไป นอกจากนี้ของที่ยกขึ้นระดับหน้าทำให้ปากและครึ่งหน้าถูกบังในหลายตัว ดูเหมือนทุกคนกำลังดื่ม

## ข้อเสนอ

1. เปลี่ยนเอลฟ์ให้เห็นสีผมตามเอกสารและหูแหลมสองข้าง แล้วลดสีเขียวสดเหลือเฉพาะเสื้อ (ตามเผ่าเอลฟ์ในเอกสาร) ห้ามคลุมผมด้วยหมวกเขียว เพื่อให้ AL22 ห้าตัว และ AL16-4 กับ AL19-2 แยกกันได้
2. แยกของที่ถือให้ต่างกันตามค่า UI อย่างน้อยคนสำคัญ ไม้ตีเกราะ (AL08-2, AL15-1), พวงกุญแจ (AL01-1, AL21-1), พัด (AL03-2), สมุดบัญชี (AL10-1), พวงมาลัย (AL05-1), โพเดียม (AL06-1) และลดการยกของขึ้นบังหน้าในท่า idle ให้ถือข้างตัวแทน
3. ทำให้ชายผมเทาเสื้อน้ำเงินห้าตัว (AL04-4, AL06-1, AL08-1, AL08-4, AL10-4) ต่างกันด้วยสิ่งเดียวที่เห็นจากไกล (ทรงผม ปกเสื้อ หมวก หรือท่ายืน) ตาม README ข้อ 5
4. แก้เผ่าสัตว์ให้ต่างจากหมาป่า: นกต้องมีจะงอยและขนนก, เสือต้องผิวส้มลายดำ, กระต่ายต้องหูยาว, เรวาต้องหูเล็กและไม่มีหางใหญ่ ส่วน AL21-1 ต้องเป็นสีเทาเข้มตามเอกสารและมีกุญแจห้อยคอ
5. ตรวจศัตรู: gas_ghoul ต้องใส่หน้ากากเหล็กและก๊าซเหลืองให้เห็นตั้งแต่ idle, ตรวจแผ่น enemies-AL.png ว่าร่างต่อสู้ของ NPC มีชื่อตรงกับภาพ NPC หรือไม่ (เปิดด้วย beasts.html?id= ได้คนละภาพ) และใส่เกราะผู้กล้าให้ AL02-3, แขนจักรกลให้ AL13-1 / AL19-3, กระดานชอล์กให้ AL19-7S
