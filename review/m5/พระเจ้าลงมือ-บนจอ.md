# รีวิว M5: พระเจ้าลงมือ (ผู้เล่นจำลอง) ใช้ทุกพลังผ่านจอ

เล่นที่ 1280×720 บน localhost:5173 อ่าน docs/appearance/20-god-ui.md และ docs/systems/god/README.md ก่อน ชีวิตแรก "วีดอร์" อายุ 0 ถึง 57 ชีวิตสองเริ่มเพื่อลองคำปฏิญาณ ตั้ง LLM ปิดทั้งหมด

**ที่ใช้ console (ระบุตามข้อกำหนด)**
- `store.step()` เดินเวลาเพื่อรอคำอธิษฐาน การ์ดวิกฤต และอายุ 30 ถึง 57 (ทำให้ข้ามศึกอายุ 23 และ 27 ไปโดยไม่ได้ดูหน้าศึก)
- ตั้ง `light = 200..250` และ `dread = 100..150` เพื่อลองปาฏิหาริย์ ทดสอบเท่านั้น (ตอนปิดแผงพลังเป็น 0 เพื่อดูปุ่มเทา ก็เซ็ต 0 แล้วคืนค่า)
- เรียก `store.loadLocal()` เพราะหน้าจอไม่มีทางโหลด (ดูข้อ 1)
- กดค้างของปาฏิหาริย์ใช้ pointer event สังเคราะห์ 1.8 วิ เพราะเครื่องมือกดค้างจริงไม่ได้ (กดสั้นลองจริงแล้ว: ไม่ยืนยัน)

## สิ่งที่ตรงเอกสารดี (ควรรักษา)

- ปุ่มเทาบอกเหตุ ไม่ซ่อนปุ่ม (แสงไม่พอ ช่วยซ้ำ ซากครั้งเดียว ส่วนผสมซ้ำ น้ำพุกลางทรายต้องที่แห้งแล้ง)
- preview ปาฏิหาริย์ใหญ่ละเอียดมาก: ราคาสุทธิ หลังคืน ผลที่คาด เมืองหด NPC เสี่ยง ศรัทธาข้างเคียง ระยะรอ ช่องเหลือต่อชีวิต
- การ์ดชนิดต่าง ๆ ซ้อนไม่เกินสองใบ ถูกต้อง (ลาง + ศึก) มีปุ่มลิขิต/กระซิบ/ฝันบนการ์ด
- การดูของหีบมี "เหตุที่ขึ้น" ที่ท้ายหน้าต่าง และของคำสาปเอียง/เทาเมื่อพลังไม่พอ
- สวิตช์ปิดการ์ดคำอธิษฐานทำงาน ผลการนิ่งหมดเวลาถูก -2

## ข้อเสนอ

1. เพิ่มทางโหลด: ปุ่ม "เล่นต่อจากเซฟ" ที่หน้าเริ่มเมื่อมี `overseer.save.1` พร้อมข้อความบันทึกแล้ว/บันทึกไม่ได้ และคุมขนาดเซฟ (บล็อก)
2. แก้ preview ศรัทธาเทพของหีบให้ตรงกับผลจริง หรือแก้ผลให้ตรง preview (กลาง)
3. ย้าย `GodDialog` ขึ้นเป็นชั้นบนสุด หรือเปิดหน้ากระซิบพร้อมเลือกพวกพ้องและหน้ายืนยัน เมื่อกดจากชั้นพวกพ้อง และเปิดจากการ์ดวิกฤตให้เลือกอัตโนมัติ ขึ้นป้าย ✦ ใน dropdown ของกระซิบ (หนัก)
4. ใส่ชื่อพวกพ้องและคำว่า "ขณะวิกฤต" ใน preview กระซิบ ใส่ค่าปรับสลับสายใน preview ปาฏิหาริย์
5. ให้ยกเลิกลางคืนช่อง "ใหญ่" และ `world.ruin` หรือเขียนไว้ในหน้ายืนยันยกเลิก
