# นักหาช่อง · รอบ M2 (ระบบพระเจ้า)

**บุคลิก** นักหาช่อง: หาทางโกง ทำซ้ำ ใช้เพดาน ดูว่าตัวเลขแตกไหม มีช่องที่ทำให้เกมเสียไหม

**เมล็ดที่ใช้** 304 305 306 307 308 309 (เล่นผ่าน `npm run play`) · 310 (`npm run life` นโยบาย สุ่ม และ เก็บพลัง) · สคริปต์ทดสอบเสริมที่เรียก `command()` ของแกนตรงใช้เมล็ด 304–315 และ 400–439

**วิธีที่ใช้ทำซ้ำ** ทุกคำสั่งด้านล่างรันจากโฟลเดอร์โปรเจกต์ ตั้งโฟลเดอร์เซฟก่อนเพื่อไม่ปนกับของคนอื่น: `export OVERSEER_PLAY_DIR=/tmp/ovs-play; rm -rf $OVERSEER_PLAY_DIR`

## สิ่งที่ทำ

1. ทอยหีบ: เปิดหีบ ทอยครบสามครั้ง ทอยแบบล็อก ล็อกช่องว่าง ล็อกเลข 0 ติดลบ ทศนิยม ทอยครั้งที่สี่ หยิบช่อง 0 7 ติดลบ ทศนิยม ตัวเลขยาว 20 หลัก เปิดหีบซ้อน เปิดหีบแล้วทิ้งข้ามปี
2. คำสั่งเดียวกันซ้ำในจังหวะเดียว: `chest` `dream` `whisper` `answer` `yes` ซ้ำ `--yes` ร่วมกับ `yes` พิมพ์ใหญ่ `YES`
3. ปาฏิหาริย์: ซ้ำก่อนพ้นระยะรอ (นับถอยหลังตาม `advance`) ปาฏิหาริย์กลางครบ 4 ครั้งและห่าง 5 ปีโลก มหา (MR-21) ที่แสงศรัทธา 0 50 119 120 120.5 199.9 200 ส่งปาฏิหาริย์ทุกแบบพร้อมกันในจังหวะเดียว ปลอบ/ยั่วมังกรทั้ง 15 ตัวในจังหวะเดียว ยั่วมังกรที่อารมณ์ต่ำ
4. ยกเลิกลาง MR-21 แล้วสั่งใหม่ ยกเลิกซ้ำ ยกเลิกเลข 0 ติดลบ 999 ยกเลิกหลังตัวละครตาย สั่ง MR-21 ก่อนตายหนึ่งจังหวะ
5. ตอบคำอธิษฐานที่หมดเวลา ตอบใบที่ไม่มี ตอบซ้ำ ตัวเลือกของแปลก -1 0 4 99 1.5 ตอบแทนผู้ขอที่ตายไปแล้ว
6. หลังตัวละครตาย: ทุกคำสั่งของพระเจ้า `advance`
7. ค่าแปลก: ข้อความ 100,000 ตัวอักษร ตัวเลขลบ ทศนิยม `5e-1` `1e9` `NaN` `×0.5` รหัสที่ไม่มี ชื่อซ้อน อีโมจิ `--seed=-1 0 1e10 99999999999999999999`
8. `yes` โดยไม่มีคำสั่งรอ · `no` · `yes` สองครั้ง
9. เปลี่ยนความถี่ที่เกมเรียก: ไม่มีคำสั่งในเครื่องมือ `play` จึงส่ง `command({type:'settings'})` เข้าแกนโดยตรง และแก้ไฟล์เซฟ
10. นโยบาย: `npm run life -- --seed=310 --policy=สุ่ม` และ `--policy=เก็บพลัง` และกวาดทั้งแปดนโยบาย × 14 เมล็ด (304–317) × ชีวิตเต็ม ตรวจแสงศรัทธา ความหวาดกลัว ศรัทธาเทพ ทุกจังหวะ
11. ตรวจ preview: เทียบไฟล์เซฟก่อนและหลังรันที่มีแต่ตัวอย่างผล (md5) และเทียบ JSON ของสถานะทั้งก้อนก่อนและหลัง 216 ตัวอย่างผล
12. เทียบราคาในตัวอย่างผลกับพลังที่หักจริง 677 คำสั่ง
13. สุ่มคำสั่งปนกัน 15,826 คำสั่ง × 40 เมล็ด (พลังถูกเติมให้เต็มเป็นระยะ) ตรวจว่าไม่ล้ม ไม่มีค่าออกนอกช่วง

## สิ่งที่เห็น

ผมเริ่มจากหีบเพราะเป็นของที่ล่อให้โกงที่สุด เปิดหีบแล้วทอยสามครั้งได้จริง ราคา 5 → 10 → 20 ตรงเอกสาร ล็อกหนึ่งใบบวก 5 ตรง ครั้งที่สี่ถูกปฏิเสธว่า "ทอยหีบใหม่ครบสามครั้งแล้ว" ใบที่ถูกทอยทิ้งไม่โผล่อีก ผมลองทุกทางที่เป็นตัวเลขแปลก (0 ติดลบ ทศนิยม ตัวหนังสือ 20 หลัก) เกมตอบสุภาพว่า "ช่องนี้ว่าง" หรือขึ้นวิธีใช้ ไม่ล้มสักครั้ง ผมเปิดหีบที่สองในปีเดียวกันไม่ได้ ข้ามหีบไม่คืนสิทธิ์ ทิ้งหีบไว้ข้ามปีหีบหายไปเอง

จากนั้นผมไล่กดคำสั่งเดียวกันรัว ๆ: กระซิบ "ระวัง" ซ้ำถูกกันด้วย "คำใบ้เดียวกันซ้ำไม่ได้" กระซิบครบสามครั้งแล้วคำที่สี่ถูกกัน ส่งฝันแล้วทางที่เสนอหมดทันที ตอบคำอธิษฐานใบเดียวกันสองครั้งไม่ได้ `yes` ซ้ำไม่ทำอะไร ทุกอย่างมีเพดาน

ปาฏิหาริย์เล็กใช้ซ้ำก่อนพ้นระยะรอไม่ได้ ระยะรอนับถอยหลังตามเวลาจริง (5 ปีโลกเหลือ 4 3 1 ตามที่เดิน) ปาฏิหาริย์กลางห่างกัน 5 ปีโลกและครบ 4 ครั้งต่อชีวิตตามเอกสาร พอข้ามเวลาในสคริปต์ครั้งที่ห้าถูกปฏิเสธ MR-21 ต้องมีแสงศรัทธา 120 พอ 199.9 หักไป 199 เหลือ 0.9

เสร็จแล้วผมหาช่องในเรื่องที่เอกสารเงียบ เจอสี่เรื่องที่ทำให้สะดุด (ดูหัวข้อปัญหา) ที่ผมคิดว่าใหญ่สุดคือ **ตั้งค่าความถี่ที่เกมเรียกเป็นค่าที่ไม่มีอยู่ แกนตอบ ok แล้วเกมล้มทุกจังหวะต่อจากนั้น** และ **คำตอบแบบแปลกให้พรระดับหายากในราคาเท่าคำอธิษฐานตัวเล็ก** (ถูกกว่าหีบสี่เท่า)

ฝั่งนโยบาย: แปดนโยบาย × 14 ชีวิตเต็ม แสงศรัทธากับความหวาดกลัวไม่เคยเกิน 200 ไม่เคยติดลบ ไม่เป็น NaN ศรัทธาเทพอยู่ในช่อง −100 ถึง 100 ตลอด นโยบาย เงียบ ถือพลัง 200 เต็มเพดานตอนตายใน 7 จาก 14 ชีวิต เก็บพลัง 5 จาก 14 (พลังที่เหลือหลังหารสองเหลือ 100 พอดี) เมื่อตายทายาทได้พอดี 50% ทุกครั้ง ตัวเลขนี้ไม่แตก (พลังส่วนเกินเกิน 200 ถูกตัดทิ้งเงียบ ๆ ระหว่างทาง ไม่มีโทษและไม่มีข้อความบอก)

ตัวอย่างผลไม่แตะสถานะเลย: ไฟล์เซฟตัวเดิมก่อนและหลังรันตัวอย่างผลทุกชนิด md5 ตรงกัน (`610c87328b92188752cf76036c1557b8`) สถานะทั้งก้อนเป็น JSON เหมือนเดิมใน 216 ตัวอย่างผล ราคาที่ตัวอย่างผลบอกตรงกับที่หักจริงทุกคำสั่ง ยกเว้นปาฏิหาริย์สายทำลายที่ได้ความหวาดกลัวคืน 1 ใน 3 (ดูปัญหา)

สุ่มคำสั่งปนกัน 15,826 คำสั่ง สำเร็จ 6,600 ไม่มีสักคำสั่งที่ทำให้แกนโยนข้อผิดพลาด

## สิ่งที่รู้สึก

- **ลุ้น/สนุก** ตอนทอยหีบสามครั้งแล้วเห็นของหายากโผล่ครั้งที่สามถึงสี่ ความรู้สึกว่ายอมจ่ายแพงเพื่อเสี่ยงดี
- **เบื่อ** ที่ไม่มีทางทำให้พลังพุ่งแบบวนได้ เพดานและราคาปิดช่องเกือบหมด นักหาช่องหาไม่เจอสูตรเงินไหลไม่รู้จบ (ดีสำหรับเกม)
- **งง** ตอนข้อความผิดพลาดของลิขิตขึ้น "ชะลอได้ ถึง" โดยไม่มีตัวเลข และตอนคำสั่ง `options` บอกว่ากระซิบไม่ได้ทั้งที่กระซิบคำอื่นได้
- **รำคาญ** ตอนตอบคำอธิษฐานของคนที่ตายไปแล้วได้ ยังเสียแสงศรัทธา 12
- **ตกใจ** ตอนแก้เซฟค่าเดียวแล้ว `advance` ล้มทั้งเกม

### หนัก

**H1 ค่าตั้งความถี่ที่เกมเรียกไม่ถูกตรวจ ใส่ค่าที่ไม่มีแล้วเกมล้มทุกจังหวะ**
- ที่เกิด `src/core/command/index.ts` ฟังก์ชัน `applySettings` (รับ `attention` `speed` `lang` ทุกค่า ไม่ตรวจชุดค่า) ผลไปล้มที่ `src/core/attention/index.ts` `ruleOf` (บรรทัด 27 อ่าน `rules[settings.attention]` ได้ undefined แล้ว `step` บรรทัด 104 อ่าน `.cardGap`) ตัวโหลดเซฟ `src/core/save` ก็ไม่ตรวจค่าตั้ง
- ผล `command({type:'settings',patch:{attention:'turbo'}})` ตอบ `ok:true` แล้วทุก `beat` ถัดไปโยน `TypeError: Cannot read properties of undefined (reading 'cardGap')` เกมเดินต่อไม่ได้จนกว่าจะแก้ค่ากลับ พร้อมกันนั้น `speed:'warp'` `speed:-1` `lang:'en'` `llm.setup:'yes'` ถูกเก็บลงสถานะด้วย (ไม่ล้มทันที แต่ค่าผิดชนิดอยู่ในเซฟ) ส่วน `attention` ที่เป็นสตริงว่างหรือ null ถูกข้าม (ไม่เปลี่ยน) และ `'constructor'` `'__proto__'` ผ่านเงียบ ๆ
- ทำซ้ำผ่าน `play` (ไม่มีคำสั่งตั้งค่าในเครื่องมือ จึงแก้ไฟล์เซฟแทน ซึ่งเป็นเส้นทางเดียวกับเซฟเสียหรือเซฟที่แก้มือ):
  ```
  export OVERSEER_PLAY_DIR=/tmp/ovs-play; rm -rf $OVERSEER_PLAY_DIR
  npm run play -- --seed=309 --new --cmd="advance 1"
  sed -i '' 's/"attention":"normal"/"attention":"turbo"/' /tmp/ovs-play/309.json
  npm run play -- --seed=309 --cmd="advance 4"      # ล้ม: TypeError ... 'cardGap' (attention/index.ts:104)
  ```
- ทำซ้ำผ่านแกนตรง (ยืนยันว่าคำสั่งรับค่าเสีย): สร้าง session เมล็ด 305 เดิน 4 จังหวะ แล้ว `command(ctx,{type:'settings',patch:{attention:'turbo'}})` แล้ว `game.beat()` สองครั้ง
- ค่าที่ใช้ได้จริงคือ `low` `normal` `high` (`low` เรียกน้อยลง: 2 ครั้งใน 11 ปีชีวิตเทียบ 3 ของ `normal` และ `high` ในเมล็ด 305 ตามที่ควรเป็น)

### กลาง

**M1 คำตอบ "ให้แบบแปลก" ให้พรระดับหายากในราคาของคำอธิษฐานตัวเล็ก ข้ามตัวกรองของหีบ**
- ที่เกิด `src/core/god/acts/prayers.ts` `strangeOptions` เลือกจากพรทุกใบระดับ C U R ที่ยังไม่มี และไม่ใช่พรเฉพาะเผ่า ไม่ผ่านตัวกรองหีบ (เงื่อนไขถิ่น `fromCond` คำสั่ง `blessClash` ของเผ่า วัย ระดับ L) ราคาคือราคาคำอธิษฐาน (6 ถึง 25) ไม่ตามระดับของพร ตัวอย่างผลไม่แสดงระดับของพรที่ให้เลือก
- ตัวเลข: คำอธิษฐาน 446 ใบ (36 เมล็ด) ได้ตัวเลือก 1,338 ตัว ระดับ R 404 ตัว (30%) ใบแม่ขอให้ลูกแข็งแรงราคา 6 แต่หีบขายพร R ที่ 26 และโอกาส R ต่อช่องในหีบราว 2 ถึง 7% ตัวเลือกที่ขัดกับเผ่า (`blessClash`) 26 ตัว (เมล็ด 308 ใบที่ 1 เสนอ "หัวใจเมตตา" ซึ่งเผ่าของเขาห้าม)
- ทำซ้ำ:
  ```
  npm run play -- --seed=306 --new --cmd="advance; answer 1 แปลก 3; yes; status"
  ```
  คำอธิษฐานใบที่ 1 (แม่ขอให้ลูกแข็งแรง ราคา 6) ตัวเลือกที่ 3 "ตรากรอม-ธาร" (`nb_mark_gromdhar` ระดับ R ผูกกับประเทศ SH-03 SH-17 ตัวละครไม่ได้อยู่ที่นั่น) ได้พรจริง แสงศรัทธา 49.3 → 45.3 (หักจริงสุทธิ 4 หลังได้คืน 2) เมล็ด 304 ใบที่ 1 (ขอให้สงครามจบ ราคา 25) เสนอ R สองในสามใบ (ใช้ `answer 1 แปลก` ดูรายชื่อ แต่ระดับไม่ถูกแสดง ต้องดูจากข้อมูลพร)
- เอกสาร [../../docs/systems/god/03-dreams.md](../../docs/systems/god/03-dreams.md) ตารางคำตอบ (แถว ให้แบบแปลก: "เท่ากับให้ ... ตรงคำขอ") และ [../../docs/systems/god/02-bestow.md](../../docs/systems/god/02-bestow.md) หัวข้อ 6 ("ขึ้นเฉพาะของที่ตรงกับคำขอ") ไม่ได้กำหนดระดับสูงสุดหรือว่าต้องผ่านตัวกรองหีบ ช่องว่างนี้ทำให้คำอธิษฐานตัวเล็กเป็นทางลัดไปหาพร R

**M2 คำอธิษฐานของผู้ขอที่ตายไปแล้วยังตอบได้ เสียพลังและเล่าว่าหายป่วย**
- ที่เกิด ใบ `kin_sick` (ขอให้คนสำคัญหายป่วย) ไม่ถูกถอนเมื่อ NPC ผู้ขอตาย (`src/core/god/acts/prayers.ts` เช็กตอนสร้างใบ ไม่เช็กตอนตอบ `checkAnswer`)

  ```
  npm run play -- --seed=305 --cmd="miracle MR-21; yes; cancel 1; yes; miracle MR-21"
  ```
  ได้ แสงศรัทธา 179.9 → 0.9 → 89.9 แล้วสั่งใหม่ถูกปฏิเสธ "ปาฏิหาริย์ระดับมหาใช้ได้ครั้งเดียวต่อชีวิต" ผู้เล่นเสียปาฏิหาริย์มหาของชีวิตนั้นไปพร้อมแสงศรัทธาครึ่งหนึ่ง ถ้าตั้งใจ ควรเตือนในหน้ายืนยันของ `cancel`; ถ้าไม่ตั้งใจ ควรคืนเพดานและระยะรอ (ไม่ใช่ช่องโกง: ราคายังเสียครึ่งหนึ่ง) เอกสาร [../../docs/systems/god/04-miracles.md](../../docs/systems/god/04-miracles.md) หัวข้อ 1 ข้อ 3 บอกแค่ "คืนพลังครึ่งหนึ่ง"
- เรื่องคู่กัน: ถ้าสั่ง MR-21 ในจังหวะสุดท้ายก่อนตัวละครตาย ลางไม่ทันถูกยกเลิก (หลังตายสั่ง `cancel` ไม่ได้) ปาฏิหาริย์เกิดหลังตาย พลังที่จ่ายหมดไปโดยตัวละครไม่ได้ประโยชน์ (สคริปต์เมล็ด 305 สั่งหนึ่งจังหวะก่อนตาย GD-04 บันทึกหลังตาย) ส่วนผลต่อทายาทยังทดสอบไม่ได้เพราะยังไม่มีระบบทายาท (อ่านจากสูตร `happenedSince`: ทายาทเกิดหลังเหตุการณ์จึงไม่ได้ ×1.5)

### เบา

**L1 MR-05 รวมกับลิขิตลงต่ำกว่าพื้น ×0.2 และเขียนทับลิขิต**
- `holdEvent` (`src/core/world/api.ts`) เขียนทับ ไม่ซ้อน; MR-05 (`src/core/god/acts/set.ts`) ตั้งน้ำหนักเป็น `weightOf × 0.5` ดังนั้นลิขิต ×0.2 ของ WR-03 แล้ว MR-05 ในประเทศ MH-09 ได้น้ำหนัก **0.1** ต่ำกว่าช่วงในเอกสาร 0.2 ถึง 3 ([../../docs/systems/god/04-miracles.md](../../docs/systems/god/04-miracles.md) หัวข้อ 4) ขณะที่บันทึกลิขิตยังเขียน ×0.2 ในทางกลับกัน (อ่านจากโค้ด ไม่ได้รัน) MR-05 หลังลิขิตเร่ง ×3 ที่จ่ายความหวาดกลัว 60 จะเหลือ ×1.5 โดยบันทึกลิขิตยังเขียน ×3 ทำซ้ำไม่ได้ผ่าน `play` (ต้องมีประเทศในสงคราม) ใช้สคริปต์: session เมล็ด 304 เดิน 8 จังหวะ ตั้ง `light=200` `setFlag(ctx,'MH-09','war')` แล้ว `command` `decree {event:'WR-03',mul:0.2}` ตามด้วย `miracle {id:'MR-05',country:'MH-09'}` อ่าน `weightOf(ctx,'WR-03')` ได้ 0.1
- ลิขิตซ้ำในเหตุการณ์เดียวกันถูกกัน ("ซ้อนกันไม่ได้") ถูกต้อง แต่ถูกข้ามได้ทางนี้

**L2 `options` (และบรรทัด "ทำได้ตอนนี้") ใช้คำใบ้ `ระวัง` เป็นตัวแทนของกระซิบทุกคำ**
- `scripts/tools/god-commands.ts` `options` กับ `doableNow` ทดสอบกระซิบด้วยคำเดียว หลังกระซิบ "ระวัง" แล้ว `options` บอก "ยังทำไม่ได้: คำใบ้เดียวกันซ้ำไม่ได้ภายในปีเดียว" ทั้งที่ "กล้าเถิด" ยังกระซิบได้
- ทำซ้ำ `npm run play -- --seed=307 --new --cmd="whisper ระวัง; yes; options; whisper กล้าเถิด"` (บรรทัด whisper ใน options ผิด; คำสั่งสุดท้ายออกตัวอย่างผลได้)

**L3 ข้อความผิดพลาดถูกตัดตัวเลขหรือคำที่ผู้เล่นพิมพ์ (ตัวกรอง `scrub`)**
- `decree อันดาร์ตื่น 0.19` → "ชะลอได้ ถึง" และ `3.01` → "เร่งได้ ถึง" (ช่วงที่ควรบอก ×0.2 ถึง ×0.9 / ×1.1 ถึง ×3 หายไป); `decree ... 1` → "ต้องระบุตัวคูณ ที่ไม่ใช่ 1"; `whisper foo` → `ไม่มีคำใบ้ " "` (คำ foo หาย) `miracle MR-23` ไม่ใส่มังกร → "ไม่ระบุมังกร" (วงเล็บช่วง 0 ถึง 14 หาย)
- ทำซ้ำ `npm run play -- --seed=304 --new --cmd="decree อันดาร์ตื่น 0.19; decree อันดาร์ตื่น 3.01; whisper foo"`

**L4 ตัวอย่างผลของปาฏิหาริย์สายทำลายแสดงราคาเต็ม ไม่แสดงว่าได้ความหวาดกลัวคืน 1 ใน 3**
- MR-07 08 09 12 24 (และสายทำลายอื่น) ตัวอย่างผลบอก "ความหวาดกลัว 20" หักจริงสุทธิ 13 (เทียบ 677 คำสั่ง ต่างกันเฉพาะแถวนี้) เอกสาร [../../docs/systems/god/01-power.md](../../docs/systems/god/01-power.md) หัวข้อ 1 บอกคืน ÷3 ทำซ้ำ `npm run play -- --seed=305 --new --policy=เก็บพลัง --cmd="advance 232"` แล้ว `npm run play -- --seed=305 --cmd="miracle MR-07; yes"` ได้ ราคา ความหวาดกลัว 24 แต่ 27.4 → 11.4 (หัก 16 สุทธิ)
- ยังมี `miracle MR-01`/`MR-02` ในประเทศที่ไม่มีภัยแล้ง/โรค ได้ผลจริงแค่ราคาอาหาร/ยา แต่บันทึกเขียนว่า "ภัยแล้งจบ" "ผู้ป่วยหาย โรคระบาดจบ" ทั้งที่ไม่มี (เมล็ด 304 ประเทศมีธง `war` เท่านั้น): `npm run play -- --seed=304 --new --cmd="miracle MR-01; yes; log 2"`

**L5 คำอธิษฐานตอบได้เกินเวลาหนึ่งจังหวะ และตอบใบที่หมดเวลาได้ข้อความเดียวกับใบที่ไม่เคยมี**
- ใบอายุ 14 จังหวะ (`exp` − `tick` = 14) แต่ที่จังหวะ `tick == exp` ยังตอบได้ (สคริปต์: จังหวะที่ 14 และ 15 `answer` ผ่านทั้งคู่ ใบหายเมื่อจังหวะถัดไป) `src/core/god/acts/prayers.ts` เช็ก `card.exp > tick` ก่อนลบ ตัวนับ "เหลือเวลา" ใน `waitingLines` ขึ้น 0.0 ปี
- ตอบใบที่หมดเวลา: "ไม่มีคำอธิษฐานใบนั้น" ซ้ำกับใบเลขที่ไม่เคยมี `npm run play -- --seed=306 --new --cmd="advance 40; answer 1 ให้"` (ใบ 1 หมดเวลาตอนอายุ 7) ได้ข้อความเดียวกับ `answer 99 ให้`

**L6 ทอยหีบใหม่เพิ่มตัวชดเชยความหายากทุกครั้ง ไม่ใช่ต่อหีบ**
- `settleComp` ถูกเรียกทั้งตอน `openChest` และ `rerollChest` ตัวชดเชย +2 ต่อการสุ่มหนึ่งครั้ง เอกสาร [../../docs/systems/god/02-bestow.md](../../docs/systems/god/02-bestow.md) หัวข้อ 3 พูดถึง "ต่อหีบ" วัด 146 ชีวิตที่อายุ 20 เปิดหีบแล้วทอยครบ: มีพร/ฝีมือ/ของ R ขึ้นไปในการสุ่มครั้งที่ 1 2 3 4 ที่ 18% 14% 36% 45% รวมโอกาสเห็นอย่างน้อยหนึ่งใบในสี่ครั้งราว 75% (จ่าย 35 แสงศรัทธา) เทียบ 18% ครั้งเดียว ไม่ใช่ช่องโกง (ต้องจ่าย) แต่น่าจะเกินที่เอกสารตั้งใจ: ถ้านับต่อหีบ การทอยไม่ควรดันตัวชดเชย

**L7 `--policy` ติดอยู่ในเซฟตลอด**
- `scripts/tools/play.ts` เขียน `state.god.ext.policy` ทุกครั้งที่ใส่ `--policy` และ `policyOf` อ่านค่าจากเซฟเมื่อไม่ใส่ การเล่นต่อโดยไม่ใส่ธงยังมีนโยบายตอบคำอธิษฐานแทนผู้เล่น (เห็นจากบันทึก "ท่านให้ตามคำอธิษฐาน..." ในการ `advance` ที่ไม่ใส่ธง) ไม่มีวิธีปิด นอกจาก `--new`

**L8 ชื่อมังกรจับแบบมีคำนั้นอยู่ในชื่อ**
- `refOf` ใน `god-commands.ts` ใช้ `d.id.includes(t)` พิมพ์พยางค์เดียวก็เจอมังกรตัวแรกที่มีพยางค์นั้น: `miracle MR-23 อ` ได้ "โอรัน-ซัล" ราคา 40 ตัวอย่างผลแสดงชื่อมังกรก่อนยืนยัน แต่ถ้ามี `--yes` จะทำทันที ทำซ้ำ (ต่อจากเซฟข้างบน) `npm run play -- --seed=305 --cmd="miracle MR-23 อ"` ได้ตัวอย่างผลของ "โอรัน-ซัล"

**L9 `decree <ชื่อ> ×0.5` ถูกปฏิเสธ ทั้งที่คำแนะนำในเกมเขียนด้วย ×**
- บรรทัดที่เกมพิมพ์ "decree <ชื่อ> <×0.2–0.9 ชะลอ | ×1.1–3 เร่ง>" ทำให้พิมพ์ `×0.5` แต่ `Number('×0.5')` เป็น NaN ได้ "ใช้: decree <เหตุการณ์> <ตัวคูณ>" ทำซ้ำ `npm run play -- --seed=304 --new --cmd="decree อันดาร์ตื่น ×0.5"` (`0.5` ผ่าน)

(ข้อสังเกตด้านออกแบบที่ไม่นับเป็นปัญหา: ปาฏิหาริย์ยั่วมังกร MR-24 ดันอารมณ์ติดลบได้ (3 → −7) ช่วงอารมณ์ในโค้ดคือ −100 ถึงเพดาน และเอกสาร dragon-mood บอกต่ำกว่า 3 ล้มแน่ ดังนั้นยั่วมังกรที่อารมณ์ต่ำกว่า 13 คือใบสั่งให้มังกรล้มทศวรรษหน้า ซึ่งใกล้ขอบเขตกติกาเหล็กข้อ 2 "ปาฏิหาริย์ไม่ฆ่ามังกร" แต่ผ่านเงื่อนไขของมังกรเอง)

## ข้อเสนอ

1. **ตรวจ `settings` ให้ตรงชุดค่าที่มี** (`attention` ∈ low/normal/high, `speed` ∈ pause/normal/fast, `lang` ∈ th, `llm.*` เป็นบูลีน) แล้วปฏิเสธด้วยเหตุผลแทนรับ และให้ `ruleOf` ถอยไป `normal` เมื่อเจอค่าไม่รู้จัก; ให้ `load()` ตรวจค่าตั้งด้วย (แก้ H1)
2. **จำกัดคำตอบแบบแปลก**: ผ่านตัวกรองหีบ (เงื่อนไขถิ่น เผ่า วัย ขัดกัน) ระดับสูงสุด U หรือราคาตามระดับของพรที่เลือก และแสดงระดับของพรในตัวอย่างผล (แก้ M1)
3. **ถอนใบอธิษฐานเมื่อผู้ขอตาย** และทำให้ข้อความตอบใบหมดเวลาแยกจากใบที่ไม่มี (M2, L5)
4. **ตัดสินว่ายกเลิกลางคืนเพดานหรือไม่** แล้วเขียนลงเอกสาร; ถ้าไม่คืน หน้ายืนยันของ `cancel` ต้องเตือน และตัวอย่างผลสายทำลายควรบอกราคาสุทธิหลังคืน ÷3 (M3, L4)
5. **ให้ลิขิตและ MR-05 ใช้ช่องน้ำหนักเดียวที่มีพื้น 0.2 และบันทึกว่าใครตั้ง** (ไม่เขียนทับกัน) และให้ตัวชดเชยหีบนับต่อหีบ ไม่นับตอนทอย (L1, L6)

## ของที่ผมลองแล้วไม่แตก (เพื่อรอบหน้าไม่ต้องลองซ้ำ)

- ทอยหีบ ล็อก หยิบ ข้าม: เพดานและราคาตรงเอกสาร อาวุธประทานไม่เกิน 1 ของประทานไม่เกิน 3 พรและคำสาปไม่ซ้ำ (จำลองเลือกทุกปี 8 เมล็ด)
