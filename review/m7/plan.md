## 3. โหมดประหยัด (account ที่โควตาน้อย)

ผู้ใช้สลับมาทำแกนของ M7 ด้วย account ที่โควตาราวหนึ่งในห้าของ account เดิม ให้ทำไปจนสุดก่อน ถ้าไม่ไหวผู้ใช้จะสลับกลับ

- ทำตามลำดับ ก1 → ก2 → ก3 → ก4 → ก5 แล้วค่อย ข ทีละข้อ
- agent พร้อมกันไม่เกิน 2 ตัว ทุกตัว `model: "sonnet"` brief สั้นและบอกไฟล์ที่เป็นเจ้าของชัด
- ทำเองในฐานะผู้นำเฉพาะงานเล็ก งานที่ต้องอ่านโค้ดเยอะส่ง agent
- รอบตรวจภาพใช้ 1–2 คน (ไม่ใช่ 9) ดูภาพที่ผู้นำถ่ายไว้แล้ว
- ไม่รันชุดทดสอบ balance (ไม่เกี่ยวกับภาพ) ด่านที่ต้องรัน: `npx tsc --noEmit` · `npx vitest run` · `npm run test:golden` · `npx tsx scripts/codegen/run-all.ts --check` · `npx vite build` · `npm run check:looks` ถ้าแตะ Look
- commit และ push ทุกงานย่อยที่ผ่านด่าน อัปเดต `review/progress.md` ทุกครั้ง เพื่อให้หยุดได้ทุกเมื่อโดยไม่เสียงาน
- ใกล้เพดาน: บอก agent ให้ commit WIP ในสาขาของตัวเองแล้วรายงาน จดชื่อสาขาและ commit ใน progress ("งานที่กำลังทำ") ก่อนหยุด
