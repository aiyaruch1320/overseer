# M7 ข4 ผู้เล่นจำลอง 1: เล่นเกมจริง

ผู้เล่นจำลอง (sonnet) เล่นบน production build ด้วย `scripts/tools/play-check.mjs` ผู้นำคัดลอกจากรายงานที่ส่งกลับ (เครื่องมือของ agent ไม่ยอมให้เขียนไฟล์รายงาน)

## ตัวขับ

```
node scripts/tools/play-check.mjs [--out=dir] [--max-min=25] [--every=20] [--throttle=4] [--speed=เร็ว] [--size=1300x850] [--port=4174] [--no-build] [--keep=1]
```

build แล้วเปิด `vite preview` เอง · นับ WebGL context ที่สร้างและหลุด · นับเฟรม · กดปุ่มตามข้อความ (สุ่มทั้งหมด เริ่มชีวิต เร็ว ให้ชีวิตเดินต่อ) · ถ่ายภาพทุก N วินาทีและเมื่อฉากเปลี่ยน · ล็อก heap nodes listeners error ลง `log.jsonl` `summary.json` `summary.md` · จบเมื่อชีวิตจบ (ถ่ายหน้าตาย บันทึกชีวิต ผู้สืบ) · ใช้ `localhost` ไม่ใช่ 127.0.0.1 · ไม่มีตัวเลือกเมล็ดหรือเผ่า ไม่เลือกคำปฏิญาณ

## ที่ตรวจแล้วดี

- ฉากเล่นจบไม่เริ่มใหม่ (แถบ x / y ไม่ถอยเลยใน A B C) การแก้ heldScene ได้ผล
- ภาพนิ่งแสดงที่อยู่ ฤดู อายุ ป้ายอยู่บนฟ้าไม่ทับตัวละคร ฉากหลังต่างทวีปต่างกันชัด
- การ์ดคำอธิษฐานและลางศึก หน้าหยุดอ่านชัด
- หน้าจบมีฉากความตาย บันทึกชีวิตพร้อมจารึก เลือกผู้สืบ หน้า "ตระกูลสิ้น"

## เข้าไม่ถึง

- การ์ดวิกฤตในหน้าหยุดเปิดกระซิบ: ไม่เจอในสี่ชีวิต (บันทึก "ซิเรียล (ครู) ตกอยู่ในวิกฤต" B อายุ 33 แต่การ์ดไม่ขึ้น)
- ใบจบบอกเงื่อนไขคำปฏิญาณที่ขาด: "สุ่มทั้งหมด" ไม่ตั้งคำปฏิญาณ
- บรรทัดของพระเจ้าใต้เวที: ไม่ได้แทรกแซง
- ชีวิตที่สองหลังเลือกผู้สืบ หน้าตำนาน ของสะสม สรุปโลก
