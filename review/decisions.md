# การตัดสินใจระหว่างลงโค้ด

ตามหัวข้อ 16.1 ของ [../docs/guide/code-plan.md](../docs/guide/code-plan.md) หนึ่งแถวต่อเรื่อง ใหม่อยู่ล่าง

| วันที่ | ไฟล์และหัวข้อ | ก่อน | หลัง | เหตุผล | ผลที่วัดหลังแก้ |
| --- | --- | --- | --- | --- | --- |
| 2026-11-02 | `src/core/types.ts` · โครงข้อมูลของแต่ละกลุ่ม | แผนให้ผู้นำถือชนิดทั้งหมดใน `types.ts` | `types.ts` ถือสัญญากลาง (สถานะ บันทึก คำสั่ง ไวยากรณ์ผล โหนดเส้นเรื่อง) ชนิดของ JSON แต่ละกลุ่มอยู่ใน `src/core/data/types-<กลุ่ม>.ts` ที่ผู้สร้างข้อมูลของกลุ่มเป็นเจ้าของ | ห้า agent ของ M0-ข ทำพร้อมกัน ถ้าทุกชนิดอยู่ไฟล์เดียวต้องรอผู้นำทุกครั้ง ชนิดที่ระบบอื่นใช้ร่วมยังย้ายเข้า `types.ts` ได้ระหว่างคลื่น | |
| 2026-11-02 | `scripts/codegen/` · ที่อยู่ตัวสร้าง | ตัวสร้างหนึ่งไฟล์ต่อกลุ่มใต้ `scripts/codegen/` | ตัวสร้างใหม่อยู่ใน `scripts/codegen/groups/<กลุ่ม>.ts` `run-all.ts` หาเองทุกไฟล์ ตัวสร้างเดิมสามตัวเขียนลง `legacy/data/` (`npm run gen:data:legacy`) | agent เพิ่มกลุ่มได้โดยไม่แก้ไฟล์กลาง | |
