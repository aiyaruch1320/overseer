# เกมจำลองต่างโลก — MVP

เกมจำลองชีวิตในโลกแฟนตาซี ผู้เล่นคือ "พระเจ้า" ที่เฝ้ามองตัวละครหนึ่งคน ซึ่งเป็นแค่หนึ่งในผู้คนนับพันในโลกที่มีชีวิตของตัวเอง ผู้เล่นช่วยเหลือหรือทำลายได้ผ่านพร คำสาป อาวุธ ความฝัน ปาฏิหาริย์ คำอธิษฐาน และภารกิจ ตัวละครมีเจตจำนงของตัวเอง ผู้เล่นทำได้แค่ "เอียง" ความน่าจะเป็น

## วิธีรัน

```bash
npm install
npm run dev
```

เปิด http://localhost:5173

| คำสั่ง | ใช้ทำอะไร |
| --- | --- |
| `npm run dev` | รันเกมพร้อม API (narration, cloud save, telemetry) ใน Vite |
| `npm run build` | typecheck, build เกมไปที่ `dist/` และ bundle server ไปที่ `server-dist/main.mjs` |
| `npm start` | รัน production server (เสิร์ฟ `dist/` + API ที่พอร์ตเดียว ค่าเริ่มต้น 8080) |
| `npm run sim -- 300` | จำลอง 300 ชีวิตแบบ headless เพื่อเช็กบั๊กและจังหวะเกม |

## ผู้เล่นมีส่วนร่วมอย่างไร

เกมหยุดรอผู้เล่นเฉพาะ "ทางแยกแห่งชะตา" (~11 ครั้งต่อชีวิต; เปิดโหมด "ตัดสินใจเอง" แล้วเหลือแค่ตอนใกล้ตาย) ส่วนที่เหลือเป็นการ์ดและปุ่มที่ไม่บังคับ เกมเดินต่อได้ระหว่างที่ผู้เล่นคิด (ตั้งค่า "หยุดทุกเหตุการณ์" ได้ถ้าต้องการแบบเดิม)

| ระบบ | ทำอะไร | ไฟล์ |
| --- | --- | --- |
| คำอธิษฐาน | การ์ดคำขอจากตัวละคร (~13 ใบต่อชีวิต, 17 แบบ) ประทาน / เพิกเฉย / ลงโทษ ภายใน 14 ฤดู ถ้าเงียบ ความเชื่อลดลงเล็กน้อย | `src/data/prayers.ts` |
| เสียงกระซิบ ณ ทางแยก | ผลักให้เลือกทางที่ต้องการ โอกาสเชื่อฟังขึ้นกับความเชื่อและนิสัย | `Game.whisper` |
| พลังเทพบนแผนที่ | 9 พลัง (ฝน, โรคระบาด, สงบศึก ฯลฯ) เลือกประเทศเป้าหมายบนแผนที่ | `MAP_POWERS` |
| ภารกิจของพระเจ้า | เลือก 1 จาก 3 ภารกิจตอนเกิด (12 แบบ) มีแถบความคืบหน้าและรางวัลกรรม | `QUESTS` |

ผู้ล่าเทพ (อาชีพลับ) จะเกิดได้ก็ต่อเมื่อพระเจ้าเคยสาปแช่ง ลงโทษ หรือใช้พลังแห่งความกลัวใส่ตัวละครเท่านั้น การเพิกเฉยอย่างเดียวไม่ทำให้เกิด

## LLM narrator (ไม่บังคับ)

```bash
cp .env.example .env   # แล้วใส่ DEEPSEEK_API_KEY
```

- คีย์อยู่ที่ server เท่านั้น เบราว์เซอร์ส่งแค่ชื่องาน (`fate`, `dream`, `epitaph`, `flavor`, `setup`) กับข้อมูลสั้น ๆ ส่วน prompt สร้างที่ `server/prompts.ts` จึงใช้ endpoint นี้สั่ง LLM ทำอย่างอื่นไม่ได้
- หน้าเกมไม่แสดงชื่อ engine หรือโมเดล
- ถ้าไม่มีคีย์ เกมก็เล่นได้ครบ เพราะใช้เหตุการณ์จาก template ทั้งหมด

| บทบาท | เมื่อไร | โควตาต่อชีวิต | ผลต่อเกม |
| --- | --- | --- | --- |
| [ชะตา] | หลังตัดสินทางแยก | 5 | บรรยายเสริม (ไม่เปลี่ยนค่า) |
| [ฝัน] | หลังส่งฝัน | 3 | ความคิดในใจของตัวละคร (ไม่เปลี่ยนค่า) |
| [สุ่ม] | ~5% ของฤดู | 4 | เหตุการณ์ใหม่ + ผลจาก whitelist `LLM_FX` |
| [จารึก] | ตอนตาย | 1 | คำจารึกบนการ์ดสรุปชีวิต |
| ตั้งค่าการเกิด | พิมพ์ "อยากเกิดเป็นแบบไหน" | — | แปลงเป็นนิสัย/ความถนัด/พรระดับต่ำ ผ่าน `sanitizeSetup` จึงไม่ OP |

การประหยัด token:
- prefix ของ prompt เหมือนกันทุกครั้ง และกติกาอยู่ใน user turn ของตัวเอง ทำให้ส่วนนี้คิดราคา cache hit
- ปิด thinking mode, `max_tokens` 70–140, งบรวม 12 ครั้งต่อชีวิต, cache คำตอบใน localStorage
- ไม่ block เกม: แสดงข้อความจาก template ก่อน แล้วค่อยเติมข้อความจาก LLM

ผลวัดจริง 1 ชีวิต: 11 calls, input 5,963 tokens (cache hit 58%), output 534 tokens ≈ $0.0014 ต่อชีวิต

การป้องกันคีย์และค่าใช้จ่าย (ตั้งผ่าน env):

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- |
| `NARRATE_PER_IP_10MIN` | 40 | จำนวน narration ต่อ IP ต่อ 10 นาที |
| `NARRATE_DAILY_CAP` | 20000 | เพดาน call ทั้ง server ต่อวัน (≈ $2.5/วัน ในกรณีเลวร้ายสุด) |
| `SAVES_PER_IP_10MIN` | 60 | cloud save + telemetry ต่อ IP ต่อ 10 นาที |
| `DATA_DIR` | `.data` | ที่เก็บ save และ telemetry |

IP มาจาก header `CF-Connecting-IP` ของ Cloudflare จึงควรเปิด server ให้เข้าได้ทาง tunnel เท่านั้น ถ้าเปิดตรง ผู้ใช้ปลอม header นี้ได้

## โลกและแผนที่

- โลก 768×432 tile 9 ทวีป 143 ประเทศ ~1,600 เมือง ผังทวีปตามเนื้อเรื่อง ดู [docs/world/world-map.md](docs/world/world-map.md)
- ซูมลื่นจากท้องฟ้า ผ่านชั้นเมฆ หมอก และพายุ ลงมาถึงเมือง สภาพอากาศสุ่มตามฤดูและภูมิอากาศของแต่ละประเทศ (`src/ui/sky.ts`)
- แผนที่เป็นภาพเวกเตอร์วาดใหม่ทุกครั้งที่กล้องขยับ ที่ความละเอียดจริงของจอ (รวม DPR) จึงคมทุกระดับซูม (`src/render/terrain/`)
- ซูมเข้าจนสุดเพื่อเข้าเมือง ผังเมือง 4 แบบ (ตาราง, ริมแม่น้ำ, ชายฝั่ง, หมู่บ้าน) และสถาปัตยกรรม 6 แบบตามภูมิอากาศ
- ชาวเมืองวาดจากชั้นของ เผ่า × สีผิว × ทรงผม × สีผม × ชุดตามบทบาท × สีชุด × เครื่องประดับ (หลายหมื่นแบบ) และมีชีวิตประจำวัน 1,262 รูปแบบ (`src/data/townlife.ts`)
- NPC ทั่วโลกใช้ชีวิตรายปี, ผู้กล้า จอมมาร และกองคาราวานเดินทางจริงบนแผนที่, เหตุการณ์ระดับภูมิภาค 17 แบบเกิดได้ทุกที่ (`src/sim/society.ts`)

## ชีวิตในเมืองและเหตุการณ์ใหญ่

**ตัวละครและ animation** (`src/scenes/people.ts`, `CityScene.ts`)
- ทุกคนวาดเป็นแถบ 14 ท่า: ยืน หายใจ เดิน 4 จังหวะ ใช้เครื่องมือ (ตี/ฟัน) นั่ง อุ้มของเดิน ชูมือเชียร์ คุกเข่า — ขยับเท้า แกว่งมือ มีประกายไฟ ฝุ่น ไอน้ำ โน้ตเพลง ตามอาชีพ
- หน้าตาประกอบจากเผ่า × รูปร่าง (4) × สีผิว × ทรงผม (12) × หนวดเครา × รอยบนหน้า × ชุดตามบทบาท (20+ แบบ) × ลวดลาย × สี × หมวก (14) × เครื่องมือ (19) และแต่งตามภูมิอากาศ (ผ้าคลุมทะเลทราย ขนสัตว์ในหิมะ ผ้าถุงเขตร้อน)
- ตัวละครหลักเปลี่ยนตามวัย: ทารก (0–3) นอนในเปลข้างประตูบ้านมีพ่อแม่เฝ้า ไม่เดิน → เด็กวิ่งเล่น → วัยรุ่นเดินเล่น/คุยกับเพื่อน → ทำงานตามอาชีพ → ผู้สูงวัยถือไม้เท้าและนั่งพัก ส่วนบนแผนที่โลกทารกแสดงเป็นเปล

**NPC มีจุดมุ่งหมาย** (`src/data/npclife.ts`, `Game` → `society.ts`)
- 28 อาชีพ แต่ละอาชีพมีที่ทำงานและท่าทางของตัวเอง (ช่างเหล็กตีที่หน้าโรงตีเหล็ก ชาวนาไถนา คนจับปลานั่งที่ท่าน้ำ นักบวชคุกเข่าที่วิหาร ทหารยามเดินตรวจ ฯลฯ) กลางคืนคนส่วนใหญ่กลับบ้าน
- ทุกคนมีฝีมือ 0–100 ที่เพิ่มขึ้นทุกปี และ **เป้าหมายชีวิต** (16 แบบ เช่น เป็นอัศวิน เปิดร้าน เขียนตำรา ล่ามังกร) ที่คืบหน้าเป็นปี ๆ เมื่อสำเร็จจะเปลี่ยนตัวคนและบางครั้งเมือง (ทำยารักษาโรคระบาด แจกข้าวตอนอดอยาก ขุดเจอสายแร่) วางเมาส์บน NPC เพื่อดูอาชีพ ฝีมือ และความใฝ่ฝัน

**เมืองและแคว้นมีเอกลักษณ์** (`src/sim/locale.ts`)
- 14 จุดเด่นของเมือง (เมืองประมง ไร่องุ่น เมืองช่างเหล็ก หอเวท เมืองแสวงบุญ ทุ่งเลี้ยงม้า ฯลฯ) กำหนดจากภูมิอากาศ เผ่า ศาสนา และชายฝั่ง มีผลต่ออาชีพของคนในเมือง, ของประกอบฉากในเมือง (แท่นตากปลา ถังเหล้า ทั่งตีเหล็ก ผ้าไหม ฯลฯ) และเอฟเฟกต์ในอากาศ
- 15 เทศกาลของแต่ละแคว้น (ลอยโคม ระบำมังกร แข่งเรือยาว เทศกาลไฟ งานหน้ากาก ฯลฯ) แต่ละแคว้นมี 2 เทศกาลตามฤดู ตอนเทศกาล ชาวเมืองมารวมที่จัตุรัสเต้นรำ มีพลุ โคม กลีบดอกไม้ตามชนิดงาน

**เหตุการณ์ใหญ่** (`src/data/disasters.ts`, `src/ui/cine.ts`)
- 11 ภัยที่สุ่มเกิดได้ทุกที่: มังกรบุก อุกกาบาตตก ผู้มาเยือนจากดวงดาว ไททันตื่น ตั๊กแตนมหาภัย น้ำท่วม แผ่นดินไหว สุริยคราสทมิฬ พายุเวทมนตร์ วาฬฟ้า คราเคน (เฉพาะชายฝั่ง) แต่ละอย่างมีทางแยกของตัวเองและเด็กจะเจอแบบเด็ก
- เมื่อเกิดเหตุใหญ่ **ในแคว้นของตัวละคร** เกมหยุดและเล่นอนิเมชั่นฉากสั้น ๆ (วาดด้วยโค้ดแบบ pixel 40+ ฉาก); ส่วนเหตุการณ์ในแคว้นข้างเคียงและเทศกาลจะเป็นแถบเล็กที่ไม่หยุดเกม (ปิดการหยุดได้ในตั้งค่า) ในเมืองจะเห็นผลจริง: มังกรบินผ่านพร้อมคนแตกตื่น จานบินพร้อมลำแสง น้ำท่วมสูงขึ้น แผ่นดินสั่น ท้องฟ้ามืดตอนสุริยคราส
- ค่าเฉลี่ยต่อชีวิต: หยุดเพื่ออนิเมชั่น ≈ 3 ครั้ง, แถบไม่หยุดเกม ≈ 9 ครั้ง (ห่างกันอย่างน้อย 5 ฤดู)

**ควบคุมเอง**
- ปุ่ม **ตัดสินใจเอง** บนแถบเวลา: ตัวละครตัดสินทางแยกเอง เกมไม่หยุด (หยุดเฉพาะตอนใกล้ตาย) มีข้อความแจ้งว่าเลือกอะไร และพร ฝัน กระซิบ พลังเทพ ยังใช้ได้ทุกเมื่อ
- หุบแผงด้านข้าง, หุบปุ่มพลังเทพ, หุบบันทึกเรื่องราวด้านล่าง (จำค่าไว้)
- หน้าเกิดมีปุ่ม **กลับไปแก้คำขอ** (ข้อความคงอยู่) และปุ่มสุ่มใหม่ยังยึดตามคำขอเดิม

## สถาปัตยกรรม

```
เบราว์เซอร์                                  server (Node, ไฟล์เดียว)
  sim ทั้งหมด (~40 µs/tick)                    GET  /            dist/ (brotli/gzip, assets cache 1 ปี)
  Phaser วาดฉาก + Web Worker วาดแผนที่   ──►   POST /api/narrate  สร้าง prompt + เรียก LLM (คีย์อยู่ที่นี่)
  save ใน localStorage                         PUT  /api/save/:id cloud save (ทุก ≥2 นาที)
                                               POST /api/telemetry สถิติ playtest (ปิดได้ในตั้งค่า)
```

เหตุผลที่ sim อยู่ในเบราว์เซอร์: sim ใช้ CPU น้อยมาก (คอขวดคือการวาด ซึ่งย้ายไป Worker แล้ว) ถ้าย้ายไป server จะต้องจ่าย CPU ต่อผู้เล่น ได้ latency ทุก tick และใช้ bandwidth มากขึ้น

Bandwidth ต่อผู้เล่น (ผ่าน Cloudflare Tunnel):

| รายการ | ขนาด | ความถี่ |
| --- | --- | --- |
| เกม (JS+CSS) | ~450 KB brotli (2 MB ถ้าไม่บีบอัด) | ครั้งแรกเท่านั้น (immutable, Cloudflare cache ที่ edge) |
| index.html | < 1 KB | ทุกครั้งที่เปิดเกม |
| narration | ~2 KB | ≤ 12 ครั้งต่อชีวิต |
| cloud save | ~30 KB (gzip จากเบราว์เซอร์) | ≤ 1 ครั้งต่อ 2 นาที |
| telemetry | < 5 KB | ทุก 30 วินาทีถ้ามี event |

## โครงสร้างโค้ด

```
src/sim/        ตรรกะเกม TypeScript ล้วน ไม่พึ่ง Phaser (test และ save/load ได้)
src/data/       เนื้อหาแบบ data-driven
src/render/     วาดแผนที่ (ใช้ใน Web Worker)
src/scenes/     Phaser: แผนที่โลก, ฉากเมือง, sprite ชาวเมือง
src/ui/         HTML overlay: แผง, การ์ด, tooltip, ท้องฟ้า
src/llm/        narrator ฝั่ง client (ส่งแค่ชื่องาน)
src/net/        cloud save + telemetry
server/         API + production server
scripts/        simtest แบบ headless
```

เซฟอัตโนมัติใน localStorage (`isekai.save.v1`, `isekai.meta.v1`) และสำรองขึ้น server ด้วย player id แบบสุ่ม (ไม่มีข้อมูลส่วนตัว)
