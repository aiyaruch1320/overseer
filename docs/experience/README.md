## ประโยคจุดขาย

คุณเป็นพระเจ้าที่มองเห็นชีวิตหนึ่งชีวิตของคนคนหนึ่งตั้งแต่เกิดจนตาย ชี้นำได้แต่บังคับไม่ได้ แล้วลุ้นว่าชีวิตนั้นจะจบแบบไหน จากนั้นย้อนไปดูทางอื่นของชีวิตเดียวกันได้ ชีวิตทุกชีวิตทิ้งร่องรอยไว้ในโลกที่มีเรื่องของตัวเอง

## เสาหลักห้าข้อ

1. **ผู้ชมที่ลุ้น** ผู้เล่นไม่ได้ควบคุมตัวละคร ตัวละครตัดสินใจเองจากนิสัย ผู้เล่นเอียงน้ำหนักและสร้างเหตุการณ์ ความสนุกคือการรอดูผล
2. **หนึ่งชีวิต หนึ่งคำถาม** ทุกชีวิตเริ่มด้วยคำถามที่ผู้เล่นอยากรู้คำตอบ และต้องได้คำตอบก่อนตัวละครตาย
3. **ผูกใจกับคนไม่กี่คน** ชีวิตหนึ่งมีผู้คนที่เจอซ้ำไม่กี่คน และตัวละครสวดอธิษฐานต่อเรา
4. **ตอนจบเป็นชิ้นงาน** จบแล้วได้บันทึกชีวิตที่อยากเก็บ เล่าต่อ หรือแชร์ และได้ของสะสมที่ทำให้อยากเล่นอีก
5. **โลกจำได้** ชีวิตที่ผ่านไปทิ้งร่องรอยในโลก ผู้เล่นรู้ว่าสิ่งที่ทำมีผล
