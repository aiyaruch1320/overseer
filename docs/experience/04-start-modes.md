# แบบเริ่มต้น

ภาพรวม: [README.md](README.md) · โครงชีวิต: [01-one-life.md](01-one-life.md) · กำเนิด: [../character/01-origin.md](../character/01-origin.md)

แบบเริ่มต้นคือเมนูตอนเปิดรอบ แต่ละแบบเป็นมุกต่างโลกที่คนรู้จักอยู่แล้ว ผู้เล่นเลือกเองหรือกดสุ่ม แบบเริ่มต้นเปลี่ยนแค่กำเนิดและโหนดแรกของชีวิต โลกและกติกาเหมือนกันทุกแบบ ทุกแบบมีอยู่ในเส้นเรื่องที่เขียนไว้แล้ว ไม่ต้องเขียนเรื่องใหม่

| แบบ | อารมณ์ที่ให้ผู้เล่น | ที่มาในเอกสาร |
| --- | --- | --- |
| ถูกอัญเชิญ | ตัวละครมาจากต่างโลกตอนอายุ 16 ไม่มีครอบครัวในโลกนี้ ความถนัดพิเศษหนึ่งอย่าง ถูกหักหลังได้ | มนุษย์ สายผู้ถูกอัญเชิญ ([../storylines/01-human.md](../storylines/01-human.md)) |

| เกิดเป็นสไลม์ | เริ่มจากไม่มีอะไร กลืนความสามารถและสร้างชุมชน | [../storylines/12-slime.md](../storylines/12-slime.md) |

## กติกา

- แบบเริ่มต้นบางแบบเปิดตั้งแต่ครั้งแรก บางแบบปลดล็อกจากของสะสมหรือหลังจบชีวิตแรก ([03-ending-and-collection.md](03-ending-and-collection.md)) ผู้สืบตระกูลเปิดเมื่อมีชีวิตก่อนหน้าให้สืบ
- กดสุ่มได้ทุกเมื่อ ผลสุ่มใช้น้ำหนักตามจำนวนผู้อยู่ในโลก
- ไม่มีแบบใดแรงกว่าแบบอื่น ความต่างคือเรื่องและวิธีเล่น ไม่ใช่ค่าสถานะ
- ทุกแบบมีคำถามของชีวิตเริ่มต้นของตัวเอง ([02-hooks.md](02-hooks.md) ตะขอข้อ 1)
