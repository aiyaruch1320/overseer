# ตอนจบและของสะสม

ภาพรวม: [README.md](README.md) · ตะขอ: [02-hooks.md](02-hooks.md) · ทายาท: [../heirs/README.md](../heirs/README.md)

ตอนจบของชีวิตเป็นชิ้นงานที่ผู้เล่นอยากเก็บและเล่าต่อ ไม่ใช่หน้าจอ "คุณตายแล้ว"

## 1. บันทึกชีวิต

หลังฉากความตาย เกมแสดงบันทึกชีวิตหนึ่งหน้า

| ส่วน | เนื้อหา |
| --- | --- |
| หัว | ชื่อ เผ่า ถิ่นเกิด ชนชั้นตอนเกิด อายุที่ตาย สาเหตุ |
| คำถามของชีวิต | คำถามคืออะไร ได้คำตอบแบบไหน (สำเร็จ ล้มเหลว หรือกลายเป็นอย่างอื่น) |
| ช่วงเวลาที่เปลี่ยนชีวิต | สามถึงห้าเหตุการณ์ที่ทำให้ชีวิตเดินไปทางนี้ |
| ผู้คน | คนที่เจอซ้ำและเขาเป็นอย่างไรเมื่อตัวละครจากไป |
| ร่องรอยที่ทิ้งไว้ | ลูก ของที่ส่งต่อ เรื่องค้าง สิ่งที่โลกจำได้ |
| มือของพระเจ้า | แทรกแซงกี่ครั้ง ครั้งไหนเปลี่ยนชีวิตมากที่สุด |
| จารึก | ข้อความสั้นที่ LLM เขียนจากข้อมูลจริงของชีวิตนี้ |

กติกา LLM เขียนได้เฉพาะจารึกและถ้อยคำเล่า ข้อเท็จจริงทุกข้อมาจากบันทึกของเกม LLM แต่งชื่อคน ประเทศ หรือเหตุการณ์เองไม่ได้ ([../storylines/llm-ideas.md](../storylines/llm-ideas.md))

## 2. ผลของชีวิตต่อโลก

ทุกชีวิตจบด้วยระดับผลต่อโลกหนึ่งระดับ

| ระดับ | ความหมาย |
| --- | --- |
| ไม่ทิ้งรอย | ชีวิตธรรมดา ไม่มีใครจำ |
| รอยในถิ่น | เมืองหรือประเทศจำได้ |
| รอยในยุค | ชีวิตนี้ไปแตะเหตุการณ์ใหญ่ ผลจดอยู่ในประวัติของโลก |

ผลที่ชัดคือสิ่งที่ผู้เล่นอยากเห็นเมื่อกลับไปเปิดชีวิตเก่า

## 3. หน้าตำนาน

เก็บชีวิตที่ผ่านมาทุกชีวิตเป็นรายการ เปิดดูบันทึกชีวิตและการ์ดได้ เปิดชีวิตซ้ำด้วยเมล็ดเดิมเพื่อลองแทรกแซงอีกทางได้ ([02-hooks.md](02-hooks.md) ตะขอข้อ 5) ตำนานของตระกูลเรียงตามรุ่นเมื่อเล่นต่อเนื่อง

## 4. การ์ดแชร์

การ์ดสองแบบ การ์ดเกิด (เผ่า ถิ่น ครอบครัว ลาง) ที่ชวนให้เพื่อนลองเมล็ดเดียวกัน และการ์ดจบ (บันทึกชีวิตย่อ) เมล็ดเดียวกันให้ชีวิตเริ่มต้นเดียวกัน ผู้เล่นเทียบกันได้ว่าใครพาชีวิตไปได้ไกลหรือต่างกว่า

## 6. สิ่งที่คงข้ามรอบ

หน้าตำนาน ของสะสม และแบบเริ่มต้นที่ปลดล็อกคงอยู่ข้ามรอบเสมอ ส่วนที่เกี่ยวกับโลก (ยุค มังกรที่ล้ม ประเทศที่เปลี่ยน) ขึ้นกับวิธีสืบต่อของโลก ([05-world-across-lives.md](05-world-across-lives.md))
