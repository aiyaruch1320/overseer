# ธาตุ ชนิดศัตรู และการแพ้ทาง

ระบบ: [README.md](README.md) · แกนการคำนวณ: [01-core.md](01-core.md) · ศัตรู: [03-enemies.md](03-enemies.md) · กติกาเผ่า: [../character/03-synergy-rules.md](../character/03-synergy-rules.md)

ตารางนี้ตัดสินว่าแท็กการโจมตีของตัวละครได้ผลกับศัตรูชนิดใดมากน้อยเท่าไร ผลแปลงเป็นโบนัสในการทอย ([01-core.md](01-core.md) หัวข้อ 4)

| สัญลักษณ์ | ความหมาย | โบนัส |
| --- | --- | --- |
| ★ | แพ้รุนแรง | +6 และทอยสำเร็จทำ 2 แผล |
| ▲ | แพ้ | +4 |
| · | ปกติ | 0 |
| ▼ | ทน | −4 |
| ✕ | ภูมิคุ้มกัน | ท่าทีนั้นใช้ไม่ได้ |

## 1. แท็กการโจมตีของตัวละครมาจากไหน

| ที่มา | แท็กที่ได้ |
| --- | --- |
| ความถนัดและ skill | แท็กของความถนัด เช่น `fire` `light` `holy` `blade` `blunt` `pierce` `ranged` `necro` `rune` `poison` (จาก [../character/catalog/aptitudes-skills.md](../character/catalog/aptitudes-skills.md)) |
| อาวุธ | ธาตุของอาวุธ (`light` สำหรับอาวุธศักดิ์สิทธิ์ `dark` สำหรับอาวุธต้องสาป และธาตุอื่นที่สุ่มได้) และชนิดอาวุธ (ดาบ = `blade` ค้อน = `blunt` หอก ธนู = `pierce`) |
| พร | `#light` `#holy` `#fire` `#ice` `#lightning` `#water` `#earth` `#undead_bane` `#demon_bane` `#dragon_bane` ฯลฯ |
| สัตว์คู่หู | ธาตุของสัตว์ (`pa_breath_fire` = `fire` · `pa_breath_frost` = `ice` · `pa_shock_touch` = `lightning` · `pa_venom_bite` = `poison`) |
| วัตถุ | อาวุธเงิน (`silver`) อาวุธเหล็กกล้า (`iron`) โคมสีขาว (`light` สำหรับศัตรูหมอก) |

**แท็กสังหาร** `#undead_bane` `#demon_bane` `#dragon_bane` ให้ผล ★ กับชนิดของมันเสมอ (เทียบเท่าแพ้รุนแรง) แม้ชนิดนั้นจะทนธาตุอื่น

## 5. ลักษณะเสริมของศัตรู

| ลักษณะ | ผล |
| --- | --- |
| บิน `flying` | ปะทะประชิด −2 · ยิงระยะไกล +2 |
| ฝูง `swarm` | เวทพื้นที่ (ไฟ ลม ดิน ระดับ 2 ขึ้นไป) +4 · ปะทะประชิดทำได้ทีละแผล |
| ตัวใหญ่ `huge` | แทง +2 · ศัตรูเหยียบ ความเสียหาย ×1.3 |
| ฟื้นตัว `regen` | หลังจังหวะที่ไม่เสียแผล ฟื้นหนึ่งแผล ยกเว้นถูกไฟ |
| ไร้ความคิด | เจรจาและเสน่ห์ ✕ |
| ซ่อนตัว | ผู้ไม่มี `#truth` `#seer` `u_appraisal` ทอยรับรู้ −2 |
| ในน้ำ | ผู้ไม่มี `water_breath` −2 ทุกท่าที |

## 6. เผ่าที่เล่นได้เมื่อเป็นศัตรู (NPC)

NPC ใช้แท็กเผ่าเดียวกับตัวละคร ([../character/03-synergy-rules.md](../character/03-synergy-rules.md)) จุดอ่อนของเผ่าจึงเป็นจุดอ่อนในการต่อสู้

| เผ่าของศัตรู | ชนิด | จุดอ่อน (▲ หรือ ★) | ทน (▼ หรือ ✕) |
| --- | --- | --- | --- |
| แวมไพร์ | ผู้ตาย + คน | แสง ★ ศักดิ์สิทธิ์ ★ ไฟ ▲ เงิน ▲ (แสงแดดถ้าสู้กลางวัน ★) | มืด ▼ ฟัน ▼ |
| มัมมี่ | ผู้ตาย | ไฟ ★ (ร่างแห้ง) แสง ▲ ศักดิ์สิทธิ์ ▲ น้ำ ▲ | พิษ ✕ |
| กูล | ผู้ตาย | แสง ▲ ศักดิ์สิทธิ์ ▲ | พิษ ✕ |
| เผ่าปีศาจ | ปีศาจ + คน | ศักดิ์สิทธิ์ ★ แสง ▲ | ไฟ ✕ |
| เผ่าลาวา | คน | น้ำ ▲ น้ำแข็ง ▲ | ไฟ ✕ |
| เผ่ามังกร | คน | น้ำแข็ง ▲ `#dragon_bane` ▲ | ไฟ ▼ |
| ภูตพราย | ภูต | เหล็ก ★ | เสน่ห์และมายา ▼ |
| สไลม์ | ไร้รูป | ไฟ ▲ น้ำแข็ง ▲ | ฟัน ทุบ แทง ▼ |
| ลูกผสมจักรกล หุ่นวิญญาณ | สิ่งประดิษฐ์ + คน | สายฟ้า ★ รูน ▲ (หุ่นวิญญาณ) | พิษ ✕ |
| ยักษ์ | ยักษ์ | แทง ▲ ยิง ▲ | ทุบ ▼ |
| เงือก นาคา | คน (ในน้ำได้เปรียบ) | สายฟ้า ▲ (เงือก) น้ำแข็ง ▲ (นาคา) | น้ำ ▼ |
| คนแคระ | คน | — | ไฟ ▼ พิษ ▼ |
| เผ่าอื่น | คน | ตามคำสาปที่ตัวนั้นมี | ตามพรที่ตัวนั้นมี |

## 7. กติกาความสมเหตุสมผล

| ID | เงื่อนไข | ผล |
| --- | --- | --- |
| CR-01 | ตัวละครเป็นเผ่าที่แพ้แสง แต่มีพรแสง (SR-20) | ใช้เวทแสงโจมตีผู้ตายได้ ★ ตามปกติ และแสงของศัตรูไม่ทำร้ายตัวเองเพิ่ม |
| CR-02 | ตัวละครเป็นผู้ตาย ใช้เนโครแมนซีกับผู้ตาย | ไม่ทำแผล แต่ทอยควบคุม (เวท) ถ้าสำเร็จศัตรูกลายเป็นพวก |
| CR-03 | ตัวละครเป็นภูตพราย ใช้อาวุธเหล็ก | ใช้ไม่ได้ (แพ้เหล็กเอง) |
| CR-04 | ตัวละครมี `#fire_res` สู้กับมังกรเพลิง | ลมหายใจไฟของมังกรเสียหาย ×0.5 |
| CR-05 | ศัตรูหมอก ตัวละครส่งเสียง (ดนตรี ระฆัง ตะโกน) | ศัตรูเพิ่มอีกหนึ่งตัวต่อจังหวะ |
| CR-06 | ศัตรูหมอก ตัวละครถือโคมสีขาวหรือมี `ns_lantern_light` | ★ แสง และศัตรูไม่เข้าใกล้หนึ่งจังหวะ |
| CR-07 | ตัวละครเป็นเผ่ามังกร สู้กับมังกร | ★ เจรจา (เลือดเดียวกัน) แต่ ▼ ทุกการโจมตีถ้ามังกรเป็นพี่น้องตัวที่ตัวละครถือตรา |
| CR-08 | สู้ในถิ่นศักดิ์สิทธิ์ของศาสนาแสง | ผู้ตายและปีศาจ DC −2 · ผู้ใช้เนโครแมนซี −2 |

| CR-10 | สู้ในฤดูหนาวเถ้า (หลัง DR-04) | ไฟของตัวละคร +2 (ความร้อนหายาก) · ศัตรูธาตุไฟ DC −2 |
