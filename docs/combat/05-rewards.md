# ของรางวัลและผลหลังการต่อสู้

ระบบ: [README.md](README.md) · ศัตรู: [03-enemies.md](03-enemies.md) · มังกร: [06-dragon-encounters.md](06-dragon-encounters.md)

## 1. หลักการ

- ทุกการชนะได้ **เงินและชื่อเสียง** ตามโค้ดเดิม (ช่อง `loot` ของมอนสเตอร์)
- นอกจากนั้น **สุ่ม** ของรางวัลพิเศษ ได้บ้างไม่ได้บ้าง ความหายากถ่วงตามเรื่องราวของตัวละคร (ระบบ `fortune.ts` เดิม) ตัวละครที่สู้ศัตรูชนิดเดียวกันซ้ำ ๆ และมีเส้นเรื่องสายนั้น (`thread:holy` สำหรับผู้ล่าผี) ได้ของสายนั้นหายากกว่า
- ชนะด้วยวิธีที่ไม่ฆ่า (เจรจา สงบ ฝึกให้เชื่อง) ได้ของคนละแบบ

## 2. ตารางสุ่มรางวัลพิเศษตามระดับศัตรู

ทอยแยกแต่ละช่อง (ได้หลายอย่างพร้อมกันได้)

| ระดับศัตรู | วัสดุ | อาวุธ | พร | คำสาป (ติดมาจากศัตรู) | skill | ไม่ได้อะไรพิเศษเลย |
| --- | --- | --- | --- | --- | --- | --- |
| ลูกกระจ๊อก | 40% | 1% | 0.5% | 1% | 0.5% | ประมาณ 58% |
| ปกติ | 60% | 4% | 2% | 3% | 2% | ประมาณ 36% |
| หัวหน้า | 80% | 10% | 6% | 6% | 5% | ประมาณ 16% |
| บอส | 100% | 25% | 15% | 12% | 12% | 0% |
| ตำนาน | 100% | 50% | 35% | 30% | 25% | 0% |

ชนะเด็ดขาดเพิ่มทุกช่อง (ยกเว้นคำสาป) ×1.5 · แพ้หรือหนีไม่ได้รางวัล (ยกเว้นคำสาปจากศัตรู ตาม [01-core.md](01-core.md) หัวข้อ 5)

**ระดับความหายากของของที่สุ่มได้** สุ่ม C ถึง L ตามน้ำหนักเดิม และเลื่อนตามระดับศัตรู: หัวหน้า น้ำหนัก R ×2 · บอส E ×3 · ตำนาน L ×5

## 3. วัสดุ

วัสดุใช้ขาย ตีอาวุธ (ช่างตีเหล็ก) ปรุงยา (นักเล่นแร่ หมอยา) หรือมอบเป็นบรรณาการ (ศาสนา มังกร)

| ชนิดศัตรู | วัสดุ | ใช้ |
| --- | --- | --- |
| สัตว์ | หนัง เขี้ยว ขน | ช่างฟอกหนัง ช่างตัดเสื้อ ค้าขาย |
| ผู้ตาย | กระดูกต้องสาป ผงศพ | เนโครแมนซี ไสยศาสตร์ |
| วิญญาณ | ผลึกวิญญาณ | อาวุธต่อวิญญาณ (ได้แท็ก `spirit_bane` ชั่วคราว) พิธีกรรม |
| ปีศาจ | เขาปีศาจ เลือดอสูร | สัญญาปีศาจ อาวุธต้องสาป |
| มังกรป่า ไวเวิร์น | เกล็ด เขี้ยวมังกร | เกราะทนไฟ อาวุธ `#dragon_bane` (เมื่อตีด้วย `smithing_3`) |
| ยักษ์ | กระดูกยักษ์ | อาวุธหนัก |
| สิ่งประดิษฐ์ | แกนรูน ชิ้นส่วนกลไก | ช่างกล ช่างสลักรูน สัตว์คู่หูจักรกล |
| ภูต | ฝุ่นภูต | เวทมายา น้ำหอม เครื่องสำอาง |
| พืช | ยางไม้ สปอร์ | หมอยา เภสัชกร |
| ไร้รูป | เจลสไลม์ | ยารักษาแผล |
| สิ่งจากรอยแยก | หมึกหมอก | หน้ากากกรองหมอก โคมพิเศษ (หายาก ราคาสูงในตลาดมืด NB-09) |
| ธาตุ | แก่นธาตุ | อาวุธธาตุ ตามธาตุของศัตรู |
| สัตว์ทะเล | มุก หนวดทะเล | เครื่องประดับ ยา |

## 4. อาวุธที่สุ่มได้

ใช้ตัวสร้างอาวุธเดิมของโค้ด (ชนิด ศักดิ์สิทธิ์ หรือ ต้องสาป · ธาตุ · ความหายาก) โดยกำหนดชนิดและธาตุตามศัตรู

| ศัตรู | ชนิดอาวุธที่ได้ | ธาตุ |
| --- | --- | --- |
| ผู้ตาย วิญญาณ | ต้องสาป 70% | มืด |
| ปีศาจ | ต้องสาป 80% | ไฟหรือมืด |
| คน NPC ทหาร อัศวิน | ตามอาวุธของ NPC (ศักดิ์สิทธิ์ถ้าเป็นอัศวินศาสนาแสง) | ตาม NPC |
| ธาตุ | ศักดิ์สิทธิ์ 50% | ตามธาตุศัตรู |
| มังกรป่า | ศักดิ์สิทธิ์ 60% | ไฟหรือน้ำแข็งตามสายมังกร |
| อื่น ๆ | ศักดิ์สิทธิ์ 50% | สุ่ม |

## 5. พรและคำสาปที่สุ่มได้ตามชนิดศัตรู

เมื่อสุ่มได้ช่อง **พร** หรือ **คำสาป** จากตารางหัวข้อ 2 ใช้รายการด้านล่างก่อน (น้ำหนัก ×4) แล้วค่อยตกไปสุ่มทั่วไป

| ชนิดศัตรู | พรที่มักได้ | คำสาปที่มักติดมา |
| --- | --- | --- |
| ผู้ตาย | `b_undeadslayer` `b_lightward` `b_curseward` | `c_undeadtouch` `c_ghost` `c_lichseed` (จากลิช) |
| วิญญาณ | `b_mindward` `b_insight` `nb_sv_fog` | `c_shadow` `c_whisper` `c_nightmare` |
| แวมไพร์ | `b_nighteye` `b_regen` | `c_vampbite` `c_bloodthirst` |
| ปีศาจ | `b_demonslayer` `b_flameward` | `c_demonmark` `c_cursedblood` |
| มังกรป่า ไวเวิร์น | `b_dragonscale` `b_dragonslayer` `b_flameward` | `c_greed` (หลงทองของมังกร) |
| ยักษ์ | `b_giant` `b_mountain` | `c_stoneskin` |
| สัตว์ | `b_beastlord` `b_hare` `b_nighteye` | `c_moonfrenzy` (จากมนุษย์หมาป่า) |
| สิ่งประดิษฐ์ | `b_ironskin` `nb_gear_sense` | `c_insomnia` |
| ภูต | `b_lucid` `b_inspire` | `c_rhyme` `c_dance` `c_chicken` (ภูตแกล้ง) |
| พืช | `b_harvest` `nb_root_sense` | `c_allergy` |
| สิ่งจากรอยแยก | `nb_sv_fog` `nb_fog_walker` | `nc_fog_shadow` `nc_sv_fog` |
| ธาตุ | สัมผัสธาตุตามธาตุศัตรู (`b_firetouch` `b_frosttouch` `b_thundertouch` `b_tidetouch` `b_earthtouch`) | แพ้ธาตุตรงข้าม (`c_fireweak` `c_coldweak`) |
| NPC | `b_warcry` `b_swordgod` (จากนักดาบ) `b_silvertongue` (จากเจรจาสำเร็จ) | `c_wanted` (ฆ่า NPC ในเมือง) `c_feud` (ฆ่า NPC ที่มีตระกูล) |

## 6. รางวัลเมื่อชนะโดยไม่ฆ่า

| วิธี | รางวัล |
| --- | --- |
| เจรจาให้ถอย | ชื่อเสียง +3 · `karma` +2 · ศัตรู NPC ไว้ใจ +1 (อาจเป็นพันธมิตรในอนาคต) |
| สงบสัตว์ | `karma` +2 · โอกาสได้สัตว์คู่หู ตามระดับความหายากของสัตว์นั้น ([../character/13-companions-overview.md](../character/13-companions-overview.md)) |
| ปล่อยศัตรูที่แพ้ | `kind` +5 · NPC ที่ถูกปล่อยมีโอกาส "คืนบุญ" ในอนาคต (ระบบ NPC เดิม) |
| ไล่วิญญาณให้สงบ | `b_mindward` หรือ `nb_mourning_ear` ในโอกาสเล็ก · ผลึกวิญญาณ |

## 7. ฉายาและสถิติ

| เงื่อนไข | ฉายาที่ได้ (เพิ่มชื่อเสียงและเปิดเรื่อง) |
| --- | --- |
| ชนะผู้ตายหรือวิญญาณ 10 ครั้ง | ผู้ส่งวิญญาณ |
| ชนะปีศาจ 10 ครั้ง | ผู้ปราบมาร (เพิ่มน้ำหนักเป้าหมาย `demonbane` ในโค้ดเดิม) |
| ชนะมังกรป่า 3 ครั้ง | นักล่ามังกร (เพิ่มน้ำหนัก DR-13 และ DM-10) |
| ปกป้องหมู่บ้าน 3 ครั้ง | ผู้พิทักษ์แห่ง<ชื่อเมือง> |
| ชนะดวล 5 ครั้ง | นักดาบไร้พ่าย |
| สงบสัตว์ 5 ครั้ง | เพื่อนแห่งพงไพร |
| สังหาร NPC ที่มีชื่อ 3 คน | ฆาตกรที่ทุกคนรู้จัก (`c_infamous`) |
