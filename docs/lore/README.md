# ชั้นโลก (lore): ความจริงของโลก

ภาพรวม: [../README.md](../README.md) · วิธีจัดเอกสาร: [../guide/organization.md](../guide/organization.md)

ชั้นนี้ตอบว่า **โลกเป็นอย่างไร ใครคือใคร เกิดอะไรขึ้นที่ไหน** อ่านแล้วไม่ต้องรู้สูตรของเกม ทุกไฟล์เป็นข้อเท็จจริงในโลก ไม่ใช่นิยาย ใช้เป็นต้นทางให้ชั้นระบบและชั้นภาพ

## สิ่งที่อยู่ในชั้นนี้

- ข้อเท็จจริงของโลก: ประวัติ ภูมิศาสตร์ ความสัมพันธ์ ความขัดแย้ง ปมเรื่องหลัก
- ตัวตน: ประเทศ เผ่า มังกร ศาสนา NPC ตระกูล
- เส้นเรื่อง: โหนดของชีวิตแต่ละเผ่า และจุดที่เส้นเรื่องมาบรรจบ

## สิ่งที่ไม่อยู่ในชั้นนี้

- สูตร ค่าสถานะ เปอร์เซ็นต์ เงื่อนไขและผลของเหตุการณ์ → [../systems/](../systems/README.md)
- สี ทรง ท่า เอฟเฟกต์ → [../appearance/](../appearance/README.md)

ข้อยกเว้น: ไฟล์เส้นเรื่องและ NPC มีค่าผลเชิงเกมของโหนดในตารางเพราะโหนดคือเนื้อเรื่องกับผลของมันในแถวเดียวกัน ถ้าต้องแยกเป็นสองไฟล์ จะต้องคัดลอกรหัสโหนดทุกตัว
