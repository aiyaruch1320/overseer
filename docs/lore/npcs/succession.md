# ผู้สืบตำแหน่งและ NPC ที่มาใหม่ตามยุค

NPC ของโลก: [README.md](README.md) · เวลาของโลก: [../world/world-time.md](../world/world-time.md) หัวข้อ 8 · ยุคปลาย: [../../systems/events/branches/04-last-era.md](../../systems/events/branches/04-last-era.md) · พวกพ้อง: [../../systems/bonds/README.md](../../systems/bonds/README.md) · ทายาท: [../heirs/README.md](../heirs/README.md)

รายชื่อ NPC 614 ตัวเขียนด้วยอายุ ความลับ และความสัมพันธ์ของ ศ.ม. 10,400 แต่ตัวละครของผู้เล่นเกิดทุกช่วงของเส้นเวลา ([../world/world-time.md](../world/world-time.md) หัวข้อ 8.1) ไฟล์นี้กำหนดว่า NPC ที่ตัวละครพบเมื่อเกิดหลังต้นเรื่องคือใคร

**นาฬิกาเรื่อง** เรื่องของ NPC เปิดตามนาฬิกาของแต่ละตำแหน่ง ไม่เริ่มพร้อมกัน ([README.md](README.md) หัวข้อ 2.1)

**หลักคิด** (ผู้ใช้ตัดสินแล้ว) เราเป็นพระเจ้าที่เฝ้ามองโลกที่เดินไปเอง ถ้าตัวละครเกิดหลัง NPC คนหนึ่งตายไปแล้วก็ไม่ได้พบกัน และไปพบเหตุการณ์อื่นแทน ช่วงที่ NPC ต้นฉบับหมดไปจึงต้องมี NPC และเรื่องใหม่มาแทน ไม่ปล่อยให้โลกว่าง

## 1. ทำไมต้องมีไฟล์นี้

ผลจำลองจาก [sim-start.mjs](../../../scripts/sim/sim-start.mjs) (800 โลก) ด้วยกติกาจุดเริ่มของ [world-time.md](../world/world-time.md) หัวข้อ 8.1 ชี้ว่า ณ ตอนที่ตัวละครโตเป็นผู้ใหญ่ NPC ต้นฉบับยังมีชีวิตเฉลี่ยเพียง 31% ของรายชื่อ และต่ำมากในเผ่าอายุสั้นซึ่งเป็นกลุ่มใหญ่ของรายชื่อ

| เผ่า | NPC ในรายชื่อ | ต้นฉบับยังอยู่ตอนตัวละครโตเป็นผู้ใหญ่ |
| --- | --- | --- |
| มนุษย์ | 263 | 11% |
| ออร์ค | 23 | 9% |
| เผ่าสัตว์ | 21 | 13% |
| กูล | 7 | 10% |
| เผ่าปีก | 30 | 28% |
| เอลฟ์ | 55 | 32% |
| คนแคระ | 44 | 43% |
| สไลม์ | 6 | 51% |
| มัมมี่ | 5 | 67% |

เพราะไม่มีเผ่าใดอายุขัยเกิน 400 ปีโลก และมีเรื่องของ NPC ที่เอกสารอื่นอ้างถึงถึง 442 ตัว (ผู้นำประเทศ 143 พวกพ้องตัวหลัก 55 และที่ถูกเอ่ยชื่อในโหนดเส้นเรื่องกับเหตุการณ์) ข้อความที่อ้างชื่อ NPC ต้องอ่านได้ต่อไป

## 2. NPC สามชั้น

| ชั้น | ใคร | เมื่อต้นฉบับไม่อยู่แล้ว |
| --- | --- | --- |
| 1 คนจริง | พวกพ้องตัวหลัก 55 คน ([../../systems/bonds/README.md](../../systems/bonds/README.md)) | ปรากฏเมื่อตัวละครโตทันช่วงชีวิตของเขา ถ้าไม่ทัน ช่องของเขาเป็นศิษย์หรือญาติ ตามหัวข้อ 4 |
| 2 ตำแหน่ง | ผู้นำประเทศ 143 ตัว (รหัสลงท้าย -1) และ NPC ที่ผูกกับตำแหน่ง | รหัสคือตำแหน่ง ผู้ถือคนปัจจุบันเป็นผู้สืบ ตามหัวข้อ 3 |
| 3 ฉากหลัง | NPC ที่เหลือ | ไม่สืบเป็นรายตัว สร้างใหม่ตามบทบาทเมื่อฉากต้องการ และ NPC ที่มาใหม่ตามหัวข้อ 5 เข้ามาเติม |

ข้อความในเอกสารอื่นที่อ้างชื่อ NPC ถือเป็น **ชื่อต้นแบบ** ของตำแหน่ง ในเกมแสดงชื่อของผู้ถือจริง ณ เวลานั้น

## 3. ผู้สืบตำแหน่ง (ชั้น 2)

สร้างเฉพาะผู้ถือคนปัจจุบัน ณ จุดเริ่ม ประวัติระหว่างทางสรุปเป็นเลขรุ่น ไม่จำลองทุกรุ่น

| ข้อ | กติกา |
| --- | --- |
| ชื่อ | ชื่อต้นแบบตามด้วยเลขรุ่น เช่น "เอลเดรียนที่ 4" เหมือนชื่อไวรอน-1 ถึง ไวรอน-4 ของหุ่นวิญญาณ ไม่ต้องมีชุดชื่อ ชุดชื่อจริงต่อถิ่นเก็บไว้ทำใน MVP2 |
| เลขรุ่น | จำนวนปีโลกจากต้นเรื่องถึงจุดเริ่ม หารด้วยระยะห่างรุ่นของเผ่า ([../world/world-time.md](../world/world-time.md) หัวข้อ 3) ปัดขึ้น |
| อายุ | สุ่มระหว่างอายุผู้ใหญ่ถึงผู้เฒ่าของเผ่า |
| บทบาท ความลับ ความสัมพันธ์ | สืบจากต้นแบบ 80% อีก 20% เปลี่ยนตามตารางหัวข้อ 3.1 |
| ต้นแบบ | กลายเป็นผู้ก่อตั้งหรือบรรพบุรุษ ถูกพูดถึงในบทสนทนา ตำนาน และศิลาจารึกของถิ่น |
| ถ้าต้นแบบยังมีชีวิต | ใช้ตัวต้นแบบ ไม่ต้องสร้างรุ่นสืบ (ทอยอายุขัยตามหัวข้อ 4.4 ของ [04-last-era.md](../../systems/events/branches/04-last-era.md) เพื่อตัดสินว่ายังอยู่) |

ตัวเลข 80/20 เป็นค่าเริ่มต้น ยังไม่ได้ทดสอบ

### 3.1 ตารางเมื่อ 20% เปลี่ยน

ทอยหนึ่งครั้งต่อผู้สืบ

| ผล | ความหมาย |
| --- | --- |
| ความลับเดิมหมดความสำคัญ | ผู้สืบไม่รู้หรือไม่สนใจเรื่องที่ต้นแบบปกปิด ความลับกลายเป็นเรื่องที่ผู้อื่นค้นพบ |
| ความลับถูกเปิดเผยแล้ว | ทุกคนรู้เรื่องที่ต้นแบบซ่อน ผู้สืบอยู่กับผลของมัน |
| ผู้สืบเป็นฝ่ายตรงข้ามกับต้นแบบ | กลับท่าทีต่อศัตรูหรือพันธมิตรเดิม |
| ผู้สืบมีแผนใหม่ | อยากทำสิ่งที่ต้นแบบไม่เคยทำ ใช้ทางเลือก ค) ของแถวเดิมเป็นเป้าหมายแทน |
| ตำแหน่งเปลี่ยนมือด้วยเหตุรุนแรง | ผู้ถือเป็นผู้ที่ชิงตำแหน่ง ไม่ใช่สายสืบ |
| ผู้สืบอ่อนกว่าตำแหน่ง | อายุน้อยหรือไม่ชำนาญ ผู้ช่วยมีบทบาทสูงขึ้น |

## 4. พวกพ้องตัวหลักเมื่อต้นฉบับไม่อยู่ (ชั้น 1)

พวกพ้องตัวหลักแต่ละคนมีเรื่องเฉพาะ ใช้ซ้ำกับผู้สืบแบบตำแหน่งไม่ได้ จึงมีกติกาแยก

| ข้อ | กติกา |
| --- | --- |
| ปรากฏตามช่วงชีวิต | พวกพ้องตัวหลักปรากฏเมื่อจุดเริ่มอยู่ในช่วงที่เขามีชีวิตและอายุอยู่ในกรอบของเรื่องเขา ผลจำลองบอกว่ายังมีชีวิตตอนตัวละครโตเป็นผู้ใหญ่เพียง 9–67% ตามเผ่า (หัวข้อ 1) |
| ถ้าไม่ปรากฏ | ช่องนั้นเป็น **ศิษย์** หรือ **ญาติ** ของเขา เขียนรายตัวครบ 55 คนแล้วใน [../../systems/bonds/07-successors.md](../../systems/bonds/07-successors.md) เรื่องของพวกพ้องเล่าเป็น "เรื่องที่สืบมา" ปลายทางทั้งสามของเรื่อง (ก ข ค) ยังใช้ได้ แต่ชื่อเรื่องและสถานที่เปลี่ยนเป็นของผู้สืบ |
| สายสัมพันธ์ | ยึดสายเดิม ยกเว้นคนรักที่ไม่สืบ และเริ่มที่ระดับต่ำกว่าเดิมหนึ่งระดับ เพราะเป็นความผูกพันที่ต้องสร้างใหม่ |
| เพดานระดับ | ใช้กติกาเดิม ผู้ที่ถูกผูกตัวอยู่ระดับ 3 ได้ถึงจะได้รับการไถ่ |

## 6. ผลต่อส่วนอื่น

- รายชื่อ NPC เดิมไม่ถูกแก้ ตัวเลขและข้อความยังถูกต้องสำหรับต้นเรื่อง
- ตัวตรวจรหัส NPC ไม่เปลี่ยน แม่แบบ NT ไม่ใช่รหัส NPC (ไม่ตรงรูป `AA00-0`)
- ผลจำลอง: ใช้ [sim-start.mjs](../../../scripts/sim/sim-start.mjs) กับ [sim-npc-fate.mjs](../../../scripts/sim/sim-npc-fate.mjs)

## 7. ที่ยังไม่ได้ทำ

- ภาพของ NPC ที่มาใหม่เขียนแล้วใน [../../appearance/18-last-era-scenes.md](../../appearance/18-last-era-scenes.md) ภาพผู้สืบพวกพ้องใน [../../appearance/19-ally-successors.md](../../appearance/19-ally-successors.md)

- ชุดชื่อต่อถิ่นสำหรับผู้สืบและ NPC ที่มาใหม่ ใช้ชื่อต้นแบบกับเลขรุ่นไปก่อน
- ตัวเลข 80/20 และ 40% ยังไม่ได้ทดสอบ และผู้เล่นจริงอาจรู้สึกว่าผู้สืบเป็นสำเนา รอรีวิวจากผู้เล่น
