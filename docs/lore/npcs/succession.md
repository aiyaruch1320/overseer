# ผู้สืบตำแหน่งและ NPC ที่มาใหม่ตามยุค

NPC ของโลก: [README.md](README.md) · เวลาของโลก: [../world/world-time.md](../world/world-time.md) หัวข้อ 8 · ยุคปลาย: [../../systems/events/branches/04-last-era.md](../../systems/events/branches/04-last-era.md) · พวกพ้อง: [../../systems/bonds/README.md](../../systems/bonds/README.md) · ทายาท: [../heirs/README.md](../heirs/README.md)

รายชื่อ NPC 614 ตัวเขียนด้วยอายุ ความลับ และความสัมพันธ์ของ ศ.ม. 10,400 แต่ตัวละครของผู้เล่นเกิดทุกช่วงของเส้นเวลา ([../world/world-time.md](../world/world-time.md) หัวข้อ 8.1) ไฟล์นี้กำหนดว่า NPC ที่ตัวละครพบเมื่อเกิดหลังต้นเรื่องคือใคร

**นาฬิกาเรื่อง** เรื่องของ NPC เปิดตามนาฬิกาของแต่ละตำแหน่ง ไม่เริ่มพร้อมกัน ([README.md](README.md) หัวข้อ 2.1)

**หลักคิด** (ผู้ใช้ตัดสินแล้ว) เราเป็นพระเจ้าที่เฝ้ามองโลกที่เดินไปเอง ถ้าตัวละครเกิดหลัง NPC คนหนึ่งตายไปแล้วก็ไม่ได้พบกัน และไปพบเหตุการณ์อื่นแทน ช่วงที่ NPC ต้นฉบับหมดไปจึงต้องมี NPC และเรื่องใหม่มาแทน ไม่ปล่อยให้โลกว่าง

## 1. ทำไมต้องมีไฟล์นี้

ผลจำลองจาก [sim-start.mjs](../../../scripts/sim/sim-start.mjs) (3,000 โลก) ด้วยกติกาจุดเกิดของ [world-time.md](../world/world-time.md) หัวข้อ 8.1 ชี้ว่า ณ ตอนที่ตัวละครโตเป็นผู้ใหญ่ NPC ต้นฉบับยังมีชีวิตเฉลี่ยเพียง 30% ของรายชื่อ และต่ำมากในเผ่าอายุสั้นซึ่งเป็นกลุ่มใหญ่ของรายชื่อ

| เผ่า | NPC ในรายชื่อ | ต้นฉบับยังอยู่ตอนตัวละครโตเป็นผู้ใหญ่ |
| --- | --- | --- |
| มนุษย์ | 263 | 11% |
| ออร์ค | 23 | 9% |
| เผ่าสัตว์ | 21 | 15% |
| กูล | 7 | 13% |
| เผ่าปีก | 30 | 27% |
| เอลฟ์ | 55 | 29% |
| คนแคระ | 44 | 40% |
| สไลม์ | 6 | 49% |
| มัมมี่ | 5 | 56% |

เพราะไม่มีเผ่าใดอายุขัยเกิน 400 ปีโลก และมีเรื่องของ NPC ที่เอกสารอื่นอ้างถึงถึง 442 ตัว (ผู้นำประเทศ 143 พวกพ้องตัวหลัก 55 และที่ถูกเอ่ยชื่อในโหนดเส้นเรื่องกับเหตุการณ์) ข้อความที่อ้างชื่อ NPC ต้องอ่านได้ต่อไป

## 2. NPC สามชั้น

| ชั้น | ใคร | เมื่อต้นฉบับไม่อยู่แล้ว |
| --- | --- | --- |
| 1 คนจริง | พวกพ้องตัวหลัก 55 คน ([../../systems/bonds/README.md](../../systems/bonds/README.md)) | ปรากฏเมื่อตัวละครโตทันช่วงชีวิตของเขา ถ้าไม่ทัน ช่องของเขาเป็นศิษย์หรือญาติ ตามหัวข้อ 4 |
| 2 ตำแหน่ง | ผู้นำประเทศ 143 ตัว (รหัสลงท้าย -1) NPC ที่ผูกกับตำแหน่ง และ NPC ทุกตัวที่แถวผูกเหตุการณ์โลก (บทบาทในแถว เช่น ผู้เก็บศพ ล่ามใต้ปากเหว คือตำแหน่ง) ยกเว้นพวกพ้องตัวหลักซึ่งอยู่ชั้น 1 | รหัสคือตำแหน่ง ผู้ถือคนปัจจุบันเป็นผู้สืบ ตามหัวข้อ 3 เรื่องที่ผูกเหตุการณ์เปิดกับผู้ถือ ณ ตอนที่เหตุการณ์เกิด ([README.md](README.md) หัวข้อ 2.1 ข้อ 6) พวกพ้องตัวหลักที่แถวผูกเหตุการณ์ใช้ผู้สืบตามหัวข้อ 4 แทน |
| 3 ฉากหลัง | NPC ที่เหลือ | ทอยครั้งเดียวต่อแถวเมื่อโลกเริ่ม 60% ของแถวมีผู้สืบทุกรุ่นตามหัวข้อ 3 (บทบาทในแถวคือตำแหน่ง) แถวที่ไม่ผ่านไม่สืบเป็นรายตัว สร้างใหม่ตามบทบาทเมื่อฉากต้องการ ทุกประเทศได้ NPC ที่มาใหม่ตามหัวข้อ 5 เข้ามาเติม |

ข้อความในเอกสารอื่นที่อ้างชื่อ NPC ถือเป็น **ชื่อต้นแบบ** ของตำแหน่ง ในเกมแสดงชื่อของผู้ถือจริง ณ เวลานั้น

**เรื่องที่ผูกกับตัวคนหรือกับต้นเรื่อง** แถวที่เรื่องหลักคือความทรงจำ กำเนิด หรือความลับของตัวคนนั้นเอง หรือผูกกับสภาพที่มีเฉพาะตอนต้นเรื่อง (เช่น ผลพวงของภารกิจเมฆา FG-01) ผู้สืบใช้ตาราง 3.1 เสมอแทน 80/20 ผู้สืบจึงไม่เล่นเรื่องของต้นฉบับซ้ำ

**เหตุผลของ 60%** วัดด้วย [sim-npc-density.mjs](../../../scripts/sim/sim-npc-density.mjs) (ผลในหัวข้อ 5.1) ถ้าไม่มีผู้สืบชั้น 3 NPC ที่มีเรื่องต่อประเทศลดจากราว 4 ตอนต้นเรื่องเหลือราว 1.7 หลังปีที่ 100 ไปตลอดโลก ถ้าสืบทุกแถว ทุกเรื่องวนซ้ำทุกยุค

## 3. ผู้สืบตำแหน่ง (ชั้น 2)

สร้างเฉพาะผู้ถือคนปัจจุบัน ณ จุดเริ่ม ประวัติระหว่างทางสรุปเป็นเลขรุ่น ไม่จำลองทุกรุ่น

| ข้อ | กติกา |
| --- | --- |
| ชื่อ | ชื่อต้นแบบตามด้วยเลขรุ่น เช่น "เอลเดรียนที่ 4" เหมือนชื่อไวรอน-1 ถึง ไวรอน-4 ของหุ่นวิญญาณ ไม่ต้องมีชุดชื่อ ชุดชื่อจริงต่อถิ่นเก็บไว้ทำใน MVP2 |
| เลขรุ่น | จำนวนปีโลกจากต้นเรื่องถึงจุดเริ่ม หารด้วยระยะห่างรุ่นของเผ่า ([../world/world-time.md](../world/world-time.md) หัวข้อ 3) ปัดขึ้น แล้วบวก 1 (ต้นแบบคือรุ่นที่ 1) |
| อายุ | สุ่มระหว่างอายุผู้ใหญ่ถึงผู้เฒ่าของเผ่า |
| บทบาท ความลับ ความสัมพันธ์ | สืบจากต้นแบบ 80% อีก 20% เปลี่ยนตามตารางหัวข้อ 3.1 |
| ต้นแบบ | กลายเป็นผู้ก่อตั้งหรือบรรพบุรุษ ถูกพูดถึงในบทสนทนา ตำนาน และศิลาจารึกของถิ่น |
| ถ้าต้นแบบยังมีชีวิต | ใช้ตัวต้นแบบ ไม่ต้องสร้างรุ่นสืบ (ทอยอายุขัยตามหัวข้อ 4.3 ของ [04-last-era.md](../../systems/events/branches/04-last-era.md) เพื่อตัดสินว่ายังอยู่) |
| ผู้ถือตายระหว่างชีวิตตัวละคร | สร้างรุ่นถัดไปทันที เลขรุ่น +1 ทอย 80/20 ใหม่ และเริ่มนาฬิกาเรื่องใหม่ ([README.md](README.md) หัวข้อ 2.1 ข้อ 4) ผู้ถือที่ย้ายถิ่นหรือสาบสูญใช้กติกาเดียวกัน ยกเว้นผู้เฝ้ากุญแจที่ตายหรือสาบสูญจากตารางชะตายุคปลาย ซึ่งตำแหน่งจบพร้อมกุญแจ ([04-last-era.md](../../systems/events/branches/04-last-era.md) หัวข้อ 4.3) |

ตัวเลข 80/20 เป็นค่าเริ่มต้น ยังไม่ได้ทดสอบ

### 3.1 ตารางเมื่อ 20% เปลี่ยน

ทอยหนึ่งครั้งต่อผู้สืบ

| ผล | ความหมาย |
| --- | --- |
| ความลับเดิมหมดความสำคัญ | ผู้สืบไม่รู้หรือไม่สนใจเรื่องที่ต้นแบบปกปิด ความลับกลายเป็นเรื่องที่ผู้อื่นค้นพบ |
| ความลับถูกเปิดเผยแล้ว | ทุกคนรู้เรื่องที่ต้นแบบซ่อน ผู้สืบอยู่กับผลของมัน |
| ผู้สืบเป็นฝ่ายตรงข้ามกับต้นแบบ | กลับท่าทีต่อศัตรูหรือพันธมิตรเดิม |
| ผู้สืบมีแผนใหม่ | อยากทำสิ่งที่ต้นแบบไม่เคยทำ ใช้ทางเลือก ค) ของแถวเดิมเป็นเป้าหมายแทน |
| ตำแหน่งเปลี่ยนมือด้วยเหตุรุนแรง | ผู้ถือเป็นผู้ที่ชิงตำแหน่ง ไม่ใช่สายสืบ |
| ผู้สืบอ่อนกว่าตำแหน่ง | อายุน้อยหรือไม่ชำนาญ ผู้ช่วยมีบทบาทสูงขึ้น |

## 4. พวกพ้องตัวหลักเมื่อต้นฉบับไม่อยู่ (ชั้น 1)

พวกพ้องตัวหลักแต่ละคนมีเรื่องเฉพาะ ใช้ซ้ำกับผู้สืบแบบตำแหน่งไม่ได้ จึงมีกติกาแยก

| ข้อ | กติกา |
| --- | --- |
| ปรากฏตามช่วงชีวิต | พวกพ้องตัวหลักปรากฏเมื่อจุดเริ่มอยู่ในช่วงที่เขามีชีวิตและอายุอยู่ในกรอบของเรื่องเขา ผลจำลองบอกว่ายังมีชีวิตตอนตัวละครโตเป็นผู้ใหญ่เพียง 9–56% ตามเผ่า (หัวข้อ 1) |
| ถ้าต้นแบบตายแล้วหรืออายุเลยกรอบของเรื่อง | ช่องนั้นเป็น **ศิษย์** หรือ **ญาติ** ของเขา เขียนรายตัวครบ 55 คนแล้วใน [../../systems/bonds/07-successors.md](../../systems/bonds/07-successors.md) เรื่องของพวกพ้องเล่าเป็น "เรื่องที่สืบมา" ปลายทางทั้งสามของเรื่อง (ก ข ค) ยังใช้ได้ แต่ชื่อเรื่องและสถานที่เปลี่ยนเป็นของผู้สืบ |
| สายสัมพันธ์ | ยึดสายเดิม ยกเว้นคนรักที่ไม่สืบ และเริ่มที่ระดับต่ำกว่าเดิมหนึ่งระดับ เพราะเป็นความผูกพันที่ต้องสร้างใหม่ |
| เพดานระดับ | ใช้กติกาเดิม ผู้ที่ถูกผูกตัวอยู่ระดับ 3 ได้ถึงจะได้รับการไถ่ |


## 5. NPC ที่มาใหม่ตามยุค (ชั้น 3 ที่ถูกเติม)

ทุก 100 ปีโลกนับจากต้นเรื่อง (ปีที่ 100 200 …) และเมื่อเริ่มยุค 2 3 และช่วงย่อย 4ก 4ข 4ค แต่ละประเทศมีโอกาส 40% ได้ NPC ที่มาใหม่หนึ่งคน เลือกจากแม่แบบที่ยุคตรงกับยุคตอนนั้นและเงื่อนไขตรงกับประเทศ แม่แบบประจำทวีป (NT-19 ถึง NT-54) น้ำหนัก ×2 ของแม่แบบทั่วไป แม่แบบหนึ่งใช้ได้ครั้งเดียวต่อประเทศต่อโลก ถ้าไม่มีที่ตรง ไม่เกิด ยุค 4 ใช้รอบทอยชะตาของ [04-last-era.md](../../systems/events/branches/04-last-era.md) หัวข้อ 4 ร่วมด้วย NPC ที่มาใหม่ใช้รหัสตามประเทศต่อจากเลขสูงสุดของประเทศนั้น และมีความลับกับเส้นเรื่อง 3 ทางเหมือน NPC ปกติ (น้ำหนักในตาราง) ต้นฉบับยุค 1 ไม่ได้เกิดจากแม่แบบเหล่านี้ แม่แบบ NT-13 ถึง NT-18 เป็นแม่แบบทั่วไปของยุค 1 NT-19 ถึง NT-54 เป็นแม่แบบประจำทวีป ทวีปละหนึ่งแบบต่อยุค

เรื่องของ NPC ที่มาใหม่เปิดแบบผูกวัย ([README.md](README.md) หัวข้อ 2.1 ข้อ 1 แบบ 2) คอลัมน์ "เชื่อม" คือเหตุการณ์ที่เรื่องส่งผลถึงหรือที่ทำให้แม่แบบนั้นเกิด ไม่ใช่จุดเปิด

ตัวเลข 40% รอบ 100 ปี และ ×2 เป็นค่าเริ่มต้น ยังไม่ได้ทดสอบกับผู้เล่น แม่แบบเหล่านี้เป็นคนในโลก ไม่ใช่ตัวละครของผู้เล่น ทำหน้าที่แทรกเรื่องในช่วงที่ต้นฉบับหมดไป

## 6. ผลต่อส่วนอื่น

- รายชื่อ NPC เดิมไม่ถูกแก้ ตัวเลขและข้อความยังถูกต้องสำหรับต้นเรื่อง
- ตัวตรวจรหัส NPC ไม่เปลี่ยน แม่แบบ NT ไม่ใช่รหัส NPC (ไม่ตรงรูป `AA00-0`)
- ผลจำลอง: ใช้ [sim-start.mjs](../../../scripts/sim/sim-start.mjs) กับ [sim-npc-fate.mjs](../../../scripts/sim/sim-npc-fate.mjs)

## 7. ที่ยังไม่ได้ทำ

- ภาพของ NPC ที่มาใหม่เขียนแล้วใน [../../appearance/18-last-era-scenes.md](../../appearance/18-last-era-scenes.md) ภาพผู้สืบพวกพ้องใน [../../appearance/19-ally-successors.md](../../appearance/19-ally-successors.md)
