# เผ่าสัตว์

ค่าสถานะ ความสามารถ พร คำสาป สกิล: [../../systems/character/races/07-beast.md](../../systems/character/races/07-beast.md)

## ประวัติ

ธาตุป่าไม่ได้ตกแต่บนต้นไม้ มันตกบนสัตว์ด้วย สัตว์ที่ได้รับธาตุยืนสองขา พูดได้ และจดจำได้ เผ่าสัตว์จึงเป็นผู้อยู่ในป่ามาก่อนเอลฟ์ และมองต้นไม้โลกเป็นบรรพบุรุษร่วม

ศ.ม. 4,000 เอลฟ์กับเผ่าสัตว์ทำ *สนธิสัญญารากหญ้า* แบ่งป่าด้วยความเท่าเทียม แต่เมื่อ ศ.ม. 7,800 เอลฟ์ประกาศกฎลำต้นห้ามล่าในร่มไม้ เผ่าสัตว์เสียเขตล่าและถูกขับออกจากหัวใจของป่า ความแค้นนี้ยังไม่หาย

เผ่าสัตว์รักพวกพ้องเหนือสิ่งอื่น หนึ่งฝูงคือหนึ่งชีวิต ผู้ที่ทิ้งฝูงถือเป็นผู้เสียชีวิตไปแล้ว

## ที่อยู่

ธาลาวิน (SV-16) · ลาเฟธิลร่วมกับเอลฟ์ (SV-09) · ไวลด์มาร์กในทุ่งราบ (AL-23) · อัลมาในทะเลทราย (SH-10) · เซวาร์ธในมอร์เฮเวน (MH-04) บางส่วน

## สายเลือดย่อย

| สาย | ลักษณะ |
| --- | --- |
| เผ่าหมาป่า | นักล่าฝูง สายสัมพันธ์แน่น |
| เผ่าเสือและแมวใหญ่ | นักล่าเดี่ยว เร็วและเงียบ |
| เผ่ากวางและวัว | ผู้ป้องกัน ความทนทานสูง |
| เผ่านก | ส่งสาร ร่อนได้ในระยะสั้น (ไม่ใช่เผ่าปีก) |
| เผ่าอูฐและจิ้งจกทราย | ทนแล้ง นักนำทาง |

## ความสัมพันธ์

พันธมิตรกับฮาล์ฟลิงและเผ่าที่เคารพธรรมชาติ ขัดแย้งกับเอลฟ์ (กฎลำต้น) ออร์ค (ที่ล่า) และมนุษย์ที่ล่าสัตว์เพื่อเกียรติ

## เรื่องราวที่ผูกกับเรื่องหลัก

1. ธาลาวินเรียกร้องการล่าครั้งใหญ่ ถ้าเอลฟ์ไม่ยอม สงครามป่า (WR-17) เกิด
2. ผู้ลี้ภัยเผ่าสัตว์ที่ไวลด์มาร์กเป็นจุดกำเนิดของการอพยพใหญ่ (BIO-09)
3. ลาเฟธิลคือหลักฐานว่าเอลฟ์กับเผ่าสัตว์ร่วมมือกันได้ เป็นความหวังเดียวของการปรองดอง
