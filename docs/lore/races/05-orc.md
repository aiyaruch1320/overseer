# ออร์ค

ค่าสถานะ ความสามารถ พร คำสาป สกิล: [../../systems/character/races/05-orc.md](../../systems/character/races/05-orc.md)

## ประวัติ

ธาตุสงครามที่ตกใส่มอร์เฮเวนไม่ได้ทำให้คนชั่ว มันทำให้ทุกอย่าง **หิว** ผู้รอดชีวิตที่ปรับตัวได้กลายเป็นออร์ค ร่างใหญ่ กำลังดิบ เก็บพลังโดยกินและรบ ผู้ที่ปรับตัวไม่ได้ตายหรือกลายเป็นกูล

ออร์คไม่ได้รักการรบ พวกเขารบเพราะต้องกิน เกียรติของออร์ควัดจากการที่ไม่ปล่อยให้พวกพ้องอดอยาก ผู้ที่รบเพื่อชื่อเสียงอย่างเดียวถูกมองว่าเสียสติ

เมื่อ ศ.ม. 9,560 ห้าธงรบกันสี่สิบปีโดยไม่มีผู้ชนะ และตกลงข้อตกลงห้าธง ออร์คจึงเข้าใจว่าสงครามไม่ได้แก้ความหิว แต่ยังหาทางอื่นไม่ได้ ทัพข้ามทะเลคือคำตอบเดียวที่พวกเขานึกออก

## ที่อยู่

มอร์เฮเวน (กาธเรธ MH-01, นอคดรีน MH-05, เซวาร์ธ MH-04) · ซาร์กัช ในซาฮารัน (SH-11) · ทหารรับจ้างทั่วโลก

## สายเลือดย่อย

| สาย | ที่อยู่ | ลักษณะ |
| --- | --- | --- |
| โอเกอร์ | กาธเรธ | ร่างใหญ่ที่สุด กำลังสูง ปัญญาต่ำ |
| ออร์คเถ้า | เซวาร์ธ | เบา เร็ว ขี่หมาป่า |
| ออร์คช่าง | นอคดรีน | ทำเครื่องล้อมเมืองและป้อม |
| ออร์คทราย | ซาร์กัช | ทนแล้ง ปล้นกองคาราวาน |
| ออร์คสันติ | วีซาเฮเวน (MH-06) | ปลูกข้าวเถ้า |

## ความสัมพันธ์

พันธมิตรกับเผ่าปีศาจและกูลในยามศึก ขัดแย้งกับเอลฟ์ (เรื่องชายแดนใต้) เผ่าสัตว์ (เรื่องที่ล่า) และคนแคระ (เรื่องเหล็ก) ถูกมนุษย์ทุ่งราบหวาดกลัว

## เรื่องราวที่ผูกกับเรื่องหลัก

1. จอมมารเกิดจากศึกชิงมงกุฎกระดูกที่ออร์คคือผู้เข้าร่วมหลัก และนี่คือที่มาของการบุกทุกครั้ง
2. ออร์คสันติที่ปลูกข้าวเถ้าอาจเปลี่ยนความหิวของทั้งทวีปได้ (HP-07)
3. ทหารรับจ้างออร์คไหลสู่เมคาเรียมากเกินจนมอร์เฮเวนขาดนักรบดี (MC-08)
