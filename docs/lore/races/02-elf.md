# เอลฟ์

ค่าสถานะ ความสามารถ พร คำสาป สกิล: [../../systems/character/races/02-elf.md](../../systems/character/races/02-elf.md)

## ประวัติ

เอลฟ์เป็นผู้ดูแลต้นไม้โลกตั้งแต่ต้นไม้ยังเป็นกล้า ธาตุป่าที่ตกลงบนซิลวาเนลทำให้ต้นหนึ่งโตเกินธรรมชาติ ผู้รอดชีวิตที่เดินเข้าไปในร่มของมันได้รับอายุยืนและความสงบ จนกลายเป็นเอลฟ์

เอลฟ์เชื่อว่าโลกมีสิ่งที่ต้องรักษา และเผ่าอื่นเป็นผู้ที่มักทำลาย พวกเขาจึงเลือกอยู่แยก ตั้งสภาผู้อาวุโสเมื่อ ศ.ม. 1,000 ประกาศ *กฎลำต้น* เมื่อ ศ.ม. 7,800 ห้ามล่าสัตว์ภายใต้ร่มไม้ ซึ่งทำให้เผ่าสัตว์เสียเขตล่าและเกิดความแค้นยืดยาว

เอลฟ์ไม่ได้เกลียดเผ่าอื่น เพียงรู้สึกว่าใช้เวลาด้วยกันแล้วเหนื่อย พวกเขามีอายุสองถึงสามร้อยปี ผู้ที่ตายก่อนเสร็จเรื่องที่คุยถือว่าเสียมารยาท

## ที่อยู่

ซิลวาเนล (14 ประเทศใต้ร่มต้นไม้โลก) · เอลฟ์พลัดถิ่นที่เซเลสเทีย (AL-22) · ผู้ลี้ภัยช่างกลที่อีลาเวียร์ (MK-11)

## สายเลือดย่อย

| สาย | ที่อยู่ | ลักษณะ |
| --- | --- | --- |
| เอลฟ์ต้นไม้ | ซิลนเนลลอร์, ธิลเอวา | ดูแลต้นไม้โลกโดยตรง |
| เอลฟ์จันทรา | ลูไอลิส (SV-05) | นักดาราศาสตร์ นักพยากรณ์ |
| เอลฟ์ฟ้า | ซิลเฟลิส (SV-10) | อยู่บนยอดไม้ ใช้เวทลม |
| เอลฟ์ราก | เดลวินธ์ (SV-12) | อยู่ใต้ดิน เก็บเห็ดและยา |
| เอลฟ์สูง | เซเลสเทีย | พลัดถิ่น คิดถึงป่า |

## ความสัมพันธ์

พันธมิตรกับภูต ฮาล์ฟลิง และบางส่วนของเผ่าสัตว์ ไม่ลงรอยกับมนุษย์ (โลภ) คนแคระ (ปิดบัง) เผ่าสัตว์ (เรื่องกฎลำต้น) ถือดาร์กเอลฟ์เป็นญาติที่ละทิ้งคำสาบาน

## เรื่องราวที่ผูกกับเรื่องหลัก

1. ต้นไม้โลกป่วยหนักกว่าที่ผู้อาวุโสบอก และเอลฟ์ไม่อยากขอความช่วยเหลือ (BIO-01)
2. เอลฟ์ที่ออกจากป่าไปเมคาเรียรู้ก่อนใครว่ามลพิษเป็นเหตุ แต่ไม่ได้รับอนุญาตให้กลับ
3. กฎลำต้นเป็นสาเหตุของสงครามป่า (WR-17) ถ้าเอลฟ์ยอมแก้กฎ อาจรักษาต้นไม้ได้ด้วยพันธมิตรเผ่าสัตว์
