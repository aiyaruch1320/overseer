# เผ่าพันธุ์ทั้ง 21 เผ่า

ทวีป: [../world/continents.md](../world/continents.md) · ประเทศ: [../countries/README.md](../countries/README.md) · เรื่องราว: [../world/story-continents.md](../world/story-continents.md) · เส้นเรื่องตัวละครแต่ละเผ่า: [../storylines/README.md](../storylines/README.md)

ไฟล์ละเผ่า แต่ละไฟล์มี ประวัติ ที่อยู่ สายเลือดย่อย (ถ้ามี) ความสัมพันธ์ ช่วงค่าสถานะเริ่มต้น ความสามารถประจำเผ่า พร 4 ระดับ (U, R, E, L) คำสาป 3 ข้อ สกิลเฉพาะเผ่า 4 ข้อ และเรื่องราวที่ผูกกับเรื่องหลัก รายการพร คำสาป และสกิลทั้งหมดเป็นของเฉพาะเผ่านั้น ไม่นับของพื้นฐานที่ทุกเผ่ามีร่วมกัน

ค่าสถานะ ความสามารถ พร คำสาป สกิลของแต่ละเผ่าอยู่ในชั้นระบบ: [../../systems/character/races/README.md](../../systems/character/races/README.md)

## สายเลือดย่อยที่ไม่นับเป็นเผ่าแยก

| เผ่าหลัก | สายเลือดย่อย |
| --- | --- |
| มนุษย์ | ชาวทุ่ง, ชาวหมอก, ชนผืนทราย, มนุษย์เรือ, ชาวพื้น, ผู้กลับชาติ, ผู้ถูกอัญเชิญ |
| เอลฟ์ | เอลฟ์ต้นไม้, เอลฟ์จันทรา, เอลฟ์ฟ้า, เอลฟ์ราก, เอลฟ์สูง |
| คนแคระ | ช่างตี, ผู้ปิดรูน, ผู้เปิดรูน, วิศวกร, คนเหมืองลึก, คนแคระเหนือ |
| ออร์ค | โอเกอร์, ออร์คเถ้า, ออร์คช่าง, ออร์คทราย, ออร์คสันติ |
| เผ่าสัตว์ | หมาป่า, เสือและแมวใหญ่, กวางและวัว, นก, อูฐและจิ้งจกทราย |
| เงือก | เงือก, เงือกน้ำลึก, ไซเรน, กัปปะ |
| เผ่าปีก | อาเวียนขาว, ปีกราตรี, ปีกเกล็ด, ปีกสั้น, ชาวน้ำฟ้า |
| ยักษ์ | ไซคลอปส์, จอตุน, ยักษ์ช่าง, ยักษ์ผู้เงียบ |
| ลูกผสมจักรกล | ผู้ติดตั้ง, ผู้รอดชีวิตตุ๊กตา, ลูกผสมนีออน, ผู้เลือกเอง |

## ที่มาของเผ่า ตามธาตุของมหาล่มสลาย

| ธาตุ | เผ่าที่เกิด |
| --- | --- |
| ฟ้า | เผ่าปีก, เผ่ามังกร (สายผสม) |
| สงคราม | ออร์ค, เผ่าปีศาจ, กูล |
| ไฟ | เผ่าลาวา, คนแคระ (มาถึงภายหลัง) |
| น้ำ | เงือก, นาคา |
| ผู้คน | มนุษย์, ฮาล์ฟลิง |
| จักรกล | ลูกผสมจักรกล, หุ่นวิญญาณ |
| หิน | ยักษ์ |
| ป่า | เอลฟ์, เผ่าสัตว์, ภูตพราย, สไลม์ (บางสาย) |
| หมอก | แวมไพร์ (ย้ายเข้ามา), ชาวหมอก |
| ทะเลทราย | มัมมี่ |
| ทุกธาตุ | สไลม์ (ชิ้นส่วนของมหาล่มสลาย), ดาร์กเอลฟ์ (เอลฟ์ที่ละทิ้งป่า) |

## การจับคู่ชื่อเผ่าในไฟล์ประเทศ กับรายชื่อ 21 เผ่า

| ชื่อในไฟล์ประเทศ | จัดเป็น |
| --- | --- |
| ชนใต้ทราย (SH-12) | สายเลือดย่อยของมนุษย์ |
| มนุษย์น้ำแข็ง (KD-12) | สายเลือดย่อยของมนุษย์ (คนแคระเหนือเป็นสายของคนแคระ) |
| ปีศาจเพลิง (KD) | สายเพลิงของเผ่าปีศาจ |
| ผู้ไร้เงา (NB-13) | สถานะของผู้ที่สูญเสียเงา พบในดาร์กเอลฟ์และมนุษย์ ไม่ใช่เผ่าแยก |
| ผีเมือง ผีเมืองปฐม ผีเอลฟ์ วิญญาณทหาร วิญญาณหมอก | วิญญาณและปรากฏการณ์ ไม่ใช่เผ่าที่เกิดเป็นตัวละครได้ |
| เผ่าเห็ด (SV-18) | สายเลือดย่อยของสไลม์ที่ติดสปอร์ |
| ภูตแสง ภูตลม ภูตน้ำ ภูตจิ๋ว | สายเลือดย่อยของภูตพราย |
| นักล่า เดรุยด์ นักปราชญ์ | อาชีพ ไม่ใช่เผ่า |
| ราชาเห็ด | ผู้ปกครองพิเศษของสไลม์สายเห็ด |
| นาคาลูกครึ่ง (SV-17) | ลูกผสมของนาคาและมนุษย์ |
