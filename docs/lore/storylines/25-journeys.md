# เส้นเรื่อง: การเดินทางและการเจอต่างเผ่า (sf ps ml sc ex wd xc)

โครงสร้าง: [README.md](README.md) · กติกาการเดินทาง: [../../systems/travel/01-travel-rules.md](../../systems/travel/01-travel-rules.md) · การค้าและขบวน: [24-economy.md](24-economy.md) (โหนด tr) · จุดบรรจบ: [00-convergence.md](00-convergence.md) · เศรษฐกิจ: [../../systems/economy/05-trade.md](../../systems/economy/05-trade.md)

แรงบันดาลใจ: ขบวนพ่อค้าข้ามทะเลทราย กองเรือที่ไม่เคยจอดท่าเดิมสองครั้ง ผู้แสวงบุญที่ไปถึงแล้วพบว่าที่นั่นไม่เหมือนที่เล่า ทหารรับจ้างที่รบคนละฝ่ายกับญาติตัวเอง

## 1. ธีม

ชีวิตหนึ่งอาจอยู่ที่เดิมทั้งชีวิตหรือเดินทางทั้งชีวิตก็ได้ ไฟล์นี้คือเส้นของผู้ที่ออกเดินทางและเส้นของผู้ที่ได้เจอคนต่างเผ่า **คำถามหลัก: ไปแล้วเป็นใคร** เมื่อไปไกลจากที่ที่ใครก็รู้จักตน เผ่าและชนชั้นที่ติดตัวจะเป็นประตูหรือกำแพง
