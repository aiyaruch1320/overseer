# เส้นเรื่อง: พระหัตถ์ในชีวิต (mr dp)

โครงสร้าง: [README.md](README.md) · ระบบพระเจ้า: [../../systems/god/README.md](../../systems/god/README.md) · ปาฏิหาริย์และซาก: [../../systems/god/04-miracles.md](../../systems/god/04-miracles.md) · ความฝัน: [../../systems/god/03-dreams.md](../../systems/god/03-dreams.md)

## 1. ธีม

สิ่งที่พระเจ้าทำต้องกลายเป็นเรื่องของผู้คน ไม่ใช่ตัวเลขบนแผนที่ เส้นนี้มีสองส่วน **mr** คือชีวิตที่สัมผัสผลของปาฏิหาริย์ (ซาก ผู้ลี้ภัย ลัทธิ ที่ดินใหม่) และ **dp** คือชีวิตที่สัมผัสพระเจ้าโดยตรง (ความฝัน คำอธิษฐานที่ถูกตอบหรือถูกเมิน การถูกลงโทษ) **คำถามหลัก: เมื่อรู้ว่ามีผู้เฝ้ามอง จะใช้ชีวิตต่างไปไหม**

## 2. วิธีใช้

| ข้อ | กติกา |
| --- | --- |
| 1 | เป็นเส้นซ้อนทับ ไม่แทนโหนดของเผ่า เหมือน [26-hearth.md](26-hearth.md) |
| 2 | โหนด mr เปิดเมื่อเหตุการณ์ RU หรือปาฏิหาริย์ MR เกิดในประเทศของตัวละครหรือประเทศข้างเคียง ถ้าเหตุการณ์ไม่เกิด โหนดข้าม |
| 3 | โหนด dp เปิดจากประวัติของพระเจ้ากับตัวละคร (ความฝันที่ทำตาม คำอธิษฐาน คำสาป) ตัวละครที่พระเจ้าไม่เคยแทรกแซงไม่มีโหนด dp |
| 4 | ชีวิตหนึ่งเดินโหนด mr ได้ไม่เกินสามโหนด และ dp ไม่เกินสามโหนด |
| 5 | เป็นโหนดส่วนตัว (P) ไม่ซ้ำกับรุ่นก่อน ([../heirs/02-no-repeat.md](../heirs/02-no-repeat.md) หัวข้อ 3) ยกเว้น `dp.e1` |
| 6 | โหนด dp เล่นเมื่อประวัติของพระเจ้ากับตัวละครคนนี้ครบ: ธง `god_dream_obeyed` คือความฝันที่ทำตามครั้งแรก · `god_dreams_3` ครบสามครั้ง · `god_prayers_ignored_3` คำอธิษฐานถูกเมินสามครั้งติด (หายไปเมื่อพระเจ้าตอบใบหนึ่ง) · โหนดที่ยังไม่ครบรอจนพ้นช่วงอายุของมันแล้วข้าม ไม่ใช่ข้ามทันทีที่ถึงอายุ |
