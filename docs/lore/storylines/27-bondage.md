# เส้นเรื่อง: การผูกตัว (bd bo ab)

โครงสร้าง: [README.md](README.md) · กติกาและท่าทีของประเทศ: [../../systems/economy/10-bondage.md](../../systems/economy/10-bondage.md) · เศรษฐกิจและหนี้: [24-economy.md](24-economy.md) · การเดินทาง: [25-journeys.md](25-journeys.md) · เหตุการณ์ท้องถิ่น: [../../systems/events/local-events.md](../../systems/events/local-events.md)

แรงบันดาลใจ: เรื่องของคนที่ถูกขายเพราะหนี้ของครอบครัว ผู้บัญชีที่รู้ทุกสัญญาแต่ไม่มีสัญญาของตัวเอง ผู้ที่ไถ่ตัวแล้วเปิดโรงเรียนให้คนอื่น ไม่ใช่เรื่องหลักของโลก ไม่เปลี่ยนเหตุการณ์โลก เป็นเรื่องระดับประเทศ NPC และตัวละครหลักที่มีโอกาสเกิดขึ้น

## 1. ธีม

บางคนเกิดมาเป็นของคนอื่น บางคนถูกทิ้งแล้วถูกเก็บ บางคนซื้อผู้อื่นแล้วต้องอยู่กับผลของมัน บางคนช่วยแล้วไม่ได้อะไรกลับมา **คำถามหลัก: ใครเป็นของใคร และอิสระมีราคาเท่าไร** ผู้ถูกผูกตัวทุกคนมีชื่อและเส้นเรื่องของตัวเอง ผู้ครอบครองไม่ได้รางวัลจากการครอบครอง การปล่อยหรือไถ่ให้ผลดีกว่า

## 2. วิธีใช้

| ข้อ | กติกา |
| --- | --- |
| 1 | เป็นเส้นซ้อนทับ (overlay) ไม่แทนโหนดของเผ่า ตัวละครเดินเส้นเผ่าหลักแล้วเสริมเส้นนี้ตามเงื่อนไข |
| 2 | **bd** เปิดเมื่อตัวละครเป็นผู้ถูกผูกตัว ตามทางในหัวข้อ 5 ของ [../../systems/economy/10-bondage.md](../../systems/economy/10-bondage.md) (เกิดในพันธะ ถูกทิ้ง ถูกขาย เป็นหนี้ ถูกจับ ถูกศาลสั่ง ขายตัวเอง) |
| 3 | **bo** เปิดเมื่อตัวละครมีทุนพอและอยู่ในประเทศท่าที D L M ([../../systems/economy/10-bondage.md](../../systems/economy/10-bondage.md) หัวข้อ 3) ประเทศท่าที A และ H ไม่เปิด |
| 4 | **ab** เปิดได้ทุกประเทศ เมื่อตัวละครพบผู้ถูกผูกตัวที่ขอความช่วย (ตัวละครที่มีนิสัย `kind` `brave` น้ำหนักทางช่วย ×1.5) |
| 5 | NPC ที่ปรากฏเป็นผู้ถูกผูกตัว (ฟีร่า MH09-7 ไคโร NR05-7 ราฟี SH01-7 โรวัน MK16-7) ถูกใช้ในโหนด bo และ ab เป็นเป้าหมายของการซื้อ การไถ่ และการช่วย ผลคือบุญคุณและเส้นเรื่องร่วมของเขา |
| 6 | ผู้ที่ได้รับการไถ่ ปล่อย หรือช่วยหนี เป็นผู้สมัครพวกพ้อง ระบบพวกพ้องออกแบบต่อจากเรื่องนี้ |
| 7 | การแทรกแซงของพระเจ้ารอระบบพระเจ้า |
