# การใช้ LLM เป็นระบบเสริม

ระบบเส้นเรื่อง: [README.md](README.md) · โค้ด: `src/llm/narrator.ts`

## 1. สิ่งที่มีในโค้ดแล้ว

- เซิร์ฟเวอร์เก็บ prompt และกุญแจ API เบราว์เซอร์ส่งแค่ชื่องานและข้อมูลสั้น ๆ
- บทบาท (role) 5 แบบ: `fate` ชะตา · `dream` ความฝัน · `epitaph` คำจารึก · `flavor` เรื่องเล็ก · `setup` ตั้งตัวละคร มีเพดานจำนวนต่อชีวิต
- ผลที่ LLM เลือกได้มีแค่ในรายการอนุญาต (`LLM_FX`) เช่น `pow+1` `gold+15` `hurt` LLM เขียนผลเองไม่ได้
- คำตอบเก็บ cache ไว้ และเกมไม่รอ LLM (ข้อความแม่แบบขึ้นก่อน)

## 2. หลักการที่ใช้ต่อ

1. **LLM เขียนคำ ไม่ตัดสินผล** การทอย สุ่ม และกติกาตัดสินผลทั้งหมด LLM แค่บรรยาย
2. **ผูกกับรหัสในเอกสาร** prompt ส่งรหัส (เผ่า เหตุการณ์ NPC ศัตรู) และข้อมูลสั้นจากเอกสาร LLM ห้ามสร้างชื่อเหตุการณ์หรือ NPC ใหม่ที่ไม่มีในข้อมูล
3. **คุมต้นทุน** ใช้ prompt ส่วนต้นที่ตายตัว (สรุปโลกสั้น ๆ) เพื่อให้ cache ของผู้ให้บริการใช้ได้ และเพดานต่อชีวิต
4. **มีแม่แบบสำรองเสมอ** ถ้า LLM ปิดหรือเกินเพดาน เกมใช้ข้อความแม่แบบ

## 3. ไอเดียบทบาทใหม่

| บทบาท | ทำอะไร | ข้อมูลที่ส่ง | ผลที่อนุญาต | เพดานต่อชีวิต (เสนอ) |
| --- | --- | --- | --- | --- |
| `battle` บรรยายศึก | บรรยายการต่อสู้หลายจังหวะเป็นฉากสั้น เน้นเหตุผล (แสงชนะผี) | ชื่อศัตรู ชนิด จุดอ่อนที่ใช้ ผลแต่ละจังหวะ | ไม่มี (ผลตัดสินแล้ว) | 6 เฉพาะศึกระดับหัวหน้าขึ้นไป |
| `npc_voice` เสียง NPC | บทพูดหนึ่งถึงสองประโยคของ NPC ที่มีชื่อ เมื่อตัวละครพบหรือโต้ตอบ | แถวของ NPC (ยูนีค เป้าหมาย เส้นที่กำลังเดิน) ความสัมพันธ์กับตัวละคร | ไม่มี | 8 |
| `omen` คำใบ้จากพระเจ้า | แปลงคำใบ้ที่ผู้เล่นเลือก (หัวข้อ 4) เป็นลางในโลก | คำใบ้ ถิ่น ศาสนาของตัวละคร | ไม่มี (คำใบ้มีผลตามกติกา) | 6 |
| `rumor` ข่าวลือ | ข่าวลือในโรงเตี๊ยมจากเหตุการณ์โลกที่เกิดในทวีปอื่น | รหัสเหตุการณ์ สรุปสั้น | ไม่มี | 6 |
| `homeland_letter` จดหมายจากบ้านเก่า | สำหรับตัวละครที่เกิดนอกถิ่น ([../../systems/character/01-origin.md](../../systems/character/01-origin.md) หัวข้อ 5) | ถิ่นหลักของเผ่า เหตุการณ์ที่เกิดที่นั่น NPC ครอบครัว | `none` `faith` `doubt` | 3 |
| `prayer` คำอธิษฐาน | เขียนคำอธิษฐานของตัวละครให้ผู้เล่นอ่านก่อนตัดสินใจตอบ | สถานการณ์ ศาสนา นิสัย | ไม่มี | 6 |
| `naming` ตั้งชื่อ | ชื่อและประวัติสั้นของอาวุธ สัตว์คู่หู ฉายา | ชนิด ความหายาก เหตุการณ์ที่ได้ | ไม่มี | 6 |
| `legend` ตำนาน | สรุปชีวิตทั้งชีวิตเป็นตำนานแบบที่คนในเผ่าเล่าต่อ (ต่างจาก epitaph ที่สั้น) | ลำดับโหนดเส้นเรื่องที่ผ่าน ศึกใหญ่ ปลายทาง | ไม่มี | 1 |
| `side_event` เหตุการณ์เสริม | เหตุการณ์เล็กที่ไม่มีในคลัง เมื่อตัวละครอยู่ในสถานการณ์ที่คลังไม่ครอบคลุม | ช่วงชีวิต ถิ่น แท็กของตัวละคร | รายการ `LLM_FX` เดิมหนึ่งค่า | 4 |

## 4. คำใบ้ของพระเจ้า (MVP)

การแทรกแซงแบบคำใบ้ไม่ใช้พรหรือคำสาป แต่เปลี่ยนน้ำหนักการตัดสินใจของตัวละคร ใช้ระบบความฝันเดิมเป็นฐาน

| คำใบ้ | ผลตามกติกา | LLM ทำอะไร |
| --- | --- | --- |
| ระวัง | ทางเลือกปลอดภัย ×2 ครั้งถัดไป และทอยรับรู้ในศึก +2 | เขียนลาง เช่น นกบินผิดทาง |
| กล้าเถิด | ทางเลือกเสี่ยง ×2 ครั้งถัดไป | เขียนลางแห่งความกล้า |
| จงไป (ชี้ทิศ) | เพิ่มน้ำหนักการเดินทางไปทวีปที่ชี้ | เขียนความฝันถึงสถานที่ |
| จงอยู่ | ลดน้ำหนักการย้ายถิ่น | เขียนความผูกพันกับบ้าน |
| จุดอ่อนของศัตรู | ตัวละครรู้จุดอ่อนในศึกถัดไป (ท่าทีที่ตรงจุดอ่อน ×3) | เขียนนิมิตของศัตรู |
| คนนั้นโกหก (ชี้ NPC) | ไว้ใจต่อ NPC นั้น −2 | เขียนความรู้สึกไม่ไว้ใจ |

## 5. ใช้ LLM ตอนพัฒนา (ไม่ใช่ในเกม)

| งาน | วิธี |
| --- | --- |
| ตรวจความสอดคล้อง | ส่งไฟล์เส้นเรื่องเผ่าพร้อมเหตุการณ์โลกและ NPC ที่เกี่ยวข้อง ให้ LLM หาจุดที่ขัด แล้วคนตรวจซ้ำ |
| ขยายคลังเหตุการณ์ | ให้ LLM ร่าง storylet ใหม่ตามแม่แบบในโค้ด (`Storylet`) แล้วผ่านสคริปต์ตรวจรหัส |
| แปลงเอกสารเป็นข้อมูล | ให้ LLM ช่วยแปลงตารางในเอกสารเป็นข้อมูลในโค้ด แล้วตรวจด้วยสคริปต์ |

## 6. ความเสี่ยง

| ความเสี่ยง | ทางป้องกัน |
| --- | --- |
| LLM สร้างข้อเท็จจริงที่ขัดกับโลก | ส่งเฉพาะข้อมูลที่จำเป็น และห้ามสร้างชื่อใหม่ ตรวจคำตอบว่าไม่มีรหัสหรือชื่อที่ไม่อยู่ในข้อมูลที่ส่ง |
| ค่าใช้จ่ายสูง | เพดานต่อชีวิต cache และใช้เฉพาะเหตุการณ์ที่สำคัญ |
| เกมรอนาน | แม่แบบขึ้นก่อนเสมอ LLM แทนที่เมื่อได้คำตอบ |
| เนื้อหาไม่เหมาะสม | กรองฝั่งเซิร์ฟเวอร์ และใช้ข้อความแม่แบบแทนเมื่อถูกกรอง |
