# เส้นเรื่อง: เผ่าสัตว์ (be)

โครงสร้าง: [README.md](README.md) · เผ่า: [../races/07-beast.md](../races/07-beast.md) · จุดบรรจบ: [00-convergence.md](00-convergence.md) · ศัตรู: [../../systems/combat/03-enemies.md](../../systems/combat/03-enemies.md)

แรงบันดาลใจ: สังคมสัตว์กินพืชและสัตว์กินเนื้อที่ต้องอยู่ร่วมกันในมังงะยุคใหม่ · เด็กที่โตในป่ากับฝูงหมาป่าในวรรณกรรมคลาสสิก · การอพยพของชนเร่ร่อนที่เสียผืนดินในประวัติศาสตร์จริง

## 1. ธีม

เผ่าสัตว์มีสัญชาตญาณแรงกว่าเผ่าอื่น สิทธิ์การล่าเป็นเรื่องศักดิ์ศรี แต่กฎลำต้นของเอลฟ์ห้ามล่าในเขตต้นไม้ ป่าที่ถูกตัดผลักเผ่าสัตว์ออกไปทีละฝูง **คำถามหลัก: จะล่าตามสิทธิ์เดิม หรือยอมเปลี่ยนเพื่อให้ฝูงอยู่รอด**
