# เส้นเรื่อง: ยุคปลาย (le)

โครงสร้าง: [README.md](README.md) · เหตุการณ์และช่วงย่อย: [../../systems/events/branches/04-last-era.md](../../systems/events/branches/04-last-era.md) · จุดบรรจบ: [00-convergence.md](00-convergence.md) · พวกพ้อง: [28-allies.md](28-allies.md) · เวลาของโลก: [../world/world-time.md](../world/world-time.md)

แรงบันดาลใจ: ช่วงเวลาก่อนเหตุการณ์ใหญ่ในเรื่องที่ผู้คนยังใช้ชีวิตประจำวันไปพร้อมกับความกลัวที่คนทั้งเมืองรู้ร่วมกัน เช่น วันสุดท้ายของเมืองที่ประกาศอพยพ จดหมายลาในสมรภูมิ และการสะสางหนี้ก่อนออกเรือ

## 1. ธีม

ยุคปลายยาวหลายร้อยปีในโลกที่ไม่จบ (แต่ละช่วงย่อยราว 130 ปี) ทุกคนที่ผ่านมันต้องตอบคำถามเดียวกันในแบบของตัวเอง **คำถามหลัก: เมื่อรู้ว่าเวลาเหลือน้อย จะอยู่กับใคร และสะสางอะไรก่อน**

## 2. วิธีใช้

| ข้อ | กติกา |
| --- | --- |
| 1 | เป็นเส้นซ้อนทับ (overlay) ไม่แทนโหนดของเผ่า ตัวละครเดินเส้นเผ่าหลักแล้วเสริมเส้นนี้ตามเงื่อนไข |
| 2 | เปิดให้ตัวละครทุกเผ่าทุกช่วงอายุที่ชีวิตซ้อนกับยุค 4 (DFC 10–14) ไม่ต้องรอช่วงผู้ใหญ่ |
| 3 | โหนดเรียงตามช่วงย่อย 4ก 4ข 4ค ของ [04-last-era.md](../../systems/events/branches/04-last-era.md) ตัวละครผ่านเฉพาะโหนดของช่วงที่ตนมีชีวิตอยู่ |
| 4 | le.e1 เปิดเฉพาะเมื่อตัวละครอยู่ช่วงผู้เฒ่าตอนเกิด LE-07 |
| 5 | NPC ที่ตัวละครผูกด้วยระดับ 3 ขึ้นไปในระบบพวกพ้อง ([../../systems/bonds/README.md](../../systems/bonds/README.md)) ปรากฏในโหนด le.a6 (และ le.a9 เมื่อเกิด) ตามชะตาที่ทอยไว้ |
| 6 | การแทรกแซงของพระเจ้ารอระบบพระเจ้า |

## 4. ตรวจความสอดคล้อง

- le.a4 ถึง le.a6 ใช้ได้เมื่อเกิด LE-05 LE-06 LE-08 ตามลำดับ ถ้าไม่เกิดในโลกนั้น ข้ามโหนด ช่วงนั้นว่างได้
- le.a8 และ le.a9 เกิดเฉพาะเมื่อฉากจบเริ่มนับถอยหลัง (LE-10 LE-12) ราว 8% ของโลก จึงเป็นโหนดหายาก ส่วน le.a1 ถึง le.a7 เกิดในโลกยุค 4 ทั่วไป
- โหนดนี้ไม่ใช่จุดบรรจบ ตัวละครไม่พบต่างเผ่าตามกติกาของ cv
