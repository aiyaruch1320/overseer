## เส้นแบ่งความขัดแย้งทางศาสนา

| คู่ | ที่มา |
| --- | --- |
| แสง × ลัทธิปีศาจ | ศาลศาสนาล่าผู้ทำสัญญา สงครามศักดิ์สิทธิ์ |
| แสง × ผู้ไร้ศาสนา (รอสกราด) | การห้ามนับถือ และการล่าผู้นอกรีต |
| แสง × เทนเซอริส | ผู้กล้าที่แปรพักตร์ |
| มังกร × ผู้ไม่ก้มหัว | การสังเวย |
| มังกร × ผู้ปลดผนึก | ผนึกหรือกรง |
| จันทรา × ฝ่ายสุริยาในลัทธิมังกร | ศึกของสองหัวของราหู |
| ผู้บูชาเตา × ผู้ถ่ายทอด | ส่งศรัทธาผ่านมังกรหรือไม่ |
| ผู้ท่องบท × ผู้ถอดบท | ภาษาปฐมในลัทธิเฟือง |
| ผู้สงบรอ × ลัทธิคำพิพากษา | ความหมายของเสียงในหมอก |
| ศรัทธาศิลา × ลัทธิมังกร | ยักษ์ค้ำเกาะ ปีกลืมยักษ์ |
| ต้นไม้โลก (อนุรักษ์) × วิญญาณสัตว์ | กฎลำต้น |
