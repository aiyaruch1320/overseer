## อารมณ์ของมังกร

มังกรแต่ละตัวมีอารมณ์ 0 ถึง 100

| ช่วง | สถานะ | ผล |
| --- | --- | --- |
| 70–100 | มั่นคง | ผนึกแน่น ไม่มีภัยจากมังกร ยอมฟังคำขอ |
| 30–69 | ปกติ | ภัยตามธาตุเกิดได้เล็กน้อย |
| 10–29 | ไม่มั่นคง | ภัยตามธาตุเกิดบ่อย เหตุการณ์ PL เปิด |
| 0–9 | เสี่ยงล้ม | เหตุการณ์ล้ม (DR, END) เปิด |

**ที่มาของอารมณ์** ศรัทธาช่อง A ของเขตที่มังกรดูแล, บรรณาการที่ตรงกับสิ่งที่มังกรต้องการจริง, ความเจ็บปวดจากการถูกรบกวน (ขุด เจาะ ผูกมัด), ความเหงา และความเศร้าจากพี่น้อง (ดู "พี่น้องสิบห้า")

## ที่คนเชื่อ กับที่ต้องการจริง

มังกรทุกตัวขอน้อยกว่าที่ผู้คนคิด ธรรมเนียมสังเวยทอง อาวุธ และผู้อาวุโสส่วนใหญ่เป็นสิ่งที่นักบวชสร้างขึ้นภายหลัง ไม่มีมังกรตัวใดขอชีวิตคน โอรัน-ซัลและอีริดานรู้ว่าธรรมเนียมนี้เริ่มจากนักบวชโอรันธาร์และไม่เคยบอกใคร

บรรณาการที่ตรงกับสิ่งที่มังกรต้องการจริงเพิ่มอารมณ์มากกว่าบรรณาการที่คนเชื่อว่ามันต้องการหลายเท่า

## พี่น้องสิบห้า

มังกรทั้งสิบห้าเกิดจากแสงแรกของพระเจ้าชิ้นเดียวกัน พวกมันรักกันมาก ไม่ใช่เพียงเพราะเป็นพี่น้อง แต่เพราะมีกันอยู่เพียงสิบห้าในโลกที่ไม่มีมังกรตำนานตัวอื่นอีก

**เสียงพี่น้อง** มังกรทุกตัวเชื่อมกันด้วยเสียงที่มนุษย์ไม่ได้ยิน รู้สึกถึงความสุขและความเจ็บของกันและกันได้ทั้งโลก โอรัน-ซัลกล่อมน้องทุกคืนด้วยเสียงนี้ ผู้ที่ได้ยินเสียงมังกรในความฝัน (พร "เสียงมังกร" ของเผ่ามังกร) ได้ยินเพียงเศษของเสียงนี้

**ลำดับพี่น้อง** ตามขนาดของแสงที่เกิดมา: โอรัน-ซัลเป็นพี่ใหญ่ ผู้อาวุโสทั้งห้าเป็นพี่กลาง เสาทั้งเก้าเป็นน้อง ผู้อาวุโสดูแลเสาเหมือนพี่ดูแลน้อง
