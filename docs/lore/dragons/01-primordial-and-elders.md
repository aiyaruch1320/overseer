# มังกรปฐมและห้าผู้อาวุโส

หกตัวที่อาศัยบนเกาะลอยฟ้าของอัซการ์ เสาทั้งเก้าอยู่ที่ [02-pillars.md](02-pillars.md)

ทุกตัวเกิดจากแสงแรกของพระเจ้า ตัวที่เกิดจากชิ้นใหญ่ที่สุดคือมังกรปฐม ชิ้นรองลงมาคือผู้อาวุโส ความทรงจำที่แต่ละตัวมีเกี่ยวกับพระเจ้าไม่เหมือนกัน พระเจ้าจำสิ่งเหล่านี้ไม่ได้

---

## 1. โอรัน-ซัล — มังกรปฐม ผู้ถือฟ้า

- **รูปลักษณ์** เกล็ดสีมุกเก่า ปีกกว้างเท่านครหนึ่ง ลืมตาน้อยครั้งในหนึ่งปี
- **บุคลิก** เฒ่า ใจเย็น เหนื่อยล้าที่สุดในมังกรทั้งหมด รู้ความจริงทุกชั้น พูดน้อยจนนักบวชตีความความเงียบตามใจ
- **ความทรงจำกับพระเจ้า** เป็นลูกคนแรก จำคำแรกที่พระเจ้าพูดได้เพียงตัวเดียว: "ต้องมี" พระเจ้าขอให้ยกฟ้า "จนกว่าข้าจะจำได้ว่าทำไม" และไม่เคยกลับมาบอก
- **ที่อยู่** รังฟ้า ใจกลางโอรันธาร์ (AZ-01)
- **ศาสนาที่ส่งศรัทธา** ลัทธิบูชามังกร (โดยเฉพาะนิกายสังเวยนิยม)
- **ที่คนเชื่อว่าต้องการ** ทอง อาวุธ และผู้อาสาสังเวย
- **ที่ต้องการจริง** คำสาบานดูแลกัน เกาะที่สาบานว่าจะไม่ทิ้งคนล่างแล้วทำตามจริง เขาไม่เคยขอชีวิตคน นักบวชรุ่นแรกเป็นผู้เริ่มธรรมเนียมสังเวยคน
- **ความฝัน** ทุ่งเมฆที่ไม่มีแผ่นดินให้ต้องค้ำ
- **ความกลัว** เกาะตกทับยักษ์ที่เคยยืนค้ำปลายเกาะเมื่อมหาล่มสลาย เขารู้สึกผิดต่อพวกเขาตลอดมา
- **พี่น้อง** พี่ใหญ่ของทุกตัว กล่อมน้องทุกคืนผ่านเสียงพี่น้อง สนิทสุดกับฮรอด-กาธ ผู้ที่เขาไม่เคยตำหนิเรื่องกินมังกร ทุกครั้งที่น้องตัวหนึ่งตาย หัวใจเขาช้าลงและเกาะลอยฟ้าต่ำลงหนึ่งขั้น
- **อารมณ์ขึ้น** เด็กเกิดใหม่บนเกาะ ยักษ์ให้อภัย คำสาบานของเกาะที่ทำจริง
- **อารมณ์ลง** เกาะร่วง ศรัทธาลด เรือเหาะรุกล้ำ การล่ามังกร การเสียชีวิตของผู้อาสาสังเวย
- **ทางล้ม** (เรียงตามโอกาส) สิ้นแรง → DR-01 · หลับลึก → DR-02 · สละชีวิต (เมื่อเกาะร่วงจริง) · ถูกฆ่า (ต้องใช้อาวุธตำนานผูกมังกร)
- **ทางรอด** ไข่ใบที่สิบหก (DR-03) ที่ฟักเป็นทายาทฟ้า และเกาะใหม่ (HP-08)
- **ความลับ** กุญแจเกล็ดฟ้าแรกคือเกล็ดบนอกของเขา จังหวะหัวใจของเขาคือสิ่งที่ทำให้ศิลาลอยทั้งทวีปลอยอยู่ได้

## 2. เพลิงนิรันดร์ — ผู้อาวุโสเพลิง

- **รูปลักษณ์** เกล็ดแดงเข้มเหมือนถ่านร้อน ปีกมีเส้นทองไหลเหมือนเหล็กหลอม
- **บุคลิก** ฉุนเฉียว ซื่อตรง เกลียดคำโกหก พูดตรงจนบางครั้งทำร้ายใจ
- **ความทรงจำกับพระเจ้า** จำได้ว่าพระเจ้าอุ่นมือ ตอนที่เขายังตัวเล็ก
- **ที่อยู่** ปล่องภูเขาไฟบนซากโรการ์ (AZ-02)
- **ศาสนาที่ส่งศรัทธา** ลัทธิบูชามังกร (ธาตุนิยม) ส่วนศรัทธาเตาหลอมไม่ส่งถึงเขา
- **ที่คนเชื่อว่าต้องการ** เลือดจากดวลหรือสงคราม
- **ที่ต้องการจริง** เปลวไฟที่ถูกใช้อย่างซื่อตรง ดวลที่ผู้ชนะไม่ฆ่า ช่างที่ตีเหล็กด้วยใจ
- **ความฝัน** เตาไฟอุ่นในทุกบ้าน
- **ความกลัว** เย็นลงจนถูกลืม
- **บาดแผลเก่า** เขากับสมุทรอาลัยเคยทำงานด้วยกัน ให้ไอน้ำที่ทำให้โลกอบอุ่น วันหนึ่งน้ำตาของสมุทรอาลัยดับไฟในงานเทศกาลที่เขาตั้งใจจัด เขายังเจ็บและคิดถึง แต่ไม่รู้จะเอ่ยคำขอโทษอย่างไร
- **พี่น้อง** สนิทสุดกับสมุทรอาลัย ทะเลาะกันมาพันปีแต่ไม่เคยเลิกรัก ถ้าสมุทรอาลัยตาย ไฟของเขาลุกโชนด้วยความเสียใจจนอาจเผาตัวเอง
- **อารมณ์ขึ้น** ดวลเกียรติ งานตีอาวุธตำนานที่ทำด้วยใจ (KD-01) พิธีตะวันหลอมเหล็ก
- **อารมณ์ลง** การใช้ไฟฆ่าคนไร้ทางสู้ คำโกหกในพิธี ศาสนาเตาหลอมแย่งศรัทธาโดยไม่ส่งผ่านเขา
- **ทางล้ม** สิ้นแรง (ต้นทางของ DR-04) · ถูกฆ่าด้วยอาวุธน้ำแข็งหรือน้ำ · สงครามธาตุกับสมุทรอาลัย (DR-09)
- **ทางรอด** ศรัทธาเตาหลอมถูกส่งผ่านเขา (ผู้ถ่ายทอดของธรอกาด KD-07) และการคืนดีกับสมุทรอาลัย
- **ความลับ** เขาเป็นผู้ที่ให้กำเนิดเผ่าลาวา จากไฟที่เขาปล่อยลงดินโดยไม่ได้ตั้งใจ

## 3. สมุทรอาลัย — ผู้อาวุโสสมุทร

- **รูปลักษณ์** เกล็ดสีฟ้าเหมือนคลื่นตอนเย็น ดวงตาเปียกเสมอ
- **บุคลิก** เศร้า อ่อนโยน ร้องไห้ง่าย จำได้ทุกอย่างที่ไหลผ่านน้ำ
- **ความทรงจำกับพระเจ้า** พระเจ้าไม่เคยบอกชื่อ ซึ่งเธอเสียใจมาตลอด
- **ที่อยู่** ทะเลลอยฟ้าบนดราซาวาส (AZ-06) เมื่อเศร้าหนักจะลงไปพักที่ร่องลึกตะวันตกของเนเรีย (ไอทอล NR-04)
- **ศาสนาที่ส่งศรัทธา** เทพแห่งสมุทร พญานาคราช
- **ที่คนเชื่อว่าต้องการ** ไข่มุกและเรือสมบัติ
- **ที่ต้องการจริง** ชื่อของผู้ที่ตายในทะเล เขาจำทุกชื่อที่ไหลมาในน้ำ ต้องการให้มีคนอ่านชื่อเหล่านั้นออกเสียง
- **ความฝัน** ชายหาดที่ไม่มีใครต้องจากไป
- **ความกลัว** ชื่อที่ไม่มีใครเรียก หายไปในน้ำ
- **พี่น้อง** สนิทสุดกับเพลิงนิรันดร์ ถ้าเพลิงนิรันดร์ตาย เธอร้องไห้ไม่หยุดจนน้ำท่วมทุกทวีป
- **อารมณ์ขึ้น** เพลงไว้อาลัยจากไซเรน การอ่านชื่อผู้ตาย พิธีไข่มุกของคนรัก
- **อารมณ์ลง** ปะการังตาย (BIO-07) สงครามทะเล (WR-07) ของเสียทิ้งลงน้ำ การลืม
- **ทางล้ม** สิ้นแรงจากความเศร้า (ต้นทางของ DR-05) · สงครามธาตุกับเพลิงนิรันดร์ (DR-09)
- **ทางรอด** ไซเรนที่ร้องชื่อผู้ตายครบ หนึ่งในหน้าที่ของทาลานีสท่าเรือ (NR-01) คือบันทึกชื่อลูกเรือที่ไม่กลับ
- **ความลับ** น้ำตาของเธอคือที่มาของไข่มุกน้ำตา กุญแจของทวีปน้ำ

## 4. พายุไร้ทิศ — ผู้อาวุโสพายุ

- **รูปลักษณ์** ร่างเรียวคล้ายงู ปีกโปร่งเหมือนพายุฝน เกล็ดเปลี่ยนสีตามอารมณ์
- **บุคลิก** ขี่เล่น ไม่รับผิดชอบ หนีหน้าที่บ่อยที่สุด ชอบเล่นเกม
- **ความทรงจำกับพระเจ้า** จำได้ว่าพระเจ้าหัวเราะ เป็นเสียงเดียวที่เขาจำ
- **ที่อยู่** เกาะที่ไม่อยู่ที่เดิม วีร์กาดุส (AZ-03)
- **ศาสนาที่ส่งศรัทธา** ลัทธิบูชามังกร (ธาตุนิยม) และลางนิยมเล็กน้อย
- **ที่คนเชื่อว่าต้องการ** ทองและผู้พลีชีพ
- **ที่ต้องการจริง** การแข่งลมที่ยุติธรรม ของเล่นแปลก ๆ เรื่องเล่า และเวลาว่าง
- **ความฝัน** วันที่ไม่มีใครต้องการเขา เขาจะได้เล่นอย่างอิสระ
- **ความกลัว** ถ้าเขาจริงจังเมื่อไร ลมของโลกจะหยุดนิ่งเมื่อนั้น เขารู้เรื่องนี้ จึงหนี
- **พี่น้อง** สนิทสุดกับอีริดาน เพื่อนเล่นคนเดียวที่ไม่เคยบังคับเขา ถ้าอีริดานตาย เขาหยุดเล่น และลมของโลกหยุดตาม
- **อารมณ์ขึ้น** การแข่งลม (AZ-03, NR-15) เด็กที่เล่นว่าวใต้ฟ้า
- **อารมณ์ลง** การผูกมัดพิธีตายตัว เรือเหาะที่ทำลายกระแสลม ความพยายามจับเขา
- **ทางล้ม** ถูกจับขังหรือผูกพิธี → ลมหยุด (DR-06) · หลับลึกเมื่อเหนื่อยจากหนีหน้าที่
- **ทางรอด** ปล่อยให้เขาเล่น ไม่บังคับเขาเป็นผู้ค้ำ และมีเพื่อนเล่นอย่างอีริดาน
- **ความลับ** ที่จริงเขาไม่ได้หนีหน้าที่ การ "เล่น" ของเขาคือวิธีหมุนเวียนลมของโลก

## 5. ศิลาสะท้าน — ผู้อาวุโสศิลา

- **รูปลักษณ์** ร่างกลมเหมือนก้อนหินใหญ่ ปีกพับเป็นเกราะ ไม่ค่อยขยับ
- **บุคลิก** เงียบ ดื้อ เกลียดการถูกปลุก คิดช้ามากแต่ไม่เคยลืม
- **ความทรงจำกับพระเจ้า** พระเจ้าวางมือบนหลังเขา ตอนที่เขายังเล็ก เป็นความอบอุ่นเดียวที่เขาเก็บ
- **ที่อยู่** ธีโรวาส เกาะที่ต่ำและหนักที่สุด (AZ-04)
- **ศาสนาที่ส่งศรัทธา** ลัทธิบูชามังกร ศรัทธาศิลา
- **ที่คนเชื่อว่าต้องการ** หินก้อนใหญ่และแร่หายาก
- **ที่ต้องการจริง** ความเงียบ วันหินหลับ วันเดียวในหนึ่งปีที่ทุกคนหยุดขุด หยุดเคาะ หยุดทุบ
- **ความฝัน** นอนหลับโดยไม่มีเสียง
- **ความกลัว** ถูกขุดจนบาง
- **พี่น้อง** สนิทสุดกับกรอม-ธาร น้องที่ถูกกลืนในภูเขา เขาอยากช่วยแต่ไม่กล้าขยับ ถ้ากรอม-ธารตาย เขาตื่นขึ้นเดินเพื่อแบกแทน
- **อารมณ์ขึ้น** วันหินหลับ ผู้เฝ้าบันไดที่เคารพ
- **อารมณ์ลง** เหมืองลึก (KD-10) ค้อนทุบฟ้า (GI-03) ผู้ที่ปลุกเขาโดยไม่จำเป็น
- **ทางล้ม** ถูกขุดจนบาง (DR-07) · ถูกปลุกเมื่อ GI-02 ไททันตื่น
- **ทางรอด** วันหินหลับที่ทุกทวีปปฏิบัติ และการขุดที่หยุดที่เขตหยุด
- **ความลับ** เขาเป็นพี่ของกรอม-ธาร ที่ถูกกลืนอยู่ในภูเขาของซาฮารัน เขาไม่เคยบอกว่าอยากช่วย

## 6. ราหูแห่งสุริยคราส — ผู้อาวุโสสุริยันจันทรา

- **รูปลักษณ์** สองหัวบนร่างเดียว หัวหนึ่งสีทอง หัวหนึ่งสีเงิน
- **บุคลิก** หัวสุริยาเป็นระเบียบ ภาคภูมิ ชอบพิธี หัวจันทราเป็นความลับ อ่อนโยน เก็บความทรงจำ ทะเลาะกันตลอด แต่ไม่เคยแยกกัน
- **ความทรงจำกับพระเจ้า** หัวสุริยาจำได้ว่าพระเจ้าชื่นชมที่เขาสว่าง หัวจันทราจำได้ว่าพระเจ้านั่งข้างเขาในคืนที่ไม่มีใครเห็น
- **ที่อยู่** โคซาโมเรีย (AZ-05) ราชสำนักสองฝ่ายอยู่ในวังเดียว
- **ศาสนาที่ส่งศรัทธา** ฝ่ายสุริยา: ลัทธิบูชามังกร ฝ่ายจันทรา: เทพีแห่งจันทรา
- **ที่คนเชื่อว่าต้องการ** เครื่องบูชากลางวันและกลางคืนแยกกัน
- **ที่ต้องการจริง** พิธีที่สองหัวได้ยินกัน เช่นพิธีสุริยคราสที่ทั้งสองฝ่ายสวดร่วมกัน
- **ความฝัน** สุริยคราสสมบูรณ์ ที่สองหัวมองเห็นหน้ากันเป็นครั้งแรก
- **ความกลัว** ถูกแยกออกจากกัน
- **พี่น้อง** เป็นจังหวะของพี่น้องทั้งหมด ทุกตัวหายใจและหลับตามวัน-คืนของเขา หัวสุริยารักพี่ใหญ่ หัวจันทรารักน้องเล็ก ถ้าราหูตาย ทุกตัวสูญเสียจังหวะ และอารมณ์ของพี่น้องที่เหลือลดเพิ่มทั้งหมด
- **อารมณ์ขึ้น** พิธีสุริยคราสร่วม ศรัทธาสองฝ่ายสมดุล
- **อารมณ์ลง** ศรัทธาเทพีจันทราเกินสุริยามาก หรือกลับกัน
- **ทางล้ม** สองหัวแตกกัน (DR-08) → วันคืนปั่นป่วน · แปลงกาย (หัวหนึ่งยอมเป็นมนุษย์) · สงครามธาตุภายใน (DR-09 รูปแบบหนึ่ง)
- **ทางรอด** ราชสำนักสองฝ่ายประนีประนอม
