# ทายาทและรุ่นถัดไป

ผู้เล่นเป็นพระเจ้าที่เฝ้าดู **ตระกูล** ตัวละครแต่ละรุ่นตายไป แต่สิ่งที่ทำไว้ยังส่งต่อให้ลูกหลาน เอกสารชุดนี้กำหนดว่าใครสืบทอด ส่งต่ออะไร และ **เรื่องของรุ่นถัดไปไม่ซ้ำกับเหตุการณ์ของรุ่นก่อน** ได้อย่างไร

## 1. ศัพท์

| คำ | ความหมาย |
| --- | --- |
| ตระกูล | สายเลือดและชื่อสกุลที่ผู้เล่นเฝ้าดูข้ามรุ่น (`dynastyName` ในโค้ด) |
| รุ่น | ตัวละครหลักหนึ่งชีวิตของตระกูล (ตัวแปร generation ในโค้ด) |
| สมุดตระกูล | บันทึกสิ่งที่ทุกรุ่นทำไว้ ใช้ตัดสินว่าอะไรซ้ำไม่ได้ ([02-no-repeat.md](02-no-repeat.md)) |
| เรื่องค้าง | สิ่งที่ชีวิตหนึ่งยังทำไม่เสร็จและส่งต่อให้รุ่นถัดไป ([03-open-threads.md](03-open-threads.md)) |
| รูปสืบ | โหนดหรือจุดบรรจบรูปที่ใช้เมื่อรุ่นก่อนเดินไปแล้วหรือโลกผ่านเหตุการณ์ไปแล้ว |

## 2. ความต่างจากโค้ดปัจจุบัน

โค้ดอยู่ใน `src/sim/game.ts` (ฟังก์ชัน addChild heirs และ continueAsHeir)

| เรื่อง | โค้ดปัจจุบัน | ระบบในเอกสาร |
| --- | --- | --- |
| เผ่าของลูก | สุ่ม 50/50 ระหว่างเผ่าของตัวละครกับเผ่าคู่ครอง | ตารางลูกของลูกครึ่งและคู่ที่เป็นไปได้ ([../../systems/character/01-origin.md](../../systems/character/01-origin.md) หัวข้อ 4) |
| ที่ส่งต่อ | ค่าสถานะสูงสุด +1 · อาวุธ · ขุนนาง · `c_heircurse` · ทอง 70% · ชื่อเสียง 1 ใน 3 · ศรัทธา 60% · ความสัมพันธ์กับพ่อแม่ | เพิ่มพรสายเลือด skill ความสัมพันธ์ (บุญคุณ แค้น หนี้) ที่มั่น และเรื่องค้าง ทุกอย่างมีเพดาน |
| อาวุธผูกเจ้าของ | ส่งต่อทั้งชิ้น | ความสามารถแบบผูกเจ้าของหยุดจนกว่าทายาทถูกยอมรับ |
| เรื่องของรุ่นใหม่ | เริ่มเส้นเรื่องของเผ่าตามอายุเหมือนตัวละครใหม่ จุดบรรจบเข้าซ้ำได้ | ใช้สมุดตระกูลและรูปสืบ ไม่ซ้ำกับรุ่นก่อน |
| ตัวนับการแทรกแซงของพระเจ้า | ล้างทุกรุ่น | บางส่วนข้ามรุ่น พร้อมพรสายเลือดที่ข้ามรุ่นได้ |
| ไม่มีทายาท | จบ | หาผู้สืบเรื่อง หรือเริ่มสายใหม่ด้วยกรรมที่สะสม |

## 3. ลำดับการทำในโค้ด (เสนอ)

1. เก็บสมุดตระกูลใน state ของเกม (โหนด จุดบรรจบ เหตุการณ์ ปลายทาง) และส่งต่อใน `continueAsHeir`
2. ใช้ตารางลูกของลูกครึ่งแทนการสุ่ม 50/50 ใน `addChild`
3. เพิ่มการส่งต่อพร skill ความสัมพันธ์ และอาวุธผูกเจ้าของ
4. เพิ่มตรวจโหนดซ้ำก่อนเลือกโหนด และใช้รูปสืบหรือโหนด hr แทน
5. เพิ่มเรื่องค้างตอนตัวละครตาย
6. ทดสอบหลายรุ่นด้วย `npm run sim` ว่าตัวเลขไม่สะสมจนเกินคุม

ตัวเลขในเอกสารทั้งหมดเป็นค่าเริ่มต้น ต้องทดสอบด้วยการจำลองหลายรุ่นก่อนใช้จริง

อายุของทายาทและเกณฑ์ในไฟล์ชุดนี้เป็นอายุเทียบมนุษย์ (ปีชีวิต) ส่วนระยะห่างระหว่างรุ่นเป็นปีโลก ตารางต่อเผ่าอยู่ใน [../world/world-time.md](../world/world-time.md)
