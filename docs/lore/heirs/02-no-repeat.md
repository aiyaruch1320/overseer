# เรื่องของทายาทไม่ซ้ำกับรุ่นก่อน

ระบบ: [README.md](README.md) · การสืบทอด: [01-inheritance.md](01-inheritance.md) · เรื่องค้าง: [03-open-threads.md](03-open-threads.md) · โหนดทายาท: [../storylines/23-heir.md](../storylines/23-heir.md) · จุดบรรจบ: [../storylines/00-convergence.md](../storylines/00-convergence.md)

เส้นเรื่องของเผ่าเขียนไว้สำหรับชีวิตเดียว ถ้าทายาทของเผ่าเดียวกันเดินโหนดเดิมซ้ำ จะได้ฟ้าถล่มซ้ำ ไข่พญานาคราชฟักซ้ำ และเข้าสภาเก้าทวีปซ้ำแบบเดิมทุกรุ่น ซึ่งขัดกับโลกที่เดินต่อและทำให้เรื่องของตระกูลไม่มีความหมาย ไฟล์นี้กำหนดกติกาที่ทำให้แต่ละรุ่นมีเรื่องของตัวเอง

## 1. สามชั้นที่ไม่ซ้ำ

| ชั้น | ไม่ซ้ำเพราะ | อยู่ที่ไหน |
| --- | --- | --- |
| โลก | เหตุการณ์ของโลก 194 รายการเกิดครั้งเดียว (มังกรล้ม ฟ้าถล่ม หมอกกลืน ฯลฯ) ทายาทเกิดในโลกหลังเหตุการณ์นั้น | ธงเหตุการณ์ของโลก ([../../systems/events/branches/README.md](../../systems/events/branches/README.md)) |
| ตระกูล | สิ่งที่รุ่นก่อนเดินไปแล้ว (โหนด จุดบรรจบ ปลายทาง) ถูกจดไว้ ทายาทได้รูปสืบแทน | สมุดตระกูล (หัวข้อ 2) |
| บุคคล | พิธีและชีวิตส่วนตัว (วัยเด็ก พิธีของเผ่า รักแรก งานแรก) ทุกคนต้องผ่าน แต่ทางเลือกที่รุ่นก่อนเลือกถูกคนในถิ่นจำและกดน้ำหนัก | ตัวคูณในหัวข้อ 4 |

## 2. สมุดตระกูล

สมุดตระกูลเพิ่มรายการทุกครั้งที่ตัวละครของตระกูลผ่านสิ่งที่ระบุ และส่งต่อไปยังทายาททุกรุ่น

| รายการ | จดอะไร | ใช้ทำอะไร |
| --- | --- | --- |
| โหนดที่เดินแล้ว | รหัสโหนด และทางที่เลือก (ก ข ค) | ตัดโหนดซ้ำ กดน้ำหนักทางเดิม |
| จุดบรรจบที่เข้าแล้ว | `cv.N` และทางที่เลือก | ใช้รูปสืบ (หัวข้อ 5) |
| เหตุการณ์ของโลกที่ตระกูลมีส่วน | รหัสเหตุการณ์ และผล (ตระกูลทำให้เกิด ป้องกัน หรือเป็นพยาน) | ตัดเหตุการณ์ที่เป็นผลของตระกูลเองและแสดงผลสืบ |
| ปลายทางที่ได้ | ชื่อปลายทางจากไฟล์เส้นเรื่อง | ปลายทางไม่ซ้ำ (หัวข้อ 6) |
| NPC | ไว้ใจ บุญคุณ แค้น และสถานะที่รุ่นก่อนทำให้ (ตาย ย้ายถิ่น ขึ้นตำแหน่ง) | NPC ไม่เล่นเส้นเรื่องเดิมซ้ำ (หัวข้อ 7) |
| อาชีพ | อาชีพที่ผ่านและอาชีพลับที่ได้ | ไม่เสนออาชีพลับซ้ำถ้าอาชีพนั้นล้มไปแล้ว |
| อาวุธ | ประวัติอาวุธที่ส่งต่อ | เรื่องของอาวุธต่อจากเดิม ไม่เริ่มใหม่ |
| เรื่องค้าง | ที่ยังไม่ปิด | ใช้แทนโหนดที่ซ้ำ ([03-open-threads.md](03-open-threads.md)) |

## 3. ประเภทของโหนด

โหนดในไฟล์เผ่า 279 โหนด แบ่งตามตัวโหนดเอง

| ประเภท | ความหมาย | จำนวน |
| --- | --- | --- |
| P ส่วนตัว | ไม่ผูกเหตุการณ์ของโลก (วัยเด็ก พิธี รักแรก งานแรก ปลายชีวิต) | 143 (51%) |
| W ผูกเหตุการณ์โลก | มีรหัสเหตุการณ์ในโหนด (ฟ้าถล่ม มังกรกบฏ ฯลฯ) | 52 (19%) |
| C จุดบรรจบ | โหนดที่เขียนว่า "→ cv.N" | 84 (30%) |

โหนดของลูกครึ่ง (hb และชุดเสริม) นับเป็นประเภท P ถ้าไม่มีรหัสเหตุการณ์ในโหนด และเป็น W หรือ C ตามที่เขียน

## 4. ลำดับเลือกโหนดของทายาท

ตอนทายาทถึงอายุของโหนดหนึ่ง ใช้ลำดับนี้ตามลำดับ

| ขั้น | เงื่อนไข | ผล |
| --- | --- | --- |
| 1 | โหนดไม่อยู่ในสมุด และเหตุการณ์ในโหนด (ถ้ามี) ยังไม่เกิด | ใช้โหนดตามปกติ |
| 2 | โหนดเป็น P และอยู่ในสมุด | ใช้โหนดเดิม แต่ทางที่รุ่นก่อนเลือกน้ำหนัก ×0.5 และตัวละครถูกคนในถิ่นเทียบกับรุ่นก่อน (ไว้ใจ ±1 ตามผลที่ผู้ปกครองทิ้งไว้) |
| 3 | โหนดเป็น W และเหตุการณ์เกิดแล้ว (โดยใครก็ตาม) | ใช้รูปหลังเหตุการณ์ที่เขียนไว้ในโหนด ถ้าไม่มี ใช้ผลสืบเนื่องของเหตุการณ์ (หัวข้อ 4.1) |
| 4 | โหนดเป็น C | ใช้รูปสืบของจุดบรรจบ (หัวข้อ 5) ถ้ารุ่นก่อนเข้าแล้วหรือโลกผ่านเหตุการณ์แล้ว |
| 5 | ทุกรูปข้างต้นไม่มีหรือใช้ไม่ได้ | แทนด้วยโหนดทายาท (hr) หรือเรื่องค้างตามอายุ |

### 4.1 ผลสืบเนื่องของเหตุการณ์ (ใช้เมื่อโหนด W ไม่มีรูปหลัง)

| ทาง | ผล | น้ำหนัก |
| --- | --- | --- |
| ก) ผู้รับผลโดยตรง | ผลของเหตุการณ์ยังกดตัวละคร (ผู้ลี้ภัยรุ่นสอง ลูกกำพร้าสงคราม ถิ่นที่ยังไม่ฟื้น) · ไว้ใจผู้รอด +1 | 40 |
| ข) ผู้สร้างใหม่ | ใช้ซากเหตุการณ์ตั้งสิ่งใหม่ (ชุมชน ร้าน สนธิสัญญา) · ความถนัดที่เกี่ยวหนึ่งอย่าง +1 | 35 |
| ค) ผู้เล่าเรื่อง | เก็บคำให้การของผู้รอด · ชื่อเสียง +3 · ไม่มีศึก | 25 |

ผลสืบเนื่องไม่มีศึกประจำเส้น ศึกของรุ่นสืบมาจากเรื่องค้างหรือศึกสุ่มปกติ

## 5. รูปสืบของจุดบรรจบ

จุดบรรจบเข้าได้ครั้งเดียวต่อชีวิตตามกติกาเดิม แต่ทายาทเป็นชีวิตใหม่ จึงต้องกันไม่ให้เข้าจุดเดิมซ้ำ ถ้ารุ่นก่อนเข้าแล้ว หรือเหตุการณ์ในคอลัมน์ "เปิดเมื่อ" ของ [../storylines/00-convergence.md](../storylines/00-convergence.md) จบไปแล้ว ให้ใช้รูปสืบ ถ้าจุดนั้นยังไม่ถูกเข้าและเหตุการณ์ยังไม่จบ ทายาทเข้ารูปปกติได้

## 6. ปลายทางที่ใช้แล้ว

ปลายทางที่มีชื่อในไฟล์เส้นเรื่อง (เช่น "ผู้ปิดความแค้นน้ำเก่า" "ผู้คืนชีพหิน" "ผู้ร้องเพลงฟัก") ได้ครั้งเดียวต่อตระกูล

| กรณี | กติกา |
| --- | --- |
| ทายาทเผ่าเดียวกัน | ปลายทางที่รุ่นก่อนได้ถูกตัดออกจากรายการ |
| ทายาทต่างเผ่า | ใช้ปลายทางของเผ่าตัวเองตามปกติ ตัดเฉพาะที่ตระกูลเคยได้ |
| ปลายทางหมดทั้งรายการ | ใช้ปลายทางสืบ 4 อย่างด้านล่าง |

| ปลายทางสืบ | เงื่อนไข |
| --- | --- |
| ผู้ปิดสมุดตระกูล | ปิดเรื่องค้างครบทุกข้อก่อนตาย |
| ผู้พาตระกูลข้ามยุค | ตระกูลอยู่รอดเหตุการณ์ใหญ่จากสองยุคขึ้นไป (DFC ต่างกัน) |
| ผู้ถูกเทียบกับบรรพบุรุษ | ชื่อเสียงสูงกว่ารุ่นก่อนสูงสุด |
| ผู้เริ่มสายใหม่ | ย้ายออกจากถิ่นของตระกูลและตั้งชื่อสกุลใหม่ (hr.t2 ทาง ค) |

## 7. NPC ไม่เล่นเส้นเรื่องเดิมซ้ำ

ตามกติกา "เส้นเรื่องสืบทอด" ใน [../npcs/README.md](../npcs/README.md) หัวข้อ 3

| กรณี | ผล |
| --- | --- |
| รุ่นก่อนเลือกช่วย ขัดขวาง หรือร่วมเดินทางกับ NPC | ผลของทางที่ NPC เดินไปแล้วคงอยู่ NPC ไม่เล่นเส้นเรื่องนั้นซ้ำ |
| NPC ตายหรือขึ้นตำแหน่งใหม่ | ใช้ผู้สืบทอดที่ไฟล์ NPC เขียนไว้ (เช่น NB08-1 เนวันตาย ผู้เฝ้าคือ NB08-3 โอเว่น) |
| NPC ติดบุญคุณหรือแค้นตระกูล | ส่งต่อ 100% แต่การตอบแทนใช้ผู้สืบหรือญาติของ NPC ตามกติกาเดิม ถ้า NPC ตายก่อน ผู้สืบตอบแทนด้วยโอกาสครึ่งหนึ่งของที่เขียนไว้ในแถว |
| NPC ที่เป็นผู้นำประเทศ | ยังอยู่ตามวงจรชีวิต ถ้ายังมีชีวิต ทายาทเจอ NPC แก่ลงตามเวลา ไม่ใช่ NPC ที่ล้างเรื่องใหม่ |

## 8. ตัวอย่าง

### 8.1 ตระกูลนาคา

รุ่นที่ 1 (นาคา) เลือก cv.7 ทาง ข พาทูตเงือกมาดูการฟัก ไข่ฟัก WR-20 ไม่เกิดในยุคนี้ สมุดตระกูลจด cv.7 ทาง ข และปลายทาง "ผู้ปิดความแค้นน้ำเก่า"

รุ่นที่ 2 (นาคา อายุ 30) เดินถึง na.a3 ซึ่งเป็น "→ cv.7" และ BIO-08 ฟักแล้ว ใช้รูปสืบ "ราชานาคาองค์ใหม่" ตัวเลือก ค) รักษาข้อตกลงกับเงือก na.a4 (สงครามน้ำเก่า) ถูกข้ามตามกติกาเดิมของไฟล์นาคา (cv.7 จบทาง ข) แทนด้วยเรื่องค้างข้อแรกของรุ่นก่อน (hr.a1) ปลายทาง "ผู้ปิดความแค้นน้ำเก่า" ถูกตัด ผู้เล่นได้ "ผู้ปิดสมุดตระกูล" ถ้าปิดเรื่องค้างครบ

### 8.2 ตระกูลมนุษย์

รุ่นที่ 1 เข้า cv.2 ทาง ค รับจ้างลอบสังหารสำเร็จ PO-08 เกิด WR-14 ตามมา ได้ `c_wanted` สมุดตระกูลจด cv.2 ทาง ค และ PO-08 เป็นผลของตระกูล

รุ่นที่ 2 (มนุษย์) เกิดในสงคราม hu.a4 เป็น "→ cv.3" แต่ WR-14 เกิดแล้ว จึงใช้ "หลังสงครามเก้าทวีป" ทาง ข) ตามหาผู้บัญชาการ ได้ `nc_blood_feud` จากแค้นที่รุ่นก่อนทิ้งไว้ (`c_wanted` ส่งต่อเป็นเรื่องค้างชนิดค่าหัว) hu.a5 ไป cv.2 ใช้รูป "สภารุ่นใหม่" ทาง ค) เปิดเผยความจริงของ PO-08 ซึ่งเป็นการสะสางรุ่นก่อนในตัว

### 8.3 ตระกูลลูกครึ่ง

รุ่นที่ 1 เป็นฮาล์ฟออร์ค (ho) ผ่าน ho.a2 ทาง ก ปลูกข้าวเถ้า ได้ปลายทาง "ล่ามของทุ่งและกระดูก" รุ่นที่ 2 แต่งกับมนุษย์ ลูกเป็นมนุษย์เต็ม เลือดออร์คเจือจาง (25% ได้แท็กเผ่าออร์คหนึ่งแท็ก) ใช้เส้นมนุษย์ ถึง hu.a5 ที่เป็น "→ cv.10" และ HP-07 เกิดแล้ว ใช้ "ข้าวรุ่นสอง" ลูกไม่ใช่ลูกครึ่งแล้ว จึงไม่ใช้ชุดเสริม ho และไม่เข้า ho.a2 ซ้ำ

## 9. ตรวจความสอดคล้อง

- รูปสืบทุกอย่างอ้างเหตุการณ์ NPC และอาชีพที่มีอยู่จริงในเอกสาร ไม่มีเหตุการณ์ใหม่
- จุดบรรจบรูปสืบยังนับเป็น "ครั้งเดียวต่อชีวิต" สำหรับทายาท
- cv.13 เกิดซ้ำได้ตามเดิมเพราะเป็นความฝันตอนมังกรล้ม ไม่ใช่เหตุการณ์ที่ตระกูลต้องผ่าน
- ตัวเลขร้อยละของรูปสืบทุกแถวรวม 100 (ก่อนตัดทางที่ไม่ตรงสถานะโลก)
- สมุดตระกูลไม่เก็บรายละเอียดของเหตุการณ์สุ่มเล็ก ๆ และศึกสุ่มทั่วไป เก็บเฉพาะรายการในหัวข้อ 2
