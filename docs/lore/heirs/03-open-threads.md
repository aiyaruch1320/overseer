# เรื่องค้าง

ระบบ: [README.md](README.md) · การสืบทอด: [01-inheritance.md](01-inheritance.md) · ไม่ซ้ำ: [02-no-repeat.md](02-no-repeat.md) · โหนดทายาท: [../storylines/23-heir.md](../storylines/23-heir.md)

เรื่องค้างคือสิ่งที่ชีวิตหนึ่งยังทำไม่เสร็จเมื่อตายและส่งต่อให้ทายาท เป็นเหตุผลที่รุ่นสืบมีเรื่องของตัวเอง ไม่ต้องเดินโหนดเดิมซ้ำ และเป็นตัวเชื่อมให้ผู้เล่นรู้สึกว่าตระกูลมีความต่อเนื่อง

## 1. ชนิดของเรื่องค้าง

| ชนิด | เกิดเมื่อ | ตัวอย่างจากเอกสาร | ทางสะสาง |
| --- | --- | --- | --- |
| หนี้ | ตายโดยมีหนี้ทอง (`c_debt`) หรือหนี้บุญคุณ (`nc_favor_unpaid`) | หนี้ที่ติด SV04-2 พิกซี่ หนี้ผู้ช่วยในการทดสอบนาคา | จ่ายทอง ทำงานให้เจ้าหนี้ หรือทำเรื่องแลก |
| ศึกสายเลือด | แค้นกับ NPC หรือกลุ่ม (`nc_blood_feud` `c_feud`) หรือค่าหัว (`c_wanted`) | ผู้ลี้ภัยที่ตามแก้แค้นจากตั๋วเรือปลอม (cv.1 ทาง ข) | ชนะ ไกล่เกลี่ย (`ns_mediate`) หรือหนี |
| สัญญา | ตายขณะมีสัญญาที่ยังไม่ครบ (ธงมีชื่อในบัญชีของชุด ct หนี้ภูตของชุด fy ใบสั่งตีอาวุธที่ช่างตายก่อน) | ชื่อในบัญชีของเซนวาล MH02-2 | ตัดสัญญา (`ns_pact_cut`) ทำตามสัญญา หรือไถ่ |
| คำมั่น | ตายหลังรับปากกับ NPC มังกร หรือสถาบัน | คำสัตย์ร้อยเผ่า (hu.a7) การเฝ้าไข่ (cv.7 ทาง ก) | ทำตามคำมั่น หรือส่งต่อให้ผู้อื่นที่ NPC ยอมรับ |
| ที่มั่น | ตายขณะเป็นผู้ดูแลชุมชนหรือสถานที่ | ชุมชนของ `third_home_founder` ประตูของ `gate_warden` | ดูแลต่อ ขาย หรือยกให้ ถ้าที่ยึดหาย ปิดเรื่องค้างอัตโนมัติ |
| ของที่ยังไม่ส่ง | ตายขณะถือของที่ต้องส่งหรือคืน | อาวุธตำนานที่ต้องไปคืนที่เดิม ([../../systems/items/08-legendary.md](../../systems/items/08-legendary.md)) จดหมายในขวด (`ns_wave_letter`) | ส่งของ คืนของ |
| ความลับ | ตายโดยไม่ได้บอกความจริงที่ทายาทเกี่ยว | เลือดอีกฝั่งที่ลูกครึ่งไม่เคยบอก ต้นกำเนิดของอาวุธ | ค้นหา เปิดเผย หรือปิดไว้ต่อ |
| ศิษย์ของผู้อื่น | มีผู้ที่ตระกูลรับสอนไว้กลางคัน (ความสัมพันธ์ `mentor`) | ผู้ที่ตัวละครสอน skill ไว้ครึ่งทาง | สอนต่อ ส่งต่อ หรือปล่อย |

## 3. วงจรของเรื่องค้าง

| สถานะ | ความหมาย |
| --- | --- |
| ค้าง | อยู่ในสมุดตระกูล ยังไม่ถึงโหนดสะสาง |
| กำลังสะสาง | ทายาทเดินโหนด hr ที่เกี่ยวกับเรื่องนี้ |
| ปิด | สะสางสำเร็จ จดในสมุดตระกูล ปลายทาง "ผู้ปิดสมุดตระกูล" นับเมื่อปิดครบ |
| ทิ้ง | ทายาทเลือกทิ้ง ผลเป็นของรุ่นต่อไป |
| จางหาย | ที่ยึดหายหรือคู่กรณีตาย และไม่มีผู้สืบ เรื่องหายโดยไม่มีผล |

**ถ้าทิ้ง** เรื่องค้างไม่หายแต่เปลี่ยนรูป ใช้ตารางด้านล่าง ทิ้งแล้วส่งให้รุ่นถัดไปได้ไม่เกินสองรุ่น หลังจากนั้นกลายเป็น "ตำนานของตระกูล" (ไม่มีผลต่อเกม ใช้เป็นข้อความของ LLM บทบาท `legend` ตาม [../storylines/llm-ideas.md](../storylines/llm-ideas.md))

| ชนิด | ผลเมื่อทิ้ง |
| --- | --- |
| หนี้ | ดอกเบี้ย +50% ต่อรุ่น เจ้าหนี้ส่งคนมาทวง (`npc_slaver` หรือ `npc_bandit`) |
| ศึกสายเลือด | แค้นเพิ่ม +1 ทุกรุ่น คู่กรณีโจมตีตระกูลในเหตุการณ์ใหญ่ถัดไป |
| สัญญา | ผลของสัญญาออกกับทายาทเต็มที่ (`c_souldebt` หรือคำสาปตามสัญญา) |
| คำมั่น | NPC ตัดความไว้ใจ ตระกูลถูกบันทึกเป็นผู้ผิดคำสัตย์ (`c_oathbreaker` 30%) |
| ที่มั่น | ชุมชนหรือสถานที่ตกเป็นของผู้อื่น ที่ยึดหาย |
| ของที่ยังไม่ส่ง | ของถูกริบหรือหาย ประวัติอาวุธจบ |
| ความลับ | ถูกเปิดโดยคนอื่นเมื่อเกิดเหตุการณ์ใหญ่ ผลแรงกว่าถ้าตระกูลเปิดเอง |
| ศิษย์ของผู้อื่น | ศิษย์ไปหาครูคนอื่น ความไว้ใจตระกูล −1 |

## 4. ตัวอย่างจากเนื้อเรื่องที่มีอยู่

| ตัวอย่าง | เรื่องค้างที่ส่งต่อ | ทายาท |
| --- | --- | --- |
| ลูกสัญญา (ct.b2 ทาง ก) ตายก่อนไถ่ชื่อในบัญชี | สัญญา: ชื่อในบัญชีของเซนวาล MH02-2 | ct.a1 กลายเป็นเรื่องค้างของทายาท เปิด `contract_redeemer` ได้ง่ายขึ้นถ้าผู้ปกครองทำสัญญาไว้แล้ว |
| ผู้ก่อบ้านหลังที่สาม (hb.a3 ทาง ค) ตาย | ที่มั่น: ชุมชนลูกครึ่ง | ทายาทดูแลชุมชนหรือยกให้ ชุมชนอยู่รอดสิบปีเปิดอาวุธ `wj_third_home_founder_e` ([../../systems/items/05-job-weapons-secret-special.md](../../systems/items/05-job-weapons-secret-special.md)) |
| สั่งอาวุธ E ที่ช่างยังไม่ตี | สัญญา: ใบสั่งตี | ทายาทรับใบสั่ง ช่างตีต่อ |
| เด็กที่ฟักจากไข่ที่ถูกขโมย (nh.a2 ทาง ข) | ความลับและที่มั่น: เด็กอยู่ SV-17 | ทายาทดูแลหรือส่งเด็กกลับ NR-07 |
| ศึกกับผู้ลี้ภัยที่ตามแก้แค้นจากตั๋วเรือปลอม (cv.1 ทาง ข) | ศึกสายเลือด | ทายาทไกล่เกลี่ย ชนะ หรือหนี |

## 5. พระเจ้ากับเรื่องค้าง

| การแทรกแซง | ผล |
| --- | --- |
| คำใบ้ "สางเรื่อง" | เรื่องค้างข้อแรกน้ำหนักทาง ก ×2 |
| คำใบ้ "คนนั้นโกหก" | ชี้ว่าใครในเรื่องค้างหลอก ทาง ข ของ hr.a2 ×2 |
| `b_secondchance` | ทิ้งเรื่องค้างหนึ่งข้อโดยไม่มีผลเมื่อทิ้ง (ใช้ได้หนึ่งครั้งต่อรุ่น) |
| `b_peacemaker` | ศึกสายเลือดสะสางด้วยการไกล่เกลี่ยแน่นอน ถ้าคู่กรณียังมีชีวิต |
| คำสาป `c_heircurse` | ทายาทได้เรื่องค้างอย่างน้อยหนึ่งข้อชนิดศึกสายเลือด |

## 6. ตรวจความสอดคล้อง

- เรื่องค้างมาจากสิ่งที่ตัวละครทำไว้จริง ไม่สร้างขึ้นเอง ทุกชนิดมีที่มาในเอกสารเส้นเรื่อง NPC หรืออาวุธ
- ปลายทาง "ผู้ปิดสมุดตระกูล" ใน [02-no-repeat.md](02-no-repeat.md) ต้องปิดเรื่องค้างครบทุกข้อที่ทายาทรับมา ไม่นับเรื่องที่จางหาย
- เรื่องค้างไม่เปลี่ยนเหตุการณ์ของโลก (ตัวละครเดียวทำให้ DR หรือ WR เกิดหรือหายไม่ได้ด้วยเรื่องค้าง) เปลี่ยนได้เฉพาะผลต่อ NPC และตัวละครเท่านั้น
