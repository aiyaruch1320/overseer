## ภาพรวมการเมือง

**โครงสร้าง: ระฆังกลาง** — ทวีปที่ไม่มีกลางวันกลางคืน ใช้ระฆังเวลาของเวลมีร์ (NB-01) บอกเวลาให้ทั้งทวีป ทุกเมืองมีระฆังรอง ตีตามสัญญาณจากกลาง ผู้ที่ควบคุมระฆังกลางควบคุมเวลาของทุกคน

- **ตลาดมืด** (NB-09) ค้าข้อมูลและสินค้าผิดกฎหมายข้ามทวีป ซึ่งหลายประเทศนอกทวีปพึ่งพาอย่างลับ ๆ
- **ตระกูลหมอกเก่า** ปกครองมาตั้งแต่ก่อนแวมไพร์ย้ายมา ระวังไม่ให้เคานตีแวมไพร์ขยายอำนาจ
- **ใต้หมอกมีเมืองปฐม** ที่จมอยู่ ผู้เฝ้าประตู (NB-08) รู้ทางเข้า
- **เสียงกระซิบ** ในหมอกชัดขึ้นทุกปี ศรัทธาเสียงกระซิบ (NB-07) แพร่หลาย
- **หมอกกินคน** — ตั้งแต่ ศ.ม. 10,390 หมอกบางหย่อมกลายเป็น *หมอกทึบ* ที่พาสิ่งมีชีวิตจากรอยแยกมา ดูหัวข้อด้านล่าง

| ศ.ม. | เหตุการณ์ |
| --- | --- |
| 0 | มหาล่มสลาย เมืองปฐมจมในหลุม หมอกเกิดจากไอเสีย |
| ~1,200 | แวมไพร์จากเหนือย้ายเข้ามา |
| 5,000 | ตั้งระฆังกลางเวลมีร์ |
| 7,700 | ตลาดมืดแห่งแรกเปิด |
| 9,000 | ศรัทธาเสียงกระซิบแพร่ |
| 9,900 | ปีหมอกดำ ความอดอยากและโรคระบาด |
| 10,200 | ผู้ลี้ภัยตุ๊กตากลุ่มแรกเข้ามา |
| 10,350 | เสียงกระซิบชัดขึ้น คนในเมืองหนึ่งหายทั้งหมด |
| 10,388 | *ภารกิจเมฆา* เจาะประตูเมืองปฐมเพื่อเอากุญแจ "ความทรงจำเมฆา" |
| 10,390 | หมอกทึบหย่อมแรกเกิดที่เมอเนบ สิ่งมีชีวิตจากรอยแยกพรากคนหายไปทั้งท่าเรือ |
| 10,396 | ตลาดโคมใหญ่ถูกปิดตายสิบเอ็ดวัน |
| 10,400 | ปัจจุบัน หมอกทึบแพร่ไปสามประเทศ นครต่าง ๆ ปิดประตู ต้นไม้โลกเริ่มกรองไม่ทัน |

**กลุ่ม**
- **ตระกูลหมอกเก่า** — NB-01, NB-03, NB-07
- **เคานตีแวมไพร์และเงา** — NB-02, NB-13
- **กิลด์ลับ** — NB-05, NB-09, NB-11, NB-06
- **ผู้ลี้ภัยและผู้พเนจร** — NB-10, NB-14
- **ผู้เฝ้าความลับ** — NB-08, NB-04
- **ชายแดนและแนวหน้าหมอกทึบ** — NB-12, NB-03, NB-14

**จุดวาบไฟ:** PL-09 (NB-08), BIO-04, BIO-05, BIO-06 (NB-08), CT-06 (รอยแยกจากภารกิจเมฆา), WR-08, WR-09, CT-03 (NB-12), PO-07 (NB-09), MC-09, END-09, MC-02 (NB-10), DM-09 (NB-08)

## ประเทศ

#### NB-01 เวลมิร์ — นครระฆังกลาง
- **รัฐ:** สภาตระกูลเก้า ผู้ตีระฆังเป็นประมุข · **เผ่า:** ชาวหมอก มนุษย์ · **ศาสนา:** จันทรา
- **เรื่องราว:** หอระฆังสูงทะลุหมอก ระฆังตีทุกชั่วโมงพร้อมกันทั้งทวีป ตระกูลเก่าที่สุดในโลกอยู่ที่นี่ ผู้ที่ไม่ทำตามเวลาคือผู้ทรยศ แต่ตั้งแต่หมอกทึบมา เสียงระฆังเรียกสิ่งมีชีวิตจากรอยแยก สภาแตกเป็นสองฝ่าย ฝ่ายหนึ่งสั่งให้ระฆังเงียบ อีกฝ่ายยืนยันว่าถ้าเวลาหยุด ทวีปจะแตกเป็นเสี่ยง
- **ความสัมพันธ์:** หัวหน้าตระกูลหมอกเก่า · พันธมิตร NB-03, NB-07 · ระแวง NB-02
- **ปมเรื่องหลัก:** ผู้ตัดสินว่าจะหยุดระฆังหรือไม่ ผลคือเวลาหรือชีวิต

#### NB-02 ซอร์เนบ — เคานตีแวมไพร์
- **รัฐ:** เคานตีเลือด ปกครองโดยเคานต์ผู้เฒ่า · **เผ่า:** แวมไพร์ มนุษย์ผู้ถูกกัด · **ศาสนา:** จันทรา, ลัทธิปีศาจ
- **เรื่องราว:** ปราสาทในหมอกที่ไม่มีวันหรือคืน ธนาคารเลือดเป็นสถาบันการเงิน ผู้ที่ไม่ยอมเป็นข้าติดหนี้เลือดไปตลอดชีวิต เมื่อหมอกทึบมา สิ่งมีชีวิตจากรอยแยกล่าแวมไพร์เช่นกัน เคานต์เปิดปราสาทให้มนุษย์หลบภัยโดยแลกกับสัญญาเลือด ผู้ลี้ภัยหลายพันคนตอบรับ
- **ความสัมพันธ์:** ตึงเครียดกับ NB-01 · สัญญาเงียบกับ SH-02 · พันธมิตร NB-13
- **ปมเรื่องหลัก:** วันหมอกแหวก (BIO-05) คือหายนะของที่นี่ เคานต์อาวุโสรู้ดีที่สุดว่าประตูเมืองปฐมอยู่ที่ไหน และไม่เห็นด้วยกับภารกิจเมฆามาตั้งแต่ต้น

#### NB-03 ลูเมนธาล — สหพันธ์นครโคม
- **รัฐ:** สหพันธ์เมืองโคมยี่สิบเมือง หัวหน้าโคมเป็นผู้ปกครอง · **เผ่า:** ชาวหมอก มนุษย์ ภูตแสง · **ศาสนา:** จันทรา, ศรัทธาเสียงกระซิบ
- **เรื่องราว:** เมืองที่แขวนโคมนับล้านบอกทางในหมอก คนจุดโคมคือกิลด์ที่มีอำนาจสูงสุด เมื่อหมอกทึบมา เมืองทั้งหมดปิดประตูตามกฎประตูปิด ผู้เดินทาง พ่อค้า ขุนนาง และคนแปลกหน้านับร้อยถูกขังรวมกันในตลาดโคมใหญ่ตลอดสิบเอ็ดวัน เมื่อประตูเปิด ตลาดแห่งนั้นปกครองตัวเองเป็นสาธารณรัฐเล็กที่ตั้งกติกาใหม่และปฏิเสธออกคำสั่งจากหัวหน้าโคมเดิม
- **ความสัมพันธ์:** พันธมิตร NB-01 · ใช้ผู้นำทางจาก NB-14 · ซื้อน้ำมันตะเกียงราคาแพงจาก NB-09
- **ปมเรื่องหลัก:** แสงโคมไล่สิ่งมีชีวิตได้ชั่วคราว น้ำมันกำลังหมด และโคมสีแดงคือสัญญาณของชั่วโมงหนวด

#### NB-04 ไอเลวัน — นครคนตาบอด
- **รัฐ:** สภาผู้ฟัง · **เผ่า:** มนุษย์ตาบอด ชาวหมอกหูไว · **ศาสนา:** ศรัทธาเสียงกระซิบ
- **เรื่องราว:** เมืองของคนที่เกิดมาตาบอดหรือยอมให้ตัวเองตาบอด ได้ยินทุกเสียงในหมอก ตอนนี้เป็นระบบเตือนภัยของทวีป ฟังเสียงเนื้อบินและเสียงหนวดคลาน ขายสัญญาณเตือนให้เมืองอื่น แต่ผู้ฟังหลายคนเริ่มได้ยินเสียงที่ไม่ใช่เสียงจริง
- **ความสัมพันธ์:** ค้ากับ NB-09 · ผูกพันทางดนตรีกับ NR-08
- **ปมเรื่องหลัก:** รู้ว่าเสียงกระซิบกับเสียงสิ่งมีชีวิตมาจากแหล่งเดียวกัน

#### NB-05 มอร์เนบ — กิลด์เงา
- **รัฐ:** สมาคมนักฆ่า ปกครองโดยเจ้าแห่งเงา · **เผ่า:** มนุษย์ ดาร์กเอลฟ์ แวมไพร์ · **ศาสนา:** ไม่มี
- **เรื่องราว:** ผู้เชี่ยวชาญการลอบเร้นและลอบสังหาร ไม่มีกฎ ไม่มีสัญญา แต่มีเกียรติของนักฆ่า รับงานจากทุกทวีป
- **ความสัมพันธ์:** กิลด์ลับ · ใช้ NB-09 เป็นตลาดงาน
- **ปมเรื่องหลัก:** PO-08 ลอบสังหารผู้แทนสภา ผู้บงการมักมีเงาของที่นี่

#### NB-06 เลซิล — นครนักเล่นแร่ยาพิษ
- **รัฐ:** สหภาพผู้ปรุงยา · **เผ่า:** มนุษย์ ดาร์กเอลฟ์ สไลม์ · **ศาสนา:** ไม่เคร่งครัด
- **เรื่องราว:** ผลิตยาพิษและยาถอนพิษ ตลาดหลักของผู้เดินทางที่ต้องผ่านหมอก ผู้ผลิตพิษรู้จักยาแก้ทุกชนิด เพราะต้องรู้ทั้งสองด้าน
- **ความสัมพันธ์:** กิลด์ลับ · ซื้อเห็ดจาก SV-12, SV-18
- **ปมเรื่องหลัก:** HP-06 ยาวิเศษอาจเกิดที่นี่ แต่ผู้ผลิตจะเก็บเป็นความลับ

#### NB-07 เมอลิน — สำนักกระซิบ
- **รัฐ:** อารามผู้ฟัง · **เผ่า:** ชาวหมอก มนุษย์ผู้ศรัทธา · **ศาสนา:** ศรัทธาเสียงกระซิบ
- **เรื่องราว:** นักบวชที่นั่งฟังเสียงในหมอกทุกวัน เชื่อว่าเสียงคือความทรงจำของผู้ตาย บันทึกทุกคำเป็นเล่มหนา เมื่อหมอกทึบมา สำนักแตกเป็นสองฝ่าย ฝ่ายเดิมสอนให้สงบและรอ ฝ่ายใหม่ของ *มารดาแห่งเสียง* ประกาศว่านี่คือการพิพากษา คนบาปต้องถวายเพื่อให้หมอกถอย ผู้ติดตามเพิ่มอย่างรวดเร็วในเมืองที่ถูกขังในความกลัว
- **ความสัมพันธ์:** พันธมิตร NB-01, SV-13 · ฝ่ายคำพิพากษาแทรกซึม NB-03
- **ปมเรื่องหลัก:** ความกลัวสร้างศาสดา (GD-01 รูปแบบมืด) ผู้ปฏิเสธคำพิพากษาถูกชี้ตัวเป็นผู้นำหมอกมา

#### NB-08 เนวานธาล — ผู้เฝ้าประตูเมืองปฐม
- **รัฐ:** อารามลับ · **เผ่า:** ชาวหมอก ผีเมืองปฐม · **ศาสนา:** ศรัทธาเสียงกระซิบ
- **เรื่องราว:** เก็บทางลงสู่เมืองปฐมที่จม นิเวรีมังกรเสาหลับอยู่ในหมอกดำเหนือประตู ผู้เฝ้าคัดค้านภารกิจเมฆาแต่ถูกเพิกเฉย เมื่อประตูถูกเจาะ สิ่งที่ไหลออกมาไม่ใช่ผี ผู้เฝ้ากลายเป็นแนวป้องกันสุดท้ายที่ประตู ตายวันละหลายคน และไม่มีใครส่งกำลังมาช่วย
- **ความสัมพันธ์:** ปกปิดจากทุกคน · ร่วมมือ SV-06 · ต้องการความช่วยเหลือจาก NB-02
- **ปมเรื่องหลัก:** กุญแจ "ความทรงจำเมฆา" อยู่ในเมืองใต้ นิเวรีเริ่มตื่น (PL-09) หากมันล้ม ประตูเปิดตลอดไป DM-09 ลิชตื่น เกิดที่นี่

#### NB-09 ซอร์วาน — ตลาดมืดข้ามทวีป
- **รัฐ:** สหภาพนายหน้า ไม่มีผู้ปกครองชัดเจน ผู้นำถูกเลือกด้วยมูลค่าความลับ · **เผ่า:** ทุกเผ่า · **ศาสนา:** ไม่มี
- **เรื่องราว:** ทุกอย่างซื้อขายได้: ข้อมูลสายลับ อาวุธตำนานปลอม ผู้ลี้ภัยที่ต้องการตัวตนใหม่ ธนาคารใต้ดินให้กู้แก่ผู้ที่ไม่มีใครอยากให้กู้ เป็นผู้ออกทุนให้ภารกิจเมฆา ตอนนี้ขายเชือก โคม น้ำมัน และอาหารในราคาสิบเท่า ทุกคนด่าและทุกคนซื้อ
- **ความสัมพันธ์:** ค้ากับ AZ-10, MH-02, NR-05, NR-14, SV-04 · ผู้ซื้อลับ MK-01
- **ปมเรื่องหลัก:** PO-07 ตลาดมืดครองเศรษฐกิจ ผู้ออกทุนให้การเปิดรอยแยกและรู้ดีว่ามันเป็นความผิดของใคร

#### NB-10 ไอซิลโนวา — ที่ลี้ภัยตุ๊กตา
- **รัฐ:** สภาผู้รอดชีวิต · **เผ่า:** ผู้รอดชีวิตจากโครงการตุ๊กตา ลูกผสมจักรกล หุ่นหนีนาย · **ศาสนา:** ไม่มี
- **เรื่องราว:** หมู่บ้านที่ซ่อนอยู่ในหมอกที่หนาที่สุด ผู้รอดชีวิตจากห้องทดลองตั้งรกรากที่นี่เพราะไม่มีใครตามเข้ามา เมื่อหมอกทึบมา พบว่าสิ่งมีชีวิตจากรอยแยกมักเมินลูกผสมจักรกลที่มีเนื้อน้อย พวกเขากลายเป็นผู้นำทางในหมอกทึบที่ทุกคนต้องการ และถูกเกลียดโดยคนที่เคยรังเกียจพวกเขา
- **ความสัมพันธ์:** พันธมิตร MK-10, MK-03 · ปกป้องโดย NB-04 · ถูกว่าจ้างโดย NB-03
- **ปมเรื่องหลัก:** MC-02 โครงการตุ๊กตารั่ว ผู้รอดชีวิตมีหลักฐาน และตอนนี้ยังมีคุณค่าที่ไม่มีใครมี

#### NB-11 ลูเวลิน — ช่างทำหน้ากาก
- **รัฐ:** สมาคมช่างหน้ากาก · **เผ่า:** ชาวหมอก มนุษย์ · **ศาสนา:** จันทรา
- **เรื่องราว:** ผลิตหน้ากากกรองหมอกที่ส่งออกให้ผู้เดินทางและราชสำนัก ลายแกะสลักแสดงฐานะ หน้ากากลวดลายพิเศษขายแพงในลาโรเซล
- **ความสัมพันธ์:** กิลด์ลับ · ส่งออก AL-05
- **ปมเรื่องหลัก:** หน้ากากแต่ละใบมีรหัสลับที่ซ่อนตัวผู้สวม ผู้ซื้อเป็นสายลับไม่น้อย

#### NB-12 เมอเนบ — ประตูเหนือ
- **รัฐ:** ท่าเรือหมอก ปกครองโดยกัปตันท่า · **เผ่า:** มนุษย์ ชาวหมอก นักลักลอบ · **ศาสนา:** ไม่เคร่งครัด
- **เรื่องราว:** ท่าที่เชื่อมเนบูเลียกับทุ่งราบ ทั้งค้าขายและลักลอบ กัปตันท่าอนุมัติภารกิจเมฆาและเป็นจุดตั้งต้นของมัน ฐานหน้าผาที่ใช้เจาะประตูเมืองปฐมอยู่ห่างจากท่าสามลีก เมื่อรอยแยกเปิด หมอกทึบหย่อมแรกเข้ากลืนท่าเรือในคืนเดียว ผู้รอดชีวิตล็อกประตูคลังสินค้า กองทัพจากมิสต์วอตช์มาถึงช้าไปสามวัน
- **ความสัมพันธ์:** ค้ากับ AL-20 · ใกล้ NB-09 · กัปตันท่าหายตัว
- **ปมเรื่องหลัก:** CT-03 กาฬโรคและหมอกกินคนเริ่มจากที่นี่ ผู้รอดชีวิตมีสองเรื่องเล่าที่ไม่ตรงกันเกี่ยวกับเหตุการณ์คืนนั้น

#### NB-13 เลนิธาล — แดนไร้เงา
- **รัฐ:** รัฐเงา สภาผู้ไร้เงา · **เผ่า:** ดาร์กเอลฟ์ ผู้ไร้เงา วิญญาณเงา · **ศาสนา:** จันทรา
- **เรื่องราว:** ผู้คนที่สูญเสียเงาของตัวเอง ผู้ไร้เงาเดินในหมอกได้โดยไม่ถูกเห็น นักสืบ นักลอบเข้า และผู้ลี้ภัยจากความตาย สิ่งมีชีวิตจากรอยแยกมองไม่เห็นพวกเขาเมื่ออยู่นิ่ง จึงเป็นผู้ส่งสารและผู้เก็บศพของทวีป
- **ความสัมพันธ์:** พันธมิตร NB-02 · ติดต่อ KD-05, SV-05
- **ปมเรื่องหลัก:** รู้ว่าเงาของพวกเขาไปอยู่ที่ไหน และใครเป็นผู้เก็บ

#### NB-14 เนบลิน — เมืองผู้หลงทาง
- **รัฐ:** ขบวนเกวียนเร่ร่อน · **เผ่า:** ชาวหมอก มนุษย์ผู้หลงทาง · **ศาสนา:** ไม่เคร่งครัด
- **เรื่องราว:** เมืองที่เคลื่อนที่อยู่ในหมอกตลอด ผู้คนที่หลงทางแล้วตั้งเป็นสังคม ขายแผนที่และผู้นำทาง รู้ทุกซอกมุมของทวีป เมื่อหมอกทึบมา ขบวนนี้เป็นสถานที่เดียวที่ไม่หยุดนิ่ง จึงยังหลบสิ่งมีชีวิตได้ ขบวนรับผู้รอดชีวิตจากเมืองที่ปิดตาย ขนไปส่งต่อเมืองอื่น เสบียงและน้ำมันจำกัด ต้องเลือกว่าจะรับใครเพิ่ม
- **ความสัมพันธ์:** พันธมิตร NB-03 · ขายแผนที่ให้ทุกฝ่าย · ร่วมมือ NB-10
- **ปมเรื่องหลัก:** รู้ทางเข้าเมืองปฐมอีกแห่งซึ่งไม่เคยบอกใคร และรู้ว่าสิ่งมีชีวิตตามขบวนมาตลอดเก้าปี

## หมอกกินคน

**ที่มา** ภารกิจเมฆา (ศ.ม. 10,388) เป็นการเดินทางร่วมของกองทัพมิสต์วอตช์ (AL-20) สมาคมรหัสไซเฟอร์ (MK-13) และนายท่านแห่งเมอเนบ (NB-12) ได้ทุนจากตลาดมืด (NB-09) เพื่อเจาะประตูเมืองปฐมและเอากุญแจ "ความทรงจำเมฆา" ผู้เฝ้าประตู (NB-08) คัดค้านแต่ถูกข้าม การเจาะเปิดรอยแยกที่ยังไม่ปิดสนิทจากมหาล่มสลาย **สิ่งที่มากับหมอก** ไหลออกมา ไม่ใช่ผีและไม่ใช่สัตว์ในทวีป

**สิ่งมีชีวิตจากรอยแยก** (ทุกอย่างปรากฏเฉพาะในหมอกทึบ)

| ชนิด | ลักษณะ |
| --- | --- |
| หนวดหมอก | หนวดยาวหลายสิบวาที่ลากคนออกจากหน้าต่างและประตู |
| แมลงปีกขาว | ฝูงแมลงยักษ์ที่ฆ่าด้วยพิษและกัด ทำให้คนสิ้นสติ |
| ใยดำ | แมงมุมขนาดวัวที่ถักใยขวางทางและมัดเหยื่อเป็นรังไข่ |
| เนื้อบิน | สัตว์ปีกไร้ตาที่ล่าเสียง |

- พวกมันตามเสียงและกลิ่นเลือด แสงโคมสีขาวจ้าและไฟไล่ได้ชั่วคราว
- ระฆังเรียกพวกมันมา → ระบบเวลาของเวลมีร์ (NB-01) ต้องตัดสินว่าจะหยุดตีระฆังไหม
- ผู้มีพรต้านพิษไม่ได้รับการป้องกันจากพวกมัน

**ชั่วโมงหนวด** เวลาที่หมอกทึบม้วนเข้าเมือง กินเวลาหลายชั่วโมงถึงหลายวัน เมืองปิดประตู ปิดหน้าต่าง ดับเสียง รู้กันทั่วทวีปด้วยสัญญาณโคมสีแดง

**วัฒนธรรมใหม่**
- *เชือกนำทาง* — เชือกยาวผูกระหว่างอาคารและเมือง คนที่ปล่อยเชือกหายไป
- *กฎประตูปิด* — ไม่มีใครเปิดประตูจนกว่าหัวหน้าโคมให้รหัส ไม่ว่าเสียงข้างนอกจะเป็นเสียงใคร
- *ผู้อยู่นิ่งกับผู้ออกเดิน* — ฝ่ายหนึ่งยืนยันว่าต้องรอในที่ปลอดภัย อีกฝ่ายยืนยันว่าอาหารไม่พอและต้องฝ่าออกไป
- *คำพิพากษา* — ลัทธิที่ประกาศว่าหมอกทึบคือการตัดสินบาป ต้องบูชายัญเพื่อให้มันถอย
- *บัญญัติสุดท้าย* — ธรรมเนียมที่ผู้ปกป้องสาบานว่าจะไม่ปล่อยให้ผู้ที่รักตกเป็นเหยื่อสิ่งมีชีวิต ถึงขั้นต้องจบชีวิตให้ก่อน

**ผลต่อโลก** รอยแยกนี้คือบาดแผลของเครื่องจักรปฐม (เชื่อม CT-06) หมอกทึบลามไปตามรากต้นไม้โลก (BIO-04) และหากนิเวรีล้ม ประตูเมืองปฐมเปิดกว้างทั้งทวีป (END-09)
