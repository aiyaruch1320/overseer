## ภาพรวมการเมือง

**โครงสร้าง: สนธิสัญญาเตาเหล็ก** — ทวีปที่ทุกประเทศพึ่งโลหะและความร้อนของกันและกัน ไม่มีประเทศใดอยู่ได้โดยไม่มีอีกประเทศหนึ่งขายถ่าน แร่ หรือฝีมือให้

- แหล่งแร่ เหล็กไหล และทั่งปฐม ตั้งอยู่ในสามประเทศที่ไม่ยอมแบ่งกัน
- คนแคระแตกเป็นสองฝ่ายหลังพบรูนปฐม: ฝ่ายปิด (KD-03) ฝ่ายเปิด (KD-04)
- สงครามเก่าระหว่างเผ่าลาวา (KD-06) กับดาร์กเอลฟ์ (KD-05) จบด้วยสนธิสัญญา แต่ความแค้นยังอยู่
- ปากเหวนรกและเหมืองลึกอยู่ในเขตที่ทุกคนกลัว มังกรเสาคัลดราหลับอยู่ข้างใต้

| ศ.ม. | เหตุการณ์ |
| --- | --- |
| 0 | มหาล่มสลาย แกนไฟหลุดออก ลาวาไม่เคยเย็น |
| ~800 | คนแคระกลุ่มแรกตามกลิ่นแร่ลงมา |
| 3,100 | คนแคระพบรูนปฐมในเหมืองลึก ผู้นำตัดสินปิดเป็นความลับ |
| 5,900 | ดาร์กเอลฟ์ถูกเนรเทศจากมอร์เฮเวนมาถึง |
| 5,950–6,100 | สงครามถ้ำร้อน เผ่าลาวา × ดาร์กเอลฟ์ |
| 8,200 | สนธิสัญญาเตาเหล็กลงนามที่ฮัลกาด |
| 10,150 | คนแคระแตกเป็นสองฝ่ายเรื่องรูน บาร์ดินแยกตัว |
| 10,360 | เมคาเรียซื้อเทคโนโลยีหลอมจากบาร์ดิน ฝ่ายปิดโกรธ |
| 10,400 | ปัจจุบัน เหมืองลึกเกินระดับปลอดภัย พื้นดินสั่นทุกคืน |

**กลุ่ม**
- **ฝ่ายปิดรูน** — KD-03, KD-01, KD-11
- **ฝ่ายเปิดรูน** — KD-04, KD-09, KD-10 (ฝ่ายเปิดเพราะเงิน)
- **ฝ่ายสมดุล** — KD-05, KD-06, KD-07 ผลัดกันเลือกข้าง
- **ผู้เฝ้าปากเหว** — KD-08 เป็นกลางตามสัญญา
- **ขอบน้ำแข็ง** — KD-12 โดดเดี่ยว

**จุดวาบไฟ:** DR-04, PL-03 (KD-10), GI-04 (KD-06), GI-05 (KD-03/KD-04), GI-08 (KD-08), WR-05, WR-11, WR-12, WR-13, DM-07

## ประเทศ

#### KD-01 กรอมฮอล์ม — ราชอาณาจักรทั่งทอง (ชาติช่างตีเหล็ก)
- **รัฐ:** ราชาช่างตี สภาสมาคมช่าง · **เผ่า:** คนแคระ · **ศาสนา:** บรรพบุรุษ ศรัทธาเตาหลอม
- **เรื่องราว:** ประเทศแห่งช่างตีเหล็ก เป็นที่ตั้ง *ทั่งปฐม* ที่ใช้ตีอาวุธตำนาน คลังอาวุธตำนานของโลกส่วนใหญ่ถูกตีที่นี่ เด็กที่เกิดในเมืองมีโอกาสเป็นช่างตีระดับตำนานสูงกว่าที่อื่นหลายเท่า ใครเป็นนายช่างใหญ่ของรุ่นนั้นเรียกว่า "มือทั่ง"
- **ความสัมพันธ์:** พันธมิตร KD-03, KD-11 · ซื้อแร่จาก KD-02 · ลูกค้า AZ-01, AL-18
- **ปมเรื่องหลัก:** ค้อนปฐมไฟและดาบหัวใจภูเขาอยู่ที่นี่ การตีอาวุธตำนานแต่ละชิ้นต้องใช้วัตถุดิบจากอีกทวีป เป็นเหตุให้ช่างตีออกเดินทาง

#### KD-02 ดูร์ดิน — สาธารณรัฐเหล็กไหล
- **รัฐ:** สาธารณรัฐเจ้าของแม่น้ำ แต่ละแม่น้ำมีตระกูลเจ้าของ · **เผ่า:** คนแคระ เผ่าลาวา มนุษย์ · **ศาสนา:** ศรัทธาเตาหลอม
- **เรื่องราว:** ดินแดนแม่น้ำเหล็กไหลที่ไหลเป็นสายลาวา เหล็กที่นี่มีมากเป็นพิเศษ คุณภาพต่ำกว่า KD-01 แต่ป้อนทั้งทวีปและโรงงานเมคาเรีย คือประเทศร่ำรวยที่สุดของทวีป
- **ความสัมพันธ์:** ขาย KD-01, MH-05, MK-06 · คู่แข่งการค้า KD-09
- **ปมเรื่องหลัก:** แม่น้ำเหล็กไหลเริ่มเย็นลงทีละสาย คนแคระสงสัยว่าแกนไฟกำลังอ่อนแรง หากเพลิงนิรันดร์ล้ม (DR-04) ที่นี่ล่มก่อนใคร

#### KD-03 คาซรัม — ป้อมศักดิ์ผู้ปิดรูน
- **รัฐ:** ราชอาณาจักรผู้พิทักษ์ · **เผ่า:** คนแคระเก่าแก่ · **ศาสนา:** บรรพบุรุษ
- **เรื่องราว:** ป้อมปราการที่เก่าแก่ที่สุด ผู้นำสืบทอดคำสาบาน "ไม่อ่านรูนปฐมให้คนนอกฟัง" มาสามพันปี เหมืองลึกสุดของที่นี่มีผนังจารึกทั้งผืน ถูกปิดผนึก
- **ความสัมพันธ์:** พันธมิตร KD-01, KD-11 · ศัตรูทางความคิด KD-04
- **ปมเรื่องหลัก:** ผู้อ่านรูนได้ในประเทศนี้รู้เรื่องมหาล่มสลายครบถ้วน แต่ปิดเพราะกลัวว่าความรู้จะปลุกเครื่องจักรปฐม (GI-05)

#### KD-04 บาร์ดิน — สหพันธ์เปิดรูน
- **รัฐ:** สหพันธ์เมืองช่างและนักปราชญ์ · **เผ่า:** คนแคระ วิศวกรมนุษย์ · **ศาสนา:** ไม่เคร่งครัด
- **เรื่องราว:** แยกตัวจากคาซรัมเมื่อ ศ.ม. 10,150 เปิดสอนรูนปฐมให้ทุกคน ขายเทคโนโลยีหลอมให้เมคาเรีย ได้อาหารและเงินกลับมา
- **ความสัมพันธ์:** พันธมิตร MK-07, MK-13 · ศัตรู KD-03
- **ปมเรื่องหลัก:** การถอดรหัสปฐมของเมคาเรียส่วนหนึ่งมาจากเอกสารที่นี่ (MC-06)

#### KD-05 อิรมอร์ — นครใต้พิภพ (ดาร์กเอลฟ์)
- **รัฐ:** มาตาธิปไตย ปกครองโดยสภามารดา · **เผ่า:** ดาร์กเอลฟ์ · **ศาสนา:** จันทรา, ลัทธิปีศาจ
- **เรื่องราว:** นครใต้ดินลึกที่ลาวาเรืองแสงเป็นแสงเดียวของเมือง พวกเขาหนีจากมอร์เฮเวนมาห้าพันปีก่อน เป็นนักเวทและนักฆ่า ทำสงครามกับเผ่าลาวาก่อนยอมสงบศึก
- **ความสัมพันธ์:** ตึงเครียดกับ KD-06 · ค้าลับกับ NB-13 · ติดต่อ MH-02
- **ปมเรื่องหลัก:** รู้ทางลงสู่ปากเหวนรกที่ลึกกว่าคนอื่น ประตูนรกเปิดแล้วเป็นเขตแรกที่ปะทะ

#### KD-06 ฮัลดัล — จักรวรรดิเผ่าลาวา
- **รัฐ:** จักรวรรดิสายเลือดลาวา · **เผ่า:** เผ่าลาวา · **ศาสนา:** ศรัทธาเตาหลอม
- **เรื่องราว:** ผู้คนผิวมีรอยร้าวเรืองแสง ทนความร้อนที่คนอื่นตายได้ จักรพรรดิรุ่นใหม่ (ปีที่สามสิบ) ตั้งเป้ารวมคาซ-ดูรัมเป็นหนึ่ง เพราะเชื่อว่าเผ่าลาวาคือผู้สืบเชื้อแท้ของแกนไฟ
- **ความสัมพันธ์:** ศัตรูเก่า KD-05 · เป็นพันธมิตรหลวม ๆ กับ KD-07 · ซื้อเหล็กจาก KD-02
- **ปมเรื่องหลัก:** GI-04 เกิดที่นี่ หากเพลิงนิรันดร์ล้ม เผ่าลาวาจะอ่อนแรงลงทุกคน

#### KD-07 ธรอกาด — ราชวงศ์มังกรเผา
- **รัฐ:** ราชวงศ์ · **เผ่า:** เผ่ามังกร · **ศาสนา:** บูชามังกร
- **เรื่องราว:** ญาติของเผ่าปีกเกล็ดแห่งอัซการ์ มีสายเลือดมังกรเจือ หยิ่งในศักดิ์ศรี เป็นตัวกลางระหว่างทวีปมังกรกับทวีปไฟ รับบรรณาการจากเหมืองและส่งต่อให้ซากโรการ์
- **ความสัมพันธ์:** พันธมิตร AZ-02, KD-06 · เป็นกลางต่อ KD-03 และ KD-04
- **ปมเรื่องหลัก:** ถ้าผู้อาวุโสเพลิงล้ม เผ่านี้เป็นกลุ่มแรกที่รู้สึกถึงมันก่อนใคร

#### KD-08 มอร์ดิน — ผู้เฝ้าปากเหว
- **รัฐ:** ป้อมนักบวชนักรบ · **เผ่า:** คนแคระ เผ่าลาวา มนุษย์ผู้ศรัทธาแสง · **ศาสนา:** แสง, ศรัทธาเตาหลอม
- **เรื่องราว:** ป้อมใหญ่ครอบปากเหวนรก เฝ้ากักปีศาจที่ขึ้นมา ทุกร้อยปีปีศาจขึ้นมาหนึ่งระลอก ผู้เฝ้ากลายเป็นนักรบที่ผ่านศึกมากที่สุดของทวีป
- **ความสัมพันธ์:** รับกองหนุนจาก AL-02 · เป็นกลางตามสัญญากับคนอื่น
- **ปมเรื่องหลัก:** จุดรวมพลของ WR-13 สงครามศักดิ์สิทธิ์ GI-08 จะผนึกปากเหวและมีราคาของมัน

#### KD-09 ดัลฮอล์ม — เมืองแก้วออบซิเดียน
- **รัฐ:** นครรัฐพ่อค้า · **เผ่า:** คนแคระ มนุษย์ ฮาล์ฟลิง · **ศาสนา:** ไม่เคร่งครัด
- **เรื่องราว:** ผลิตเครื่องแก้วออบซิเดียนและอัญมณีไฟ ส่งออกไปอัลเดรียและเมคาเรีย เป็นประตูการค้าของทวีป มีท่าเรือบกสู่ซาฮารัน
- **ความสัมพันธ์:** ค้ากับทุกคน · ได้ประโยชน์จากความแตกแยกของคนแคระ
- **ปมเรื่องหลัก:** ส่งออกข่าวเหมืองไปเมคาเรียในนามพ่อค้า

#### KD-10 คาซมา — สาธารณรัฐเหมืองลึก
- **รัฐ:** สาธารณรัฐสหภาพคนงาน · **เผ่า:** คนแคระ มนุษย์ คนงานจากหลายทวีป · **ศาสนา:** ไม่เคร่งครัด
- **เรื่องราว:** เหมืองที่ลึกที่สุดในโลก คนงานเป็นผู้ปกครองเอง ขุดจนถึงชั้นที่ลาวาร้อนเกินมนุษย์ ใกล้ที่นอนของคัลดรา ถือกุญแจ "หัวใจลาวา" โดยไม่รู้ว่าเป็นกุญแจ
- **ความสัมพันธ์:** ฝ่ายเปิดรูนเพราะต้องการเงิน · ติดหนี้ KD-09
- **ปมเรื่องหลัก:** ปลุกคัลดรา (PL-03) ขุดลึกเกินเมื่อใด ทวีปทั้งทวีปปะทุ

#### KD-11 ฮัลกาด — รัฐนักบวชเตาหลอม
- **รัฐ:** เทวาธิปไตย · **เผ่า:** คนแคระ เผ่าลาวา มนุษย์ผู้ศรัทธา · **ศาสนา:** ศรัทธาเตาหลอม
- **เรื่องราว:** สนธิสัญญาเตาเหล็กลงนามที่นี่ พิธีตะวันหลอมเหล็กประจำปีจัดที่นี่ นักบวชหลอมอาวุธทั้งพิธีและศรัทธา ถือว่าเปลวไฟคือเทพ
- **ความสัมพันธ์:** พันธมิตร KD-01, KD-03 · เป็นผู้ไกล่เกลี่ยของทวีป
- **ปมเรื่องหลัก:** ศรัทธาเปลวไฟของที่นี่ไม่ผ่านมังกร ความเชื่อจึงไม่เข้าสู่ผนึกของคัลดรา ซึ่งเป็นช่องโหว่

#### KD-12 ธรอ-ดู — ขอบน้ำแข็ง
- **รัฐ:** ตระกูลนักรบ · **เผ่า:** คนแคระเหนือ เผ่ามนุษย์น้ำแข็ง · **ศาสนา:** บรรพบุรุษ
- **เรื่องราว:** ที่ลาวาและธารน้ำแข็งชนกัน ผลิตอาวุธเย็นที่ช้ากว่าอาวุธไฟ แต่ไม่แตกร้าว เลี้ยงชีพด้วยการล่าสัตว์ เก็บตัวจากสงคราม
- **ความสัมพันธ์:** ค้ากับ SH-15, AL-03 · ไม่เข้าสนธิสัญญา
- **ปมเรื่องหลัก:** เมื่อฤดูหนาวเถ้ามา (DR-04) ที่นี่กลายเป็นเมืองหลักของทวีปเถ้า
