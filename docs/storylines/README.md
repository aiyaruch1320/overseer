# เส้นเรื่องตัวละครหลัก: โครงสร้าง

ผู้เล่นเป็นพระเจ้าที่เฝ้าดูตัวละครหลัก ตัวละครตัดสินใจเองจากโอกาสสุ่มและเส้นเหตุการณ์ที่พาไป แต่ละเผ่ามีเส้นทางพิเศษของตัวเอง บางเส้นบรรจบกับเผ่าอื่น พระเจ้าแทรกแซงได้ด้วยพร skill คำสาป คำใบ้ (MVP) และการเสกของหรือเหตุการณ์ (MVP2)

ตัวละคร: [../character/README.md](../character/README.md) · การต่อสู้: [../combat/README.md](../combat/README.md) · NPC: [../npcs/README.md](../npcs/README.md) · เหตุการณ์โลก: [../world-events.md](../world-events.md) · การใช้ LLM: [llm-ideas.md](llm-ideas.md)

## 1. ชิ้นส่วนของเส้นเรื่อง

| ชิ้น | ความหมาย | ตัวอย่าง |
| --- | --- | --- |
| **จุดกำเนิด** | ผลการสุ่มเกิดตาม [../character/01-origin.md](../character/01-origin.md) ซึ่งเปิดเส้นแรก | เกิดเป็นแวมไพร์ในเมืองมนุษย์ |
| **พิธีของเผ่า** | เหตุการณ์ที่ทุกคนในเผ่าต้องผ่าน แต่ละเผ่าไม่เหมือนกัน | การทดสอบนาคา การเลือกปีกของเผ่าปีก |
| **ทางแยก** | เหตุการณ์ที่มีทางเลือก ก) ข) ค) พร้อมร้อยละ ตัวละครเลือกตามนิสัย | ยอมรับมงกุฎกระดูกหรือหนี |
| **เหตุการณ์โลก** | หนึ่งใน 194 เหตุการณ์ที่เกิดในทวีปที่ตัวละครอยู่ | ฟ้าถล่ม หมอกกินคน |
| **จุดบรรจบ** | เหตุการณ์ที่หลายเผ่าเดินมาพบกันได้ | สภาเก้าทวีป สงครามฟอร์เทีย ภารกิจเมฆา |
| **ศึก** | จุดที่เข้าระบบต่อสู้ ([../combat/README.md](../combat/README.md)) | หมาป่าบุกหมู่บ้าน ดวลกับคู่แข่ง |
| **หน้าต่างพระเจ้า** | จุดที่การแทรกแซงของพระเจ้ามีผลมากที่สุด | ก่อนพิธีของเผ่า ระหว่างศึกใหญ่ |
| **ปลายทาง** | จุดจบของชีวิตหนึ่งรอบ | ตายในศึก ปลดเกษียณ กลายเป็นตำนาน |

## 2. ช่วงชีวิต

ใช้อายุเทียบมนุษย์ (`hAge`) ของโค้ดเดิม ซึ่งปรับตามอายุขัยของเผ่า เผ่าอายุยืนจึงมีช่วงชีวิตจริงยาวกว่าแต่ผ่านช่วงเท่ากัน

| ช่วง | อายุเทียบมนุษย์ | ลักษณะ |
| --- | --- | --- |
| ทารก | 0–3 | ผลของจุดกำเนิด เหตุการณ์ครอบครัว |
| เด็ก | 4–12 | สัตว์คู่หูครั้งแรก การรังแก การเรียน |
| วัยรุ่น | 13–19 | พิธีของเผ่า ความถนัดแรก รักแรก |
| ผู้ใหญ่ | 20–54 | อาชีพ ศึก เหตุการณ์โลก NPC สำคัญ อาชีพลับ |
| ผู้เฒ่า | 55 ขึ้นไป | มรดก ลูกศิษย์ ปลดเกษียณ ตำนาน |

## 3. รหัสในไฟล์เผ่า

รหัสโหนดของเส้นเรื่องใช้ตัวพิมพ์เล็ก รูปแบบ `<เผ่า>.<ช่วง><ลำดับ>` เพื่อไม่ชนกับรหัสประเทศและเหตุการณ์

| เผ่า | รหัส | เผ่า | รหัส | เผ่า | รหัส |
| --- | --- | --- | --- | --- | --- |
| มนุษย์ | hu | นาคา | na | เผ่าปีก | wi |
| เอลฟ์ | el | เผ่ามังกร | dk | ยักษ์ | gi |
| ดาร์กเอลฟ์ | de | แวมไพร์ | va | เผ่าลาวา | la |
| คนแคระ | dw | ภูตพราย | fa | ลูกผสมจักรกล | co |
| ออร์ค | or | สไลม์ | sl | หุ่นวิญญาณ | so |
| ฮาล์ฟลิง | ha | เผ่าปีศาจ | dm | มัมมี่ | mu |
| เผ่าสัตว์ | be | เงือก | me | กูล | gh |

ช่วงในรหัส: `b` ทารกและเด็ก · `t` วัยรุ่น · `a` ผู้ใหญ่ · `e` ผู้เฒ่า · `x` จุดบรรจบ เช่น `va.t2` คือโหนดที่สองของวัยรุ่นแวมไพร์ จุดบรรจบใช้รหัสร่วม `cv.<ลำดับ>`

## 4. แม่แบบไฟล์ของแต่ละเผ่า

1. ธีมและคำถามหลักของชีวิตเผ่านี้
2. จุดกำเนิด: เกิดในถิ่นหลัก พลัดถิ่น นอกถิ่น ลูกครึ่ง
3. พิธีของเผ่า
4. โหนดของแต่ละช่วงชีวิต: เงื่อนไข ทางเลือกและร้อยละ ผล (ค่าสถานะ พร คำสาป skill อาชีพ สัตว์คู่หู) ศึก NPC ที่เกี่ยว เหตุการณ์โลกที่เปิดหรือตัด
5. จุดบรรจบกับเผ่าอื่น
6. ปลายทาง
7. หน้าต่างพระเจ้าที่สำคัญ
8. การตรวจความสอดคล้องกับเหตุการณ์โลกและ NPC

## 5. ความเป็นไปได้ทั้งหมด

นับแบบอนุรักษ์นิยม (ตัดเส้นที่เกิดไม่ได้แล้ว) ต่อชีวิตหนึ่งรอบ

| ตัวแปร | จำนวนแบบ |
| --- | --- |
| เผ่า | 21 (+ ลูกครึ่ง 40 คู่) |
| ถิ่นเกิด | เฉลี่ย 6 ประเทศต่อเผ่า × ถิ่นหลัก พลัดถิ่น นอกถิ่น |
| ดวงวันเกิด | 4 เวลา × 5 ดวง = 20 |
| นิสัย 3 จาก 56 | ประมาณ 27,000 ชุด (หักคู่ที่ขัดกัน) |
| อาชีพ | 143 |
| โหนดเส้นเรื่องของเผ่า | ประมาณ 14 โหนด × 3 ทางเลือก = 3^14 ≈ 4.8 ล้าน |
| สถานะโลก | ยุค 5 × มังกรที่ยังอยู่ 2^15 × เหตุการณ์ใหญ่ที่เกิดแล้ว |
| การแทรกแซงของพระเจ้า | พร 192 · คำสาป 146 · skill 255 · คำใบ้ ในเวลาใดก็ได้ |

เฉพาะโหนดเส้นเรื่องของเผ่าเดียวก็เกินล้านแบบ เมื่อคูณกับถิ่น อาชีพ และการแทรกแซง ความเป็นไปได้มีมากกว่าหลักพันล้านล้าน

## 6. หลักความสอดคล้อง

1. เส้นเรื่องของตัวละครต้องไม่ขัดกับเหตุการณ์โลกที่เกิดแล้ว (ใช้กติกาที่ยึดของ [../branches/README.md](../branches/README.md))
2. NPC ที่ตายแล้วไม่ปรากฏ แต่เส้นสืบทอดของ NPC ปรากฏได้
3. ข้อจำกัดของเผ่า เพศ และสถาบัน ([../character/01-origin.md](../character/01-origin.md) หัวข้อ 7) ใช้กับทุกโหนด
4. โหนดที่ใช้การต่อสู้อ้างศัตรูจาก [../combat/03-enemies.md](../combat/03-enemies.md) เท่านั้น
5. การแทรกแซงของพระเจ้าไม่ลบเหตุการณ์ที่เกิดไปแล้ว แต่เปลี่ยนน้ำหนักของสิ่งที่จะเกิด
