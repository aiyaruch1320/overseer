## 1. ใครเป็นทายาท

**เผ่าของลูก** ใช้ตารางลูกของลูกครึ่งใน [../character/01-origin.md](../character/01-origin.md) หัวข้อ 4 ผู้ปกครองลูกครึ่งและผู้ปกครองเผ่าเต็มต่างกันดังนี้

| ผู้ปกครองสองคน | ลูกเป็น |
| --- | --- |
| เผ่าเดียวกัน | เผ่านั้นเต็ม |
| ต่างเผ่า และคู่นั้นมีในตารางคู่ที่เป็นไปได้ | ลูกครึ่ง เผ่าหลักคือเผ่าของผู้ปกครองที่เลี้ยง (50/50 ถ้าเลี้ยงร่วมกัน) |
| ต่างเผ่า และคู่นั้นไม่มีในตาราง (สไลม์ ลูกผสมจักรกล หุ่นวิญญาณ มัมมี่ กูล หรือคู่ที่ตารางไม่รับ) | เผ่าของผู้ปกครองที่ให้กำเนิดได้ ถ้าทั้งคู่ให้ได้ใช้เผ่าของผู้ที่เลี้ยง |
| ผู้ปกครองคนหนึ่งเป็นลูกครึ่ง | ตามตารางลูกของลูกครึ่ง |

**การเลือกทายาท**

| กรณี | กติกา |
| --- | --- |
| ลูกที่ยังมีชีวิตหลายคน | ผู้เล่นเลือกหนึ่งคน ถ้าไม่เลือกก่อนตัวละครตาย ใช้คนโต |
| ลูกบุญธรรม | เป็นทายาทได้ ได้ของและความสัมพันธ์ ไม่ได้พรสายเลือดและคำสาปสืบสาย |
| ลูกเสียชีวิตหมด | หาผู้สืบเรื่องตามหัวข้อ 6 |
| ทายาทอายุต่ำกว่า 13 ตอนรับช่วง | ผ่านช่วงผู้ปกครองแทน (hr.b1 hr.b2) ผู้เล่นยังเห็นชีวิตตามปกติ แต่ตัวละครตัดสินเองไม่ได้ |
| ทายาทอายุเกิน 50 ตอนรับช่วง | ข้ามไป hr.e1 และได้ของกับเรื่องค้างครบ |

**นิสัยของทายาท** สุ่มนิสัยสามอย่างตามเผ่า โดยหนึ่งในสามเลือกจากนิสัยของผู้ปกครองที่เลี้ยง (คนละอย่างกับที่ได้จากดวง)

## 3. อาวุธผูกเจ้าของ

อาวุธระดับ E และ L ของอาชีพลับและอาชีพพิเศษมีความสามารถ "ผูกเจ้าของ" ([../items/README.md](../items/README.md) หัวข้อ 1) เมื่อส่งต่อให้ทายาท

| ส่วนของอาวุธ | ผล |
| --- | --- |
| พลังและค่าสถานะของอาวุธ | ใช้ได้ทันที |
| ความสามารถที่ไม่ผูกเจ้าของ | ใช้ได้ทันที |
| ความสามารถ "ผูกเจ้าของ" | หยุดไว้จนทายาท **ถูกยอมรับ** |

ทายาทถูกยอมรับเมื่อเกิดข้อใดข้อหนึ่ง

- ปิดเรื่องค้างที่ผูกกับอาวุธนั้น (ที่มาของอาวุธในไฟล์ [../items/05-job-weapons-secret-special.md](../items/05-job-weapons-secret-special.md) หรือ [../items/08-legendary.md](../items/08-legendary.md))
- ใช้อาวุธนั้นชนะศึกระดับหัวหน้าขึ้นไปสามครั้ง
- เข้าอาชีพเดียวกับที่อาวุธผูกไว้

อาวุธตำนาน (L) ที่ต้อง "ไปคืนที่เดิม" ตามไฟล์ 08 ให้ทายาทรับสืบเป็นเรื่องค้างก่อน ถ้าผู้ปกครองยังไม่ได้คืน

อาวุธที่สั่งตีค้าง (`chain_forge_wait` ใน [../items/10-forging.md](../items/10-forging.md) หัวข้อ 7) ส่งต่อเป็นใบสั่งให้ทายาท ช่างที่ยังมีชีวิตทำต่อ มัดจำไม่คืน ถ้าช่างตายก่อน ใบสั่งกลายเป็นเรื่องค้างชนิดสัญญา

## 4. ไม่ส่งต่อ

| สิ่ง | เหตุ |
| --- | --- |
| อาชีพทุกชนิด | ทายาทเลือกอาชีพเองตามกติกาของ [../character/08-jobs-overview.md](../character/08-jobs-overview.md) อาชีพลับและพิเศษที่ผูกที่ยึดปิดตามกติกาเดิม |
| ตรามังกร (`nb_mark_*`) | การทดสอบของมังกรเป็นเรื่องส่วนตัว ทายาทต้องผ่านเอง |
| พรระดับ R E L | ไม่ใช่พรสายเลือด |
| อาชีพที่ผูกกับบุคคลแต่งตั้ง | ต้องแต่งตั้งใหม่ |
| ตัวนับการแทรกแซงเกินครึ่ง | ดูหัวข้อ 5 |

**ภาษีรุ่น** กันตระกูลแข็งแกร่งขึ้นไม่รู้จบ

| รุ่น | ผล |
| --- | --- |
| 2 ถึง 3 | ใช้ตัวเลขหัวข้อ 2 เต็ม |
| 4 ถึง 5 | ค่าสถานะที่ส่งต่อเป็น +0 · ทองส่งต่อ 60% · พรสายเลือด 10% |
| 6 ขึ้นไป | ทองส่งต่อ 50% · ชื่อเสียงส่งต่อ 1 ใน 4 · พรสายเลือดไม่ส่งต่อ · เลือดเผ่าที่สองในลูกครึ่งเจือจางเป็นเผ่าหลักเต็มตามตารางลูกของลูกครึ่ง |

สิ่งที่ไม่ลดตามรุ่นคือ **เรื่องค้าง** และ **แค้นกับบุญคุณ** เพราะเป็นเนื้อเรื่อง ไม่ใช่กำลัง

## 5. พระเจ้ากับตระกูล

ตัวนับของพระเจ้าในโค้ดล้างทุกรุ่น (`powerSwitches` `lifeStats` `karmaLife` ใน `continueAsHeir`) ข้อเสนอคือ

| เรื่อง | กติกา |
| --- | --- |
| แต้มศรัทธาที่เหลือ | ข้ามรุ่น 50% |
| พรสายเลือด | พรที่พระเจ้าให้ "ทั้งตระกูล" ราคาสามเท่าของพรเดี่ยว ส่งถึงทายาทแน่นอนหนึ่งรุ่น และด้วยโอกาส 60% ในรุ่นที่สอง 30% ในรุ่นที่สาม |
| คำสาปสืบสาย | ตามโค้ดเดิม พระเจ้าถอนได้ด้วยราคาสองเท่าของคำสาปเดี่ยว |
| คำใบ้ | เพิ่มคำใบ้ "ชี้ทายาท" (เลือกทายาทที่เหมาะกับเรื่องค้าง) และ "สางเรื่อง" (เรื่องค้างข้อแรกน้ำหนักทาง ก ×2) |
| กรรมสายตระกูล | `karmaLife` ล้างต่อชีวิต แต่ `meta.karma` สะสมต่อไปตามโค้ด |

ราคาจริงของแต่ละอย่างกำหนดเมื่อออกแบบระบบพลังของพระเจ้า

## 6. เมื่อตระกูลสิ้น

ตัวละครตายโดยไม่มีลูกที่ยังมีชีวิต เปิดลำดับหาผู้สืบเรื่อง

| ลำดับ | ผู้สืบ | ได้ | ไม่ได้ |
| --- | --- | --- | --- |
| 1 | ลูกบุญธรรมหรือศิษย์ที่ความสัมพันธ์เป็นอาจารย์ (`mentor`) ไว้ใจ ≥ 3 | ของ ที่มั่น ความสัมพันธ์ เรื่องค้างข้อเดียว | พรสายเลือด คำสาปสืบสาย |
| 2 | คู่ที่ยังมีชีวิต (`spouse` `lover`) | ของและเรื่องค้างครึ่งหนึ่ง | สายเลือด |
| 3 | NPC ที่ตัวละครเคยช่วยไว้ (บุญคุณ ≥ 2) รับของที่ยกให้ | ของชิ้นเดียว | ที่เหลือ |
| 4 | ไม่มี | ตระกูลสิ้น | |

ตระกูลสิ้นแล้ว บันทึกลงบันทึกตำนาน (`codex`) ตามโค้ด ผู้เล่นเริ่มสายใหม่ด้วยแต้มกรรมสะสม และโลกเดินต่อ ตระกูลใหม่เกิดในโลกหลังเหตุการณ์ที่ตระกูลเก่าผ่านมา จึงไม่ซ้ำกับตระกูลเก่าโดยธรรมชาติ ([02-no-repeat.md](02-no-repeat.md) หัวข้อ 1)
