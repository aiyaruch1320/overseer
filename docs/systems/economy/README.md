## หลักสำคัญ

1. **ทองกลางหน่วยเดียว** ตัวเลขทองในเอกสารเดิมคงเดิม ราคาและรายได้เปลี่ยนตามประเทศ
2. **สามตัวชี้วัดต่อประเทศ** W (รวย) G (เหลื่อมล้ำ) M (ใช้เงินแค่ไหน) ผสมกับเพื่อนบ้านให้ใกล้กัน
3. **เกิดที่ไหนไม่เท่ากับรวย** ชนชั้นของครอบครัวสุ่มตาม W และ G ของเกิด ของที่ได้ตอนเกิดตามชนชั้นและ W
4. **ของที่ขาดเป็นแรงผลักดัน** ส่วนต่างราคาระหว่างประเทศทำให้การค้า การส่งของ การล่า เป็นทางหาเงินของคนที่เกิดจน
5. **ทุกทางที่ทองเข้ามีทางที่ทองออก** ค่าครองชีพ ภาษี ซื้อของ ซื้อยศ ล้มละลาย กันเงินล้น
