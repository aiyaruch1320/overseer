# ชั้นระบบ (systems): กติกาและข้อมูลที่เกมคำนวณ

ภาพรวม: [../README.md](../README.md) · วิธีจัดเอกสาร: [../guide/organization.md](../guide/organization.md)

ชั้นนี้ตอบว่า **เกมคำนวณอะไรอย่างไร** ทุกไฟล์เป็นตัวเลข สูตร เงื่อนไข ผล และตารางข้อมูลที่โค้ดหรือตัวจำลองอ่านได้ ไม่เล่าเรื่องยาว เรื่องราวของแต่ละสิ่งอยู่ที่ [../lore/](../lore/README.md) หน้าตาอยู่ที่ [../appearance/](../appearance/README.md)

## โฟลเดอร์

| โฟลเดอร์ | เนื้อหา | ใช้เมื่อ |
| --- | --- | --- |
| [character/](character/README.md) | ที่มา พร คำสาป สกิล อาชีพ สัตว์คู่หู และ [ค่าสถานะของเผ่า](character/races/README.md) | เขียนระบบตัวละคร |
| [travel/](travel/README.md) | การเดินทาง ตัวกรองจุดหมายตามเผ่าและศีลธรรม เหตุการณ์ระหว่างทาง เป้าการเจอต่างเผ่า |
| [combat/](combat/README.md) | แกนการต่อสู้ ตารางธาตุ ศัตรู การเผชิญหน้า รางวัล มังกรในศึก | เขียนระบบต่อสู้ |
| [items/](items/README.md) | อาวุธ 816 เกราะ เครื่องประดับ เครื่องราง ของใช้ วัสดุ การตี | เขียนระบบไอเทม |
| [economy/](economy/README.md) | เงิน ชนชั้น รายได้ การค้า การลงทุน ความมั่งคั่งของ 143 ประเทศ | เขียนระบบเศรษฐกิจ |
| [events/](events/README.md) | เหตุการณ์โลก 152 รายการ และเส้นทางแตกแขนงเมื่อมังกรล้มหรือทวีปเปลี่ยนรูป | เขียนระบบเหตุการณ์ |
| [simulation/](simulation/README.md) | ผลจำลองโลก อารมณ์มังกร | ปรับสมดุล |
| [experience/](experience/README.md) | ผู้เล่นเห็นและรู้สึกอะไรในหนึ่งชีวิต วงจรหลายชีวิต บทบาทระบบ | ตัดสินใจออกแบบ |

## สิ่งที่ไม่อยู่ในชั้นนี้

- ประวัติ ความสัมพันธ์ ปมเรื่อง → [../lore/](../lore/README.md)
- สี ทรง ท่า เอฟเฟกต์ ค่า UI → [../appearance/](../appearance/README.md)
- แคตตาล็อกที่สคริปต์สร้าง → [../_generated/](../_generated/README.md)

## กติกาของชั้นนี้

- ทุกค่าที่เกมใช้อยู่ในตาราง หนึ่งแถวหนึ่งรหัส ช่องเรียงเหมือนกันทุกไฟล์ในชุด
- ช่วงตัวเลขเขียนเป็น `ต่ำ–สูง` ตัวเลขที่ได้จากการจำลองบอกที่มา ([simulation/world-sim.md](simulation/world-sim.md))
- สคริปต์อ่านไฟล์เหล่านี้: `check-docs.mjs` ตรวจรหัสอ้างอิง `sim-world.mjs` จำลองโลกจาก [events/world-events.md](events/world-events.md) และ [character/races/README.md](character/races/README.md) ห้ามเปลี่ยนหัวตารางโดยไม่รันสคริปต์ซ้ำ
