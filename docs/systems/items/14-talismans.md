# เครื่องราง

ระบบ: [11-item-system.md](11-item-system.md) · เรื่องของเครื่องราง: [15-talisman-stories.md](15-talisman-stories.md) · มรดก: [../../lore/heirs/01-inheritance.md](../../lore/heirs/01-inheritance.md)

เครื่องรางถือได้หนึ่งชิ้นต่อช่อง มีสองกลุ่ม

- **เครื่องรางโบราณ (24)** มี **ผู้สถิต** คือวิญญาณหรือความทรงจำที่อยู่ในของชิ้นนั้น ให้ผลดีที่เห็นชัดแต่มีราคา และอาจกลายเป็นเส้นเรื่องพิเศษ เช่น ลางแรก การถูกสิง การขับไล่ การปรองดอง หรือการส่งต่อให้ทายาท ([15-talisman-stories.md](15-talisman-stories.md))
- **ของขลังพื้นบ้าน (24)** ไม่มีผู้สถิต ผลเล็กและไม่มีราคา เป็นของที่ชาวบ้านทำและส่งต่อ เหมาะกับตัวละครชีวิตช้า (`tm_f_` นำหน้ารหัส)
