## 3. การสวมอัตโนมัติ

ตัวละครสวมของหนึ่งช่องด้วยคะแนนสูงสุด คำนวณใหม่เมื่อได้ของใหม่และปีละครั้ง

```
คะแนน = ระดับ × 2 + ป้องกัน × 2 + ค่าสถานะที่ตรงกับอาชีพ − ค่าลบ + แท็กที่เข้ากับเรื่องราว (+1 ต่อแท็ก)
```

| ข้อ | กติกา |
| --- | --- |
| ภาระ | เกราะที่มี `spd` ติดลบ ลดน้ำหนักการหนีและความเร็วเดินทางตามค่าลบ |
| ห้ามสวม | ของที่ผิดเงื่อนไข เช่น เสื้อคลุมเวทกับยักษ์ตัวใหญ่เกินขนาดมาตรฐาน หรือเครื่องรางที่นิสัยของตัวละครปฏิเสธ (`skeptic` ปฏิเสธเครื่องรางระดับ E ขึ้นไป 50%) |
| ติดตัว | เครื่องรางและของสำคัญที่ผูกเลือดหรือถูกสาป ถอดไม่ได้จนกว่าจะแก้ ([15-talisman-stories.md](15-talisman-stories.md)) |
| ความต่างจากพระเจ้า | การที่พระเจ้าสั่งให้สวมหรือถอดกำหนดทีหลัง ตอนนี้ตัวละครตัดสินเองทั้งหมด |

## 4. เกราะกับการต่อสู้

เสนอเพิ่มในตาราง "ตัวคูณลดความเสียหาย" ของ [../combat/01-core.md](../combat/01-core.md) หัวข้อ 5

| ตัวคูณ | ค่า |
| --- | --- |
| เกราะป้องกัน N | ×(1 − 0.04 × N) เช่น ป้องกัน 3 ได้ ×0.88 · ป้องกัน 6 ได้ ×0.76 |
| โล่ในท่าตั้งรับ | ตัวคูณตั้งรับ ×0.5 ลดอีก 0.05 ต่อ 1 ป้องกันของโล่ (โล่ป้องกัน 3 ได้ ×0.35) |
| เพดานรวม | ตัวคูณรวมหลังคูณทุกอย่างไม่ต่ำกว่า ×0.35 |
| แท็กธาตุ | `#fire_res` `#cold_res` `#heat_res` `#poison_res` `#plague_res` ใช้ตารางธาตุที่ตัวละครทนเดิม (×0.5) ไม่ซ้อนกับของเดิม |

เกราะสึกเมื่อแพ้ศึก: ป้องกัน −1 ต่อการแพ้สามครั้ง (ต่ำสุด 0) ช่างซ่อมกลับคืนได้ที่ราคา 20% ของราคาตีสั่ง ระดับ E และ L ไม่สึก เครื่องประดับและเครื่องรางไม่สึก

## 5. ของใช้ในศึก

ตัวละครมีกระเป๋า 3 ช่อง ใช้ตามนิสัยในศึกหรือหลังศึก

| นิสัย | ใช้เมื่อ |
| --- | --- |
| `coward` `paranoid` | ใช้ยารักษาเมื่อ hp ต่ำกว่า 60% ใช้ของป้องกันตั้งแต่เริ่มศึก |
| `reckless` `bloodlust` | ไม่ใช้ยาจนต่ำกว่า 25% ใช้ระเบิดก่อน |
| `calm` `pragmatic` | ใช้ยาที่ 40% ใช้ของตามศัตรู (ธาตุที่แพ้) |
| `greedy` | เก็บของใช้ไว้ขาย ใช้เมื่อ hp ต่ำกว่า 30% เท่านั้น |
| `generous` `kind` | แบ่งยาให้พวกพ้องก่อนตัวเอง |
| `glutton` | กินอาหารศึกทันทีที่ได้ ไม่ใช่เก็บไว้ |

## 6. เครื่องมือชีวิตช้า

ตัวละครที่ทำอาชีพชีวิตช้า (14 อาชีพใน [../character/08-jobs-overview.md](../character/08-jobs-overview.md) หัวข้อ 4) หรืออาชีพงานฝีมือถือเครื่องมือประจำอาชีพได้สี่ชิ้น

```
ผลผลิตประจำปี = ฐานของอาชีพ × (1 + โบนัสเครื่องมือรวม) × ผลฤดู
```

| ข้อ | กติกา |
| --- | --- |
| โบนัสเครื่องมือรวม | ผลรวมของเครื่องมือที่ใช้ ไม่เกิน +50% |
| เครื่องมือผิดชนิด | ไม่ให้ผล (จอบไม่ช่วยร้านน้ำชา) |
| เครื่องมือชำรุด | สึกตามปีที่ใช้ (C 15 ปี · U 25 ปี · R 40 ปี) ซ่อมที่ช่างงานไม้หรือช่างตี |
| คุณภาพของผลผลิต | ระดับเครื่องมือ R ขึ้นไปเพิ่มโอกาสได้ของชั้นดี (ส่งขายราคาสูงหรือส่งเป็นของขวัญบุญคุณ) |
| เหตุการณ์ใหญ่ | ที่ดินที่เสียหาย (CT-08 ตั๊กแตน DR-04 เถ้า) ทำให้โบนัสเครื่องมือหายสองฤดู ไม่ทำให้เครื่องมือหาย |
| ทายาท | เครื่องมือส่งต่อไปพร้อมที่ดินและที่มั่น ([../../lore/heirs/01-inheritance.md](../../lore/heirs/01-inheritance.md) หัวข้อ 2) เครื่องมือระดับ E เป็นของประจำตระกูล |

## 9. ความสอดคล้อง

- เกราะป้องกันสูงสุดที่ระดับ L (6) ได้ ×0.76 เมื่อรวมกับตั้งรับและ `#guard` ตัวคูณรวมไม่ต่ำกว่า ×0.35 จึงไม่ทำให้ตัวละครไม่เจ็บเลย
- ทองในเกม (ค่ามัธยฐานที่อายุ 30 เท่ากับ 219 ตาม [../../../RAW_PLAN.md](../../../RAW_PLAN.md) หัวข้อ 3.2) จึงตั้งราคาเกราะ C U R ในหัวข้อเศรษฐกิจตามระดับเดียวกับอาวุธ (C 15 · U 50 · R 250 · E 800) ราคาจริงของไอเทมแต่ละหมวดอยู่ใน [../economy/04-income-and-living.md](../economy/04-income-and-living.md) หัวข้อ 7 ไม่ใส่ในไฟล์นี้
- ไอเทมทุกอย่างมีที่มาในโลก (ประเทศ วัสดุ เหตุการณ์) ที่ตรวจสอบกับเอกสารประเทศ NPC และเหตุการณ์ได้
