# โลกข้ามชีวิต

ภาพรวม: [README.md](README.md) · ตอนจบ: [03-ending-and-collection.md](03-ending-and-collection.md) · ทายาท: [../../lore/heirs/README.md](../../lore/heirs/README.md) · ยุคของโลก: [../../lore/world/story-continents.md](../../lore/world/story-continents.md) หัวข้อ 3.5

ไฟล์นี้บอกทางเลือกของวิธีที่โลกสืบต่อและเวลาของโลก ทั้งสองเรื่องยังไม่ตัดสิน ผลต่อประสบการณ์ต่างกัน

## 1. สามแบบ

| แบบ | วิธี | ประสบการณ์ | ความเสี่ยง |
| --- | --- | --- | --- |
| รอบเดี่ยว | ทุกรอบสร้างโลกใหม่จากเมล็ดสุ่ม ชีวิตจบ รอบจบ | เริ่มเล่นได้เร็ว เทียบชีวิตจากเมล็ดเดียวกันง่าย แชร์ง่าย | โลกไม่มีเรื่องยาว ผู้เล่นไม่เห็นว่าชีวิตก่อนหน้ามีผลต่อโลก |
| แคมเปญ | หนึ่งโลกมีหลายชีวิตต่อกัน (ทายาทหรือคนอื่นในโลกเดียวกัน) โลกจบเมื่อถึงฉากจบ เช่น มังกรล้มครบ 15 ตัวหรือผนึกถาวร | ชีวิตก่อนหน้าทำให้มังกรตัวที่สามล้มจริง เรื่องใหญ่ของโลกเดินด้วยมือของผู้เล่น | เริ่มเล่นช้ากว่า ต้องกำหนดกติกาเวลาของโลกให้ชัด ผู้เล่นที่แพ้ชีวิตแรกอาจรู้สึกว่าโลกเสียแล้ว |
| ผสม | เริ่มแบบรอบเดี่ยวเพื่อเรียนรู้ แล้วเปิดแคมเปญเมื่อผู้เล่นจบชีวิตแรกหรือเลือกเอง | ได้ข้อดีทั้งสองแบบ | ต้องทำสองโหมดให้ทำงานจากกติกาเดียวกัน |

สิ่งที่ต้องกำหนดไม่ว่าเลือกแบบใด ได้แก่ สิ่งที่คงข้ามชีวิต สิ่งที่โลกจำ และเวลาของโลก

## 2. สิ่งที่โลกจำ

เมื่อเล่นแบบแคมเปญหรือผสม สิ่งที่คงอยู่ในโลกหลังชีวิตจบ

| สิ่ง | ตัวอย่าง |
| --- | --- |
| ยุคและมังกร | จำนวนมังกรที่ล้ม ผู้ที่ยังอยู่ ([../../lore/dragons/README.md](../../lore/dragons/README.md)) |
| ประเทศ | ประเทศที่ล่ม ตั้งใหม่ หรือเปลี่ยนมือ |
| ร่องรอยของตัวละคร | ชื่อเสียงในถิ่น ตำนาน เรื่องค้างที่ยังไม่มีใครสะสาง ([../../lore/heirs/03-open-threads.md](../../lore/heirs/03-open-threads.md)) |
| ของ | อาวุธระดับตำนานและเครื่องรางโบราณที่เจ้าของตายแล้ว |
| NPC | ตัวที่ยังอยู่ ตัวที่ตาย ตัวที่แก่ลง |

## 3. เวลาของโลก

ตัดสินแล้ว ใช้นาฬิกาโลกที่แยกจากชีวิต โลกมีปีของตัวเอง (ศ.ม.) เดินต่อเนื่องไม่ว่าใครเป็นตัวละครหลัก ชีวิตของตัวละครใช้ปีชีวิต (อายุเทียบมนุษย์) ช่องว่างระหว่างชีวิตและรุ่นเป็นปีโลกจริง รายละเอียด ตารางอายุขัยของ 21 เผ่า และเส้นเวลาหลักราว 900 ปีโลกอยู่ใน [../../lore/world/world-time.md](../../lore/world/world-time.md)

ผลต่อประสบการณ์

- ชีวิตมนุษย์เห็นมังกรล้มเฉลี่ย 0.8 ตัว ชีวิตเอลฟ์ ยักษ์ แวมไพร์ มัมมี่ ดาร์กเอลฟ์ เห็นราวสี่ตัว ไม่มีเผ่าใดอยู่ได้ตลอดเส้นเวลา
- เผ่าอายุยืนไม่ได้ชีวิตยาวกว่าในเวลาที่เล่น เกมเดินตามอายุเทียบมนุษย์ แต่โลกเปลี่ยนไปมากกว่าในชีวิตเดียว
- แคมเปญของสายตระกูลมนุษย์ใช้ราว 30 รุ่นถึงจะเดินเส้นเวลาหลักหมด จึงต้องเลือกว่าเล่นหลายสายตระกูลในโลกเดียวหรือเล่นเฉพาะช่วง

## 4. เมื่อชีวิตจบในแคมเปญ

ผู้ใช้ตัดสินแล้ว: เมื่อตัวละครตาย โลกเดินต่อ ผู้เล่นในฐานะพระเจ้า **เลือกได้ว่าจะเฝ้ามองตัวหลักเดิมต่อ หรือไปเริ่มโลกใหม่เลย**

| ทางเลือก | ความหมาย |
| --- | --- |
| เฝ้ามองต่อ | ตามทายาทหรือผู้สืบของตัวละครเดิมตามกติกาใน [../../lore/heirs/README.md](../../lore/heirs/README.md) สายตระกูลเดิมต่อเนื่องในโลกเดิม |
| เริ่มโลกใหม่ | สร้างโลกใหม่จากเมล็ดใหม่ ตัวละครใหม่เกิดตามกติกาจุดเกิดของ [../../lore/world/world-time.md](../../lore/world/world-time.md) หัวข้อ 8.1 **โลกเดิมถูกทิ้งไปเลย** (ผู้ใช้ตัดสินแล้ว) เก็บแค่เมล็ดกับบันทึกชีวิตในหน้าตำนาน ([03-ending-and-collection.md](03-ending-and-collection.md) หัวข้อ 3) กลับไปเล่นโลกเดิมต่อจากจุดที่ทิ้งไม่ได้ ทำได้เพียงเปิดชีวิตซ้ำด้วยเมล็ดเดิมตามที่มีอยู่ |

**ผลของการตัดสิน** ไม่มีระบบเลือกตัวละครใหม่ในโลกเดิม จึงไม่ต้องมีรายชื่อผู้สมัคร ไม่ต้องมีระบบเสนอสามตัวเลือก และกติกาจุดเกิด 8.1 ใช้ได้ตรง ๆ กับโลกใหม่ทุกครั้ง ของที่คงข้ามรอบเป็นไปตามหัวข้อ 6 ของ [03-ending-and-collection.md](03-ending-and-collection.md) (หน้าตำนาน ของสะสม แบบเริ่มต้นที่ปลดล็อก) ไอเดียที่ไม่ได้ใช้: ให้ระบบเสนอสามตัวเลือกจากโลกเดิม เก็บไว้พิจารณาใน MVP2 ถ้าผู้เล่นอยากเปลี่ยนตัวละครโดยไม่ทิ้งโลก

ที่ยังไม่ตัดสิน: ถ้าโลกจบขณะผู้เล่นเฝ้ามองสายเดิมอยู่ ใช้หน้าสรุปโลกตาม [03-ending-and-collection.md](03-ending-and-collection.md) หัวข้อ 7 และจำนวนรุ่นที่ผู้เล่นเฝ้ามองต่อได้ในโลกเดียวไม่มีเพดาน โลกจบเมื่อถึงฉากจบ
