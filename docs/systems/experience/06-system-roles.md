# บทบาทของระบบต่อประสบการณ์

ภาพรวม: [README.md](README.md) · โครงชีวิต: [01-one-life.md](01-one-life.md) · ตะขอ: [02-hooks.md](02-hooks.md)

ไฟล์นี้จัดว่าสิ่งที่เขียนไว้แล้วแต่ละส่วนช่วยประสบการณ์ในไฟล์ชุดนี้อย่างไร ใช้ตัดสินลำดับทำเมื่อเวลาไม่พอ ไม่ได้บอกว่าส่วนไหนไม่ดี

| ระดับ | ความหมาย |
| --- | --- |
| แกน | ต้องมี ไม่งั้นประสบการณ์ในไฟล์ชุดนี้ไม่เกิด |
| เสริม | เพิ่มความหลากหลายและความลึก ทำหลังแกนนิ่ง |
| บรรยากาศ | ทำให้โลกเชื่อได้ ส่งผลเป็นข้อความเล่าหรือตัวเลขเบา ๆ ก็พอ |

| ส่วน | ระดับ | ช่วยประสบการณ์ข้อใด |
| --- | --- | --- |
| เส้นเรื่องของเผ่า (โหนด) | แกน | ชีวิตมีเรื่องและจุดเลี้ยว เป็นเนื้อของคำถามชีวิต |
| ชะตาและลางล่วงหน้า | แกน | คำถามของชีวิต ผู้ชมที่รู้ก่อน |
| คำอธิษฐานและศรัทธา | แกน | ตัวละครผูกกับพระเจ้า |
| ผู้คนที่เจอซ้ำ (ความสัมพันธ์ สัตว์คู่หู) | แกน | ผูกใจกับคนไม่กี่คน |
| เหตุการณ์โลกและมังกร ชุดเล็กก่อน | แกน | ฉากตระการตา โลกมีเรื่องของตัวเอง |
| บันทึกชีวิตและหน้าตำนาน | แกน | ตอนจบเป็นชิ้นงาน |
| จุดบรรจบ 16 จุด | แกน | ชีวิตเล็กแตะเรื่องใหญ่ |
| ทายาทและสมุดตระกูล | แกน | โลกจำได้ ร่องรอยข้ามรุ่น |
| ชนชั้นและทองตอนเกิด | แกน (แบบย่อ) | ฉากหลังของชีวิตและแรงผลักให้ออกผจญภัย |
| อาชีพลับและความลับ | เสริมสูง | เหตุผลเล่นซ้ำ ของสะสม |
| เครื่องรางโบราณและผู้สถิต | เสริมสูง | เรื่องแปลกที่เกิดจากของ |
| ลูกครึ่ง | เสริม | แบบเริ่มต้นและเรื่องใหม่ |
| ศึก | เสริม | ฉากที่ผู้เล่นลุ้น ผลบอกในเรื่อง ผู้เล่นไม่ควบคุมทีละท่า |
| เครื่องมือชีวิตช้า (ทำนา เย็บผ้า) | เสริม | ชีวิตเรียบที่เป็นแบบเริ่มต้นหนึ่งแบบ |
| ทาสและหนี้ผูกตัว | เสริม | เรื่องหนักของชนชั้นล่างและเหตุการณ์ในไม่กี่ประเทศ ออกแบบแบบเบา |
| การค้า ส่งของ คุ้มกัน | เสริม | ทางของคนเกิดจนที่ออกผจญภัย |
| อาวุธระดับตำนาน 36 ชิ้น | เสริม | ของสะสมและเรื่องของอาวุธ |
| อาวุธระดับอื่น เกราะ เครื่องประดับ | บรรยากาศ | ความรู้สึกถึงฐานะและความก้าวหน้า |
| ตลาดที่ราคาเปลี่ยนตามเวลา ต่อรอง การลงทุน | บรรยากาศ | ราคาคงที่ต่อประเทศบวกตัวปรับจากเหตุการณ์ให้ผลต่อเรื่องใกล้เคียงกัน ส่วนตลาดสดทำเมื่อตัวละครเลือกอาชีพการค้า |
| NPC 614 ตัว | บรรยากาศ | คลังตัวละครให้สุ่มเข้าชีวิต |

ลำดับการนำลงเกมที่เขียนไว้ในแต่ละโฟลเดอร์ ([../economy/08-implementation.md](../economy/08-implementation.md) [../combat/README.md](../combat/README.md) [../items/README.md](../items/README.md)) ใช้ตารางนี้ตัดสินว่าขั้นไหนทำก่อน
