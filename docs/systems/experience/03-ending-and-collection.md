# ตอนจบและของสะสม

ภาพรวม: [README.md](README.md) · ตะขอ: [02-hooks.md](02-hooks.md) · ทายาท: [../../lore/heirs/README.md](../../lore/heirs/README.md)

ตอนจบของชีวิตเป็นชิ้นงานที่ผู้เล่นอยากเก็บและเล่าต่อ ไม่ใช่หน้าจอ "คุณตายแล้ว"

## 1. บันทึกชีวิต

หลังฉากความตาย เกมแสดงบันทึกชีวิตหนึ่งหน้า

| ส่วน | เนื้อหา |
| --- | --- |
| หัว | ชื่อ เผ่า ถิ่นเกิด ชนชั้นตอนเกิด อายุที่ตาย สาเหตุ |
| คำถามของชีวิต | คำถามคืออะไร ได้คำตอบแบบไหน (สำเร็จ ล้มเหลว หรือกลายเป็นอย่างอื่น) |
| ช่วงเวลาที่เปลี่ยนชีวิต | สามถึงห้าเหตุการณ์ที่ทำให้ชีวิตเดินไปทางนี้ |
| ผู้คน | คนที่เจอซ้ำและเขาเป็นอย่างไรเมื่อตัวละครจากไป |
| ร่องรอยที่ทิ้งไว้ | ลูก ของที่ส่งต่อ เรื่องค้าง สิ่งที่โลกจำได้ |
| มือของพระเจ้า | แทรกแซงกี่ครั้ง ครั้งไหนเปลี่ยนชีวิตมากที่สุด |
| จารึก | ข้อความสั้นที่ LLM เขียนจากข้อมูลจริงของชีวิตนี้ |

กติกา LLM เขียนได้เฉพาะจารึกและถ้อยคำเล่า ข้อเท็จจริงทุกข้อมาจากบันทึกของเกม LLM แต่งชื่อคน ประเทศ หรือเหตุการณ์เองไม่ได้ ([../../lore/storylines/llm-ideas.md](../../lore/storylines/llm-ideas.md))

## 2. ผลของชีวิตต่อโลก

ทุกชีวิตจบด้วยระดับผลต่อโลกหนึ่งระดับ

| ระดับ | ความหมาย |
| --- | --- |
| ไม่ทิ้งรอย | ชีวิตธรรมดา ไม่มีใครจำ |
| รอยในถิ่น | เมืองหรือประเทศจำได้ |
| รอยในยุค | ชีวิตนี้ไปแตะเหตุการณ์ใหญ่ ผลจดอยู่ในประวัติของโลก |

ผลที่ชัดคือสิ่งที่ผู้เล่นอยากเห็นเมื่อกลับไปเปิดชีวิตเก่า

## 3. หน้าตำนาน

เก็บชีวิตที่ผ่านมาทุกชีวิตเป็นรายการ เปิดดูบันทึกชีวิตและการ์ดได้ เปิดชีวิตซ้ำด้วยเมล็ดเดิมเพื่อลองแทรกแซงอีกทางได้ ([02-hooks.md](02-hooks.md) ตะขอข้อ 5) ตำนานของตระกูลเรียงตามรุ่นเมื่อเล่นต่อเนื่อง

## 4. การ์ดแชร์

การ์ดสองแบบ การ์ดเกิด (เผ่า ถิ่น ครอบครัว ลาง) ที่ชวนให้เพื่อนลองเมล็ดเดียวกัน และการ์ดจบ (บันทึกชีวิตย่อ) เมล็ดเดียวกันให้ชีวิตเริ่มต้นเดียวกัน ผู้เล่นเทียบกันได้ว่าใครพาชีวิตไปได้ไกลหรือต่างกว่า

## 5. ของสะสม

แสดงเป็นอัตราส่วนที่พบแล้วต่อทั้งหมด รายการที่ยังไม่พบเห็นเป็นเงา ไม่เปิดเผยว่าเกิดได้อย่างไร

| อาชีพลับ | 26 | [../character/10-jobs-secret.md](../character/10-jobs-secret.md) |

| แบบเริ่มต้น | ดู [04-start-modes.md](04-start-modes.md) | |

ตัวเลขความเป็นไปได้รวมของเส้นเรื่อง ([../../lore/storylines/README.md](../../lore/storylines/README.md) หัวข้อ 5) ใช้บอกขนาดของโลกได้ แต่ไม่ใช้เป็นเป้าสะสม เพราะผู้เล่นเก็บให้ครบไม่ได้

## 6. สิ่งที่คงข้ามรอบ

หน้าตำนาน ของสะสม และแบบเริ่มต้นที่ปลดล็อกคงอยู่ข้ามรอบเสมอ ส่วนที่เกี่ยวกับโลก (ยุค มังกรที่ล้ม ประเทศที่เปลี่ยน) ขึ้นกับวิธีสืบต่อของโลก ([05-world-across-lives.md](05-world-across-lives.md))

## 7. หน้าสรุปโลก

แสดงเมื่อโลกล่มสลาย (END-10 END-11 END-12) ขณะตัวละครยังมีชีวิต แล้วเกมจบ โลกล่มสลายหายาก ราว 8% ของโลก และ 0–1% ของชีวิตเจอ หน้านี้จึงเป็นฉากพิเศษ ไม่ใช่ปลายทางปกติ ([../../lore/world/world-time.md](../../lore/world/world-time.md) หัวข้อ 8) ถ้าตัวละครตายก่อนโลกจบ ใช้บันทึกชีวิตตามหัวข้อ 1 ตามเดิม โหมดที่โลกจบหลังชีวิตจบยังไม่ตัดสิน ([05-world-across-lives.md](05-world-across-lives.md))

| ส่วน | เนื้อหา |
| --- | --- |
| หัว | ฉากจบที่เกิด (END-10 ล่มสลายครั้งที่สอง · END-11 ยุคที่สอง · END-12 ผนึกถาวร) และปีโลกที่จบ |
| เวลา | จากจุดเริ่มของชีวิตนี้ถึงโลกจบกี่ปีโลก ผ่านกี่ยุค |
| มังกร | ล้มกี่ตัวจาก 15 ตัวไหนก่อนตัวไหนหลัง ตัวที่เหลือหรือผนึกแกน |
| ประเทศ | ที่ล่ม ตั้งใหม่ หรือเปลี่ยนมือ |
| กุญแจ | ใครถือกี่ชิ้นตอนจบ |
| เหตุการณ์ใหญ่ | จำนวนทั้งโลก และห้ารายการสำคัญที่สุดเรียงตามเวลา พร้อมระบุว่าตัวละครนี้เห็นหรือไม่ |
| ตัวละครของคุณ | บรรทัดเดียว อยู่ที่ไหนและทำอะไรอยู่วันที่โลกจบ แล้วตามด้วยบันทึกชีวิตย่อ |
| มือของพระเจ้า | แทรกแซงกี่ครั้ง ครั้งไหนเปลี่ยนโลกมากที่สุด (รายละเอียดตามระบบพระเจ้าที่ออกแบบทีหลัง) |
| ตำนานของโลก | ข้อความสั้นที่ LLM เขียนจากข้อมูลจริงของโลกนี้ |

กติกาเดียวกับบันทึกชีวิต LLM เขียนได้เฉพาะตำนานของโลกและถ้อยคำเล่า ข้อเท็จจริงทุกข้อมาจากบันทึกของเกม

**ที่จดไว้ทำใน MVP2** ฉากสั้นของตัวละครก่อนหน้านี้ เขียนตามฉากจบ 3 แบบและแยกเผ่าหรือปลายทาง ใช้แบบฉากใน `docs/appearance/` เป็นแม่แบบ
