# ผลการเล่นของ skill

ระบบ: [README.md](README.md) · รายชื่อ skill ในโค้ด: [../../_generated/character-catalog/aptitudes-skills.md](../../_generated/character-catalog/aptitudes-skills.md) · กติกาเผ่า: [03-synergy-rules.md](03-synergy-rules.md)

ในโค้ดปัจจุบัน skill แต่ละระดับให้ค่าสถานะ +1 +2 +3 ของสถานะหลักเท่านั้น ตารางนี้เพิ่ม **ผลการเล่น** ของแต่ละระดับ ผลสะสม (ระดับ 2 รวมผลระดับ 1 ด้วย) ค่าสถานะ +N ของโค้ดเดิมยังคงอยู่ ตัวเลข % คือหน่วยเทียบกับค่าพื้นฐานของการกระทำนั้น

## ความถนัดการต่อสู้

| ความถนัด | ระดับ 1 | ระดับ 2 | ระดับ 3 |
| --- | --- | --- | --- |
| ดาบ `sword` | ความเสียหายดาบ +10% | โจมตีซ้ำอีกครั้งในรอบเดียว 25% | ตัดเกราะ เพิกเฉยเกราะ 50% |
| ขวาน `axe` | ทำลายโล่ได้ | โจมตีศัตรูทุกตัวรอบตัว | ทำลายสิ่งกีดขวางที่เป็นไม้หรือหิน |
| หอก `spear` | ระยะโจมตีเพิ่ม โจมตีก่อนศัตรูระยะประชิด | แทงทะลุศัตรูสองตัวเรียงกัน | สังหารศัตรูตัวใหญ่ (เผ่ายักษ์ มังกร) ×1.5 |
| ธนู `bow` | ยิงแม่น +10% | ยิงสามดอกในรอบเดียว | ยิงจุดตายโอกาส 30% ได้ความเสียหาย ×2 |
| มีดสั้น `dagger` | โจมตีข้างหลัง ×2 | โจมตีสองครั้งต่อรอบ | สังหารทันที 20% ต่อศัตรูที่ไม่ทันระวัง |
| มวยมือเปล่า `unarmed` | หมัดไม่ต้องใช้อาวุธ ความเสียหายเท่าอาวุธเล็ก | ทำให้ศัตรูมึน 1 ตา 20% | ทลายเกราะหินและไม้ได้ด้วยมือเปล่า |
| โล่ `shield` | ลดความเสียหายที่รับ 10% | บล็อกโจมตีระยะไกลได้ 30% | ปกป้องผู้อื่นข้างตัว รับความเสียหายแทน |
| ค้อน `hammer` | ความเสียหายต่อเกราะ ×1.3 | สั่นพื้น ทำให้ศัตรูหน้าล้ม 20% | ทุบเปลี่ยนรูปอาวุธและโล่ศัตรู |
| แส้ `whip` | ดึงอาวุธ หรือกระชากศัตรูเข้ามา | มัดศัตรูหนึ่งตัวไว้ 2 ตา | พันธนาการหลายตัว ทำให้ชะงัก |
| หนังสติ๊ก `sling` | ยิงไกลและเงียบ | กระสุนเด้ง โจมตีสองเป้าหมาย | ยิงทะลุเกราะไม้ ฆ่าตัวใหญ่ด้วยหินเดียว (ผ่าน `luk`) |
| ขี่สัตว์ `mounted` | ขี่ม้าและสัตว์ใหญ่ได้ ความเร็วเดินทาง +30% | พุ่งชนศัตรู ความเสียหาย ×1.5 ในรอบแรก | ขี่สัตว์วิเศษ (ไวเวิร์น หมาป่าเงา) เดินทางข้ามภูมิประเทศได้ |

## ความถนัดเวท

| ความถนัด | ระดับ 1 | ระดับ 2 | ระดับ 3 |
| --- | --- | --- | --- |
| เวทไฟ `fire` | ลูกไฟ จุดไฟได้ | กำแพงเพลิง กั้นทางศัตรู | ไฟลามพื้นที่กว้าง ความเสียหาย ×2 ต่อพื้นที่ |
| เวทน้ำ `water` | ทำให้น้ำสะอาด ดับไฟเล็ก | คลื่นซัดศัตรูถอยหลัง | ควบคุมน้ำทั้งบ่อหรือลำธาร |
| เวทลม `wind` | ผลักลมเบา ๆ ชะลอลูกธนูศัตรู | พายุหมุน ลอยตัวได้สั้น ๆ | ไต้ฝุ่น ขับไล่เรือและค่ายศัตรูในรัศมีไกล |
| เวทดิน `earth` | ก้อนหินพุ่งใส่ศัตรู | หนามดิน สร้างกำแพงหินกั้นทาง | แผ่นดินแยก ทำให้ศัตรูล้มพื้นที่กว้าง |
| เวทน้ำแข็ง `ice` | หอกน้ำแข็ง ชะลอศัตรู | แช่แข็งพื้นที่ ศัตรูไถล | ยุคน้ำแข็งชั่วคราว ลดอุณหภูมิในเมือง |
| เวทสายฟ้า `lightning` | ประกายไฟฟ้า ช็อตศัตรู | โซ่สายฟ้าข้ามศัตรูสามตัว | อัสนีบาตลงจากฟ้า ความเสียหาย ×3 ต่อเป้าหมายเดียว |
| เวทแสง `light` | ส่องที่มืด ไล่ผีเบา ๆ | ศรแสง ความเสียหาย ×1.5 ต่อผู้ตาย | ตะวันพิพากษา ทำลายผีและปีศาจในรัศมี |
| เวทมืด `dark` | ลูกบอลเงา มองเห็นในที่มืด | ม่านราตรี ซ่อนกลุ่มจากสายตา | สุริยคราส ดับแสงทั้งเมืองชั่วคราว |
| เนโครแมนซี `necro` | ปลุกโครงกระดูกหนึ่งตัวสู้ให้ | กองทัพผีดิบ ควบคุมได้หกตัว | ราชันย์แห่งความตาย ควบคุมผู้ตายที่ไม่ใช่เผ่าเดียวกัน |
| เวทโลหิต `blood` | ดูดเลือดศัตรูฟื้นพลัง | หอกโลหิต แลกพลังชีวิตเป็นความเสียหาย | ทะเลเลือด ศัตรูทุกตัวในพื้นที่เสียเลือดทุกตา |
| เวทมายา `illusion` | ภาพลวงตา ล่อให้ศัตรูหลงทิศ | ร่างแยกมายา ศัตรูโจมตีผิดตัว 40% | โลกมายา ศัตรูติดในภาพลวงจนกว่าจะแก้ |
| อัญเชิญ `summon` | เรียกภูตเล็กหนึ่งตัว | สัญญากับภูตธาตุ เรียกเมื่อต้องการ | อัญเชิญเทพอสูร ทำศึกครั้งเดียวต่อปี |
| เวทรักษา `healing` | รักษาแผลเล็ก | ฟื้นฟูหมู่ รักษาทั้งกลุ่ม | ชุบชีวิต (ผู้ที่เพิ่งตายภายในวัน) ใช้ได้ครั้งเดียวต่อปี |
| อักษรรูน `rune` | สลักรูนป้องกันบนของ | รูนป้องกันเมือง กันของที่จุดไฟหรือยิงเข้ามา | รูนบรรพกาล เปิดและปิดผนึกโบราณได้ |
| เวทธรรมชาติ `nature` | พูดกับพืช สัตว์ได้ระดับต้น | เถาวัลย์พันธนาการศัตรู | ผืนป่าตื่น เรียกต้นไม้ช่วยรบ |
| เวทมิติ `space` | กล่องเก็บของมิติขนาดเล็ก | วาร์ประยะสั้น | เปิดประตูข้ามทวีปได้ (ใช้ครั้งเดียวต่อเดือน) |
| พยากรณ์ `divination` | ดูดวงรายวัน | นิมิตอนาคตระดับเหตุการณ์ใหญ่ | อ่านเส้นชะตา เห็นว่าเหตุการณ์ใดกำลังจะเกิดในทวีปตัวเอง |
| เล่นแร่แปรธาตุ `alchemy` | ปรุงยารักษาและยาพิษขั้นต้น | ยาพิษไร้สี ยาถอนพิษเฉพาะทาง | ศิลาอาถรรพ์ เปลี่ยนโลหะ ทำยาชุบชีวิตระดับเล็ก |
| สัญญาปีศาจ `contract` | ลงนามเลือด ทำสัญญาเล็ก | เรียกทาสปีศาจ ทำงานสามวัน | สัญญากับอสูรใหญ่ แลกพลังกับราคาที่แพง |
| ไสยศาสตร์ `curse` | ตุ๊กตาสาป ทำเรื่องซวยเล็ก | คุณไสยเข้าตัว ศัตรูได้คำสาปจำพวกระดับ C | มหาคำสาปเจ็ดชั่วโคตร สาปสายเลือดศัตรู (ผูกกับ `c_heircurse`) |

## ความถนัดงานช่างและชีวิต

| ความถนัด | ระดับ 1 | ระดับ 2 | ระดับ 3 |
| --- | --- | --- | --- |
| ตีเหล็ก `smithing` | ตีมีดและเครื่องมือ | ตีดาบชั้นดี ราคาขาย +50% | ตีอาวุธในตำนาน (ระดับ R ขึ้นไป) |
| ทำอาหาร `cooking` | อาหารเลี้ยงชีพ ได้ฟื้นเล็กน้อย | อาหารชาววัง ได้พรชั่วคราวจากอาหาร | อาหารที่ทำให้มังกรร้องไห้ ได้ความไว้ใจจาก NPC ผู้ทรงอำนาจ |
| เกษตรกรรม `farming` | ปลูกผัก ผลผลิต +10% | นาข้าวทองคำ ผลผลิต +50% | ผืนดินอุดมไม่สิ้นสุด ผลผลิตไม่ลดแม้ในปีฤดูหนาวเถ้า |
| ดนตรี `music` | ร้องเพลง ได้เงินทิป | ขลุ่ยสะกดใจ ทำให้คนสงบ | บทเพลงปลุกวีรชน ให้กำลังใจกลุ่ม (+20% ทุกค่า 1 ตา) |
| ค้าขาย `trade` | ต่อราคา ประหยัด 10% | กองคาราวาน กำไรจากการค้า +50% | เจ้าพ่อการค้าข้ามทวีป เปิดตลาดสินค้าหายากได้ |
| ลอบเร้น `stealth` | ย่องเบา ไม่ถูกจับเสียงฝีเท้า | หายตัวในเงา ซ่อนกลุ่มเล็ก | ไร้ตัวตน ไม่ถูกเห็นนอกจากผู้ที่มองหาเฉพาะ |
| แกะรอย `tracking` | อ่านรอยเท้า ตามสัตว์ได้ | ล่าสัตว์ใหญ่ ตามผู้คนได้ข้ามเมือง | ตามผู้ที่ซ่อนอย่างดีที่สุดได้ |
| ฝึกสัตว์ `taming` | เลี้ยงสัตว์เล็กได้ | ขี่ไวเวิร์น ฝึกสัตว์ปีก | สัญญากับสัตว์เทพ (หมาป่าเงา วาฬฟ้า) |
| เดินเรือ `sailing` | พายเรือ เดินเรือใกล้ฝั่ง | กัปตันเรือ ออกทะเลลึก | ผู้พิชิตเจ็ดคาบสมุทร ผ่านวังวนและพายุได้ |
| ความเป็นผู้นำ `leadership` | หัวหน้ากลุ่ม ผู้ติดตามภักดีขึ้น | แม่ทัพ กองทหารได้โบนัส +15% | ผู้นำแห่งยุค กลุ่มใหญ่ทำตามโดยไม่ต้องบังคับ |
| เสน่ห์ `charm` | ยิ้มหวาน ราคาที่ NPC ตั้งลดลง 5% | ปากหวานละลายใจ ได้ข้อมูลจาก NPC ง่ายขึ้น | เสน่ห์ล่มเมือง NPC สำคัญหลงรักหรือยอมเป็นพันธมิตร |
| วิชาการ `scholar` | อ่านออกเขียนได้ เข้าห้องสมุด | นักปราชญ์ เข้าถึงตำราเก่า | ผู้รู้แจ้งทุกศาสตร์ ปลดล็อกบันทึกต้องห้าม |
| ขุดแร่ `mining` | ขุดถ่านหิน ได้เงินเล็กน้อย | หาแร่มิธริล พบแร่หายาก | ผู้ปลุกหัวใจขุนเขา (อันตราย ผูกกับ PL-03) |
| กลืนกิน `absorb` | กลืนก้อนหิน ได้ความทนทานชั่วคราว | เลียนแบบร่างของศัตรูที่เพิ่งกลืน | ผู้ล่า (Predator) กลืนศัตรูแล้วได้ skill หนึ่งอย่างของมัน |
