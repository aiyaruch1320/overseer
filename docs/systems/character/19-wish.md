# สั่งตัวละคร

ระบบ: [README.md](README.md) · ลำดับการเกิด: [01-origin.md](01-origin.md) · แบบเริ่มต้น: [../experience/04-start-modes.md](../experience/04-start-modes.md) · ผู้แปล: [../llm/04-story.md](../llm/04-story.md) หัวข้อ 4 · ภาพ: [../../appearance/20-god-ui.md](../../appearance/20-god-ui.md) หัวข้อ 11

ผู้ใช้ขอ (2026-11-01): ผู้เล่นบอกว่าอยากได้ตัวละครหลักแบบไหน แล้วเกมจัดให้ ผู้เล่นพิมพ์เป็นภาษาธรรมดา (เช่น "อยากเป็นเด็กกำพร้าเผ่าสัตว์ที่โตมาในเมืองมนุษย์ แล้วอยากให้ชีวิตได้เดินทางไกล") เกมแปลเป็นใบคำขอ ตรวจว่าทำได้และไม่แรงเกิน แล้วให้ผู้เล่นเห็นก่อนเริ่ม

โค้ดเดิมมีงาน `setup` อยู่แล้ว (LLM อ่านคำขอแล้วเลือกเผ่า ภูมิอากาศ ศาสนา ทวีป นิสัย ความถนัด อาชีพ ดวง พรหนึ่งอย่าง และความเป็นขุนนาง จากแคตตาล็อก) ไฟล์นี้ขยายให้ครบกับเอกสาร เพิ่มงบ และทำให้ใช้ได้โดยไม่มี LLM

## 1. หลัก

| ข้อ | หลัก |
| --- | --- |
| 1 | **ขอได้ทุกอย่างที่ชีวิตเกิดมาเป็นได้** เผ่า ถิ่น ครอบครัว ฐานะ นิสัย ความถนัด ดวง |
| 2 | **ขออนาคตไม่ได้ ขอได้แค่แนวโน้ม** "อยากเป็นผู้กล้า" ไม่ได้ทำให้เป็นผู้กล้า แต่ให้คำถามของชีวิตและน้ำหนักที่พาไปทางนั้น ตัวละครยังตัดสินใจเอง (หลักของเกม) |
| 3 | **ของดีมีราคา** สิ่งที่ทำให้ชีวิตง่ายขึ้นใช้แต้มชะตา สิ่งที่ทำให้ชีวิตยากขึ้นคืนแต้ม (หัวข้อ 4) |
| 4 | **ผู้เล่นเห็นก่อนเริ่มเสมอ** อะไรได้ อะไรเป็นแนวโน้ม อะไรทำไม่ได้และเพราะอะไร อะไรยังสุ่ม |
| 5 | **ไม่มี LLM ก็สั่งได้** ตัวแปลคำพ้องของเกม และหน้าเลือกเอง |
| 6 | **ส่วนที่ไม่ได้ขอยังสุ่ม** ตามลำดับการเกิดใน [01-origin.md](01-origin.md) หัวข้อ 1 ชีวิตยังมีสิ่งที่ไม่คาดคิด |

## 2. ใบคำขอ

ผลของการแปลคือใบคำขอหนึ่งใบ มีสามส่วน

**ส่วนตายตัว** ถ้าขอและทำได้ ใช้ค่านี้แทนการสุ่มของขั้นนั้น

| ช่อง | ค่าที่เป็นไปได้ | ขั้นการเกิดที่แทน |
| --- | --- | --- |
| เผ่า | 21 เผ่า (ผู้ที่ตื่นหรือลุกตามขั้น 1ง) | 1 |
| กำเนิดพิเศษ | ผู้ถูกอัญเชิญ ผู้กลับชาติ (มนุษย์) · ตุ๊กตา (ลูกผสมจักรกล) | 1ข 1ค |
| ลูกครึ่ง | เผ่าที่สองตามคู่ที่เป็นไปได้ ([01-origin.md](01-origin.md) หัวข้อ 4) | 2 |
| เพศ | ตามเผ่า | 3 |
| ถิ่นเกิด | ประเทศ หรือทวีป หรือชนิดถิ่น (ถิ่นหลัก พลัดถิ่น นอกถิ่น) | 4 |
| ฐานะ | ชนชั้น 1 ถึง 5 หรือคำกว้าง (ยากจน ธรรมดา มั่งมี ขุนนาง) | 4ก |
| ครอบครัว | กำพร้า พ่อหรือแม่คนเดียว ลูกคนเดียว พี่น้องมาก | ครอบครัวในเหตุการณ์ทารก |
| ดวงวันเกิด | เวลาและดวง | 6 |
| ศาสนาของครอบครัว | ศาสนาที่มีในถิ่นนั้น | ศรัทธาของตัวละคร |

**ส่วนแนวโน้ม** ใส่น้ำหนัก ไม่ได้ตั้งค่า

| ช่อง | ผล |
| --- | --- |
| นิสัย (ไม่เกิน 3) | นิสัยที่ขอได้แน่นอนหนึ่งข้อ ที่เหลือน้ำหนัก ×3 ในการสุ่มนิสัย |
| ความถนัด (ไม่เกิน 2) | หนึ่งข้อได้แน่นอนที่ระดับต่ำสุด อีกข้อน้ำหนัก ×3 |
| อาชีพที่อยากเป็น | ข้อเสนออาชีพตอนบรรลุนิติภาวะ อาชีพนั้น ×3 อาชีพลับและพิเศษขอไม่ได้ ([08-jobs-overview.md](08-jobs-overview.md) หัวข้อ 1) |
| สัตว์คู่หู | โอกาสพบสัตว์ชนิดนั้นในวัยเด็ก ×3 |
| พรหนึ่งอย่าง | ระดับ C หรือ U เท่านั้น ใช้แต้มชะตา (หัวข้อ 4) |

**ส่วนเรื่อง** สิ่งที่ผู้เล่นอยากให้ชีวิตเป็น แปลงเป็นเครื่องมือของเกมที่มีอยู่

| คำขอแบบนี้ | แปลงเป็น |
| --- | --- |
| อยากเดินทาง อยากเห็นโลก | นิสัย `freedom` แนวโน้ม · คำปฏิญาณที่เสนอมี GV-04 · การเดินทาง ×1.5 สิบปีแรกของวัยผู้ใหญ่ |
| อยากมีความรัก (เศร้าหรือสุข) | คำปฏิญาณที่เสนอมี GV-06 · จังหวะชะตาเสนอชะตาโศกหรืออ่อนโยน ([../god/08-goals.md](../god/08-goals.md) หัวข้อ 5) |
| อยากล้างแค้น | คำถามของชีวิตแบบปมกำเนิดที่มีผู้ทำร้ายครอบครัว ([../experience/02-hooks.md](../experience/02-hooks.md) ตะขอข้อ 1) · คำปฏิญาณที่เสนอมี GV-07 GV-08 |
| อยากเป็นผู้กล้า อยากเป็นตำนาน | คำถามของชีวิตแบบภารกิจพระเจ้า · คำปฏิญาณที่เสนอมี GV-09 · ไม่การันตีอาชีพลับหรืออาวุธตำนาน |
| อยากเป็นคนธรรมดา ชีวิตเรียบ | แบบเริ่มต้นชีวิตเรียบ · คำปฏิญาณที่เสนอมี GV-10 |
| อยากเห็นมังกรล้ม อยากอยู่ตอนโลกจะจบ | จุดเกิดเอนไปยุคที่ขอตามกติกาจุดเกิด ([../../lore/world/world-time.md](../../lore/world/world-time.md) หัวข้อ 8.1) ไม่การันตีว่าเหตุการณ์จะเกิดในชีวิต |
| อยากเป็นจอมมาร | เผ่าปีศาจหรือลูกครึ่งปีศาจ · แบบเริ่มต้นจอมมารมือใหม่ · คำถามของชีวิตเรื่องมงกุฎกระดูก |
| ไม่อยากให้พระเจ้ายุ่ง | คำปฏิญาณที่เสนอมี GV-12 |

ส่วนเรื่องไม่ใช้แต้มชะตา เพราะไม่ได้ทำให้ชีวิตง่ายขึ้น แค่ชี้ว่าผู้เล่นอยากดูชีวิตแบบไหน

## 3. แปลอย่างไร

| ทาง | ใช้เมื่อ | ทำอย่างไร |
| --- | --- | --- |
| **ตัวแปลคำพ้อง** | เสมอ ก่อน LLM | ตารางคำพ้องของทุกค่าในแคตตาล็อก (เช่น "แวมไพร์" "ผีดูดเลือด" → `vampire` · "รวย" "ลูกเศรษฐี" → ชนชั้น 4 · "ทะเลทราย" → ทวีปซาฮารันหรือภูมิอากาศทะเลทราย) และรูปประโยคที่บอกส่วนเรื่อง ("อยาก...เดินทาง") ถ้าเข้าใจครบทุกส่วนของคำขอ ไม่ต้องถาม LLM |
| **ผู้แปล (LLM)** | ตัวแปลคำพ้องเข้าใจไม่ครบ | ส่งคำขอ (ไม่เกิน 300 ตัวอักษร) และแคตตาล็อก ใช้ tool call strict ทุกช่องต้องเป็นค่าใน `enum` หรือว่าง ได้ใบคำขอและคำบรรยายตัวละครหนึ่งถึงสองประโยค |
| **หน้าเลือกเอง** | ไม่มี LLM และตัวแปลคำพ้องเข้าใจน้อย | หน้าเดียวกับใบเกิด (หัวข้อ 5) ทุกช่องเลือกจากรายการได้ |

ตารางคำพ้องของทุกช่อง คำปฏิเสธ คำบอกระดับ คำสุ่ม กติกาเมื่อขอขัดกัน ลำดับการแปล และผลทดสอบ อยู่ใน [20-wish-synonyms.md](20-wish-synonyms.md) (ตัวทดสอบ `scripts/sim/sim-wish-parse.mjs`)

**ขอสิ่งที่ไม่มีในเกม** (อมตะ เก่งที่สุดในโลก มีพลังทุกธาตุ) ผู้แปลเลือกสิ่งที่ใกล้ที่สุดที่ทำได้ แล้วบอกในใบเกิดว่าเปลี่ยนเป็นอะไร (อมตะ → เผ่าอายุยืนที่ขอได้ เช่น แวมไพร์หรือเอลฟ์)

## 4. แต้มชะตา

ทุกคำขอมี 10 แต้ม ส่วนตายตัวและแนวโน้มบางอย่างใช้แต้ม สิ่งที่ทำให้ชีวิตยากคืนแต้ม

| สิ่งที่ขอ | แต้ม |
| --- | --- |
| เผ่าที่พบบ่อย (มนุษย์ ออร์ค ฮาล์ฟลิง เผ่าสัตว์ คนแคระ เอลฟ์) | 0 |
| เผ่าอื่น | 1 |
| เผ่าที่เกิดน้อยมาก (เผ่ามังกร แวมไพร์ หุ่นวิญญาณ มัมมี่) | 2 |
| กำเนิดพิเศษ (ผู้ถูกอัญเชิญ ผู้กลับชาติ) | 3 |
| ลูกครึ่ง | 1 |
| ถิ่นเกิดเป็นประเทศเจาะจง | 1 (ทวีปหรือชนิดถิ่น 0) |
| ชนชั้น 4 · ชนชั้น 5 | 2 · 4 |
| ชนชั้น 1 หรือกำพร้า | −2 (คืนแต้ม) |
| ดวงหายาก (ดาวหาง สุริยคราส) | 2 |
| นิสัยแน่นอน | 0 |
| ความถนัดแน่นอน | 1 ต่อข้อ |
| พร C · U | 2 · 4 |
| ขอคำสาปหนึ่งอย่าง (ชีวิตที่ยาก) | −2 |
| อยู่ถิ่นที่กำลังมีภัย (หมอกทึบ หลังมังกรล้ม สงคราม) | −1 |
| ส่วนเรื่อง | 0 |

**เกินงบ** ผู้แปลเก็บสิ่งที่ผู้เล่นพูดถึงก่อน (ลำดับในคำขอ) ตัดที่เหลือ และใบเกิดแสดงสิ่งที่ตัดพร้อมแต้มที่ขาด ผู้เล่นสลับได้เองในใบเกิด

**ไม่มีแบบใดแรงกว่าแบบอื่น** ([../experience/04-start-modes.md](../experience/04-start-modes.md)) งบ 10 แต้มทำให้ชีวิตที่สั่งไม่แรงกว่าชีวิตสุ่มมาก ค่าเฉลี่ยของชีวิตสุ่มใช้แต้มราว 2 (ประมาณจากสัดส่วนเผ่าและชนชั้น) ค่าเริ่มต้นนี้ยังไม่ได้ทดสอบ

## 5. ใบเกิด

หน้าที่ผู้เล่นเห็นก่อนเริ่ม

| ส่วน | แสดง |
| --- | --- |
| ได้แน่นอน | รายการที่ขอและทำได้ เครื่องหมายถูก |
| แนวโน้ม | รายการที่เป็นน้ำหนัก เครื่องหมายคลื่น พร้อมคำว่า "มีแนวโน้ม" |
| ทำไม่ได้ | รายการที่ทำไม่ได้หรือตัดเพราะงบ พร้อมเหตุผลหนึ่งบรรทัด และสิ่งที่ใช้แทน |
| ยังสุ่ม | ช่องที่ไม่ได้ขอ แสดงเป็นเครื่องหมายคำถาม |
| แต้มชะตา | ใช้ไปเท่าไร เหลือเท่าไร |
| คำบรรยาย | หนึ่งถึงสองประโยคว่าตัวละครนี้เป็นใคร (ผู้แปลหรือแม่แบบ) |
| คำปฏิญาณที่เสนอ | สามข้อ ถ่วงตามส่วนเรื่อง |
| ปุ่ม | เริ่มชีวิต · แก้ใบคำขอ (เปิดหน้าเลือกเอง) · สุ่มส่วนที่ยังสุ่มใหม่ |

## 6. หลังเริ่ม

- ใบคำขอ ผลการแปล และเมล็ดของชีวิต บันทึกลงเซฟ เล่นซ้ำใช้ใบคำขอที่บันทึก ไม่แปลใหม่
- การ์ดเกิด ([../experience/03-ending-and-collection.md](../experience/03-ending-and-collection.md) หัวข้อ 4) แสดงว่าชีวิตนี้ "ถูกสั่ง" ผู้ที่เปิดเมล็ดนี้ได้ใบคำขอเดียวกัน
- คำขอที่ทำไม่ได้ในโลกนี้ตอนนี้ (เช่น ขอเกิดในประเทศที่เป็นซากแล้ว) ใช้ถิ่นพลัดถิ่นของประเทศนั้นแทน และบอกในใบเกิด

## 7. ข้อมูลที่ต้องขยายในโค้ด

`setup` ตอนนี้คืนค่า เผ่า เพศ ภูมิอากาศ ศาสนา ทวีป นิสัย ความถนัด อาชีพ เวลาเกิด ดวง พร ขุนนาง และหมายเหตุ ต้องเพิ่มช่อง: เผ่าครบ 21 (แคตตาล็อกในโค้ดมี 14) กำเนิดพิเศษ เผ่าที่สอง ประเทศ ชนิดถิ่น ชนชั้น 1 ถึง 5 ครอบครัว คำสาปที่ขอ สัตว์คู่หู ส่วนเรื่อง (แท็ก) ยุคที่อยากเกิด และรายการที่ทำไม่ได้พร้อมเหตุผล
