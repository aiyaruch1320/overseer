### ค่าของลูกครึ่ง

- **เผ่าหลัก** คือเผ่าที่ผู้เล่นสุ่มได้ในขั้น 1 และ **เผ่าที่สอง** คือเผ่าที่ได้จากตารางด้านบน
- ค่าสถานะทั้ง 6 ค่าสุ่มแยกกัน แต่ละค่าโยนเหรียญ 50/50 ว่าใช้ช่วงของเผ่าหลักหรือเผ่าที่สอง แล้วสุ่มจากช่วงนั้น
- อายุขัยธรรมชาติสุ่มจากช่วงกลางของสองเผ่า (ค่ากลางของเผ่าหลัก บวกค่ากลางของเผ่าที่สอง หารสอง ± 15%)
- **แท็กเผ่า** (เช่น `#darkvision` `#weak_sun`) เผ่าหลักได้ครบ เผ่าที่สองได้แต่ละแท็ก 50% ยกเว้นแท็กอ่อนแอ (`#weak_*`) ที่ได้ 100% เสมอ
- **พรและคำสาปเฉพาะเผ่า** เลือกได้จากทั้งสองเผ่า ระดับ L ของเผ่าที่สองเข้ามาไม่ได้
- **นิสัย** ได้นิสัยเพิ่มหนึ่งอย่างจากรายการเสริมของเผ่าที่สอง
- **ถิ่นเกิด** ใช้ตารางถิ่นพบกันด้านล่าง (หัวข้อ ถิ่นเกิดและเหตุที่พ่อแม่พบกัน) ถ้าถิ่นนั้นรังเกียจลูกครึ่ง (ตารางด้านบน) มีโอกาส 40% ได้คำสาปผู้ถูกเนรเทศ `c_outcast` และ 25% ได้คำสาปไร้เพื่อนตลอดกาล `c_lonely`
- **เส้นเรื่อง** ลูกครึ่งเดินตามเส้นของเผ่าหลักและมีโหนดเพิ่มตาม [../../lore/storylines/22-halfblood.md](../../lore/storylines/22-halfblood.md)
- **การผสมที่ผิดธรรมชาติ** ลูกครึ่งของเผ่าที่สายเลือดขัดกัน (เช่น นาคาลูกครึ่งเงือกในยุคสงครามน้ำเก่า WR-20) มีโอกาส 20% ได้พร `nb_both_banks` ในไฟล์ [05-new-blessings.md](05-new-blessings.md) เพราะเป็นคนเดียวที่เดินข้ามทั้งสองฝั่งได้

### ลูกของลูกครึ่ง

ผู้ปกครองเป็นลูกครึ่งเผ่าหลัก A กับเผ่าที่สอง B และมีคู่ครองเผ่า P ลูกที่เกิดใช้ตารางนี้ (ใช้กับตัวละครหลักที่เป็นทายาทและกับ NPC)

| คู่ครอง | ลูกเป็น | หมายเหตุ |
| --- | --- | --- |
| P = A | เผ่า A เต็ม | เลือด B เจือจาง: ได้แท็กเผ่าจาก B หนึ่งแท็กด้วยโอกาส 25% (ไม่นับแท็ก `#weak_*`) ไม่ถูกนับเป็นลูกครึ่ง ถิ่นที่รังเกียจลูกครึ่งไม่ใช้กับลูก |
| P = B | เผ่า B เต็ม | เลือด A เจือจางแบบเดียวกัน |
| P = เผ่า C อื่น และมีคู่ C กับ A ในตารางคู่ที่เป็นไปได้ | ลูกครึ่ง เผ่าหลัก C เผ่าที่สอง A | สุ่มถิ่นเกิดและเหตุที่พ่อแม่พบกันตามตารางของคู่ C กับ A |
| P = เผ่า C อื่น และไม่มีคู่ C กับ A | เผ่า C เต็ม | เลือดของผู้ปกครองหายไป ตัวละครได้พร `nb_homeland_call` 10% |
| ผู้ปกครองสองคนเป็นลูกครึ่งทั้งคู่ | เผ่าหลักของผู้ปกครองที่เลี้ยงลูก | อีกเผ่าเป็นเลือดเจือจางตามแถวแรก |

## 5. เกิดนอกถิ่น และเรื่องที่ทิ้งไว้

ตัวละครที่เกิดนอกถิ่นหลักของเผ่า (พลัดถิ่นหรือนอกถิ่น) มี **สองสายเรื่อง** ที่ผูกกับเหตุการณ์ของโลก

| สายเรื่อง | ความหมาย | ผล |
| --- | --- | --- |
| **สายบ้านเกิดเผ่า** | เรื่องของถิ่นหลักของเผ่า (เหตุการณ์ในทวีปนั้น) | ไม่เข้ามาหาตัวละครเอง เข้ามาเป็น "ข่าวจากบ้านเก่า" ผ่านผู้เดินทาง พ่อค้า จดหมาย |
| **สายถิ่นที่อยู่** | เรื่องของประเทศและทวีปที่เกิดจริง | เหตุการณ์ในทวีปนี้กระทบตัวละครเต็มที่ |

กติกา

- เหตุการณ์ใน 194 รายการนับเป็นผลโดยตรงต่อตัวละครเฉพาะเมื่อตัวละครอยู่ในทวีปที่เหตุการณ์นั้นเกิด เหตุการณ์ของสายบ้านเกิดเผ่าให้ผลเป็นข่าวและตัวเลือกเดินทางกลับ
- ตัวละครที่เกิดนอกถิ่นได้นิสัย `homebody` หรือ `freedom` เพิ่มหนึ่งตัว (สุ่ม 50/50) และมีโอกาส 30% ได้พร `nb_homeland_call` ในไฟล์ [05-new-blessings.md](05-new-blessings.md)
- ถ้าถิ่นหลักของเผ่าหายไปแล้วก่อนตัวละครเกิด (เช่น อัซการ์หลัง DR-01) ตัวละครนับเป็น **ผู้ลี้ภัยรุ่นสอง** และสายบ้านเกิดเผ่าเปลี่ยนเป็นสายบ้านที่หายไป ผู้ที่เกิดนอกถิ่นก่อนเหตุการณ์จึงรอดจากการสูญเสียแผ่นดินโดยบังเอิญ
- เรื่องที่ทิ้งไว้ที่ประเทศอื่น: NPC ในถิ่นหลักที่เกี่ยวกับเผ่าของตัวละคร (เช่น ครอบครัว ผู้ปกครอง) มีโอกาสส่งข่าวมาหรือเดินทางมา ตามความสัมพันธ์ที่ตั้งตอนเกิด

### ข้อจำกัดของสถาบัน

ข้อจำกัดเป็นของ **สถาบัน** ไม่ใช่ของทั้งโลก เมื่อออกแบบอาชีพ (หลังจากไฟล์นี้) ให้ใช้ตารางนี้เป็นเงื่อนไขของอาชีพ ผู้ที่ไม่ผ่านเงื่อนไขหาทางอื่นได้ แต่มีราคา

| สถาบัน | ข้อจำกัด | ทางอื่นสำหรับผู้ไม่ผ่าน |
| --- | --- | --- |
| ศาสนจักรแห่งแสง (AL-02) | ตำแหน่ง **พระ** และสังฆราชบวชให้ชายเท่านั้น หญิงเป็น **ผู้รับใช้ศาสนจักร** ได้ (เช่น ผู้ดูแลวงเวท) และเป็นผู้พิพากษาศาลศาสนาได้ แต่บวชเป็นพระไม่ได้ | หญิงที่อยากเป็นพระออกไปขบวนการผู้ไม่ก้มหัว (GD-03) หรือเทพีแห่งจันทรา |
| เทพีแห่งจันทรา (SV-05 NB-03) | นักบวชหลักเป็นหญิงเท่านั้น ชายเป็นผู้พิทักษ์ (ถือดาบ ถือโคม) ไม่ใช่ผู้ประกอบพิธี | ชายที่อยากเป็นนักบวชไปสายศาสนาอื่น |
| ลัทธิบูชามังกร (AZ-01) | ผู้ปรนนิบัติที่ถวายตัวต่อมังกรเป็นเผ่าปีกเท่านั้น (เผ่าอื่นเป็นผู้ช่วยได้) | เผ่าอื่นที่อยากถวายตัวไปลัทธิอื่น |
| พญานาคราช (NR-07) | ผู้ผ่านการทดสอบเป็นนาคา มนุษย์ และเงือก (ไม่ใช่เผ่าสัตว์) | ผู้ไม่ผ่านกลายเป็นหินตามธรรมเนียม |
| ราชวงศ์ฟาโรห์ (SH-02) | บัลลังก์สืบตามสายเลือดฟาโรห์ ไม่จำกัดเพศ | ไม่มี |
| สภาช่างศึก นอคดรีน (MH-05) | ไม่จำกัดเพศ จำกัดเผ่าให้ผู้มีมือช่าง (โอเกอร์ ออร์คช่าง คนแคระ) | เผ่าอื่นเป็นผู้ช่วย |
| ไชร์ฮาล์ฟลิง (AL-16) | ไม่จำกัดเพศ | ไม่มี |
| ผู้ถือกุญแจน้ำตก (NR-02) | ผู้ถือเจ็ดคนมีที่นั่งตามเผ่า (นาคา เงือกปีก มนุษย์) ไม่จำกัดเพศ | ไม่มี |
| ผู้ฟังวิญญาณ (SV-13) | เอลฟ์ผู้เฒ่าเท่านั้น (ต้องมีอายุเกินร้อยแปดสิบปี) | เผ่าอื่นเป็นผู้ช่วย |
| ผู้เฝ้าประตูเมืองปฐม (NB-08) | ชาวหมอกหรือผีเมืองปฐม เท่านั้น | เผ่าอื่นเป็นผู้ช่วยภายนอกประตู |
| ตระกูลมารดาแห่งอิรมอร์ (KD-05) | ตำแหน่งมารดาสืบทางหญิงเท่านั้น | ชายเป็นที่ปรึกษาเงาหรือนักฆ่า |
