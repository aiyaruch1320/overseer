# กติกาเสริม ขัด และตรงข้าม

ระบบ: [README.md](README.md) · ความเข้ากับเผ่า: [02-race-affinity.md](02-race-affinity.md) · แท็ก: [../../_generated/character-catalog/tags.md](../../_generated/character-catalog/tags.md)

กติกาเขียนด้วย **แท็ก** (`#แท็ก` ของพร คำสาป นิสัย skill และแท็กเผ่า) ตัวละครมีแท็กรวมจากเผ่า นิสัย skill พร คำสาป และอาวุธ กติกาทุกข้อด้านล่างอ่านจากแท็กรวมนั้น ค่า × คือตัวคูณผลของฝ่ายที่ระบุ

## ข. ของที่ขัดกับร่างของตัวเอง

เมื่อตัวละครได้พรหรือ skill ที่ขัดกับเผ่า ผลเปลี่ยนเป็นพิเศษ ไม่ใช่ไม่ได้ผล ทุกข้อในหมวดนี้มีราคา (เป็นคนแปลกของเผ่า) ตาม SR-39

| ID | เงื่อนไข | ผล |
| --- | --- | --- |
| SR-20 | เผ่ามี `weak_light` และตัวละครมี `#light` หรือ `#holy` จากพรหรือ skill | **ลบ `weak_light` ทิ้ง** ได้ต้านเวทแสง (ความเสียหายจากแสง ×0.5) และเดินในแสงจ้าได้ แต่ถูกพวกเดียวกันเรียกว่าคนนอกรีต |
| SR-21 | เผ่ามี `weak_sun` และตัวละครมี `b_sunward` หรือ `#heat_res` | ลดเป็นอ่อนแรงในแสงแดด แทนการสลายเป็นผง (แวมไพร์ทนแดดครึ่งวันได้) |
| SR-22 | เผ่ามี `undead` และตัวละครมี `#heal` | รักษาตัวเองได้ครึ่งหนึ่ง และรักษาผู้อื่นสร้างความเจ็บปวดให้ผู้ตาย |
| SR-23 | เผ่ามี `infernal` (เผ่าปีศาจ) และตัวละครมี `#demon_bane` | ล่าปีศาจเผ่าเดียวกันได้ ×1.3 แต่เสีย `#infernal` ถูกลัทธิปีศาจหมายหัว |
| SR-24 | เผ่ามี `dragon_blood` และตัวละครมี `#dragon_bane` | พรทำให้ร่างขัดกัน ได้รับ `c_outcast` ทันที และถูกลัทธิบูชามังกรไม่ยอมรับ แต่มังกรรู้สึกถึงพรนี้เป็นคำสาป |
| SR-25 | เผ่ามี `flight` และตัวละครมี `c_vertigo` | ใช้ไม่ได้ ดู [02-race-affinity.md](02-race-affinity.md) ข้อ ค |
| SR-26 | เผ่ามี `water_breath` และตัวละครมี `c_hydrophobia` | เปลี่ยนเป็น `nc_fear_deep` |
| SR-27 | เผ่ามี `amorphous` (สไลม์) และตัวละครมีความถนัดดาบ ขวาน หอก | ใช้อาวุธได้โดยกลืนอาวุธเข้าตัว (ผลเท่าเดิม แต่ทิ้งอาวุธไม่ได้) |
| SR-28 | เผ่ามี `mechanical` และตัวละครมี `#heal` หรือ `b_regen` | ไม่ได้ผล ต้องซ่อมด้วยช่าง |
| SR-29 | เผ่ามี `dry` (มัมมี่) และตัวละครมี `#water` หรือ `b_waterwalk` | ร่างพองน้ำ ลดความสามารถทั้งหมด 20% ขณะเปียก |
| SR-30 | เผ่ามี `huge` และตัวละครมี `#stealth` | ซ่อนตัวได้เฉพาะในที่โล่งกว้าง (ภูเขา ทะเลทราย) ไม่มีผลในเมือง |
