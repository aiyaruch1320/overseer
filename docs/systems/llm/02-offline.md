# เล่นได้เต็มโดยไม่มี LLM

ระบบ: [README.md](README.md) · ค่าใช้จ่าย: [01-cost.md](01-cost.md) · ชื่อที่โลกจำ: [03-naming.md](03-naming.md) · สามชั้นของถ้อยคำ: [../god/05-llm.md](../god/05-llm.md) หัวข้อ 2

ผู้ใช้ตัดสินแล้ว (2026-11-01): เกมต้องไม่พึ่ง LLM ถ้าเชื่อมต่อไม่ได้หรือเครดิตหมด เกมเล่นต่อได้เหมือนเดิม LLM มีไว้เพิ่มความหลากหลายเท่านั้น

## 1. หลัก

| ข้อ | หลัก | ทำให้จริงอย่างไร |
| --- | --- | --- |
| 1 | **เกมที่ไม่มี LLM คือเกมเต็ม** ไม่ใช่เกมที่เสียบางส่วน | ทุกงานมีชั้น 0 (แม่แบบ) และชั้น 1 (คลัง) ที่ส่งไปกับตัวเกม |
| 2 | **ไม่มี LLM ก็ไม่ขาดอะไร** ทุกจุดที่ LLM มีส่วนมีทางของเกมเอง LLM เปลี่ยนตัวเลขได้เฉพาะผู้กำกับและผู้แปล ([04-story.md](04-story.md)) และทุกค่าที่ LLM ตอบบันทึกลงเซฟ | ไม่มี LLM ใช้น้ำหนักเดิมของเกม และหน้าเลือกเองแทนการพิมพ์ |
| 3 | **ผู้เล่นไม่ต้องรู้ว่า LLM หาย** ไม่มีหน้าต่างแจ้งข้อผิดพลาด ไม่มีปุ่มที่ใช้ไม่ได้ ไม่มีการรอ | ข้อความจากคลังขึ้นทันที ไอคอนขนนกเล็กมุมจอเป็นสีเทาเมื่อ LLM ไม่ทำงาน |
| 4 | **เล่นออฟไลน์ได้** | คลังและคลังคำอยู่ในตัวเกม ไม่ได้อยู่ที่เซิร์ฟเวอร์ |

## 2. อะไรอยู่ในตัวเกม

| ของ | ขนาดโดยประมาณ | ใช้ทำอะไร |
| --- | --- | --- |
| [แม่แบบชั้น 0](06-god-templates.md) | ไม่กี่ร้อยแม่แบบ น้อยกว่า 1 MB | ทุกงานมีอย่างน้อยหนึ่งแม่แบบต่อชนิดของสถานการณ์ |
| คลังชั้น 1 | ราว 1,500 บรรทัดใน 8 ชุด ([09-library.md](09-library.md) หัวข้อ 2) ราว 0.5 MB ก่อนบีบอัด | ถ้อยคำหลายแบบต่อชุดสถานะ เขียนโดย agent Claude Opus |
| คลังคำสำหรับชื่อ | ไม่กี่พันคำ | ชื่อโครง ([03-naming.md](03-naming.md) หัวข้อ 2) |
| ตัวแปลคำขอของผู้เล่น | ตารางคำพ้องของแคตตาล็อกตัวละคร | `setup` เมื่อไม่มี LLM (หัวข้อ 4) |

คลังเล็กพอส่งไปกับเกมทั้งหมด ไม่ต้องแบ่งชุดหลักกับชุดที่โหลดภายหลัง

**ความหลากหลายเมื่อไม่มี LLM** คลังมี 4 ถึง 16 แบบต่อชุดสถานะ บวกแม่แบบชั้น 0 อีกหนึ่งถึงสามแบบ เลือกด้วยเมล็ด และจำว่าชิ้นไหนใช้แล้วในชีวิตนี้ ชิ้นที่ใช้แล้วไม่ขึ้นซ้ำจนกว่าชุดนั้นจะหมด ([09-library.md](09-library.md) หัวข้อ 7)

## 3. งานที่ต้องเปลี่ยนเพื่อให้ผลเหมือนกัน

ตอนนี้มีสองงานที่ LLM เปลี่ยนตัวเลขได้ ([README.md](README.md) หัวข้อ 4) ต้องเปลี่ยนก่อนหลัก 2 จะเป็นจริง

| งาน | ตอนนี้ | ต้องเป็น |
| --- | --- | --- |
| `flavor` | LLM เลือกผลจาก `LLM_FX` | เกมสุ่มผลด้วยเมล็ดก่อน แล้วให้ชั้นที่ใช้ได้เขียนเรื่องของผลนั้น คลังชั้น 1 ของ `flavor` แบ่งตามผลอยู่แล้ว |
| `setup` | LLM แปลคำขอเป็นค่าเริ่มต้น | แปลด้วยตัวแปลคำพ้องของเกมก่อน (หัวข้อ 4) LLM ใช้เมื่อตัวแปลไม่เข้าใจคำขอ และผลต้องอยู่ใน `enum` ของแคตตาล็อก ผลที่ได้เก็บกับเมล็ดของชีวิต เล่นซ้ำใช้ผลที่เก็บ |

## 4. งานที่ต้องมีทางสำรองพิเศษ

| งาน | ทางสำรองเมื่อไม่มี LLM |
| --- | --- |
| `setup` | ตัวแปลคำพ้อง: ค้นคำในคำขอ (เผ่า ถิ่น ศาสนา นิสัย อาชีพ ความถนัด) กับตารางคำพ้องของแคตตาล็อก ได้ค่าไหนใช้ค่านั้น ค่าที่ไม่ได้ให้เกมสุ่ม ถ้าไม่เข้าใจเลย เปิดหน้าเลือกเองที่มีช่องเดียวกับ JSON ของ `setup` |
| ชื่อทุกชนิด | ไม่ใช้ LLM อยู่แล้ว ([03-naming.md](03-naming.md)) |
| `miracle_day` ของการเสกตามใจ | ห้าจังหวะจากแม่แบบตามแก่นและกริยา ([../../appearance/20-god-ui.md](../../appearance/20-god-ui.md) หัวข้อ 7.3 ใช้แบบที่ใกล้ที่สุด) |
| `dream` | ภาพฝันจากความหมายของสัญลักษณ์ตามเผ่าและภูมิอากาศ (มีในโค้ด) และคลังภาพฝันชั้น 1 แบ่งตามสัญลักษณ์ × น้ำเสียงของทาง |
| [`epitaph`](07-ending-templates.md) `legend` `vow_page` `chronicle` `world_legend` | แม่แบบหลายประโยคที่ประกอบจากบันทึก: ข้อเท็จจริงสามถึงห้าข้อจากบันทึกชีวิตหรือพงศาวดาร เรียงตามเวลา ใส่คำเชื่อมจากคลัง ไม่มีความคิดเห็นที่บันทึกไม่มี รายละเอียดแม่แบบทุกชิ้นอยู่ใน [07-ending-templates.md](07-ending-templates.md) |
| `answer_twist` | แม่แบบตามชนิดของคำขอกับชนิดของของที่ได้ |
| `battle` | ข้อความของจังหวะศึกในระบบศึกเดิม |

## 5. เมื่อ LLM ล้ม

| เหตุ | สังเกตจาก | ทำอะไร |
| --- | --- | --- |
| ไม่มีเครือข่าย | คำขอไม่ถึงเซิร์ฟเวอร์ | ใช้ชั้น 1 ลองใหม่เมื่อเครือข่ายกลับ |
| ตอบช้า | เกิน 15 วินาที (ค่าเดิมของโค้ด) | ยกเลิกคำขอนั้น ใช้ชั้น 1 |
| เครดิตหมด | ผู้ให้บริการตอบว่ายอดไม่พอ | เซิร์ฟเวอร์ปิดการบรรยายทั้งระบบ และตอบ `/api/narrate/status` ว่าปิด จนกว่าผู้ดูแลเติมเงิน |
| ถูกจำกัดความถี่ | 429 | หยุดส่งตามเวลาที่บอก ใช้ชั้น 1 |
| ผู้ให้บริการล่ม | 5xx | ใช้ชั้น 1 |
| คำตอบเสีย | JSON ผิดแบบ ข้อความว่าง ไม่ผ่านตัวตรวจ | ขอใหม่หนึ่งครั้ง แล้วใช้ชั้น 1 |
| งบของวันหมด | ตัวนับของเซิร์ฟเวอร์ | ปิดการบรรยายถึงเที่ยงคืนตามเวลาไทย |

**ตัวตัดวงจร** ฝั่งเกม: ล้มติดกันสามครั้ง หยุดส่งสิบนาที แล้วลองหนึ่งคำขอ ผ่านจึงเปิดต่อ ฝั่งเซิร์ฟเวอร์: งบเป็นเงินต่อวันแทนจำนวนคำขอ ([01-cost.md](01-cost.md) หัวข้อ 8)

**ข้อความที่ขึ้นแล้วไม่เปลี่ยน** ข้อความจากคลังขึ้นทันที ถ้าคำตอบของ LLM มาถึงภายในสองวินาทีและผู้เล่นยังไม่ได้อ่าน (หน้าเพิ่งเปิด) ข้อความถูกแทนครั้งเดียว ถ้ามาช้ากว่านั้น เก็บเข้าแคชไว้ใช้ครั้งหน้า ข้อความที่แสดงแล้วบันทึกลงบันทึกชีวิต เปิดเซฟภายหลังไม่ว่ามีหรือไม่มี LLM เห็นข้อความเดิม

## 6. ทดสอบ

| ทดสอบ | ผ่านเมื่อ |
| --- | --- |
| เล่นเต็มชีวิตโดยปิด LLM | จบได้ทุกแบบเริ่มต้นและทุกเผ่า ไม่มีข้อความว่างหรือช่องที่ไม่ถูกเติม |
| เทียบชีวิตเดียวกันเปิด LLM (ปิดผู้กำกับและผู้แปล) และปิด LLM | แฮชของสถานะโลกและตัวละครเท่ากันทุกปีชีวิต |
| เล่นซ้ำจากเซฟที่เคยมีผู้กำกับ โดยปิด LLM | ได้ชีวิตเดิมทุกปี เพราะใช้ค่าที่บันทึก |
| ตัดการเชื่อมต่อกลางชีวิต | เล่นต่อได้ ไม่มีการรอ ข้อความถัดไปมาจากคลัง |
| จำลองเครดิตหมด | เซิร์ฟเวอร์ปิดการบรรยาย ผู้เล่นไม่เห็นข้อผิดพลาด |
| ความหลากหลายของคลัง | ชีวิตปกติหนึ่งชีวิตเห็นถ้อยคำซ้ำไม่เกิน 3% ของข้อความทั้งหมด |
