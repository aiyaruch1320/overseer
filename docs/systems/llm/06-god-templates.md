# แม่แบบชั้น 0 ของระบบพระเจ้า

ระบบ: [README.md](README.md) · เล่นได้เต็มโดยไม่มี LLM: [02-offline.md](02-offline.md) · สามชั้นของถ้อยคำ: [../god/05-llm.md](../god/05-llm.md) หัวข้อ 2 · ความฝัน กระซิบ คำอธิษฐาน: [../god/03-dreams.md](../god/03-dreams.md) · หีบ: [../god/02-bestow.md](../god/02-bestow.md) · ปาฏิหาริย์: [../god/04-miracles.md](../god/04-miracles.md) · หน้าจอ: [../../appearance/20-god-ui.md](../../appearance/20-god-ui.md) หัวข้อ 4 ถึง 7

ผู้ใช้ตัดสินแล้ว (2026-11-01): ระหว่างชีวิต ไม่ใช้ LLM เขียนถ้อยคำของระบบพระเจ้าเลย สิ่งที่ผู้เล่นอ่านมาจากชั้น 0 (ไฟล์นี้) และคลังชั้น 1 ที่สร้างตอนพัฒนา ([../god/05-llm.md](../god/05-llm.md) หัวข้อ 2) ไฟล์นี้จึงเป็นชั้นที่ **ต้องอ่านได้ครบด้วยตัวเอง** ถ้าคลังชั้น 1 ไม่มีชุดสถานะนั้น หรือชุดนั้นถูกใช้หมดในชีวิตนี้ เกมใช้แม่แบบของไฟล์นี้ ไม่มีช่องว่างและไม่มีข้อความขาด

ไฟล์นี้เป็นเอกสารต้นฉบับ ถ้อยคำเขียนไว้ให้ใช้ตรง ๆ ได้ และเป็นต้นแบบน้ำเสียงของคลังชั้น 1 ด้วย (ชุดสถานะละ 4 ถึง 16 แบบ เขียนโดย agent ตาม [09-library.md](09-library.md))

## 2. ความฝัน

### 2.1 กลุ่มเผ่า

ความหมายของสัญลักษณ์ในโค้ดแยกตามเผ่าไม่กี่เผ่าและภูมิอากาศ เกมมี 21 เผ่า จึงจัดเป็น 6 กลุ่มเพื่อให้ทุกเผ่ามีความหมายของตัวเอง

| กลุ่ม | เผ่า |
| --- | --- |
| คนบ้านเมือง | มนุษย์ ฮาล์ฟลิง สไลม์ |
| ป่าและฟ้า | เอลฟ์ ภูตพราย เผ่าสัตว์ เผ่าปีก |
| ภูผาและเตา | คนแคระ ยักษ์ เผ่าลาวา ลูกผสมจักรกล หุ่นวิญญาณ |
| สายน้ำ | นาคา เงือก |
| เงา | ดาร์กเอลฟ์ แวมไพร์ เผ่าปีศาจ กูล มัมมี่ |
| ศึกและมังกร | ออร์ค เผ่ามังกร |

**ลำดับที่ใช้** ความหมายของภูมิอากาศในโค้ด ก่อนความหมายของเผ่าในโค้ด ก่อนความหมายของกลุ่มในหัวข้อ 2.2 ก่อนความหมายพื้นฐานในโค้ด ตารางนี้เปลี่ยนถ้อยคำเท่านั้น แท็กของความหมาย (ที่เกมใช้จับคู่กับทาง) ใช้ของความหมายพื้นฐานหรือของเผ่าในโค้ดเสมอ ทุกช่องจึงเขียนให้ไปทิศเดียวกับความหมายพื้นฐาน

### 2.5 เหตุผลของเทียน

## 4. คำอธิษฐาน

ชนิดและเงื่อนไขตามโค้ด `src/data/prayers.ts` (17 ชนิด) ราคาและผลของคำตอบตาม [../god/03-dreams.md](../god/03-dreams.md) หัวข้อ 7 ตารางเรียงตามลำดับชนิดในโค้ด บรรทัดผลเดิมของโค้ด (ให้และลงโทษ) ยังเป็นแบบแรกของชนิดนั้น แม่แบบในหัวข้อนี้เป็นแบบเสริม บรรทัดคำขอเดิมของโค้ดก็เป็นแบบแรกเช่นกัน ชนิดที่ชี้คนอื่นใช้ {NPC} ตามช่องของหัวข้อ 1

ผลทุกแบบเขียนให้ตรงกับผลของเกม ผลให้แบบแปลกเล่าสิ่งที่ตัวละครได้โดยไม่ได้ขอแต่ช่วยเรื่องเดียวกัน เกมเปิดตัวเลือกให้แบบแปลกกับชนิดไหนตามกติกาของ [../god/03-dreams.md](../god/03-dreams.md) หัวข้อ 7 ส่วนผลนิ่งคือการ์ดไหม้เป็นเถ้า ไม่มีลางตอบ

| ขอบุตร | {ชื่อตัวละคร} กับคู่ชีวิตเดินขึ้นศาลบนเนินอีกเดือน ถวายข้าวและขอให้บ้านนี้มีเสียงเด็ก | เปลไม้ที่ซื้อไว้ตั้งแต่ปีก่อนยังว่าง {ชื่อตัวละคร} ลูบมันแล้วกระซิบกับท้องฟ้า |
| ขอพ้นความจน | {ชื่อตัวละคร} เทกระเป๋าบนโต๊ะ มีเหรียญเดียวกลิ้งไปอีกด้าน เขามองมันแล้วขอให้ฟ้าเห็นด้วย | ค่าเช่าสิ้นเดือนนี้ยังขาดอีกครึ่ง {ชื่อตัวละคร} นอนไม่หลับและสวดทั้งคืน |
| ขอปัญญา | ตะเกียงใกล้หมดน้ำมันแต่บทเรียนยังไม่เข้าหัว {ชื่อตัวละคร} ขอให้ใครสักคนเปิดหน้าต่างของความเข้าใจ | ตัวหนังสือเหมือนมดบนกระดาษ {ชื่อตัวละคร} เอามือกุมหัวแล้วขอทางลัด |
| ขอความกล้า | ก่อนเข้าป่าที่มีเสียงคำราม {ชื่อตัวละคร} ยืนหน้าทางเข้าแล้วหายใจลึก ขอความกล้าให้ติดตัวไปสักก้าว | มือที่จับห่อเสบียงสั่นไม่หยุด {ชื่อตัวละคร} บอกตัวเองว่าอีกนิดแล้วค่อยสวดขอ |
| ขอล้างแค้น | {ชื่อตัวละคร} กำหมัดจนเล็บฝังเนื้อ แล้วพูดชื่อ{NPC}ออกมาเป็นครั้งแรกในรอบปี | ในคืนที่ฝนตกหนักที่สุด {ชื่อตัวละคร} ยืนกลางลานแล้วท้าฟ้าให้ตัดสินเรื่องของเขากับ{NPC} |
| ขอให้พ้นคำสาป | รอยคล้ำบนข้อมือของ {ชื่อตัวละคร} ไม่เคยจางตั้งแต่เด็ก เขาขอให้มันหลุดไปสักวัน | ทุกครั้งที่เรื่องร้ายเกิด คนในหมู่บ้านมองมาทาง {ชื่อตัวละคร} เขาจึงมาศาลเพื่อขอล้างเงานั้น |
| ขอชื่อเสียง | {ชื่อตัวละคร} ได้ยินกวีในตลาดร้องถึงวีรบุรุษคนอื่น จึงกระซิบขอให้สักวันชื่อของเขาอยู่ในเพลงเดียวกัน | {ชื่อตัวละคร} ฝึกเขียนชื่อตัวเองบนพื้นทรายซ้ำ ๆ แล้วขอให้ผู้คนจำมัน |
| ขอให้ทำมาค้าขึ้น | คลังของ {ชื่อตัวละคร} ว่างครึ่งหนึ่งในปลายฤดู เขากอดอกมองมันแล้วขอให้ปีหน้าดีกว่านี้ | {ชื่อตัวละคร} เปิดร้านแต่เช้าปิดดึกอีกวัน วางเหรียญแรกของวันไว้บนหิ้งแล้วขอพร |
| ขออุ้มหลาน | {ชื่อตัวละคร} นั่งที่ระเบียงบ้านเก่า มองถนนที่ไม่มีใครมา ขอเพียงได้ยินเสียงเด็กวิ่งสักครั้ง | มือเริ่มสั่นตามวัยแล้ว {ชื่อตัวละคร} ยังถักผ้าห่มเด็กที่ยังไม่มีเด็กไว้ แล้วขอให้ได้ใช้มัน |
| ท้าฟ้า | {ชื่อตัวละคร} เมาจนยืนไม่ตรง เงยหน้าเยาะฟ้า "ถ้ามีจริงก็ลงมาให้เห็นสิ" | {ชื่อตัวละคร} ยืนนิ่งกลางลานศาลที่ว่าง แล้วพูดกับฟ้าด้วยเสียงเรียบ "ข้าไม่เชื่อ ถ้ามีจริงก็พิสูจน์" |
| ขอให้คนใกล้ตัวหาย (`kin_sick`) | {NPC}หายใจแผ่วลง {ชื่อตัวละคร} ไม่ยอมไปนอน เปลี่ยนผ้าเปียกอีกผืนแล้วสวดเสียงต่ำ | หมอยาบอกว่าเหลือเวลาไม่มาก {ชื่อตัวละคร} กุมมือของ{NPC}แล้วขอเพียงให้เช้านี้มาถึง |
| แม่ขอให้ลูกแข็งแรง (`mother`) | แม่ของ {ชื่อตัวละคร} ปัดฝุ่นบนหิ้งแล้วจุดธูปดอกเล็ก ขอให้ลูกโตขึ้นโดยไม่ป่วยเหมือนเด็กบ้านข้าง ๆ | ลูกไอเบา ๆ ในห้องนอน แม่ลุกขึ้นกลางดึกและสวดคำเดิมซ้ำทั้งคืน |

### 4.2 ผลให้ และให้แบบแปลก

ให้ได้ตามขอ ให้แบบแปลกได้สิ่งที่ไม่ได้ขอแต่ช่วยเรื่องเดียวกัน (เปิดเหตุการณ์เล็กหนึ่งเรื่อง)

| ชนิด | ให้ | ให้แบบแปลก |
| --- | --- | --- |
| ขอหายเจ็บ | ไข้ออกเป็นเหงื่อทั้งคืน เช้าขึ้น {ชื่อตัวละคร} ลุกนั่งได้และหิวข้าว | ไข้ไม่ลด แต่หญิงขายยาที่ไม่เคยแวะมาก่อนเคาะประตูบ้าน แล้วนั่งดูแผลนั้นนานอย่างคนที่เคยเห็นแบบนี้มาแล้ว |
| ขอฝน | ลมเย็นมาก่อนฝนหนึ่งชั่วยาม เมื่อฝนตกลง คนทั้ง{ชื่อของที่นี่}ออกมายืนกลางถนนโดยไม่กางร่ม | ฝนไม่ตก แต่น้ำพุเล็กผุดขึ้นที่ท้ายหมู่บ้าน ไม่มีใครรู้ว่ามันอยู่ใต้ดินมานานเท่าไร |
| ขอให้พ้นโรค | เสียงไอในซอยค่อยหายไป ภายในสามวันไม่มีใครต้องทาไม้กากบาทอีก | โรคยังอยู่ในเมือง แต่หมอเร่คนหนึ่งเคาะประตูขอที่พัก และอยู่ช่วยดูแลคนในบ้านจนโรคผ่านพ้นซอยนี้ไป |
| ขอสันติ | ทูตของสองฝ่ายพบกันกลางสะพานโดยไม่มีใครนัด ภายในสามวันกองทัพเก็บค่าย | สงครามไม่จบ แต่ทางหนีที่ไม่เคยมีใครรู้เปิดขึ้นเส้นหนึ่ง เพียงพอสำหรับคนในบ้านของ {ชื่อตัวละคร} |
| ขอพบรัก | วันรุ่งขึ้น คนแปลกหน้าคนหนึ่งทำของตกหน้าร้าน {ชื่อตัวละคร} ก้มเก็บให้ มือสองมือแตะกันนานกว่าที่ควร | ไม่มีคนรัก แต่หญิงชราที่ขายน้ำชาหัวถนนเริ่มเก็บที่นั่งประจำไว้ให้ {ชื่อตัวละคร} และหาคนมานั่งคุยด้วยทุกเย็น |
| ขอบุตร | ในฤดูถัดมา หญิงชราในหมู่บ้านลูบท้องแล้วยิ้ม ไม่นานเสียงร้องของทารกก็ดังขึ้นในบ้าน | บ้านยังไม่มีเด็ก แต่ต้นไม้ในสวนออกผลสองลูกตอนไม่ถึงฤดู และหมอตำแยบอกว่าไม่ต้องรีบ |
| ขอพ้นความจน | เช้าวันถัดมา {ชื่อตัวละคร} พบถุงเงินใบเล็กใต้พุ่มไม้ข้างทาง ไม่มีชื่อ ไม่มีรอยมือ | ไม่มีเงินตก แต่ช่างซ่อมชื่อดังคนหนึ่งเดินเข้ามาถามหาคนช่วยงาน และจ่ายล่วงหน้าครึ่งหนึ่ง |
| ขอปัญญา | ประโยคที่อ่านมาครึ่งคืนต่อกันเป็นภาพเดียวในพริบตา {ชื่อตัวละคร} หัวเราะออกมาเบา ๆ | ตำราไม่ง่ายขึ้น แต่ครูเก่าคนหนึ่งผ่านมาและสอนโดยไม่เรียกเงินสามบ่าย |
| ขอความกล้า | อกอุ่นขึ้นเหมือนมีใครวางมือ ขาที่สั่นนิ่งลง {ชื่อตัวละคร} ก้าวเข้าป่าโดยไม่ชะลอ | ความกลัวยังอยู่ แต่เด็กเลี้ยงสัตว์คนหนึ่งเดินสวนมา เสนอนำทางออกอีกด้านตามทางที่ปลอดภัย |
| ขอล้างแค้น | ข่าวของ{NPC}ถูกส่งมาโดยคนแปลกหน้า {ชื่อตัวละคร} ฟังจบ นั่งนิ่งนาน แล้วรู้ว่าไม่ได้ดีใจอย่างที่คิด | {NPC}ไม่ได้รับกรรม แต่จดหมายขอโทษที่เขียนค้างไว้นานถึงมือ {ชื่อตัวละคร} โดยผู้ส่งที่ไม่ยอมบอกชื่อ |
| ขอให้พ้นคำสาป | รอยคล้ำจางหายขณะเขาหลับ ตอนตื่นข้อมือของ {ชื่อตัวละคร} ไม่หนักอีกแล้ว | คำสาปยังอยู่ แต่หมอผีเร่คนหนึ่งหยุดที่ธรณีประตูตอนเช้า บอกว่ากลิ่นของบ้านนี้พาเขามา และขอเข้าไปดูสิ่งที่ติดตัว {ชื่อตัวละคร} |
| ขอชื่อเสียง | ปลายฤดูต่อมา คนแปลกหน้าในโรงเตี๊ยมร้องเพลงที่มีชื่อ {ชื่อตัวละคร} โดยไม่มีใครสั่ง | ชื่อไม่ดัง แต่ผู้อาวุโสคนหนึ่งในเมืองเรียกเขาไปพบ และฝากกิจเล็กที่ฝากกันแต่คนที่ไว้ใจ |
| ขอให้ทำมาค้าขึ้น | ลูกค้าที่ไม่เคยเห็นหน้าเข้าร้านต่อกันเป็นแถว ภายในสัปดาห์เดียวของที่ค้างหมดชั้น | ผลผลิตไม่ล้น แต่พ่อค้าจากต่างถิ่นเสนอเป็นคู่ค้าถาวรในราคาที่เป็นธรรม |
| ขออุ้มหลาน | ฤดูต่อมามีคนวิ่งมาบอกข่าวหน้าบ้าน {ชื่อตัวละคร} หยิบผ้าห่มที่ถักไว้ออกมาด้วยมือที่สั่นทั้งยิ้ม | หลานยังไม่มา แต่ลูกที่ห่างกันมานานส่งคนมารับ {ชื่อตัวละคร} ไปเยี่ยมถึงบ้านหนึ่งฤดู |
| ท้าฟ้า | เมฆเปิดเป็นรูกลมรูเดียว แสงตกลงห่างจากเท้าเขาไม่ถึงฝ่ามือ {ชื่อตัวละคร} ทรุดลงนั่ง ปากอ้าค้าง | สิ่งที่มาไม่ใช่ฟ้าแลบ แต่เป็นนักบวชพเนจรคนหนึ่งที่เดินมานั่งลงข้าง {ชื่อตัวละคร} โดยไม่พูดอะไร จนเขาเป็นฝ่ายเปิดปากก่อน |
| ขอให้คนใกล้ตัวหาย | {NPC}ลืมตา ขอน้ำ และถามว่าทำไมทั้งบ้านต้องร้องไห้ เช้าวันนั้นเขากินข้าวต้มได้ชามเต็ม | {NPC}ยังไม่ฟื้นทันที แต่พ่อค้าที่ไม่ยอมบอกว่าใครส่งมาเคาะประตูบ้าน บอกว่ารู้จักหมอที่เคยรักษาไข้แบบนี้ และพาไปหาได้ทันที |
| แม่ขอให้ลูกแข็งแรง | {ชื่อตัวละคร} ตื่นมาร่าเริงทั้งวัน ใครมาก็บอกว่าแก้มแดงเหมือนผลท้อ | ลูกยังเป็นหวัดตามประสาเด็ก แต่หญิงชราข้างบ้านแวะมาเยี่ยม และสอนแม่วิธีต้มน้ำสมุนไพรประจำฤดู |

เหตุการณ์ ⭐ และ ● มีลาง 1 ถึง 3 ฤดูก่อนเกิด ([../events/world-events.md](../events/world-events.md) หัวข้อ 0.3) เหตุการณ์ ○ ไม่มีลางตามกติกา แถว ○ ใช้เมื่อผู้เล่นเล็งลิขิตไปที่เหตุการณ์ ○ ในทวีปที่ตัวละครอยู่ ([../god/04-miracles.md](../god/04-miracles.md) หัวข้อ 4) หรือเมื่อมีข่าวลือถึงเหตุการณ์นั้น ข้อความเป็นสิ่งที่คนทั่วไปสังเกตเห็น ไม่ใช่สิ่งที่พระเจ้ารู้

## 8. เลือกแม่แบบอย่างไร

### 8.1 กุญแจของชุด

ทุกชนิดงานมีกุญแจของชุดสถานะ แม่แบบหนึ่งชุดคือแถวหรือช่องของตารางข้างบน

| ชนิดงาน | กุญแจของชุด | แบบต่อชุด |
| --- | --- | --- |
| ความหมายสัญลักษณ์ | สัญลักษณ์ × กลุ่มเผ่า | 1 (ข้อมูล ไม่สุ่ม) |
| ภาพฝัน | สัญลักษณ์ × น้ำเสียง | 2 |
| เงาของผล | แหล่ง S1 ถึง S8 | 3 |
| เหตุผลของเทียน | เทอมของสูตร | 3 (เสริม 2) |
| ตอนตัดสินใจ | ผล (ทำตาม ตีความผิด ปฏิเสธ ขัดขืน) | 3 |
| ตีความผิดตามสัญลักษณ์ | สัญลักษณ์ | 1 |
| ภาระใจ | เหตุการณ์ | 2 |
| กระซิบ | คำใบ้ × ฉาก | 3 |
| คำขอเสริม | ชนิดคำอธิษฐาน | 2 (บวกของโค้ด 1) |

### 8.2 สุ่มด้วยเมล็ด ไม่ซ้ำ

| ข้อ | กติกา |
| --- | --- |
| 1 | เลือกจากเมล็ดของโลกร่วมกับรหัสชีวิต กุญแจของชุด และจำนวนครั้งที่ชุดนั้นถูกใช้ในชีวิตนี้ ผลลัพธ์เดิมทุกครั้งเมื่อเล่นซ้ำด้วยเมล็ดเดิม ([02-offline.md](02-offline.md) หัวข้อ 2) |

| 3 | ลำดับ: คลังชั้น 1 ของชุดที่ยังไม่ใช้ในชีวิตนี้ ก่อน แล้วแม่แบบชั้น 0 ของชุดที่ยังไม่ใช้ เมื่อทั้งสองชั้นหมด เริ่มรอบใหม่โดยเอาแบบที่ใช้นานที่สุดก่อน ไม่ใช้แบบที่เพิ่งแสดงไปในสองครั้งล่าสุด |
| 4 | การเลือกไม่แตะตัวสุ่มของกติกาโลก ใช้ตัวสุ่มของข้อความแยกต่างหาก เพื่อให้เปิดหรือปิดคลังชั้น 1 แล้วตัวเลขของโลกไม่เปลี่ยน ([02-offline.md](02-offline.md) หัวข้อ 6) |
| 5 | ข้อความที่แสดงแล้วบันทึกลงบันทึกชีวิต เปิดเซฟใหม่เห็นข้อความเดิม |
| 6 | บรรทัดของหัวข้อ 3 และ 5 ที่เอ่ยถึงทะเล ชายฝั่ง เรือ หรือคลื่น ใช้เฉพาะเมื่อที่ที่ตัวละครอยู่ติดทะเล ถ้าไม่ติด เกมข้ามบรรทัดนั้นไปแบบอื่นของชุด ทุกชุดในสองหัวข้อนี้มีแบบที่เข้ากับที่ไกลทะเลอย่างน้อยหนึ่งแบบ |

### 8.3 ช่องที่ไม่มีข้อมูล

| ช่อง | ถ้าไม่มี |
| --- | --- |
| {ชื่อตัวละคร} {เผ่า} {ทวีป} {ฤดู} | มีเสมอ ไม่มีกรณีถอย |
| {ชื่อของที่นี่} | ใช้ชื่อประเทศจากข้อมูลประเทศแทนชื่อในทะเบียน |
| {NPC} | ข้ามแม่แบบที่ใช้ช่องนี้ ทุกชุดที่ทางหรือคำขอไม่ชี้ NPC เลือกจากแบบที่ไม่ใช้ {NPC} |
| {จุดหมาย} | ใช้ชื่อประเทศ ถ้าไม่มีใช้ชื่อทวีป ถ้าคำใบ้ไม่ชี้ที่ ข้ามแม่แบบที่ใช้ช่องนี้ |
| {ศัตรู} | ใช้คำว่า "ศัตรู" |
| {นิสัย} | ข้ามแม่แบบที่ใช้ช่องนี้ ทุกเทอมของเหตุผลมีแบบที่ไม่ใช้ช่องนี้เสมอ เหตุการณ์ภาระใจแบบนิสัยเปลี่ยนมีช่องนี้เสมอ เพราะเกิดจากนิสัยนั้น |
| {นิสัยใหม่} | ข้ามไปแบบที่ไม่ใช้ช่องนี้ (แบบ 1 ของนิสัยเปลี่ยน) |
| {อาชีพ} | ข้ามแม่แบบที่ใช้ช่องนี้ (หนีงานหรือหนีบ้านใช้แบบ 2) |
| {ความถนัด} {สัตว์คู่หู} {เรื่องที่จะถึง} {เหตุการณ์โลก} | ช่องเหล่านี้ผูกกับตัวคูณ แม่แบบแต่ละแบบจึงใช้เมื่อตัวคูณนั้นเกิดจริงเท่านั้น ไม่มีกรณีถอย |
| {ที่เกิดเหตุ} | ใช้ชื่อเมือง ถ้าไม่มีใช้ชื่อประเทศ ถ้าไม่มีใช้ชื่อทวีป |
| {ชื่อปาฏิหาริย์} | ปาฏิหาริย์ในรายการใช้ชื่อของตัวเอง เสกตามใจใช้ชื่อจากทะเบียน ([03-naming.md](03-naming.md)) |

### 8.4 ชุดที่ว่างถอยไปไหน

| งาน | ถ้าชุดไม่มีแบบ |
| --- | --- |
| ความหมายสัญลักษณ์ | ภูมิอากาศในโค้ด ก่อนเผ่าในโค้ด ก่อนกลุ่มเผ่า ก่อนความหมายพื้นฐาน (หัวข้อ 2.1) |
| ภาพฝัน | สัญลักษณ์เดียวกันที่น้ำเสียง "ปลอดภัย" ถ้าไม่มี ใช้ภาพจากความหมายของสัญลักษณ์ตามโค้ด |
| ตีความผิด | สัญลักษณ์ที่ไม่มีบรรทัดของตัวเองใช้แบบทั่วไปของผล "ตีความผิด" |

| ผลของคำอธิษฐาน | ชนิดที่ไม่มีบรรทัดถอยไปใช้บรรทัดเดิมของโค้ด (ให้และลงโทษ) หรือบรรทัดทั่วไปของคำตอบ (ปฏิเสธและนิ่ง) |
| วันเกิดเหตุ | ฉากของตัวเอง ก่อนฉากของแบบใกล้ที่สุดในสายเดียวกัน ก่อนแม่แบบกริยา (หัวข้อ 8.5) |
