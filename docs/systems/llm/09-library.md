## 4. รูปแบบไฟล์

หนึ่งชุดใหญ่หนึ่งไฟล์ `data/library/<ชุด>.jsonl` UTF-8 หนึ่งบรรทัดคือ JSON หนึ่งก้อน ลำดับบรรทัดไม่มีผล

| ช่องของ JSON | มีเสมอ | ค่า |
| --- | --- | --- |
| กุญแจของชุด | ใช่ | ตามหัวข้อ 6 ของชุดนั้น (เช่น kind กับ voice ของคำอธิษฐาน) |
| img | ใช่ | คำสั้นที่บอกภาพหลักของบรรทัด ต้องปรากฏในข้อความ ไม่ซ้ำในชุดสถานะ ใช้ให้ตัวตรวจนับว่าชุดมีภาพต่างกันครบ |
| text | ใช่ | ถ้อยคำ |
| races | ไม่ | รายการกลุ่มเผ่าจาก [06-god-templates.md](06-god-templates.md) หัวข้อ 2.1 (คนบ้านเมือง ป่าและฟ้า ภูผาและเตา สายน้ำ เงา ศึกและมังกร) บรรทัดขึ้นเฉพาะตัวละครในกลุ่มนั้น |
| lands | ไม่ | รายการชื่อทวีป (อัซการ์ มอร์เฮเวน คาซ-ดูรัม เนเรีย อัลเดรีย เมคาเรีย ซาฮารัน ซิลวาเนล เนบูเลีย) บรรทัดขึ้นเฉพาะเมื่อตัวละครอยู่ทวีปนั้น |

```json
{"kind":"rain","voice":"ภักดี","lands":["ซาฮารัน"],"img":"พายุทราย","text":"พายุทรายพัดมาสามวันไม่หยุด {ชื่อตัวละคร} ใช้ผ้าปิดหน้าแล้วคุกเข่าหันไปทางภูเขา ขอให้บรรพบุรุษในหินส่งฝนลงมาล้างฟ้า"}
```

บรรทัดที่มี races หรือ lands ไม่เกินหนึ่งในสามของชุดสถานะ (ปัดลง) เพื่อให้ทุกเผ่าและทุกทวีปยังมีบรรทัดพอ
