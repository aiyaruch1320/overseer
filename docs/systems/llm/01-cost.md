# ค่าใช้จ่ายของ LLM

ระบบ: [README.md](README.md) · LLM ในระบบพระเจ้า: [../god/05-llm.md](../god/05-llm.md) · ตัวคำนวณ: `node scripts/sim/sim-llm-cost.mjs` (อ่านตารางในหัวข้อ 1 และ 4 ของไฟล์นี้)

ทุกตัวเลขในไฟล์นี้คำนวณจากตารางราคาและตารางงานข้างล่าง ถ้าราคาหรือจำนวนครั้งเปลี่ยน แก้ตารางแล้วรันตัวคำนวณใหม่

## 1. ราคา

DeepSeek V4.1 Flash รุ่น 1017 (`deepseek-flash`) ดอลลาร์ต่อหนึ่งล้านโทเคน จากหน้าราคาของ DeepSeek ณ 2026-11-01 ไม่มีราคาแยกโหมดคิด (โทเคนความคิดนับเป็นโทเคนออก) ไม่พบส่วนลด batch

| ช่วงเวลา | เข้าชนแคช | เข้าไม่ชนแคช | ออก |
| --- | --- | --- | --- |
| ช่วงเร่งด่วน | 0.006 | 0.30 | 1.20 |
| นอกช่วงเร่งด่วน | 0.003 | 0.15 | 0.60 |

**ช่วงเร่งด่วน** 01:00–04:00 และ 06:00–10:00 UTC วันจันทร์ถึงศุกร์ ยกเว้นวันหยุดของจีน (เวลาไทย 08:00–11:00 และ 13:00–17:00 วันธรรมดา) นอกนั้นรวมเย็น กลางคืน และเสาร์อาทิตย์เป็นนอกช่วง ผู้เล่นไทยส่วนใหญ่เล่นตอนเย็นและวันหยุด ตัวคำนวณใช้สมมติฐานว่า 25% ของคำขอตกช่วงเร่งด่วน

## 3. โครงของ prompt

DeepSeek สร้างหน่วยแคชที่ท้ายข้อความ user และท้ายคำตอบ จึงแบ่งเป็นสามส่วน

| ส่วน | อยู่ที่ | เนื้อหา | โทเคน (เป้า) | แคช |
| --- | --- | --- | --- | --- |
| ส่วนหน้าร่วม | system และ user แรก ตามด้วย assistant "รับทราบ" | น้ำเสียงของโลก กติกาการเขียน ข้อห้าม (ภาษาอังกฤษ) สรุปโลกสั้น | 1,100 | ชนเกือบทุกครั้ง เพราะทุกงานของทุกผู้เล่นใช้ส่วนนี้ |
| ส่วนของงาน | user ที่สอง ตามด้วย assistant "รับทราบ" | วิธีทำงานนี้ แบบ JSON ตัวอย่างหนึ่งชิ้น | 400 | ชนเมื่องานนี้ถูกเรียกบ่อยพอ |
| ข้อมูล | user สุดท้าย | สถานะของเกมสำหรับคำขอนี้ | ตามตารางงาน | ไม่ชน |

ไม่ส่ง `user_id` (แยกแคชต่อผู้ใช้ ทำให้ส่วนหน้าร่วมไม่ชนข้ามผู้เล่น)

## 5. กุญแจแคชคำตอบ

แคชคำตอบของเกมเอง (คนละอย่างกับแคชของ DeepSeek) คำขอที่กุญแจตรงกันไม่ส่งไป LLM

`กุญแจ = sha256(งาน | รุ่นของแบบข้อมูล | รุ่นของ prompt | ภาษา | รุ่นของข้อมูลโลก | ช่องสถานะที่ส่งจริง | กลุ่มเมล็ด)`

- **ช่องสถานะ** คือข้อมูลที่ส่งจริงหลังตัดแล้ว ไม่มีข้อมูลที่ไม่ส่ง
- **กลุ่มเมล็ด** = เมล็ดของชีวิต mod 8 ให้ผู้เล่นต่างคนที่ได้สถานะเดียวกันได้ข้อความต่างกันได้แปดแบบ แต่ยังใช้แคชร่วมกัน
- เก็บสองที่: ในเครื่องผู้เล่น (localStorage ตามโค้ดเดิม) และที่เซิร์ฟเวอร์ร่วมทุกผู้เล่น
- งาน `setup` `legend` `epitaph` `chapter` `chronicle` `director` มีข้อมูลเฉพาะตัวมากจนแทบไม่ชน คิดเป็นต้นทุนเต็มในตัวคำนวณ งานอื่นตัวคำนวณยังไม่หักส่วนที่แคชร่วมชน (ตัวเลขจริงควรต่ำกว่า)

## 7. ข้อสังเกตจากผล

- **สามงานถูกมาก** ค่าเริ่มต้น (สั่งตัวละคร ผู้กำกับ สรุปตอนจบ) ราว 0.0015 ดอลลาร์ (ราว 0.05 บาท) ต่อชีวิต ราว 11 คำขอต่อชีวิต 10,000 ผู้เล่นต่อเดือนราว 225 ดอลลาร์ ปิดผู้กำกับเหลือราวครึ่งหนึ่ง
- **ผู้กำกับคือค่าหลัก** (ราว 54%) รองลงมาคือสรุปตอนจบ (ราว 40%) ซึ่งเป็นคำขอเดียวแต่คำตอบยาว
- **ห้ามเปิดโหมดคิด** โหมดคิดเปิดเป็นค่าเริ่มต้นของ `deepseek-flash` ถ้าลืมปิด ค่าต่อชีวิต ×2.7 โค้ดเดิมปิดแล้วทุกคำขอ
- **รักษาส่วนหน้าให้คงที่** แคชไม่ชนทำให้ค่า ×3 ส่วนหน้าต้องเหมือนเดิมทุกไบต์ ไม่ใส่วันที่ เมล็ด หรือข้อมูลของผู้เล่นในส่วนหน้า เปลี่ยนส่วนหน้าเมื่อออกรุ่นเกมเท่านั้น
- **ถ้าเปิดงานอื่นภายหลัง** ตารางหัวข้อ 4 เก็บจำนวนครั้งและโทเคนของทุกงานไว้แล้ว เปลี่ยนชั้นเป็น 2 แล้วรันตัวคำนวณใหม่ (ถ้าเปิดทั้งหมดเคยคำนวณได้ราว 0.013 ดอลลาร์ต่อชีวิต)
