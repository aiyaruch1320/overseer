# ชื่อที่โลกจำ

ระบบ: [README.md](README.md) · เสกตามใจ: [../god/07-conjure.md](../god/07-conjure.md) · ซากพระเจ้า: [../god/04-miracles.md](../god/04-miracles.md) หัวข้อ 5 · ตีอาวุธ: [../items/10-forging.md](../items/10-forging.md)

สิ่งใหม่ที่เกิดในโลกระหว่างเล่น (ปาฏิหาริย์ที่เสกตามใจ ลัทธิที่เกิดจากซาก เมืองใหม่บนซาก อาวุธที่ตี) ต้องมีชื่อ ชื่อนั้นกลายเป็นข้อเท็จจริงของโลก NPC เหตุการณ์ และข่าวลือภายหลังพูดถึงด้วยชื่อเดียวกัน ไปจนถึงชีวิตของทายาท

**ผู้ใช้ตัดสินแล้ว (2026-11-01): เกมตั้งชื่อเอง ไม่ใช้ LLM ตั้งชื่อระหว่างเล่น** ชื่อมาจากแม่แบบกับคลังคำที่อยู่ในตัวเกม เลือกด้วยเมล็ดของโลก LLM ใช้ชื่อเหล่านี้ได้ในงานเรียบเรียง (การ์ดตอนจบ ตำนาน) แต่ไม่ตั้งหรือเปลี่ยนชื่อ

## 1. อะไรมีชื่อ อะไรไม่มี

| ชนิด | ตัวอย่าง | ใช้ซ้ำที่ |
| --- | --- | --- |
| ปาฏิหาริย์ที่เสกตามใจ | ฝนเงินแห่งซอร์เนบ | พงศาวดาร ข่าวลือ บทพูด NPC ตำนานของชีวิต การ์ดตอนจบ |
| ปาฏิหาริย์ใหญ่ในรายการ (MR-17 ถึง MR-22) | คืนดาวแดงแห่งซอร์เนบ | เหมือนข้างบน และป้ายบนแผนที่ |
| ซาก | ซากซอร์เนบ (ตายตัว "ซาก" + ชื่อเดิม) | แผนที่ ([../../appearance/20-god-ui.md](../../appearance/20-god-ui.md) หัวข้อ 7.4) |
| ลัทธิจากซาก (RU-04) | ผู้เฝ้าหลุมซอร์เนบ | เหตุการณ์ โหนด `mr.a3` |
| เมืองใหม่บนซาก (RU-07) และแผ่นดินใหม่ (MR-20) | รุ่งซอร์ · เกาะหินเดือด | แผนที่ ประเทศ |
| อาวุธที่ตี | ใบพายุของคาโรซา | ชื่อของไอเทม บันทึกชีวิต |
| สัตว์คู่หูที่ยังไม่มีชื่อ | ตามชนิดสัตว์ | บันทึกชีวิต |
| คน (NPC ผู้สืบ NPC ที่มาใหม่ ทายาท) | ไม่ใช้ระบบนี้ ใช้ชื่อต้นแบบกับเลขรุ่น หรือชุดชื่อต่อถิ่น ([../../lore/npcs/succession.md](../../lore/npcs/succession.md)) | |
| สิ่งที่มีในเอกสารแล้ว (ประเทศ มังกร NPC อาวุธตำนาน) | ไม่ตั้งใหม่ | |

## 2. แม่แบบและคลังคำ

| ชนิด | แม่แบบ | ช่อง |
| --- | --- | --- |
| เสกตามใจ | {ภาพ}{คำขยาย}แห่ง{ที่} | ภาพจากแก่น คำขยายจากกริยาหรือสี ที่คือชื่อประเทศ เมือง หรือทวีปตามขนาด |
| ปาฏิหาริย์ใหญ่ | {เวลา}{ภาพ}แห่ง{ที่} | เวลา (คืน วัน ฤดู ปี) ภาพจากชนิดปาฏิหาริย์ |
| ลัทธิจากซาก | {ผู้}{กริยาบูชา}{หลุม/น้ำ}{ชื่อเดิม} | ผู้ (ผู้เฝ้า บุตร คนของ) กริยาบูชา (เฝ้า ฟัง รอ) |
| เมืองใหม่ | {คำฟื้น}{รากของชื่อเดิม} หรือ {รากของชื่อเดิม}{คำใหม่} | คำฟื้น (รุ่ง ฟื้น ใหม่) รากคือพยางค์แรกของชื่อเดิม |
| แผ่นดินใหม่ | {ชนิดที่ดิน}{ลักษณะ} | ชนิดที่ดิน (เกาะ แหลม ผา) ลักษณะ (หินเดือด ไอขาว เกลือ) |
| อาวุธที่ตี | {ลักษณะ}{คำเรียกอาวุธ}ของ{ช่าง} | ลักษณะจากวัสดุหรือธาตุ คำเรียกจากทรงอาวุธ ช่างคือชื่อช่างในเอกสาร |
| สัตว์คู่หู | {คำจากรูปร่างหรือสี}{คำเล่น} | ตามชนิดสัตว์ |

**คลังคำ** หนึ่งไฟล์ต่อภาษา ส่งไปกับเกม แต่ละช่องมีคำ 8 ถึง 20 คำ แยกตามแก่น ทวีป และน้ำเสียง (สร้าง: อุ่น สว่าง · ทำลาย: หนัก มืด) ตัวอย่างช่อง "ภาพ" ของแก่นน้ำ: ฝน หมอกน้ำ ธาร น้ำพุ ทะเลนิ่ง คลื่นเงียบ หยาดฟ้า น้ำตาฟ้า คลังคำเขียนมือ หรือร่างด้วย LLM ตอนพัฒนาแล้วคนตรวจ

**จำนวนชื่อที่เป็นไปได้** เสกตามใจ: ภาพราว 10 × คำขยายราว 12 × ที่ 143 ประเทศ ราว 17,000 ชื่อ ต่อแก่นต่อกริยา ปาฏิหาริย์ใหญ่: เวลา 6 × ภาพ 10 × ที่ ราว 8,600 ชื่อ ต่อชนิด ชื่อซ้ำในโลกเดียวแทบไม่เกิด ถ้าเกิด เกมเลือกคำถัดไปตามเมล็ด

**ตรวจชื่อ** ไม่ซ้ำชื่อในทะเบียน ชื่อประเทศ ชื่อมังกร ชื่อ NPC และยาวไม่เกิน 24 ตัวอักษรไทย

## 3. ทะเบียนชื่อของโลก

ทุกชื่อที่ตั้งลงทะเบียนหนึ่งแถว ทะเบียนอยู่ในข้อมูลของโลก (เซฟ)

| ช่อง | ความหมาย |
| --- | --- |
| รหัส | รหัสของสิ่งที่ถูกตั้งชื่อ (รหัสการเสก รหัสเหตุการณ์ RU รหัสไอเทม) |
| ชนิด | ตามหัวข้อ 1 |
| ชื่อ | ชื่อที่ใช้ |
| ปีโลก ที่ | ตั้งเมื่อไร ที่ไหน |
| เหตุการณ์ที่โยง | รหัสเหตุการณ์ที่เกิดจากสิ่งนี้ภายหลัง |

**ชื่อถูกใช้ซ้ำอย่างไร**

- แม่แบบทุกชนิดมีช่อง `{ชื่อของที่นี่}` เกมเติมชื่อจากทะเบียนของประเทศนั้น ข่าวลือ บทพูด และพงศาวดารจึงพูดถึงชื่อเดิม
- เมื่อ LLM ใช้ได้ ชื่อจากทะเบียนถูกส่งไปใน `allowed_names` ของงานเรียบเรียงและงานเขียนถ้อยคำ LLM อ้างถึงได้ แต่สร้างชื่อใหม่ไม่ได้
- ชื่อที่โลกจำข้ามชีวิต: ทายาทเกิดในโลกเดิมเห็นชื่อเดิม (เช่น ตำนานของตระกูลพูดถึง "ฝนเงินแห่งซอร์เนบ" ที่บรรพบุรุษเห็น)
- ชื่อในทะเบียนแสดงในของสะสม หมวดปาฏิหาริย์ที่เสกตามใจ ([../god/08-goals.md](../god/08-goals.md) หัวข้อ 7)

ชื่อขึ้นกับเมล็ดและสถานะเท่านั้น เล่นซ้ำด้วยเมล็ดเดิมได้ชื่อเดิมทุกครั้ง มีหรือไม่มี LLM
