# คลังคำ

ระบบ: [README.md](README.md) · แม่แบบและทะเบียน: [03-naming.md](03-naming.md) · เสกตามใจ: [../god/07-conjure.md](../god/07-conjure.md) · ปาฏิหาริย์และซาก: [../god/04-miracles.md](../god/04-miracles.md) · ตีอาวุธ: [../items/10-forging.md](../items/10-forging.md) · สัตว์คู่หู: [../character/15-companion-species.md](../character/15-companion-species.md) · ทวีป: [../../lore/world/continents.md](../../lore/world/continents.md)

คำที่เกมใช้ประกอบชื่อตามแม่แบบใน [03-naming.md](03-naming.md) หัวข้อ 2 เกมตั้งชื่อเอง ไม่ใช้ LLM (ผู้ใช้ตัดสินแล้ว 2026-11-01) คลังเขียนมือ ส่งไปกับเกม คำที่ซ้ำกับเอกสารโลกใช้ตามเดิม (เหล็กดาว ศิลาลอย หลุมดาว ผนึก เกล็ด เตาหลอม เทาเถ้า แดงเลือด) ไม่มีชื่อเฉพาะของมังกร ประเทศ NPC หรืออาวุธตำนานในคลัง

ทุกคลังคั่นคำด้วยช่องว่าง ไม่มีคำที่มีช่องว่างข้างใน คำที่ต่อท้ายด้วย * หรือ ~ มีข้อห้ามจับคู่ (หัวข้อ 6)

**น้ำเสียง** คำแบ่งเป็นสองชุดตามผลของปาฏิหาริย์ในโลก

| ชุด | ใช้เมื่อ | ลักษณะคำ |
| --- | --- | --- |
| อุ่น สว่าง | สร้าง (จ่ายด้วยแสงศรัทธา) | ของที่คนเห็นทุกวัน ฝน ไฟเตา รวงข้าว แสงเช้า ไม่หวานเกินไป |
| หนัก มืด | ทำลาย (จ่ายด้วยความหวาดกลัว) | ของที่คนกลัวจริงในโลกนี้ เถ้า ลาวา เหล็กแดง ห่า ไม่ใช้คำหยาบ ไม่ใช้คำสยอง |

### 2.2 คำขยาย

เมล็ดเลือกก่อนว่าจะใช้คำตามกริยาหรือคำสี (เลขคู่ใช้คำตามกริยา เลขคี่ใช้คำสี) แล้วจึงเลือกคำในคลังนั้น คำสีใช้น้ำเสียงเดียวกับภาพ

| กริยา | คำขยายตามกริยา (10) |
| --- | --- |
| ให้กำเนิด | แรกเกิด ผลิบาน แรกรุ่ง เกิดใหม่ แตกหน่อ เบิกฟ้า ปฐม อุดม งอกงาม ล้นเหลือ |
| ทำลาย | ล้างผลาญ ทลาย พินาศ ร้าวราน ไร้ปราณี กลืนกิน ผนึกแตก สิ้นสูญ แหลกลาญ ลงทัณฑ์ |
| เปลี่ยน | ผันแปร พลิกผัน แปรธาตุ กลายร่าง ผลัดใบ ผลัดผิว พลิกฟ้า สลับสี หลอมใหม่ เวียนคืน |
| ปลุก | ลืมตา ตื่นรู้ ลุกโชน กระหึ่ม ฟื้นแรง สะท้านฟ้า คืนแรง ลั่นกลอง ฮึกเหิม ผนึกสั่น |
| สงบ | เงียบสงบ เย็นใจ อ่อนโยน ราบเรียบ ปรองดอง รับขวัญ กล่อมนอน คืนสุข เย็นฉ่ำ สงบนิ่ง |
| เผย | กระจ่าง ปรากฏ เห็นแจ้ง เผยโฉม เปิดตา ฉายแสง แจ้งใจ โผล่พ้น ไขลับ ผนึกเปิด |

| น้ำเสียง | คำสี (10) |
| --- | --- |
| อุ่น สว่าง | ทอง เงิน ขาว ฟ้าใส เขียวอ่อน ส้มทอง อำพัน ชมพู รุ้ง ม่วงอ่อน |
| หนัก มืด | ดำ แดงเลือด เทาเถ้า เขียวพิษ ม่วงคล้ำ ครามเข้ม ขาวซีด แดงฉาน สนิม ดำสนิท |

ทอง เงิน แดงเลือด เทาเถ้า เป็นสีที่เอกสารใช้แล้ว ([../god/04-miracles.md](../god/04-miracles.md) · [../../appearance/20-god-ui.md](../../appearance/20-god-ui.md) หัวข้อ 7.4) เปลี่ยนและปลุกไม่มีน้ำเสียงของตัวเอง คำตามกริยาของสองตัวนี้ใช้ได้กับทั้งสองชุด

## 4. ลัทธิจากซาก

แม่แบบ {ผู้}{กริยาบูชา}{หลุม/น้ำ}{ชื่อเดิม} มีสองรูปแบบ เมล็ดเลือกรูปแบบก่อน

| รูปแบบ | ประกอบ | ตัวอย่าง |
| --- | --- | --- |
| ก ทำ | "ผู้" + กริยาบูชา + หลุมหรือน้ำ + ชื่อเดิม | ผู้เฝ้าหลุมซอร์เนบ |
| ข สังกัด | คำสังกัด + หลุมหรือน้ำ + ชื่อเดิม | บุตรแห่งก้นน้ำลูเมนธาล |

**กริยาบูชา** เลือกชุดตามพลังของพระเจ้า ณ วันที่ลัทธิเกิด ([../god/04-miracles.md](../god/04-miracles.md) หัวข้อ 5 RU-04) ถ้าความหวาดกลัวสูงกว่าแสงศรัทธา ใช้ชุดเกรง ถ้าไม่ ใช้ชุดเฝ้ารอ

| ชุด | คำ (8) |
| --- | --- |
| เฝ้ารอ | เฝ้า ฟัง รอ ไว้ทุกข์ ระลึก ขานชื่อ เก็บเถ้า ดูแล |
| เกรง | เกรง กราบ สำนึก ชดใช้ ขอขมา บูชา ยำเกรง สวดขอ |

**คำสังกัด** (8) บุตรแห่ง คนของ สาวกแห่ง ศิษย์แห่ง ลูกของ พี่น้องแห่ง ผู้รอดแห่ง เหล่าชนแห่ง

**หลุมหรือน้ำ** เลือกตามรูปของซากวันที่ลัทธิเกิด หลุมของ MR-17 (RU-01 ถึง RU-04) และทะเลสาบ (RU-08 หลัง MR-18 หรือ 20 ปีหลัง MR-17 ในประเทศที่ฝนชุก)

| รูปของซาก | คำ (8) |
| --- | --- |

### 5.1 ราก 143 ราก

**ราก** คือชิ้นสั้นของชื่อเดิม 1 ถึง 3 พยางค์ เลือกด้วยหูทีละประเทศ เขียนเป็นช่องในข้อมูลประเทศ ไม่ตัดจากตัวอักษรอัตโนมัติ ส่วนใหญ่เป็นพยางค์แรกหรือสองพยางค์แรก ขีดในชื่อ (ธรอ-ดู) ไม่ติดมา ทุกแถวมีรากหลักหนึ่งและรากสำรองหนึ่ง

| ข้อ | กติกาของราก |
| --- | --- |
| 1 | รากทั้ง 286 (หลัก 143 สำรอง 143) ไม่ซ้ำกันเลย ไม่เท่ากับชื่อของประเทศอื่นหรือทวีปใด (รากที่เป็นชื่อเต็มเท่ากับชื่อประเทศของแถวตัวเองเท่านั้น) ไม่มีรากขึ้นต้นด้วย "ซาก" |

| 5 | ราก 129 รากผ่านครบทั้ง 22 คู่ตามหัวข้อ 9.3 อีก 14 รากชนกับคำใหม่หรือคำฟื้นหนึ่งคำ: โรการ์ (แรก) · บาร์ดิน (บุรี) · นูวา นิวเฮเวน โนวา นิวา เนวาน (นว) · ทอร์ตู ทอลวา (ทอง) · นาคา (นคร) · รอส (เรือง) · ลาเวียร์ (เวียง) · ธาเนล (ธานี) · เลนิ (ลาน) เกมข้ามคู่นั้นตามขั้น 5 และ 6 ของหัวข้อ 9.1 รากเหล่านี้เหลือ 21 คู่ ไม่ต้องแก้ราก |

### 10.1 เสกตามใจ

| สถานะ | เลือกได้ | ชื่อ | ตัวอักษร |
| --- | --- | --- | --- |
| ให้กำเนิด · น้ำ · ประเทศซอร์เนบ | ฝน (อุ่น) + เงิน (สีอุ่น) | **ฝนเงินแห่งซอร์เนบ** | 17 |
| ทำลาย · ไฟ · ประเทศทรอนกาธ | ลาวา (หนัก) + แดงเลือด (สีหนัก) | **ลาวาแดงเลือดแห่งทรอนกาธ** | 23 |
| สงบ · ลม · ประเทศทาลานีส | สายลม (อุ่น) + อ่อนโยน (กริยาสงบ) | **สายลมอ่อนโยนแห่งทาลานีส** | 23 |
| เผย · เงา · ประเทศไอเลวัน (นครคนตาบอด) | เงาร่ม (อุ่น) + เปิดตา (กริยาเผย) | **เงาร่มเปิดตาแห่งไอเลวัน** | 23 |
| ปลุก · ความตาย · ประเทศเวลมิร์ (จ่ายด้วยความหวาดกลัว จึงหนัก) | ศพเดิน (หนัก) + ลืมตา (กริยาปลุก) | **ศพเดินลืมตาแห่งเวลมิร์** | 22 |
| เปลี่ยน · ไฟ · ประเทศดูร์ดิน (สาธารณรัฐเหล็ก) | คบไฟ (อุ่น) + หลอมใหม่ (กริยาเปลี่ยน) | **คบไฟหลอมใหม่แห่งดูร์ดิน** | 23 |

**ลองใหม่เพราะยาวเกิน** ทำลาย · ไฟ · ประเทศทรอนกาธ รอบ 0 ได้ เพลิงโหม + ไร้ปราณี = เพลิงโหมไร้ปราณีแห่งทรอนกาธ 27 ตัวอักษร เกิน 24 ตัวนับลอง +1 รอบ 1 ได้ ลาวา + ล้างผลาญ = **ลาวาล้างผลาญแห่งทรอนกาธ** 23 ตัวอักษร ผ่าน

**ลองใหม่เพราะคู่ห้าม** สงบ · ไฟ · ประเทศซิลเฟลิส รอบ 0 ได้ ไฟเตา + เย็นฉ่ำ ตกข้อ 3 (ไฟเย็นขัดกัน) รอบ 1 ได้ ไฟเตา + รับขวัญ = **ไฟเตารับขวัญแห่งซิลเฟลิส** 24 ตัวอักษร
