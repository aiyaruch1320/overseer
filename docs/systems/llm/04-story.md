# LLM ที่เปลี่ยนเรื่องได้

ระบบ: [README.md](README.md) · เล่นได้โดยไม่มี LLM: [02-offline.md](02-offline.md) · ค่าใช้จ่าย: [01-cost.md](01-cost.md) · สั่งตัวละคร: [../character/19-wish.md](../character/19-wish.md)

ผู้ใช้ตั้งคำถาม (2026-11-01): ถ้า LLM แค่เขียนถ้อยคำและตั้งชื่อ มันไม่ได้ช่วยให้เรื่องต่างไป ไฟล์นี้กำหนดบทบาทที่ LLM **เปลี่ยนเรื่องได้จริง** แต่ยังอยู่ในขอบของเกม และยกเลิกการให้ LLM ตั้งชื่อระหว่างเล่น (ชื่อมาจากเกมอย่างเดียว [03-naming.md](03-naming.md))

## 1. บทบาท

| บทบาท | ทำอะไร | เปลี่ยนเรื่องไหม | ไม่มี LLM แล้ว |
| --- | --- | --- | --- |
| **ผู้เรียบเรียง** | รวมสิ่งที่เกิดในชีวิตเป็นบทสรุป การ์ดตอนจบ ตำนาน หน้าพงศาวดาร | ไม่ เปลี่ยนวิธีที่ผู้เล่นจำชีวิตนั้น | แม่แบบหลายประโยคประกอบจากบันทึก |
| **ผู้กำกับ** | ที่จุดแยก เกมเอียงน้ำหนักให้ทางที่โยงกับความทรงจำของชีวิตนี้ (ผู้กำกับตามกติกา) LLM ช่วยเลือกระหว่างสองทางที่ดีที่สุดที่จุดสำคัญ (เปิดเป็นค่าเริ่มต้น สวิตช์ `llm_director`) | **ใช่** ภายในทางที่เกมอนุญาต | ผู้กำกับตามกติกายังทำงาน |
| **ผู้แปล** | แปลคำพูดของผู้เล่นเป็นค่าที่เกมเข้าใจ (สั่งตัวละคร เข้าฝันด้วยคำพูดของตัวเอง) | **ใช่** ผู้เล่นพูดอะไรก็ได้ เกมเข้าใจ | ผู้เล่นเลือกจากตัวเลือกบนจอ |
| **ผู้เขียนถ้อยคำ** | ภาพฝัน คำอธิษฐาน ข่าวลือ บทพูด NPC | ไม่ | คลังชั้น 1 · **ยังไม่ทำ** ผู้ใช้ตัดสิน (2026-11-01) ใช้แม่แบบและคลังไปก่อน |

**ผู้ใช้ตัดสินแล้ว (2026-11-01)** ใช้ LLM สามจุด: ผู้แปลก่อนเกิด (`setup`) ผู้กำกับระหว่างชีวิต (`director`) และผู้เรียบเรียงตอนจบ (`epitaph`) ([README.md](README.md) หัวข้อ 2) งานอื่นในไฟล์นี้เก็บเป็นไอเดีย

## 2. ผู้เรียบเรียง

งานที่ผู้ใช้ชอบที่สุดและเหมาะกับ LLM ที่สุด เพราะข้อเท็จจริงมีครบในบันทึกแล้ว เหลือแค่เลือกว่าอะไรสำคัญและเล่าอย่างไร

| งาน | ใช้เมื่อ | ข้อมูลเข้า | ข้อมูลออก |
| --- | --- | --- | --- |
| `epitaph` (ใช้) | ตัวละครตาย | บันทึกชีวิตทั้งหมด เหตุการณ์ที่มีน้ำหนักมากที่สุด คนที่เจอซ้ำ คำปฏิญาณและผล ชื่อในทะเบียน | **สรุปเส้นเรื่องทั้งชีวิต** ให้ผู้เล่นอ่าน (สามถึงห้าย่อหน้าสั้นตามช่วงวัย) **การ์ดตอนจบ** (หัวข้อ 2.1) **จารึก** และหน้าคำปฏิญาณ ในคำขอเดียว |
| `world_legend` (ใช้) | โลกถึงฉากจบ | สรุปโลก | ตำนานของโลก |
| `chapter` `legend` `chronicle` (ยังไม่ทำ) | จุดหยุดตามอายุ โหนดที่ระบุ ปาฏิหาริย์ | | ใช้แม่แบบที่ประกอบจากบันทึก |
| `world_legend` | โลกถึงฉากจบ | สรุปโลก | ตำนานของโลก |

### 2.1 การ์ดตอนจบ

การ์ดแชร์ตอนจบ ([../experience/03-ending-and-collection.md](../experience/03-ending-and-collection.md) หัวข้อ 4) เกมเลือก **ข้อเท็จจริง** ทั้งหมด LLM เลือก **ลำดับและน้ำเสียง**

| ช่อง | มาจาก |
| --- | --- |
| ชื่อ เผ่า ถิ่น อายุที่ตาย ฉายาชีวิต ฉายาของพระเจ้า | บันทึก |
| สามช่วงเวลาที่เปลี่ยนชีวิต | เกมเสนอห้าเหตุการณ์ที่มีน้ำหนักมากที่สุด (เปลี่ยนชนชั้น จุดบรรจบ ความตายของคนใกล้ตัว ความฝันที่ทำตาม ปาฏิหาริย์ที่เห็น) LLM เลือกสามและเรียงให้เป็นเรื่อง |
| หนึ่งประโยคที่จำ | LLM เขียนจากสามช่วงเวลา |
| จารึก | LLM หรือแม่แบบ |

## 3. ผู้กำกับ

ผู้กำกับคือบทบาทที่ทำให้เรื่องต่างไปจริง ได้แนวคิดจากผู้เล่าเรื่องของ RimWorld และเหตุการณ์ที่รู้ว่าเกิดอะไรมาก่อนของ Hades: ชีวิตที่มีผู้กำกับมีเรื่องที่ **โยงกลับ** มากกว่าชีวิตที่สุ่มล้วน (ศัตรูเก่ากลับมา คนที่ช่วยไว้ตอบแทน ความฝันที่ปฏิเสธกลับมาหลอน)

**ผู้ใช้ตัดสินแล้ว (2026-11-01): ผู้กำกับมีสองชั้น** ชั้นหลักคือผู้กำกับตามกติกาของเกม ไม่ใช้ LLM ชั้นบนคือผู้กำกับ LLM **เปิดเป็นค่าเริ่มต้น** ปิดได้ด้วยสวิตช์ `llm_director` ([README.md](README.md) หัวข้อ 3) และวัดผลตามหัวข้อ 3.5 เพื่อตัดสินว่าจะเก็บไว้

### 3.1 ทำงานอย่างไร

1. ถึงจุดแยก เกมสร้างรายการ **ทางที่เป็นไปได้** ตามกติกาเดิม (ทางที่ถูกตัดไม่อยู่ในรายการ) พร้อมน้ำหนักเดิม
2. **ผู้กำกับตามกติกา** เทียบทุกทางกับ **ความทรงจำ** ของชีวิตนี้ (แปดบรรทัด: คำถามของชีวิต คำปฏิญาณ คนที่เจอซ้ำ เรื่องค้าง ความฝันที่ทำตามหรือปฏิเสธ เหตุการณ์ล่าสุด เกมอัปเดตเมื่อมีเหตุการณ์สำคัญ ไม่ค้นย้อนจากบันทึก) ทางที่ตรงได้ตัวคูณตามตารางข้างล่าง คูณกันได้ไม่เกิน ×2
3. **ผู้กำกับ LLM** ถ้าสวิตช์เปิดอยู่และจุดนี้เป็นจุดสำคัญ (หัวข้อ 3.4) เกมส่งสองทางที่ผู้กำกับตามกติกาให้คะแนนสูงสุดพร้อมความทรงจำ LLM เลือกหนึ่งทางและเหตุผลหนึ่งรหัส (โยงคนเก่า โยงความฝัน โยงคำถามของชีวิต โยงคำปฏิญาณ ให้พัก ให้ตึงขึ้น) ทางที่เลือก ×1.5 เพิ่ม รวมทั้งสองชั้นไม่เกิน ×2.5
4. เกมทอยตามน้ำหนักที่ได้ **ไม่มีชั้นไหนเลือกแทน** ทางที่น้ำหนักเดิมต่ำมากยังไม่น่าเกิด
5. ค่าที่ LLM ตอบบันทึกลงเซฟ เปิดเซฟหรือเล่นซ้ำใช้ค่าที่บันทึก ไม่ถามใหม่ ผู้กำกับตามกติกาไม่ต้องบันทึกเพราะคำนวณซ้ำได้จากเมล็ดและสถานะ

**ตัวคูณของผู้กำกับตามกติกา** (วัดสองแถวแรกแล้ว หัวข้อ 3.5 แถวอื่นเป็นค่าเริ่มต้น)

| ทางนี้เกี่ยวกับ | ตัวคูณ |
| --- | --- |
| คนที่เจอซ้ำ หรือพวกพ้อง | ×1.75 |
| เรื่องค้างของชีวิตหรือของสายตระกูล | ×1.75 |
| แท็กของคำถามของชีวิต | ×1.3 |
| แท็กของคำปฏิญาณ | ×1.3 |
| สัญลักษณ์หรือเป้าหมายของความฝันที่เคยส่ง (ทำตามหรือปฏิเสธ) | ×1.3 |
| เหตุการณ์ใหญ่เกิดในสามปีชีวิตล่าสุด และทางนี้เป็นเรื่องเงียบ | ×1.3 (ให้พัก) |
| ช่วงเงียบเกินห้าปีชีวิต และทางนี้มีความขัดแย้ง | ×1.3 (ให้ตึงขึ้น) |

### 3.5 การทดลองที่ต้องผ่าน

| ทดลอง | ผ่านเมื่อ |
| --- | --- |
| นับในตัวจำลอง (ไม่มี LLM vs ผู้กำกับตามกติกา) | ผู้กำกับตามกติกาเพิ่มเรื่องโยงกลับต่อชีวิต (NPC ที่เจอซ้ำ เรื่องค้างที่ได้สาง ความฝันที่ถูกอ้างถึง) อย่างน้อย 30% ถ้าไม่ถึง ปรับตัวคูณ |
| A/B กับผู้เล่นจริง (สวิตช์ปิด vs เปิด) | ผู้เล่นเลือกชีวิตที่มี LLM ว่า "รู้สึกเป็นเรื่องเดียวกันมากกว่า" ในสัดส่วนที่ชัด (เช่น 60% ขึ้นไป) และเรื่องโยงกลับเพิ่มอีกอย่างน้อย 15% |
| ไม่ผ่าน | ตั้ง `llm_director` เป็นปิด ผู้กำกับตามกติกาอยู่ต่อ |

**ผลนับในตัวจำลอง** (2026-11-01 `node scripts/sim/sim-life.mjs 1500 --director`) เรื่องโยงกลับคือทางที่ตัวละครเลือกแล้วระบุ NPC หรือเหตุการณ์โลกที่ชีวิตนี้เจอมาก่อน ทั้งสองแบบใช้เมล็ดเดียวกัน

| ผู้กำกับ | จุดที่มีทางโยงกลับต่อชีวิต | เรื่องโยงกลับต่อชีวิต |
| --- | --- | --- |
| ปิด | 0.34 | 0.13 |
| ตามกติกา (×1.75) | 0.34 | 0.17 |

เพิ่มขึ้น 34% (เป้าอย่างน้อย 30%) · 1500 ชีวิตต่อเผ่า

- ที่ ×1.5 เพิ่มเพียง 24% ไม่ถึงเป้า ×1.75 เพิ่ม 34% ×2 เพิ่ม 43% จึงตั้งสองแถวแรกเป็น ×1.75 ยังอยู่ใต้เพดานรวม ×2
- ผลเพิ่มสูงสุดเมื่อทางที่โยงกลับมีส่วนน้อยของทางทั้งหมด ถ้าทางโยงกลับมีราวหนึ่งในสาม ตัวคูณ ×1.5 เพิ่มได้ไม่ถึง 30% เสมอ
- ตารางเส้นเรื่องมีจุดที่มีทางโยงกลับเพียงราว 0.34 จุดต่อชีวิต เพราะโหนดส่วนใหญ่ไม่ระบุคนที่เจอมาก่อน งานหลักของผู้กำกับจึงอยู่ที่คนที่จะเจอซ้ำและเหตุการณ์ช่วงเงียบ (หัวข้อ 3.2) ซึ่งตัวจำลองนี้ไม่มี ต้องนับซ้ำเมื่อลงโค้ด

| ขั้น | กติกา |
| --- | --- |
| แปล | LLM จับข้อความเข้ากับหนึ่งในสามทางที่เกมเสนอ หรือ "ไม่ตรงทางใด" และบอกความชัด (ชัด หรือ กำกวม) |
| ผล | ตรงทางใด ใช้ทางนั้นตามกติกาความฝัน ความชัด "ชัด" ให้ความชัด +0.05 "กำกวม" ให้ −0.05 ([../god/03-dreams.md](../god/03-dreams.md) หัวข้อ 3) ไม่ตรงทางใด ส่งเป็นความฝันที่ไม่ชี้ทาง ตัวละครจำได้ (ใช้ในบทพูดภายหลัง) ไม่เสียแสงศรัทธา |
| ข้อความของผู้เล่น | ปรากฏในฉากฝันเป็นเสียงที่ตัวละครได้ยิน ผ่านตัวกรองเนื้อหาก่อน |
| ไม่มี LLM | ช่องพิมพ์ไม่แสดง ผู้เล่นเลือกจากสามทางตามปกติ |

ทางนี้ทำให้ผู้เล่นรู้สึกว่าพูดกับตัวละครจริง แต่ผลยังมาจากสามทางที่เกมตรวจแล้ว

## 5. ผลต่อการเล่นซ้ำ

ผู้กำกับและผู้แปลเปลี่ยนตัวเลขได้ จึงแก้หลักใน [02-offline.md](02-offline.md) หัวข้อ 1 ข้อ 2 เป็น

- ไม่มี LLM เกมเล่นได้เต็มและเหมือนเดิมทุกอย่าง
- มี LLM ผลต่างได้เฉพาะจุดที่ไฟล์นี้อนุญาต และทุกคำตอบที่เปลี่ยนตัวเลขบันทึกลงเซฟ
- เล่นซ้ำด้วยเมล็ดเดิมและเซฟเดิม ได้ชีวิตเดิมเสมอ ไม่ว่ามี LLM ตอนเล่นซ้ำหรือไม่
- การทดสอบเทียบแฮชของสถานะ ทำโดยปิดผู้กำกับและผู้แปล หรือเล่นซ้ำจากค่าที่บันทึก
