# การเดินทางและการเจอต่างเผ่า

ภาพรวมชั้นระบบ: [../README.md](../README.md) · เส้นเรื่องที่ใช้กติกานี้: [../../lore/storylines/25-journeys.md](../../lore/storylines/25-journeys.md) · การค้า: [../economy/05-trade.md](../economy/05-trade.md)

ตัวละครไม่จำเป็นต้องเดินทาง ชีวิตทั้งชีวิตในประเทศเดียวทำได้และเป็นชีวิตที่ถูกต้องแบบหนึ่ง แต่ชีวิตที่เดินทางต้องเดินทางได้อย่างสมเหตุสมผล: ไปที่ที่ตัวละครเข้าได้ ด้วยเหตุที่ตัวละครมี และเจอสิ่งที่ที่นั่นมีจริง

| ไฟล์ | เนื้อหา |
| --- | --- |
| [01-travel-rules.md](01-travel-rules.md) | ระดับการเดินทางของชีวิต เหตุที่ทำให้ได้เดินทาง ตัวกรองจุดหมาย (เส้นทาง ท่าทีของเผ่า ศีลธรรมและอาชีพ ธงโลก) ตารางระหว่างทาง เป้าของการเจอต่างเผ่า |
