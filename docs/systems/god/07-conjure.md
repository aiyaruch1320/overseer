ผู้ใช้ตัดสินแล้ว (2026-11-01): พระเจ้าเสกอะไรก็ได้ แต่ต้องมีจำนวนจำกัด ไฟล์นี้ให้ผู้เล่นประกอบปาฏิหาริย์เองจากชิ้นส่วนสามชิ้น ผลมาจากตารางของเกม ไม่ได้มาจากการพิมพ์อิสระ เกมตั้งชื่อจากคลังคำและเล่าวันเกิดเหตุจากแม่แบบ ไม่ใช้ LLM

## 4. เงาสะท้อน

การฝืนโลกมีราคาที่ไม่ได้ตั้งใจ (แบบ Paradox ของ Mage) ทุกการเสกตามใจทอยเงาสะท้อนหนึ่งครั้ง

| ขนาด | โอกาส |
| --- | --- |
| คน | 0% |
| ถิ่น | 10% |
| ประเทศ | 20% |
| ทวีป | 35% |

แก่นที่ขัดกับภูมิอากาศของที่ (ไฟในเขตน้ำแข็ง น้ำในเขตลาวา ชีวิตในซาก) +15% เงาสะท้อนเป็นผลระดับเล็กหนึ่งอย่างที่ประเทศข้างเคียงหรือที่เดียวกัน เลือกตามแก่น

| แก่น | เงาสะท้อน |
| --- | --- |
| ไฟ | ไฟลามระดับเล็ก (W −1 สองปี) |
| น้ำ | น้ำท่วมเล็กหนึ่งฤดู |
| ดิน | แผ่นดินไหวเล็ก |
| ลม | พายุเล็กในทะเลข้างเคียง |
| ชีวิต | สัตว์ป่าเพิ่ม ศึกสุ่มในประเทศ ×2 สองปี |
| ความตาย | ผีเร่ร่อนหนึ่งตน (ศัตรูระดับถิ่น) |
| แสง | ผู้คลั่งศาสนาหนึ่งกลุ่ม (เหตุการณ์ท้องถิ่น) |
| เงา | ฝันร้ายระบาดหนึ่งปี |

## 6. ขั้นตอน

1. ผู้เล่นเปิดหน้าเสกตามใจ เลือกกริยา แก่น ขนาด แล้วเลือกเป้าหมายบนแผนที่
2. เกมหาผลจากตารางปฏิกิริยา (หัวข้อ 3) แล้วตารางผล (หัวข้อ 2) แสดงผลที่คาด ราคา โอกาสเงาสะท้อน และลางหนึ่งบรรทัด ถ้าส่วนผสมตรงกับ MR เกมบอกว่าเป็นปาฏิหาริย์ในรายการ ไม่ใช้โควต้า
3. เกมตั้งชื่อจากคลังคำ (เช่น "ฝนเงินแห่งซอร์เนบ" [../llm/03-naming.md](../llm/03-naming.md)) และเลือกรายละเอียดด้วยเมล็ด (ใครเห็นก่อน ตกที่จุดไหนของเมือง สีของแสง) รายละเอียดไม่เปลี่ยนตัวเลข ห้าจังหวะของวันเกิดเหตุใช้แม่แบบตามแก่นและกริยา
4. ผู้เล่นกดค้างยืนยัน ขนาดประเทศขึ้นไปมีลางหนึ่งฤดูเหมือนปาฏิหาริย์ใหญ่
5. ผลเกิด ทอยเงาสะท้อน ลงพงศาวดารและทะเบียนชื่อของโลก ชื่อนี้เป็นของโลก เหตุการณ์และ NPC ภายหลังใช้ชื่อนี้ได้ (เช่น "ตั้งแต่ฝนเงินแห่งซอร์เนบ")

**ผลคงที่** ส่วนผสม เป้าหมาย และสถานะโลกเดียวกัน ด้วยเมล็ดเดียวกัน ได้ผลและชื่อเดียวกันเสมอ

## 7. ความเป็นไปได้

6 กริยา × 8 แก่น × 4 ขนาด = 192 ส่วนผสม ช่องที่เสกได้เฉพาะโหมดนี้ 33 ช่อง × 4 ขนาด = 132 ส่วนผสมใหม่ × เป้าหมาย 143 ประเทศ (ขนาดคน: NPC 614 ตัว) และปฏิกิริยา 10 แบบ เงาสะท้อน 8 แบบ ชื่อจากคลังคำทำให้ปาฏิหาริย์แต่ละครั้งมีตัวตนในโลก ผลมาจากตารางที่ตรวจได้
