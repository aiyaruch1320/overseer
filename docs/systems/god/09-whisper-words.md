# ตารางคำพูดของกระซิบ

ระบบ: [README.md](README.md) · กระซิบ: [03-dreams.md](03-dreams.md) หัวข้อ 6 · LLM: [05-llm.md](05-llm.md) · ตัวแปลคำพ้องของตัวละคร: [../character/20-wish-synonyms.md](../character/20-wish-synonyms.md) · หน้าจอ: [../../appearance/20-god-ui.md](../../appearance/20-god-ui.md) หัวข้อ 5

ตารางที่ตัวแปลของเกมใช้อ่านคำที่ผู้เล่นพิมพ์ในช่องกระซิบ ([../llm/README.md](../llm/README.md) หัวข้อ 2 จุด `command`) เป็นทางแรกที่ทำงานเสมอ ไม่ต้องใช้ LLM ตัวสร้างข้อมูลอ่านตารางนี้เข้า `data/gen/god.json`

## 1. กติกา

| ข้อ | กติกา |
| --- | --- |
| 1 | ชื่อของคำใบ้ ([03-dreams.md](03-dreams.md) หัวข้อ 6) เป็นคำพูดของมันเสมอ ไม่ต้องเขียนซ้ำในตาราง |
| 2 | ตัดเว้นวรรคและอักขระควบคุมก่อนเทียบ ค้นคำในประโยคทั้งประโยค คำที่ยาวที่สุดชนะ |
| 3 | คำพูดของคำใบ้ไม่ซ้ำกับของคำใบ้อื่น และไม่ใช้คำที่มีชื่อคำใบ้อื่นอยู่ข้างใน |
| 4 | คำใบ้ที่ชี้ (จงไป คนนั้นโกหก ช่วย ชี้ทายาท) ต้องมีชื่อหรือรหัสของที่หรือคนในประโยคด้วย ถ้าไม่มีให้ส่งต่อให้ LLM (ถ้าเปิด) หรือแสดงเก้าคำใบ้ |
| 5 | ไม่เจอคำใดเลย ตัวแปลไม่เดา แสดงเก้าคำใบ้ |
