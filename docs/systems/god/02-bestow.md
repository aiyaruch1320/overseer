# หีบประทาน

ระบบ: [README.md](README.md) · ราคา: [01-power.md](01-power.md) · พร: [../character/05-new-blessings.md](../character/05-new-blessings.md) · คำสาป: [../character/06-new-curses.md](../character/06-new-curses.md) · ของ: [../items/README.md](../items/README.md) · ภาพ: [../../appearance/20-god-ui.md](../../appearance/20-god-ui.md) หัวข้อ 3

พระเจ้าไม่ได้เลือกจากคลังทั้งหมด พระเจ้าเปิดหีบ เกมสุ่มสิ่งที่ประทานได้ **ไม่เกิน 6 อย่าง** ตามสภาพของตัวละครตอนนั้น พระเจ้าเลือกหนึ่งอย่างหรือไม่เลือกเลย

## 1. หกช่อง

แบ่งเป็นคู่ตามชนิด เพื่อให้ผู้เล่นเทียบได้เร็ว (หกตัวเลือกปนกันอ่านยาก การแบ่งคู่ทำให้เหลือการเทียบสามครั้ง)

| ช่อง | ชนิด | คลัง | ถ้าคลังว่าง |
| --- | --- | --- | --- |
| 1 2 | **พร** | พร 200 (โค้ด 107 ใหม่ 93) และพรของเผ่า | ช่องว่าง |
| 3 4 | **คำสาป** | คำสาป 152 และคำสาปของเผ่า | ช่องว่าง |
| 5 | **ฝีมือ** | เลื่อนความถนัดที่มีหนึ่งระดับ หรือสกิลใหม่ ([../character/07-new-skills.md](../character/07-new-skills.md)) | กลายเป็นพรอีกหนึ่งใบ |
| 6 | **ของ** | อาวุธ ถ้ายังไม่เคยได้อาวุธประทาน · ไม่เช่นนั้นเกราะ เครื่องประดับ ของขลังพื้นบ้าน ของใช้ | ช่องว่าง |

หีบที่มีช่องว่างคือ "ไม่เกิน 6" ตามที่ออกแบบ หีบไม่เติมของที่ไม่เข้ากับตัวละครเพื่อให้ครบ

## 2. ใครได้อะไร (ตัวกรอง)

ของที่ไม่ผ่านตัวกรองไม่ขึ้นในหีบเลย

| ตัวกรอง | กติกา |
| --- | --- |
| มีอยู่แล้ว | พรหรือคำสาปที่ตัวละครมีอยู่แล้วไม่ขึ้น ไม่ซ้อนกัน |
| ขัดกัน | พรที่ตรงข้ามกับคำสาปที่มี (และกลับกัน) ไม่ขึ้น ใช้คู่ตรงข้ามจากแท็กในแคตตาล็อก |
| เผ่าและกำเนิด | พรและคำสาปของเผ่าอื่นไม่ขึ้น ([../character/races/](../character/races/README.md)) ของที่เผ่านั้นใช้ไม่ได้ไม่ขึ้น (ถุงมือสำหรับเผ่าที่ไม่มีมือ อาวุธดาบสำหรับสไลม์) |
| วัย | ต่ำกว่าอายุเทียบ 13 ช่อง 6 ไม่มีอาวุธ ขึ้นของขลังพื้นบ้านหรือของเล่นแทน ([../items/README.md](../items/README.md)) |
| ระดับ L | พร L ขึ้นได้เมื่อศรัทธาเทพ ≥ 50 หรือที่หน้าต่างพระเจ้า คำสาป L ขึ้นได้เมื่อศรัทธาเทพ ≤ −30 หรือที่หน้าต่างพระเจ้า |
| ของที่มีชิ้นเดียวในโลก | อาวุธตำนาน 36 ชิ้น เครื่องรางโบราณที่มีผู้สถิต 24 ชิ้น และของคู่ ไม่ขึ้นในหีบ (มีเจ้าของและเรื่องของตัวเอง [../items/08-legendary.md](../items/08-legendary.md)) |
| อาชีพลับ | ของและพรที่เป็นเงื่อนไขของอาชีพลับขึ้นได้ แต่ไม่ให้อาชีพเอง ([../character/10-jobs-secret.md](../character/10-jobs-secret.md)) |

**ซ้ำกับ NPC ได้** พรและคำสาปที่ NPC มีอยู่ ขึ้นในหีบได้ตามปกติ ไม่มีพรหรือคำสาปที่โลกมีได้คนเดียว ยกเว้นที่แถวของมันเขียนไว้ว่าเป็นของคนเดียว

## 3. การสุ่ม

แต่ละช่องสุ่มแยกกัน ไม่ซ้ำกันในหีบเดียว

**น้ำหนักพื้นฐานตามระดับ** (จาก `RARITY` ในโค้ด) C 100 · U 38 · R 11 · E 2.6 · L 0.5

**ตัวคูณตามสถานการณ์** คูณกันได้ แล้วปรับให้รวมเป็น 100 ในแต่ละช่อง

| เงื่อนไข | ตัวคูณ |
| --- | --- |
| แท็กของของตรงกับโหนดเส้นเรื่องที่ตัวละครกำลังจะถึง (ภายในหนึ่งปีชีวิต) | ×3 |
| ตรงกับอาชีพ ความถนัด หรือสัตว์คู่หูของตัวละคร | ×2 |
| ตรงกับถิ่นที่อยู่ (ประเทศ ทวีป ภูมิอากาศ) | ×1.5 |
| ตรงกับเหตุการณ์โลกที่เพิ่งเกิดในทวีป (สิบปีล่าสุด) หรือที่มีลางอยู่ | ×2 |
| ระดับ E และ L ในยุค 3 และ 4 | ×1.5 |
| ศรัทธาเทพ ≥ 50: พร R ขึ้นไป · ศรัทธาเทพ ≤ −30: คำสาป R ขึ้นไป | ×1.3 |
| ช่องคำสาปเมื่อตัวละครกำลังอยู่ในศึก | คำสาปที่ใช้กับศัตรูได้ ×2 |

**ตัวชดเชยความหายาก** (แบบ Slay the Spire) เริ่มที่ −5% หีบที่ไม่มีของระดับ R ขึ้นไปในช่องพรหรือช่องของ เพิ่ม +2% ให้โอกาส R ของหีบถัดไป รีเซ็ตเมื่อขึ้น R ขึ้นไป

**หีบที่หน้าต่างพระเจ้า** ถ้าแถวหน้าต่างพระเจ้าระบุพร (เช่น `b_courage` ใน `hu.b2`) ช่องพรใบหนึ่งเป็นพรนั้นแน่นอน ถ้าระบุคำใบ้ หีบไม่เปลี่ยน แต่ปุ่มกระซิบจะเน้นคำใบ้นั้น ([03-dreams.md](03-dreams.md) หัวข้อ 6)

## 4. เลือก ทอยใหม่ ข้าม

| การกระทำ | ผล |
| --- | --- |
| **เลือก** | จ่ายราคาของใบนั้น ([01-power.md](01-power.md) หัวข้อ 2) ของถึงตัวละครทันที ศรัทธาเทพเปลี่ยนตาม [01-power.md](01-power.md) หัวข้อ 3 หีบปิด |
| **ทอยใหม่** | สุ่มใหม่ทั้งหกช่อง ราคา 5 · 10 · 20 แสงศรัทธา ไม่เกินสามครั้งต่อปีชีวิต ใบที่ถูกทอยทิ้งไม่ขึ้นอีกในปีนั้น |
| **ล็อกหนึ่งใบแล้วทอย** | ทอยใหม่ห้าช่องที่เหลือ ราคาเพิ่ม +5 จากการทอยปกติ |
| **ข้าม** | ไม่จ่าย หีบปิด นับเป็นการเปิดหีบของปีนั้น |

**ตัวละครรู้ว่าได้อะไร** เกมแสดงฉากสั้นตอนตัวละครได้รับ (ฝัน แสง ลมพัด ของตกตรงหน้า) ตัวละครที่ศรัทธาเทพ ≥ 20 รู้ว่ามาจากพระเจ้า ตัวละครที่ต่ำกว่าคิดว่าเป็นโชค (ศรัทธาเทพยังเปลี่ยนตามตาราง แต่ครึ่งเดียว)

**ปฏิเสธพร** ตัวละครไม่ปฏิเสธพรหรือคำสาปได้ ยกเว้นผู้ถือ `curse_ward` ที่สะท้อนคำสาปกลับ (ศรัทธาเทพ −5) และผู้ถือ `wj_godslayer_e` `wk_az_3` ที่การแทรกแซงไม่มีผล

**ของประทาน** ตัวละครสวมใส่เองตามกติกาเดิม ([../items/11-item-system.md](../items/11-item-system.md)) พระเจ้าไม่สั่งสวมหรือถอด สิ่งที่พระเจ้าทำได้คือกระซิบ `จงไป` หรือส่งฝันที่ชี้ไปหาการใช้ของนั้น

## 5. อาวุธประทาน

| กติกา | ค่า |
| --- | --- |
| จำนวน | หนึ่งชิ้นต่อตัวละคร ตลอดชีวิต |
| ระดับ | C ถึง E จากแคตตาล็อกอาวุธ ([../../_generated/weapon-catalog.md](../../_generated/weapon-catalog.md)) ไม่รวมอาวุธตำนาน |
| ศักดิ์สิทธิ์หรือต้องสาป | ช่อง 6 ขึ้นอาวุธหนึ่งชิ้น สุ่มว่าเป็นรุ่นศักดิ์สิทธิ์ (จ่ายแสงศรัทธา แท็ก `holy` เพิ่ม) หรือรุ่นต้องสาป (จ่ายความหวาดกลัว แท็ก `cursed_weapon` เพิ่ม) ตามสัดส่วนแสงศรัทธาต่อความหวาดกลัวของพระเจ้าตอนนั้น ค่าสถานะอยู่ในงบของระดับเดิม |
| น้ำหนักพิเศษ | อาวุธที่ตรงกับอาชีพ ×3 อาวุธประจำถิ่นของประเทศที่อยู่ ×2 |
| อาวุธตำนานเล่มเดียวที่พระเจ้าสร้าง | `wl_light_sword` เกิดเมื่อ GD-04 เกิดผ่านตัวละคร ([../items/08-legendary.md](../items/08-legendary.md)) ไม่นับเป็นอาวุธประทาน |
| เมื่อตาย | ทายาทรับได้ ([01-power.md](01-power.md) หัวข้อ 6) ถ้าไม่มีทายาท อาวุธอยู่ที่หลุมศพ กลายเป็นของที่ NPC ไปหาได้ |

**ชี้ทางไปอาวุธตำนาน** พระเจ้าไม่ประทานอาวุธตำนาน แต่ใช้กระซิบ `จงไป` ไปยังที่คืนของอาวุธตำนานที่ไม่มีเจ้าของได้ ผลคือตัวละครเป็นผู้ชิงหนึ่งคน (โอกาสต่อทศวรรษ 10% ตาม [../items/08-legendary.md](../items/08-legendary.md) หัวข้อ 3 เพิ่มเป็น 15% เมื่อถูกชี้) การเปลี่ยนผลการทอยของผู้ชิงคนอื่นทำไม่ได้

## 6. กรณีพิเศษ

**พร L ที่ผูกกับมังกรเมื่อมังกรล้ม** (เผ่าปีก เงือก เผ่าลาวา) พรดับตามกติกาเดิมของมังกรล้ม ([../events/branches/01-dragon-falls.md](../events/branches/01-dragon-falls.md)) พระเจ้าได้ **หีบชดเชย** หนึ่งใบฟรี มีสามช่องพร ระดับ R ขึ้นไป หนึ่งใบระดับ E แน่นอน และขึ้นเฉพาะพรที่เข้ากับเผ่านั้น ตัวละครที่เคยมีพร L นั้นได้ศรัทธาเทพ +5 ถ้าพระเจ้าเลือกใบใดใบหนึ่ง

**หีบจากคำอธิษฐาน** คำอธิษฐานบางชนิดตอบแบบให้ได้ด้วยหีบเล็กสามช่อง ที่ขึ้นเฉพาะของที่ตรงกับคำขอ ([03-dreams.md](03-dreams.md) หัวข้อ 7) ไม่นับเป็นการเปิดหีบของปี

**คำสาปบนตัวละครของตัวเอง** มีเหตุผลสามอย่างที่ผู้เล่นจะสาปตัวละครหลัก คือ เป็นแหล่งความหวาดกลัวสำหรับปาฏิหาริย์สายลงโทษ คำสาปบางชนิดเปิดเส้นเรื่อง (เช่น ผู้ถูกกระทำ เปิดทางผู้ล่าเทพ) และผู้เล่นอยากเห็นชีวิตที่ยาก เกมไม่ห้าม แต่ศรัทธาเทพลดตามตาราง และชีวิตที่ถูกสาปซ้ำจะจบที่ฉายา "ผู้ถูกชิงชัง" ได้

**สาปผู้อื่น** หีบให้ของกับตัวละครหลักเท่านั้น การสาปศัตรูทำผ่านศึก (ศัตรู DC −2 ด้วยความหวาดกลัว [../combat/01-core.md](../combat/01-core.md) หัวข้อ 8) หรือผ่านการลงโทษผู้อธิษฐาน หรือผ่านปาฏิหาริย์ฟ้าผ่า ([04-miracles.md](04-miracles.md) MR-06)
