# เป้าหมายของผู้เล่น

ระบบ: [README.md](README.md) · ฉายาของพระเจ้า: [01-power.md](01-power.md) หัวข้อ 7 · บันทึกชีวิตและของสะสม: [../experience/03-ending-and-collection.md](../experience/03-ending-and-collection.md) · คำถามของชีวิต: [../experience/02-hooks.md](../experience/02-hooks.md) · ภาพ: [../../appearance/20-god-ui.md](../../appearance/20-god-ui.md) หัวข้อ 10

ผู้ใช้ให้ออกแบบเป้าหมายรวมกับระบบพระเจ้า (2026-11-01) เกมนี้ไม่มีคะแนนตัวเลข ผู้เล่นเป็นผู้เฝ้ามอง เป้าที่บังคับให้แทรกแซงมากจะทำลายบทบาทนั้น

## 1. หลัก

| ข้อ | หลัก | ที่มา |
| --- | --- | --- |
| 1 | เป้าคือเลนส์ที่ใช้มองชีวิต ไม่ใช่โควต้าที่ต้องทำให้ครบ | Reigns ให้สามเป้าต่อรัชกาล |
| 2 | รางวัลเป็นเรื่อง (ฉายา หน้าในพงศาวดาร) ไม่ใช่พลัง | Hades ใช้เรื่องเป็นรางวัล |
| 3 | ความล้มเหลวก็เขียนหน้าของมันเอง | Dwarf Fortress "แพ้คือสนุก" |
| 4 | สิ่งที่สะสมข้ามรอบเพิ่มทางเลือก ไม่เพิ่มความแรง | Wildermyth และ Reigns เปิดการ์ดใหม่ ไม่ใช่พลังใหม่ |
| 5 | ความยับยั้งได้รางวัล การแทรกแซงมากเกินมีราคาในเรื่อง | บทเรียนจากระบบความสำเร็จที่บั่นทอนแรงจูงใจภายใน |
| 6 | รายการที่ยังไม่พบเป็นเงา ไม่บอกวิธีทำ | ของสะสมเดิม ([../experience/03-ending-and-collection.md](../experience/03-ending-and-collection.md) หัวข้อ 5) |

## 2. คำปฏิญาณของพระเจ้า

ตอนตัวละครเกิด เกมเสนอคำปฏิญาณ 3 ข้อ ผู้เล่นเลือกหนึ่งข้อหรือไม่เลือก เปลี่ยนได้ครั้งเดียวที่จุดหยุดอายุ 15 ตรวจผลตอนตัวละครตาย

**เสนออย่างไร** สุ่มจากรายการข้างล่าง ถ่วงน้ำหนัก ×3 ให้ข้อที่ตรงกับคำถามของชีวิต จุดกำเนิด หรือลางตอนเกิด ข้อที่เป็นไปไม่ได้กับตัวละครนี้ไม่ขึ้น (สายเลือดสืบต่อ สำหรับหุ่นวิญญาณ มัมมี่ กูล สไลม์ที่แยกร่าง ใช้รูปผู้สืบแทน)

| รหัส | คำปฏิญาณ | สำเร็จเมื่อ |
| --- | --- | --- |
| GV-01 | ให้เขาอยู่จนแก่ | ตายตามธรรมชาติหลังอายุเทียบ 55 |
| GV-02 | ให้เขาตายอย่างสงบ | ตายนอกศึก ไม่มีคำสาปที่ยังอยู่ ศรัทธาเทพ ≥ 0 |
| GV-03 | ให้เขากลับบ้าน | ตายในประเทศเกิด หลังเคยออกจากทวีปเกิด |
| GV-04 | ให้เขาเห็นโลก | เคยอยู่อย่างน้อยสี่ทวีป |
| GV-05 | ให้สายเลือดสืบต่อ | มีทายาทที่มีชีวิตตอนตาย |
| GV-06 | ให้เขาได้รัก | มีสายคนรักระดับ 4 ขึ้นไป ([../bonds/README.md](../bonds/README.md)) |
| GV-07 | ให้คู่แข่งของเขาล้ม | NPC ที่เป็นคู่แข่งหรือผู้แค้นของตัวละครตายหรือหายก่อนตัวละคร |
| GV-08 | ให้เขาให้อภัย | ทางคืนดีกับผู้แค้นหรือผู้ทรยศถูกเลือกอย่างน้อยหนึ่งครั้ง |
| GV-09 | ให้เขาเป็นตำนาน | ได้อาชีพลับ อาวุธตำนาน หรือผ่านจุดบรรจบสองจุด |
| GV-10 | ให้เขาเป็นคนธรรมดาที่ดี | ไม่ได้อาชีพลับ ไม่ผ่านจุดบรรจบ แกนเมตตา ≥ 30 ตอนตาย |
| GV-11 | ให้เขารู้จักข้า | ศรัทธาเทพ ≥ 85 ตอนใดตอนหนึ่ง |
| GV-12 | ให้เขาเป็นตัวของเขาเอง | พระเจ้าแทรกแซงไม่เกินห้าครั้งทั้งชีวิต (ไม่นับคำอธิษฐานที่ตอบ) |
| GV-13 | ให้เขาเปลี่ยนชะตา | ชะตาร้ายหนึ่งข้อของเขาไม่เกิด ([../character/18-fates.md](../character/18-fates.md)) |

| GV-15 | ให้เขาเห็นมังกร | อยู่ในฉากเดียวกับมังกรตำนานอย่างน้อยหนึ่งครั้ง |

| GV-17 | ให้เขาสร้างสิ่งที่อยู่ต่อ | ทิ้งร้าน ตำแหน่ง อาวุธที่ตีเอง หรือลูกศิษย์ไว้ ([../../lore/storylines/26-hearth.md](../../lore/storylines/26-hearth.md)) |

| GV-19 | ให้เขาชิงชังข้า | ศรัทธาเทพ ≤ −70 ตอนตาย และอยู่ถึงวัยผู้เฒ่า (อายุเทียบ 55) (คำปฏิญาณของพระเจ้าที่อยากสร้างศัตรูของตัวเอง) |
| GV-20 | ไม่ปฏิญาณ | ไม่มีเงื่อนไข เลือกได้เสมอ |

**ผลตอนตาย**

| ผล | สิ่งที่ได้ |
| --- | --- |
| สำเร็จ | ฉายาของคำปฏิญาณบนหน้าบันทึกชีวิต หน้าพงศาวดารหนึ่งหน้า (LLM งาน `vow_page` หรือแม่แบบ) พงศาวดารสายตระกูล +3 |
| ไม่สำเร็จ | หน้าพงศาวดาร "คำปฏิญาณที่ไม่เป็นจริง" ที่เล่าว่าชีวิตไปทางไหนแทน พงศาวดารสายตระกูล +1 |
| ไม่ปฏิญาณ | ไม่มีหน้าพิเศษ ไม่มีโทษ |

คำปฏิญาณไม่เปลี่ยนราคา ไม่ให้พลัง ไม่เปลี่ยนการสุ่มของโลก ผู้เล่นเห็นมันมุมจอตลอดชีวิตเป็นข้อความเล็กข้อเดียว

## 3. ฉายาชีวิต

ตอนตาย เกมดูว่าชีวิตนี้ถูกครอบด้วยอะไร แล้วให้ฉายาหนึ่งถึงสามฉายา (แบบริบบิ้นของ BitLife ซ้อนกันได้ มีทั้งดีและร้าย) ฉายาเป็นของตัวละคร ต่างจากฉายาของพระเจ้า ([01-power.md](01-power.md) หัวข้อ 7) ที่เป็นของผู้เล่น

| ฉายา | ชีวิตถูกครอบด้วย |
| --- | --- |
| ผู้ศรัทธา | ศรัทธาเทพ ≥ 50 นานกว่าครึ่งชีวิตผู้ใหญ่ |
| ผู้ไม่มีใครเห็น | ไม่ผ่านจุดบรรจบ ไม่มีชื่อเสียง ไม่มีเหตุการณ์โลกมาแตะ |
| นักเดินทาง | อยู่มากกว่าห้าประเทศ |
| ผู้อยู่ที่เดิม | ไม่เคยออกจากประเทศเกิด |
| ผู้รบ | ศึกมากกว่า 30 ครั้ง |
| ผู้รักษา | อาชีพรักษาหรือช่วยชีวิตคนในเรื่องมากกว่าห้าครั้ง |
| ผู้ฆ่าญาติ | ฆ่าหรือทำให้ญาติหรือพวกพ้องตาย |
| ผู้ทรยศ | เลือกทางทรยศมากกว่าสองครั้ง |
| ผู้รอดจากฟ้า | อยู่ในประเทศตอนปาฏิหาริย์ระดับใหญ่หรือมังกรล้ม และรอด |
| ผู้ถูกเลือก | ทำตามความฝันมากกว่าห้าครั้ง |
| ผู้ขัดขืนฟ้า | ปฏิเสธหรือขัดขืนความฝันมากกว่าห้าครั้ง |
| ผู้รอฟ้า | ได้รับการประทานมากกว่า 15 ครั้ง (ดูหัวข้อ 6) |
| ผู้มั่งคั่ง | ขึ้นชนชั้นอย่างน้อยสองชั้น |
| ผู้ตกต่ำ | ตกชนชั้นอย่างน้อยสองชั้น |
| ผู้ถูกผูก | เป็นผู้ถูกผูกตัวมากกว่าครึ่งชีวิตผู้ใหญ่ |
| ผู้เป็นตำนาน | ได้อาชีพลับหรืออาวุธตำนาน |

ค่าที่ขึ้นอย่างเดียวของสายตระกูล (แบบความรุ่งเรืองของ CK3 ที่ใช้แล้วไม่ลด) อยู่ในหน้าตำนานข้ามรอบ

| ได้จาก | ค่า |

| ฉายาชีวิตแต่ละฉายา | +1 |
| ผ่านจุดบรรจบ อาชีพลับ อาวุธตำนาน ฉากจบของโลกระหว่างชีวิต | +2 ต่ออย่าง |
| ชีวิตแรกของสายตระกูลในโลกใหม่ | +1 |

## 5. จังหวะชะตา

เลือกตอนเริ่มโลก (แบบผู้เล่าเรื่องของ RimWorld) เปลี่ยนน้ำหนักของเหตุการณ์ส่วนตัวของตัวละคร ไม่เปลี่ยนเหตุการณ์โลก ตัวจำลองโลกจึงไม่เปลี่ยน

| แบบ | ผล |
| --- | --- |
| ตามธรรมชาติ (ค่าเริ่มต้น) | ใช้น้ำหนักในเอกสารตามเดิม |
| ชะตาอ่อนโยน | ทางที่มีความตายของคนใกล้ตัว ×0.6 ศึกสุ่ม ×0.7 ชะตาร้าย ×0.7 |
| ชะตาโศก | ทางที่มีความสูญเสีย ×1.5 ชะตาร้าย ×1.3 คำอธิษฐานเกิดบ่อยขึ้น ×1.3 |
| ชะตาประชด | ผลที่ตรงข้ามกับคำขอในคำอธิษฐานที่ถูกให้แบบแปลก ×2 ความฝันตีความผิด ×1.5 |

## 6. ราคาของการแทรกแซงมากเกิน

ตัวละครที่ได้รับมากเกินเริ่มพึ่งฟ้า เป็นราคาในเรื่อง ไม่ใช่การลงโทษผู้เล่น

| เงื่อนไข | ผล |
| --- | --- |
| ได้รับพร ฝีมือ หรือของประทานครบ 10 ครั้ง (คำสาปไม่นับ) | ทางเลือกที่ต้องลงมือเอง (ฝึก ลงทุน เดินทางไกล) ×0.9 |
| ครบ 15 ครั้ง | ×0.8 และ NPC ใกล้ตัวพูดว่าเขา "รอฟ้า" ฉายาผู้รอฟ้าเปิด |
| ไม่มีการประทานสิบปีชีวิตหลังจากนั้น | ตัวคูณกลับเป็น 1 |

ฉายาของพระเจ้า "ผู้คุ้มครองเงียบ" และคำปฏิญาณ GV-12 เป็นทางที่ความยับยั้งได้รับการจดจำ
