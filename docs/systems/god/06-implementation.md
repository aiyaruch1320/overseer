# นำระบบพระเจ้าลงโค้ด

ระบบ: [README.md](README.md) · โค้ดเดิม: `src/sim/game.ts` `src/sim/fortune.ts` `src/data/prayers.ts` `src/sim/fate.ts` · ลำดับเอกสารลงโค้ด: [../../../RAW_PLAN.md](../../../RAW_PLAN.md) หัวข้อ 4.7

โค้ดเดิมเป็นตัวทดลองที่มีพลังพระเจ้าอยู่บางส่วน (`faith` `dread` `belief` `COSTS` คำอธิษฐาน 17 ชนิด พลังแผนที่ 9 แบบ ความฝันและกระซิบ) เอกสารชุดนี้ชนะเมื่อขัดกัน ไฟล์นี้บอกโครง ลำดับ และการตรวจ

## 1. โครงข้อมูล

| โครง | ช่องหลัก | หมายเหตุ |
| --- | --- | --- |
| สถานะพระเจ้า | แสงศรัทธา ความหวาดกลัว ตัวนับต่อปีชีวิต (หีบ ฝัน กระซิบ ทอยใหม่) ระยะรอของปาฏิหาริย์แต่ละแบบ ตัวชดเชยความหายาก สายพลังล่าสุด ตัวนับต่อชีวิต (อาวุธประทาน ของประทาน ปาฏิหาริย์มหา ปลุกชีพ) | ข้ามรุ่นตาม [01-power.md](01-power.md) หัวข้อ 6 |
| หีบ | ช่อง 6 ช่อง (ชนิด รหัส ระดับ ราคา เหตุที่ขึ้น) จำนวนครั้งที่ทอย ใบที่ล็อก | เหตุที่ขึ้นใช้แสดงใน UI และทดสอบ |
| ข้อเสนอความฝัน | สามทาง (แหล่ง เป้าหมาย สัญลักษณ์ น้ำเสียง โอกาสทำตาม ระดับ เหตุผล) ข้อความจาก LLM หรือแม่แบบ | ทอยผลตอนตัวละครถึงจังหวะตัดสินใจ |
| การกระทำปาฏิหาริย์ | รหัส MR เป้าหมาย ราคา ผลที่คาด (สำหรับหน้ายืนยัน) วันลาง วันเกิด | ปาฏิหาริย์ระดับใหญ่ขึ้นไปผ่านระยะลาง |
| พงศาวดารพระหัตถ์ | รายการ: ปีโลก ปีชีวิต ชนิด รหัส เป้าหมาย ผล รหัสเหตุการณ์ที่เปิดหรือปิด | เหตุการณ์และ LLM อ้างถึงได้ หน้าสรุปโลกอ่านจากที่นี่ |
| ธงประเทศใหม่ | `god_ruin` | เพิ่มเข้าธงเดิม `war` `famine` `plague` `golden` `fallen` และค่าชะตาใน `src/sim/fate.ts` |

## 3. ลำดับในหนึ่งการแทรกแซง

1. ตรวจสิทธิ์: เพดานต่อปีและต่อชีวิต ระยะรอ กติกาเหล็ก ([04-miracles.md](04-miracles.md) หัวข้อ 2) และพลังพอ
2. คำนวณผลที่คาดสำหรับหน้ายืนยัน (ไม่ทอยสุ่ม)
3. ผู้เล่นยืนยัน
4. หักพลัง ใช้ตัวคูณราคา
5. ใช้ผลผ่านฟังก์ชันเดิมของเกม: ให้พรและคำสาป ตั้งธงประเทศ (`setFate` สำหรับซาก) เปลี่ยนน้ำหนักโหนด เปลี่ยนตัวแปรโลก
6. ปรับศรัทธาเทพและศรัทธาของประเทศ
7. ลงพงศาวดาร
8. ขอข้อความจาก LLM ถ้ามีเพดานเหลือ ใช้แม่แบบระหว่างรอ

## 4. จำลองสมดุลก่อนเขียนเกม

เพิ่มนโยบายพระเจ้าในตัวจำลองระดับเอกสาร (`scripts/sim/sim-world.mjs` สำหรับปาฏิหาริย์และลิขิต `scripts/sim/sim-life.mjs` สำหรับหีบ ฝัน และศรัทธาเทพ)

| นโยบาย | พฤติกรรม | ใช้ตอบคำถาม |
| --- | --- | --- |
| เงียบ | ไม่แทรกแซงเลย | ค่าฐานของโลกเดิม เทียบได้กับตัวเลขในเอกสารตอนนี้ |
| เมตตา | ใช้แสงศรัทธาทุกครั้งที่ถึงเพดาน ตอบคำอธิษฐานแบบให้ ปาฏิหาริย์สายสร้าง | ศรัทธาเทพสุดท้าย ฉากจบ END-12 บ่อยขึ้นเท่าไร |
| ลงโทษ | ใช้ความหวาดกลัว สาป ลงโทษ ปาฏิหาริย์สายทำลายตามเพดาน | สัดส่วน `godslayer` จำนวนซากต่อโลก GD-08 ฉากจบ END-10 |
| สุ่ม | สุ่มการกระทำที่ทำได้ | การกระจายของผล |
| เร่งจบ | ลิขิตเร่งเหตุการณ์ที่เป็นเงื่อนไขของฉากจบ ยั่วมังกร | ฉากจบเร็วขึ้นได้มากแค่ไหน เพดาน ×3 และ ×0.5 พอไหม |

| เมืองร้าวจากการโจมตีหมุดผนึก (นโยบายลงโทษ) | มังกรล้มเร็วขึ้นไม่เกินหนึ่งยุคย่อยต่อโลกเทียบกับนโยบายเงียบ |
| ตัดสินใจต่อชีวิต (นโยบายเมตตา) | 25 ถึง 40 |

## 5. ทดสอบที่ต้องมี

- หีบ: ไม่มีของที่ผิดตัวกรอง ไม่มีของซ้ำในหีบ อาวุธประทานไม่เกินหนึ่ง ของตำนานไม่ขึ้น
- ความฝัน: ทุกทางชี้เป้าหมายที่มีอยู่ ทางที่ต้องใช้เหตุการณ์ที่ยังไม่เกิดไม่ขึ้น ระดับที่แสดงตรงกับโอกาสจริง
- ปาฏิหาริย์: กติกาเหล็กทั้งเจ็ดข้อ ประเทศที่มีมังกรอยู่ไม่เป็นซาก ตัวละครหลักไม่ตายจากปาฏิหาริย์ เหตุการณ์ที่ยึดกับประเทศซากปิด
- ข้ามรุ่น: พลังครึ่งหนึ่งไปทายาท ตัวนับต่อชีวิตเริ่มใหม่
- LLM: ทดสอบทั้งชุดใน [../llm/02-offline.md](../llm/02-offline.md) หัวข้อ 6 โดยเฉพาะชีวิตเดียวกันเปิดและปิด LLM ต้องได้แฮชของสถานะเท่ากันทุกปีชีวิต คำตอบที่มีชื่อนอกรายการถูกแทนด้วยชั้นที่ต่ำกว่า

## 6. ความเสี่ยง

| ความเสี่ยง | ทางลด |
| --- | --- |
| ผู้เล่นใช้หีบจนตัวละครเก่งเกินและเรื่องไม่ตึง | เพดานหีบต่อปี ราคาตามระดับ ตัวละครที่ได้พรมากถูก NPC อิจฉาและศัตรูเลือก (เหตุการณ์เดิมของพร) |
| ความฝันรู้สึกเหมือนปุ่มที่ไม่ทำงาน | แสดงเหตุผลที่ไม่ทำตาม ผลตีความผิดยังเปลี่ยนเรื่อง ภาระใจทำให้การยืนยันเปลี่ยนตัวละครได้ |
| ปาฏิหาริย์ใหญ่ทำให้โลกพังจนไม่มีเรื่อง | เพดาน 25 ปี กติกาเหล็ก ซากเปิดเรื่องใหม่แทนที่เรื่องที่ปิด และฟื้นเป็นเมืองใหม่ใน 40 ถึง 80 ปี |
| ค่า LLM | เพดานต่อชีวิต แคช แม่แบบ |
