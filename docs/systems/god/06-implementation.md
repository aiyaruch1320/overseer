# นำระบบพระเจ้าลงโค้ด

ระบบ: [README.md](README.md) · โค้ดเดิม: `src/sim/game.ts` `src/sim/fortune.ts` `src/data/prayers.ts` `src/sim/fate.ts` · ลำดับเอกสารลงโค้ด: [../../../RAW_PLAN.md](../../../RAW_PLAN.md) หัวข้อ 4.7

โค้ดเดิมเป็นตัวทดลองที่มีพลังพระเจ้าอยู่บางส่วน (`faith` `dread` `belief` `COSTS` คำอธิษฐาน 17 ชนิด พลังแผนที่ 9 แบบ ความฝันและกระซิบ) เอกสารชุดนี้ชนะเมื่อขัดกัน ไฟล์นี้บอกโครง ลำดับ และการตรวจ

## 1. โครงข้อมูล

| โครง | ช่องหลัก | หมายเหตุ |

## 3. ลำดับในหนึ่งการแทรกแซง

1. ตรวจสิทธิ์: เพดานต่อปีและต่อชีวิต ระยะรอ กติกาเหล็ก ([04-miracles.md](04-miracles.md) หัวข้อ 2) และพลังพอ
2. คำนวณผลที่คาดสำหรับหน้ายืนยัน (ไม่ทอยสุ่ม)
3. ผู้เล่นยืนยัน
4. หักพลัง ใช้ตัวคูณราคา
5. ใช้ผลผ่านฟังก์ชันเดิมของเกม: ให้พรและคำสาป ตั้งธงประเทศ (`setFate` สำหรับซาก) เปลี่ยนน้ำหนักโหนด เปลี่ยนตัวแปรโลก
6. ปรับศรัทธาเทพและศรัทธาของประเทศ
7. ลงพงศาวดาร
8. ขอข้อความจาก LLM ถ้ามีเพดานเหลือ ใช้แม่แบบระหว่างรอ

## 4. จำลองสมดุลก่อนเขียนเกม

ตัวจำลองคือ `node scripts/sim/sim-god.mjs [ชีวิต=20000] [โลก=600] [--write]` (`npm run sim:god`) วัดแล้ว 2026-11-01 ผลอยู่ท้ายหัวข้อนี้ `--write` เขียนผลใหม่ลงที่เดิม

| ส่วน | ทำอะไร |
| --- | --- |
| ชีวิต | เดินทีละปีชีวิตของตัวละครหนึ่งคน: รายได้ ราคา ตัวคูณราคา ศรัทธาเทพ คำอธิษฐาน (สี่ช่วงต่อปี ค้างได้สองใบ หมดเวลาใน 14 ช่วง ตาม `prayerTick` ในโค้ด) หีบ ความฝัน กระซิบ ภาระใจ ตามไฟล์ 01 ถึง 03 |
| โลก | ใช้ `runWorld` ของ `sim-world.mjs` ผ่านตัวเกี่ยว `god` (ทำงานทุกทศวรรษ แก้อารมณ์มังกรและเพดานอารมณ์ได้) และ `godW` (ตัวคูณน้ำหนักของเหตุการณ์ ใช้กับลิขิต) ไม่ส่งตัวเกี่ยวแล้วผลของ `sim-world.mjs` เท่าเดิมทุกตัว สายตระกูลเดียวต่อโลก ชีวิตต่อกันตามอายุขัยของเผ่า ทายาทรับพลังครึ่งหนึ่ง พระเจ้าใช้พลังที่เหลือจากการตอบคำอธิษฐานกับโลกทั้งหมด จึงเป็นขอบบน |

- ศรัทธาเทพของนโยบายเมตตาชนเพดาน 100 (ค่ากลางตอนตาย) ความฝันจึงทำตามเกือบทุกครั้ง ตัวจำกัดจริงคือราคาที่เพิ่มขึ้น ไม่ใช่ความเชื่อฟัง

## 5. ทดสอบที่ต้องมี

- หีบ: ไม่มีของที่ผิดตัวกรอง ไม่มีของซ้ำในหีบ อาวุธประทานไม่เกินหนึ่ง ของตำนานไม่ขึ้น
- ความฝัน: ทุกทางชี้เป้าหมายที่มีอยู่ ทางที่ต้องใช้เหตุการณ์ที่ยังไม่เกิดไม่ขึ้น ระดับที่แสดงตรงกับโอกาสจริง
- ปาฏิหาริย์: กติกาเหล็กทั้งเจ็ดข้อ ประเทศที่มีมังกรอยู่ไม่เป็นซาก ตัวละครหลักไม่ตายจากปาฏิหาริย์ เหตุการณ์ที่ยึดกับประเทศซากปิด
- ข้ามรุ่น: พลังครึ่งหนึ่งไปทายาท ตัวนับต่อชีวิตเริ่มใหม่
- LLM: ทดสอบทั้งชุดใน [../llm/02-offline.md](../llm/02-offline.md) หัวข้อ 6 โดยเฉพาะชีวิตเดียวกันเปิดและปิด LLM ต้องได้แฮชของสถานะเท่ากันทุกปีชีวิต คำตอบที่มีชื่อนอกรายการถูกแทนด้วยชั้นที่ต่ำกว่า
