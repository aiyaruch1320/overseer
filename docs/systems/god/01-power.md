# พลังของพระเจ้า

ระบบ: [README.md](README.md) · ศรัทธาของโลก: [../../lore/religions/01-faith-flow.md](../../lore/religions/01-faith-flow.md) · ศรัทธาของตัวละคร: [../character/README.md](../character/README.md)

คำว่า "ศรัทธา" ในเอกสารมีสามความหมาย ไฟล์นี้แยกชื่อให้ชัด

| ชื่อในไฟล์นี้ | ตัวแปรในโค้ด | ช่วง | ของใคร |
| --- | --- | --- | --- |
| **แสงศรัทธา** | `faith` | 0–200 | พระเจ้า (ผู้เล่น) ใช้จ่ายเป็นพลัง |
| **ความหวาดกลัว** | `dread` | 0–200 | พระเจ้า ใช้จ่ายเป็นพลังสายลงโทษ |
| **ศรัทธาเทพ** | `belief` | −100 ถึง 100 | ตัวละครหลัก รู้สึกต่อพระเจ้าอย่างไร |

ศรัทธาของประเทศและของโลก (ช่องทาง A ถึง E) อยู่ใน [../../lore/religions/01-faith-flow.md](../../lore/religions/01-faith-flow.md) ไฟล์นี้อ่านค่าเหล่านั้นเป็นรายได้

## 1. รายได้

พลังไม่ได้มาจากเวลาอย่างเดียว มาจากคนที่เชื่อหรือกลัว (บทเรียนจาก Black & White: แหล่งพลังต้องฟาร์มไม่ได้)

| แหล่ง | แสงศรัทธาต่อปีชีวิต | ความหวาดกลัวต่อปีชีวิต |
| --- | --- | --- |
| ฐาน | 1 | 0.3 |
| ศรัทธาตรงของประเทศที่ตัวละครอยู่ (ช่องทาง B 0–100) | B ÷ 25 (0 ถึง 4) | |
| ศรัทธาเทพของตัวละคร | belief ÷ 30 เมื่อเป็นบวก (สูงสุด +3.3) | −belief ÷ 75 เมื่อเป็นลบ (สูงสุด +1.3) |
| ตัวละครเป็นศาสดา (`prophet`) | +4 | |
| ตอบคำอธิษฐานแบบให้ | +2 ต่อครั้ง (ผู้ขอรู้ว่าพระเจ้าช่วย) | |
| ลงโทษผู้ขอ หรือลงโทษศัตรูในศึก | | +6 ถึง +10 ต่อครั้ง |
| ปาฏิหาริย์สายทำลาย | | ราคา ÷ 3 กลับมาเป็นความหวาดกลัว (ผู้รอดเล่าต่อ) |
| ภารกิจของพระเจ้า 12 แบบ ([../events/branches/03-character-and-quests.md](../events/branches/03-character-and-quests.md) หัวข้อ 6) | ตามภารกิจ เช่น ศาสดา +80 | ตามภารกิจ |
| GD-04 ปาฏิหาริย์แห่งพระเจ้าเกิดแล้ว | ×1.5 ทุกแหล่งตลอดชีวิตที่เหลือ | |
| GD-05 ความเงียบของพระเจ้าเกิดแล้ว | ×0.5 จนกว่าจะตอบคำอธิษฐาน 3 ครั้ง | |

**ค่าเริ่มต้น** แสงศรัทธา 30 ความหวาดกลัว 10 ทั้งสองมีเพดาน 200 ตามโค้ดเดิม ตัวอย่าง ตัวละครศรัทธาเทพ 30 อยู่ประเทศช่องทาง B 40 ได้แสงศรัทธาราว 3.6 ต่อปี ชีวิตมนุษย์ 75 ปีได้ราว 270 รวมคำอธิษฐานราว 320

## 3. ผลต่อศรัทธาเทพ

ศรัทธาเทพคือความทรงจำของตัวละครต่อสิ่งที่พระเจ้าทำ (บทเรียนจาก Black & White: ความเชื่อฟังต้องเกิดจากประวัติที่ผู้เล่นสร้าง) ระดับใช้ดัชนี C 0 · U 1 · R 2 · E 3 · L 4

| เหตุ | ศรัทธาเทพ |
| --- | --- |
| ได้รับพร ฝีมือ หรือของ | +(5 + 3 × ระดับ) |
| ได้รับคำสาป | −(4 + 3 × ระดับ) |
| อาวุธศักดิ์สิทธิ์ · อาวุธต้องสาป | +10 · −5 และแกนเมตตา −10 |
| ทำตามความฝัน · ตีความผิด · ปฏิเสธ | +3 · +1 · −2 |
| คำอธิษฐานถูกตอบแบบให้ · ปฏิเสธ · ลงโทษ · ปล่อยจนหมดเวลา | +8 (×1.5 ถ้าแกนศรัทธา > 30) · −3 · −12 · −2 |
| ปาฏิหาริย์สายสร้างในประเทศที่ตัวละครอยู่ · สายทำลายในประเทศที่ตัวละครอยู่ | +5 · −10 (ถ้าตัวละครเห็นผล) |
| ปลุกชีพด้วยแสงศรัทธา · ด้วยความหวาดกลัว | +35 · −10 |
| ไม่มีการแทรกแซงเลยสิบปีชีวิต | เคลื่อนเข้าหา 0 ทีละ 2 ต่อปี (ความรู้สึกจางลง) |

**ระดับของศรัทธาเทพ** ใช้ในทุกไฟล์ของระบบนี้

| ช่วง | ชื่อ | ผล |
| --- | --- | --- |
| 50 ขึ้นไป | ผู้ภักดี (แท็ก devoted ในโค้ด) | ความฝันชัด อธิษฐานบ่อย เปิดทางนักบุญ ผู้ปลุกชีพ ศาสดา |
| 20 ถึง 49 | ผู้เชื่อ | ท่าทีอธิษฐานในศึกใช้ได้ |
| −29 ถึง 19 | ผู้ลังเล | |
| −69 ถึง −30 | ผู้หันหลัง (แท็ก heretic ในโค้ด) | ราคาแสงศรัทธา ×1.5 |
| −70 ลงไป | ผู้ชิงชัง | ไม่อธิษฐานอีก เปิดทาง `godslayer` ถ้าเงื่อนไขอื่นครบ |

## 4. เพดานและจังหวะ

| การแทรกแซง | เพดาน |
| --- | --- |
| ประทาน | เปิดหีบได้หนึ่งครั้งต่อปีชีวิต บวกหนึ่งครั้งที่หน้าต่างพระเจ้าหรือจุดหยุดตามอายุ |
| เข้าฝัน | สองครั้งต่อปีชีวิต |
| กระซิบ | สามครั้งต่อปีชีวิต คำใบ้เดียวกันซ้ำไม่ได้ภายในปีเดียว |
| คำอธิษฐาน | ค้างได้สองใบพร้อมกัน หมดเวลาใน 14 ช่วงเวลา (ราวสามปีครึ่งชีวิต) |
| ปาฏิหาริย์ | ต่อชีวิต: เล็กไม่จำกัดจำนวน · กลาง 4 · ใหญ่ 2 · มหา 1 · เสกตามใจ 3 และระยะรอใช้ซ้ำของแต่ละแบบ ([04-miracles.md](04-miracles.md) หัวข้อ 2 ข้อ 6 และหัวข้อ 3) |
| อาวุธประทาน | หนึ่งชิ้นต่อตัวละคร |
| ของประทานที่ไม่ใช่อาวุธ | สามชิ้นต่อตัวละคร |

**ผู้เล่นไม่ต้องรีบ** พลังที่ไม่ได้ใช้สะสมได้ถึงเพดาน 200 ไม่หายเมื่อจบปี ความเงียบไม่มีโทษ ยกเว้นคำอธิษฐานที่ปล่อยจนหมดเวลา และ GD-05 เมื่อคำอธิษฐานทั้งโลกไม่ได้รับคำตอบหลายทศวรรษ

## 5. ทางของ `godslayer`

เป้าในเอกสาร (`godslayer` ไม่เกิน 0.1% ของชีวิต และศรัทธาเทพ −70 ลงไปไม่เกินราว 0.4%) เป็นเป้าของ **ชีวิตที่พระเจ้าไม่ได้ทำร้าย** ตัวละครที่ถูกสาปหรือถูกลงโทษซ้ำ ๆ ไปถึง −70 ได้เพราะผู้เล่นเลือก นั่นคือเรื่องที่ตั้งใจให้เกิด

- ในการจำลอง ให้วัดเป้า 0.4% กับนโยบาย "พระเจ้าเงียบ" และ "พระเจ้าเมตตา" ([06-implementation.md](06-implementation.md) หัวข้อ 4)
- ตัวละครที่ลดศรัทธาเทพจากการกระทำของผู้เล่น นับแยก แสดงในหน้าตำนานว่า "ผู้ที่พระเจ้าสร้างศัตรูขึ้นเอง"

## 6. ข้ามรุ่น

รับข้อเสนอใน [../../lore/heirs/01-inheritance.md](../../lore/heirs/01-inheritance.md) หัวข้อ 5 พร้อมราคา

| สิ่ง | กติกา |
| --- | --- |
| พลังที่เหลือเมื่อตัวละครตาย | ทายาทรับ 50% ของแสงศรัทธาและความหวาดกลัว |
| ศรัทธาเทพของทายาท | 60% ของพ่อแม่ (ตามโค้ดเดิม) |
| พรสายเลือด (ทั้งตระกูล) | ราคา 3 เท่าของพรเดียว ถึงทายาทรุ่นแรกแน่นอน รุ่นสอง 60% รุ่นสาม 30% |
| ถอนคำสาปที่สืบทอด | ราคา 2 เท่าของคำสาปนั้น จ่ายด้วยแสงศรัทธา |
| อาวุธประทานของรุ่นก่อน | ทายาทรับได้ ไม่นับเป็นอาวุธประทานของทายาท |
| ตัวนับเพดานต่อชีวิต | เริ่มใหม่ทุกรุ่น |

## 7. ฉายาของพระเจ้า

ตัวตนของพระเจ้าที่โลกเห็น เป็นส่วนหนึ่งของเป้าหมายของผู้เล่น ระบบเป้าหมายเต็ม (คำปฏิญาณ ฉายาชีวิต พงศาวดารสายตระกูล) อยู่ใน [08-goals.md](08-goals.md)

| ฉายา | เงื่อนไขตอนจบชีวิต |
| --- | --- |
| ผู้ให้แสง | แสงศรัทธาที่ใช้ ≥ 3 เท่าของความหวาดกลัวที่ใช้ และศรัทธาเทพ ≥ 50 |
| ผู้คุ้มครองเงียบ | ใช้พลังรวมน้อยกว่า 60 ตลอดชีวิต และตัวละครอยู่ถึงวัยผู้เฒ่า |
| ผู้พิพากษา | ความหวาดกลัวที่ใช้ ≥ แสงศรัทธาที่ใช้ และศรัทธาเทพไม่ต่ำกว่า 0 |
| ผู้ทำลาย | ปาฏิหาริย์สายทำลายระดับใหญ่ขึ้นไปอย่างน้อยสองครั้ง |
| ผู้ถูกชิงชัง | ศรัทธาเทพตอนตาย ≤ −70 |
| ผู้ลิขิต | ลิขิตเหตุการณ์ ⭐ อย่างน้อยหนึ่งครั้ง และเหตุการณ์นั้นเกิดหรือถูกเลื่อนตามที่ลิขิต |

- ฉายาแสดงบนหน้าบันทึกชีวิตและหน้าตำนาน ([../experience/03-ending-and-collection.md](../experience/03-ending-and-collection.md)) ไม่มีฉายาที่ดีกว่ากัน
- หน้าสรุปโลกมีส่วน "พระหัตถ์" ที่รวมพงศาวดารพระหัตถ์ของทุกชีวิตในโลกนั้น
- เป้าต่อชีวิตยังเป็นคำถามของชีวิต ([../experience/02-hooks.md](../experience/02-hooks.md) ตะขอข้อ 1) พระเจ้าเปลี่ยนคำตอบได้แต่ไม่บังคับ
