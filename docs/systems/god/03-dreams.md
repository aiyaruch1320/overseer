# เข้าฝัน กระซิบ และคำอธิษฐาน

ระบบ: [README.md](README.md) · ราคา: [01-power.md](01-power.md) · เส้นเรื่อง: [../../lore/storylines/README.md](../../lore/storylines/README.md) · LLM: [05-llm.md](05-llm.md) · ภาพ: [../../appearance/20-god-ui.md](../../appearance/20-god-ui.md) หัวข้อ 4 ถึง 6

การเข้าฝันคือการแทรกแซงที่ชี้ทางเรื่องได้มากที่สุด พระเจ้าไม่ได้เขียนเรื่องเอง เกมดึงทางที่เป็นไปได้จริงจากเส้นเรื่อง เสนอ 3 ทาง พระเจ้าเลือกหนึ่งทางส่งเข้าฝัน ตัวละครตื่นมาแล้วตัดสินใจเองว่าจะทำตามไหม

## 1. ทางทั้งสามมาจากไหน

เกมหาทางที่เป็นไปได้จากแหล่งเหล่านี้ เรียงตามความสำคัญ แหล่งที่ไม่มีของตอนนั้นข้ามไป

| แหล่ง | ทางที่ได้ | ผลถ้าตัวละครทำตาม |
| --- | --- | --- |
| S1 โหนดถัดไป | ทาง ก) ข) ค) ของโหนดเส้นเรื่องที่ตัวละครจะถึงภายในสองปีชีวิต | ทางนั้น ×4 |
| S2 จุดบรรจบ | จุดบรรจบที่เปิดอยู่และตัวละครเข้าได้จากโหนดใกล้ ๆ ([../../lore/storylines/00-convergence.md](../../lore/storylines/00-convergence.md)) | ทางที่ชี้ไป cv.N ×4 หรือเปิดการเดินทางไปที่จุดนั้น |
| S3 เรื่องของ NPC | เรื่องของ NPC ที่เปิดอยู่ในประเทศเดียวกันและแถวมีทาง `[ช่วย]` `[ร่วม]` `[ขัดขวาง]` ([../../lore/npcs/README.md](../../lore/npcs/README.md) หัวข้อ 2.1) | ตัวละครเข้าไปในเรื่องนั้นตามทางที่ชี้ |
| S4 อาชีพลับ | อาชีพลับที่เงื่อนไขครบแล้วอย่างน้อยครึ่งหนึ่ง ([../character/10-jobs-secret.md](../character/10-jobs-secret.md)) | โอกาสต่อปีของอาชีพนั้น ×1.5 สิบปี |
| S5 การเดินทาง | จุดหมายที่ตัวกรองเผ่าและศีลธรรมยอมรับ ([../travel/README.md](../travel/README.md)) | การเดินทางไปที่นั้น ×3 |
| S6 ลางของโลก | เหตุการณ์โลกที่มีลางในทวีปภายในสิบปี ([../events/world-events.md](../events/world-events.md) หัวข้อ 0.3) | ทางเตรียมรับ (หนี ช่วยคน กักตุน) ×3 เมื่อเหตุการณ์เกิด |
| S7 เรื่องค้าง | เรื่องค้างของสายตระกูล ([../../lore/heirs/03-open-threads.md](../../lore/heirs/03-open-threads.md)) | เปิดโหนดสางเรื่อง |
| S8 พวกพ้องและการผูกตัว | วิกฤตขั้น 3 ของพวกพ้อง การชวน การปฏิเสธ ([../bonds/README.md](../bonds/README.md)) หรือทางหนีของผู้ถูกผูกตัว ([../economy/10-bondage.md](../economy/10-bondage.md) หัวข้อ 9) | ทางที่ชี้ ×3 |

**เลือกสามทาง**

1. ทางแรกมาจาก S1 เสมอถ้ามี (ทางที่ตรงกับนิสัยมากที่สุดของโหนดนั้น)
2. ทางที่สองเป็นทางที่ **ขัดนิสัย** แต่ผลน่าสนใจ จาก S1 ถึง S6 (เสี่ยงกว่า หรือเปิดสิ่งที่ตัวละครจะไม่ทำเอง)
3. ทางที่สามมาจากแหล่งที่หายาก (S2 S4 S7 S8) ถ้ามี ถ้าไม่มีใช้ S3 หรือ S5
4. ไม่เกินสองทางจากแหล่งเดียวกัน และสามทางต้องพาไปผลต่างกัน (ห้ามสองทางที่ต่างแค่คำ)

ทางที่ขัดกฎของโลกไม่ขึ้น ทางที่ต้องใช้เหตุการณ์ที่ยังไม่เกิดไม่ขึ้น (กติกาเดียวกับโหนด [../../lore/storylines/README.md](../../lore/storylines/README.md) หัวข้อ 6 ข้อ 6 และ 7)

## 3. ความเชื่อฟัง

**โอกาสทำตาม** = 0.30 + ศรัทธาเทพ ÷ 140 + ความเข้ากัน + ความชัด แล้วจำกัดไว้ที่ 0.05 ถึง 0.95

| ส่วน | ค่า |
| --- | --- |
| ความเข้ากัน | ทางตรงกับนิสัยสองข้อขึ้นไป +0.15 · หนึ่งข้อ +0.05 · ขัดนิสัย −0.20 · ขัดศีลธรรม (ทำร้ายผู้บริสุทธิ์ ทรยศ) −0.30 |
| ความชัด | ความฉลาด (int − 10) × 0.02 · `u_oracle` +0.10 · `nb_god_whisper` +0.20 · ฝันซ้ำทางเดิมภายในสามปี +0.10 · ตัวละครเพิ่งถูกพระเจ้าลงโทษ (ห้าปี) −0.10 |

**ผู้เล่นเห็นสามระดับ ไม่เห็นตัวเลข** (การเห็นร้อยละทำให้รู้สึกว่าโดนโกงเมื่อพลาด บทเรียนจาก XCOM) ระดับต้องตรงกับโอกาสจริงเสมอ

| ระดับ | โอกาส | ภาพบนจอ |
| --- | --- | --- |
| เต็มใจ | 0.70 ขึ้นไป | เปลวเทียนนิ่ง |
| ลังเล | 0.40–0.69 | เปลวเทียนไหว |
| ขัดขืน | ต่ำกว่า 0.40 | เปลวเทียนจวนดับ |

เหตุผลที่แสดงเลือกจากส่วนที่หนักที่สุดของสูตร เช่น "เขากลัวน้ำ" (ขัดนิสัย) "เขายังจำคำอธิษฐานที่ท่านเมิน" (ศรัทธาเทพต่ำจากคำอธิษฐาน) "เขาฝันถึงทางนี้มาแล้ว" (ฝันซ้ำ)

**ตัดสินแล้ว (2026-11-01)** แสดงสามระดับพร้อมเหตุผล ไม่แสดงร้อยละในค่าปกติ กติกาเพิ่มเพื่อให้ระดับเชื่อถือได้

| กติกา | ค่า |
| --- | --- |
| ระดับต้องซื่อตรง | ระดับที่แสดงคำนวณจากโอกาสจริงตอนที่ทอย ถ้าสถานการณ์เปลี่ยนระหว่างรอ (นิสัยเปลี่ยน ศรัทธาเทพเปลี่ยนข้ามเกณฑ์) เทียนในการ์ดความฝันที่ค้างอยู่เปลี่ยนตาม พร้อมเสียงเปลวกระพือ |
| ตัวกันโชคร้าย | ทางระดับเต็มใจที่ไม่ผ่านสองครั้งติดกันในชีวิตเดียว ครั้งถัดไปของระดับเต็มใจได้ +0.15 (บทเรียนจาก XCOM ที่ผู้เล่นรู้สึกว่าโดนโกงเมื่อพลาดซ้ำ) |
| เห็นย้อนหลัง | พงศาวดารพระหัตถ์บันทึกระดับตอนส่งและผลที่ออก ผู้เล่นเห็นว่าระดับเต็มใจผ่านบ่อยแค่ไหนในชีวิตนี้ |
| ตั้งค่าแสดงร้อยละ | มีในหน้าตั้งค่า ปิดเป็นค่าเริ่มต้น สำหรับผู้เล่นที่อยากเห็นตัวเลข เปิดแล้วร้อยละแสดงใต้เทียน |

## 4. ผลเมื่อตื่น

ทอยหนึ่งครั้งเมื่อตัวละครถึงจังหวะตัดสินใจที่ทางนั้นผูกไว้ (ไม่ใช่ตอนตื่น) ความฝันค้างได้สามเหตุการณ์ตามโค้ดเดิม ถ้าไม่ถึงจังหวะภายในสองปีชีวิต ความฝันจางไป ไม่เสียศรัทธาเทพ

| ผล | เงื่อนไข | สิ่งที่เกิด |
| --- | --- | --- |
| **ทำตาม** | ทอยผ่านโอกาสทำตาม | ทางนั้นตามตารางหัวข้อ 1 (ส่วนใหญ่ ×4 ไม่ใช่บังคับ) ศรัทธาเทพ +3 |
| **ตีความผิด** | ไม่ผ่าน และศรัทธาเทพ ≥ 0 ครึ่งหนึ่งของกรณี | ตัวละครทำทางอื่นของโหนดเดียวกันที่ใกล้ความหมายของสัญลักษณ์ ×2 ศรัทธาเทพ +1 ฉากเล่าว่าเขาเข้าใจความฝันอย่างไร (แม่แบบตามสัญลักษณ์) |
| **ปฏิเสธ** | ไม่ผ่านและไม่ตีความผิด | ทางนั้นไม่เปลี่ยน ศรัทธาเทพ −2 ตัวละครจำความฝันที่ไม่ทำ (ผู้กำกับตามกติกาใช้เป็นความทรงจำ) |
| **ขัดขืน** | ปฏิเสธ และศรัทธาเทพ ≤ −30 | ทางนั้น ×0.3 ตัวละครทำตรงข้ามเพื่อพิสูจน์ว่าไม่ใช่ของใคร |

**ภาระใจ** (แบบความเครียดของ CK3) การทำตามความฝันที่ขัดนิสัยเพิ่มภาระใจ +1 ครบ 2 เกิดเหตุการณ์ภาระใจหนึ่งเรื่อง แล้วรีเซ็ต ความฝันที่ตรงนิสัยไม่ลดภาระใจ (ปรับจากการจำลอง [06-implementation.md](06-implementation.md) หัวข้อ 4: ที่ 3 และราคาเข้าฝันที่เพิ่มขึ้นทุกครั้ง พระเจ้าที่ส่งทางขัดนิสัยครึ่งหนึ่งได้เหตุการณ์ภาระใจเพียง 0.19 ครั้งต่อชีวิต ที่ 2 ได้ราว 0.5 ครั้ง ส่วนการลดภาระใจเมื่อทำตามทางที่ตรงนิสัยแบบความเครียดของ CK3 ทำให้เหลือ 0.33 จึงไม่ใช้)

| ผลของเหตุการณ์ภาระใจ (สุ่มตามนิสัย) | ผล |
| --- | --- |
| ตั้งคำถามกับพระเจ้า | ศรัทธาเทพ −8 ตัวละครอธิษฐานถามตรง ๆ หนึ่งใบ (ถ้าพระเจ้าตอบแบบให้ ศรัทธาเทพ +12 แทน) |
| หนีงานหรือหนีบ้านหนึ่งฤดู | อาชีพหยุดหนึ่งปี เปิดเหตุการณ์การเดินทางสุ่ม |
| นิสัยเปลี่ยน | นิสัยที่ถูกขัดบ่อยที่สุดหายไป ได้นิสัยตรงข้ามแทน (คนกลัวน้ำที่ถูกส่งลงทะเลสามครั้งกลายเป็นคนกล้า) |

ภาระใจทำให้การชี้ทางที่ขัดตัวตนของตัวละครมีราคาที่เห็นได้ และเปลี่ยนตัวละครได้จริงถ้าพระเจ้ายืนยัน
