# ไอเทมคู่

ระบบ: [README.md](README.md) · ระบบไอเทม: [../items/11-item-system.md](../items/11-item-system.md) · เครื่องราง: [../items/14-talismans.md](../items/14-talismans.md) · สายและระดับ: [01-ties-and-levels.md](01-ties-and-levels.md) · มรดก: [../../lore/heirs/01-inheritance.md](../../lore/heirs/01-inheritance.md)

ไอเทมคู่คือของที่ทำมาเป็นสองซีกสำหรับสองคน คนหนึ่งถือซีกหนึ่ง อีกคนถืออีกซีก เป็นรูปธรรมของสายพวกพ้อง ไม่ใช่ของที่ซื้อ ได้จากเรื่องราวระหว่างสองคนเท่านั้น

## 1. กติกา

| ข้อ | กติกา |
| --- | --- |
| 1 | แต่ละซีกให้ผลเล็กเมื่อถืออยู่คนเดียว (**ผลซีกเดียว**) และให้ผลเต็มเมื่อครบเงื่อนไขของคู่ (**ผลครบคู่**) |
| 2 | **ครบคู่** เมื่อทั้งสองซีกมีผู้ถือที่ยังมีชีวิต สายระหว่างผู้ถือสองคนอยู่ระดับ 3 ขึ้นไป และอยู่ในทวีปเดียวกัน (ยกเว้นคู่ที่ระบุเป็นอย่างอื่น) |
| 3 | ถ้าอีกฝ่ายตาย ซีกที่เหลือกลายเป็น **ของระลึก** ใช้ผลของระลึกแทนผลครบคู่ อย่างถาวร |
| 4 | ถ้าสายแตก (แยกทาง หักหลัง) ผลครบคู่หายและเหลือผลซีกเดียว ถ้าคืนดี ผลครบคู่กลับมา |
| 5 | ซีกหนึ่งใช้ช่องเครื่องประดับหนึ่งช่อง ([../items/11-item-system.md](../items/11-item-system.md) หัวข้อ 2) ค่าสถานะอยู่ในงบตามระดับของไอเทม ไม่แย่งช่องเครื่องราง |
| 6 | ไม่ขาย ไม่ซื้อ ไม่ตี ถ้าขายหรือทิ้ง สายเสีย B −15 (ถ้าอีกฝ่ายรู้) |
| 7 | **ส่งต่อทายาทได้** ทายาทได้ซีกที่ตัวละครถือ ซีกอีกซีกที่ยังเหลืออยู่ในตระกูลของอีกฝ่ายเป็นเหตุให้ทายาทได้พบกับทายาทของอีกฝ่าย (เรื่องรุ่นต่อรุ่น) |
| 8 | NPC ถือซีกของตนตามเรื่องของเขา ถ้า NPC ตายและตัวละครไม่ได้อยู่ ซีกของ NPC ไปตามเรื่องค้าง (มรดกหรือถูกขาย) ถ้ามีคนอื่นถือซีกนั้น ตัวละครยังไม่ครบคู่ |

## 2. ที่มา

| ที่มา | โอกาส | ตัวอย่าง |
| --- | --- | --- |
| เพื่อนวัยเด็กในเส้น bn.b1 ([../../lore/storylines/28-allies.md](../../lore/storylines/28-allies.md)) | 30% (ระดับ C ถึง U) | สองเด็กทำของจากไม้ท้ายซอยเดียวกัน |
| งานแต่งหรือสัญญาของคู่ชีวิต | 40% | ผู้ใหญ่ช่วยทำแหวนสองซีก |
| ครูให้ศิษย์ตอนจบการสอน | 35% | ครูส่งสิ่วที่ใช้มาตลอดชีวิตและเก็บอีกซีก |
| ช่างตีหรือช่างฝีมือรับทำจาก NPC | 20% (ต้องมีวัสดุตามระดับ [../items/02-materials.md](../items/02-materials.md)) | ตัวละครสั่งช่างทำของคู่ให้พี่น้อง |
| คู่แข่งตกลงยอมรับกัน | 25% | เหรียญที่แต่ละฝ่ายสลักชื่ออีกฝ่าย |
| รางวัลจากเรื่องของพวกพ้อง ปลายทางที่ดี | ตามแม่แบบ | ทางจบ ก) ของเรื่อง `FT-03` `FT-12` |
