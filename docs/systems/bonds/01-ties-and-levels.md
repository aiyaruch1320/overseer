# สายสัมพันธ์และระดับความผูกพัน

ระบบ: [README.md](README.md) · อารมณ์: [02-feelings.md](02-feelings.md) · การเกิดสาย: [03-formation.md](03-formation.md)

## 1. สายสัมพันธ์ 9 แบบ

ชื่อสายนับจาก **ตัวละครหลักมองไปที่ NPC** เช่น "ครู" คือ NPC เป็นครูของตัวละครหลัก "ศิษย์" คือ NPC เป็นศิษย์ของตัวละครหลัก การแยกทิศนี้จำเป็นเพราะอารมณ์ของครูต่อศิษย์ไม่เหมือนศิษย์ต่อครู ([02-feelings.md](02-feelings.md))

| สาย | ความหมาย | ชนิดเดิมในโค้ด | ผลหลักที่ต่างจากสายอื่น |
| --- | --- | --- | --- |
| สหาย | เพื่อน ร่วมวัยหรือใกล้กัน ไม่มีผลประโยชน์ผูกกัน | `friend` | ช่วยในวิกฤต เตือนภัย แนะนำคนอื่น |
| คู่หู | ร่วมงานหรือร่วมทางตามอาชีพ ค้าด้วยกัน สู้ด้วยกัน | ใหม่ (`friend` ที่มีธงงานร่วม) | เศรษฐกิจและศึก: เครดิตการค้า ราคา ทีมในศึก |
| คนรัก | คนรักและคู่ชีวิต | `lover` `spouse` | กันความเครียด ลูก ความกลัวเสียที่สุด |
| ครู | ผู้สอนตัวละครหลัก | `mentor` | skill เพิ่ม ทางลัดสู่อาชีพ |
| ศิษย์ | ผู้ที่ตัวละครหลักสอน | `mentor` (ทิศกลับ) | ส่งต่อ skill เรื่องค้าง มรดก |
| ญาติผู้ใหญ่ | พ่อแม่ ปู่ย่าตายาย ลุง ป้า น้า อา | `parent` | บ้าน ที่พึ่ง ภาระและธรรมเนียม |
| ญาติรุ่นเยาว์ | ลูก หลาน ลูกบุญธรรม | `child` | ทายาท ความห่วง ความหวัง |
| พี่น้อง | พี่น้องร่วมสายเลือดหรือร่วมเลี้ยง ลูกพี่ลูกน้อง | ใหม่ | ที่พึ่งร่วมวัย แรงเสียดทานของครอบครัว |
| คู่แข่ง | คนที่แข่งเรื่องเดียวกัน | `rival` | แรงผลักดัน กลายเป็นสหายหรือศัตรูได้ |

ศัตรูตลอดกาล (`nemesis`) ไม่ใช่พวกพ้อง ใช้กติกาเดิมของ [../combat/04-encounters.md](../combat/04-encounters.md)

## 2. ความผูกพันและระดับ

ทุกสายมีค่าความผูกพัน **B** ตั้งแต่ 0 ถึง 100 แบ่งเป็นระดับ

| ระดับ | B | ชื่อ | ความหมาย |
| --- | --- | --- | --- |
| 1 | 0–19 | รู้จัก | เคยเจอ จำชื่อได้ ยังไม่มีเรื่องร่วมกัน |
| 2 | 20–39 | คุ้นเคย | เจอกันเป็นประจำ เรื่องของเขาเริ่มปรากฏ |
| 3 | 40–59 | สนิท | ช่วยกันได้ เรื่องของเขาเข้ามาเป็นเรื่องของตัวละคร |
| 4 | 60–79 | ไว้ใจ | บอกความลับได้ ยอมเสียสละเล็ก ๆ |
| 5 | 80–100 | ชั่วชีวิต | ไม่ทิ้งกันถ้าไม่ถูกหักหลัง |

**เพดาน** สายระดับ 3 ขึ้นไปมีพร้อมกันไม่เกิน 5 สาย (ตรงกับตะขอ "ผู้คนที่เจอซ้ำ" ใน [../experience/02-hooks.md](../experience/02-hooks.md) บวกญาติใกล้ชิด) สายระดับ 1–2 มีไม่เกิน 10 สาย ถ้าเกินเพดาน สายที่ B ต่ำสุดและห่างที่สุดกลายเป็น "จางหาย" ชื่อยังอยู่ในสมุดตระกูลแต่ไม่ปรากฏเป็นเหตุการณ์อีก

### 2.1 ที่ B ขึ้นและลง

| เหตุ | B |
| --- | --- |
| เจอกันตามปกติ (ปีละไม่เกินหนึ่งครั้งนับ) | +3 |
| ช่วยกันผ่านวิกฤต | +8 |
| ช่วยเขาตอนที่เขาขอ | +6 |
| ความสุขร่วมกัน (งานแต่ง งานฉลอง ได้ของดี) | +4 |
| อยู่ในขบวนเดียวกันตลอดปี (ผู้ร่วมทาง) | +4 ต่อปี |
| ให้ของที่ตรงใจ | +2 |
| ไม่ติดต่อกันนานกว่า 3 ปี ในประเทศเดียวกัน | −1 ต่อปี |
| ไม่ติดต่อกันนานกว่า 3 ปี คนละทวีป | −2 ต่อปี |
| ผิดคำมั่น | −10 |
| ขัดค่านิยมกันเรื่องสำคัญ | −5 |

สายญาติเริ่มที่ระดับต่างกันตามความใกล้ ([05-family.md](05-family.md)) ผู้ที่ไม่ได้เป็นญาติเริ่มที่ระดับ 1 เสมอ เว้นแต่เกิดจากเหตุใหญ่ (ไถ่ ช่วยชีวิต) ที่ระบุเริ่มสูงกว่านั้น

## 3. ผลตามสายและระดับ

ตัวเลขเริ่มต้นสำหรับทดสอบ ผลนับเมื่อ NPC ยังมีชีวิตและตัวละครอยู่ในระยะที่ติดต่อได้ ([03-formation.md](03-formation.md) หัวข้อ 4)

| สาย | ระดับ 3 | ระดับ 4 | ระดับ 5 |
| --- | --- | --- | --- |
| สหาย | วิกฤตของตัวละคร (ล้มละลาย ถูกตามล่า ป่วย) 20% ที่เพื่อนช่วยจนความเสียหายลดครึ่ง | 35% และเตือนภัยก่อนเหตุร้าย (ข้ามการซุ่มโจมตี 25%) | 50% และยอมเสียของตนช่วยหนึ่งครั้งในชีวิต |
| คู่หู (การค้า) | ซื้อเชื่อได้ราคาลด 3% บนเส้นที่ทำร่วมกัน | 5% | 8% และแบ่งกำไรโดยไม่ต้องเจรจา |
| คู่หู (การศึก) | ผู้ร่วมทางหนึ่งคนให้ โบนัสการทอยในศึก +3% และลดความเสียหาย 5% | +4% และ 5% | +5% และ 5% |
| คนรัก | ผลเสียทางใจจากเหตุร้ายลด 30% | 40% | 50% และตัวละครกล้าเสี่ยงเพื่อเขาเกินปกติ |
| ครู | skill ที่เขาสอนเพิ่มหนึ่งระดับต่อห้าปี | ทางลัดสู่อาชีพที่เขาถนัด | ส่งต่อเรื่องที่ไม่สอนใคร (อาชีพลับถ้ามีตามกติกา [../character/10-jobs-secret.md](../character/10-jobs-secret.md)) |
| ศิษย์ | ตัวละครได้ชื่อเสียงจากผลงานศิษย์ | ศิษย์ตั้งตัวได้และช่วยตอบแทน | ศิษย์รับเรื่องค้างบางอย่างแทนเมื่อตัวละครตาย |
| ญาติผู้ใหญ่ | ที่พักและข้าวเมื่อยากจน (ลดผลของชนชั้นตก) | ยอมให้ยืมทองหรือค้ำประกัน | ยกมรดกหรือความลับของตระกูล |
| ญาติรุ่นเยาว์ | ความหวังเพิ่มความสุข | ลูกที่ผูกพันช่วยงาน | ผู้สืบที่เข้าใจตัวละครเป็นพิเศษ (รูปสืบ [../../lore/heirs/02-no-repeat.md](../../lore/heirs/02-no-repeat.md)) |
| พี่น้อง | ที่พึ่งร่วมวัย ให้ที่นอนและข่าว | ค้ำประกันและแบกภาระครอบครัวร่วมกัน | ตายแทนกันได้ในเหตุที่เลือกเอง |
| คู่แข่ง | ในเรื่องเดียวกัน ผลงานตัวละครดีขึ้นเล็กน้อย (+1 ต่อการทอยที่แข่งกัน) | ยอมรับกันและกลายเป็นสหายได้ | ผู้ที่เข้าใจตัวละครที่สุดแม้ไม่เป็นมิตร |

**ผู้ร่วมทาง** คือพวกพ้องที่ติดตามตัวละครเดินทางหรือออกศึก ขบวนมีได้ไม่เกิน 4 คน ผู้ร่วมทางรวมกันให้โบนัสไม่เกิน +9% และลดความเสียหายไม่เกิน 15% "พวกพ้องอย่างน้อย 3 คน" ในกติกามังกรหมายถึงผู้ร่วมทางระดับ 3 ขึ้นไปสามคน

สายไม่ได้ให้แค่ตัวเลข ทุกครั้งที่ระดับเปลี่ยนต้องมีฉากที่บอกเหตุ ([04-friend-arcs.md](04-friend-arcs.md) หัวข้อ 4) ไม่ใช่ข้อความ "ได้เพื่อน" ข้อความเดียว

## 4. การเปลี่ยนสาย

| จาก | เป็น | เมื่อ |
| --- | --- | --- |
| คู่แข่ง | สหาย | ระดับ 3 ขึ้นไปและมีเหตุให้ยอมรับกัน (ช่วยกันผ่านเหตุ) |
| สหาย | คนรัก | ระดับ 3 ขึ้นไป ทั้งคู่ยังไม่มีคนรักผูกพัน อายุผ่านเกณฑ์ ไม่ติดข้อห้ามเผ่า (ตาม [../character/01-origin.md](../character/01-origin.md) หัวข้อ 4 สำหรับลูกครึ่ง) |
| สหาย | คู่หู | ตัวละครและเขาทำงานหรือเดินทางด้วยกันตลอดอย่างน้อยหนึ่งปี |
| คนรัก | คนรักที่เป็นคู่ชีวิต | ระดับ 4 ขึ้นไป และเกิดเหตุการณ์ตกลงใจ (แต่งงานหรือสัญญาเทียบเท่าตามถิ่น) |
| ศิษย์ | สหาย | ระดับ 4 ขึ้นไปและศิษย์ผ่านการทดสอบเอง |
| ผู้ที่ถูกช่วย (เด็ก) | ศิษย์ หรือ ญาติรุ่นเยาว์ | รับสอนหรือรับเลี้ยงตามเหตุการณ์ |
| สายใดก็ได้ | ศัตรูตลอดกาล | ถูกหักหลังอย่างร้ายแรงและตัวละครเลือกแค้น |

**ห้าม** ญาติเป็นคนรัก · ผู้ใหญ่เป็นคนรักของศิษย์อายุต่ำกว่า 18 · มีคนรักผูกพันพร้อมกันสองคน (ตัวละครเลือกหรือเรื่องบังคับให้เลือก) · ศัตรูตลอดกาลกลับเป็นพวกพ้องโดยไม่มีเหตุการณ์ไถ่โทษ

## 5. การสิ้นสุดของสาย

| ทางสิ้นสุด | เกิดเมื่อ | ผลต่อตัวละคร |
| --- | --- | --- |
| ตาย | NPC ตาย (ชรา ศึก เหตุ) | ความโศกตามระดับ: ระดับ 3 สั้น ระดับ 4–5 ยาวและถ่ายเป็นเรื่องค้างหรือของระลึก ([06-paired-items.md](06-paired-items.md)) |
| จางหาย | ห่างจนไม่มีเหตุการณ์ใหม่ | ไม่มีผลเสีย ชื่อยังอยู่ในสมุดตระกูล |
| แยกทาง | ทะเลาะหรือขัดค่านิยมแล้วไม่คืนดี | B ตกเหลือ 0 ผลเสียตามความใกล้ |
| หักหลัง | ฝ่ายใดฝ่ายหนึ่งทรยศ | B −30 สายกลายเป็นคู่ศัตรูได้ ตามหัวข้อ 4 |
| จบอย่างดี | ภารกิจร่วมจบหรือส่งต่อ | เก็บเป็นมรดก ฉายา หรือของระลึก |

**เรื่องของพวกพ้องที่ยังไม่จบเมื่อตัวละครตาย** ถูกนับเป็นเรื่องค้างชนิดใหม่ในตาราง [../../lore/heirs/03-open-threads.md](../../lore/heirs/03-open-threads.md) (สัญญา ศิษย์ของผู้อื่น คำมั่น) ทายาทรับได้ตามเพดานเดิม 3 ข้อ

## 6. ที่ต้องทดสอบเมื่อมีโค้ด

| ข้อ | ตรวจ |
| --- | --- |
| เพดาน | ชีวิตตัวอย่างมีสายระดับ 3 ขึ้นไปเฉลี่ย 2–4 สาย และไม่เกิน 5 |
| ค่า B | ตัวละครที่ไม่เดินทางเลยมีสายระดับ 3 ขึ้นไปอย่างน้อย 1 สายกี่เปอร์เซ็นต์ (เป้า ≥ 85%) |
| โบนัสศึก | ผู้ร่วมทาง 4 คนรวมกันไม่ทำให้ศึกปกติชนะอัตโนมัติ |
| ความโศก | อายุเฉลี่ยของ NPC ตายไม่ทำให้ทุกชีวิตเต็มไปด้วยงานศพ (เป้า สายระดับ 3 ขึ้นไปตายระหว่างชีวิตเฉลี่ย 1–2 สาย) |
