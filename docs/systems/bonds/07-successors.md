# ผู้สืบของพวกพ้องตัวหลัก

ภาพรวม: [README.md](README.md) · สายและระดับ: [01-ties-and-levels.md](01-ties-and-levels.md) · การเกิดพวกพ้อง: [03-formation.md](03-formation.md) · เรื่องของพวกพ้องตัวหลัก: [../../lore/storylines/28-allies.md](../../lore/storylines/28-allies.md) [../../lore/storylines/29-allies-flagship.md](../../lore/storylines/29-allies-flagship.md) · ภาพ: [../../appearance/19-ally-successors.md](../../appearance/19-ally-successors.md) · กติกากลาง: [../../lore/npcs/succession.md](../../lore/npcs/succession.md) หัวข้อ 4

พวกพ้องตัวหลัก 55 คนเป็นคนจริง ปรากฏเมื่อตัวละครโตทันช่วงชีวิตของเขา ([../../lore/world/world-time.md](../../lore/world/world-time.md) หัวข้อ 8.1 ผู้เล่นไม่จำเป็นต้องพบทุกคน) ถ้าตัวละครเกิดหลังที่ต้นแบบตายไปแล้ว ช่องนั้นเป็นผู้สืบในไฟล์นี้ ไม่ใช่ผู้สมัครเพิ่มจึงไม่นับเกินเป้า 55

## 1. กติกา

| ข้อ | กติกา |
| --- | --- |
| 1 เมื่อใช้ | ต้นแบบไม่ปรากฏ (ตายแล้ว หรือไม่ผ่านการสุ่มปรากฏ) ต้นแบบที่ยังมีชีวิตใช้ตัวต้นแบบเสมอ |
| 2 รหัส | รหัสต้นแบบตามด้วย S เช่น MH09-7S รหัสนี้ไม่ใช่รหัส NPC ในรายชื่อ (ตัวตรวจ NPC ไม่นับ) |
| 3 เรื่อง | ใช้เรื่องเดียวกับต้นแบบ ปลายทาง ก) ข) ค) น้ำหนักเดิม แต่ชื่อและสถานที่เป็นของผู้สืบ ต้นแบบกลายเป็นคนที่ถูกกล่าวถึง ของที่ทิ้งไว้ หรือหลุมศพ |
| 4 สาย | ใช้สายเดิมของต้นแบบ ยกเว้น **คนรักไม่สืบ** ถ้าสายเดิมมีคนรัก ตัดออก เหลือสายอื่น (ต้นแบบที่มีคนรักทุกคนมีสายอื่นอยู่แล้ว) |
| 5 ระดับ | เริ่มที่ B ต่ำกว่าต้นแบบหนึ่งระดับ เพราะต้องสร้างความผูกพันใหม่ |
| 6 สายครู | ผู้สืบของพวกพ้องสายครูเป็นศิษย์ของครูเดิม สอนต่อด้วยวิธีที่ครูเดิมสอน ไม่ใช่ครูคนใหม่ที่มาจากที่อื่น |
| 7 ผู้ถูกผูกตัว | ผู้สืบของพวกพ้องที่เป็นผู้ถูกผูกตัว (MH09-7 NR05-7 SH01-7 MK16-7) เริ่มในสถานะผูกตัวแบบเดียวกัน ตามกติกาใน [../economy/10-bondage.md](../economy/10-bondage.md) |
| 8 เพดาน | เพดานสายสนิทเดิมใช้ต่อ ผู้สืบนับเป็นพวกพ้องหนึ่งคนเท่ากับต้นแบบ |
