# ระบบพวกพ้อง

ภาพรวมชั้นระบบ: [../README.md](../README.md) · ตะขอผู้คนที่เจอซ้ำ: [../experience/02-hooks.md](../experience/02-hooks.md) · ทายาท: [../../lore/heirs/README.md](../../lore/heirs/README.md) · เส้นเรื่อง: [../../lore/storylines/28-allies.md](../../lore/storylines/28-allies.md)

ตัวละครหลักไม่ได้เดินชีวิตคนเดียว **พวกพ้อง** คือคนที่ตัวละครผูกพัน ได้แก่เพื่อน คู่หู คนรัก ครู ศิษย์ ญาติ และคู่แข่ง ทุกคนมีเรื่องของตัวเองที่เดินต่อไปแม้ตัวละครหลักไม่อยู่ และตัวละครหลักแสดงความรู้สึกต่อแต่ละคนตามสายที่เป็น ไม่ใช่แค่บันทึกว่า "ได้เพื่อน" แล้วจบ

ผู้เล่นเป็นพระเจ้าที่เฝ้าดูตัวละครคนเดียว **เรื่องของพวกพ้องจึงมาถึงผู้เล่นผ่านตัวละครหลักเท่านั้น** (จดหมาย ข่าว การมาเยือน การขอความช่วย) ไม่มีมุมมองแยกที่ตามดูพวกพ้อง

| ไฟล์ | เนื้อหา |
| --- | --- |
| [01-ties-and-levels.md](01-ties-and-levels.md) | สายสัมพันธ์ 9 แบบ ความผูกพัน 0–100 และระดับ 1–5 ผลของแต่ละสาย การเปลี่ยนสาย การสิ้นสุด |
| [02-feelings.md](02-feelings.md) | อารมณ์ 24 อย่างและตารางว่าสายไหนแสดงอารมณ์ไหนได้ตั้งแต่ระดับใด วิธีแสดงออก กติกาที่ตัวตรวจใช้ |
| [03-formation.md](03-formation.md) | พวกพ้องมาจากไหน การชวน การปฏิเสธ ชีวิตของพวกพ้องที่เดินต่อเมื่อห่างกัน |
| [04-friend-arcs.md](04-friend-arcs.md) | เรื่องของพวกพ้อง 3 ชั้น แม่แบบ 12 แบบ กติกาคุณภาพ |
| [05-family.md](05-family.md) | พี่น้อง ลุง น้า ป้า อา ปู่ย่าตายาย ญาติใกล้ชิด ลูก |
| [06-paired-items.md](06-paired-items.md) | ไอเทมคู่ 10 คู่ ของเพื่อนวัยเด็ก คู่รัก ครู คู่แข่ง |
| [../../lore/storylines/28-allies.md](../../lore/storylines/28-allies.md) | โหนด bn kn และเรื่องของพวกพ้องตัวหลักชุดแรก 10 คน |

## ที่มาในโค้ดและเอกสารเดิม

| ของเดิม | ที่ใช้ในระบบนี้ |
| --- | --- |
| `Relation` ในโค้ด 8 ชนิด (`mentor` `rival` `lover` `spouse` `nemesis` `friend` `child` `parent`) และค่า `affinity` | เป็นฐาน: `friend` เป็นสายสหาย `lover` `spouse` เป็นสายคนรัก `mentor` เป็นสายครู `rival` เป็นสายคู่แข่ง `child` `parent` เป็นสายญาติ ส่วน `nemesis` (ศัตรูตลอดกาล) ยังเป็นของ [../combat/04-encounters.md](../combat/04-encounters.md) ไม่นับเป็นพวกพ้อง |
| เป้าหมายของ NPC (`NPC_GOALS` `deeds` ใน `src/data/npclife.ts`) | เป็นเครื่องยนต์ชั้นแรกของเรื่องพวกพ้อง ([04-friend-arcs.md](04-friend-arcs.md) หัวข้อ 1) |
| ผู้คนที่เจอซ้ำ 3–5 คน ([../experience/02-hooks.md](../experience/02-hooks.md) หัวข้อ 3) | เป็นเพดานสายสนิท ([01-ties-and-levels.md](01-ties-and-levels.md) หัวข้อ 2) |
| ผู้สมัครพวกพ้องจากการไถ่ ([../economy/10-bondage.md](../economy/10-bondage.md) หัวข้อ 8) | เป็นที่มาหนึ่งของพวกพ้อง ([03-formation.md](03-formation.md) หัวข้อ 1) |
| พวกพ้อง 3 คนขึ้นไปในศึกระดับตำนาน ([../combat/06-dragon-encounters.md](../combat/06-dragon-encounters.md)) | นิยามชัดเจนว่าหมายถึงผู้ร่วมทางระดับ 3 ขึ้นไป ([01-ties-and-levels.md](01-ties-and-levels.md) หัวข้อ 3) |
| เรื่องค้าง ศิษย์ของผู้อื่น ([../../lore/heirs/03-open-threads.md](../../lore/heirs/03-open-threads.md)) | เรื่องของพวกพ้องที่ยังไม่จบส่งต่อทายาทด้วยกติกานี้ |

## ตัวเลขสรุป

| เรื่อง | จำนวน |
| --- | --- |
| สายสัมพันธ์ | 9 (สหาย คู่หู คนรัก ครู ศิษย์ ญาติผู้ใหญ่ ญาติรุ่นเยาว์ พี่น้อง คู่แข่ง) |
| ระดับความผูกพัน | 5 |
| อารมณ์ในตาราง | 24 |
| แม่แบบเรื่องของพวกพ้อง | 12 (`FT-01` ถึง `FT-12`) |
| แม่แบบญาติ | 8 (`KN-01` ถึง `KN-08`) |
| ไอเทมคู่ | 10 คู่ 20 ชิ้น |
| โหนดเส้นเรื่อง | 13 (bn 8 · kn 5) |
| พวกพ้องตัวหลักที่เขียนมือ | 10 (ชุดแรก เป้าหมายรวม 40–60) |
