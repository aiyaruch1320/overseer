# ความรู้สึกของตัวละครต่อพวกพ้อง

ระบบ: [README.md](README.md) · สายและระดับ: [01-ties-and-levels.md](01-ties-and-levels.md) · เรื่องของพวกพ้อง: [04-friend-arcs.md](04-friend-arcs.md)

ตัวละครหลักแสดงความรู้สึกต่อพวกพ้อง แต่ **ความรู้สึกต้องตรงกับสายที่เป็นจริง** เพื่อนไม่หึงเหมือนคนรัก พี่น้องไม่เอ็นดูเหมือนครูต่อศิษย์ ไฟล์นี้กำหนดว่าสายไหนแสดงอารมณ์ไหนได้ ตั้งแต่ระดับความผูกพันเท่าไร และตัวตรวจเอกสาร ([../../../scripts/docs/check-docs.mjs](../../../scripts/docs/check-docs.mjs)) อ่านตารางนี้ตรวจทุกเรื่องที่เขียนอารมณ์ไว้

## 1. อารมณ์ 24 อย่าง

| อารมณ์ | ความหมาย | ต้องมีเหตุ |
| --- | --- | --- |
| ห่วง | กังวลความปลอดภัยหรือความเป็นอยู่ของเขา | เขาอยู่ในอันตราย ป่วย หรือยากจน |
| คิดถึง | อยู่ไกลกันและอยากพบ | ห่างกันอย่างน้อยหนึ่งปี |
| ภูมิใจ | ดีใจกับความสำเร็จของเขาเหมือนเป็นส่วนหนึ่งของตน | เขาสำเร็จเรื่องที่ตัวละครมีส่วนหรือหวังไว้ |
| ไว้ใจ | วางใจให้พึ่งพาและบอกความลับ | เขาเคยรักษาคำหรือช่วยในยามยาก |
| ขอบคุณ | สำนึกบุญคุณ | เขาช่วยจนเกิดบุญคุณ |
| ยินดี | ดีใจกับเรื่องดีของเขา | เขาได้เรื่องดี |
| เสียใจ | ทุกข์เพราะเรื่องร้ายหรือการสูญเสียของเขา | เขาเสียของ เสียคน หรือตาย |
| น้อยใจ | รู้สึกถูกมองข้ามหรือถูกวางไว้ข้างหลัง | เขามีคนใหม่ มีเรื่องใหม่ หรือไม่ตอบ |
| โกรธ | โกรธการกระทำของเขา | เขาทำร้ายหรือเลี่ยงคำมั่น |
| ผิดหวัง | คาดหวังไว้แล้วไม่เป็นตาม | เขาเลือกทางที่ตัวละครไม่หวัง |
| อิจฉา | อยากได้สิ่งที่เขามี | เขาสำเร็จหรือมีของที่ตัวละครอยากได้ |
| หึง | กลัวคนรักจะรักคนอื่น | มีคนอื่นเข้ามาในความสัมพันธ์รักเท่านั้น |
| หวงแหน | ปกป้องและไม่ยอมให้ใครพรากเขาไป | เขาถูกคุกคามหรือยังเปราะบาง |
| เกรงใจ | ไม่กล้ารบกวนเพราะรักษาน้ำใจหรือติดบุญคุณ | เขามีฐานะหรือบุญคุณเหนือกว่า |
| เคารพ | ยกย่องในฐานะผู้อาวุโสหรือผู้มีคุณวุฒิ | เขาควรแก่การยกย่อง |
| ชื่นชม | ประทับใจฝีมือหรือคุณสมบัติของเขา | เขาทำสิ่งที่น่าทึ่ง |
| ละอาย | อายต่อหน้าเขาเพราะการกระทำของตนหรือครอบครัว | ตัวละครทำผิดหรือไม่ถึงที่หวัง |
| รู้สึกผิด | สำนึกว่าทำร้ายหรือทิ้งเขา | ตัวละครทำให้เขาเสียหาย |
| กลัวเสีย | กลัวเขาจะตายหรือจากไป | เขาเสี่ยงชีวิตหรือแก่ชรา |
| เหงา | ว่างเปล่าเพราะขาดเขา | หลังแยกกันหรือเสียเขาไป |
| ระแวง | ไม่แน่ใจว่าเขาซื่อสัตย์ | มีเบาะแสว่าเขาปิดบังหรืออาจทรยศ |
| แค้น | อยากเอาคืนสิ่งที่เขาทำ | เขาหักหลังหรือฆ่าคนใกล้ชิด |
| รัก | ผูกพันแบบคนรัก | คนรักเท่านั้น |
| เอ็นดู | รักและเมตตาต่อผู้เยาว์กว่า | ผู้เยาว์ที่ตัวละครดูแล |

## 3. ข้อห้ามที่ทำให้เรื่องไม่สมเหตุสมผล

| อารมณ์ | ใช้ได้กับ | ห้ามใช้กับ | ถ้าเรื่องต้องการความรู้สึกใกล้เคียง ให้ใช้ |
| --- | --- | --- | --- |
| หึง | คนรักเท่านั้น | สหาย คู่หู ครู ศิษย์ ญาติ พี่น้อง คู่แข่ง | สหายที่เพื่อนมีเพื่อนใหม่ใช้ **น้อยใจ** · พี่น้องที่พ่อแม่รักอีกคนมากกว่าใช้ **อิจฉา** · ครูที่ศิษย์ไปเรียนกับคนอื่นใช้ **น้อยใจ** หรือ **ผิดหวัง** |
| รัก | คนรักเท่านั้น | ทุกสายอื่น | ศิษย์และเด็กใช้ **เอ็นดู** · สหายสนิทใช้ **ไว้ใจ** หรือ **ห่วง** |
| หวงแหน | คนรัก ศิษย์ ญาติรุ่นเยาว์ พี่น้อง | สหาย คู่หู ครู ญาติผู้ใหญ่ คู่แข่ง | สหายที่ถูกคุกคามใช้ **ห่วง** |
| เอ็นดู | ศิษย์ ญาติรุ่นเยาว์ พี่น้อง (ผู้พี่มองผู้น้อง) | ผู้ที่ไม่ได้เยาว์กว่าหรือไม่ได้ดูแล | คนวัยเดียวกันใช้ **ชื่นชม** |
| อิจฉา | สายที่เปรียบเทียบกันได้ (สหาย คู่หู คนรัก ศิษย์ พี่น้อง คู่แข่ง) | ครู ญาติผู้ใหญ่ ญาติรุ่นเยาว์ | ครูที่เก่งกว่ามากใช้ **ชื่นชม** หรือ **เคารพ** |
| เคารพ | ผู้อาวุโสหรือมีคุณวุฒิ | ศิษย์ ญาติรุ่นเยาว์ พี่น้อง | ผู้ที่ด้อยกว่าที่ทำเรื่องใหญ่ใช้ **ชื่นชม** |
| เกรงใจ | ผู้มีฐานะหรือบุญคุณเหนือกว่า | ศิษย์ ญาติรุ่นเยาว์ พี่น้อง คู่แข่ง | ใช้ **ขอบคุณ** |
| ห่วง คิดถึง กลัวเสีย | ผู้ที่มีสายผูกพัน | คู่แข่ง | คู่แข่งที่กลายเป็นสหายแล้วใช้ตามสายใหม่ |

## 4. กติกาอื่น

| ข้อ | กติกา |
| --- | --- |
| 1 | ทุกอารมณ์ต้องมี **เหตุ** ตามตารางหัวข้อ 1 ไม่มีอารมณ์ลอย |
| 2 | คนเดียวแสดงอารมณ์พร้อมกันได้ไม่เกิน 2 อย่าง (เช่น ห่วง กับ โกรธ) |
| 3 | ตัวละครแสดงอารมณ์ต่อสายเดียวกันไม่เกิน 2 ครั้งต่อปี กันล็อกซ้ำ |
| 4 | อารมณ์จางตามเวลา อารมณ์รุนแรง (โกรธ แค้น เสียใจ) จางช้ากว่าอารมณ์เบา (ยินดี ชื่นชม) |
| 5 | อารมณ์น้ำเสียงตามนิสัยของตัวละคร คนใจร้อนแสดงโกรธเร็ว คนขี้อายแสดงน้อยใจแทนโกรธ นิสัยเปลี่ยนน้ำเสียง ไม่เปลี่ยนว่าอารมณ์นั้นมีได้หรือไม่ |
| 6 | สายที่เปลี่ยน ([01-ties-and-levels.md](01-ties-and-levels.md) หัวข้อ 4) เปลี่ยนชุดอารมณ์ที่ใช้ได้ตามสายใหม่ทันที และอารมณ์ที่ใช้ไม่ได้กับสายใหม่ (เช่น น้อยใจแบบเพื่อน) แปรเป็นอารมณ์ใกล้เคียงของสายใหม่ในเรื่องที่ต่อกัน |
| 7 | คนรักอยู่ในสายเดียวกันทั้งตอนเป็นแฟนและตอนเป็นคู่ชีวิต ตารางไม่แยก |

## 5. วิธีแสดงออก

อารมณ์หนึ่งครั้งออกได้สามทาง ต้องมีอย่างน้อยหนึ่งทาง และอารมณ์รุนแรงต้องมีสองทาง

| ทาง | ใช้กับ | หมายเหตุ |
| --- | --- | --- |
| บรรทัดล็อก | ทุกอารมณ์ | เขียนเหตุกับอารมณ์ในประโยคเดียว ไม่เขียนว่า "รู้สึก X" ตรง ๆ ให้เห็นจากการกระทำ |
| อีโมตในแอนิเมชัน | อารมณ์ที่เห็นได้ (ยินดี เสียใจ โกรธ หึง กลัวเสีย เหงา) | รายละเอียดภาพอยู่ในชั้น appearance |
| ผลต่อใจตัวละคร | อารมณ์ที่เปลี่ยนค่าอารมณ์ระยะยาว (ยังไม่มีค่านี้ในโค้ด ให้ผูกกับค่าอารมณ์ที่มีตอนทำ) | ตารางด้านล่าง |

| อารมณ์ | ผลต่อใจ (ต่อปีที่ยังมีอารมณ์) |
| --- | --- |
| ยินดี ภูมิใจ ไว้ใจ ขอบคุณ ชื่นชม รัก เอ็นดู | +1 |
| ห่วง คิดถึง เกรงใจ เคารพ | 0 (ไม่เปลี่ยนใจ แต่เปลี่ยนการตัดสินใจ) |
| น้อยใจ ผิดหวัง อิจฉา ละอาย ระแวง | −1 |
| โกรธ หึง รู้สึกผิด กลัวเสีย เหงา เสียใจ | −2 |
| แค้น | −2 และเปิดทางเรื่องค้างศึกสายเลือด |

ตัวอย่างน้ำเสียงของล็อก (ใช้เป็นแนวในเอกสารชั้น appearance)

| อารมณ์และสาย | ตัวอย่าง |
| --- | --- |
| น้อยใจ (สหาย) | เพื่อนสมัยเด็กไปงานวันเกิดของคนอื่นโดยไม่ชวน ตัวละครเก็บของขวัญไว้ใต้เตียงอีกปี |
| หึง (คนรัก) | ตัวละครเห็นเธอหัวเราะกับพ่อค้าคนใหม่ แล้วเดินกลับบ้านไม่พูดตลอดทาง |
| อิจฉา (พี่น้อง) | พี่ชายได้รับดาบของพ่อ ตัวละครรับน้ำให้แขกเงียบ ๆ |
| ภูมิใจ (ศิษย์) | ศิษย์ตีดาบเล่มแรกเสร็จ ตัวละครไม่พูดอะไร แต่แขวนไว้เหนือเตาตลอดปี |
| เกรงใจ (ครู) | ครูไม่เคยขอสิ่งใด ตัวละครจึงไม่กล้าขอให้ครูพักผ่อน |
| กลัวเสีย (ญาติผู้ใหญ่) | ลุงไอตอนเช้าทุกวัน ตัวละครเริ่มซื้อยาโดยไม่บอก |

## 6. สัญญาที่ตัวตรวจใช้

เอกสารที่เขียนอารมณ์ของตัวละครต่อพวกพ้อง (เช่น [../../lore/storylines/28-allies.md](../../lore/storylines/28-allies.md)) ใส่เครื่องหมายแบบ `{สาย:อารมณ์@ระดับ}` เช่น `{คนรัก:หึง@3}` และ `{สหาย:น้อยใจ@2}` ตัวตรวจ `check-docs.mjs`

- ตรวจว่าสายและอารมณ์อยู่ในตารางนี้
- ตรวจว่าระดับที่ระบุไม่ต่ำกว่าระดับต่ำสุดของช่องนั้น และช่องนั้นไม่ใช่ `-`
- ตรวจว่าในเรื่องของ NPC หนึ่งคนที่ประกาศสายไว้ เครื่องหมายใช้เฉพาะสายที่ประกาศ

ตัวอย่างที่ตัวตรวจ **ไม่ผ่าน** เมื่อเขียนเป็นเครื่องหมาย: หึงของสหาย หึงของพี่น้อง รักของศิษย์ เอ็นดูของคนวัยเดียวกัน
