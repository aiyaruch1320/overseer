# อารมณ์มังกร: ผลเมื่อมังกรล้มและค่าเริ่มต้น

ตัวตนของมังกรและความสัมพันธ์: [../../lore/dragons/README.md](../../lore/dragons/README.md) (ชั้นโลก) ไฟล์นี้เก็บเฉพาะกติกาที่เกมคำนวณ

## เมื่อมังกรตัวหนึ่งตาย

ไม่ว่าจะล้มด้วยวิธีใด (ถูกฆ่า สิ้นแรง สละชีวิต แปลงกาย หลับลึกถาวร) เกิดเหตุการณ์ DR-15 คลื่นไว้อาลัย ทันที

| ผลต่อ | ขนาด |
| --- | --- |
| มังกรที่เหลือทุกตัว | อารมณ์ −3 ถึง −5 ตามความสนิทกับผู้ล้ม (−3 + −2 × ความสนิท 0 ถึง 1) ตัวที่สนิทสุดได้ −8 (ค่าเดิม −15 ถึง −25 และ −40 ทำให้ยุค 3 และ 4 พังภายในร้อยปี รอบแรกลดเป็น −5 ถึง −9 รอบสองเป็นค่านี้ ดู [world-sim.md](world-sim.md)) |
| มังกรที่สนิทสุด | เข้าสถานะ **ขาดสติ** เลือกหนึ่ง: คลั่ง สละตัว หรือหลับลึก ตามตารางคู่สนิท |
| เพดานอารมณ์ของทุกตัว | ลดถาวร 3 ต่อการล้มหนึ่งตัว (ตัวสูงสุดเหลือ 100 − 3 × DFC) |
| ผู้คนทั้งโลก | ทุกคนในทุกทวีปได้ยินเสียงร้องไห้ในความฝันหนึ่งคืน |
| ศรัทธาช่อง A ทั่วโลก | +10 เป็นเวลาห้าปี (ผู้คนหวาดกลัวและสวด) แล้วลดลงถ้าไม่มีคำตอบ |
| ทวีปของมังกร | ผลหลัก (เหตุการณ์ DR, PL, END ของตัวนั้น) |
| **ทุกทวีป** | **ผลรองตามธาตุของผู้ล้ม** ตามตารางด้านล่าง |

### ผลรองที่ทุกทวีปรู้สึก

| มังกรที่ล้ม | ผลรองทุกทวีป |
| --- | --- |
| โอรัน-ซัล | ศิลาลอยและของที่ลอยอ่อนแรงทั่วโลก ท้องฟ้าทุกทวีปมีแสงสีมุกหนึ่งคืน |
| เพลิงนิรันดร์ | ไฟทุกกองเย็นลงหนึ่งฤดู เตาหลอมและเตาผิงติดยาก อาวุธธาตุไฟอ่อนลง |
| สมุทรอาลัย | ฝนตกเป็นน้ำเค็ม แม่น้ำและทะเลสาบสูงขึ้น ชายฝั่งทั้งโลกน้ำขึ้นหนึ่งขั้นชั่วคราว |
| พายุไร้ทิศ | ลมทุกทวีปนิ่งสิบวันแล้วพัดสุ่ม เรือเดินไม่ได้ |
| ศิลาสะท้าน | แผ่นดินไหวเล็กทุกทวีปตลอดหนึ่งเดือน |
| ราหู | วัน-คืนทั่วโลกเพี้ยนสามวัน สุริยคราสเกิดทุกทวีป |
| อีริดาน | เมฆรวมเป็นรูปมังกรหนึ่งวัน ฝนไร้ฤดู ผลผลิตเกษตรทั่วโลกลด 20% |
| ฮรอด-กาธ | ความหิวและอารมณ์ก้าวร้าวพุ่งทุกทวีป ราคาอาหาร +50% |
| คัลดรา | ภูเขาไฟเล็กทั่วโลกปะทุ ฤดูหนาวสั้นหรือยาวผิดปกติ |
| ธาลาสซา | น้ำขึ้นน้ำลงรวนสามวัน ปลาตายหมู่ในทะเลสาบทุกแห่ง |
| อันดาร์ | ฝันร้ายร่วมกันทั้งโลกตลอดหนึ่งฤดู |
| เซเรเน | ไฟและแสงเมคาเรียดับทั้งทวีป อุปกรณ์เวทรูนทั่วโลกผิดปกติ |
| กรอม-ธาร | ภูเขาทุกลูกสั่น หินร่วงทั่วโลก ยักษ์ทั้งโลกหยุดงานหนึ่งปีเพื่อไว้อาลัย |
| ซิลเวรา | พืชทุกชนิดเหี่ยวหนึ่งฤดู การรักษาทั่วโลกด้อยลง |
| นิเวรี | หมอกบางหย่อมปรากฏทุกทวีปหนึ่งวัน เสียงกระซิบในหูผู้คน |

## ค่าเริ่มต้นของอารมณ์และอัตราเปลี่ยน

ค่าที่จูนด้วยการจำลอง ([world-sim.md](world-sim.md)) ค่าลดต่อทศวรรษในตารางคูณ 0.7 ก่อนใช้ ยุค 2 / 3 / 4 เริ่มที่ราว 620 / 980 / 1,320 ปีโลก และโลกจบเพียง 8%

| --- | --- | --- | --- |
| โอรัน-ซัล | 72 | 1.2 | ชราและเหนื่อยที่สุด |
| เพลิงนิรันดร์ | 72 | 0.8 | |
| สมุทรอาลัย | 62 | 1.1 | เศร้ามากขึ้นทุกทศวรรษ |

| ศิลาสะท้าน | 72 | 0.7 | ดื้อ นิ่ง |
| ราหู | 70 | 0.9 | สองหัวทะเลาะกัน |
| อีริดาน | 72 | 0.8 | |
| ฮรอด-กาธ | 70 | 1.0 | หิวตลอด |

**กติกาต่อทศวรรษ** อารมณ์เปลี่ยน = 0.03 × (เพดาน − อารมณ์) × (ศรัทธาโลก ÷ 60) − ค่าลดของตัวนั้น เพดาน = 100 − 3 × DFC ศรัทธาโลกเริ่ม 60 ลดเฉลี่ย 0.3 ต่อทศวรรษ และเพิ่ม 4 ทุกครั้งที่มังกรล้ม เมื่ออารมณ์ต่ำกว่า 10 มังกรล้มด้วยโอกาส 35% ต่อทศวรรษ (ต่ำกว่า 3 ล้มแน่) ยกเว้นมังกรตัวสุดท้าย ล้มได้เฉพาะพร้อมฉากจบของโลก ผู้อาวุโสล้มได้เมื่อยุคถึงเงื่อนไขของเหตุการณ์ตัวเอง (DR-01 DR-04 DR-05 DR-06 DR-08 ยุค 2 ขึ้นไป DR-07 ยุค 3 ขึ้นไป) มังกรเสาล้มได้ทุกยุค
