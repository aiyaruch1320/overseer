# เหตุการณ์ท้องถิ่น: จุดบรรจบของ NPC

ระบบ: [README.md](README.md) · เหตุการณ์โลก: [world-events.md](world-events.md) · NPC: [../../lore/npcs/README.md](../../lore/npcs/README.md) · ความครอบคลุม: [../../_generated/event-coverage.md](../../_generated/event-coverage.md) · การเดินทาง: [../travel/01-travel-rules.md](../travel/01-travel-rules.md)

เหตุการณ์โลก 152 รายการ ([world-events.md](world-events.md)) เขียนระดับทวีปและยุค จึงมีประเทศน้อยมากที่มีเหตุการณ์ระบุชื่อ (ก่อนเพิ่มไฟล์นี้: 118 จาก 143 ประเทศไม่มีเหตุการณ์ใดระบุ และ NPC 260 ตัวไม่ผูกทั้งเหตุการณ์และ NPC อื่น หลังเพิ่ม LC-01 ถึง LC-09 เหลือ 105 ประเทศและ 246 ตัว ตัวเลขปัจจุบันอยู่ใน [../../_generated/event-coverage.md](../../_generated/event-coverage.md)) ไฟล์นี้เพิ่มชั้นเหตุการณ์ **ระดับเมืองและประเทศ** ที่ทำให้ NPC หลายตัวมาพบกันเพราะเรื่องเดียว

## 1. หลักการ

| ข้อ | กติกา |
| --- | --- |
| 1 | เหตุการณ์ท้องถิ่น (รหัส `LC-`) เกิดในประเทศหรือคู่ประเทศเดียว ไม่เปลี่ยนแผนที่หรือยุคของโลก |
| 2 | ทุกเหตุการณ์ต้องมี **NPC ที่บรรจบ** อย่างน้อยสามตัว (อย่างน้อยหนึ่งตัวต่างเผ่าจากอีกตัว หรือต่างประเทศ) เพื่อให้เป็นจุดบรรจบจริง ไม่ใช่ฉากของคนเดียว |
| 3 | ทุกเหตุการณ์อ่านเหตุการณ์โลกอย่างน้อยหนึ่งรายการ (คอลัมน์ ขึ้นกับ) และเขียนผลกลับเป็นน้ำหนักของเหตุการณ์โลกหรือเส้นของ NPC |
| 4 | NPC ที่ตายหรือหายไปก่อนเหตุการณ์ตัดออกจากรายชื่อ ถ้าเหลือน้อยกว่าสามตัว เหตุการณ์ไม่เกิด |
| 5 | ตัวละครหลักเข้าร่วมได้ด้วย `[ช่วย]` `[ขัดขวาง]` `[ร่วม]` ตามกติกา NPC ([../../lore/npcs/README.md](../../lore/npcs/README.md) หัวข้อ 4) ถ้าอยู่ในประเทศนั้นในปีที่เกิด |
| 6 | เหตุการณ์ท้องถิ่นเกิดได้ครั้งเดียวต่อโลก และเกิดตามโอกาสของแถว (ต่อทศวรรษ) |

## 3. แม่แบบและเหตุการณ์ที่สร้างจากแม่แบบ
