# ระบบต่อสู้: แกนการคำนวณ

ระบบ: [README.md](README.md) · ธาตุและชนิดศัตรู: [02-type-matrix.md](02-type-matrix.md) · ศัตรู: [03-enemies.md](03-enemies.md)

ผู้เล่นเป็นพระเจ้าที่ดู ตัวละครเลือกเองว่าจะสู้ หนี เจรจา หรือใช้เวท การต่อสู้จึงคำนวณอัตโนมัติจากค่าของตัวละคร แต่ผลต้องอธิบายได้ว่าเพราะอะไร (เช่น เวทแสงจึงชนะผี) และเปิดช่องให้พระเจ้าแทรกแซงได้

## 1. ของเดิมในโค้ดที่เป็นฐาน

| ส่วน | โค้ดปัจจุบัน (`src/sim/game.ts`) |
| --- | --- |
| การทอย | d20 + โบนัส ≥ DC สำเร็จ · ทอย 20 สำเร็จเสมอ · ทอย 1 ล้มเหลวเสมอ · ล้มเหลวแล้วมีโอกาสทอยใหม่ตามโชค (`rerollChance`) |
| โบนัส (`checkBonus`) | (ค่าสถานะ − 10) ÷ 2 · มีแท็กที่ศัตรูแพ้ +4 · มีแท็กที่ทำให้ตัวเองเสียเปรียบ −4 · `hero_luck` +1 · พลังอาวุธ (ถ้าเป็นทางเลือกต่อสู้) · `dull` −2 · hp ต่ำกว่า 30% −2 |
| ผล | ชนะ: ของรางวัล + `kill` + ชื่อเสียง · แพ้: hp ลด DC × 2.4 |
| ทางเลือก | ชักอาวุธ (กำลัง) · ร่ายเวท (เวท ถ้ามีความถนัดเวท) · สื่อสารและสงบ (โชค ถ้ามีแท็กสัตว์) · หนี (เร็ว) |
| การเลือกของตัวละคร | สุ่มตามน้ำหนักนิสัยและเส้นเรื่อง (`choiceProbs`) |
| ความถี่ | ต่อฤดู 1.2% × ความอันตรายของประเทศ × (1 − โชค × 1.5%) |

ระบบใหม่ **ใช้การทอยและโบนัสเดิม** แต่แบ่งการต่อสู้เป็นหลายจังหวะ เพิ่มชนิดศัตรู ธาตุ สัตว์คู่หู พวกพ้อง บาดแผลถาวร และรางวัลแบบสุ่ม

## 2. ลำดับการต่อสู้

| ลำดับ | ชื่อ | เกิดอะไร |
| --- | --- | --- |
| 0 | รับรู้ | ตัวละครทอยรับรู้ (ปัญญาหรือเร็ว) เทียบความลอบเร้นของศัตรู สำเร็จ: ได้เปรียบจังหวะแรก (+2) ล้มเหลว: ถูกซุ่ม (−2 จังหวะแรก) สัตว์คู่หูที่มี `pa_danger_sense` หรือ `pa_night_watch` ทำให้ไม่ถูกซุ่ม |
| 1 | ตัดสินใจ | ตัวละครเลือกท่าทีจากรายการในหัวข้อ 3 ตามน้ำหนักนิสัย (ของเดิม) และกติกาหัวข้อ 6 |
| 2 | ปะทะ | ทอยจังหวะละหนึ่งครั้ง สำเร็จ: ศัตรูเสีย **แผล** หนึ่งแผล (หรือสองแผลถ้าทอยได้ 20 หรือโจมตีจุดอ่อนรุนแรง) ล้มเหลว: ตัวละครเสีย hp |
| 3 | จบ | ศัตรูแผลหมด: ชนะ · ตัวละคร hp หมดหรือถอย: แพ้หรือหนี · ครบจำนวนจังหวะสูงสุด: เสมอหรือแยกย้าย |

**จำนวนแผลของศัตรู** และจำนวนจังหวะสูงสุด

| ระดับศัตรู | แผล | จังหวะสูงสุด | ตัวอย่าง |
| --- | --- | --- | --- |
| ลูกกระจ๊อก | 1 | 2 | สไลม์ป่า ก๊อบลินตัวเดียว |
| ปกติ | 2 | 3 | หมาป่าเงา โจรภูเขา |
| หัวหน้า | 3 | 4 | โทรลล์ภูเขา แม่ทัพโจร |
| บอส | 4 ถึง 6 | 6 | ลิชโบราณ คราเคน แม่ทัพปีศาจ |
| ตำนาน | 8 | 8 | มังกร ไททัน (ดู [06-dragon-encounters.md](06-dragon-encounters.md)) |

ศัตรูที่เป็น **ฝูง** นับแผลรวมของฝูง (เช่น ฝูงหมาป่าห้าตัว 4 แผล) และ DC เพิ่มตามหัวข้อ 4

## 3. ท่าทีของตัวละคร

| ท่าที | ค่าสถานะที่ใช้ | แท็กของทางเลือก | มีเมื่อ |
| --- | --- | --- | --- |
| ปะทะประชิด | กำลัง (`pow`) หรือ เร็ว (`spd`) ถ้าใช้มีดสั้น แส้ | fight | เสมอ |
| ยิงระยะไกล | เร็ว (`spd`) หรือ โชค (`luk`) ถ้าหนังสติ๊ก | fight ranged | มีความถนัดธนู หนังสติ๊ก หรืออาวุธยิง |
| ร่ายเวท | เวท (`mag`) หรือปัญญา (`int`) สำหรับรูน มายา มิติ | fight learn | มีความถนัดเวทอย่างน้อยหนึ่ง |
| ตั้งรับ | ทน (`vit`) | fight safe | มีโล่ หรือ `#guard` หรือพวกพ้องที่ต้องปกป้อง ลดความเสียหายครึ่งหนึ่ง แต่ทำแผลได้เฉพาะเมื่อทอยได้ 18 ขึ้นไป |
| เจรจา ข่มขู่ ต่อรอง | โชคหรือปัญญา | help trust | ศัตรูมีความคิด (มนุษย์ เผ่าต่าง ๆ ปีศาจ มังกร) |
| สงบสัตว์ ฝึกให้เชื่อง | โชค | help trust | ศัตรูเป็นสัตว์และตัวละครมี `#beast_friend` `#beast` `taming` หรือ `#polyglot` · สำเร็จแล้วอาจได้สัตว์คู่หู ([../character/13-companions-overview.md](../character/13-companions-overview.md)) |
| หลอกล่อ ลอบหลบ | เร็ว | flee stealth | มี `stealth` หรือ `#stealth` หรือสัตว์คู่หูที่ `pa_distract` |
| สวดภาวนา | ศรัทธาเทพ (`belief`) ÷ 10 แทนโบนัสค่าสถานะ | pray | ตัวละครมีศรัทธาเทพ ≥ 20 สำเร็จ: เปิดหน้าต่างให้พระเจ้าแทรกแซง (หัวข้อ 8) |
| หนี | เร็ว | flee safe | เสมอ |

## 4. โบนัสและ DC

**โบนัสของตัวละคร** (เพิ่มจาก `checkBonus` เดิม)

| ส่วน | ค่า | หมายเหตุ |
| --- | --- | --- |
| ค่าสถานะ | (ค่า − 10) ÷ 2 ปัดลง | ของเดิม |
| skill ของความถนัดที่ตรงท่าที | ระดับ 1: +1 · ระดับ 2: +2 · ระดับ 3: +4 | ใช้ระดับสูงสุดที่ตรง เช่น ปะทะด้วยดาบ ใช้ `sword_*` |
| พลังอาวุธ | ตามอาวุธ | ของเดิม ใช้เมื่อท่าทีเป็น fight |
| ธาตุของอาวุธตรงจุดอ่อน | +2 | ตาม [02-type-matrix.md](02-type-matrix.md) |
| แท็กที่ศัตรูแพ้ | +4 แพ้ · +6 แพ้รุนแรง | ของเดิม +4 · แพ้รุนแรงเพิ่มใหม่ |
| แท็กที่ศัตรูทน | −4 · ภูมิคุ้มกัน: ท่าทีนั้นใช้ไม่ได้ | ของเดิมคือ DC +2 เปลี่ยนเป็นโบนัส −4 เพื่อให้เห็นชัด |
| แท็กที่ทำให้ตัวเองเสียเปรียบ | −4 | ของเดิม เช่น ภูตพรายถูกอาวุธเหล็ก |
| สัตว์คู่หู | `pa_bite_assist` `pa_flank` `pa_claw_dive` ฯลฯ ระดับ 1: +1 · 2: +2 · 3: +3 | ใช้สูงสุดหนึ่งความสามารถต่อจังหวะ |
| พวกพ้อง NPC ที่สู้ด้วย | +2 ต่อคน สูงสุด +4 | ผู้ติดตาม (`[ร่วม]` ในระบบ NPC) |
| สภาพแวดล้อม | −2 ถึง +2 | กลางคืนสำหรับผู้ไม่มี `darkvision` −2 · หมอกสำหรับผู้มี `#fog_sight` +2 · ถิ่นที่ชอบของเผ่า +1 · ในน้ำสำหรับ `water_breath` +2 |
| สภาพร่างกาย | hp ต่ำกว่า 30% −2 · `#berserk` เปลี่ยนเป็น +2 | ของเดิม + ใหม่ |
| ได้เปรียบหรือถูกซุ่ม | +2 หรือ −2 | จังหวะแรกเท่านั้น |
| `hero_luck` `dull` | +1 · −2 | ของเดิม |

**DC ของศัตรู** = DC พื้นฐาน (ใน [03-enemies.md](03-enemies.md)) + ฝูง (+1 ต่อศัตรูเพิ่มทุก 2 ตัว สูงสุด +5) + ภาวะพิเศษ (ศัตรูอยู่ในถิ่นตัวเอง +1 · ศัตรูโกรธหรือคลั่ง +2)

## 5. ความเสียหายและบาดแผล

**ความเสียหายเมื่อทอยล้มเหลว** = DC × 2.4 ÷ จำนวนจังหวะสูงสุด × ตัวคูณ (ความเสียหายรวมของการต่อสู้ทั้งครั้งยังใกล้เคียงของเดิม)

| ตัวคูณลดความเสียหาย | ค่า |
| --- | --- |
| ตั้งรับ | ×0.5 |
| `#guard` (`b_aegis` `b_ironskin` ฯลฯ) | ×0.8 |
| `iron_body` `stone_blood` `#stone_skin` | ×0.85 ถึง ×0.9 |
| สัตว์คู่หู `pa_thick_hide` (ของตัวละคร) | ×0.95 ถึง ×0.85 |
| `pa_life_share` | รับแทนครั้งหนึ่ง (ตามระดับ) |
| ธาตุของศัตรูที่ตัวละครทน (เช่น ไฟกับ `fire_res`) | ×0.5 |
| ธาตุที่ตัวละครแพ้ (เช่น แสงกับ `weak_light`) | ×1.5 |

**บาดแผลถาวร** เมื่อแพ้ (ตัวละครหนีหรือถูกล้ม) ทอยดูบาดแผลหนึ่งครั้ง

| ผลทอย d100 | บาดแผล |
| --- | --- |
| 1–60 | ไม่มี แค่ฟื้นตามปกติ |
| 61–80 | แผลเป็นที่มีเรื่องเล่า (`fame+2` ได้ประโยคเรื่องเล่า) |
| 81–90 | บาดเจ็บนาน (hp สูงสุด −10 หนึ่งปี) |
| 91–96 | คำสาปจากการบาดเจ็บ: `c_limp` เดินกะเผลก · `c_oneeye` ตาบอดข้างหนึ่ง · `c_glassjaw` คางแก้ว · `nc_bad_back` หลังเสื่อม (สุ่มตามชนิดการโจมตี) |
| 97–100 | คำสาปจากศัตรู (ตามตาราง [05-rewards.md](05-rewards.md) ช่อง คำสาปเมื่อแพ้) |

ศัตรูที่มีพิษ (`poison` ในช่องการโจมตี) เพิ่มโอกาสคำสาป `c_fever` ศัตรูผู้ตายเพิ่มโอกาส `c_undeadtouch` แวมไพร์เพิ่มโอกาส `c_vampbite`

## 6. ตัวละครเลือกท่าทีอย่างไร

ใช้น้ำหนักนิสัยเดิม (`choiceProbs`) บวกกติกาความสมเหตุสมผล

| เงื่อนไข | ผลต่อการเลือก |
| --- | --- |
| hp ต่ำกว่า 30% | น้ำหนักหนี ×2 ยกเว้นนิสัย `reckless` `bloodlust` หรือ `#berserk` |
| นิสัย `coward` หรือคำสาป `c_rabbitheart` | หนี ×3 ในจังหวะแรก |
| นิสัย `kind` หรือ `#peace` กับศัตรูที่คิดได้ | เจรจา ×2 |
| ตัวละครรู้จุดอ่อนของศัตรู (เคยเจอ หรือมี `#seer` `u_appraisal` `#truth`) | เลือกท่าทีที่ตรงจุดอ่อน ×3 |
| ปกป้องผู้อื่น (หมู่บ้าน ครอบครัว ผู้ติดตาม) | หนี ×0.3 ตั้งรับ ×2 |
| อาชีพนักบวช ผู้ขับไล่ผี กับศัตรูผู้ตาย | สวดภาวนาและเวทแสง ×2 |
| อาชีพนักฝึกสัตว์ เดรุยด์ กับศัตรูสัตว์ | สงบสัตว์ ×3 |
| ความฝันจากพระเจ้า (ระบบความฝันเดิม) ที่ตรงท่าที | ×3 (ของเดิม "ทำตามความฝัน") |

## 7. ผลของการต่อสู้

| ผล | เงื่อนไข | ผลต่อตัวละคร |
| --- | --- | --- |
| ชนะเด็ดขาด | ศัตรูแผลหมดโดยตัวละครไม่เสีย hp | รางวัลเต็ม · `fame` +50% · เส้นเรื่อง `thread:warrior` +2 |
| ชนะ | ศัตรูแผลหมด | รางวัลตาม [05-rewards.md](05-rewards.md) |
| สงบศึก หรือ ฝึกให้เชื่องได้ | เจรจาหรือสงบสัตว์สำเร็จ | ไม่ได้ของรางวัลจากการฆ่า แต่ได้ `karma` ชื่อเสียงคนละแบบ อาจได้พันธมิตรหรือสัตว์คู่หู |
| หนีรอด | หนีสำเร็จ | ไม่ได้ ไม่เสีย (ยกเว้นความเสียหายที่ได้มาก่อนหน้า) |
| เสมอ | ครบจังหวะสูงสุด | ศัตรูถอย อาจกลับมาเป็นศัตรูประจำ (`rel:+nemesis` ถ้าเป็น NPC) |
| แพ้ | hp เหลือน้อยหรือถอยหนีไม่สำเร็จ | ทอยบาดแผลถาวร อาจถูกจับ ถูกปล้น หรือได้คำสาปจากศัตรู |
| ตาย | hp ≤ 0 | กติกาความตายเดิม (`b_laststand` `#rewind` `#guardian_angel`) และหน้าต่างพระเจ้าครั้งสุดท้าย |

## 8. พระเจ้าแทรกแซงการต่อสู้

| ช่วง | สิ่งที่พระเจ้าทำได้ (MVP) | ผล |
| --- | --- | --- |
| ก่อนสู้ | ส่งความฝัน (ของเดิม) หรือคำใบ้ | ตัวละครรู้จุดอ่อนของศัตรู · ท่าทีที่ตรงความฝัน ×3 |
| ก่อนสู้ | ให้พร skill หรืออาวุธ (ของเดิม) | โบนัสในการต่อสู้ทันที |
| ระหว่างสู้ (ตัวละครสวดภาวนาสำเร็จ หรือ hp ต่ำกว่า 30%) | ตอบคำอธิษฐาน (ของเดิม `heal` `courage`) | ฟื้น hp หรือได้โบนัส +2 จังหวะที่เหลือ |
| ระหว่างสู้ | สาปศัตรู (ใช้กลุ่มความกลัว dread) | ศัตรู DC −2 |
| หลังสู้ | ชุบชีวิต (ของเดิม) | ตามต้นทุนเดิม |
| MVP2 | เสกของ เสกเหตุการณ์ เช่น ฟ้าผ่า อุกกาบาต ลงกลางสนามรบ | ใช้ปาฏิหาริย์เดิมในระดับประเทศ แต่ผูกกับการต่อสู้หนึ่งครั้ง |

ทุกการแทรกแซงที่สำเร็จเพิ่มศรัทธา (`faith`) เมื่อตัวละครรู้ว่าพระเจ้าช่วย และเพิ่มความกลัว (`dread`) เมื่อศัตรูถูกลงโทษ ตามระบบเดิม
