## ความต่างจากโค้ดปัจจุบัน

| เรื่อง | โค้ดปัจจุบัน | ระบบในเอกสาร |
| --- | --- | --- |
| จำนวนการทอย | ครั้งเดียวต่อการต่อสู้ | หลายจังหวะตามแผลของศัตรู (ฝูง หัวหน้า บอส ตำนาน) |
| ท่าที | ชักอาวุธ ร่ายเวท สื่อสาร หนี | เพิ่มยิงระยะไกล ตั้งรับ เจรจา หลอกล่อ สวดภาวนา |
| การแพ้ทาง | แท็กจุดอ่อน +4 · ทน DC +2 | ตาราง 14 ชนิด ★ +6 · ▲ +4 · ▼ −4 · ✕ ใช้ไม่ได้ |
| skill | เพิ่มค่าสถานะเท่านั้น | ระดับ skill ของท่าทีเพิ่มโบนัสโดยตรง (+1 +2 +4) |
| สัตว์คู่หู พวกพ้อง | ไม่มี | เพิ่มโบนัสและลดความเสียหาย |
| ศัตรู | มอนสเตอร์ 32 ตัว สุ่มตามภูมิอากาศ | มอนสเตอร์ 72 · NPC · บอส ผูกกับทวีปและธงโลก |
| ผลการแพ้ | เสีย hp | เพิ่มบาดแผลถาวร คำสาปจากศัตรู ถูกจับ |
| รางวัล | เงิน ชื่อเสียง บางตัวได้ skill หรือคำสาป | ตารางสุ่มตามระดับ วัสดุ อาวุธ พร คำสาป ฉายา |
| มังกร | มังกรเพลิงและมังกรน้ำแข็งเป็นมอนสเตอร์ | แยกมังกรป่ากับมังกรสิบห้า การฆ่ามังกรสิบห้าเปลี่ยนโลก |
| พระเจ้า | ให้พร อาวุธ ความฝัน รักษา | ผูกกับช่วงการต่อสู้ และหน้าต่างเมื่อตัวละครสวดภาวนา |

## ลำดับการทำในโค้ด (เสนอ)

1. เพิ่มชนิดศัตรูและตารางการแพ้ทางในข้อมูลมอนสเตอร์ (`MONSTERS`) โดยแปลงช่อง `weak` `resist` เดิมเป็นระดับ ★ ▲ ▼ ✕
2. เปลี่ยน `buildMonster` ให้สร้างการต่อสู้หลายจังหวะ ยังใช้ `checkBonus` และการทอยเดิม แค่วนตามจำนวนแผล
3. เพิ่มโบนัส skill สัตว์คู่หู และพวกพ้องเข้า `checkBonus`
4. เพิ่มตารางรางวัลและบาดแผลถาวรหลังการต่อสู้
5. เพิ่มเหตุการณ์บุกหมู่บ้านและปะทะ NPC
6. แยกมังกรป่ากับมังกรสิบห้า

ตัวเลขทั้งหมดในเอกสารเป็นค่าเริ่มต้น ต้องทดสอบความสมดุลด้วยการจำลอง (`npm run sim` มีอยู่ในโปรเจกต์) ก่อนใช้จริง
