# เหตุการณ์ท้องถิ่นรายประเทศ (สร้างอัตโนมัติ)

สร้างด้วย `node scripts/docs/build-local-events.mjs` ห้ามแก้ด้วยมือ ถ้าต้องการเปลี่ยนเหตุการณ์ของประเทศใด ให้เขียนแถวมือ (`LC-` สองหลัก) ใน [../systems/events/local-events.md](../systems/events/local-events.md) ที่ระบุประเทศนั้น แถวที่สร้างของประเทศนั้นจะหายไปเอง

ทุกแถวมาจากแม่แบบ LT-1 ถึง LT-6 ในไฟล์นั้น เลือกแม่แบบจากบริบทของประเทศ ([../appearance/countries/11-context-and-landmarks.md](../appearance/countries/11-context-and-landmarks.md)) แล้วใส่ NPC ของประเทศตามบทบาท และ NPC ตัวที่ 1 ของประเทศที่เกี่ยวข้องในช่อง ความสัมพันธ์ เพื่อให้เกิดจุดบรรจบข้ามประเทศ จำนวน 61 รายการ โอกาสทุกแถว 8% ต่อทศวรรษ ปรับเมื่อทดสอบ
