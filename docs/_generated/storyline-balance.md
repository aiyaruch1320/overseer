## 2. สรุป

- NPC ที่แยกเผ่าได้ 525 จาก 608 ตัว มนุษย์ 204 (34%) อีก 83 ตัวเป็นเผ่าย่อยที่ไม่ได้จัดกลุ่ม (ชาวหมอก ชาวพื้น ฯลฯ)
- ประเทศ 143 แห่ง ระบุ "ทุกเผ่า" 8 แห่ง ประเทศที่ระบุมนุษย์ 86 แห่ง (60%)
- จุดบรรจบที่เข้าได้เฉลี่ย: มนุษย์ 11 · เผ่าอื่นเฉลี่ย 3.2
- NPC ต่างเผ่าที่โหนดอ้างเฉลี่ยของเผ่าที่ไม่ใช่มนุษย์: 3.3 → 3.8 (รวมโหนด xc)
- ทวีปที่โหนดกล่าวถึงเฉลี่ยของเผ่าที่ไม่ใช่มนุษย์: 1.6 → 2.5 (รวมโหนด xc)

## 3. อ่านอย่างไร

- มนุษย์เป็นตัวเอกเมื่อทุกช่องของมนุษย์สูงกว่าเผ่าอื่นหลายเท่า ช่องที่ควรปรับก่อนคือ "จุดบรรจบที่เข้าได้" และ "NPC ของเผ่า"
- ต้องการให้เผ่าอื่นอย่างน้อย 3 NPC ต่างเผ่าต่อชีวิตตาม [../systems/travel/01-travel-rules.md](../systems/travel/01-travel-rules.md) หัวข้อ 5
