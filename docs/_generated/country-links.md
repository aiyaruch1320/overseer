# การเชื่อมของแต่ละประเทศกับตัวละครหลัก (สร้างอัตโนมัติ)

สร้างด้วย `node scripts/docs/build-country-links.mjs` ห้ามแก้ด้วยมือ ตอบสองคำถาม: (1) ตัวละครหลักไปถึงประเทศนี้ได้ทางไหน (2) ไฟล์ประเทศ NPC และเหตุการณ์ขัดกันตรงไหน

ทางที่ตัวละครหลักไปถึงประเทศได้: **เกิด** (ตารางถิ่นเกิดใน [../systems/character/01-origin.md](../systems/character/01-origin.md) หัวข้อ 3) · **โหนดเส้นเรื่อง** ที่ระบุรหัสประเทศ · **เส้นเดินทาง** ใน [../lore/storylines/25-journeys.md](../lore/storylines/25-journeys.md) · **เหตุการณ์โลก** และ **เหตุการณ์ท้องถิ่น** ที่ระบุประเทศ (ตัวละครที่อยู่ในประเทศในปีนั้นเข้าร่วมได้)

## 1. สรุป

- ประเทศ 143 แห่ง เกิดได้โดยกำหนด (ถิ่นหลักหรือพลัดถิ่นในตารางถิ่นเกิด หรือช่อง เผ่า ของประเทศระบุเผ่านั้น) 141 แห่ง ไม่มีเผ่าใดเกิดที่นั่นเลย 2 แห่ง
- มีโหนดเส้นเรื่องระบุรหัสประเทศ 81 แห่ง ไม่มีโหนดใดระบุ 62 แห่ง
- ตัวละครหลักไปถึงได้ด้วยทางใดทางหนึ่งข้างต้นไม่ได้เลย (ไม่เกิด ไม่มีโหนด ไม่มีเส้นเดินทาง) 0 แห่ง ซึ่งถึงได้เพียงโดยเหตุการณ์หรือการเดินทางสุ่มตามกติกา [../systems/travel/01-travel-rules.md](../systems/travel/01-travel-rules.md)
- ความสัมพันธ์ที่สองไฟล์ขัดกัน 0 คู่ · NPC ที่เผ่าไม่อยู่ในช่อง เผ่า ของประเทศ 5 ตัว · NPC ข้ามทวีปในเหตุการณ์ท้องถิ่นเขียนมือที่ไม่มีความสัมพันธ์รองรับ 0 รายการ

### 2.2 NPC ที่เผ่าไม่ตรงช่อง เผ่า ของประเทศ

ช่อง เผ่า เป็นข้อความอิสระ รายการนี้ใช้ตรวจว่าควรเพิ่มเผ่าในไฟล์ประเทศหรือแก้ NPC
