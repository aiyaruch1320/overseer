# ความครอบคลุมของเหตุการณ์ต่อประเทศและ NPC (สร้างอัตโนมัติ)

สร้างด้วย `node scripts/docs/build-event-coverage.mjs` ห้ามแก้ด้วยมือ ใช้หาประเทศและ NPC ที่ยังไม่ผูกกับเหตุการณ์หรือ NPC อื่น เพื่อเพิ่มจุดบรรจบของ NPC

ที่มา: เหตุการณ์ที่ระบุรหัสประเทศในแถวของตนใน `systems/events/` (ระบุด้วยรหัสหรือชื่อประเทศ เหตุการณ์ที่เขียนเพียงชื่อทวีปไม่นับ) และรหัสเหตุการณ์ รหัส NPC ที่ปรากฏในแถว NPC ใน `lore/npcs/` ความเชื่อมระหว่าง NPC นับสองทาง (A อ้างถึง B ถือว่า B เชื่อมกับ A)
