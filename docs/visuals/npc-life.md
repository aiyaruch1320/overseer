# ชีวิตประจำวันของ NPC ในเมือง

ผู้คนในเมืองไม่ได้เดินสุ่ม ทุกคนมีบ้าน มีอาชีพที่ผูกกับอาคารจริง มีนาฬิกาของวัน และมีความต้องการที่ส่งให้ไปอาคารอื่น เข้าอาคารได้จริง (เดินไปที่ประตู หายเข้าไปข้างใน หน้าต่างสว่างตอนค่ำ แล้วเดินออกมา) โค้ดทั้งหมดอยู่ที่ `src/scenes/routine.ts` ส่วน `CityScene.ts` ทำหน้าที่เป็นเวทีและเรียก `routine.think(p)` เมื่อใครว่าง

เอกสารที่เกี่ยวข้อง: ภาพตัวละคร [README.md](README.md) · อาชีพและเทศกาล `src/data/npclife.ts`

## วันหนึ่งของเมือง

หนึ่งวันในเมืองยาว 150 วินาที (`DAY_LEN`) แบ่งเป็นช่วง

| ช่วง | ส่วนของวัน | เวลาในเมือง | คนส่วนใหญ่ทำอะไร |
| --- | --- | --- | --- |
| รุ่งเช้า (dawn) | 0.02–0.08 | 06:00 | ตื่น ทยอยออกจากบ้านไปทำงาน |
| เช้า (morning) | –0.38 | | ทำงาน เด็กบางคนไปเรียนที่หอสมุดหรือวิหาร |
| เที่ยง (noon) | –0.50 | | พักกินข้าว: ห่อข้าวมากินที่ที่ทำงาน ซื้อจากแผง กินที่โรงเตี๊ยม หรือกลับบ้าน (พ่อค้า ทหาร นักบวช หมอ ยังทำงานต่อบางส่วน) |
| บ่าย (afternoon) | –0.72 | | ทำงาน |
| เย็น (evening) | –0.82 | | เลิกงาน ไปโรงเตี๊ยม วิหาร กลับบ้าน เจอเพื่อนบ้าน (โรงเตี๊ยม นักบวช ขอทาน ทหารยาม นักกวี ยังทำงาน) |
| กลางคืน (night) | 0.82–1.02 | | นอนที่บ้าน (หายเข้าไป หน้าต่างสว่างก่อน) ทหารยามกะดึกหนึ่งในสามยังยืนประจำที่ |

นาฬิกาของเมืองคือ `clockOf(f)` ตอนกลางวัน 12 ชั่วโมงอยู่ในสามในสี่แรกของรอบ

## บ้านและที่ทำงาน

- **บ้าน** ทุกคนที่มีอาชีพอยู่บ้านใกล้ที่ทำงาน (บ้านที่ว่างที่สุดในห้าหลังที่ใกล้ที่สุด) เพราะเมืองกว้าง 162 × 101 ช่อง ถ้าบ้านกับงานอยู่คนละฝั่งเมือง ทั้งวันจะหมดไปกับการเดิน
- **ที่ทำงาน** แต่ละอาชีพมี "ที่" ของมัน (`TRADES[...].site`) และ "จุดยืน" (`at`): หน้าประตูอาคาร (`door`) แผงตลาด (`stall`, พ่อค้าแต่ละคนมีแผงของตัวเอง) หรือพื้นที่กลางแจ้ง (`place`: นา ท่าน้ำ ป่า สุสาน ถนน) งานกลางแจ้งเลือดพื้นที่ก่อน แล้วหาโกดัง/ตลาด/บ้านที่ใกล้ที่สุด

| อาชีพ | ที่ทำงาน | วันของเขา |
| --- | --- | --- |
| ชาวนา | นา → ยุ้งฉาง | ไถนา, ขนผลผลิตเข้ายุ้งฉาง (เข้าไปวางของข้างใน), พักใต้ร่มไม้ |
| ชาวประมง | ท่าน้ำ → ตลาด | ตกปลา (ท่าตกปลา กระตุกเมื่อปลากิน), เอาปลาไปขายที่แผง |
| ชาวเรือ | ท่าน้ำ → โกดัง | ขนสินค้าเข้าโกดัง, ซ่อมเชือก |
| ช่างตีเหล็ก | โรงตีเหล็ก | ตีเหล็กหน้าโรง (ประกายไฟ), เข้าไปดูเตา, เอาของไปขายที่ตลาด |
| ช่างไม้ | โกดัง/บ้าน | เลื่อยไสไม้, ไปซ่อมบ้านลูกค้า (เคาะประตู เข้าไป) |
| คนตัดไม้ | ป่า → โกดัง | ตัดไม้, ขนฟืน |
| คนงานเหมือง | ปากเหมือง | ลงเหมือง (เข้าไปข้างใน), ทุบหิน, ขนแร่ |
| พ่อค้า | แผงตลาด | ตะโกนขายของ (ท่าเรียกลูกค้า ยกของให้ดู), เติมของจากโกดัง |
| คนทำขนมปัง | ตลาด/ร้านค้า | นวดแป้ง, อบในร้าน, ขายขนมปังร้อน |
| เจ้าของโรงเตี๊ยม | โรงเตี๊ยม | ดูแลลูกค้าข้างใน, ยกเครื่องดื่มไปเสิร์ฟโต๊ะหน้าร้าน (ทำงานถึงดึก) |
| ทหารยาม | ค่ายทหาร/ประตูเมือง | เดินตรวจ (ประตู ลาน ค่าย), ยืนเฝ้าประตู, รายงานตัว (กะดึกยืนประจำที่) |
| นักบวช | วิหาร | ให้พรผู้คนหน้าวิหาร, ประกอบพิธีข้างใน, สวดมนต์ |
| หมอยา | โรงพยาบาล/วิหาร | รักษาคนไข้ข้างใน, ไปตรวจที่บ้านคนไข้, บดสมุนไพร |
| นักปราชญ์ | หอสมุด/หอสมาคม | ค้นคว้าข้างใน, นั่งจดบันทึก |
| นักเวท / นักเล่นแร่ | หอสมาคม | ฝึกเวทหน้าสำนัก, ศึกษาข้างใน, ต้มยา |
| นักกวี | โรงเตี๊ยม | ร้องหน้าโรงเตี๊ยม, เดินร้องในเมือง, เล่นข้างใน |
| ช่างตัดเสื้อ | ร้านค้า/บ้าน | เย็บผ้า (นั่ง), ไปส่งเสื้อ |
| คนซักผ้า | ริมน้ำ | ซักผ้า, ถือผ้ากลับบ้าน |
| นายพราน | ป่า → ตลาด | ซุ่มยิงธนู, เอาเนื้อไปขาย |
| นักผจญภัย | หอสมาคม/ค่าย | ซ้อมต่อสู้, ดูกระดานภารกิจ, ไปหาข่าวโรงเตี๊ยม |
| ขุนนาง | ศาลากลาง | เดินตรวจเมือง, ว่าราชการข้างใน, ไปดูตลาดและวิหาร |
| คนส่งสาร | ศาลากลาง/หอ | เคาะประตูบ้านส่งจดหมาย, วิ่งส่งสารไปทั่ว |
| สัปเหร่อ / คนกวาดถนน / ขอทาน / คนเลี้ยงแกะ / ผู้ฝึกสัตว์ | สุสาน ถนน ลานกลาง ทุ่ง | ขุด กวาด นั่งขอ ต้อนฝูง |

NPC ในเอกสาร (docs/npcs) ที่ประจำเมืองหลวงได้อาชีพจากตำแหน่งและชุด (`jobOfLook`): ราชากับขุนนางไปศาลากลาง นักบวชไปวิหาร แม่ทัพไปค่าย พ่อมดไปหอสมาคม

## ความต้องการและธุระ

ทุกคนมี `hunger` (หิว) `shop` (อยากซื้อของ) `piety` (ศรัทธา) `sick` (ป่วย) ที่ขึ้นลงตามเวลา แล้ว `think()` ชั่งน้ำหนักตัวเลือกของช่วงเวลานั้น ทำงานหนักที่สุดในเวลางาน ส่วนธุระอื่นแทรกเมื่อถึงเวลาหรือถึงความต้องการ

- **กิน** เที่ยงเป็นเวลากินข้าว: 30% ห่อข้าวมากินที่ที่ทำงาน, โรงเตี๊ยม, ซื้อจากแผง (ยืนกิน), หรือกลับบ้าน ทุกธุระมีระยะทางสูงสุด ไกลเกินไปก็เลือกอย่างอื่น
- **ซื้อของ** เดินไปแผงที่มีพ่อค้ากำลังขายอยู่ เจรจา (ท่าคุย ไอคอนเหรียญ พ่อค้าตอบ) แล้วบางคนถือของกลับบ้าน
- **ศรัทธา** เช้ากับเย็นไปวิหาร: เข้าไปข้างใน หรือคุกเข่าหน้าวิหาร (มีแสงรัศมี) คนศรัทธามากและผู้เฒ่าไปบ่อย
- **ป่วย** ดินแดนที่มีโรคระบาดมีคนป่วย 22% ไอ แล้วไปรักษาที่โรงพยาบาลหรือวิหาร (มีหมออยู่ข้างใน)
- **สังสรรค์** ตอนเย็นไปโรงเตี๊ยม เข้าไปข้างในนาน ๆ หรือยืนคุยกับเพื่อนบ้านหน้าบ้าน
- **เด็ก** เช้าไปเรียนหนังสือ (หอสมุดหรือวิหารที่ใกล้ที่สุด) บ่ายวิ่งเล่นแถวบ้าน เที่ยงกลับไปกินข้าว
- **ผู้เฒ่า** นั่งพัก ไปวิหาร เดินช้า
- **สภาพอากาศ** ฝน พายุ หิมะ พายุทราย: คนทำงานกลางแจ้งหลบเข้าอาคาร (ทหารยาม นักบวช หมอยังทำงาน)
- **ภัยพิบัติ** วิ่งหนีเข้าอาคารที่ใกล้ที่สุด
- **เทศกาล** บางคนไปเต้นรำที่ลานกลาง

## การเข้าอาคาร

`enter(p, venue, secs, doing)` เดินไปประตู หันหลังให้กล้อง จางหาย อยู่ข้างในตามเวลา แล้ว `leave(p)` ออกมาที่ประตู ระหว่างนั้นบุคคลไม่ถูกเลือกเป็นเป้าหมายเหตุการณ์ในเมือง ตัวละครของผู้เล่นไม่หายเข้าไป แค่ไปยืนที่หน้าประตู

- ตอนค่ำ อาคารที่มีคนอยู่ข้างในสว่างก่อนอาคารว่าง (หน้าต่างสว่าง)
- คนที่อยู่ข้างในเลยเวลา (โรงเตี๊ยมตอนดึก) จะถูกไล่ให้ออกกลับบ้าน
- เลื่อนเมาส์ไปบนอาคาร: ชื่ออาคาร คนทำงานที่นั่น หรือผู้อยู่อาศัย และมีคนอยู่ข้างในกี่คน
- เลื่อนเมาส์ไปบนคน: ชื่อ เผ่า อาชีพ ที่ทำงาน และ "ตอนนี้: …" บอกว่ากำลังทำอะไรอยู่ เช่น "ตีเหล็กหน้าโรงตี · โรงตีเหล็ก"

## ท่าทางประจำอาชีพ

`pose.ts` มี 22 ท่าใหม่ (ลำดับ 33 ถึง 54): กวาด (2) นวดแป้ง/คน (2) ตกปลา (2) ดื่ม ให้พร (2) ตะโกนขาย (2) เย็บผ้า (2) เขียน เคาะประตู (2) โค้ง กิน (2) ไอ ยิงธนู ยืนตรงเฝ้ายาม รวมกับท่าเดิมที่มี (ตี ขุด ตัดไม้ ร่ายเวท นั่งอ่าน คุกเข่า ฉลอง) ตาราง `ACT` ใน `routine.ts` จับคู่กิจกรรมกับท่า เอฟเฟกต์ (ประกายไฟ ฝุ่น ไอน้ำ ละอองน้ำ รัศมี โน้ต) และจังหวะ ไม้กวาดถูกแก้ให้ตั้งตรงปลายแปรงลง

ท่าทำงานทั้งหมดยังวาดหันหน้าเข้าหากล้อง (เฉพาะท่าเดินและยืนที่มีด้านข้างและด้านหลัง)

## ปรับค่าได้ที่ไหน

| อยากปรับ | ที่ |
| --- | --- |
| ตารางงานของอาชีพ น้ำหนัก ข้อความ | `TRADES` |
| ท่าและเอฟเฟกต์ของกิจกรรม | `ACT` |
| ช่วงของวัน | `phaseOfDay` |
| ธุระ ตัวเลือก น้ำหนัก ระยะ | `Routine.think` และ `eat` `buy` `worship` `drink` |
| ตำแหน่งอาคารที่ใช้เป็นที่ทำงาน | `FN` (ประเภทอาคาร → หน้าที่) |

## ที่ยังทำต่อได้ (ข้อเสนอ)

1. **ครอบครัว** เด็กอยู่บ้านเดียวกับพ่อแม่ พ่อแม่ไปส่งลูกที่โรงเรียน พาเด็กเดินตลาด ตอนนี้ทุกคนมีบ้านตามที่ทำงาน
2. **เงินและสต็อกสินค้า** พ่อค้ามีของจริง ราคาขึ้นลงตามสินค้าที่ชาวนา ชาวประมงส่งเข้าตลาด เมืองที่ขาดอาหารอดอยากจริง
3. **ความสัมพันธ์** เพื่อนสนิทนัดกัน คู่รักเดินด้วยกัน ศัตรูหลบหน้ากัน สร้างจากความสัมพันธ์ใน `g.s.npcs`
4. **อาคารเปิดให้ดูข้างใน** คลิกอาคารเปิดหน้าตัดเห็นคนข้างใน
5. **งานตามฤดู** เกี่ยวข้าวฤดูใบไม้ร่วง ตกปลาน้ำแข็งหน้าหนาว ตลาดนัดวันตลาด
6. **ศพและงานศพ** สัปเหร่อทำพิธี ขบวนไปสุสาน
7. **ตัวละครผู้เล่นร่วมงาน** ตัวละครของผู้เล่นฝึกงานกับช่างในเมือง ได้ฝีมือจากการอยู่ในวงชีวิตเหล่านี้
8. **อาชญากรรม** โจรล้วงกระเป๋าที่ตลาด ทหารยามไล่จับ ขึ้นศาล
