# การค้า การส่งของ และการคุ้มกัน

ระบบ: [README.md](README.md) · เศรษฐกิจโลก: [01-world-economy.md](01-world-economy.md) · รายได้: [04-income-and-living.md](04-income-and-living.md) · ลงทุน: [06-investment.md](06-investment.md) · ศัตรู: [../combat/03-enemies.md](../combat/03-enemies.md) · อาชีพ: [../character/09-jobs-common.md](../character/09-jobs-common.md)

ประเทศที่จนมากไม่ได้มีทางเดียวคือเก็บเงินทีละเหรียญ ส่วนต่างของราคาระหว่างประเทศ ([01-world-economy.md](01-world-economy.md) หัวข้อ 3) คือเหตุผลที่คนออกเดินทาง ตัวละครหาทองได้จากห้าทางที่ผูกกับเรื่องราว: ค้าขายเอง รับจ้างส่งของ คุ้มกัน ล่าวัสดุไปขาย และลักลอบ

## 1. ห้าทางหาทอง

| ทาง | ใช้อะไร | ความเสี่ยง | เรื่องที่เปิด |
| --- | --- | --- | --- |
| ค้าขายเอง | ทุนซื้อสินค้า พาหนะ ความรู้เส้นทาง | โจร ภาษีผ่านทาง ราคาเปลี่ยน | ขบวนคาราวาน พ่อค้าคู่แข่ง สงครามเส้นทาง |
| รับจ้างส่งของ | ความไว้ใจ ความเร็ว | ของหาย ล่าช้า ถูกดัก | ผู้ว่า NPC ของลับ เครื่องรางโบราณระหว่างทาง |
| คุ้มกัน | ฝีมือสู้ ชื่อเสียง | ศึกจริง | ขบวนใหญ่ ผู้จ้างที่ซ่อนความลับ |
| ล่าวัสดุไปขาย | ฝีมือสู้ ความรู้ว่าใครซื้อ | ศึก ศัตรูแรง | ล่ามังกรป่า ลงซาก ตลาดมืด |
| ลักลอบ | ความลับ เส้นทางที่ไม่มีใครรู้ | ถูกจับ `c_wanted` | ตลาดมืด ปิดทวีป (PO-06) |

## 2. การต่อรอง

ทุกการซื้อขายระหว่างตัวละคร NPC และพ่อค้าต่อรองได้ครั้งเดียวต่อรายการต่อฤดู (ถ้าล้มเหลว ผู้ขายไม่ให้ต่อรองซ้ำในฤดูนั้น)

```
ทอย d20 + โบนัสต่อรอง ≥ DC ของฝ่ายตรงข้าม
โบนัสต่อรอง = (int − 10) ÷ 2 + ระดับ ns_haggle × 2 + ระดับ trade + ความไว้ใจ ÷ 2 + ชื่อเสียง ÷ 20
DC = 10 + นิสัยฝ่ายตรงข้าม + สภาพตลาด
```

| ส่วนของ DC | ค่า |
| --- | --- |
| นิสัยฝ่ายตรงข้าม | `greedy` +3 · `cunning` +2 · พ่อค้าอาชีพ +2 · `generous` −2 · `kind` −1 · `gullible` −3 |
| สภาพตลาด | สินค้าขาดแคลนในถิ่น (ผู้ขายได้เปรียบเมื่อตัวละครซื้อ) +2 · ล้นตลาด −2 |
| ความสัมพันธ์ | ไว้ใจ +3 ขึ้นไป −2 · แค้น +1 ขึ้นไป +3 |

| ผลเทียบ DC | ราคาที่ได้ |
| --- | --- |
| ทอย 20 หรือเกิน DC อย่างน้อย +10 | ดีกว่าปกติ 25% (ซื้อถูกลง ขายแพงขึ้น) |
| เกิน DC +5 ถึง +9 | ดีกว่าปกติ 15% |
| ผ่าน DC ถึง +4 | ดีกว่าปกติ 7% |
| พลาดไม่เกิน −4 | ราคาปกติ ต่อรองไม่ได้อีกในฤดูนี้ |
| พลาดเกิน −5 หรือทอย 1 | แย่กว่าปกติ 10% และความไว้ใจ −1 (ผู้ขายรู้สึกถูกดูหมิ่น) |

**ชนิดของคู่ค้า** (มีผลต่อกติกาและเรื่องราว)

| ชนิด | กติกา |
| --- | --- |
| พ่อค้าประจำร้าน | ราคาเดียวทุกคน DC +2 ตัวละครที่ขายสม่ำเสมอได้ลูกค้าประจำ (ราคา −5% หลังซื้อห้าครั้ง) |
| ขุนนางและผู้มั่งคั่ง | ไม่ต่อรอง จ่ายเกินราคา 10% ถ้าไม่ต่อรอง และต่อรองถือเป็นการเสียหน้า (ไว้ใจ −1) |
| ชาวบ้านยากจน | ต่อรองได้ แต่ขายของให้ได้เพียงราคา ×0.7 ของตลาด |
| ผู้ค้าตลาดมืด | DC +3 ราคาเป็นของเถื่อน ถ้าเอาเปรียบเกินไปถูกหักหลัง (`c_betrayal` 15%) |
| นักสะสม | จ่ายเกินราคา 30% ถ้าของมีเรื่อง (ประวัติอาวุธ เครื่องรางโบราณ) ต่อรองไม่ได้ |
| NPC ที่ติดบุญคุณ | ไม่ต่อรอง ขายให้ในราคาที่ได้เปรียบตามที่เขียนใน NPC |

ผู้ที่ไม่ต่อรองและยอมรับราคาเสนอทุกครั้งสิบครั้งติด ได้ชื่อว่า "ผู้ไม่ต่อรอง" ไว้ใจ +1 กับคู่ค้าประจำ

## 3. ค้าขายเอง

**ความจุ** ตามพาหนะ

| พาหนะ | หน่วยการค้า | หมายเหตุ |
| --- | --- | --- |
| เดินเท้า | 3 | |
| ล่อหรือม้า | 8 | ต้องซื้อ 30 ถึง 120 |
| เกวียน | 20 | ต้องมีถนนหรือทางเรียบ |
| ขบวนคาราวาน | 40 ขึ้นไป | ต้องมีผู้นำขบวน (`caravan_master`) และผู้คุ้มกัน |
| เรือ | 100 ขึ้นไป | ต้องมีเรือ (`shipowner`) |

**กำไรต่อเที่ยว**

```
กำไร = (ราคาขายปลายทาง − ราคาซื้อต้นทาง) × หน่วย − ต้นทุนขนส่ง − ภาษีผ่านทาง − ค่าคุ้มกัน − ของที่เสียหาย
```

ต้นทุนขนส่งและความเสี่ยงตามหัวข้อ 4 ของ [01-world-economy.md](01-world-economy.md) เหตุการณ์ระหว่างเที่ยว: ทอยตามความเสี่ยงของเส้นทางหนึ่งครั้งต่อ 10 วันเดินทาง

| ความเสี่ยงเส้นทาง | โอกาสเหตุการณ์ | ศัตรูหรือภัยที่เจอ |
| --- | --- | --- |
| ต่ำ | 10% | `wolf` `npc_bandit` เล็ก |
| กลาง | 25% | `npc_bandit` ฝูง `npc_smuggler` `goblin` |
| สูง | 40% | `npc_pirate` `ghost_crew` `sand_raiders` `storm_harpy` |
| สูงมาก | 60% | `fog_tentacle` `fog_moth_swarm` `shadow_pack` `mirage_phantom` |

**ตัวอย่างเที่ยวค้า** (ค่าเริ่มต้น ตัวเลขทองกลาง)

| เส้นทาง | ซื้อที่ | ขายที่ | กำไรต่อหน่วยก่อนหัก | หมายเหตุ |
| --- | --- | --- | --- | --- |
| ข้าวจาก AL-17 ไป MH-05 | 7.2 (ส่งออก W 5) | 12.0 (ขาด W 3) | 4.8 | หักขนส่งบก 10% (0.8) เหลือ 4.0 ขบวน 20 หน่วย ได้ 80 |
| ข้าวจาก AL-17 ไป MH-03 ช่วง WR-03 | 7.2 | 16.8 (ขาด W 1 ×2 สงคราม) | 9.6 | หักขนส่ง 0.8 เหลือ 8.8 ขบวน 20 หน่วย ได้ 176 ก่อนหักโจรและค่าคุ้มกัน |
| ไม้และขนจาก KD-12 ไป AL-04 | 4.6 (ส่งออก W 2) | 13.5 (ผลิตพอใช้ W 5) | 8.9 | ส่วนต่างใหญ่เพราะส่งออกจากประเทศจนไปประเทศรวย หักขนส่ง 0.9 ขบวน 20 หน่วย ได้ 160 |
| น้ำเลี้ยงจาก SV-15 ไป MK-01 | 43.2 (ส่งออก W 4) | 90 (ปกติ W 5) · 270 (ช่วง WR-04 ×3) | 46.8 ถึง 226.8 | ผิดกฎปันส่วน PO-04 ลักลอบ (`c_wanted`) |

## 4. รับจ้างส่งของ

NPC ผู้ว่า (พ่อค้า สถาบัน ตระกูล) จ้างตัวละครส่งของ ผู้ที่มีอาชีพ `courier` `caravan_guard` `merchant` `smuggler` `guide` `explorer` ได้งานมากขึ้น ×2

| ชนิดงาน | ของที่ส่ง | ค่าจ้าง |
| --- | --- | --- |
| พัสดุเล็ก | จดหมาย ของมีค่าเล็ก | ฐาน |
| สินค้าเปราะบางหรือเสี่ยง | ยา ของวิเศษ อัญมณี ไข่ | ×1.5 |
| ส่งคน | ผู้ลี้ภัย ตัวประกัน ผู้แสวงบุญ | ×1.5 และผูกกับความเป็นอยู่ของคนนั้น |
| ของลับ | จดหมายลับ ของต้องห้าม | ×2 และเสี่ยง `c_wanted` |

**ค่าจ้างฐาน** ตามระยะ

| ระยะ | ค่าจ้างฐาน (ทอง) |
| --- | --- |
| ในประเทศ | 15 |
| ข้ามประเทศในทวีป | 40 |
| ข้ามทวีปทางบก | 90 |
| ข้ามทะเล | 140 |
| ผ่านทะเลทรายหรือหมอก | 220 |

ตัวคูณมูลค่าของ: ต่ำกว่า 100 ×1 · 100 ถึง 500 ×1.5 · เกิน 500 ×2.5 คูณความเสี่ยง: ต่ำ ×1 · กลาง ×1.3 · สูง ×1.7 · สูงมาก ×2.2 และรับ **มัดจำ** 20% ของมูลค่าของ (ผู้ว่าเก็บคืนเมื่อสำเร็จ ไม่คืนถ้าของหาย)

| ผลของงาน | ผล |
| --- | --- |
| ส่งถึงตรงเวลา | ค่าจ้างเต็ม ไว้ใจผู้ว่า +1 (ถึงสามครั้งได้ลูกค้าประจำ) |
| ล่าช้าไม่เกิน 10 วัน | ค่าจ้าง −20% |
| ของหายหรือถูกยึด | เสียมัดจำ ผู้ว่าแค้น +1 |
| ส่งสำเร็จด้วยการทำศึก | โบนัสศึก (ชื่อเสียง + ส่วนแบ่ง 10% ของมูลค่า) |
| เปิดดูของ (ของลับ) | ความไว้ใจ −3 แต่ได้ความลับ (เส้นเรื่อง NPC) |

ผู้ถือเครื่องรางโบราณขณะส่งของ ใช้กติกา "การพบเครื่องราง" ได้ทุกเที่ยวที่ผ่านซาก ([../items/15-talisman-stories.md](../items/15-talisman-stories.md) หัวข้อ 8)

## 5. คุ้มกัน

| ฝ่าย | รายได้ |
| --- | --- |
| ผู้คุ้มกันขบวนเล็ก (เกวียน 2 ถึง 4 คัน) | วันละ 3 ถึง 5 + ส่วนแบ่ง 3% ของกำไร |
| ผู้คุ้มกันขบวนใหญ่ (คาราวาน 40 หน่วยขึ้นไป) | วันละ 6 ถึง 10 + ส่วนแบ่ง 5% |
| หัวหน้าผู้คุ้มกัน (`caravan_guard` ที่มีชื่อเสียง ≥ 15) | วันละ 12 + ส่วนแบ่ง 10% |
| คุ้มกันเรือ | เที่ยวละ 40 ถึง 120 ตามระยะ |
| คุ้มกันบุคคลสำคัญ (ผู้แทนสภา ตัวประกัน) | เหมาตามงาน 100 ถึง 400 |

เหตุการณ์ซุ่มโจมตีใช้ระบบต่อสู้ ([../combat/04-encounters.md](../combat/04-encounters.md)) ขบวนใหญ่เจอศึกฝูงมากกว่า ผู้คุ้มกันชนะได้ชื่อเสียงและเรื่องราวกับผู้ว่า แพ้ ผู้ว่าเสียสินค้าและไม่จ้างอีก (`nc_betrayed_trust` 10% ถ้าผู้คุ้มกันหนีก่อน)

ทักษะ `ns_guard_post` ลดโอกาสถูกซุ่ม ([../character/07-new-skills.md](../character/07-new-skills.md) หัวข้อ ช)

## 7. ลักลอบ

ผู้ที่ทำอาชีพเหล่านี้ได้ผล: `broker` ต่อรอง +2 · `appraiser` เห็นมูลค่าจริงของของทุกชิ้น (ไม่ถูกหลอกราคา) · `guide` ลดความเสี่ยงเส้นทางหนึ่งระดับสำหรับขบวนที่นำ · `caravan_master` ขบวนใหญ่ได้ความจุ +50%

## 9. NPC ผู้ค้า

NPC ค้าขายด้วยสูตรเดียวกัน ขบวนคาราวานของ NPC เดินเส้นทางตามตาราง และเป็นสาเหตุที่ราคาระหว่างประเทศเข้าใกล้กัน ([01-world-economy.md](01-world-economy.md) หัวข้อ 3) ขบวนถูกโจมตีเมื่อเส้นทางเสี่ยงสูง ถ้าถูกโจมตีหลายขบวน ราคาปลายทางสูงขึ้นสองฤดู NPC ที่ผูกกับการค้า (NR01-2 อิซาเบลลา วอสส์ AL10-1 จูเซปเป้ มาร์เชลโล AL10-3 ฟรานเชสก้า SH04-2 ไซด์ KD09-3 ออบซาร์ MH09-3 เซน่า AL17-3 มาร์ติน) ว่าจ้างตัวละครได้
