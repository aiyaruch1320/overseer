# การนำเศรษฐกิจลงเกม

ระบบ: [README.md](README.md) · เศรษฐกิจโลก: [01-world-economy.md](01-world-economy.md) · รายงานการตรวจ: [09-audit.md](09-audit.md) · ทายาท: [../heirs/README.md](../heirs/README.md)

ไฟล์นี้บอกว่าระบบเศรษฐกิจสร้างได้จริงหรือไม่ ต้องแก้โค้ดตรงไหน ต้องทดสอบอะไร และเสี่ยงอะไร ข้อมูลเกี่ยวกับโค้ดตรวจจากไฟล์ใน `src/` ขณะเขียน (ชุด demo ปัจจุบัน) ที่ไม่ได้ตรวจใช้คำว่า "สันนิษฐาน"

## 1. โค้ดมีอะไรอยู่แล้ว

| ส่วน | ที่อยู่ | สภาพ |
| --- | --- | --- |
| ทองของตัวละคร | `Character.gold` ใน `src/sim/types.ts` | ตัวเลขเดียว ค่าเริ่มต้น 0 ถึง 15 (`createCharacter`) |
| ที่มาของทอง | ผลของเหตุการณ์ (`gold±N` ใน `applyOutcome`) · ยุคทองของประเทศ +20 · พร `gold_luck` ×1.5 ของทองที่ได้ | ไม่พบรายได้อาชีพรายปี ร้านค้า ราคา ค่าครองชีพ หรือภาษี |
| ประเทศ | `Country` มี `flags` (`war` `plague` `famine` `golden` `fallen`) ระดับอันตราย การปกครอง เผ่า และเมือง | ไม่มีค่าความรวย การใช้เงิน หรือสินค้า |
| ความรวยฝั่งภาพ | `wealthOf` และ `flavorOf` ใน `src/city/flavor.ts` | คำนวณจากคำสำคัญในเอกสาร ค่าตั้งต้นต่อทวีป แล้วบวกลบตามจำนวนคำ ใช้วาดเมืองเท่านั้น |
| อาชีพของ NPC | `NPC_JOBS` (`src/data/npclife.ts`) ทำงานและทักษะ `spec` ต่อเมือง | ไม่มีรายได้ ใช้ในฉากเมืองและการจำลองประจำปี |
| อาชีพของตัวละคร | `JOBS` (`src/data/lore.ts`) ความถนัด สถานะหลัก ระดับ | ไม่มีช่องรายได้ |
| ทายาท | `continueAsHeir` ใน `src/sim/game.ts` | ส่งต่อทอง 70% ชื่อเสียง 1 ใน 3 ศรัทธา 60% |
| ราคาของพระเจ้า | `COSTS` ใน `src/sim/game.ts` | เป็นของระบบพระเจ้า ไม่ใช่ของเศรษฐกิจ |

## 2. สิ่งที่ต้องเพิ่ม

```ts
type GoodId = 'F' | 'M' | 'T' | 'W' | 'S' | 'H' | 'X' | 'E';

interface CountryEconomy {   // สร้างจาก docs/economy/02-countries.md
  w: 1 | 2 | 3 | 4 | 5;          // ความมั่งคั่ง (ค่าฐานของยุค 1)
  g: 'l' | 'm' | 'h' | 'x';      // ความเหลื่อมล้ำ
  m: 'f' | 'p' | 'n';            // การใช้เงิน
  exports: GoodId[];
  imports: GoodId[];
}

interface EconomyState {         // อยู่ใน GameState
  trust: number;                 // ความเชื่อมั่นทองกลาง C 0..100
  wMod: Record<string, number>;  // ตัวปรับ W ต่อประเทศจากเหตุการณ์
  price: Record<string, Record<GoodId, number>>; // ราคาปัจจุบันต่อประเทศ
}

interface Character {
  // เพิ่ม
  class: 1 | 2 | 3 | 4 | 5;      // ชนชั้นของครอบครัว (ชั้น 5 ตั้งธง noble เดิมด้วย)
  assets: Asset[];               // การลงทุน
  debts: Debt[];                 // หนี้
}
```

ข้อมูลประเทศไม่ควรเขียนมือ ให้สร้างจากเอกสารแบบเดียวกับ `scripts/gen-countries.ts` (เสนอ `scripts/gen-economy.ts` อ่านตารางในไฟล์ 02 แล้วเขียน `src/data/economy.ts`) เอกสารเป็นแหล่งข้อมูลเดียว ฝั่งภาพอ่านจากข้อมูลเดียวกัน จึงเลิกใช้ `wealthOf` ที่นับคำ

## 3. ลูปประจำปี

```
สำหรับแต่ละปี:
  1. อัปเดตความเชื่อมั่น C ตามเหตุการณ์ของปี ฟื้น +2 ถ้าไม่มีสงคราม
  2. สำหรับแต่ละประเทศ: W_eff = clamp(1..5, W_base + wMod(เหตุการณ์ ธง))
  3. สำหรับแต่ละหมวดสินค้า (8) ในแต่ละประเทศ: คำนวณผลผลิตและความต้องการ → ราคา
  4. ขบวนค้า NPC ลดส่วนต่างราคา 30% ตามเส้นทางที่เปิด (ส่วนต่างมาก = โอกาสของผู้เล่นและตัวละคร)
  5. ตัวละครหลัก: รายได้ − ค่าครองชีพ − ภาษี ± ผลลงทุน ± ดอกเบี้ย → ทอง
  6. NPC (ปรากฏอยู่): ทำสูตรเดียวกันแบบย่อ
  7. ตรวจความจน (ทอง ต่ำกว่าเกณฑ์) → สร้างเหตุการณ์ตึงมือหรือขัดสน
```

| ภาระต่อปี | จำนวน |
| --- | --- |
| ประเทศ × หมวดสินค้า | 143 × 8 = 1,144 ค่า |
| NPC ที่ปรากฏ | ประมาณ 400 ถึง 450 (ผลรวมโอกาสปรากฏ 407 ตามแผนที่ NPC) |
| ตัวละครหลัก | 1 |
| ผลรวมต่อปี | คำนวณหลักร้อยถึงพันครั้ง เป็นงานเบามาก (เกมทำหลายพันเหตุการณ์ต่อปีอยู่แล้ว) |

ความเป็นไปได้ด้านประสิทธิภาพ: ไม่เป็นปัญหา ตัวที่หนักจริงคือ `npm run sim` ที่รันหลายสิบถึงหลายร้อยชีวิต ซึ่งเพิ่มต้นทุนไม่ถึง 10% ตามสันนิษฐาน

## 4. จุดที่ต้องแก้ในโค้ด

| จุด | งาน |
| --- | --- |
| `createCharacter` | สุ่มชนชั้นตาม W G ของประเทศเกิด ตั้งทองเริ่มต้นที่อายุ 17 และระดับอาวุธเกราะตามตารางในไฟล์ชนชั้น |
| `addChild` | ใช้ตารางลูกของลูกครึ่ง ([../character/01-origin.md](../character/01-origin.md) หัวข้อ 4) และสืบชนชั้น |
| `continueAsHeir` | ภาษีมรดก ส่งต่อชนชั้นและหนี้ ตัดทองตามเพดานของประเทศ |
| `JOBS` | เพิ่มช่องระดับรายได้ หรือใช้ระดับ (`r`) อยู่แล้วคำนวณจากสูตร |
| สร้างอาวุธ | อ่านชนชั้นกับ W ตามตาราง (ปัจจุบันอาวุธสุ่มตามระดับ `RARITY` ล้วน) |
| ตลาดและร้าน | ยังไม่มี ต้องเพิ่มจุดซื้อขาย (หน้าเมือง หรือเหตุการณ์ร้านค้า) |
| เหตุการณ์ | เพิ่มตัวปรับ W และราคาตามไฟล์เศรษฐกิจโลก หัวข้อ 6 |
| การจำลอง | เพิ่ม `scripts/sim-economy.ts` วัดตัวชี้วัดในหัวข้อ 6 |
| `src/city/flavor.ts` | อ่านค่า W จาก `economy.ts` แทน `wealthOf` |

## 5. ลำดับทำ

1. **P0 ข้อมูล** สร้าง `gen-economy.ts` และ `src/data/economy.ts` จากเอกสาร ใช้ฝั่งภาพก่อน (เปลี่ยนแค่ที่มาของค่า เห็นผลเร็ว ไม่แตะกติกา)
2. **P1 ชนชั้นและของเริ่มต้น** ทองเริ่มต้นและระดับของที่ได้ตั้งแต่เกิด ยังไม่มีรายได้
3. **P2 รายได้ ค่าครองชีพ ภาษี** ใส่ตารางรายได้ตามอาชีพ รัน `sim-gold` ปรับให้มัธยฐานที่อายุ 30 อยู่ราว 250 ถึง 350
4. **P3 ราคาและร้านค้า** ตลาด ตัวคูณขาดแคลน ต่อรอง
5. **P4 งานรับจ้างส่งของและคุ้มกัน** เป็นเหตุการณ์ (storylet) ที่ผูกเส้นทางและเที่ยวค้า
6. **P5 การลงทุนและธนาคาร**
7. **P6 NPC** ให้ NPC ใช้สูตรเดียวกัน
8. **P7 ปรับสมดุล** ตามหัวข้อ 6 ก่อนปล่อยใช้

แต่ละขั้นเล่นได้เองโดยไม่ต้องรอขั้นถัดไป P0 ถึง P2 สร้างความต่างระหว่างประเทศรวยกับจนทันที

## 6. การทดสอบ

| ตัวชี้วัด | เป้าหมายเริ่มต้น | วัดอย่างไร |
| --- | --- | --- |
| ทองมัธยฐานที่อายุ 30 แยก W | W 1 ราว 220 · W 3 ราว 300 · W 5 ราว 470 (ตัวเลขในไฟล์รายได้ หัวข้อ 8) | `sim-gold` ขยายให้แยกตามประเทศเกิดและชนชั้น |
| อัตราทองเข้า ต่อ ออก ต่อชีวิต | 0.8 ถึง 1.2 (ตามแนวเกมทั่วไป ใช้เป็นแนวทาง ไม่ใช่กฎ) | รวมทุกทางเข้าและทางออก แยกชนชั้น |
| สัดส่วนที่ล้มละลาย | 5 ถึง 10% ของชีวิต | นับ `c_debt` และตกชั้น |
| สัดส่วนที่ขึ้นชั้นได้ | จากชั้น 1 ถึง 2 → 2 ถึง 3 ใน 15% ของชีวิต | นับการเปลี่ยนชั้น |
| กำไรจากการค้า | มัธยฐานต่อเที่ยวเป็นบวก แต่ไม่เกิน 40% ของรายได้ประจำปีของอาชีพ | จำลองเที่ยวค้าต่อปี |
| ความเสถียรของราคา | ราคาในประเทศเดียวกันไม่เปลี่ยนเกิน ×2 ต่อปีนอกเหตุการณ์ใหญ่ | บันทึกราคาต่อประเทศต่อปี |
| ความต่างระหว่างประเทศ | ส่วนต่างราคาข้ามชายแดนมัธยฐาน 20 ถึง 40% | เทียบหลังขบวนค้า NPC |
| การเข้าถึงของ | ตัวละครเกิดชั้น 5 ใน W 5 ได้ E 23%, ชั้น 2 ใน W 1 ได้ R < 1% | นับของเริ่มต้น |

## 7. ความเสี่ยงและวิธีลด

| เสี่ยง | ลดอย่างไร |
| --- | --- |
| ระบบซับซ้อนเกินจนผู้เล่นอ่านไม่ออก (มีเกมที่เคยทำเศรษฐกิจแบบมีเงินแล้วต้องเลิก) | ผู้เล่นเห็นแค่ 3 อย่าง: ทองของตัวละคร ชนชั้น และ "ประเทศนี้รวยหรือจน" ส่วนที่เหลือเป็นตัวแปรหลังบ้าน ไม่มีหน้าจอตลาดเต็มรูป |
| ขบวนค้า NPC ทำให้ส่วนต่างหายหมด ไม่มีกำไรค้า | ลดส่วนต่าง 30% ต่อปี ไม่ใช่ 100% และเส้นทางที่ปิดไม่ลด ตั้งค่าได้ |
| ล้นตลาด (ผู้เล่นขายของมากจนราคาตก) | ตัวละครเดียวไม่ส่งผลต่อราคาตลาดโลก เฉพาะราคาท้องถิ่นของเมืองนั้นลด 5% ต่อ 10 หน่วยที่ขายซ้ำในปีเดียวกัน |
| เงินล้น | ทางออกของชั้นสูง (ค่าครองชีพ ภาษี ซื้อยศ) และเพดานผลตอบแทน ตามไฟล์ลงทุน |
| ประเทศจนแล้วจน ไม่มีทางออก | ทางออกมีเสมอ: ผจญภัยล่าวัสดุ ส่งของ คุ้มกัน ย้ายถิ่น พึ่งผู้ช่วย ความจนไม่ทำให้ตายโดยอัตโนมัติ |
| ตัวเลขชนกับเนื้อเรื่องเดิม (ทอง +300 ในประเทศ W 1) | รางวัลจากเหตุการณ์เป็นทองกลาง คงเดิม ตัวเลขขนาดนี้เป็นรางวัลการผจญภัยไม่ใช่รายได้ปกติ |
| ทาสและการค้ามนุษย์เป็นเนื้อหาที่ละเอียดอ่อน | ทำเป็นไฟล์แยก มีจุดต่อชัดเจน (ชั้น 1 ผู้ลี้ภัย ทาสหนี้) ไม่ปนในไฟล์เศรษฐกิจ |

## 8. อ้างอิงจากเกมอื่น

ข้อมูลจากการค้นหา ไม่ใช่เอกสารออกแบบของเกมนั้น บางส่วนมาจากบล็อกหรือกระทู้ผู้เล่น

- **Mount & Blade II: Bannerlord** ราคาตั้งจากอุปสงค์อุปทานต่อหมวดสินค้าต่อเมือง ผู้ผลิตคือหมู่บ้านและโรงงาน ขบวนค้าทำให้ราคาเมืองใกล้กันเข้าหากัน การโจมตีและสงครามขัดขวางสายส่ง และถ้าผลิตมากเกินความต้องการราคาตก ([Developer Blog: Economy and Trade](https://gamebanshee.com/k4cr3) · [คู่มือเก่าและความเห็นผู้เล่น](https://naguide.com/?p=15874)) ใช้เป็นแนวคิดของไฟล์ 01 หัวข้อ 3
- **Patrician IV** แต่ละเมืองผลิตของไม่กี่ชนิดจากประมาณ 20 ชนิด ทำให้เกิดความไม่สมดุลที่พ่อค้าหากำไร การผลิตผูกกับประชากร และมีเหตุการณ์ที่เปลี่ยนราคา ([บทความ](https://www.gamingnexus.com/Article/2819/Patrician-IV) · [คู่มือ](https://www.rune-soft.com/upload/documents/Manual_PDF_Patrician4%20.pdf)) ใช้เป็นแนวคิดของสินค้า 9 หมวดและตัวปรับตามเหตุการณ์
- **Recettear** การต่อรองเป็นเกมหลักของการขาย ลูกค้าให้โอกาสต่อรองจำกัด และลูกค้าแต่ละประเภทยอมจ่ายเกินราคาต่างกัน ([รีวิว](https://www.hardcoregaming101.net/recettear-an-item-shops-tale/)) ใช้เป็นแนวคิดของการต่อรองครั้งเดียวต่อฤดูและชนิดคู่ค้า
- **หลัก faucet และ sink** ทุกทางที่เงินเข้าต้องมีทางที่เงินออก เงินล้นทำให้ของแพงขึ้น และทางออกที่ผู้เล่นอยากได้เอง (ที่ดิน ตำแหน่ง) ช่วยดึงเงินออกโดยไม่รู้สึกถูกลงโทษ ([บทความภาพรวม](https://medium.com/@msahinn21/designing-game-economies-inflation-resource-management-and-balance-fa1e6c894670)) ตัวเลขช่วง 0.8 ถึง 1.2 ในแหล่งนั้นเป็นตัวอย่าง ใช้เป็นเป้าเริ่มต้นเท่านั้น
- **Dwarf Fortress** รายงานจากผู้เล่นว่าเคยลองทำเศรษฐกิจมีเงินแล้วปิดไป ([GamesRadar](https://gamesradar.com/strategy-games-keep-giving-players-the-most-depressing-insights-into-real-world-politics-and-economics)) ข้อมูลนี้ยังไม่ได้ยืนยันกับผู้พัฒนา ใช้เป็นข้อเตือนว่าเศรษฐกิจที่ละเอียดเกินไปอาจกลายเป็นภาระ จึงจำกัดผู้เล่นให้เห็นแค่สามค่า
- **ทาสกับเศรษฐกิจ** งานวิชาการเรื่อง *The Poverty of Slavery* (Wright) เสนอว่าแรงงานบังคับดึงเศรษฐกิจโดยรวมให้ต่ำ ผลดีอยู่ที่ผู้เป็นเจ้าของ ([รายการหนังสือ](https://www.kinokuniya.co.jp/f/dsg-12-EY00154596)) ใช้เป็นข้อมูลตั้งต้นของไฟล์ทาสที่จะเขียนต่อ

ไม่พบเอกสารที่เชื่อถือได้เกี่ยวกับกลไกหนี้และชนชั้นของ Crusader Kings 3 และระบบทาสของ Kenshi จากการค้นหาครั้งนี้ จึงไม่ได้อ้างอิงสองเกมนี้
