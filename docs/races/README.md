# เผ่าพันธุ์ทั้ง 21 เผ่า

ทวีป: [../continents.md](../continents.md) · ประเทศ: [../countries/README.md](../countries/README.md) · เรื่องราว: [../story-continents.md](../story-continents.md) · เส้นเรื่องตัวละครแต่ละเผ่า: [../storylines/README.md](../storylines/README.md)

ไฟล์ละเผ่า แต่ละไฟล์มี ประวัติ ที่อยู่ สายเลือดย่อย (ถ้ามี) ความสัมพันธ์ ช่วงค่าสถานะเริ่มต้น ความสามารถประจำเผ่า พร 4 ระดับ (U, R, E, L) คำสาป 3 ข้อ สกิลเฉพาะเผ่า 4 ข้อ และเรื่องราวที่ผูกกับเรื่องหลัก รายการพร คำสาป และสกิลทั้งหมดเป็นของเฉพาะเผ่านั้น ไม่นับของพื้นฐานที่ทุกเผ่ามีร่วมกัน

## กติกาการสุ่มค่าสถานะเริ่มต้น

ทุกเผ่าใช้กติกาเดียวกัน ต่างกันที่ช่วงค่าเท่านั้น

- ค่าสถานะ 6 ค่า (กำลัง เวท เร็ว โชค ปัญญา ทน) สุ่มแยกกัน เป็นอิสระต่อกัน
- แต่ละค่าสุ่มจำนวนเต็มจากช่วง [ต่ำสุด, สูงสุด] ของเผ่านั้น ทุกค่าในช่วงมีโอกาสเท่ากัน
- ช่วงของทุกเผ่ากว้าง 5 ค่า (ค่ากลาง ±2) ยกเว้นมนุษย์ที่กว้าง 9 ค่า (ค่ากลาง ±4)
- ค่าอยู่ในขอบเขต 1 ถึง 20 ทุกเผ่า
- ค่ากลางของช่วงคือค่าเฉลี่ยของเผ่านั้น
- อายุขัยธรรมชาติสุ่มจากช่วงของเผ่าด้วยกติกาเดียวกัน (จำนวนเต็ม โอกาสเท่ากันทุกค่า) ช่วงกว้างราว ±25% ของค่ากลาง
- อายุขัยธรรมชาติคือจุดที่ร่างกายเริ่มทรุดตามธรรมชาติ ไม่ใช่เวลาตายตัว ตัวละครอาจตายก่อนหรือหลังจากนั้นได้ เหตุการณ์ โรค สงคราม พร คำสาป และอาชีพ เพิ่มหรือลดอายุได้
