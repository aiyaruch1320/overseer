# ดาร์กเอลฟ์

## ประวัติ

ดาร์กเอลฟ์คือเอลฟ์ที่ปฏิเสธคำสาบานต่อต้นไม้โลกเมื่อ ศ.ม. ประมาณ 2,800 พวกเขาเชื่อว่าเอลฟ์ผูกตัวเองกับต้นไม้จนขาดอิสรภาพ จึงเดินลงใต้สู่มอร์เฮเวน ที่ซึ่งธาตุสงครามบิดเบือนทุกสิ่งให้หิว

ผู้ที่ลงไปไม่ได้ตายแต่เปลี่ยนไป ผิวคล้ำจากเถ้า ตาไวต่อแสงน้อย เวทของจันทรากลายเป็นเวทของเงา พวกเขาสร้างนครที่อยู่ได้ท่ามกลางความอดอยากด้วยการแลกเปลี่ยนความลับ แต่เมื่อ ศ.ม. 5,900 เผ่าสงครามของมอร์เฮเวน (ซึ่งภายหลังรวมเป็นห้าธง) เริ่มกวาดล้าง จึงถูกขับออกจากแผ่นดิน

พวกเขาอพยพลงใต้พิภพของคาซ-ดูรัมและตั้งนครอิรมอร์ ใช้แสงลาวาเป็นแสงเดียว ปกครองด้วยมารดา ไม่ใช่กษัตริย์ เพราะสตรีเป็นผู้ที่ชนะสงครามถ้ำร้อนกับเผ่าลาวา

## ที่อยู่

อิรมอร์ (KD-05) · แดนไร้เงา (NB-13) · ผู้ลี้ภัยในลูไอลิส (SV-05) · ประปรายในเมืองใหญ่ทั่วโลกในฐานะนักฆ่า

## ความสัมพันธ์

พันธมิตรกับแวมไพร์ (เงาและความลับ) และเผ่าปีศาจ (สัญญา) ขัดแย้งกับเผ่าลาวา (สงครามถ้ำร้อน) ถูกเอลฟ์ตัดขาดเป็นญาติ แต่เอลฟ์จันทราบางคนยังคุยด้วยอยู่

## ความสามารถประจำเผ่า

- **ตาใต้พิภพ** มองเห็นในที่มืดสนิทชัดเจน แต่แพ้แสงจ้า (`#weak_light`)
- **เงาซ่อน** ตัวผสมกับเงาได้ง่ายกว่าเผ่าอื่น
- **ภาษาจันทรา** อ่านรหัสและสัญลักษณ์ลับโดยกำเนิด

## พรเฉพาะเผ่า

| พร | ระดับ | ผล |
| --- | --- | --- |
| ใต้ผ้าคลุมจันทรา | U | ความเร็วและการซ่อนตัวดีขึ้นในที่มืด |
| ผู้ตีราคาความลับ | R | รู้ว่าความลับใดมีค่าและควรขายให้ใคร |
| เงาที่สามารถยืนแทน | E | ส่งเงาไปแทนตัวเองเมื่อถูกโจมตีครั้งหนึ่งต่อวัน |
| ผู้เดินสองโลก | L | ผ่านระหว่างที่มืดสองแห่งในทันทีได้ ไม่ว่าจะห่างเพียงใด |

## คำสาปเฉพาะเผ่า

| คำสาป | ระดับ | ผล |
| --- | --- | --- |
| ถูกเนรเทศสองครั้ง | C | ไม่มีบ้านที่แท้จริง ความผูกพันกับที่ใดก็ตามเสื่อมเร็ว |
| ไร้เงาแท้ | U | เงาของผู้ถือบางครั้งทำสิ่งที่เจ้าตัวไม่ได้สั่ง |
| คำสัตย์ที่ถูกขาย | R | ความไว้ใจที่ได้มาถูกอีกฝ่ายนำไปขายต่อ |

## สกิลเฉพาะเผ่า

- **เดินเงา** เคลื่อนผ่านเงาไปยังเงาอื่นในระยะใกล้
- **สัญญามารดา** ผูกคำสาบานที่ไม่อาจผิดต่อผู้ที่ตอบรับ
- **ลิ้มรสพิษ** รู้จักพิษทุกชนิดโดยรสและกลิ่น
- **ตัดเส้นเสียง** ทำให้พื้นที่เงียบสนิทชั่วขณะ

## เรื่องราวที่ผูกกับเรื่องหลัก

1. อิรมอร์รู้ทางลงสู่ปากเหวที่ลึกกว่าใคร ประตูนรกเปิดเมื่อไรที่นี่ปะทะก่อน (DM-07)
2. ดาร์กเอลฟ์ในลูไอลิสรู้จากคำพยากรณ์จันทร์ว่า "คืนไม่มีเงา" จะมา (CT-07)
3. แดนไร้เงาแห่งเนบูเลียเก็บเงาที่ถูกขาย และรู้ว่าใครเป็นผู้เก็บ
