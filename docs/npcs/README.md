## 1. NPC คือเส้นเรื่องที่อาจเกิด

โลกไม่ได้มี NPC ครบ 572 ตัวเสมอไป แต่ละตัวมี **ความน่าจะเป็นปรากฏ** เมื่อโลกเริ่ม ตัวที่ไม่ปรากฏคือตำแหน่งนั้นว่างหรือมีคนอื่นอยู่แทนโดยไม่มีเรื่องราวพิเศษ เรื่องที่เล่นในแต่ละรอบจึงต่างกัน

- **ปรากฏ** ตัวเลขร้อยละในช่องสุดท้ายของทุกแถว ถ้าสุ่มไม่ผ่าน NPC นั้นไม่มีอยู่ และเส้นเรื่องทั้งหมดของเขาไม่เกิด
- **ผู้นำของประเทศ** (ตัวที่ 1 ของทุกประเทศ) ปรากฏเสมอในรูปแบบใดรูปแบบหนึ่ง ถ้าตัวนี้ไม่ปรากฏ ตำแหน่งถูกแทนด้วยผู้นำทั่วไป
- **NPC ตัวอื่นๆ** ปรากฏตามโอกาส ผู้ที่ปรากฏน้อยคือคนที่เส้นเรื่องผูกกับเงื่อนไขพิเศษ

## 2. วงจรชีวิตของ NPC

| สถานะ | ความหมาย |
| --- | --- |
| ยังไม่ปรากฏ | ยังไม่ผ่านการสุ่มปรากฏ หรือเงื่อนไขยังไม่ถึง |
| มีชีวิต | อยู่ในโลก มีเส้นเรื่องที่เดินอยู่ |
| ย้ายถิ่น | เดินทางไปประเทศอื่น ที่ยึดเปลี่ยน |
| หายสาบสูญ | ไม่รู้ชะตา เส้นเรื่องหยุด อาจโผล่กลับเป็นเหตุการณ์ |
| ตาย | เส้นเรื่องที่ยังไม่เกิดถูกตัด ผลของสิ่งที่ทำไว้ยังอยู่ |
| ขึ้นสู่ตำแหน่งใหม่ | เปลี่ยนบทบาท เปิดเส้นเรื่องชุดใหม่ (เช่น ขึ้นเป็นจอมมาร) |

ทุกฤดู NPC ที่มีชีวิตได้รับการสุ่มว่าจะเกิดอะไรกับเส้นเรื่องของตนเอง

## 3. เส้นเรื่องและการตัดเส้นที่ไม่มีทางเกิด

แต่ละแถวเขียนเส้นเรื่องเป็นทางเลือก **ก)** **ข)** **ค)** แต่ละทางมีร้อยละ ทางที่เป็นไปไม่ได้ถูกตัดทิ้ง และร้อยละที่เหลือถูกปรับสัดส่วนให้รวมกัน

**เงื่อนไขที่ตัดเส้น**
- **ที่ยึดหาย** ประเทศ ทวีป มังกร หรือสิ่งของที่เส้นเรื่องผูกไว้ไม่มีแล้ว (ตัวอย่าง: ผู้ปรนนิบัติของโอรันธาร์ที่ผูกกับโอรัน-ซัล ถ้า DR-01 เกิด เส้นเรื่อง "ประกาศยกเลิกสังเวย" ถูกตัด เพราะไม่มีการสังเวยให้ยกเลิก)
- **คนที่เกี่ยวข้องตาย** เส้นเรื่องที่ต้องมีอีกคนเป็นคู่ถูกตัดเมื่ออีกคนตาย หรือเปลี่ยนเป็นเส้นเรื่องการแก้แค้น
- **ธงโลก** ฟ้าร่วง เถ้าตก น้ำกลืน ฯลฯ เปิดหรือปิดเส้นเรื่อง
- **ตัวละครหลักก้าวก่าย** ถ้าตัวละครหลักทำสิ่งที่ตัดผล (เช่น ฆ่าผู้ทรยศก่อน) เส้นเรื่องของผู้ทรยศหายและเส้นของคนที่เกี่ยวข้องถูกเปลี่ยน

**เส้นเรื่องสืบทอด** เมื่อเส้นเรื่องหนึ่งถูกตัด ต้องมีเส้นเรื่องที่ตามมาเสมอ (แก้แค้น ผู้สืบทอดขึ้นแทน ชุมชนจดจำ) ไม่ปล่อยให้เรื่องหยุดกลางอากาศ

## 4. การโต้ตอบกับตัวละครหลัก

NPC แต่ละตัวมีความสัมพันธ์กับตัวละครหลักในสี่แกน

| แกน | ช่วง | ผล |
| --- | --- | --- |
| **ไว้ใจ** | −5 ถึง +5 | เปิดเส้นเรื่องที่ต้องการความไว้ใจ (ขอความช่วยเหลือ ความลับ) |
| **บุญคุณ** | 0 ถึง +5 | จำนวนครั้งที่ตัวละครหลักช่วยไว้ คืนบุญคุณในอนาคต |
| **แค้น** | 0 ถึง +5 | จำนวนครั้งที่ตัวละครหลักทำร้าย กลับมาแก้แค้น |
| **ความรู้จัก** | 0 ถึง +5 | รู้จักกันนานแค่ไหน รู้ความลับกันแค่ไหน |

**รูปแบบการโต้ตอบ**
- **ช่วย** ช่วย NPC ที่ตกอยู่ในอันตราย เพิ่มบุญคุณและไว้ใจ
- **ขัดขวาง** ทำให้เส้นเรื่องของ NPC ล้ม (เช่น ไม่ให้ขึ้นเป็นจอมมาร) เพิ่มแค้นและเปลี่ยนเส้น
- **ปล่อย** เมินเฉย เส้นเรื่องเดินตามน้ำหนักเดิม
- **ร่วมเดินทาง** ติดตามหรือชวนให้ร่วมงาน เปิดเส้นเรื่องร่วม
- **ทรยศ/ฆ่า** ตัดเส้น เพิ่มแค้นของคนใกล้ตัว

**การตอบแทนในอนาคต** NPC ที่ได้รับบุญคุณมีโอกาสกลับมาช่วยตัวละครหลักตามร้อยละที่เขียนในแถว ถ้า NPC ตายก่อน การตอบแทนไม่เกิด แต่ลูกหลานหรือสหายอาจรับช่วงหรือไม่ก็ได้

## 4.1 ชนชั้นและความมั่งคั่งของ NPC

NPC แต่ละตัวมีชนชั้น 1 ถึง 5 ตามตารางใน [../economy/03-classes.md](../economy/03-classes.md) หัวข้อ 8 ผู้นำของประเทศ (ตัวที่ 1) เป็นชั้น 5 เสมอ NPC ผู้ถือตำแหน่งธนาคาร กิลด์ บริษัท เป็นชั้น 4 NPC ที่เขียนว่าคนงาน ผู้ลี้ภัย หรือลูกกำพร้า เป็นชั้น 1 ถึง 2 ความรวยของประเทศ (W) กำหนดว่า NPC ซื้อของระดับไหนได้

## 5. NPC ส่งผลต่อโลก

บางเส้นเรื่องเปลี่ยนน้ำหนักของเหตุการณ์ในโลก เขียนในแถวด้วยรหัสเหตุการณ์ ตัวอย่าง

- ผู้นำคนใดขึ้นเป็นจอมมาร → น้ำหนัก DM-01 สูงขึ้น
- นักบวชที่เผยแพร่ลัทธิ → น้ำหนัก GD-xx เพิ่ม
- วิศวกรที่ปิดการเจาะ → น้ำหนัก PL-06 ลด

NPC ตัวเล็กตัวหนึ่งไม่ได้เปลี่ยนโลก แต่หลายคนที่เลือกทางเดียวกันเปลี่ยนได้

## 6. ความเป็นไปได้

แต่ละแถวมี 3 ทางเลือกขึ้นไป และเส้นเรื่องของ NPC ผูกกับ NPC อื่นและเหตุการณ์โลก จำนวนเส้นทางที่ไม่ซ้ำกันของทั้งโลก

- ถ้านับเฉพาะ NPC 572 ตัว แต่ละตัว 3 ทางเลือก ได้ 3^572 แบบ (ราวหนึ่งตามด้วยศูนย์สองร้อยกว่าตัว)
- แม้นับเพียงผู้นำ 143 ตัว ได้ 3^143 (ราว 10^68)
- เส้นทางจริงน้อยกว่านี้เพราะการตัดเส้น แต่ยังมากกว่าล้านล้านหลายเท่าตัว

| **เส้นเรื่องและตัวละครหลัก** | ทางเลือกก) ข) ค) พร้อมร้อยละ เงื่อนไข ผลต่อโลก และการโต้ตอบกับตัวละครหลัก |

**สัญลักษณ์ในเส้นเรื่อง**
- `→ รหัส` ส่งผลไปยังเหตุการณ์หรือ NPC อื่น (เช่น `→ DR-01`, `→ AZ03-2`)

- `คืนบุญ` การตอบแทนในอนาคต
- `ตัด` เส้นที่ถูกตัดเมื่อเงื่อนไขถูกทำลาย
