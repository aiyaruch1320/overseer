# แผนที่โลก

ผังทวีปและวิธีวาดแผนที่ · ข้อมูลทวีป: [continents.md](continents.md) · การเมืองข้ามทวีป: [world-politics.md](world-politics.md)

แผ่นแผนที่ขนาด 1600 × 900 หน่วย (MU) 1 MU = 3.84 หน่วยโลก = 0.48 tile (ตารางของ sim คือ 768 × 432 tile) รูปทรงทั้งหมดอยู่ใน `src/world/geo.ts` ใช้ฟังก์ชันเดียวกันทั้งตอนวาดและตอนสร้างตารางประเทศ เมืองจึงอยู่บนแผ่นดินที่วาดเสมอ

## 1. ผังทวีป

ทวีปแต่ละเสี่ยงเป็นแผ่นดินแยก คั่นด้วยช่องแคบแคบ ๆ เว้นแต่ที่เอกสารระบุว่าเดินทางทางบก (เป็น "คอแผ่นดิน")

| ทวีป | ตำแหน่ง | อยู่ติดกับ | เหตุผลจากเอกสาร |
| --- | --- | --- | --- |
| อัลเดรีย | กลาง ใหญ่สุด | ซิลวาเนล เนบูเลีย เมคาเรีย ซาฮารัน คาซ-ดูรัม (ทางบก) เนเรีย (ทะเลสาบด้านใต้) | ศูนย์กลางการค้า ทุกเส้นทางบกในตาราง §12 ผ่านที่นี่ ป้อม AL-20 ติดเนบูเลีย |
| ซิลวาเนล | ตะวันตก-เหนือ | อัลเดรีย (ทางบก) มอร์เฮเวน (คอแผ่นดินใต้) เนบูเลีย (ช่องแคบ รากไม้ใต้น้ำ) | ต้นไม้โลกกรองหมอก SV-08 เป็นแนวหน้ากันมอร์เฮเวน |
| เนบูเลีย | เหนือ | อัลเดรีย (ทางบก) ซิลวาเนล (ช่องแคบ) เมคาเรีย | ที่ราบลุ่มใต้ต้นไม้โลกที่กรองหมอก ภารกิจเมฆามีเมคาเรียร่วม |
| เมคาเรีย | ตะวันออกเฉียงเหนือ | อัลเดรีย (รถไฟ) อัซการ์ (เรือเหาะ) | ซื้อศิลาลอยจากอัซการ์ |
| ซาฮารัน | ตะวันออกเฉียงใต้ | อัลเดรีย (กองคาราวาน) อัซการ์ (บันไดหมื่นขั้น) | ภูเขายักษ์อยู่เหนือและตะวันออก ทรายลึกอยู่ใต้ |
| คาซ-ดูรัม | ใต้กลาง | อัลเดรีย (ทางบก) มอร์เฮเวน (ปากเหว) | แกนไฟ ปากเหวนรกดูดน้ำจากมอร์เฮเวน |
| มอร์เฮเวน | ตะวันตกเฉียงใต้ | ซิลวาเนล คาซ-ดูรัม เนเรีย (ทะเล) | ทัพบุกซิลวาเนลก่อน ชายฝั่งตะวันออกข้ามไปเนเรียและอัลเดรีย |
| เนเรีย | ทะเลใน (ใต้อัลเดรีย) + สายไข่มุกทางตะวันออกเฉียงใต้ | ทุกทวีปทางเรือ | คุมเส้นทางเดินเรือ เกาะ NR-01…16 เป็นเกาะละประเทศ |
| อัซการ์ | ลอยฟ้านอกชายฝั่งตะวันออก | ซาฮารัน (บันได) เมคาเรีย (เรือเหาะ) เนเรีย (วาฬฟ้า น้ำตก NR-02) | เกาะ AZ-01…10 เป็นเกาะละประเทศ AZ-01 ใหญ่สุดล้อมด้วยเกาะบริวารผูกสะพานโซ่ |

## 2. วิธีวาด (`src/render/terrain/`)

ภาพเวกเตอร์วาดลง canvas ที่ขนาดจริงของจอ (คูณ `devicePixelRatio`) ทุกครั้งที่กล้องขยับ จึงไม่มีภาพขยายแล้วแตก ไม่ว่าจะซูมเข้าหรือออก

| ชั้น (หลังไปหน้า) | ทำอย่างไร |
| --- | --- |
| ทะเล | สีตามระยะห่างจากฝั่ง (ไล่ลึกตื้น) ลายคลื่น เรือใบ |
| ชายฝั่ง | เส้นขอบแบบ marching squares ที่ละเอียดเพิ่มเมื่อซูมเข้า (เติมความขรุขระแบบกำหนดซ้ำได้) แล้วเกลี่ยเป็นเส้นโค้ง มีฟองคลื่นและเส้นหมึก |
| พื้นดิน | สีตามทวีป ความสูง โซน และเงาภูเขา |
| สัญลักษณ์ | ต้นไม้ ภูเขา เนินทราย ภูเขาไฟ โรงงาน ทุ่งนา ฯลฯ กระจายตามชีวนิเวศ ยิ่งซูมเข้ายิ่งมีสัญลักษณ์ชั้นเล็กโผล่เพิ่ม ความหนาแน่นบนจอจึงคงที่ แต่ละตัววาดจากเวกเตอร์ลงสไปรต์ที่ความละเอียดจอแล้ววางแบบ 1:1 |
| จุดเด่น หมอก | วาดสดทุกเฟรมเพื่อให้ขยับ |
| เกาะลอยฟ้า | เงาทอดลงพื้น เมฆใต้เกาะ ก้อนหินห้อยใต้เกาะ ผิวบนเกาะ สะพานโซ่ |
| ป้ายชื่อทวีป | ตัวอักษรที่ความละเอียดจริงของจอ |

`WorldScene` เป็นเจ้าของกล้อง ป้ายประเทศ เมือง และตัวละคร (Phaser, โปร่งใส) อยู่เหนือ canvas ภูมิประเทศ

## 3. ระดับซูม (กล้องเดียว ซูมต่อเนื่อง ไม่มีภาพตัด)

| ระดับ | ซูม (`cam.zoom`) | เห็นอะไร |
| --- | --- | --- |
| โลก | ต่ำกว่า 0.33 | ทุกทวีป ป้ายชื่อทวีป เมฆ |
| ทวีป | 0.33–0.75 | ภูมิประเทศเต็ม ป้ายประเทศ เมืองหลวง |
| ประเทศ | 0.75–2 | ไอคอนและชื่อเมืองทุกแห่ง ผังเมืองเริ่มโผล่บนแผนที่ตั้งแต่ 0.9 |
| เมือง | 2–7 | ผังเมืองเต็ม (ถนน อาคาร กำแพง ทุ่งนา) วางบนแผนที่ ณ ตำแหน่งจริง ไอคอนหายไป |
| ในเมือง | 7–48 | เมืองที่อยู่ใต้กล้องมีชีวิต: ผู้คน เวลากลางวันกลางคืน เทศกาล ภัยพิบัติ จนเห็นผู้คนทีละคน |

เมืองกว้าง 120 หน่วยโลก (15 tile ของแผนที่) พื้นที่ 162 × 101 tile ของเมือง ใหญ่กว่าเมืองเดิม (48 × 30) ราว 11 เท่าในแง่พื้นที่ เมืองสองแห่งอยู่ห่างกันอย่างน้อย 16 tile ของแผนที่ (`src/sim/worldgen.ts`) ผังเมืองจึงไม่ทับกัน ค่าขนาดอยู่ใน `src/city/citygen.ts` (`CW`, `CH`, `CITY_WU`) เมืองไม่ได้มีพื้นของตัวเอง พื้นคือแผนที่จริง จึงเห็นชายฝั่งและขอบเกาะลอยฟ้าตรงกับแผนที่ (ท่าเรือยื่นออกไปในน้ำ ท่าลงจอดยื่นออกไปในอากาศ) เมืองที่อยู่ในเขตแผ่นดินจะไม่ล้ำน้ำ

ผู้คนในเมืองเดินตามถนน ลาน ท่า และพื้นโล่งเท่านั้น ใช้ A* บนตารางของเมือง (`route` ใน `src/scenes/CityScene.ts`) จึงไม่เดินทะลุบ้าน กำแพง ต้นไม้ หรือน้ำ ถนนมีต้นทุนต่ำสุดจึงถูกเลือกก่อน

## 4. หน้าตาเมืองของแต่ละประเทศ (`src/city/themes.ts`)

ทุกทวีปมีธีมพื้นฐาน แล้วแต่ละประเทศปรับตามผู้คน ศาสนา และแฮชของตัวเอง จึงไม่มีสองประเทศที่หน้าตาเหมือนกัน

| ทวีป | ผังเมือง | อาคาร | ของเด่น |
| --- | --- | --- | --- |
| อัซการ์ | วงแหวนและซี่ล้อ | หอคอยหินขาวหลังคาฟ้า/ทอง โดม | ท่าลงจอดยื่นออกอากาศ เมฆลอยต่ำ รูปปั้นกลางลาน |
| มอร์เฮเวน | ถนนคดเคี้ยวระหว่างค่าย | เต็นท์หนัง กระท่อมโคลน | รั้วไม้แหลม กองไฟกลางลาน ประกายไฟ |
| คาซ-ดูรัม | ตารางแน่น | บ้านเจาะหน้าผา โรงตีเหล็กมีเตาเรืองแสง ป้อมหิน | เตาหลอมกลางลาน กำแพงเหล็ก ควันถ่าน ไอน้ำจากปล่อง |
| เนเรีย | ตารางและคลอง | บ้านยกพื้น ทาวน์เฮาส์ริมท่า | คลองและสะพาน ปาล์ม นกนางนวล |
| อัลเดรีย | ตาราง/วงกลม/คดเคี้ยวแล้วแต่ประเทศ | ต่างยุคกันตามประเทศ: โรงนามุงจาก ทาวน์เฮาส์หน้าจั่วขั้นบันได ตึกอิฐโรงงาน เมืองตื่นทองไม้ระแนง ตึกกระจกนีออน บ้านเนินฮาล์ฟลิง | ทุ่งนาล้อมเมือง แม่น้ำ (ยุคของประเทศกำหนดโคมถนนและควัน) |
| เมคาเรีย | ตารางสม่ำเสมอ | โรงงานอิฐ ปล่องควัน ตึกสูงบางแห่ง | เฟืองกลางลาน กำแพงเหล็ก |
| ซาฮารัน | ถนนคดเคี้ยวหรือรัศมี | บ้านอิฐดินเผาซ้อนชั้นมีปลายคานโผล่ โดมทราย เต็นท์ | โอเอซิสกลางลาน ปาล์ม พายุทราย |
| ซิลวาเนล | ถนนดินคดเคี้ยว | บ้านบนต้นไม้ใหญ่ สีใบตามกิ่งของต้นไม้โลก | ต้นกล้าเรืองแสง ใบไม้ปลิว แม่น้ำ |
| เนบูเลีย | ถนนแคบคดเคี้ยว | บ้านหินชนวน ทาวน์เฮาส์ | หอระฆัง โคมถนน หมอก |

ธีมของแต่ละประเทศอยู่ใน `src/city/flavor.ts` (ครบทั้ง 143 ประเทศ: แบบบ้าน หลังคา ผัง กำแพง ลานกลาง อาคารเด่น) ปรับตามเนื้อหาใน `docs/countries/` เช่น AL-13 เนออนเวย์เป็นตึกกระจกนีออน AL-16 ไชร์วิกเป็นบ้านเนิน AL-27 โกลด์ครีกเป็นเมืองตื่นทอง SH-xx ใช้อิฐดินเผา KD-xx เจาะหน้าผา

### แบบบ้าน (`src/city/houses.ts`, `src/city/paint.ts`)

| แบบ | ลักษณะ |
| --- | --- |
| `gable` บ้านไร่ | หลังคา 4 วัสดุ (กระเบื้อง สเลต ไม้แผ่น จาก) จั่วด้านข้างหรือด้านหน้า ปีกต่อเติม ระเบียง ชั้นสอง ปล่องไฟ หน้าต่างใต้หลังคา |
| `terrace` ทาวน์เฮาส์ | แถวบ้านหน้าจั่วขั้นบันได คนละสี คนละกิจการ ร้านค้ามีกันสาดลาย |
| `adobe` | บล็อกดินเผาซ้อนชั้น ปลายคานโผล่ กรอบประตูสีเทอร์ควอยซ์ บันไดขึ้นหลังคา |
| `carved` | บ้านเจาะหน้าผา หน้าหินสลัก ประตูเหล็ก ช่องแสงไฟ ปล่องไอน้ำ |
| `boomtown` | อาคารไม้หน้าจั่วปลอมมีป้าย ระเบียงยาวหน้าร้าน |
| `burrow` | เนินหญ้าประตูกลม สวนดอกไม้ |
| `tower` | ตึกกระจกสูงไฟนีออน เสาอากาศ |
| แบบเดิม | โดม หอแหลม กระท่อม เต็นท์ A-frame บ้านยกพื้น ตึกอิฐ โรงตีเหล็ก ป้อม บ้านต้นไม้ บ้านเห็ด |

บ้านทุกหลังถูกวาดบนผืนผ้าใบของตัวเองแล้วจึงลงไฟ (แสงจากซ้ายบน เงาตกขวาล่าง เส้นมืดที่โคนผนัง) เงาเป็นรูปทรงของบ้านจริง สีหลังคาและผนังสุ่มเพี้ยนเล็กน้อยต่อหลัง ทางเดินหินจากประตู และรั้ว (ไม้ระแนง หวาย หิน พุ่มไม้ ตามประเทศ) ที่หน้าบ้านบางหลัง

เฟสถัดไป: เส้นเขตแดนและสีประเทศแบบเวกเตอร์ (ตอนนี้มีแค่ขอบเรืองของประเทศที่เลือก) · ย้ายป้ายและไอคอนเมืองมาวาดความละเอียดจอ · เนื้อหาประเทศจริงจาก `docs/countries/` (ชื่อ สถานที่เฉพาะของแต่ละประเทศ)

### อนุสาวรีย์ประจำเมือง (`src/city/landmarks.ts`)

ไม่ใช่ทุกเมืองมีอนุสาวรีย์ มีเฉพาะเมืองหลวงและเมืองใหญ่บางแห่ง (ราว 1 ใน 7 ของเมืองขนาดกลางขึ้นไป) เมืองอื่นมีแต่ลานตลาดที่ปูหินเป็นวงแหวนตามสีของประเทศ พร้อมแผงขาย

ตำแหน่งขึ้นกับธีมของประเทศ (`SITE`): **ในลาน** (เยื้องไปด้านหนึ่ง ไม่อยู่กลางพอดี) เช่น น้ำพุ รูปปั้นวีรบุรุษ หอนาฬิกา **ริมขอบเมือง** ตรงทิศที่เปิดสู่หน้าผาหรือทะเล เช่น รังฟ้า ปล่องภูเขาไฟ ประตูบันได ปิรามิด **ริมน้ำ** (ประภาคาร ทะเลสาบ ท่าเรือเรือเหาะ) **ย่านช่าง** (เฟือง เตาหลอม ปั๊ม) หรือ **มุมสงบ** (ต้นกล้า เสาจารึก โอเอซิส) ส่วนต้นไม้โลกยังเป็นใจกลางเมืองเพราะเมืองเติบโตรอบมัน

พื้นที่ที่อนุสาวรีย์ครอบ (`FOOT`) ทั้งฐานและส่วนสูงด้านบน ถูกกันเป็นพื้นที่ตัน (`solid`) NPC จึงเดินทะลุหรือเดินอ้อมไปหลังตัวอนุสาวรีย์ไม่ได้ แผงตลาดก็ตันเช่นกัน

**อัซการ์** ทุกเมืองหลวงมีใจกลางเป็นของตัวเองตาม `docs/countries/01-azgar.md`

| ประเทศ | ใจกลางเมือง |
| --- | --- |
| AZ-01 โอรันธาร์ | **รังฟ้า**: เสาหินที่โอรัน-ซัลพันรอบ ถ้ำเรืองแสง สะพานโซ่ไปเสาสมอสี่ต้น ไอคอนบนแผนที่เป็นมังกรขนาดใหญ่ในรัศมีทอง |
| AZ-02 ซากโรการ์ | ปล่องภูเขาไฟเพลิงนิรันดร์ มีลานดวลบนขอบปล่อง |
| AZ-03 วีร์กาดุส | เรือใบศิลาลอยจอดท่า |
| AZ-04 ธีโรวาส | ประตูบนของบันไดหมื่นขั้น |
| AZ-05 โคซาโมเรีย | วังเดียวสองราชสำนัก ฝั่งสุริยาสีทอง ฝั่งจันทราสีคราม |
| AZ-06 ดราซาวาส | ทะเลสาบลอยฟ้า |
| AZ-07 อัซเมโรส | ศาลอีริดาน มังกรขนคลุมกองฟาง บนไร่เมฆ |
| AZ-08 โคธีดุส | หอยกศิลาลอยของเหมือง |
| AZ-09 วีร์เนกา | ปั๊มศิลาลอยเทียมและธงโซ่ขาด |
| AZ-10 นอคโมรา | หอคอยใต้ฝนไม่หยุด โคมในความชื้น |

โอรันธาร์ยังมีหอพักอัศวินปีก (`aerie`) ป้อมปราการและค่ายฝึกของ ธรักซ์ลีเจียน ส่วนวีร์กาดุสมีท่าเรือเรือเหาะ (`skydock`)

### เมืองมีหน้าที่ (`src/city/civic.ts`)

ทุกเมืองมีร้านค้า (แถวร้านพร้อมป้ายอาชีพ) ส่วนอาคารอื่นอ่านจากเนื้อหาของแต่ละประเทศ (`roleExtras` ใน `flavor.ts`): ประเทศที่รบเก่ง (สงคราม ทัพ ป้อม อัศวิน ชายแดน) มี **ป้อมปราการ** (กำแพง หอคอยมุม ปราสาทกลาง ประตูเหล็ก) **กรมทหาร** และ **ลานฝึก** (หุ่นฟาง เป้าธนู ที่เก็บอาวุธ) ประเทศที่ตัดสินกันด้วยการดวล มี **ลานประลอง** (อัฒจันทร์ ซุ้มประตู ธงรอบขอบ) นครการค้ามี **ธนาคาร** นครหมอมี **โรงพยาบาล** ผู้อาศัยในเมืองเดินไปใช้อาคารเหล่านี้ตามประเภท (`computeSpots`) ป้อมปราการเฉพาะเมืองขนาดกลางขึ้นไปและเมืองหลวง

### ผังเมืองให้สมจริง (`src/city/citygen.ts`)

อ้างอิงหลักการผังเมืองยุคกลาง เช่น ลานตลาดเป็นแกนของเมือง ศาลากลาง วิหาร และสมาคมอยู่รอบลาน ที่ดินแบ่งเป็นแปลงต่อเนื่องหน้าถนน ถนนสายหลักวิ่งจากประตูเมืองเข้าหาลาน (ตัวอย่าง [ลานตลาดวรอตซวาฟ](https://en.wikipedia.org/wiki/Market_Square,_Wroc%C5%82aw)) และแนวคิดย่านแบบ ward ของ [Medieval Fantasy City Generator](https://watabou.itch.io/medieval-fantasy-city-generator)

- **ย่าน** อาคารหน้าที่เลือกที่ตั้งตามประเภท: วิหาร สมาคม ธนาคาร ร้านค้า หอสมุด อยู่ใกล้ลาน โรงตีเหล็กและโรงเตี๊ยมอยู่แนวถนนกลาง โกดัง ยุ้งฉางอยู่ชั้นนอกหรือริมท่า ค่ายทหาร ป้อม ลานฝึกรวมกันในย่านทหารด้านเดียวใกล้ประตู สถานพยาบาลอยู่ฝั่งตรงข้ามย่านทหาร ลานประลองอยู่ข้างย่านทหาร
- **ผู้คน** คนมีฐานะอยู่กลางเมือง บ้านหลังใหญ่ ส่วนชั้นนอกบ้านเล็กลงและเป็นแบบเรียบง่ายของประเทศ (กระท่อม เต็นท์ หรือบ้านยกพื้นตามธีม)
- **หน้าบ้าน** บ้านหันประตูเข้าถนนหรือลาน (แถวใต้ตัวบ้านเป็นถนน) บ้านหลังถนนมีน้อย
- **กำแพงและประตู** เมืองหลวงและเมืองที่ธีมมีกำแพงล้อมรอบ ถนนที่ผ่านกำแพงมีหอคอยประตูสองข้าง

### ศาสนสถาน (`src/city/sacred.ts`)

วัด โบสถ์ และวิหารวาดตามศาสนาของประเทศ (`Theme.religion`) ใหญ่และเด่นกว่าบ้าน อยู่ใกล้ลานกลางเมือง หมู่บ้านมีศาลเล็กของศาสนาเดียวกัน

| ศาสนา | สิ่งก่อสร้าง |
| --- | --- |
| แสง | มหาวิหารกอทิก หอคู่ ยอดแหลม หน้าต่างกุหลาบ ตะวันทอง |
| มังกร | วัดซ้อนชั้นหลังคาทองปลายโค้ง เสาแดง มังกรขดบนสันหลังคา |
| นาคา | ปราสาทขั้นบันไดหินเขียว พญานาคเจ็ดเศียรแผ่เหนือประตู สระน้ำ |
| สมุทร | วิหารขาวหลังคาเปลือกหอย สมอเรือเหนือประตู โคมไฟยอดเรือน |
| ธรรมชาติ | ลานต้นไม้ศักดิ์สิทธิ์ ล้อมด้วยหินตั้งจารึกรูนเรืองแสง แท่นมอส |
| จันทรา | หอดูดาวสีเงิน โดมเปิดช่องส่องกล้อง จันทร์เสี้ยว |
| บรรพบุรุษ | ห้องโถงยาวหินมืด ช่องตะเกียงและใบหน้าสลัก กระถางไฟไม่ดับ |
| สงคราม | วิหารหินหยาบ ธงแดง ดาบไขว้ ราวหอก กะโหลกตามชายคา |
| ปีศาจ | ยอดแหลมออบซิเดียนแตกด้วยรูนแดง กระถางไฟ ประตูมีเขา |
| ไม่มีศาสนา | ศาลาประชาคมไม้และระฆัง |

### ถนนหลายแบบตามความมั่งคั่ง (`src/city/streets.ts`)

ทุกเมืองมีค่าความมั่งคั่ง (`wealthOf` ใน `flavor.ts`: พื้นฐานตามทวีป ปรับตามคำใน docs เช่น ธนาคาร การค้า ผู้ลี้ภัย ยากจน เมืองหลวงมากกว่า หมู่บ้านน้อยกว่า) ถนนแบ่งเป็นซอย ถนนสาย และถนนใหญ่ ถนนใหญ่ดีกว่าซอยเสมอ พื้นผิวไล่จากดินแดงมีร่องล้อและแอ่งน้ำ ดินอัดกรวด หินกลม แผ่นหิน จนถึงแผ่นหินขัดมีลายเส้นสีเมืองและขอบถนน เมืองบนน้ำใช้ทางไม้กระดาน

### เมืองท่าและเมืองลอยน้ำ (`src/city/ships.ts`)

เมืองท่าตั้งริมทะเล (เมืองหลวงของประเทศที่ docs เน้นการเดินเรือ การค้า ท่าเรือ ถูกย้ายมาติดชายฝั่ง) เมืองท่าใหญ่มีท่าหินตลอดแนวฝั่ง สะพานท่ายาวกว้างหลายสิบแห่ง เรือจอดสองข้าง (เรือใบใหญ่ เรือสำเภา เรือกลไฟ เรือยาวมอร์เฮเวน เรือใบสามเหลี่ยมซาฮารัน) เครน โกดัง และประภาคารปลายคันดิน ประเทศเนเรียบางแห่ง (NR-03, 05, 10, 11, 13, 14 และบางเมืองอื่น) ลอยอยู่บนน้ำ ถนนเป็นทางไม้ บ้านตั้งบนแพมีทุ่นถัง

### ต้นไม้และการซูมผ่าน

ใบไม้วาดเป็นใบจริงหลายร้อยใบต่อกลุ่ม มีสีเข้มด้านล่าง ไฮไลต์ด้านบนซ้าย ไม้เลื้อยและดอกเรืองแสง (`src/render/treeart.ts`) ใช้กับต้นไม้โลกบนแผนที่ ต้นไม้โลกกลางเมือง ต้นกล้า และบ้านต้นไม้ ระหว่างซูมลงสู่เมือง กล้องจะผ่านเอฟเฟกต์ของทวีปที่อยู่ใต้กล้อง (`PASS_FX` ใน `ui.ts`, `drawPass` ใน `sky.ts`): เมฆหนาในอัซการ์ หมอกในเนบูเลีย ไอทะเลในเนเรีย ควันและประกายไฟในมอร์เฮเวนกับคาซ-ดูรัม ไอน้ำในเมคาเรีย ทรายในซาฮารัน

ซิลวาเนลต่างออกไป: เอฟเฟกต์ใบไม้เกิดเฉพาะเมืองที่อยู่ใต้เรือนยอดของต้นไม้โลกจริง ๆ (`canopyCover` ใน `treeart.ts` ตามตำแหน่งกล้องบนแผนที่) เมืองในป่านอกร่มไม่มี ระหว่างซูมเข้า กิ่งใบไม้แกว่งผ่านหน้ากล้อง เมื่อกล้องเข้าไปอยู่ใต้ร่ม เรือนยอดของต้นไม้บนแผนที่ค่อยจางหายไปเพราะอยู่เหนือหัว แต่ต้นไม้ยังอยู่: เหลือโคนลำต้นขนาดใหญ่และรากที่แผ่ไปทั่วพื้น เมืองหลวงซิลนเนลลอร์ตั้งอยู่ที่โคนต้นท่ามกลางราก (ไม่มีอนุสาวรีย์กลางลาน เพราะต้นไม้คืออนุสาวรีย์) แสงลอดใบเป็นลำและเป็นดวงระยิบบนพื้น ฝุ่นละอองลอยในแสง ใบไม้ร่วงช้า ๆ โดยไม่มีกรอบใบไม้บังสายตา

### เมื่อเส้นเรื่องเปลี่ยนโฉมแผ่นดิน (`src/sim/fate.ts`)

`docs/world-events.md` §15 ระบุว่าบางเหตุการณ์ทำให้ทวีปเปลี่ยนรูป แต่ละแบบมีหน้าตาเตรียมไว้แล้ว ตั้งด้วย `Country.fate` (หรือ `scene.setFate({ continent }, 'ash')` ใน `WorldScene`) ประเทศที่มีธง `fallen` นับเป็น `fallen` เอง

| fate | เหตุการณ์ | แผนที่โลก | เมือง |
| --- | --- | --- | --- |
| `skyfall` สกายฟอลล์ | DR-01 ฟ้าถล่ม (อัซการ์) | เทาหม่น | ซากเมือง หลังคาถล่ม รอยแตกบนพื้น อนุสาวรีย์พัง ฝุ่นลอย |
| `ash` ทวีปเถ้า | DR-04 ฤดูหนาวเถ้า (คาซ-ดูรัม) | ขาวเทา | เถ้าปกคลุมหลังคาและพื้น เถ้าร่วงตลอด |
| `flood` ทุ่งจม | DR-05 มหาน้ำขึ้น (ชายฝั่ง) | น้ำเงิน | น้ำท่วมถึงผนัง เรือในถนน |
| `split` ทุ่งแยก | DR-07 (อัลเดรีย) | น้ำตาลดิน | รอยแยกผ่าเมือง บางหลังพัง |
| `withered` ป่าเหี่ยว | BIO-02 ต้นไม้โลกตาย (ซิลวาเนล) | เหลืองแห้ง | ใบเหลือง ต้นไม้โกร๋น ไม่มีแสงเรือง |
| `rust` ดินแดนสนิม | MC-04 (เมคาเรีย) | สนิม | ไฟดับ ปล่องไม่มีควัน คราบสนิม |
| `light` ทวีปแสง | BIO-05 (เนบูเลีย) | ทอง | บ้านเรืองแสง ละอองแสงลอย ไม่มีกลางคืน |
| `fog` หมอกกลืน | FG-11 (เนบูเลีย) | ม่วงทึบ | โคมดับ เมืองร้างในหมอก มืดตลอด |
| `fallen` ล่มสลาย | ประเทศล่มสลาย | เทาควัน | ซาก ไฟไหม้ กำแพงพัง |

หน้าข้อมูลประเทศแสดงชื่อและเหตุการณ์ของสถานะนี้ ตัวเกมยังไม่ได้ปล่อยเหตุการณ์เหล่านี้เอง เมื่อเขียนเส้นเรื่องแล้วเรียก `setFate` ที่จุดเกิดเหตุการณ์ได้ทันที

## 5. รูปร่างและตำแหน่งของประเทศ

- **อัซการ์และเนเรีย** 1 เกาะ = 1 ประเทศตามลำดับในเอกสาร ทุกเกาะเป็นรูปทรงไม่สม่ำเสมอ (ก้อนหลักพร้อมแขนงยื่นออกไป `lumpy` ใน `src/world/geo.ts`) ไม่ใช่วงกลม พันธมิตรอยู่ติดกันจนเป็นแผ่นดินเดียวกัน (`join`) กลุ่มบัลลังก์ของอัซการ์ห้อยอยู่กับ AZ-01 ส่วนเนเรียจัดตามกลุ่มในเอกสาร (ฝ่ายน้ำลึกเรียงกันที่ฝั่งตะวันตกเฉียงเหนือ ฝ่ายแม่น้ำที่ฝั่งตะวันออก โจรสลัดที่ตะวันตกเฉียงใต้ ฝ่ายวาฬใต้เกาะลอยฟ้า)
- **ทวีปใหญ่** แบ่งดินแดนด้วย Voronoi ที่ยืดตามทิศของแต่ละประเทศ ถ่วงขนาดตามรัฐ (จักรวรรดิใหญ่ นครรัฐเล็ก) และบิดขอบด้วยสัญญาณรบกวนสองระดับ ชิ้นส่วนที่หลุดไปถูกรวมกลับเข้าประเทศข้างเคียง
- **กลุ่มพันธมิตร** อ่านจากหัวข้อ "กลุ่ม" ในเอกสารแต่ละทวีป (ซิลวาเนลใช้ "กิ่ง" ของต้นไม้โลก) เก็บในฟิลด์ `bloc` ของ `src/data/countries.ts` (สร้างด้วย `npx tsx scripts/gen-countries.ts`) ประเทศในกลุ่มเดียวกันถูกวางบนเมล็ดที่อยู่ใกล้กัน จึงติดกันบนแผนที่ ประเทศที่เอกสารระบุตำแหน่งไว้ (`SEED_HINTS`) ยังอยู่ที่เดิม
