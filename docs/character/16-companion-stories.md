# เรื่องราวการได้สัตว์คู่หู 31 เรื่อง

ระบบ: [13-companions-overview.md](13-companions-overview.md) · ชนิดสัตว์: [15-companion-species.md](15-companion-species.md) · อาชีพ: [09-jobs-common.md](09-jobs-common.md)

รหัสขึ้นต้น `cs_` เรื่องที่เกิดเมื่อสุ่มผ่านโอกาสต่อปีของกลุ่มอาชีพ ([13-companions-overview.md](13-companions-overview.md) หัวข้อ 2) เรื่องหนึ่งมี **ทางเลือก** ก) ข) ค) แต่ละทางมีผลต่อสัตว์ที่ได้และความผูกพันเริ่มต้น **ตัดเมื่อ** คือเงื่อนไขที่ทำให้เรื่องเกิดไม่ได้ (ตามกติกาตัดเส้นที่ไม่มีทางเกิด) และมีเรื่องสืบทอดตามที่ระบุ ช่อง **โอกาสสัมพัทธ์** ใช้เปรียบเทียบน้ำหนักของเรื่องที่เข้าเงื่อนไขพร้อมกัน
