# ความสามารถของสัตว์คู่หู

ระบบ: [13-companions-overview.md](13-companions-overview.md) · ชนิดสัตว์: [15-companion-species.md](15-companion-species.md) · เรื่องราวการได้: [16-companion-stories.md](16-companion-stories.md)

ความสามารถแต่ละอย่างมี 3 ระดับ (สะสมผลเหมือน skill) สัตว์เริ่มต้นด้วยระดับที่ระบุในไฟล์ชนิดสัตว์ และเพิ่มระดับเมื่อความผูกพันเพิ่ม ([13-companions-overview.md](13-companions-overview.md) หัวข้อ 4) ผลเป็นผลที่ตัวละครหลักหรือกลุ่มได้รับขณะสัตว์อยู่ด้วย **ช่องเสริมอาชีพ** คืออาชีพที่ผลเป็นสองเท่า (ตามรหัสใน [09-jobs-common.md](09-jobs-common.md))

รหัสขึ้นต้น `pa_` ทั้งหมด 60 ความสามารถ
