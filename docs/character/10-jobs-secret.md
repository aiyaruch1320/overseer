# อาชีพลับ 26 อย่าง

ระบบ: [08-jobs-overview.md](08-jobs-overview.md) · อาชีพทั่วไป: [09-jobs-common.md](09-jobs-common.md) · อาชีพพิเศษ: [11-jobs-special.md](11-jobs-special.md)

อาชีพลับไม่ถูกเสนอตอนบรรลุนิติภาวะ ระบบตรวจเงื่อนไขทุกปี เมื่อครบเงื่อนไข ทอยโอกาสตามหัวข้อ ง (ได้ยาก แต่เพิ่มขึ้นมากเมื่อมาตามเส้นเรื่องที่เหมาะสม) ถ้าทอยผ่านจึงเกิดเหตุการณ์ให้ตัวละครเลือก **ยอมรับ** หรือ **ปฏิเสธ** (ปฏิเสธแล้วอาจกลับมาอีกครั้งที่เงื่อนไขยังครบ) ตัวละครที่มีอาชีพลับแล้วไม่ได้รับอีกอัน ผู้เล่นเลือกอาชีพลับล่วงหน้าไม่ได้ ระดับความหายากคือ L เสมอ

เงื่อนไขเขียนจากค่าและแท็กของตัวละคร: **ค่า** คือค่าสถานะ (`pow` `mag` ฯลฯ) หรือแกนนิสัย (`kind` `brave` ฯลฯ) · **แท็ก** คือ `#แท็ก` จาก [catalog/tags.md](catalog/tags.md) หรือจากพรใหม่ · **skill** คือรหัส skill เช่น `sword_3` · ช่อง **ข้อห้ามเพิ่มจากโลก** คือเงื่อนไขที่เพิ่มเพื่อให้สมเหตุสมผล

## ง. ความยากและโอกาสได้อาชีพลับ

อาชีพลับต้องได้ยาก เงื่อนไขครบอย่างเดียวไม่พอ ทุกปีที่ตัวละครบรรลุนิติภาวะแล้ว ไม่มีอาชีพลับ และเงื่อนไขของอาชีพนั้นครบ ระบบทอยโอกาสหนึ่งครั้งต่ออาชีพ ถ้าผ่านจึงเกิดเหตุการณ์ให้ยอมรับหรือปฏิเสธ

```
โอกาสต่อปี = 2% × ทางเอื้อ × เหตุการณ์ผูก × คนชักชวน × พระเจ้า   (ไม่เกิน 60%)
```

| ตัวคูณ | ค่า | เมื่อไร |
| --- | --- | --- |
| ฐาน | 2% | เงื่อนไขครบ ไม่มีอะไรเอื้อ ตัวละครที่ไม่มีเส้นเรื่องที่เหมาะจะรอเฉลี่ย 50 ปี ได้เองก่อนหมดอายุน้อยกว่าครึ่ง |
| ทางตรง | เสนอปีถัดไปแน่นอน | ตัวละครเลือกทางที่ระบุ "ทางสู่" ในเส้นเรื่อง (คอลัมน์ทางตรงของตาราง) และเงื่อนไขครบ ไม่ต้องทอย |
| ทางเอื้อ | ×6 | ตัวละครผ่านโหนดหรือจุดบรรจบในคอลัมน์ทางเอื้อ (12% ต่อปี คาดว่าได้ใน 8 ปี) |
| เหตุการณ์ผูก | ×2 | เหตุการณ์ในคอลัมน์สุดท้ายของตารางเกิดแล้วในทวีปที่ตัวละครอยู่ |
| คนชักชวน | ×1.5 | มี NPC ในเส้นเรื่องของอาชีพนั้นที่ไว้ใจตัวละคร ≥ 5 |
| พระเจ้า | ×1.5 | คำใบ้ "จงไป" ชี้ไปยังที่ตั้งของเส้นเรื่องอาชีพนั้น หรือพรสายชะตา (`b_fateweaver` `b_destiny`) ×1.3 |

อาชีพที่เขียนว่าเกิดเฉพาะเหตุการณ์ (เช่น `godslayer` ต้องมี GD-08) มีฐาน 0% จนกว่าเหตุการณ์นั้นจะเกิด ปฏิเสธแล้วทอยใหม่ปีถัดไปด้วยฐาน 1% ตัวคูณอื่นเท่าเดิม

ตารางต่อไปนี้ระบุทางตรง ทางเอื้อ และเหตุการณ์ผูกของอาชีพลับทั้ง 26 อย่าง ช่อง "—" คือยังไม่มีโหนดเฉพาะ ได้โอกาสจากฐานและตัวคูณอื่นเท่านั้น
