# อาชีพลับ 27 อย่าง

ระบบ: [08-jobs-overview.md](08-jobs-overview.md) · อาชีพทั่วไป: [09-jobs-common.md](09-jobs-common.md) · อาชีพพิเศษ: [11-jobs-special.md](11-jobs-special.md)

อาชีพลับไม่ถูกเสนอตอนบรรลุนิติภาวะ ระบบตรวจเงื่อนไขทุกปี เมื่อครบเงื่อนไข จะเกิดเหตุการณ์ให้ตัวละครเลือก **ยอมรับ** หรือ **ปฏิเสธ** (ปฏิเสธแล้วอาจกลับมาอีกครั้งที่เงื่อนไขยังครบ) ตัวละครที่มีอาชีพลับแล้วไม่ได้รับอีกอัน ผู้เล่นเลือกอาชีพลับล่วงหน้าไม่ได้ ระดับความหายากคือ L เสมอ

เงื่อนไขเขียนจากค่าและแท็กของตัวละคร: **ค่า** คือค่าสถานะ (`pow` `mag` ฯลฯ) หรือแกนนิสัย (`kind` `brave` ฯลฯ) · **แท็ก** คือ `#แท็ก` จาก [catalog/tags.md](catalog/tags.md) หรือจากพรใหม่ · **skill** คือรหัส skill เช่น `sword_3` · ช่อง **ข้อห้ามเพิ่มจากโลก** คือเงื่อนไขที่เพิ่มเพื่อให้สมเหตุสมผล
