# skill ใหม่ที่ผูกกับโลก

ระบบ: [README.md](README.md) · skill เดิม: [catalog/aptitudes-skills.md](catalog/aptitudes-skills.md) · ผลของ skill เดิม: [04-skill-effects.md](04-skill-effects.md)

skill ใหม่ไม่ได้ผูกกับความถนัดเดียวในโค้ดเดิม แต่ผูกกับ **วัฒนธรรมหรือสถานที่** ในโลก แต่ละ skill มี 3 ระดับ (สะสมผล) และมี **ความถนัดแม่** ที่เมื่อมีอยู่แล้วเรียนได้ง่ายขึ้น 2 เท่า รหัสขึ้นต้น `ns_` ช่อง **เรียนได้จาก** บอกที่ที่น้ำหนักสุ่มเพิ่ม
