# ศาสนาตามดินแดน

เก้าศาสนาที่ผูกกับทวีปหรือเผ่าเฉพาะ ศาสนาหลักอยู่ที่ [02-major-faiths.md](02-major-faiths.md) ขบวนการอยู่ที่ [04-movements.md](04-movements.md)

## 11. ศรัทธาเตาหลอม

- **ผู้ศรัทธา** คนแคระ เผ่าลาวา ช่างตีทั่วโลก (ฮัลกาด กรอมฮอล์ม ดูร์ดิน ราว 3%)
- **หลักความเชื่อ** เปลวไฟคือเทพ ผู้ตีเหล็กคือผู้ทำพิธี อาวุธทุกชิ้นเป็นคำสวดที่เป็นรูปธรรม
- **พิธี** ตะวันหลอมเหล็ก ลงมือตีโดยไม่พูดตลอดสามวัน พิธีหลอมอาวุธตำนาน
- **ช่องทาง** C รั่ว ศรัทธาไปถึงเปลวไฟ ไม่ผ่านมังกร คัลดราจึงไม่ได้รับศรัทธาเท่าทวีปอื่น
- **นิกายย่อย**
  - *ผู้บูชาเตา* เปลวไฟคือเทพองค์เดียว
  - *ผู้ถ่ายทอด* (เผ่ามังกรธรอกาด) เสนอให้ส่งศรัทธาผ่านคัลดรา เพื่อเสริมผนึก
- **พร (U)** ไฟในมือช่าง: ตีอาวุธได้ดีขึ้นระหว่างพิธี
- **คำสาป (R)** เตาที่หิว: เตาหลอมต้องการวัตถุดิบหายากทุกครั้งที่ตี
- **หนุน** PL-03 ×1.5 (คัลดราขาดศรัทธา) GI-04 ×1.3 **ต้าน** DR-04 ผลลดลง ×0.8 ในช่วงต้น **เปิดเฉพาะ** GI-05 เมื่อผู้ถ่ายทอดชนะ

## 12. ลัทธิเฟืองหมุน

- **ผู้ศรัทธา** ชาวแอสเทรียและเมืองคนยากจนในเมคาเรีย ลูกผสมจักรกลบางส่วน (ราว 4%)
- **หลักความเชื่อ** จักรวาลคือเฟืองขนาดใหญ่ ทุกชีวิตเป็นฟันเฟือง ผู้ที่หมุนตามจังหวะจะไม่ถูกบดขยี้
- **พิธี** สวดบทเฟือง หมุนวงล้อพิธีกลางเมือง สวดภาษาโบราณที่ไม่มีใครรู้ความหมาย
- **ช่องทาง** D ผิดทาง บทสวดเป็นภาษาปฐมจริง เครื่องจักรปฐมที่ซากอาร์เคียได้ยินและตอบสนองทุกครั้งที่สวดครบ
- **ความลับ** ผู้นำลัทธิส่วนหนึ่งรู้และตั้งใจให้เป็นเช่นนั้น
- **นิกายย่อย**
  - *ผู้ท่องบท* รักษาบทเดิม ไม่เปลี่ยนแม้แต่พยางค์
  - *ผู้ถอดบท* พยายามอ่านบทเพื่อรู้ความหมาย (สัมพันธ์กับสมาคมรหัสไซเฟอร์)
- **พร (U)** จังหวะเฟือง: ทำงานซ้ำได้ไม่ล้า
- **คำสาป (R)** เฟืองสะดุด: ชีวิตเกิดอุบัติเหตุซ้ำ ๆ เมื่อฝ่าฝืนจังหวะ
- **หนุน** MC-05 ×2, MC-06 ×1.5, END-06 ×1.5 เมื่อลัทธิเกิน 8% **ต้าน** GD-03 ×0.8 **เปิดเฉพาะ** MC-12 เมื่อเครื่องตื่นแล้ว

## 13. ศรัทธาศิลา

- **ผู้ศรัทธา** ยักษ์ ชนผืนทรายบางส่วน (กัชมีร์ ซากกัช รามีร์ ซีมาร์ บัดมีร์ ราว 2%)
- **หลักความเชื่อ** ภูเขาทุกลูกคือบรรพบุรุษที่ยืนค้ำแผ่นดิน ผู้ใดแตะหินที่ไม่ได้รับอนุญาตคือผู้ล่วงเกินศพ
- **พิธี** แกะสลักบรรพบุรุษลงหิน เฝ้าบันไดหมื่นขั้น เต้นกล่อมไททัน
- **ช่องทาง** A ผนึก ศรัทธาไหลผ่านบรรพบุรุษสู่กรอม-ธาร ซึ่งเป็นเสาค้ำเกาะลอยฟ้า
- **ผลลูกโซ่** ยักษ์เลิกเฝ้าบันไดหรือเลิกศรัทธา → กรอม-ธารอ่อน → เสาที่ค้ำเกาะอ่อน → เกาะร่วงง่ายขึ้น
- **นิกายย่อย**
  - *ผู้เฝ้าบันได* (SH-03)
  - *ผู้กล่อมไททัน* (SH-06) หวังให้ไททันตื่น
  - *ผู้เงียบ* (SH-13)
- **พร (U)** ผิวหินศักดิ์สิทธิ์: ทนความเสียหายจากการตกและการกระแทก
- **คำสาป (R)** หินที่ถูกแตะ: ถูกหินบนทางไม่ยอมให้ผ่าน
- **หนุน** PL-07 ×1.5, GI-02 ×1.3, WR-02 ×1.3 **ต้าน** GI-01 ×0.5 (ศรัทธาสูงรักษาหน้าที่เฝ้า) **เปิดเฉพาะ** HP-03 เมื่อผู้เฝ้าบันไดยอมเจรจา

## 14. ศรัทธาเสียงกระซิบ

- **ผู้ศรัทธา** ชาวหมอก นักบวชแห่งเมอลิน คนตาบอดแห่งไอเลวัน (ราว 2%)
- **หลักความเชื่อ** เสียงในหมอกคือความทรงจำของผู้ที่ตายแล้ว ผู้ฟังที่ดีจะได้ความจริงที่คนมีชีวิตไม่รู้
- **พิธี** นั่งฟังเสียงตลอดวัน จดทุกคำ เล่าเสียงให้เด็กฟังก่อนนอน
- **ช่องทาง** D ผิดทาง ศรัทธาไปสู่ความทรงจำของเมืองปฐมที่จมอยู่ ซึ่งเป็นสิ่งเดียวกับที่ถูกรอยแยกเมฆาปลุก
- **นิกายย่อย** *ผู้สงบรอ* (สายเดิม) และ *ผู้พิพากษา* (แตกออกเป็นลัทธิคำพิพากษา ดู [04-movements.md](04-movements.md))
- **พร (U)** หูของผู้ฟัง: ได้ยินเสียงจากที่ไกลและความจริงที่ถูกซ่อน
- **คำสาป (R)** ถูกเรียกชื่อ: ได้ยินเสียงเรียกที่ไม่มีใครอื่นได้ยิน เสี่ยงเดินออกไปหาเสียง
- **หนุน** FG-12 ×1.5, BIO-06 ×1.5, PL-09 ×1.3 **ต้าน** FG-05 ×0.7 ในสายผู้สงบรอ **เปิดเฉพาะ** DM-09 เมื่อมีผู้ฟังที่ได้ยินเสียงลิช

## 15. ศรัทธาฟาโรห์ (บัญชีวิญญาณ)

- **ผู้ศรัทธา** มัมมี่ ผู้รับใช้ในอัมเมนราและมาราซาร์ (ราว 1%)
- **หลักความเชื่อ** ผู้ปกครองชั่วนิรันดร์คือผู้ค้ำโลกหลังความตาย ทุกคนเขียนชื่อไว้ในบัญชีวิญญาณ เพื่อรับใช้ต่อในโลกหน้า
- **พิธี** การทำมัมมี่ สาบานตนในพีระมิดใหญ่ เซ่นไหว้ฟาโรห์ทุกคืนเดือนดับ
- **ช่องทาง** C รั่วแบบกักไว้ ศรัทธาไม่ไหลออก แต่สะสมในบัญชีวิญญาณมาสองพันปี
- **ความลับ** ศรัทธาที่ถูกกักไว้มีปริมาณมหาศาล ถ้าบัญชีถูกทำลาย ศรัทธาทั้งหมดไหลออกพร้อมกันสู่พระเจ้า (เปิด GD-04) หรือถูกผู้ปกครองใช้ทำสิ่งอื่น
- **พร (U)** ลงชื่อไว้: ไม่ถูกลืมหลังความตาย ฟื้นคืนได้ง่ายขึ้น
- **คำสาป (R)** ติดบัญชี: ถูกเรียกกลับมารับใช้เมื่อตาย
- **หนุน** GD-04 ×1.3 (เมื่อบัญชีถูกเปิด) **ต้าน** DM-09 ×0.6 **เปิดเฉพาะ** เหตุการณ์ระดับประเทศที่มัมมี่ล่าธุลีทิพย์เมื่อสงครามธุลีทิพย์ขาดแคลน

## 16. ลัทธิผู้ชี้ทาง

- **ผู้ศรัทธา** ชนผืนทราย ผู้อยู่ในซาร์ฮาดีน ผู้ลี้ภัยทั่วทะเลทราย (ราว 1%)
- **หลักความเชื่อ** ผู้ชี้ทางคนหนึ่งจะมาเปิดดวงตาศิลา และนำคนทั้งทะเลทรายไปสู่น้ำ ศรัทธาของพวกเขาเป็นความหวังรวม
- **พิธี** เฝ้ารอผู้ชี้ทางที่โอเอซิส ทดสอบเด็กที่เกิดในคืนที่ธุลีทิพย์สว่าง
- **ช่องทาง** B ตรง ศรัทธาเก็บสะสมไว้รอผู้ชี้ทาง ถ้าผู้ชี้ทางปรากฏจริง กระแสทั้งหมดไหลสู่พระเจ้าพร้อมกัน
- **นิกายย่อย** *ผู้เฝ้ารอ* และ *ผู้ประกาศ* (ผู้ที่ประกาศว่าใครเป็นผู้ชี้ทาง มีมากกว่าหนึ่งร้อยคนแล้ว ส่วนใหญ่ปลอม)
- **พร (U)** สายตาชี้ทาง: หาเส้นทางและน้ำได้ในที่แห้งแล้ง
- **คำสาป (R)** ผู้ถูกชี้ผิด: ถูกประกาศเป็นผู้ชี้ทางแล้วไม่ใช่
- **หนุน** GD-01 ×2, GD-06 ×1.2 **ต้าน** WR-10 ×0.8 **เปิดเฉพาะ** ผู้ชี้ทางตัวจริงเมื่อกุญแจ "ดวงตาศิลา" ถูกเรียก

## 17. ศรัทธาความฝัน

- **ผู้ศรัทธา** ชาวดรีมมอร์ ผู้ตีความฝัน ฮาล์ฟลิงบางส่วน (ราว 2%)
- **หลักความเชื่อ** โลกนี้คือความฝันของผู้ที่หลับอยู่ใต้ดิน ผู้ตีความฝันคือผู้รับสาร
- **พิธี** นอนในวัดร่วมกัน ตีความฝันของทั้งหมู่บ้านในตอนเช้า ห้ามหลับระหว่างเดินทางผ่านเขตดรีมมอร์
- **ช่องทาง** A ผนึก ไหลสู่อันดาร์โดยตรง ศรัทธาของผู้ฝันคือความฝันของมังกรเอง
- **ความเสี่ยง** ถ้าศรัทธากลายเป็นความกลัว ฝันของอันดาร์กลายเป็นฝันร้าย
- **พร (U)** ฝันจริง: ความฝันบางคืนทำนายเหตุการณ์ใกล้ตัวได้
- **คำสาป (R)** ฝันค้าง: ฝันร้ายตามหลอนในตอนตื่น
- **หนุน** PL-05 ×2, END-05 ×1.3 เมื่อฝันร้ายเกินเกณฑ์ **ต้าน** FG-05 ×0.8 **เปิดเฉพาะ** GD-01 เมื่อผู้ฝันร่วมกันเห็นศาสดาคนเดียวกัน

## 18. ศรัทธาวิญญาณสัตว์

- **ผู้ศรัทธา** เผ่าสัตว์ทุกชนิด ผู้อยู่ป่าและทะเลทราย (ธาลาวิน ไวลด์มาร์ก อัลมา ราว 3%)
- **หลักความเชื่อ** สัตว์ทุกตัวมีวิญญาณผู้พิทักษ์ ผู้ล่าที่ดีต้องขอ ผู้กินที่ดีต้องขอบคุณ
- **พิธี** เต้นรำก่อนล่า ถวายเนื้อชิ้นแรกคืนป่า ไว้ทุกข์ให้เหยื่อ
- **ช่องทาง** C รั่ว ศรัทธาไปสู่วิญญาณสัตว์ ซึ่งไม่ต่อสู่มังกร
- **พร (U)** เสียงฝูงวิญญาณ: สัตว์ในพื้นที่ไม่โจมตีผู้ศรัทธา
- **คำสาป (R)** วิญญาณล่าถอย: สัตว์หนีและเลิกเข้าใกล้
- **หนุน** WR-17 ×1.3, BIO-09 ×1.5 **ต้าน** FG-02 ผลต่อป่า ×0.8 **เปิดเฉพาะ** การล่าครั้งใหญ่ เมื่อสภาธาลาวินประกาศ

## 19. ลางนิยม

- **ผู้ศรัทธา** โจรสลัด นักขุดทอง นักพนัน พ่อค้าเร่ ชาวเรือ (ทอร์ตูโมอา โกลด์ครีก ราว 2%)
- **หลักความเชื่อ** ลางและโชคคือเทพองค์เล็ก ๆ ที่ต้องเอาใจ ไม่มีเทพองค์ใดใหญ่พอจะไว้ใจ
- **พิธี** ผูกริบบิ้นลางดี ห้ามนับคนก่อนออกเรือ โยนเหรียญก่อนเปิดสัญญา
- **ช่องทาง** C รั่ว ศรัทธากระจัดกระจายตามลางแต่ละอัน
- **พร (U)** ฝ่าด้วยลาง: ลางที่ผู้ถือยึดถือมีโอกาสตรงสูงกว่าปกติ
- **คำสาป (R)** ลางร้ายตามตัว: ลางร้ายตามไปทุกที่
- **หนุน** CT-10 ×1.3, HP-04 ×1.3 **ต้าน** DR-11 ×0.6 **เปิดเฉพาะ** การเปลี่ยนศาสนาของโจรสลัดเมื่อเรือสมบัติถูกพบ
