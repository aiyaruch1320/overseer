# กติการูปลักษณ์อาวุธและอาวุธมาตรฐาน

ภาพรวม: [README.md](README.md) · ตัวเลขอาวุธ: [../items/README.md](../items/README.md) · วัสดุ: [../items/02-materials.md](../items/02-materials.md) · ตำนาน: [06-legendary-weapons.md](06-legendary-weapons.md)

อาวุธในโลกนี้มี 816 ชิ้น ไม่มีใครวาดทีละชิ้นได้เหมือนกันหมด ไฟล์นี้จึงให้ **กติกาประกอบภาพ** ที่ทำให้ชิ้นไหนก็ออกมาไม่ซ้ำและอ่านออกจากไกล แล้วบอกรายตัวสำหรับสองกลุ่มที่ผู้เล่นเห็นบ่อยที่สุด คือของใช้ 40 ชิ้นกับอาวุธมาตรฐาน 55 ชิ้น อาวุธประจำอาชีพ ประเทศ ทวีป โรงตี ตำนาน และของเกราะเครื่องประดับเครื่องรางอยู่ในไฟล์ถัดไป

## 1. สูตรประกอบภาพอาวุธ

อาวุธหนึ่งชิ้น = **ทรงตามประเภท** + **สีและผิวตามวัสดุ** + **การตกแต่งตามระดับ** + **เอฟเฟกต์ตามแท็ก** + **ร่องรอยการใช้** ผู้เล่นอ่านลำดับนี้โดยไม่รู้ตัว ทรงบอกว่าใช้อย่างไร สีบอกว่าทำจากอะไร การตกแต่งบอกว่าล้ำค่าแค่ไหน เอฟเฟกต์บอกว่ามีอะไรผิดปกติ ร่องรอยบอกว่าผ่านมือใครมา

กฎสำหรับคนวาด

1. ทรงต้องอ่านออกจากเงาดำ ถ้ากลบสีหมดแล้วบอกไม่ได้ว่าดาบหรือค้อน ทรงนั้นใช้ไม่ได้
2. วัสดุเปลี่ยนสีและผิว ไม่เปลี่ยนทรง ดาบสั้นเหล็กกับดาบสั้นเงินมีเงาเดียวกัน
3. ระดับ C U R ไม่เปลี่ยนทรงเช่นกัน เปลี่ยนเฉพาะรายละเอียด ส่วนอาวุธประจำถิ่นและตำนานมีทรงเฉพาะ
4. เอฟเฟกต์ติดตัวไม่เกินหนึ่งอย่างต่ออาวุธ ถ้ามีหลายแท็กเลือกแท็กที่มาก่อนในตารางหัวข้อ 5
5. ทุกชิ้นต้องมีร่องรอยอย่างน้อยหนึ่งจุด ของใหม่เอี่ยมในโลกนี้ไม่เสมอไป

## 6. ร่องรอยการใช้

ทุกชิ้นมีร่องรอยหนึ่งจากรายการนี้ เลือกตามที่มาที่ตารางต้นทางบอก ร่องรอยไม่ต่างระดับ ของ C ที่ใช้มาสิบปีดูเก่ากว่าของ R ที่เพิ่งตีเสร็จ

| ที่มา | ร่องรอย |
| --- | --- |
| เพิ่งตีเสร็จ | ผิวยังเป็นเส้นขัด ป้ายช่างยังติดอยู่ที่ด้ามหนึ่งจุด |
| ใช้งานประจำ | ด้ามเว้าตามรอยมือ ขอบใบมีรอยลับซ้ำสามถึงห้าครั้ง |
| ผ่านศึก | รอยบิ่นที่คมหนึ่งจุด เศษผ้าหรือสายหนังเก่าผูกซ่อมด้าม |
| สืบทอด | ชื่อเจ้าของเก่าสลักไว้ใต้กั้นหนึ่งชื่อ (ซ้อนทับกันถ้ามีหลายรุ่น) |
| จากสุสานหรือซาก | ดินติดร่องผิวและกลิ่นเย็น มีสนิมหรือคราบสีตามที่ที่ได้มา |
