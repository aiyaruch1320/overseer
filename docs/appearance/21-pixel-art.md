# ภาพพิกเซลและการวาดบนจอ

ภาพรวม: [README.md](README.md) · เผ่า: [02-races.md](02-races.md) · ศัตรู: [04-enemies.md](04-enemies.md) · มังกร: [03-dragons.md](03-dragons.md) · หน้าจอพระเจ้า: [20-god-ui.md](20-god-ui.md) · แผนลงโค้ด: [../guide/code-plan.md](../guide/code-plan.md) หัวข้อ 9 · ตัวทดลองเวกเตอร์เดิม (ที่มาของท่าและชิ้นส่วน): [poc-visuals/README.md](poc-visuals/README.md)

ภาพทุกชิ้นในเกมเป็นพิกเซลอาร์ตที่วาดด้วยโค้ดจาก Look ของเอกสาร แล้วแสดงด้วย WebGL (Phaser) ไม่มีไฟล์ภาพตัวละครวาดมือ ไฟล์นี้เป็นสัญญาของภาพ: ขนาด สี ท่า ซูม และวิธีแสดง พรรณนาของแต่ละสิ่งยังอยู่ในไฟล์ของมัน

## 4. วาดและแสดง

| ที่ | วิธี | ซูม |
| --- | --- | --- |
| ฉากชีวิต ฉากคัตซีน ศึก | Phaser WebGL เวทีขนาด 320 × 180 พิกเซลศิลป์ ฉากหลังหลายชั้นเลื่อนต่างความเร็ว | ขยายเป็นเท่าเต็มที่พอดีจอ (3× ที่ 960 × 540 · 4× ที่ 1280 × 720) · กล่องที่เล็กกว่า 2× (640 พิกเซล) ขยายเต็มความกว้างแบบ pixelated ไม่เต็มเท่า (ภาพ 1× เล็กจนอ่านไม่ออก) |
| แผนที่ระดับเมืองและในเมือง | Phaser WebGL พื้นวาดด้วยโค้ดเป็นแผ่น ตัวละคร บ้าน ต้นไม้เป็นสไปรต์ | ซูมต่อเนื่อง 1× ถึง 8× |
| แผนที่ระดับโลก ทวีป ประเทศ | Phaser WebGL ภาพย่อของระดับนั้นวาดไว้ก่อน ตัวละครและมังกรเป็นไอคอน | ไม่ย่อพิกเซลต่ำกว่า 1× (ย่อแล้วพิกเซลกระพริบ) |
| ภาพเหมือนบนการ์ดและหน้าจอ | เฟรมจากแผ่นสไปรต์เดียวกัน วางบนแคนวาสเล็กใน DOM | 3× |
| หน้าจอ ปุ่ม ข้อความไทย | DOM + CSS ตาม token ของ 20-god-ui.md หัวข้อ 1 ไอคอนเป็น SVG | |

ข้อความไทยไม่วาดลงในภาพพิกเซล ซ้อนเป็น DOM บนเวทีเสมอ

## 6. ภาพสำเร็จ (ชั้นเสริม)

ภาพที่วาดหรือสร้างนอกเกมใช้ได้เฉพาะชิ้นใหญ่ไม่กี่ชิ้น: ฉากหลังของคัตซีน หน้าเริ่ม การ์ดจบชีวิต ภาพแผนที่ระดับโลกและทวีป ใช้สัญญาเดียวกับภาพแผนที่ (code-plan หัวข้อ 8.4) ชิ้นที่ไม่มีภาพใช้แบบวาดด้วยโค้ด ภาพสำเร็จต้องเป็นพิกเซลอาร์ตขนาดตามหัวข้อ 2 และ 4 ไม่ใช้กับตัวละคร NPC ศัตรู (614 NPC × 5 วัย × ทุกท่า ทำให้ลายเส้นตรงกันไม่ได้)

## 7. ที่วัดแล้ว

ห้องทดลอง `art-lab.html` (เปิดด้วย `npm run dev`) วาดตัวละครชุดเดียวกันห้าแบบ วัดด้วย Chrome บน Apple M2 Max ที่ 60 Hz ในวงเล็บคือเมื่อทำ CPU ช้าลง 4 เท่า เวที 1240 × 420 ซูม 3×

| วิธี | 200 ตัว | 1000 ตัว | 3000 ตัว | 200 ตัวขณะซูม |
| --- | --- | --- | --- | --- |
| DOM + CSS (box-shadow) | 60 (60) | 5 (4) | 1 (1) | 20 (14) |
| SVG | 56 (3) | 3 (1) | 1 (0) | 7 (3) |
| Canvas 2D | 60 (60) | 60 (60) | 60 (60) | 60 (60) |
| WebGL (Phaser) | 60 (60) | 60 (60) | 60 (60) | 60 (60) |
| ภาพสำเร็จ + CSS | 60 (60) | 60 (13) | 3 (2) | 58 (20) |

แผนที่ Phaser กับคนเดิน 1500 ตัว 60 (60) · ฉากคัตซีน 60 (60) · แผ่นสไปรต์ 9 แผ่นเป็น PNG รวม 33.5 KB

WebGL ชนะเพราะเร็วเท่ากันทุกจำนวน กิน JS น้อยที่สุด (0.8 มิลลิวินาทีต่อเฟรมที่ 3000 ตัวเมื่อ CPU ช้า) และซูมต่อเนื่องได้ แผนที่ใช้ Phaser อยู่แล้ว ทุกที่ที่มีตัวละครจึงใช้ทางเดียวกัน
