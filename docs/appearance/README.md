# รูปลักษณ์ของโลก

ไฟล์ชุดนี้พรรณนาว่าสิ่งต่าง ๆ ในโลกหน้าตาเป็นอย่างไร ใช้เป็นต้นแบบการออกแบบภาพและ UI ในเกม เนื้อเรื่องอยู่ที่ [../lore/world/story-continents.md](../lore/world/story-continents.md) กฎของโลกอยู่ที่ไฟล์อื่น ๆ ไฟล์นี้ไม่ใส่กฎ ใส่เฉพาะสิ่งที่ตามองเห็น หูได้ยิน และจมูกได้กลิ่น

โค้ดปัจจุบันเป็นตัวทดลอง มีภาพตัวละครแบบเวกเตอร์ ([poc-visuals/README.md](poc-visuals/README.md)) และแผนผังเมือง 143 แบบ (`src/city/flavor.ts`) เมื่อขัดกับเอกสารชุดนี้ ให้เอกสารชนะ

## น้ำเสียงภาพของโลก

โลกนี้ดิบและจริงจัง ไม่ใช้สัดส่วนการ์ตูน ไม่มีเครื่องประดับน่ารัก สีฐานหม่น ความงามมาจากรอยใช้งาน ของที่สึก ผ้าที่ซีด แสงที่ตกอยู่ผิดที่ สีสดมีไว้บอกจุดเด่นเพียงจุดเดียวต่อฉาก ทุกสถานที่มีด้านที่ไม่สบายตา (หนี้ ความหิว ความกลัว ความตาย) และด้านที่งดงามอย่างขัดกัน คนอ่านต้องรู้สึกว่าที่นั่นอยู่ได้จริง และไม่อยากอยู่นานนัก

## กติกาการเขียน

1. เขียนสิ่งที่เห็น ไม่เขียนเหตุผลของเรื่อง เหตุผลอยู่ในไฟล์เรื่องราว
2. ทุกรายการมีห้ามิติ: สิ่งที่เห็น เสียง กลิ่น ของที่สัมผัส และสิ่งที่ผิดปกติ (จุดเดียวที่ทำให้จำได้)
3. ใช้คำที่ UI ใช้ได้ทันที: สี (ชื่อสีและรหัส hex ถ้ามี) วัสดุ รูปทรง แสง สภาพอากาศ
4. ขนาดอ้างเป็นเท่าของมนุษย์
5. หนึ่งรายการต้องต่างจากรายการข้าง ๆ ด้วยสิ่งเดียวที่เห็นได้จากไกล (สีหลัก ทรงหลัก หรือแสงหลัก)
6. ไม่ซ้ำคำพรรณนาข้ามรายการ ถ้าสองที่คล้ายกัน ระบุว่าต่างกันตรงไหน

## วิธีอ่านช่อง ค่า UI

ทุกไฟล์มีช่อง **ค่า UI** ที่เขียนเป็นคำสั้น ๆ คั่นด้วย `·` เพื่อให้คนทำภาพหรือโค้ดหยิบไปใช้โดยไม่ต้องอ่านพรรณนา รูปแบบต่างกันตามชนิด

| ไฟล์ | รูปแบบช่อง ค่า UI |
| --- | --- |
| ทวีป ประเทศ | `styles=` ทรงอาคาร · `roofs=` สีหลังคา hex · `plan=` ผัง · `wall=` กำแพง · `centre=` จุดกลางเมือง · `ambient=` บรรยากาศลอย · `tree=` `farm=` `lamps=` `graves=` และ `extra=` สำหรับของเฉพาะ |
| เผ่า | scale head shoulders ears lower gait skin accent feats |
| มังกร | ขนาด S M L XL · รูปทรง · สีหลัก สีรอง สีตา hex · เอฟเฟกต์ · บรรยากาศลอย |
| NPC | `สี #หลัก #รอง · ของ รายการของติดตัว · ท่า ท่าประจำ` วัยคำนวณจากอายุจริงกับอายุขัยของเผ่า |
| ศัตรู | `ขนาด S–XXL (เท่าของมนุษย์) · ฝูง · สี #หลัก #รอง ตา # · ท่า idle atk die` ตารางจุดอ่อนและเอฟเฟกต์โจมตีอยู่ในหัวข้อต้นของไฟล์ |
| อาวุธ เกราะ เครื่องราง | `ทรง · ยาวหรือขนาดเทียบมนุษย์ · สี #หลัก #รอง (แสง #) · เอฟเฟกต์ · ท่าหรือตำแหน่ง` |

## คำของโค้ดที่ UI ใช้ตอนนี้

ใช้เป็นคำเชื่อมระหว่างคำพรรณนากับภาพ ไฟล์ที่เขียนแล้วอ้างคำเหล่านี้ในช่อง "ค่า UI" ทั้งคำไทยและรหัสในโค้ด (ตัวอักษรเล็กอังกฤษ) ไฟล์ประเทศใช้รหัสเพราะอ่านเข้าไปในโค้ดได้โดยตรง

| ทรงอาคาร `styles=` | จั่ว = `gable` · โดม = `dome` · กระท่อม = `hut` · ทรงเอ = `aframe` · ต้นไม้ = `tree` · หิน = `stone` · เต็นท์ = `tent` · ยกพื้น = `stilt` · อิฐ = `brick` · ยอดแหลม = `spire` · เตาหลอม = `forge` · เห็ด = `mushroom` · ป้อม = `keep` · ขั้นบันได = `terrace` · ดินเหนียว = `adobe` · แกะสลัก = `carved` · เมืองบูม = `boomtown` · โพรง = `burrow` · หอคอย = `tower` |

| กลางเมือง `centre=` | น้ำพุ = `fountain` · รูปปั้น = `statue` · เตา = `forge` · เฟือง = `gear` · โอเอซิส = `oasis` · กองไฟ = `bonfire` · นาฬิกา = `clock` · กล้าไม้ = `sapling` · ต้นไม้โลก = `worldtree` · ปากเหว = `abyss` · ซากอาร์เคีย = `arkea` · ประตู = `gate` · ทะเลสาบ = `lake` · เรือเหาะ = `airship` · ประภาคาร = `lighthouse` · สภา = `council` · พีระมิด = `pyramid` · ผลึก = `crystal` · เสาหิน = `obelisk` · รังฟ้า = `skynest` · ปล่องภูเขาไฟ = `caldera` · บันไดประตู = `stairgate` · พระราชวังคู่ = `twinpalace` · อีริดาน = `eridan` · ปั๊ม = `pump` · ยอดฝน = `rainspire` · รอกเหมือง = `liftmine` · หอคอย = `tower` · ไม่มี = `none` |

## ข้อควรรู้ก่อนนำไปใช้

- ไฟล์นี้ชนะโค้ดเมื่อขัดกัน ถ้าพบค่า `centre=` หรือ `styles=` ที่โค้ดยังไม่รู้จัก ให้เพิ่มในโค้ด ไม่ต้องแก้ไฟล์
- ความสูงและขนาดทั้งหมดเป็นเท่าของมนุษย์ ไม่ใช่พิกเซล ขนาดพิกเซลของสไปรต์ให้ตัดสินตอนทำภาพ
- สีทุกค่าเป็นสีฐานของวัตถุ ยังไม่รวมแสงและบรรยากาศ ต้นแบบแสงของฉากอยู่ใน [01-continents.md](01-continents.md)
- พรรณนาเขียนจากข้อมูลไฟล์ต้นทางในวันที่เขียน ถ้าไฟล์ต้นทางเปลี่ยนชื่อ อายุ หรือเผ่า ให้ตามไปแก้แถวนั้นในไฟล์นี้ตามรหัส
