# รูปลักษณ์ของโลก

ไฟล์ชุดนี้พรรณนาว่าสิ่งต่าง ๆ ในโลกหน้าตาเป็นอย่างไร ใช้เป็นต้นแบบการออกแบบภาพและ UI ในเกม เนื้อเรื่องอยู่ที่ [../story-continents.md](../story-continents.md) กฎของโลกอยู่ที่ไฟล์อื่น ๆ ไฟล์นี้ไม่ใส่กฎ ใส่เฉพาะสิ่งที่ตามองเห็น หูได้ยิน และจมูกได้กลิ่น

โค้ดปัจจุบันเป็นตัวทดลอง มีภาพตัวละครแบบเวกเตอร์ ([../visuals/README.md](../visuals/README.md)) และแผนผังเมือง 143 แบบ (`src/city/flavor.ts`) เมื่อขัดกับเอกสารชุดนี้ ให้เอกสารชนะ

## น้ำเสียงภาพของโลก

โลกนี้ดิบและจริงจัง ไม่ใช้สัดส่วนการ์ตูน ไม่มีเครื่องประดับน่ารัก สีฐานหม่น ความงามมาจากรอยใช้งาน ของที่สึก ผ้าที่ซีด แสงที่ตกอยู่ผิดที่ สีสดมีไว้บอกจุดเด่นเพียงจุดเดียวต่อฉาก ทุกสถานที่มีด้านที่ไม่สบายตา (หนี้ ความหิว ความกลัว ความตาย) และด้านที่งดงามอย่างขัดกัน คนอ่านต้องรู้สึกว่าที่นั่นอยู่ได้จริง และไม่อยากอยู่นานนัก

## กติกาการเขียน

1. เขียนสิ่งที่เห็น ไม่เขียนเหตุผลของเรื่อง เหตุผลอยู่ในไฟล์เรื่องราว
2. ทุกรายการมีห้ามิติ: สิ่งที่เห็น เสียง กลิ่น ของที่สัมผัส และสิ่งที่ผิดปกติ (จุดเดียวที่ทำให้จำได้)
3. ใช้คำที่ UI ใช้ได้ทันที: สี (ชื่อสีและรหัส hex ถ้ามี) วัสดุ รูปทรง แสง สภาพอากาศ
4. ขนาดอ้างเป็นเท่าของมนุษย์
5. หนึ่งรายการต้องต่างจากรายการข้าง ๆ ด้วยสิ่งเดียวที่เห็นได้จากไกล (สีหลัก ทรงหลัก หรือแสงหลัก)
6. ไม่ซ้ำคำพรรณนาข้ามรายการ ถ้าสองที่คล้ายกัน ระบุว่าต่างกันตรงไหน

## คำของโค้ดที่ UI ใช้ตอนนี้

ใช้เป็นคำเชื่อมระหว่างคำพรรณนากับภาพ ไฟล์ที่เขียนแล้วอ้างคำเหล่านี้ในช่อง "ค่า UI"

| ชนิด | ค่าที่โค้ดรู้จัก |
| --- | --- |
| ทรงอาคาร | จั่ว โดม กระท่อม ทรงเอ ต้นไม้ หิน เต็นท์ ยกพื้น อิฐ ยอดแหลม เตาหลอม เห็ด ป้อม ขั้นบันได ดินเหนียว แกะสลัก เมืองบูม โพรง หอคอย |
| ผังเมือง | ตาราง อินทรีย์ รัศมี คลอง |
| กำแพง | หิน ไม้ปัก พุ่มไม้ เหล็ก ไม่มี |
| กลางเมือง | น้ำพุ รูปปั้น เตา เฟือง โอเอซิส กองไฟ นาฬิกา กล้าไม้ ต้นไม้โลก ปากเหว ซากอาร์เคีย ประตู ทะเลสาบ เรือเหาะ ประภาคาร สภา พีระมิด ผลึก เสาหิน รังฟ้า ปล่องภูเขาไฟ บันไดประตู พระราชวังคู่ อีริดาน |
| บรรยากาศลอย | ไม่มี ถ่านร้อน หมอก ใบไม้ ควัน ทราย เมฆ นกนางนวล เถ้า ฝุ่น ประกายแสง |
| ต้นไม้ | โอ๊ก สน ปาล์ม ตาย ป่าดิบ กระบองเพชร ไม่มี |
| หูของเผ่า | กลม ยาว แหลม สัตว์ ครีบ ไม่มี |
| ท่อนล่าง | สองขา หางงู ชายผ้า ก้อนเจล |
| ท่าเดิน | ปกติ หนัก ลื่น กระโดด ลากเท้า ลอย |

## แผนทำต่อ

เรียงตามประโยชน์ต่อ UI: ประเทศในอัซการ์ (10) ตามด้วยทวีปที่เหลือทีละทวีป จากนั้น NPC ที่มีบทบาทในเส้นเรื่อง (ตัวที่ 1 ของแต่ละประเทศ) แล้วศัตรู อาวุธระดับตำนาน (36) และเกราะกับเครื่องรางโบราณ ส่วนอาวุธทั่วไปใช้กฎตามวัสดุและระดับ ไม่เขียนรายตัว
