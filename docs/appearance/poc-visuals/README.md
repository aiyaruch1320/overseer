# ภาพและอนิเมชันตัวละคร

**สถานะ** เอกสารชุดนี้อธิบายภาพเวกเตอร์ของตัวทดลอง (POC) ที่วาดด้วยโค้ด ไฟล์ [../README.md](../README.md) และไฟล์พี่น้องเป็นแหล่งอ้างอิงหน้าตาที่ใหม่กว่า เมื่อขัดกัน ไฟล์ใหม่ชนะ ไฟล์ที่สร้างจากโค้ดของชุดนี้อยู่ที่ [../../_generated/poc-visuals/](../../_generated/poc-visuals/races.md)

ตัวละครทุกตัวในเมืองวาดเป็นภาพเวกเตอร์ด้วยโค้ด (`src/render/characters/`) ไม่ใช่พิกเซลอาร์ตตายตัว ภาพวาดใหม่ตามความละเอียดที่กล้องต้องการ ซูมออกเห็นตัวเล็กชัด ซูมเข้า 160 เท่าเห็นกระดุม ลายผ้า ประกายตา รอยแผล และขนนกทีละเส้น

เอกสารที่เกี่ยวข้อง: ชีวิตประจำวันของ NPC ในเมือง [npc-life.md](npc-life.md) · ถิ่นเกิดของ NPC ทั้ง 591 ตัว [../../_generated/poc-visuals/birthplaces.md](../../_generated/poc-visuals/birthplaces.md) · ธีมทั้ง 21 เผ่า [../../_generated/poc-visuals/races.md](../../_generated/poc-visuals/races.md) · NPC พิเศษ [../../_generated/poc-visuals/specials.md](../../_generated/poc-visuals/specials.md) · เผ่าพันธุ์ [../../lore/races/README.md](../../lore/races/README.md) · NPC [../../lore/npcs/README.md](../../lore/npcs/README.md) · เส้นเรื่อง (ช่วงชีวิต) [../../lore/storylines/README.md](../../lore/storylines/README.md)

ดูของจริงได้ที่ `/characters.html` เมื่อรัน `npm run dev` มีครบทั้ง 21 เผ่า สายเลือดย่อย 5 ช่วงวัย ทุกท่าทาง อนิเมชัน และ NPC พิเศษ ปรับความละเอียด เพศ ชุด อาชีพได้ และใส่ `?sheet=mummy,ghoul&ppu=4` เพื่อเทียบเผ่าข้างกัน

## วิธีที่ภาพถูกสร้าง

| ชั้น | ไฟล์ | ทำอะไร |
| --- | --- | --- |
| ท่าทาง | `pose.ts` | ท่าเป็นตัวเลข (เท้า มือ ตัวโยก เอน นั่ง หน้าตา) 55 ท่า รวมท่าทำงานประจำอาชีพ ไม่ใช่ภาพ จึงใช้ร่วมกันได้ทุกเผ่า ทุกชุด ทุกวัย |
| ธีมเผ่า | `themes.ts` | สัดส่วน สี หู ท่อนล่าง ท่าเดิน ลักษณะเฉพาะ สายเลือดย่อย ท่าประจำเผ่า |
| ตัววาด | `paint.ts` `feat.ts` `gear.ts` | หนึ่งท่าของหนึ่งคน: ขาและแขนใช้ IK สองท่อน ชุด 26 แบบ ผม 14 ทรง หมวก 21 แบบ เครื่องมือ 30 ชนิด ปีก หาง เขา ฮู้ด รอยแตกลาวา แผ่นเหล็ก ผ้าพัน |
| สไปรต์ | `sprite.ts` | `PersonImage` ใช้แทน Image ธรรมดาใน Phaser วาดท่าตามที่ต้องใช้ แล้วเปลี่ยนความละเอียด 4 ระดับ (20 ถึง 160 พิกเซลกว้าง) ตามการซูม |
| ภาพนิ่ง | `portrait.ts` | วาดลงแคนวาสธรรมดา ใช้ในหน้า gallery และการ์ด |
| ผู้คน | `src/scenes/people.ts` | สุ่มลักษณะจาก seed ตามเผ่า สายเลือด วัย บทบาท ภูมิอากาศ |
| NPC พิเศษ | `src/data/specials.ts` | 36 ตัวออกแบบมือ มีภาพทุกช่วงวัย |
| NPC ทั้ง 572 | `src/data/cast.ts` + `npcCast.ts` | อ่านจาก `docs/lore/npcs` แล้วแปลงเป็นลักษณะ (`npm run docs:cast` สร้างตารางใหม่เมื่อเอกสารเปลี่ยน) |

หน่วยวาดคือ "unit": เฟรมกว้าง 56 สูง 92 หน่วย หนึ่งหน่วยเท่ากับหนึ่งในสามของพิกเซลเมือง ผู้ใหญ่สูงราว 56 หน่วย

## แนวภาพ: จริงจัง สมจริง สีกลมกลืน

เรื่องเป็นโลกดิบ จึงไม่ใช้สัดส่วนการ์ตูน

- **สัดส่วน** หัวสูงราวหนึ่งในห้าครึ่งของตัว ขายาว ไหล่กว้าง เด็กและทารกหัวโตตามวัยจริง ไม่ได้โตเกินจริง
- **ใบหน้า** ตาเล็กรูปอัลมอนด์ กว้างราวหนึ่งในห้าของหัว อยู่ที่กึ่งกลางความสูงหัว ตามสัดส่วนใบหน้ามาตรฐาน ([Proportions of the Head](https://artyfactory.com/portraits/pencil-portraits/proportions-of-a-head.html)) มีเปลือกตาบนหนา รอยพับ คิ้วที่หนักและหน้านิ่ง จมูกมีสันและปีก ริมฝีปากมีเงา แก้มและกรามมีแสงเงาจากด้านซ้ายบน ไม่มีแก้มแดงแบบการ์ตูน ผู้เฒ่ามีรอยจากจมูกถึงปาก
- **สี** ฐานสีหม่น สีสดมีเฉพาะจุดเด่น ([Value over color](https://www.scribd.com/doc/298310210/Dot-a-2-Character-Art-Guide)) ทุกคนสวม "สีหลักหนึ่งสี กับสีขลิบหนึ่งสี" จากชุดสีของอาชีพ (ขุนนางสีอัญมณีเข้มกับทอง นักบวชสีครีมกับทอง ทหารเกราะเหล็กกับสีประจำบ้าน นักเวทน้ำเงินม่วงเข้ม) และของเผ่า (เอลฟ์เขียวป่า คนแคระน้ำตาลสนิม แวมไพร์ดำแดงเลือดหมู) ไม่มีสีสุ่มที่ขัดกัน ผมและตามนุษย์เป็นสีธรรมชาติ
- **ไม่มีเครื่องประดับน่ารัก** ไม่มีดอกไม้บนหัว ผูกผมสีเข้มแทนโบว์แดง
- **สไลม์ไม่มีตา** ตัวเป็นเจลโปร่งแสงสูงเท่าคน มีนิวเคลียสเรืองแสงเต้นอยู่ข้างใน ของที่กลืนลอยอยู่ แขนเป็นเส้นเจลเรียวไม่มีมือ ออกแบบตามสัตว์เจลที่รับรู้ด้วยทั้งร่างกายแทนตา ([Ooze](https://d20srd.org/srd/monsters/ooze.htm))

## ช่วงชีวิต

แบ่งตามอายุเทียบมนุษย์ (`hAge`) ตามเส้นเรื่อง ใช้กับทุกเผ่าเท่ากัน เผ่าอายุยืนจึงแก่ช้ากว่าในปีจริงแต่ผ่านช่วงเดียวกัน

| ช่วง | hAge | ที่ภาพเปลี่ยน |
| --- | --- | --- |
| ทารก | 0–3 | นั่งห่อผ้า หัวโต ตาโต มือชูขึ้น ในเปลไม้เมื่อเป็นตัวละครหลัก |
| เด็ก | 4–12 | ตัวเล็ก หัวโตสุด เสื้อธรรมดา วิ่งและเล่น |
| วัยรุ่น | 13–19 | ผอมสูงขึ้น ยังไม่มีเครา ได้อาวุธประจำตัว |
| ผู้ใหญ่ | 20–54 | สัดส่วนเต็ม เครื่องทรงและอาชีพ |
| ผู้เฒ่า | 55+ | หลังค่อม ผมและเคราขาว ไม้เท้า รอยตีนกา หูเอลฟ์ตก นั่งพักบ่อย |

## ท่าทางและอนิเมชัน

เดินใช้วงจรสี่ท่าหลักของงานอนิเมชัน (contact, down, passing, up) สุ่มตัวอย่างแปดเฟรม ตัวขึ้นลงตามจังหวะ เท้าสลับยกสูง แขนแกว่งสวน ศีรษะเอียงตามเล็กน้อย

| กลุ่ม | ท่า |
| --- | --- |
| ยืน | `idle` `breath` `idle2` `idle3` (หายใจ หางและแสงขยับตามเฟส) |
| เดิน | `walk0`–`walk7` · แบกของ `carry0`–`carry2` |
| ทำงาน | `work0` ยก · `work1` ฟาด · `work2` พัก |
| นั่ง คุกเข่า | `sit` `sit2` · `kneel` `kneel2` (หลับตาสวด) |
| อารมณ์ | `cheer` `cheer2` · `wave0` `wave1` · `talk0` `talk1` |
| ศาสตร์ | `read` · `cast0` `cast1` (ปีกกางเต็มเมื่อร่ายเวท) · `flutter0` `flutter1` (ภูตลอยและกระพือ) |

ท่าประจำเผ่าทำเมื่อมีเวลาว่าง (โอกาส 10% ต่อรอบ) เช่น เผ่าปีกกางปีกยืดเส้น คนแคระทุบทั่งในอากาศ ออร์คทุบอกคำราม ดูทั้งหมดที่ [../../_generated/poc-visuals/races.md](../../_generated/poc-visuals/races.md) NPC พิเศษหลายตัวมีท่ายืนของตัวเอง (`sig`) เช่น ไอรัสวาร์คุกเข่าสลับยืนนิ่ง ซาเลห์เล่านิทานด้วยมือ ไวรอน-1 เอียงคอแล้วอ่านหนังสือ

เอฟเฟกต์ที่วาดในภาพเอง ไม่ใช่อนุภาคแยก: ประกายภูต ถ่านลาวาลอยขึ้น ไอน้ำจากข้อต่อจักรกล ธุลีมัมมี่ โน้ตเพลงไซเรน หยดน้ำ ควันมังกร ฮู้ดนาคาแผ่ตามลมหายใจ แกนวิญญาณหุ่นเต้นเป็นจังหวะ

## NPC

NPC ของโลกมี 572 ตัว (`docs/lore/npcs`) ทุกตัวได้ลักษณะเฉพาะจากสิ่งที่เอกสารบอก: เผ่าและสายเลือด (อาเวียนขาวมีรัศมี ปีกราตรีมีปีกค้างคาว) อายุ (คิดตามอายุขัยของเผ่า ฟาโรห์สี่พันปีจึงแก่ แต่เอลฟ์พันปีไม่) เพศเมื่อชื่อหรือบทบาทบอก และบทบาท (ราชามีเครื่องทรง ช่างตีมีค้อนและผ้ากันเปื้อน) ในเกม NPC อยู่ในเมืองหลวงของประเทศตัวเอง ผู้นำปรากฏเสมอ ตัวอื่นตามโอกาสที่เอกสารให้ไว้

36 ตัวสำคัญออกแบบด้วยมือ ต่างจากตัวที่สร้างอัตโนมัติ มีภาพตั้งแต่ทารกถึงผู้เฒ่า รายละเอียดใน [../../_generated/poc-visuals/specials.md](../../_generated/poc-visuals/specials.md) เพิ่มตัวใหม่โดยเติมที่ `SPECIALS` ใน `src/data/specials.ts` แล้วรัน `npm run docs:visuals`

## เพิ่มเผ่าหรือลักษณะใหม่

1. เพิ่มธีมใน `THEMES` (สี หู ท่อนล่าง `feats` สายย่อย `gesture`)
2. ถ้าต้องการลักษณะที่ยังไม่มี เขียนฟังก์ชันใน `feat.ts` หรือ `paint.ts` แล้วเรียกเมื่อ `feats.has('ชื่อ')`
3. เปิด `/characters.html?race=รหัส` ตรวจทุกท่าและทุกวัย แล้วรัน `npm run docs:visuals`

เผ่าที่ยังไม่อยู่ใน `src/data/races.ts` (เผ่าปีก ยักษ์ เผ่าลาวา ลูกผสมจักรกล หุ่นวิญญาณ มัมมี่ กูล) วาดได้แล้วทั้งหมด แต่ระบบจำลองยังไม่สุ่มให้เกิด เมื่อเพิ่มใน `RACES` ภาพจะใช้ได้ทันที

## ที่มาของการออกแบบ

- วงจรเดิน: ท่า contact / down / passing / up จากหลักอนิเมชัน 2D [Walk cycle](https://en.wikipedia.org/wiki/Walk_cycle) และบทเรียน [Walk cycles (BMCC)](https://openlab.bmcc.cuny.edu/ani-260-1300-intro-2d-animation-sp-2021/?p=386) ท่า up สูงกว่าที่คิด และท่า down ลึกให้ตัวรู้สึกมีน้ำหนัก แต่ละเผ่าเดินไม่เหมือนกัน (ก้าวหนักของยักษ์และออร์ค ลื่นไหลของเอลฟ์และนาคา กระโดดของฮาล์ฟลิงและสไลม์ ลากเท้าของมัมมี่และกูล ลอยของภูต)
- สัดส่วน: ปรับจากแบบ chibi รุ่นแรก ([Chibi body ratio](https://tips.clip-studio.com/es-es/articles/4806?org=1)) มาเป็นราวห้าหัวครึ่งตามคำขอให้ดูจริงจัง เด็กยังหัวโตกว่าผู้ใหญ่
- ภาษารูปทรงของเผ่า: ออกแบบจากเงา (silhouette) ก่อน คนแคระเป็นสี่เหลี่ยมหนัก เอลฟ์เรียวหูยาว นาคาเป็นขดยาว เผ่าปีกกว้างบนไหล่ ตาม [Fantasy Races Concept Art Tutorial](https://tips.clip-studio.com/es-es/articles/3340?org=1) และ [วิธีออกแบบคนแคระ](https://artwod.com/blog/how-to-draw-unique-dandd-characters-design-secrets-for-a-dwarf-druid)
- แรงบันดาลใจของแต่ละเผ่า (ฟาโรห์อียิปต์ นาคาของไทย ผู้ปรนนิบัติมังกร) มาจากเอกสาร [../../lore/races/README.md](../../lore/races/README.md) และเส้นเรื่อง

## ข้อจำกัดที่รู้

- ซูมเมืองลึกสุด 160 เท่า (ปรับที่ `Z.max` ใน `WorldScene.ts`) ไอคอนและตัวหนังสือเหนือหัวยังเป็นพิกเซลเดิม
- ตัวละครหันหน้าตรงเอียงเล็กน้อยแล้วพลิกซ้ายขวา ยังไม่มีมุมหลังหรือมุมข้าง
- ท่าต่อสู้เต็มรูปแบบ (ฟัน ป้อง ล้ม) ยังใช้ท่าทำงานและคุกเข่าแทน

## ลูกครึ่ง

ลูกครึ่ง ([../../lore/storylines/22-halfblood.md](../../lore/storylines/22-halfblood.md)) ใช้รูปร่างและชุดของเผ่าที่เลี้ยงดู แล้วรับลักษณะเด่นของเผ่าที่สองเข้ามาแค่หนึ่งหรือสองอย่าง (`src/data/blood.ts`): หู (หูกึ่งแหลม หูสัตว์ หูครีบ) หาง เขา เขี้ยว เหงือกและเกล็ด ลายรอยร้าวลาวา สีผิวและตาบางส่วน ไม่ใส่ชุดทั้งชุดของเผ่าที่สอง คนเลยยังดูเป็นคนก่อน ตัวที่เนื้อเรื่องพูดถึงตรง ๆ 22 ตัวออกแบบมือใน `src/data/specialsHalf.ts` ส่วนลูกครึ่งอื่น ๆ ในเอกสาร NPC ถูกอ่านจากข้อความ "ครึ่ง…" "เลือดผสม" แล้วสร้างอัตโนมัติ

ถิ่นเกิดของทุกคนอ่านจากตารางกำเนิด ([../../systems/character/01-origin.md](../../systems/character/01-origin.md) หัวข้อ 3 และ 4) ผ่าน `npm run docs:birth` และกติกาใน `src/data/birth.ts` ผลอยู่ใน [../../_generated/poc-visuals/birthplaces.md](../../_generated/poc-visuals/birthplaces.md) และเลื่อนเมาส์บน NPC ในเมืองจะเห็น "เกิดที่ …" ภูมิอากาศของถิ่นเกิดมีผลต่อเสื้อผ้า
