# ภาพและ UI ของเหตุการณ์โลก 152 รายการ

ภาพรวม: [README.md](README.md) · เนื้อหาเหตุการณ์: [../systems/events/world-events.md](../systems/events/world-events.md) · มหาเหตุการณ์ที่เปลี่ยนรูปทวีป: [11-world-changes.md](11-world-changes.md) · การจำลอง: [../systems/simulation/world-sim.md](../systems/simulation/world-sim.md)

เหตุการณ์ในคลัง [../systems/events/world-events.md](../systems/events/world-events.md) มีเนื้อหาครบแต่ไม่ได้บอกว่าผู้เล่นเห็นอะไร ไฟล์นี้บอกรูปแบบการแสดงของทุกเหตุการณ์ในหนึ่งบรรทัด เพื่อให้คนทำ UI รู้ว่าต้องทำฉากใหญ่ ชั้นบนแผนที่ ฉากย่อยในเมือง หรือแค่การ์ด

## รูปแบบการแสดง 4 แบบ

| รหัส | รูปแบบ | ขนาดงาน | ใช้เมื่อ |
| --- | --- | --- | --- |
| X | ฉากเต็มจอ | ฉากแอนิเมชัน 20–40 วินาที ตามไวยากรณ์ใน [11-world-changes.md](11-world-changes.md) 1.2 | ⭐ ที่เปลี่ยนรูปทวีป จุดจบ การประกาศสำคัญ |
| M | ชั้นแผนที่ | ชั้นสีหรือเส้นบนแผนที่โลก ค้างตามระยะเวลาเหตุการณ์ ไม่มีฉากเต็มจอ | สงคราม การค้า ภัยที่แผ่เป็นพื้นที่ |
| L | ฉากท้องถิ่น | ฉากสั้น 8–12 วินาทีที่ประเทศหนึ่ง ใช้เมื่อผู้เล่นอยู่ใกล้หรือเกี่ยวข้อง | เหตุการณ์ที่เกิดกับคนหรือสถานที่ |
| C | การ์ดและเสียง | การ์ดภาพนิ่งหนึ่งใบพร้อมเสียง 3–5 วินาที | เหตุการณ์เล็ก ไม่เปลี่ยนภาพโลก |

## 1. มังกรปฐมและห้าผู้อาวุโส (DR) — 15 เหตุการณ์

| --- | --- | --- |
| **DR-01** ⭐ ฟ้าถล่ม | ฉากเต็มจอ | ดูฉากเต็มใน [11-world-changes.md](11-world-changes.md) 2.1 เกาะลอยฟ้าร่วงทั้งทวีป |

| **DR-03** ● ไข่ใบที่สิบหก | ฉากท้องถิ่น | รังฟ้าลึกสุด ไข่ใหญ่เท่าบ้านเรืองมุกอุ่น ผู้ปรนนิบัติล้อมเป็นวงเงียบ เสียงหัวใจเล็กเต้นสองจังหวะ |
| **DR-04** ⭐ ฤดูหนาวเถ้า | ฉากเต็มจอ | ดู 11-world-changes 2.2 ภูเขาไฟดับและเถ้าบังฟ้า |
| **DR-05** ⭐ มหาน้ำขึ้น | ฉากเต็มจอ | ดู 11-world-changes 2.3 น้ำขึ้นกลืนชายฝั่ง |
| **DR-06** ● ลมหยุดหายใจ | ชั้นแผนที่ | ธงและใบเรือทั่วแผนที่ตกนิ่งทุกลำ ปล่อยละอองลอยหายจากฉาก เรือพายถูกใช้แทนเรือใบ ลมสุ่มกลับมาเป็นพายุฉับพลันหลายปีหลัง |
| **DR-07** ⭐ แผ่นดินแยก | ฉากเต็มจอ | ดู 11-world-changes 2.4 หุบเหวผ่าทุ่งราบ |
| **DR-08** ● วันคืนปั่นป่วน | ชั้นแผนที่ | ฟ้าบนแผนที่กระพริบสลับสว่างและมืดเป็นแถบตามภูมิภาค ดวงอาทิตย์สีดำมีขอบขาวบ่อยขึ้น แสงเงาของเมืองสลับด้านทุกไม่กี่นาที |
| **DR-09** ● สงครามธาตุ | ชั้นแผนที่ | เส้นสองสีของธาตุตรงข้ามพุ่งชนกันกลางแผนที่ เช่น ส้มกับฟ้า ผลคือเมฆพายุคู่ ฟ้าผ่าและน้ำท่วมซ้อนกัน |
| **DR-10** ● มังกรแปลงกาย | ฉากท้องถิ่น | ร่างมังกรเล็กลงเรื่อย ๆ ในฉาก กลายเป็นร่างมนุษย์แสงสีมังกรจางที่ตา เกล็ดร่วงเป็นฝนเล็ก ชาวเมืองเปิดทางให้ |
| **DR-11** ● พิธีสังเวยมหาศักดิ์สิทธิ์ | ฉากเต็มจอ | ทุกเมืองส่งขบวนบรรณาการ เส้นทองและแสงไหลจากทุกประเทศเข้าสู่ที่นอนของมังกรสิบห้า ผู้อาสาเดินเป็นแถวขาว มังกรหันมามองทีละตัว |
| **DR-12** ● มังกรป่ากบฏ | ชั้นแผนที่ | จุดมังกรป่าสีแดงเพิ่มทั้งแผนที่พร้อมกัน บินเป็นฝูงออกจากรัง ตาสว่างพร้อมกัน |
| **DR-13** ● ผู้ฆ่ามังกรตำนาน | ฉากท้องถิ่น | ผู้กล้ายืนบนซากมังกรตำนาน เกล็ดตำนานเรืองสุดท้ายแล้วดับ ฟ้าเปลี่ยนสีตามธาตุของมังกร |
| **DR-14** ● เสียงมังกรสิบห้า | ฉากเต็มจอ | จอมืดครู่หนึ่ง ได้ยินสิบห้าเสียงซ้อนกัน ตัวอักษรปริศนาเก้ากุญแจเรืองขึ้นกลางจอทีละบรรทัด |
| **DR-15** ⭐ คลื่นไว้อาลัย | การ์ดและเสียง | คลื่นไว้อาลัย ดู 11-world-changes หัวข้อ 3 แผนที่สั่นเป็นวงและสีซีดสั้น ๆ พร้อมเสียงระฆัง |

## 2. มังกรเสาตื่น (PL) — 9 เหตุการณ์

| ID · ชื่อ | รูปแบบ | ภาพและ UI |
| --- | --- | --- |
| **PL-01** ● อีริดานตื่น | ชั้นแผนที่ | เกาะลอยฟ้าสั่น เมฆแยกเป็นวงแล้วอีริดานเหินขึ้นเหนือเมฆ (เห็นเฉพาะปีกและเงา ไม่ใช่ตัวเต็ม) |
| **PL-02** ● ฮรอด-กาธตื่น | ฉากท้องถิ่น | ฮรอด-กาธอ้าปากกลืนร่างจอมมาร ควันดำพุ่ง จอมมารคนใหม่ปรากฏด้วยแสงแดงจางที่ตา |
| **PL-03** ● คัลดราตื่น | ชั้นแผนที่ | เส้นส้มสว่างบนแผนที่ไล่ตามทางเหมืองทั่วทวีป ปากเหวทุกแห่งขยายสีแดง |
| **PL-04** ● ธาลาสซาตื่น | ฉากท้องถิ่น | วังวนสีฟ้าเข้มเกิดกลางทะเล หมุนช้าแล้วเร็ว เรือเล็กเป็นแถวถูกดูดทีละลำ |
| **PL-05** ● อันดาร์ตื่น | ชั้นแผนที่ | ทั้งทวีปมีไอสีม่วงอ่อนลอยเหนือหลังคา ผู้คนในฉากหยุดนิ่งและเดินละเมอพร้อมกัน |
| **PL-06** ● เซเรเนตื่น | ฉากท้องถิ่น | ท่อน้ำมันดำระเบิดเป็นแถวตามโรงงาน ไฟฟ้าสีฟ้าชักและควันดำเป็นเส้นพุ่งขึ้น |
| **PL-07** ● กรอม-ธารตื่น | ชั้นแผนที่ | เส้นขอบภูเขาบนแผนที่ขยับเล็กน้อย ยักษ์ในฉากหยุดงานและเงยหน้ามองภูเขาพร้อมกัน |
| **PL-08** ● ซิลเวราตื่น | ฉากท้องถิ่น | ต้นไม้เขียวสดงอกเร็วเป็นกำแพงกลืนด่านชายแดน เถาวัลย์ปีนหอ |
| **PL-09** ● นิเวรีตื่น | ชั้นแผนที่ | หมอกไหลออกเป็นคลื่นขาวข้ามชายแดนหนึ่งฤดูแล้วถอยกลับ เสียงระฆังไกลเมื่อหมอกผ่านเมือง |
