# ขนาดเมือง ที่ประทับ และศาสนสถาน 143 ประเทศ

ภาพรวม: [../README.md](../README.md) · ไฟล์ประเทศในทวีป: [01-azgar.md](01-azgar.md) ถึง [09-nebulia.md](09-nebulia.md) · ตัวชี้วัดความมั่งคั่ง: [../../economy/02-countries.md](../../economy/02-countries.md) · ศาสนา: [../../religions/03-regional-faiths.md](../../religions/03-regional-faiths.md) · สงคราม การป้องกัน กฎหมาย จุดเด่นของเมือง: [11-context-and-landmarks.md](11-context-and-landmarks.md)

ไฟล์ทวีปบอก **สิ่งที่เป็นเอกลักษณ์** ของแต่ละประเทศ ไฟล์นี้บอก **ขนาดและความสมเหตุสมผล** ว่าเมืองที่รวยต้องดูรวย เมืองที่จนต้องดูจน เมืองที่ถือศาสนาต้องมีที่ให้บูชา เมื่อค่า UI ในไฟล์ทวีปขัดกับไฟล์นี้ ให้ใช้ขนาดและจำนวนจากไฟล์นี้ แล้วคงชนิดอาคารและสีจากไฟล์ทวีป

## กติกา

### 1. ขนาดเมืองตาม W

W คือความมั่งคั่ง 1 ถึง 5 จาก [../../economy/02-countries.md](../../economy/02-countries.md) ค่าก่อนลูกศรคือค่าตอนต้นยุค ค่าหลังลูกศรคือค่าหลังเหตุการณ์ใหญ่ ถ้าสองค่าต่างกันให้ใช้ค่าหลังเมื่อเหตุการณ์นั้นเกิดแล้ว

| ขนาด (`scale=`) | จำนวนอาคารคร่าว ๆ และโครงสร้าง |
| --- | --- |
| 1 ค่ายหรือหมู่บ้านใหญ่ | 20–50 หลัง ไม่มีกำแพงถาวร ลานกลางลานเดียว |
| 2 เมืองเล็ก | 50–100 หลัง กำแพงหรือรั้วหนึ่งชั้น ตลาดหนึ่งลาน |
| 3 เมือง | 100–200 หลัง ถนนหลักสองสาย กำแพงหนึ่งชั้น ตลาดหนึ่งถึงสองแห่ง |
| 4 เมืองใหญ่ | 200–400 หลัง สองย่านชัด กำแพงหนึ่งถึงสองชั้น คฤหาสน์ 5–15 หลัง |
| 5 นครใหญ่ | 400 หลังขึ้นไป สามย่านขึ้นไป กำแพงสองชั้นขึ้นไป คฤหาสน์ 15–40 หลัง อาคารสูงกว่าบ้านทั่วไปสองถึงสามเท่า |

จำนวนชั้นกำแพงในตารางเป็นค่าตั้งต้นเมื่อประเทศมี `defense=wall` ขึ้นไป ประเทศที่เป็น `open` หรือ `natural` ไม่วาดกำแพงไม่ว่าขนาดเท่าใด (ดู [11-context-and-landmarks.md](11-context-and-landmarks.md) หัวข้อ 2) เมืองใหญ่ที่ไม่มีกำแพงชดเชยด้วยย่านชั้นนอกที่ยาวออกไปตามถนน

### 2. ที่ประทับของอำนาจ (`seat=`)

W ตั้งแต่ 4 ขึ้นไปต้องมีที่ประทับที่เห็นได้จากกลางเมือง W 3 มีจวนหรือหอ W 2 ลงมาไม่มีวังหรือมีเพียงเรือนใหญ่กว่าเรือนอื่นหนึ่งห้อง ข้อยกเว้นทำได้เมื่อประเทศนั้นไม่มีผู้ปกครองเป็นจุดเดียว (ตลาดเสรี สหภาพ ขบวนผู้ลี้ภัย)

| รหัส | ความหมาย | วาดอย่างไร |
| --- | --- | --- |
| `palace` | วังหรือราชสำนัก | อาคารกลุ่มหลังคาซ้อนหลายชั้น ลานหน้าวัง กำแพงชั้นในของตัวเอง สูงที่สุดหรือใหญ่ที่สุดในเมืองรองจากศาสนสถาน |
| `castle` | ปราสาทหรือป้อมผู้ปกครอง | ผนังหนา หอมุม ประตูเดียว ไม่เน้นความหรูหรา |
| `manor` | คฤหาสน์หรือจวนขุนนางหรือพ่อค้า | บ้านหลังใหญ่หนึ่งถึงสามหลังมีสวนหรือลานของตัวเอง |
| `hall` | หอประชุมหรือจวนผู้นำ | อาคารเดียวใหญ่กว่าบ้านทั่วไปสองเท่า |
| `tent` | กระโจมหัวหน้า | สูงกว่ากระโจมอื่นหนึ่งเท่า ธงหรือเครื่องหมายหน้าปาก |
| `none` | ไม่มีที่ประทับแยก | ผู้นำอยู่ในสิ่งเดียวกับทุกคน (เรือธง ลาน ขบวน) |

### 3. ศาสนสถาน (`sacred=`)

ทุกประเทศมีที่ให้ผู้คนบูชาอย่างน้อยหนึ่งจุด ประเทศที่ศรัทธาเป็นเอกลักษณ์ต้องมีศาสนสถานที่ใหญ่เป็นอันดับหนึ่งหรือสองของเมือง และมีสิ่งที่ผู้ศรัทธาทำให้เห็น (เทียน ผ้า เหล็ก น้ำ กระดูก) เป็นกอง ๆ ที่แท่น

| รหัส | ความหมาย | ขนาดและสิ่งที่ต้องมี |
| --- | --- | --- |
| `shrine` | ศาลเล็ก | เท่าบ้านเล็กหรือเล็กกว่า มีแท่นเดี่ยว ข้าวของถวายหยิบมือเดียว |
| `altar` | แท่นบูชากลางแจ้ง | แท่นหินหรือไม้ตั้งกลางลานหรือที่สูง ไม่มีหลังคา เครื่องบูชากองรอบแท่น |
| `temple` | วิหารหรือวัด | อาคารมีหลังคา ห้องบูชาและที่พักผู้มาเยือน ใหญ่กว่าบ้านทั่วไปสามเท่า |
| `cathedral` | มหาวิหาร | สูงที่สุดในเมืองหรือเสมอกับที่ประทับ มีหอระฆังหรือโดม แท่นบูชาใหญ่ในห้องกลาง เทียนหรือเครื่องบูชาเป็นพันชิ้น |
| `forgealtar` | แท่นเตาหลอม | ทั่งหรือเตาไฟที่ไม่ดับ ผู้ศรัทธาโยนเหล็กเป็นเครื่องสังเวย |
| `none` | ไม่มี | ประเทศที่ไม่ศรัทธาอย่างจริงจัง |

### 4. ความเหลื่อมล้ำ (G)

| G | ภาพในเมือง |
| --- | --- |
| ต่ำ | บ้านขนาดใกล้เคียงกันทั้งเมือง หลังคาสีใกล้กัน ไม่มีย่านแยกชัด |
| กลาง | มีย่านดีหนึ่งย่านบนที่สูงหรือใกล้ศูนย์กลาง ที่เหลือบ้านธรรมดา |
| สูง | เมืองแยกสองชั้นชัด ย่านบนมีกำแพงเตี้ยของตัวเอง ย่านล่างบ้านเล็กชิดกัน เห็นรอยขาดสายตลอดถนนเส้นเดียว |
| สูงมาก | ภาพตรงข้ามสุดโต่ง ย่านบนสะอาดสว่างมีประตูกั้น ย่านล่างเป็นเพิงและหลังคาปะ ถนนตัดผ่านกลางเมืองเป็นเส้นแบ่ง ต่างกันทั้งสีและแสง |

### 5. การใช้เงิน (M)

| M | ภาพในเมือง |
| --- | --- |
| เต็ม | ป้ายราคาและร้านค้าติดผนังทั่วเมือง ธนาคารหรือหอบัญชีมีที่ของตัวเอง |
| ผสม | ตลาดกลางเมืองใช้ทอง ชานเมืองแลกของ ป้ายราคามีเฉพาะในย่านกลาง |
| น้อย | ไม่มีป้ายราคา ตลาดเป็นลานโล่งแลกของ ส่วยและบรรณาการเห็นเป็นกองสิ่งของหน้าที่ประทับ |
