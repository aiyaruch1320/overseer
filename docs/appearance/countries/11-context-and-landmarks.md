# บริบทของประเทศ: สงคราม การป้องกัน กฎหมาย และจุดเด่นของเมือง

ภาพรวม: [../README.md](../README.md) · ขนาดเมือง ที่ประทับ ศาสนสถาน: [10-scale-and-sacred.md](10-scale-and-sacred.md) · ไฟล์ประเทศในทวีป: [01-azgar.md](01-azgar.md) ถึง [09-nebulia.md](09-nebulia.md) · เผ่า: [../02-races.md](../02-races.md) · การเมืองข้ามทวีป: [../../lore/world/world-politics.md](../../lore/world/world-politics.md)

ไฟล์ [10-scale-and-sacred.md](10-scale-and-sacred.md) ตอบเรื่องความมั่งคั่งและศรัทธา ไฟล์นี้ตอบเรื่องที่เหลือ **ประเทศนี้อยู่กับอะไร** เมืองที่รบบ่อยต้องมีกำแพงและลานฝึก เมืองที่ตัดสินด้วยคำสาบานต้องมีหินสาบาน เมืองของเผ่าที่ไม่ประหารต้องไม่มีลานประหาร ทุกประเทศได้ค่าภาวะสงคราม การป้องกัน วิธีตัดสินความ และจุดเด่นของเมืองสองถึงห้าจุด พร้อมเหตุผลที่ย้อนกลับไปหาไฟล์ประเทศได้

**สถานะของข้อมูล** รายการในไฟล์นี้เป็นการเติมจากบริบทที่ไฟล์ประเทศและเผ่าเขียนไว้ ไม่ใช่ข้อเท็จจริงที่ไฟล์เหล่านั้นระบุตรง ๆ ถ้าไฟล์ประเทศหรือไฟล์เผ่าขัด **ไฟล์ประเทศชนะ** แล้วแก้ที่นี่ ค่า `defense=` ในไฟล์นี้แทนค่า `wall=` เดิมในไฟล์ทวีป ส่วนจุดเด่นเป็นของเพิ่มต่อจาก `extra=` ไม่แทนของเดิม

## กติกา

### 1. ภาวะสงคราม (`war=`)

| รหัส | ชื่อ | ความหมาย | ภาพในเมือง |
| --- | --- | --- | --- |
| `peace` | สงบ | ไม่มีศัตรูที่ลงมือรบกับประเทศนี้ในรอบชีวิตคนหนึ่ง | ทหารในถนนไม่เกินหนึ่งในยี่สิบคน ไม่มีรอยสงคราม เสียงเมืองคือตลาดและงาน |
| `watch` | เฝ้าระวัง | มีคู่ตึงเครียดหรือปมที่อาจระเบิด แต่ยังไม่ยิง | ทหารหนึ่งในสิบ หอสังเกตและยามประจำ ป้ายประกาศเตือนบนกำแพง |
| `feud` | ขัดแย้งเป็นพัก ๆ | รบปะทะเป็นช่วง ปีเว้นปีหรือสองปีเว้นหนึ่ง | ทหารหนึ่งในหกคน รอยซ่อมกำแพง ธงสงครามบนหอ ชายพิการจากสงครามนั่งข้างถนน |
| `frequent` | รบบ่อย | รบเกือบทุกปี หรือชีวิตผูกกับการรบ | ทหารหนึ่งในสามคน รอยไหม้และรอยลูกศรบนกำแพง กลองซ้อมรบทุกเช้า เกวียนลำเลียงทหารและศพ |
| `total` | ภาวะสงครามเต็มตัว | เมืองคือแนวรบ ชีวิตทุกวันคือสงคราม | ทหารเกินครึ่ง บ้านพังและค่ายผู้ลี้ภัย สนามเพลาะในเมือง เสียงปืนหรือเสียงรบลอยมาตลอด |

ภาวะสงครามคูณกับจำนวนทหารในถนน ไม่ใช่กับขนาดเมือง เมืองใหญ่ที่สงบมีทหารสัดส่วนน้อย เมืองเล็กที่รบบ่อยอาจมีทหารเกินคนอื่น ผู้ลี้ภัยและผู้พิการจากสงครามเป็นตัวชี้วัดภาพที่ดีกว่าธง

### 2. การป้องกัน (`defense=`)

| รหัส | ชื่อ | วาดอย่างไร | `wall=` เดิมที่ตรงกัน |
| --- | --- | --- | --- |
| `open` | ไม่มีกำแพง | ถนนเปิดสู่ทุ่งหรือน้ำ ไม่มีประตูเมือง บ้านชั้นนอกเป็นเขตเมืองเอง | `none` |
| `natural` | ภูมิประเทศเป็นกำแพง | หน้าผา ใต้ดิน เกาะลอย หมอก หรือน้ำลึก ทางเข้ามีไม่กี่ทาง ไม่ต้องสร้างกำแพง | `none` |
| `stockade` | รั้วไม้ | ไม้ปักสูงสองคนล้อมเมืองหรือค่าย ประตูไม้สองบาน หอยามไม้ทุกร้อยก้าว | `palisade` |
| `wall` | กำแพงหิน | กำแพงหินสูงสามถึงห้าคน ประตูเมืองสองถึงสี่ประตู ทหารยามประจำ | `stone` |
| `fort` | กำแพงป้อม | กำแพงหนา หอมุมทุกมุม คูเมืองหรือรั้วชั้นนอก ประตูเดียวใหญ่พร้อมซุ้มปิด | `iron` |
| `bastion` | ปราการหลายชั้น | กำแพงสองถึงสามชั้น สนามเพลาะหน้ากำแพง ป้อมหน้า ประตูซ้อน คลังอาวุธในกำแพง | `iron` |

- ประเทศที่ `war=frequent` หรือ `total` ต้องเป็น `fort` หรือ `bastion` ยกเว้นผู้ที่ไม่สร้างเมืองถาวร (ค่ายออร์ค กองเรือ ค่ายเร่ร่อน) หรือมีภูมิประเทศเป็นกำแพง
- ประเทศที่ `war=peace` ไม่ควรเป็น `bastion`
- `natural` ใช้เมื่อภูมิประเทศปิดทางเข้าเอง (เกาะลอยฟ้า ใต้ดิน ใต้น้ำลึก ต้นไม้โลก หมอกหนา) ไม่ต้องวาดกำแพง แต่ต้องวาดทางเข้าที่ชัดหนึ่งถึงสองทาง

### 3. การตัดสินและการลงโทษ (`justice=`)

| รหัส | ชื่อ | ภาพและโทษ | จุดเด่นที่มักมาคู่กัน |
| --- | --- | --- | --- |
| `court` | ศาลเมือง | ผู้พิพากษาตัดสินจากแท่น มีทนายและพยาน โทษคือค่าปรับ คุก หรือเนรเทศ | `courthouse` `prison` |
| `council` | สภาตัดสิน | สภาหรือคณะกรรมการลงมติ ไม่มีบัลลังก์เดี่ยว | `assemblyhall` `courthouse` |
| `elders` | ผู้เฒ่าตัดสิน | ผู้เฒ่านั่งวงกลางลานหรือใต้ต้นไม้ ไม่มีอาคารศาล โทษคือไล่ออกจากกลุ่มหรือชดใช้ | `commontable` `stonecircle` `rootcourt` |
| `oath` | ศาลคำสาบาน | ตัดสินจากหินสาบานหรือแผ่นเหล็กจารึก ผู้ผิดสาบานถูกลบชื่อและเนรเทศ ไม่ประหาร | `oathstone` |
| `duel` | ศาลดวล | ข้อพิพาทตัดสินด้วยดวลในวงหิน ผู้แพ้ยอมความ ไม่ประหาร | `duelring` |
| `ledger` | ศาลบัญชีและหนี้ | ผู้ผิดสัญญาถูกยึดทรัพย์หรือขังในคุกหนี้ เสมียนสำคัญกว่าผู้พิพากษา | `ledgerhall` `prison` |
| `faith` | ศาลศาสนา | นักบวชตัดสิน โทษคือชดใช้ต่อเทพ ขับออกจากศรัทธา หรือถูกเผาในประเทศที่เข้มงวด | `pyre` `prison` |
| `martial` | ศาลทหาร | ผู้บัญชาการตัดสินเร็ว โทษคือเฆี่ยน คุก หรือแขวนคอในประเทศที่เข้มงวด | `gallows` `prison` `drill` |
| `mothers` | สภามารดา | มารดาผู้ปกครองตัดสินในห้องมืด โทษคือถูกส่งไปทำงานลึกหรือหายตัว | `mothershall` |
| `contract` | ศาลสัญญา | ตัดสินตามตัวอักษรของสัญญา ผู้ผิดเงื่อนไขติดหนี้ผู้ชนะ | `contracthall` |
| `guild` | ศาลกิลด์ | ผู้นำกิลด์ตัดสิน โทษคือถอดระดับหรือถอดชื่อ | `guildhall` |
| `ritual` | การทดสอบพิธี | ผู้ปกครองทดสอบผู้คนเป็นช่วง ผู้ไม่ผ่านถูกพิธีเปลี่ยนสภาพ | `trialhall` `stonebed` |
| `lawless` | ไม่มีศาล | ความขัดแย้งตัดสินด้วยมีด ค่าหัว หรือการแก้แค้น ผู้ปกครองไม่ยุ่ง | `bountyboard` `gallows` |
| `none` | ไม่มีระบบชัด | ปัญหาจบที่ครอบครัวหรือเงียบไป | - |

กติกาของลานประหาร (`gallows`)

- ใช้ได้เฉพาะประเทศที่ `justice=martial` หรือ `lawless` หรือประเทศมนุษย์/ลาวา/โจรสลัดที่เข้มงวด ห้ามใช้ในประเทศเอลฟ์ ฮาล์ฟลิง คนแคระ เงือก นาคา ยักษ์ หรือหุ่นวิญญาณ เพราะเผ่าเหล่านี้ไม่ประหาร (ดูหัวข้อ 5)
- วางหน้าศาลเมืองหรือริมท่า ไม่วางกลางตลาด
- ประเทศในเมืองลอยฟ้าไม่มีลานประหาร ใช้ขอบเกาะลงโทษ (`dropledge`) แทน
- ออร์คไม่ประหารในค่าย ใช้เสาประจานเกียรติ (`shamepost`) ผู้ถูกประจานไม่ได้แบ่งอาหาร

### 4. จุดเด่นของเมือง (`mark=`)

แต่ละประเทศมีสองถึงห้าจุด เรียงตามความโดดเด่น จุดแรกต้องเห็นได้จากมุมสูง ขนาดเมือง (`scale=` จาก [10-scale-and-sacred.md](10-scale-and-sacred.md)) 1 ถึง 2 ใช้ไม่เกินสามจุด ขนาด 4 ถึง 5 ใช้ได้ห้าจุด ตัวที่มี \* อยู่ในโค้ดแล้ว ที่เหลือเป็นรหัสใหม่

#### กองทัพและแนวรบ

| รหัส | ชื่อ | วาดอย่างไร |
| --- | --- | --- |
| `watchtower` | หอสังเกต | หอไม้หรือหินสูงกว่าหลังคาสามเท่า ตั้งตามมุมกำแพงหรือบนเนิน มียามหนึ่งคนและกระดิ่งหรือธงเตือน |
| `barracks` \* | ค่ายทหาร | อาคารยาวเรียงแถว หน้าค่ายมีลานโล่ง ธงหน่วยปักหน้าประตู |
| `drill` \* | ลานฝึก | ลานดินอัดมีหุ่นฟางและราวอาวุธ ทหารเรียงแถวซ้อม เสียงกลองเป็นจังหวะ |
| `armory` | คลังอาวุธ | อาคารหินหน้าต่างเล็ก ประตูเหล็กหนา ยามสองคนหน้าประตู ราวหอกวางไว้ข้างนอก |
| `trench` | สนามเพลาะ | ร่องดินลึกหน้ากำแพง กระสอบทรายและไม้ค้ำ มีสะพานไม้พาดเป็นช่วง |
| `siegeyard` | ลานเครื่องล้อม | ลานกว้างมีเครื่องยิงหินและหอล้อมกึ่งสำเร็จ กองไม้และเชือก ช่างตีเหล็กเคาะไม่หยุด |
| `barricade` | สิ่งกีดขวางถนน | เกวียนพลิกคว่ำ ถุงทราย และรั้วไม้ขวางปากซอย เปิดช่องให้คนเดียวผ่าน |
| `warcamp` | ค่ายสงคราม | กระโจมและเกวียนล้อมวงรอบกองไฟใหญ่ ไม่มีกำแพง ธงเผ่าสูงสุดเหนือกระโจมหัวหน้า |
| `warmemorial` | อนุสรณ์สงคราม | เสาหินหรือแผ่นสลักชื่อผู้ตาย ดอกไม้และอาวุธหักวางที่ฐาน ธงครึ่งเสา |
| `fieldhospital` | เต็นท์พยาบาลสนาม | ผ้าใบขาวคราบแดง เตียงเรียงยาว ผ้าพันแผลตากราว ควันต้มน้ำ |
| `beacon` | ไฟสัญญาณ | กองไฟหรือโคมสูงบนยอดเนินหรือหอ จุดเรียงเป็นระยะให้เห็นกันได้ |
| `checkpoint` | ด่านตรวจ | ซุ้มประตูมีโต๊ะตรวจและเชือกกั้น ยามตรวจสิ่งของ แถวคนยาวหน้าด่าน |
| `ruins` | ซากเมือง | กำแพงพังครึ่งหนึ่ง บ้านโล่งไม่มีหลังคา หญ้าขึ้นตามร่อง ธงขาดปลิว |

#### กฎหมายและการลงโทษ

| รหัส | ชื่อ | วาดอย่างไร |
| --- | --- | --- |
| `courthouse` | ศาลหรือหอตัดสิน | อาคารหินเสาหน้า ขั้นบันไดกว้าง แท่นผู้ตัดสินสูง ลานหน้าศาลมีคนรอ |
| `assemblyhall` | หอสภา | อาคารโดมหรือหลังคากว้าง ที่นั่งครึ่งวงกลม ธงสมาชิกเรียงหน้าประตู |
| `oathstone` | หินสาบาน | แท่นหินหรือเหล็กจารึกคำสาบานตั้งกลางลาน ผู้สาบานวางมือบนแผ่น ผู้ผิดสาบานถูกลบชื่อ |
| `duelring` | วงดวล | วงหินกลมพื้นทราย ขอบยกสูงเท่าเอว ผู้ชมยืนล้อม ราวอาวุธอยู่ข้างวง |
| `gallows` | ลานประหาร | แท่นไม้สูงหนึ่งชั้นกลางลานหน้าศาลหรือริมท่า เสาแขวนหนึ่งถึงสามเสา พื้นคล้ำ กาเกาะ ผู้คนเดินเลี่ยง |
| `stocks` | ที่ประจาน | ไม้ค้ำคอและมือกลางตลาด ผู้ถูกลงโทษนั่งโดนสายตาผู้คน |
| `prison` | คุก | อาคารหินไม่มีหน้าต่างชั้นล่าง ประตูเหล็ก ลูกกรงชั้นบน ยามเดินวน |
| `shamepost` | เสาประจานเกียรติ | เสาไม้สูงปักกลางค่ายผูกผ้าสีแดงหรือกระดูก ผู้ละเมิดเกียรติถูกยืนข้างเสาและไม่ได้แบ่งอาหาร |
| `dropledge` | ขอบเกาะลงโทษ | แท่นไม้ยื่นพ้นขอบเกาะลอยฟ้า ผู้ฝ่าฝืนถูกปล่อยลงสู่พื้นล่างหรือถูกทิ้งไว้ ราวเหล็กเปิดช่องเดียว |
| `bountyboard` | กระดานหัวเงิน | ผนังไม้ปักประกาศจับและค่าหัว ใบประกาศซ้อนกันหลายชั้น ผู้อ่านสวมผ้าคลุมหน้า |
| `tourney` | ลานประลองอัศวิน | ลานยาวมีราวกั้น อัฒจันทร์ผ้าสีบนสองฝั่ง ธงตราตระกูลเรียงตามราว |
| `commontable` | โต๊ะกลางเมือง | โต๊ะไม้ยาวสิบคนกลางลานหรือใต้ต้นไม้ ใช้กินข้าว ตัดสินความ และทำสัญญา |
| `mothershall` | หอมารดา | ห้องโถงใต้ดินแสงลาวาหรือแสงเรืองสีม่วง บัลลังก์วงกลมของสภามารดา ยามเงียบ |
