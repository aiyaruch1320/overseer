# ภาพของฉากสำคัญในเส้นเรื่องตัวละคร

ภาพรวม: [README.md](README.md) · โครงสร้างเส้นเรื่อง: [../storylines/README.md](../storylines/README.md) · เผ่า: [02-races.md](02-races.md) · ประสบการณ์หนึ่งชีวิต: [../experience/01-one-life.md](../experience/01-one-life.md) · หน้าตำนานและจุดจบของชีวิต: [../experience/03-ending-and-collection.md](../experience/03-ending-and-collection.md)

เส้นเรื่องของแต่ละเผ่าในโฟลเดอร์ [../storylines/](../storylines) บอกเงื่อนไข ทางเลือก และผลครบทุกโหนด แต่ไม่ได้บอกว่าฉากที่ผู้เล่นเห็นหน้าตาเป็นอย่างไร ไฟล์นี้เติมสองฉากที่ทุกเผ่ามีและเป็นฉากที่ผู้เล่นจำได้มากที่สุด คือ **พิธีของเผ่า** (โหนด `.t1` ช่วงวัยรุ่น) และ **ฉากปลายทาง** (ตอนจบของชีวิต) ส่วนโหนดอื่นใช้กติกากลางในหัวข้อ 1

## 1. กติกากลางของฉากในเส้นเรื่อง

ฉากทุกโหนดเป็นฉากสั้นแบบ **ภาพนิ่งเคลื่อนไหวเบา** ตามหลักของ 1in8b.life ที่ตัวละครเดินชีวิตเอง ผู้เล่นเป็นผู้เฝ้าดู ไม่ใช่ผู้ควบคุม ไม่มีกล้องที่ผู้เล่นขยับ

| ชิ้น | กติกา |
| --- | --- |
| ความยาว | โหนดทั่วไป 4–8 วินาที ฉากพิธีและปลายทาง 15–25 วินาที |
| กล้อง | มุมระดับสายตาของตัวละครเดียว เห็นตัวละครสามส่วนสี่ ไม่ซูมเข้าหน้าเกินครึ่งจอ |
| แสง | แสงของฉากบอกผล: ผ่านเป็นแสงอุ่นจากด้านหน้าตัวละคร ไม่ผ่านหรือเสียเป็นแสงเย็นจากด้านหลัง ผลเสมอเป็นแสงกระจายสม่ำเสมอ |
| ตัวหนังสือ | ชื่อโหนดหนึ่งบรรทัดและผลหนึ่งบรรทัด ไม่ใช้บทพูดยาว |
| เสียง | หนึ่งเสียงที่จำได้ของเผ่านั้น (ตาม [02-races.md](02-races.md)) ทับเสียงพื้นของถิ่น |
| ทางแยก | ถ้ามีทางเลือก ก) ข) ค) ภาพแสดงฉากของทางที่ตัวละครเลือกจริง ไม่แสดงทางที่ไม่ได้เลือก ปุ่มเลือกไม่มี เพราะตัวละครตัดสินเอง |
| เส้นหน้าต่างพระเจ้า | โหนดที่เป็นหน้าต่างพระเจ้ามีวงแสงจางบนเส้นเวลาของชีวิต ก่อนถึงโหนด ตำแหน่งและรูปแบบการแทรกแซงตัดสินในระบบพระเจ้าซึ่งออกแบบเป็นลำดับสุดท้าย ไฟล์นี้บอกเพียงว่ามีวงแสง |

## 2. พิธีของเผ่า (โหนด `.t1`)

พิธีเป็นฉากแรกที่ตัวละครเผชิญความหมายของเผ่า ใช้ชุดสีของเผ่าจาก [02-races.md](02-races.md) เป็นฐาน

| เผ่า | พิธี | ฉากที่ผู้เล่นเห็น | ผ่าน | ไม่ผ่าน |
| --- | --- | --- | --- | --- |
| มนุษย์ | พิธีของถิ่น (วันเลือกทาง) | ฉากเปลี่ยนตามถิ่นเกิด ทุ่งราบ: ลานกิลด์ มือเด็กแตะโต๊ะช่าง · หมอก: คนเดียวถือเชือกในหมอกสีขาว · ทราย: ลมแดงกับทรายสูงเท่าหัว · เรือ: ก้นอ่าวสีเขียวมืด มือคว้าเปลือกหอย · ชาวพื้น: บันไดหินและถุงบรรณาการบนบ่า | แสงอุ่นโดนหน้า มือชูของที่ได้ | เด็กนั่งพื้น ภาพเย็นลงหนึ่งขั้น |
| เอลฟ์ | พิธีผูกราก | เด็กเอลฟ์นอนหงายบนรากต้นไม้โลก รากสีเขียวทองพันข้อมืออย่างช้า ๆ แสงประกายเล็ก ๆ ลอยขึ้นจากราก | รากแน่นและเรืองทองอ่อน | รากคลายออกเอง ใบไม้ข้าง ๆ เหลือง |
| ดาร์กเอลฟ์ | พิธีเผชิญเงา | ห้องใต้ดินเงียบ เทียนม่วงหนึ่งเล่ม เงาของเด็กบนผนังขยับก่อนตัวเด็ก | เงานิ่งตามตัวเด็ก | เงาเดินออกจากผนังช้า ๆ |
| คนแคระ | วันทั่งแรก | เด็กยืนหน้าทั่งใหญ่กว่าตัวสามเท่า ค้อนหนักในมือสองข้าง ประกายส้มกระเด็นครั้งแรก | เสียงทั่งใสหนึ่งครั้งก้องทั้งโรงตี | ค้อนเด้งกลับ เด็กล้ม |
| ออร์ค | พิธีกระดูกแรก | เด็กออร์คกลางวงผู้ใหญ่ จับกระดูกขนาดฝ่ามือที่ผู้เฒ่ายื่นให้ เสียงกลองหนังต่ำ | กระดูกอุ่นในมือ วงตะโกนพร้อมกัน | วงเงียบ มือปล่อยกระดูกตก |
| ฮาล์ฟลิง | วันให้ของขวัญ | โต๊ะอาหารยาวเต็มห้อง เด็กถือของขวัญชิ้นเล็กเดินให้ทีละคน แสงเทียนเหลือง | ทุกคนยิ้มพร้อมกัน | ของขวัญถูกวางไว้โต๊ะเดียวไม่มีคนรับ |
| เผ่าสัตว์ | การล่าครั้งแรก | ป่าตอนเช้า ผู้ล่าเด็กหมอบข้างผู้ใหญ่ สายตาเกาะกับเหยื่อ ลมพัดหญ้า | เหยื่อล้มเงียบ เด็กหายใจออกยาว | เหยื่อวิ่งหนี เด็กยืนนิ่งกลางลม |
| นาคา | การทดสอบนาคา | เด็กนาคาขดอยู่หน้าโอเบลิสก์ ฝ่ามือขวาแตะหิน แสงเขียวหยกไหลจากหินสู่มือ | หินเรืองเขียวสว่างทั้งแท่ง | หินมืด เด็กคลายตัว |
| เผ่ามังกร | เปลวแรก | เด็กยืนกลางลานหิน อ้าปากพ่นเปลวแรกเป็นเส้นบางสีส้ม ฝูงญาติยืนเป็นวง | เปลวยาวและตรง | เปลวเป็นควันขาว |
| แวมไพร์ | คืนแรกแห่งเลือด | ห้องมืดใต้ปราสาท ถ้วยเลือดวางบนหินดำ ตาเด็กเปลี่ยนเป็นแดง | ตาแดงสุกใสสม่ำเสมอ | ตาแดงสั่นและเด็กปิดปาก |
| ภูตพราย | ชื่อจริง | วงดอกไม้ตูมกลางป่า ภูตผู้เฒ่ากระซิบชื่อเข้าหูเด็ก แสงแวววาวรอบหู | ชื่อลอยเป็นแสงเข้าหน้าอกแล้วเก็บ | ชื่อลอยออกจากปากเป็นเสียงให้ผู้อื่นได้ยิน |
| สไลม์ | การกลืนครั้งแรก | ก้อนเจลใสเล็กกลืนวัตถุชิ้นแรก (เม็ดทรายหรือใบไม้) เห็นวัตถุลอยในเนื้อเจล | วัตถุละลายช้าแล้วเนื้อเจลมีสี | วัตถุค้างไม่ละลายและเจลสั่น |
| เผ่าปีศาจ | การลงนามครั้งแรก | โต๊ะดำและปากกาแดง เด็กปีศาจเซ็นชื่อตัวเองลงกระดาษ แสงม่วงแดงจากหมึก | กระดาษไหม้เป็นเถ้าแล้วรอยเซ็นอยู่บนผิว | ปากกาหัก หมึกไหลลงโต๊ะ |
| เงือก | พิธีของสาย | วงแสงเรืองฟ้ากลางน้ำลึก เด็กเงือกว่ายเข้าไปสายแสงของตระกูลพันตัวเป็นครั้งแรก | สายแสงเรืองและพันแน่น | สายแสงหลุดแล้วดับ |
| เผ่าปีก | การบินครั้งแรก | หน้าผาตอนเช้า เด็กกางปีกกระโดดออกจากขอบ ลมพาตัวลอย | ปีกกางเต็มและร่อนขึ้น | ร่วงเป็นเส้นตรงแล้วผู้ใหญ่คว้า |
| ยักษ์ | การสลักชื่อ | เด็กยักษ์ใช้สิ่วหินสลักชื่อตัวเองบนก้อนหินใหญ่เท่าบ้าน หินร่วงเป็นฝุ่น | ชื่อชัดทั้งสี่ตัว หินเรืองจาง | ชื่อบิดเบี้ยว หินร้าว |
| เผ่าลาวา | การจุ่มลาวา | เด็กลาวาจุ่มมือลงสายลาวา ผิวเปลี่ยนสีจากแดงเป็นส้มสว่าง | ผิวคงรูป เปลวจากไหล่พุ่งขึ้น | ผิวแข็งเป็นหินดำที่มือ |
| ลูกผสมจักรกล | ชิ้นแรกหรือชื่อแรก | โต๊ะผ่าตัดขาวสว่าง ชิ้นส่วนโลหะชิ้นแรกและป้ายชื่อวางเคียงกัน มือเด็กเลือกหนึ่งอย่าง | แสงเลนส์ฟ้าเรืองเมื่อเลือกชิ้นส่วน หรือแสงอุ่นเมื่อเลือกชื่อ | มือค้างกลางอากาศระหว่างสองอย่าง |
| หุ่นวิญญาณ | คำถามแรก | หุ่นเหล็กทองเหลืองยืนนิ่ง เลนส์ตาเหลืองหมุนช้า ปากกลวงเปล่งเสียงถามคำเดียว แกนฟ้าอ่อนที่อกเต้น | แกนเต้นเป็นจังหวะคงที่ | แกนกระพริบสั่นแล้วดับครู่หนึ่ง |
| มัมมี่ | การชั่งหัวใจ | ตาชั่งทองใหญ่ ถาดหนึ่งมีหัวใจเรืองเขียวอีกถาดมีขนนก ฟาโรห์ผู้ชั่งยืนอยู่ปลายห้อง | ถาดสมดุล ขนนกลอยเรือง | ถาดหัวใจตก ห้องมืด |
| กูล | มื้อแรก | ห้องสุสานมืดหนึ่งเทียน กูลหนุ่มคุกเข่าหน้าศพชิ้นแรกที่ได้รับ แสงเขียวหม่น | กินเงียบ ตาเรืองอ่อน | หันหน้าหนี ตาดำสนิท |

## 3. ฉากปลายทาง (โหนด `.e` และไฟล์ ปลายทาง)

ปลายทางแต่ละแบบของเผ่า (ตายในศึก ปลดเกษียณ กลายเป็นตำนาน ฯลฯ) ใช้ฉากร่วมของเผ่านั้น ต่างกันที่ **ของวางข้างตัวละคร** และ **คนที่ยืนล้อม** ตามปลายทางในไฟล์เส้นเรื่อง รายการด้านล่างบอกฉากร่วม การจัดการร่างและสิ่งที่ผู้เล่นเห็นเป็นอย่างสุดท้าย แล้วต่อไปที่ [../experience/03-ending-and-collection.md](../experience/03-ending-and-collection.md) หัวข้อบันทึกชีวิตและหน้าตำนาน

| เผ่า | ฉากร่วมของการตาย | ของที่เหลือตอนจบ |
| --- | --- | --- |
| มนุษย์ | เตียงในบ้านหรือสนามรบ ผ้าห่มบนตัว ญาติยืนล้อมเงียบ หรือเพื่อนร่วมศึกคุกเข่า | ชื่อสลักบนหลุมไม้หรือแผ่นหิน |
| เอลฟ์ | นั่งใต้ต้นไม้ ใบไม้ร่วงลงบนตักช้า ๆ รากค่อย ๆ ดึงร่างลงดิน | ต้นกล้าเล็กงอกจากจุดนั้น |
| ดาร์กเอลฟ์ | นอนในห้องเทียนม่วงเล่มเดียว เงาของตัวเองนั่งอยู่ข้างเตียง | เงาที่ยังอยู่ที่ผนังหนึ่งคืน |
| คนแคระ | ยืนหน้าทั่งจนล้ม ค้อนหล่นบนพื้นหิน เสียงกังวานหนึ่งครั้ง | ค้อนวางบนทั่งเป็นหลุมศพ |
| ออร์ค | กลางวงเพื่อน กลองตีช้าลงเรื่อย ๆ ร่างวางบนกองฟืนกระดูก | กระดูกชิ้นแรกถูกวางบนอก |
| ฮาล์ฟลิง | โต๊ะอาหารยาว ทุกคนนั่งกินด้วยกัน คนที่ตายเงียบไปในอ้อมแขนเพื่อนบ้าน | ถ้วยชามที่ใช้ประจำวางหน้าบ้าน |
| เผ่าสัตว์ | ป่ายามเย็น ฝูงเดินวนรอบร่างสามรอบแล้วหอนพร้อมกัน | หนังหรือขนที่ฝูงเก็บไว้ |
| นาคา | ขดตัวรอบโอเบลิสก์ ผิวลอกคราบครั้งสุดท้ายเหลือแต่คราบขาวบนพื้น | คราบขาวรูปตัวนาคา |
| เผ่ามังกร | บนหินสูง ลมหายใจสุดท้ายเป็นเปลวส้มสั้น ๆ | รอยเขม่าบนหิน |
| แวมไพร์ | ปราสาทมืด ผิวร่วงเป็นผงเถ้าซีดจากปลายนิ้ว ถ้วยเลือดล้ม | ผงเถ้ากับแหวนตระกูล |
| ภูตพราย | วงดอกไม้ตูม ร่างโปร่งแสงค่อย ๆ กลายเป็นกลีบดอกไม้ลอยขึ้น | กลีบดอกไม้ที่ไม่เหี่ยว |
| สไลม์ | ก้อนเจลหดเล็กลงทีละน้อยจนเหลือแกนเรืองสุดท้าย แกนดับ | น้ำเหนียวคราบบนพื้น |
| เผ่าปีศาจ | ห้องดำ ปากกาแดงหล่นบนสัญญาที่ไหม้ ร่างกลายเป็นควันแดง | กระดาษสัญญาไหม้ครึ่ง |
| เงือก | ลอยนิ่งในน้ำลึก สายแสงของตระกูลดับทีละเส้น ร่างจมช้า | ไข่มุกเม็ดเดียวลอยขึ้นผิวน้ำ |
| เผ่าปีก | บนหน้าผา ปีกกางสุดแล้วหุบ ขนร่วงเป็นสายตกลง | ขนปีกหนึ่งเส้นปักหินที่ขอบ |
| ยักษ์ | นั่งพิงหน้าผา ร่างช้า ๆ กลายเป็นหิน มอสขึ้นคลุม | หินรูปคนนั่งที่เชิงเขา |
| เผ่าลาวา | ร่างเย็นช้า ๆ กลายเป็นหินดำเรียบ รอยส้มสุดท้ายดับที่ใจกลาง | หินดำรูปคน |
| ลูกผสมจักรกล | ห้องผ่าตัด ชิ้นส่วนโลหะหยุดหมุนทีละชิ้น ไฟเลนส์ดับ | ชิ้นส่วนที่ถอดแล้วเรียงบนโต๊ะ |
| หุ่นวิญญาณ | แกนฟ้าอ่อนที่อกเต้นช้าลง หยุด ร่างทองเหลืองคุกเข่า | แกนวิญญาณหลุดออกมาเป็นแสงหนึ่งดวงแล้วลอยหาย |
| มัมมี่ | ร่างล้มบนแท่นพีระมิด ผ้าพันคลาย ธุลีทิพย์ปลิวหมด | ผ้าพันกองรูปคนบนแท่น |

## 5. สิ่งที่ยังไม่มี (บันทึกไว้)

- ฉากของโหนดแต่ละโหนดในเส้นเรื่อง (423 โหนด) ใช้กติกากลางหัวข้อ 1 ไม่ได้เขียนทีละโหนด ถ้าต้องการภาพเฉพาะของโหนดใดให้ระบุเป็นรายการในไฟล์นี้
- รูปแบบหน้าต่างพระเจ้าและการแทรกแซง ตัดสินในระบบพระเจ้า ซึ่งออกแบบเป็นลำดับสุดท้าย
