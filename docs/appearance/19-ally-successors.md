# ภาพของผู้สืบพวกพ้อง

ภาพรวม: [README.md](README.md) · ภาพของพวกพ้อง: [16-ally-scenes.md](16-ally-scenes.md) · ข้อมูลผู้สืบ: [../systems/bonds/07-successors.md](../systems/bonds/07-successors.md)

ผู้สืบ 55 คนใช้กติกาฉากเดียวกับพวกพ้อง ([16-ally-scenes.md](16-ally-scenes.md) หัวข้อ 1 และ 2) ที่เพิ่มคือ **ร่องรอยของต้นแบบ** ผู้สืบมีของหนึ่งอย่างที่เป็นของต้นแบบติดตัวให้เห็นตั้งแต่ฉากแรก ผู้เล่นจึงรู้ว่าเขาเป็นผู้สืบ โดยไม่ต้องมีตัวหนังสือบอก

## 1. กติกา

| ชิ้น | กติกา |
| --- | --- |
| ของต้นแบบ | ทุกคนมีของหนึ่งอย่างของต้นแบบในคอลัมน์ภาพ ถ้าเป็นผ้า ผ้านั้นต้องเก่ากว่าชุดที่เหลือหนึ่งระดับสีเสมอ |
| จุดจำ | คอลัมน์ผิดปกติคือสิ่งเดียวที่เห็นได้จากไกล ห้ามซ้ำกับต้นแบบ ผู้สืบต่างจากต้นแบบอย่างน้อยหนึ่งอย่างที่เห็นได้ |
| วัย | ผู้สืบอายุน้อยกว่าต้นแบบตอนที่ต้นแบบเริ่มเรื่อง ยกเว้นมัมมี่ที่แก่กว่า |
| เส้นผูก | เริ่มเป็นเส้นบางกว่าของต้นแบบหนึ่งระดับ สีตามสาย |
| ฉากแรก | ผู้สืบเข้าเฟรมจากด้านที่ต้นแบบเคยยืน ถือของหรือหยุดมองสถานที่ที่ต้นแบบเคยอยู่ |
