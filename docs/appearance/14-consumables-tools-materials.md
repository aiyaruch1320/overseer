# รูปลักษณ์ของใช้ในศึก เครื่องมือชีวิต วัสดุ และของสำคัญ

ภาพรวม: [README.md](README.md) · กติกาประกอบภาพ: [05-weapons-rules.md](05-weapons-rules.md) · ตัวเลข: [../systems/items/16-consumables.md](../systems/items/16-consumables.md) [17-life-tools](../systems/items/17-life-tools.md) [18-materials-and-keys](../systems/items/18-materials-and-keys.md) · เกราะ เครื่องประดับ: [08-armor-and-accessories.md](08-armor-and-accessories.md) · เครื่องราง: [09-talismans.md](09-talismans.md)

ไฟล์นี้ครอบ 192 ชิ้นที่ไม่ใช่อาวุธ เกราะ เครื่องประดับ หรือเครื่องราง ของใช้ในศึก 47 · เครื่องมือชีวิต 83 · วัสดุ 35 · ของสำคัญ 27 ทั้งหมดเป็นของที่ผู้เล่นเห็นเป็นไอคอนในช่อง กระเป๋า และฉากชีวิตช้า ไม่ใช่สิ่งที่เปลี่ยนเงาตัวละคร (ยกเว้นเครื่องมือที่ถืออยู่ขณะทำงาน)

## กติกา

### 1. กรอบตามระดับ

ใช้สีกรอบใน UI ชุดเดียวกับอาวุธ ([05-weapons-rules.md](05-weapons-rules.md) หัวข้อ 4)

| ระดับ | สีกรอบ | งานช่างที่เห็นบนชิ้น |
| --- | --- | --- |
| C | #a0a0a8 | งานมือหยาบ วัสดุหาง่าย มีรอยใช้เห็นชัด |
| U | #6aa05a | ขอบเรียบ สีสม่ำเสมอ ตรากับร้านหรืองานช่าง |
| R | #5a8ac8 | งานเด่นของถิ่นที่ทำ มีลายประดับหนึ่งอย่าง |
| E | #a05ac8 | ชิ้นเดียวในตระกูลหรือในร้าน มีเรื่องเล่า มีแสงจางเมื่อใช้ |
| L | #d8a030 | ไม่เหมือนชิ้นอื่น มีแสงถาวรและเสียงเฉพาะ |

### 2. ของใช้ในศึก

| ข้อ | กติกา |
| --- | --- |
| ภาชนะบอกชนิด | ขวดเล็กคือยาดื่ม · ห่อผ้าหรือใบไม้คือยาพอกหรืออาหาร · ลูกกลมหรือหม้อดินคือขว้าง · แผ่นไม้คือกับดัก · ม้วนคือเวท · สิ่งของอื่นคือเครื่องมือ |
| สีของน้ำยาบอกผล | แดง ฟื้น hp · เขียว ถอนพิษหรือสมุนไพร · เหลือง ความเร็วหรือถอนพิษ · ฟ้า ต้านเย็นหรือน้ำหรือสติ · ม่วง สมาธิหรือสติ · ทอง ชั้นสูงหรือชีวิต · ดำ พิษหรือควัน |
| ขนาดบอกความแรง | C และ U ขนาดนิ้วหัวแม่มือถึงกำมือ · R ขนาดกำมือ · E และ L ใหญ่กว่าปกติหรือมีแสงเอง |
| ท่าใช้ | ดื่ม กิน ทา โรย ขว้าง วางกับดัก คลี่ม้วน แต่ละท่าสั้นไม่เกิน 1 วินาที ตัวละครต้องใช้ท่านั้นทุกครั้งที่ใช้ของชนิดนั้น |
| เอฟเฟกต์ตอนใช้ | ใช้สีเดียวกับสีน้ำยา และปล่อยครั้งเดียว ไม่ค้างบนตัวละครนอกจากสถานะที่ของให้ (ใช้ตามแท็กใน [05-weapons-rules.md](05-weapons-rules.md) หัวข้อ 5 เมื่อเป็นธาตุ) |

### 3. เครื่องมือชีวิต

| ข้อ | กติกา |
| --- | --- |
| เห็นเมื่อทำงาน | เครื่องมือปรากฏในมือตัวละครเฉพาะตอนทำอาชีพนั้น ไม่ปรากฏในฉากต่อสู้ ถ้าตัวละครถือสี่ชิ้นจะเห็นหนึ่งชิ้นในมือและที่เหลือพิงใกล้ตัว (ตามท่าของแต่ละชิ้น) |
| ผิวบอกอายุ | ใหม่ เงา สีสด · ใช้มาครึ่งหนึ่งของอายุ ผิวหมองและมีรอยมือ · ใกล้ชำรุด รอยแตกหรือสนิม · ชิ้นประจำตระกูล (E) ดูเก่าแต่ไม่ชำรุด |
| ขนาดเทียบคน | เครื่องมือใหญ่ (เกวียน ล้อ เตา กี่) ตั้งในฉาก ไม่ถือ ตัวละครยืนข้างชิ้นนั้น ขนาดที่ระบุคือขนาดเทียบมนุษย์ผู้ใหญ่ |
| ผู้ถือ | เผ่าตัวใหญ่ (ยักษ์) ถือชิ้นเดียวกันแต่ขนาดคูณตามร่าง เผ่าตัวเล็ก (ฮาล์ฟลิง ภูต) ใช้ชิ้นขนาดที่ออกแบบให้ |

### 4. วัสดุ

วัสดุเป็นไอคอนในถุง ไม่มีท่าหรือฉากเฉพาะ ใช้ภาพเดียวขนาดเล็ก พื้นหลังโปร่ง แสงเฉพาะวัสดุที่มีเรื่องเกี่ยวกับมังกร ผู้ตาย วิญญาณ หมอก ธาตุ และต้นไม้โลก

| กลุ่ม | เงา | แสง |
| --- | --- | --- |
| จากสัตว์ป่าและฝูง | ทรงตามส่วนของร่างที่ได้ | ไม่มี |
| จากผู้ตาย วิญญาณ ปีศาจ | มีรอยแตกหรือคราบ | แสงจางสีตามที่มา (เขียวคล้ำ ฟ้าซีด แดง) |
| จากมังกรป่า ยักษ์ | ใหญ่กว่าวัสดุอื่นหนึ่งขั้น | ไอร้อนหรือฝุ่นหิน |
| จากสิ่งประดิษฐ์ ธาตุ | โลหะหรือผลึก | รูนฟ้าหรือแสงตามธาตุ |
| จากไร่ ฟาร์ม ป่า | ภาชนะธรรมดา ห่อผ้า กระสอบ | ไม่มี |
| L (เมล็ดต้นไม้โลก) | เมล็ดเดียว | เส้นรากทองเต้นช้า |

### 5. ของสำคัญ

| ข้อ | กติกา |
| --- | --- |
| ไอคอนสีกรอบ | ใช้กรอบสีตามระดับ แต่ของสำคัญมีขอบสองชั้นเพื่อแยกจากไอเทมที่ใช้ได้ |
| ฉากที่ปรากฏ | คอลัมน์ ค่า UI ช่องสุดท้ายบอกฉากที่ของนั้นต้องปรากฏเมื่อเรื่องเดินถึง ใช้เป็นภาพประกอบเส้นเรื่อง |
| เก้ากุญแจ | ทั้งเก้าอยู่ในฉากของประเทศที่เก็บเสมอ ไม่ย้ายภาพเมื่อตัวละครได้ ตัวละครถือเฉพาะเมื่อเรื่องให้ แสงของกุญแจเห็นได้ไกลกว่าไอเทมอื่น |
| ของตระกูลและเอกสาร | ปรากฏในฉากบ้าน ตั้งบนโต๊ะหรือบนผนังเมื่อไม่ได้พก |
