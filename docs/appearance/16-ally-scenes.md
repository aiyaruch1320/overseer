# ภาพของพวกพ้อง

ภาพรวม: [README.md](README.md) · ฉากในเส้นเรื่อง: [13-storyline-scenes.md](13-storyline-scenes.md) · กติการะบบ: [../systems/bonds/README.md](../systems/bonds/README.md) · เรื่องตัวหลัก: [../lore/storylines/28-allies.md](../lore/storylines/28-allies.md) [../lore/storylines/29-allies-flagship.md](../lore/storylines/29-allies-flagship.md) · ไอเทมคู่: [../systems/bonds/06-paired-items.md](../systems/bonds/06-paired-items.md)

ไฟล์นี้บอกว่าผู้เล่นเห็นอะไรเมื่อตัวละครผูกพันกับใคร ไม่ใช่การบอกว่ารู้สึกอย่างไรด้วยตัวหนังสือ ให้เห็นจากเส้นผูก ท่าทาง และของที่อยู่ในฉาก ตามหลัก "เขียนสิ่งที่เห็น ไม่เขียนเหตุผลของเรื่อง" ใน [README.md](README.md) รูปลักษณ์ของ NPC แต่ละคนอยู่ใน [npcs/README.md](npcs/README.md) ไฟล์นี้ไม่ซ้ำแต่ระบุฉากเด่นของแต่ละคน

## 1. กติกากลาง

ใช้กติกาฉากหัวข้อ 1 ของ [13-storyline-scenes.md](13-storyline-scenes.md) ทุกข้อ (ความยาว 4–8 วินาที กล้องระดับสายตา แสงบอกผล) และเพิ่ม

| ชิ้น | กติกา |
| --- | --- |
| เส้นผูก | เมื่อตัวละครกับพวกพ้องอยู่ในเฟรมเดียวกัน มีเส้นบางจากมือหรือใจกลางอกของตัวละครไปหาพวกพ้อง สีตามสาย (หัวข้อ 2) ลักษณะเส้นตามระดับ (หัวข้อ 3) |
| ที่ว่าง | ฉากสองคนเว้นที่ว่างระหว่างกันเสมอ ไม่มีฉากที่สองคนทับกันเกินหนึ่งในสามของตัว ความใกล้ที่ลดลงหรือเพิ่มขึ้นแสดงด้วยที่ว่างนี้ |
| ฉากบอกเหตุ | ทุกครั้งที่ระดับหรือสายเปลี่ยน ฉากต้องแสดงสิ่งที่ทำให้เปลี่ยน (ของที่ยื่นให้ ท่าที่ต่างจากเดิม คำที่ไม่ตอบ) ไม่ใช้แค่เส้นผูกหนาขึ้น |
| อารมณ์ | แสดงด้วยอีโมตของตัวละครหลัก (หัวข้อ 4) ไม่ใช้ตัวหนังสือบรรยาย เว้นแต่บรรทัดล็อก |
| ขอบเขต | ฉากที่ NPC ปฏิเสธตัวละครแสดงเป็นท่าที่ NPC ยกมือหรือหันตัว ไม่ใช่ท่าหนี และเส้นผูกยังไม่ขาด |
| ผู้ที่ไม่อยู่ | ถ้าพวกพ้องไม่อยู่ในเฟรม (ข่าวถึงตัวละคร) ฉากแสดงจดหมายหรือของที่เขาส่งมา ไม่แสดงตัวเขา |
| ความโศก | เมื่อพวกพ้องตาย เส้นผูกไม่ขาดทันที ค้างเป็นเส้นจางสามวินาทีแล้วสลายเป็นฝุ่นสีเดียวกับสายนั้น |

## 4. อีโมตของอารมณ์ 24 อย่าง

อีโมตอยู่เหนือศีรษะตัวละครหลักหรือในมุมเฟรม ขนาดไม่เกินหนึ่งในหกของความสูงตัวละคร วาดแบบเส้นดิบ ไม่ใช้สีสดเกินกรอบสีของสายที่เกี่ยว ตารางอารมณ์ที่ใช้ได้ต่อสายอยู่ที่ [../systems/bonds/02-feelings.md](../systems/bonds/02-feelings.md)

| อารมณ์ | อีโมต | ท่าที่เห็นร่วม |
| --- | --- | --- |
| ห่วง | เส้นหยักสองเส้นเหนือคิ้ว | มือกุมชายเสื้อ มองไปทางที่เขาอยู่ |
| คิดถึง | ควันเส้นเดียวลอยเฉียงไปทางที่เขาอยู่ | ถือของที่เขาให้ ไม่ใช้ |
| ภูมิใจ | ประกายเล็กสามจุดเหนือไหล่ | ยืนตรงขึ้นหนึ่งนิ้ว ไม่ยิ้มกว้าง |
| ไว้ใจ | เส้นผูกหนาขึ้นชั่วครู่ | ปล่อยมือจากอาวุธ หันหลังให้เขาโดยไม่มองกลับ |
| ขอบคุณ | มือสองข้างประกบกลางอก | ก้มหัวเล็กน้อย |
| ยินดี | จุดสว่างสองจุดข้างแก้ม | ยิ้มมุมปากและมือแตะหน้าอก |
| เสียใจ | หยดน้ำเดียวไหลตามแก้ม | นั่งลงข้างของที่ทิ้งไว้ |
| น้อยใจ | แก้มป่องเล็กและก้อนเมฆเล็ก | หันตัวครึ่งหนึ่งจากเขา เก็บของขวัญไว้ใต้เสื้อ |
| โกรธ | เส้นแหลมสามเส้นตั้งเหนือศีรษะ | กำมือแน่นและเดินหนีสองก้าวแล้วหยุด |
| ผิดหวัง | เส้นดิ่งลงตรงมุมปากและไหล่ตก | มองพื้นแล้วถอนหายใจ |
| อิจฉา | เส้นเขียวหมองเล็กพันข้อมือ | มองของหรือคนที่เขามีแล้วหันหนี |
| หึง | ไฟสีแดงเล็กที่ใจกลางอก | ตามองไปที่คนที่สามแล้วก้มหน้า |
| หวงแหน | วงแขนครึ่งวงเหนือศีรษะ | ขยับตัวบังหน้าเขาโดยไม่รู้ตัว |
| เกรงใจ | เหงื่อเม็ดเดียวข้างขมับ | ยืนห่างกว่าปกติหนึ่งก้าว |
| เคารพ | เส้นตรงสั้นเหนือศีรษะ (ก้มศีรษะ) | ยืนตรงและมือประสานหน้า |
| ชื่นชม | ประกายสองดวงในตา | เอียงหน้ามองมือหรือผลงานของเขา |
| ละอาย | หน้าแดงจางครึ่งหน้า | ก้มหน้าและเสื้อผ้าถูกจัดไม่หยุด |

| แค้น | เปลวสีดำเล็กรอบเงา | เก็บของที่เขาให้ไว้ในมือแต่ไม่แตะ |

| เอ็นดู | ใบอ่อนสีอ่อนหนึ่งใบข้างศีรษะ | ย่อตัวลงให้ระดับสายตาเท่าเขา |

## 5. ไอเทมคู่

ภาพของแต่ละซีกยืนเดี่ยวได้ ซีกที่ครบคู่เปล่งแสงเส้นบางสีของสายเมื่ออยู่ในมือทั้งสองคน ของระลึกเป็นซีกเดียวที่ไม่มีแสง เส้นผูกจางไปที่ที่ตั้งของอีกซีก ตัวเลขความหายากตาม [../systems/bonds/06-paired-items.md](../systems/bonds/06-paired-items.md)

| คู่ | ภาพซีก | ครบคู่ | ของระลึก |
| --- | --- | --- | --- |
| PR-01 นกหวีดไม้ | หวีดไม้สีน้ำตาลอ่อน ผูกด้วยเชือกสีเดียวกัน ซีก ก มีรอยแกะอักษรตัวแรกของเจ้าของ | เสียงหวีดเงียบแต่เส้นฟ้าบางขึ้นจากปากหวีด | หวีดซีกเดียวที่เป่าแล้วไม่มีเสียงแต่เส้นฟ้าเบาพุ่งไปทางที่เขาตาย |
| PR-02 เหรียญแบ่งครึ่ง | เหรียญทองแดงผ่าครึ่งเรียบ ด้านผ่าเป็นรอยหยักที่พอดีกัน | วางสองซีกใกล้กัน ขอบหยักเรืองทองบางประสานกัน | เหรียญครึ่งเดียวที่ขอบเรืองทองจางเมื่อถือไว้ในมือ |
| PR-03 สายถักเส้นเดียว | สายผ้าถักสีเทาลายเดียวกัน ที่ปลายมีปมเฉพาะของแต่ละคน | ปมสองข้างสั่นพร้อมกันเมื่อเจ้าของคนใดคนหนึ่งเจ็บ | สายที่ข้อมือตัวละครค่อย ๆ ซีดตลอดปี |
| PR-04 เข็มทิศคู่ | เข็มทิศทองเหลืองฝาปิด หน้าปัดไม่มีตัวเลข มีเข็มเดียวชี้หาอีกซีก | เข็มสั่นเล็กน้อยเมื่อขยับเข้าใกล้ | เข็มชี้ที่ที่เขาตาย แล้วนิ่งเมื่อตัวละครไปถึง |
| PR-05 แหวนสองซีก | แหวนเงินผ่าครึ่งตามแนวเส้นผ่านศูนย์กลาง ซีกละครึ่งวง | สองซีกประกบเป็นวงเมื่ออยู่ใกล้กัน แสงแดงจางที่ขอบ | แหวนซีกเดียวที่ตัวละครสวมที่นิ้วก้อย |
| PR-06 สิ่วคู่ครูศิษย์ | สิ่วเหล็กด้ามไม้ซีก ก ใหม่ ซีก ข ด้ามสึกเรียบ | ด้ามทั้งสองเรืองขาวบางเมื่อใช้ร่วมงานเดียวกัน | สิ่วด้ามสึกที่ศิษย์ใช้ตีชิ้นแรกหลังครูตาย ได้รอยบากใหม่ |
| PR-07 ขนนกปีกคู่ | ขนปีกยาวสีเดียวกับเจ้าของ ปลายขนสีขาว | ขนลอยขึ้นเมื่ออีกฝ่ายตกลง | ขนสว่างน้อย ๆ เมื่อมีอันตรายใกล้ |
| PR-08 กระจกแตกสองชิ้น | กระจกเงารูปสามเหลี่ยมไม่เท่า ขอบคม ห่อผ้านุ่ม | พูดชื่อแล้วหน้าอีกฝ่ายปรากฏในกระจก ขอบกระจกสว่างสีของสาย | เศษกระจกที่ไม่ตอบ ผิวเรียบเงียบ |
| PR-09 เหรียญสลักชื่อคู่ต่อสู้ | เหรียญรางวัลสลักชื่อคู่แข่งด้านหลัง | สองเหรียญวางคู่กันเรืองส้มบาง | เหรียญที่ไม่มีคู่ ชื่อที่สลักจางลงทีละตัวอักษรตามปี |
| PR-10 โคมคู่ | โคมกระดาษเล็กมีเทียนในตัว ไส้ไม่ใช้น้ำมัน | จุดดวงหนึ่ง อีกดวงสว่างในมืออีกคน | โคมดับถาวร จุดสว่างได้วันครบรอบวันเดียว |

## 6. ฉากของโหนด bn และ kn

ฉากสั้น 4–8 วินาที ตามกติกาข้อ 1 ภาพหลักต่อโหนด (ทางเลือก ก) ข) ค) แสดงฉากที่ตัวละครเลือกจริงตามกติกา [13-storyline-scenes.md](13-storyline-scenes.md))

| โหนด | ภาพหลัก |
| --- | --- |
| bn.b1 | ซอยท้ายหมู่บ้านยามเย็น เด็กสองคนนั่งบนรั้วไม้ ขาห้อยแกว่ง กำลังแกะไม้ชิ้นเดียวกันเป็นสองซีก |
| bn.t1 | ประตูหมู่บ้านรุ่งเช้า เพื่อนวัยรุ่นยืนสะพายถุงผ้า ตัวละครยืนสองก้าวห่างบนอีกฝั่งของประตู |
| bn.a1 | ห้องเช่าเล็ก เพื่อนนั่งหน้าโต๊ะที่มีจดหมายทวงหนี้ ตัวละครเอามือแตะโต๊ะแต่ยังไม่ล้วงถุงเงิน |
| bn.a2 | กองเกวียนหรือกองเรือสองลำเคียงกัน คู่หูสองคนยืนบนคนละดาดฟ้าส่งเชือกให้กัน |
| bn.a3 | ลานงานเลี้ยงหรือสะพานตอนเย็น ตัวละครและอีกคนยืนห่างครึ่งก้าว เส้นผูกสีแดงเข้มเป็นเส้นประเสมอ |
| bn.a4 | ท่าเรือหรือทางแยก เพื่อนโบกมือไกล ตัวละครยกมือครึ่งทาง แสงอุ่นจากด้านหลังเพื่อน |
| bn.a5 | โรงฝึกเล็ก ศิษย์วัยเด็กถือเครื่องมือแน่น ตัวละครย่อตัวลงให้ระดับตาเท่ากัน |
| bn.e1 | ห้องเงียบหรือหาดยามเย็น ตัวละครนั่งข้างเตียงหรือกองไฟ เก้าอี้ว่างอีกตัว เส้นผูกเส้นหนาปมกลางที่เรืองจาง |
| kn.b1 | ลานบ้านหรือโรงช่าง ญาติผู้ใหญ่ชี้เครื่องมือแก่เด็ก หรือพี่ยืนบังน้องจากลม |
| kn.t1 | ธรณีประตูบ้านของญาติ เด็กสะพายถุงเล็ก ญาติยื่นมือรับถุงโดยไม่พูด |
| kn.a1 | เตาไฟบ้านเก่า พี่น้องสองคนนั่งคนละฝั่งโต๊ะ ที่ว่างตรงกลางมีชามอาหารเดียว |

## 9. ฉากของแม่แบบเรื่องของเพื่อน (`FT-01` ถึง `FT-12`)

ใช้กับเพื่อนที่ไม่มีชื่อ ใบหน้าและเผ่าตามเพื่อนที่สุ่มได้ ฉากเป็นของแม่แบบ

| แม่แบบ | ภาพหลักของขั้นวิกฤต |
| --- | --- |
| FT-01 หนี้ท่วม | ประตูห้องเพื่อนมีแผ่นป้ายทวงหนี้ติดทับกันสามชั้น เพื่อนยืนหลังประตูแง้มเล็ก |
| FT-02 ตามหาคนหาย | ผนังห้องมีกระดาษภาพวาดใบหน้าเรียงยี่สิบแผ่น เพื่อนมือถือแผ่นล่าสุดและตาแห้งผาก |
| FT-03 ฝันข้ามทวีป | ท่าเรือยามเช้า เพื่อนยืนที่บันไดเรือ กระเป๋าสะพายสองใบ ตัวละครยืนบนท่าห่างสี่ก้าว |
| FT-04 ป่วยเรื้อรัง | เตียงหน้าต่างเปิด เพื่อนนั่งยกถ้วยยาเปล่า ถ้วยยาหกใบเรียงบนชั้น |
| FT-05 ถูกตามล่า | ห้องใต้ถุนมืดมีเทียนเล่มเดียว เพื่อนยืนข้างประตูลับและฟังเสียงรองเท้าบนพื้นบน |
| FT-06 แต่งงานแล้วห่างกัน | ลานงานแต่ง เพื่อนในชุดพิธียืนกับคู่ ตัวละครยืนขอบวงคนและถือของขวัญห่อผ้า |
| FT-07 ก้าวหน้าเร็วกว่า | ห้องรับรางวัล เพื่อนยืนบนแท่นและมองลงหาตัวละคร ตัวละครยืนกลางแถวแล้วปรบมือช้ากว่าเพื่อน |
| FT-08 คำสัตย์ที่ผิด | โต๊ะอาหารสองที่นั่ง เพื่อนวางสิ่งที่เคยสัญญาไว้ตรงกลางโต๊ะและไม่มองหน้า |
| FT-09 ทายาทของเพื่อน | ลานบ้านเพื่อน เด็กน้อยจับมือตัวละครอีกมือจับมือเพื่อน แสงอุ่นจากด้านหลังทั้งสามคน |
| FT-10 ศรัทธาเปลี่ยน | หน้าวัดใหม่ เพื่อนในชุดนักบวชพับแขน ตัวละครยืนใต้เงาต้นไม้ห่างวัดสามก้าว |
| FT-11 สงครามเรียก | หน้าค่ายเกณฑ์ เพื่อนในแถวผู้อาสา ตัวละครถือถุงขนมที่ไม่ถูกรับ |
| FT-12 ความลับที่เพื่อนเก็บ | ห้องมืด เพื่อนเปิดหีบเล็กแสดงของที่ไม่เคยให้ใครเห็น ตัวละครยืนที่ธรณีประตูและยังไม่ก้าวเข้า |
