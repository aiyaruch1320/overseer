# ภาพและ UI ของเหตุการณ์ท้องถิ่น

ภาพรวม: [README.md](README.md) · เหตุการณ์โลก: [12-event-visuals.md](12-event-visuals.md) · เนื้อหา: [../systems/events/local-events.md](../systems/events/local-events.md) · รายประเทศที่สร้างอัตโนมัติ: [../_generated/local-events-by-country.md](../_generated/local-events-by-country.md) · NPC: [npcs/README.md](npcs/README.md)

เหตุการณ์ท้องถิ่น (`LC-`) เกิดในประเทศหรือคู่ประเทศเดียว ไม่เปลี่ยนแผนที่ ผู้เล่นเห็นเมื่อตัวละครอยู่ใกล้หรือมี NPC ที่บรรจบอยู่ในเรื่องของตน ไฟล์นี้บอกว่าเห็นอะไรและได้ยินอะไร ตรวจแล้วว่าเหตุการณ์โลก 194 รายการมีภาพครบใน [12-event-visuals.md](12-event-visuals.md) แต่เหตุการณ์ท้องถิ่นเดิมไม่มีภาพเลย ไฟล์นี้เติมช่องนั้น

## 1. กติกากลาง

| ชิ้น | กติกา |
| --- | --- |
| รูปแบบ | ฉากท้องถิ่น (L) 8–12 วินาที ตามชนิดใน [12-event-visuals.md](12-event-visuals.md) เหตุการณ์ที่เป็นข่าวหรือการตัดสินเงียบ ๆ ใช้การ์ด (C) 3–5 วินาทีพร้อมเสียง ตารางบอกรูปแบบทุกแถว |
| สีกรอบ | ใช้สีกรอบของหมวดที่เหตุการณ์ขึ้นกับ (คอลัมน์ขึ้นกับของ [../systems/events/local-events.md](../systems/events/local-events.md)) ตามตารางใน [12-event-visuals.md](12-event-visuals.md) เหตุการณ์ที่ขึ้นกับหลายหมวดใช้หมวดแรก |
| เส้นใน | เส้นบางสีหลักของทวีปที่เหตุการณ์เกิด (จากค่า UI ใน [01-continents.md](01-continents.md)) วาดห่างขอบกรอบ 4 พิกเซล ให้ผู้เล่นแยกเหตุการณ์ท้องถิ่นออกจากเหตุการณ์โลกที่ไม่มีเส้นใน |
| NPC | NPC ที่บรรจบ (อย่างน้อยสามตัว) อยู่ในเฟรมเดียวกัน หน้าตาตามแถว NPC ใน [npcs/README.md](npcs/README.md) ไม่ใส่เกินห้าตัว |
| กล้อง | ระดับสายตาของตัวละครหลักที่ยืนห่างฉากอย่างน้อยสามก้าว ไม่ซูมเข้าหน้า NPC เกินครึ่งจอ |
| เสียง | เสียงเปิดตามหมวดกรอบ ตามด้วยเสียงหนึ่งอย่างที่ระบุในแถว |
| สิ่งผิดปกติ | ทุกแถวมีสิ่งผิดปกติหนึ่งอย่างที่ผู้เล่นสังเกตเห็น ใช้เป็นตัวชี้ให้เห็นว่าเหตุการณ์นี้ไม่ใช่ฉากธรรมดา |
| ผลถาวร | ถ้าเหตุการณ์มีผลถาวร ฉากสุดท้ายค้างภาพสุดท้ายหนึ่งวินาที ไม่มีคำบรรยาย |

## 3. เหตุการณ์ที่เขียนมือ 76 รายการ

ทุกแถว: รูปแบบ L ยกเว้นที่ระบุ C ภาพที่เห็น · เสียง · สิ่งผิดปกติ

| **LC-01 ชื่อบรรทัดแรก** | ซาฮารัน | WR | L · หอบัญชีมีตะเกียงดวงเดียว นิ้วเปื้อนหมึกของมัมมี่หยุดที่บรรทัดแรก ผ้าพันตรงข้อนิ้วเปียกหมึกดำ · เสียงปาปิรุสเปิดช้า · ผิดปกติ: หมึกบรรทัดแรกเรืองจางกว่าบรรทัดอื่น |
| **LC-02 ซิสเตอร์ไร้เงา** | เนบูเลีย | FG | L · หน้าต่างกระจกสียามค่ำ ซิสเตอร์คุกเข่าและผนังด้านหลังมีเงาเทียนแต่ไม่มีเงาของเธอ · เสียงสวดเบากว่าที่ควร · ผิดปกติ: เทียนไม่ไหวเมื่อเธอเดินผ่าน |
| **LC-03 แผนที่ในเนื้อเยื่อ** | เนเรีย | HP | L · สไลม์น้ำเงินครามลอยหน้าท่าเรือ เส้นทองในเนื้อหมุนไปทางเดียว พ่อค้าสองฝ่ายยืนห่างสามก้าว · เสียงเนื้อเยื่อบีบคล้ายเข็มทิศเคลื่อน · ผิดปกติ: เส้นทองหายทีละเส้นเมื่อมีคนจ้อง |
| **LC-04 เด็กที่ไม่มีสปอร์** | ซิลวาเนล | BIO | L · บึงหมอกเขียว เด็กเผ่าเห็ดไม่มีฝุ่นสปอร์รอบตัวและสไลม์ข้างเดินใสกลางฝุ่นทอง · เสียงฝุ่นตกเบา ๆ ทุกที่ยกเว้นรอบสองคน · ผิดปกติ: ฝุ่นเปิดเป็นวงบางรอบสองคนเหมือนมีกำแพงใส |
| **LC-05 คำเตือนที่ขายได้** | คาซ-ดูรัม | DR | C · ตลาดบนผาลาวา นักขายคำเตือนกางม้วนกระดาษทีละแผ่น นักบินไวเวิร์นเงยหน้ามองฟ้าที่เปลี่ยนสีเล็กน้อย · เสียงปากกาขูดหินเย็น · ผิดปกติ: ข้อความบนม้วนจางเมื่อคนอ่านเกินสองคน |
| **LC-06 รองเท้าคู่เดียว** | มอร์เฮเวน | HP | L · ลานสุสานเงียบ เด็กกูลนั่งยองหน้าหลุม แม่มนุษย์ยืนห่างสามก้าวถือรองเท้าคู่ใหม่ ทั้งสองไม่ขยับ · เสียงลมต่ำและเล็บเด็กขูดดิน · ผิดปกติ: รองเท้าเก่าของเด็กสีเดียวกับคู่ที่แม่ถือ |
| **LC-07 คราบสุดท้าย** | เนเรีย | WR | L · ท้องน้ำใต้น้ำตก หินรูปคนมีดอกบัววางหน้า เงือกเจ้าหญิงแตะผิวน้ำแล้วดึงมือกลับ · เสียงเพลงนาคาเบาจนเกือบเป็นฟองน้ำ · ผิดปกติ: เกล็ดบนหินเรืองเมื่อเพลงถึงท่อนที่สาม |
| **LC-08 ชื่อที่ไม่เคยพบ** | เมคาเรีย | MC | L · ห้องซ่อมหุ่น หุ่นเทาอ่อนยืนหันหน้าออกหน้าต่าง ตากระจกเปลี่ยนจากเขียวเป็นขาวเมื่อได้ยินชื่อ · เสียงข้อต่อหมุนช้า · ผิดปกติ: เสียงที่เรียกชื่อเป็นเสียงผู้หญิงที่ไม่มีใครในห้อง |
| **LC-09 สนธิสัญญาศพ** | ซาฮารัน | GI | L · บันไดหินใหญ่ ยักษ์ยืนกางสัญญาศพเท่าเตียงบนผนัง มัมมี่ยื่นผ้าพันเก่าให้ · เสียงกลองหนังหนึ่งจังหวะ · ผิดปกติ: ผ้าพันเปลี่ยนสีเป็นสีของหินที่ยักษ์ถือ |
| **LC-10 ความเงียบสองฉบับ** | อัซการ์ | DR | L · ห้องรังฟ้ามืดกว่าปกติ ผู้ปรนนิบัติสองฝ่ายยืนสองมุมอ่านม้วนเดียวกันแต่เสียงต่างกัน · เสียงลมหายใจมังกรหายไปครึ่งจังหวะ · ผิดปกติ: เงาของม้วนยาวกว่าม้วน |
| **LC-11 ผู้อาวุโสที่ไม่มาประชุม** | อัซการ์ | DR | L · ราวเชือกกลางลมแปลก กองเรือลมกางใบเปล่า เด็กส่งไปรษณีย์ยืนกางแขนรับลมแทนเรือ · เสียงใบเรือไม่พองสักครั้ง · ผิดปกติ: ธงทุกผืนชี้คนละทิศ |
| **LC-12 บทเพลงชื่อผู้ตายที่เปลี่ยนเสียง** | อัซการ์ | DR | L · ทางเดินฟ้าน้ำ เด็กร้องชื่อผู้ตายยืนข้างผู้ไว้อาลัย ปากอ้ากว้างกว่าเสียงที่ออกมา · เสียงชื่อที่แปลกหนึ่งชื่อซ้อนในบทร้อง · ผิดปกติ: น้ำตกหยุดไหลหนึ่งวินาทีตรงชื่อนั้น |

| **LC-15 ฤดูหว่านที่ธงอื่นไม่ยอมให้ผ่าน** | มอร์เฮเวน | HP | L · ทุ่งข้าวเถ้าสีทองหม่น ทุกธงยืนเป็นเส้นขอบทุ่ง คบไฟที่ยังไม่จุดอยู่ในมือหลายธง · เสียงรวงข้าวเสียดสีกัน · ผิดปกติ: ข้าวหนึ่งต้นเขียวสดกลางเถ้า |

| **LC-23 สมบัติของคนที่ไม่เชื่อกัน** | เนเรีย | WR | L · ท่าโจรสลัด กัปตันเงือกยืนห่างทองสาปหนึ่งช่วงตัว ช่างตีสมอส่ายหน้า · เสียงโลหะตกน้ำ · ผิดปกติ: ทองสะท้อนเงาที่ไม่ใช่ของผู้ถือ |

| **LC-33 หมาป่าที่ไม่ยอมเลิกร้อง** | อัลเดรีย | BIO | L · ทุ่งป่าชายแดนหมาป่า ฝูงนกบินวนต่ำ หัวหน้าสหพันธ์เงยหน้าตามฝูง · เสียงหมาป่าหอนไม่หยุด · ผิดปกติ: เงานกบนพื้นเป็นป่า |
| **LC-34 รหัสปฐมที่ไม่มีใครขาย** | เมคาเรีย | MC | L · โรงไฟฟ้าสาขา ผู้ตรวจยืนบนท่อที่ร้อนผิดทิศ ท่อน้ำมันเรืองเขียวใต้เท้า · เสียงหึ่งต่ำ · ผิดปกติ: ท่อร้อนแต่ไม่มีไอ |
| **LC-35 ซากที่กระซิบกลางคืนจริง ๆ** | เมคาเรีย | MC | L · ป้อมยามดึกซาก ทหารหญิงเฝ้าจดเวลาด้วยตะเกียงเล็ก วิศวกรยืนอ่านตัวเลข · เสียงกระซิบเมื่อเข็มนาฬิกาถึงเวลาเดียวกัน · ผิดปกติ: เสียงกระซิบเป็นเสียงเข็มนาฬิกา |
| **LC-36 รูนไรเฟิลที่ยิงไม่ออก** | เมคาเรีย | MC | L · ลานทดสอบ หุ่นรบยืนตรงมือไร้ลำกล้อง ผู้ทดสอบหุ่นถูกตัดสิทธิ์ยืนข้างปืนรูนที่ไม่ยิง · เสียงไกปืนลั่นเปล่า · ผิดปกติ: รูนบนปืนเรืองจางลง |
| **LC-37 ค่ายพักที่ไม่มีค่าจ้าง** | เมคาเรีย | WR | L · ใต้เมืองเมคาเรีย แม่ค้าวางหม้อข้าวเป็นแถว ช่างไฟซ่อมโคมเดียวที่ติด · เสียงไอน้ำท่อ · ผิดปกติ: ค่ายพักเงียบเมื่อมีคนถามค่าจ้าง |
| **LC-38 ค่าจ้างของคนที่ไม่เลือกข้าง** | เมคาเรีย | MC | L · ลานค่ายบริษัททหาร ทหารปีศาจยืนข้างม้าศึกที่ไม่มีเครื่องหมายบริษัท · เสียงเกือกเดียว · ผิดปกติ: ม้าตัวหนึ่งไม่ยอมก้าวผ่านประตูบริษัท |
| **LC-39 ผู้ชี้ทางที่ถูกสอบ** | ซาฮารัน | WR | L · ทางไปธุลีทิพย์ ผู้ชี้ทางหญิงชี้ไปสองทิศ ทรายสะท้อนแดดไม่ตรงกัน · เสียงเข็มทิศหมุน · ผิดปกติ: รอยเท้าของคาราวานเก่าอยู่เหนือทรายใหม่ |

| **LC-41 คำถามที่ไม่ควรเผา** | ซาฮารัน | WR | L · บ่อน้ำเย็น ออร์คหญิงนั่งข้างแพะ พ่อค้าอาวุธวางหีบดาบ ทัพรออยู่ไกล · เสียงแพะเคี้ยวหญ้า · ผิดปกติ: ดาบทุกเล่มห่อผ้าเดียวกัน |

| **LC-43 ต้นไม้ที่ผู้อาวุโสไม่ยอมนับ** | ซิลวาเนล | BIO | L · ต้นไม้เก่าลานรากเพราะน้ำเลี้ยงข้น ผู้เก็บน้ำถือขวดแล้วเอียงดู ผู้พิทักษ์รากพันรอบลำต้น · เสียงของเหลวหยดช้า · ผิดปกติ: น้ำเลี้ยงเป็นสีเดียวกับสีตาผู้พิทักษ์ |
| **LC-44 ลัทธิที่รู้เส้นทางของเรา** | ซิลวาเนล | BIO | C · ลัทธิประชุมใต้ต้นไม้ มนุษย์สิ้นหวังยกมือ สายลับในเสื้อคลุมยืนหลังแถวสาม · เสียงสวดเรียบ · ผิดปกติ: เหรียญบริจาคเป็นของเมคาเรีย |
| **LC-45 โควตาที่ถูกขโมยโดยคนกลาง** | ซิลวาเนล | PO | C · ตลาดน้ำเลี้ยงมืด เด็กลักลอบวางขวดเล็ก ผู้ซื้อปลอมตัวหยิบทองก่อนมองสินค้า · เสียงขวดเปิด · ผิดปกติ: ขวดแต่ละใบมีตรารัฐต่างกัน |
| **LC-46 ล่าที่ไม่มีใครอนุญาต** | ซิลวาเนล | WR | L · ป่าชายลำต้น หัวหน้าสภายืนเหนือหินประกาศล่า นักล่าแก่ซ่อนมือที่เปื้อน · เสียงเขาสัตว์ · ผิดปกติ: รอยกีบที่ไม่ตรงกับสัตว์ในรายชื่อ |
| **LC-47 ระฆังที่หยุดตีเพราะเสียงเงียบ** | เนบูเลีย | FG | C · หอระฆังเมืองหมอก ฝ่ายเงียบกับฝ่ายเวลายืนคนละด้านของเชือก ระฆังแขวนนิ่ง · เสียงหนึ่งจังหวะที่ไม่มีคนตี · ผิดปกติ: เงาลิ้นระฆังขยับ |
| **LC-48 ผู้ที่ถูกชี้ตัวว่านำหมอกมา** | เนบูเลีย | FG | C · ลานเมืองหมอก คนบาปถูกชี้ตัวกลางวงล้อม ผู้ถอดเสียงยกมือห้าม · เสียงกระซิบจากหมอกไม่ตรงกับริมฝีปากใคร · ผิดปกติ: หมอกบางลงตรงตัวผู้ถูกชี้ |
| **LC-49 ที่เล่าไม่ตรงกันสองเรื่อง** | เนบูเลีย | CT | C · ล็อกคลังท่า สองคนเล่าเรื่องเดียวกันคนละเสียง มีกำแพงคั่น · เสียงประตูล็อก · ผิดปกติ: รอยมือบนกำแพงเป็นรอยเดียวกัน |
| **LC-50 ผู้ที่หยุดขบวนไม่ได้** | เนบูเลีย | FG | L · ขบวนในหมอกทึบ ผู้นำหญิงเดินนำตา ไม่หยุด ผู้ตามเงียบ · เสียงเท้าพันผ้าบนพื้นเปียก · ผิดปกติ: อาหารในกระสอบมีน้อยกว่าคนที่เดิน |
| **LC-51 ดวลแทนสงครามธาตุ** | อัซการ์ | DR | L · ลานดวลสองเกาะ ไฟและน้ำแยกสองฝั่ง ผู้ตัดสินยืนกลางยกแขน · เสียงดาบเงียบก่อนฟัน · ผิดปกติ: ไอน้ำและไฟลอยเหนือสนามพร้อมกัน |
| **LC-52 ปั๊มที่มีอายุ** | อัซการ์ | WR | L · เกาะลอยฟ้า ปั๊มเทียมเปล่งแสงจาง วิศวกรถือเกจและส่ายหน้า · เสียงปั๊มเอื่อย · ผิดปกติ: เกจชี้เลขเท่าเดิมทุกวัน |
| **LC-53 ตัวเลขที่หมอผีแต่ง** | มอร์เฮเวน | WR | C · ลานหมอผีกาธเรธ เด็กโอเกอร์ชี้ตัวเลขบนกระดูกเสบียง หมอผีหันหลัง · เสียงกระดูกกระทบกัน · ผิดปกติ: ตัวเลขขีดซ้ำมือเดียวกัน |
| **LC-54 แบบล้อมเมืองที่ขายไปแล้ว** | มอร์เฮเวน | MC | C · โรงร่างป้อมเหล็ก แบบล้อมเมืองม้วนเป็นหลอดในมือตัวแทนเมคาเรีย · เสียงตะปูเคาะเหล็ก · ผิดปกติ: เส้นแบบหนึ่งเส้นขัดกับข้อตกลง |
| **LC-55 ชื่อบนสนามรบ** | มอร์เฮเวน | DM | L · สนามรบผี นักผจญภัยกลับชาติถือสมุดเก็บค่าประสบการณ์ ทหารผีมองเงียบ · เสียงโลหะผุ · ผิดปกติ: ชื่อทหารผีเรืองเมื่อสมุดเปิด |
| **LC-56 อนาคตที่สว่างเกินไป** | คาซ-ดูรัม | GI | L · ห้องจักรพรรดิลาวา นักพยากรณ์เพลิงชี้ลาวาที่สว่างเกิน เงาเย็นหนึ่งสายซ่อนอยู่ใต้ผิว · เสียงลาวาปริ · ผิดปกติ: เงาเย็นไม่ไหลตามกระแส |
| **LC-57 ผู้ที่ไม่ใช่ศัตรูของปากเหว** | คาซ-ดูรัม | GI | L · ป้อมปากเหว นักบวชทหารถือตะเกียงไล่ตรวจเลือดปีศาจ ล่ามดาร์กเอลฟ์ยืนเฉย · เสียงโซ่ไกลลึก · ผิดปกติ: ตะเกียงดับเมื่อผ่านล่าม |
| **LC-58 กุญแจที่เจ็ดหายไป** | เนเรีย | DR | L · น้ำตกย้อนฟ้า ผู้ถือกุญแจยืนครบหกดอก ดอกที่เจ็ดว่างอยู่ในอุ้งมือ · เสียงกุญแจกระทบกัน · ผิดปกติ: น้ำตกหยุดกึ่งทางฟ้า |
| **LC-59 จารึกที่ซิมอนอยากขาย** | เนเรีย | PL | L · ห้องโบราณคดี เด็กฝึกหัดอ่านจารึกบนแผ่นหินเปียก นักดำน้ำคนแคระถือขวดอากาศ · เสียงน้ำหยด · ผิดปกติ: จารึกขาดท่อนตรงที่น้ำมาจาก |
| **LC-60 จดหมายที่ถูกกักที่ท่า** | อัลเดรีย | WR | C · ท่าอาณานิคม จดหมายพระเจ้าวางบนกองในโกดังถูกสาปด้วยผ้าคลุม ผู้ว่าเกาะชี้ตรา · เสียงตราประทับไม่ลง · ผิดปกติ: จดหมายหนาขึ้นทุกปี |
| **LC-61 นักบวชที่ไม่มีวัด** | อัลเดรีย | GD | L · โรงงานใต้ดิน คนงานสวดโดยไม่มีรูปเทพ ตำรวจลับอ่านรายงานในเงา · เสียงสวดต่ำและพร้อมกัน · ผิดปกติ: เทียนหนึ่งเล่มสว่างโดยไม่มีไส้ |
| **LC-62 ผงที่ไม่ควรจุด** | อัลเดรีย | CT | L · เหมืองผลึก เด็กผงเรืองส่องสว่างแก่ผู้ใหญ่ที่เรียงแถว เครื่องวัดพายุสั่น · เสียงผลึกคลื่นเสียงสูง · ผิดปกติ: ผงเรืองลอยเข้าหาผู้วัด |
| **LC-63 ชุดที่ผีขอยืม** | อัลเดรีย | DM | L · สุสานเก่า ผีผู้ทรยศยืนในชุดที่ไม่ใช่ของตน ผู้ดูแลสุสานถือกุญแจเงียบ · เสียงชุดเสียดสีกับหญ้า · ผิดปกติ: ชุดมีร่องรอยของคนที่ขอยืม |
| **LC-64 แขนที่สี่** | เมคาเรีย | MC | L · ห้องติดตั้งแขนเหล็ก ทหารสี่แขนยกแขนทีละข้างตรวจ ช่างติดตั้งวางเครื่องมือ · เสียงเหล็กกระทบ · ผิดปกติ: แขนข้างที่สี่ไม่สะท้อนในกระจก |
| **LC-65 บัญชีที่แพทย์คนหนึ่งเก็บ** | เมคาเรีย | MC | C · ห้องบัญชีวิจัย แพทย์เปิดสมุดจำนวนผู้เสียชีวิตที่ถูกซ่อนในตู้ยา · เสียงตู้เหล็กลั่น · ผิดปกติ: เลขหน้าไม่ต่อเนื่อง |
| **LC-66 ดวงตาที่ไม่มีใครมอง** | ซาฮารัน | GI | L · ใต้บันไดหมื่นขั้น ผู้เก็บดวงตาศิลายืนห่างดวงตาที่ห่อผ้า ยักษ์หญิงถือตะเกียงมองขึ้น · เสียงหินกลิ้งเบา · ผิดปกติ: ผ้าห่อกระเพื่อมเมื่อตะเกียงผ่าน |
| **LC-67 ตลาดวันเดียว** | ซาฮารัน | GI | L · ตลาดผีปรากฏหนึ่งฤดู ร้านแสงเทียนกลางทรายและผู้ซื้อต่างทวีปแออัด · เสียงเงินกระทบเงา · ผิดปกติ: เงาร้านค้าไม่ตรงกับร้าน |
| **LC-68 ข้อที่ผูกมังกร** | ซิลวาเนล | DR | L · ห้องบัญชีภูต พิกซี่ชี้ข้อสัญญายุคปฐมที่เรืองเขียว ผู้ถอนสัญญายืนมองมือ · เสียงปีกบางสั่น · ผิดปกติ: ข้อสัญญาเรืองเป็นรูปมังกร |
| **LC-69 รายชื่อผู้จ่าย** | เนบูเลีย | PO | C · ห้องใต้ดินกิลด์ สมุดเงาเล่มดำถูกเปิดในมือรอง ไฟเทียนหรี่ในตรอก · เสียงปากกาขนนกเบา · ผิดปกติ: ชื่อบนสมุดเขียนสลับมือ |
| **LC-70 เงาที่ไม่มีเจ้าของพูดได้** | เนบูเลีย | FG | L · แดนไร้เงา เงาวิญญาณลอยกลางตรอกและหลายสายพูดพร้อมกัน ผู้เก็บศพเงยหน้ามอง · เสียงกระซิบเสียงเดียวกัน · ผิดปกติ: เงาไม่ตามผู้ใดบนพื้น |
| **LC-71 สัญญาของผู้บัญชี** | มอร์เฮเวน | PO | L · ตลาดเลือดยามดึก ผู้บัญชีหญิงเล็กยืนข้างตู้สัญญา นิ้วเปื้อนหมึกชี้ข้อท้าย · เสียงปากกาและกระดาษหนัง · ผิดปกติ: ข้อท้ายเขียนด้วยหมึกที่ไม่ตรงกับข้ออื่น |
| **LC-72 สัญญาเจ็ดปีที่นับผิด** | เนเรีย | WR | L · กาบเรือโจรสลัด ลูกเรือหนุ่มยืนข้างสัญญาที่ปักบนเสา ผู้หนีโทษชี้เลขวัน · เสียงเชือกเสียดสีเสา · ผิดปกติ: วันที่สัญญาไม่ตรงกับพระจันทร์ |
| **LC-73 หนี้น้ำที่โอนมือ** | ซาฮารัน | WR | L · ลานบ่อน้ำ เด็กแบกถังสองใบยืนข้างผู้เฝ้าน้ำร่างล้ม หญิงเก็บน้ำชี้ถ้วยบัญชี · เสียงถังกระทบ · ผิดปกติ: ถังเปียกแต่เด็กปากแห้ง |
| **LC-74 จดหมายที่ไม่ได้ส่ง** | เมคาเรีย | MC | L · ค่ายบริษัท ทหารยืนยามกับจดหมายที่ไม่ได้ส่ง ผู้บัญชาการเห็นแล้วเบนสายตา · เสียงกระดาษพับ · ผิดปกติ: ซองจดหมายเก่ากว่าเหล็กเกราะ |
| **LC-75 โรงเรียนของผู้พ้นพันธะ** | อัลเดรีย | DR | L · โรงเก็บข้าวเก่ากลายเป็นห้องเรียน ผู้พ้นพันธะสอนนักเรียนหลังไฟตะเกียง · เสียงชอล์กบนกระดาน · ผิดปกติ: ไม่มีกุญแจที่ประตูห้อง |
| **LC-76 กรงที่ไม่เหลือสัตว์** | ซิลวาเนล | BIO | L · ป่าชายลำต้น กุญแจกรงเป็นพวงในมือชายหนีไม่มีกรงสักใบ เด็กสัตว์มองตา · เสียงกุญแจกระทบเบา · ผิดปกติ: กุญแจทุกดอกสะอาดและไม่มีสนิม |

## 4. เหตุการณ์ที่สร้างอัตโนมัติ (LC-1xx)

เหตุการณ์ที่รหัสขึ้นต้นด้วย LC-1 ถึง LC-2 ([../_generated/local-events-by-country.md](../_generated/local-events-by-country.md) 61 รายการ) มาจากแม่แบบ LT-1 ถึง LT-6 ภาพจึงมาจากแม่แบบหนึ่งชุดต่อชนิด ปรับสีและทรงด้วยไฟล์ประเทศ ([countries/README.md](countries/README.md)) ไม่เขียนทีละรายการ

| แม่แบบ | ภาพที่เห็น | เสียง | สิ่งผิดปกติ | รูปแบบ |
| --- | --- | --- | --- | --- |
| LT-1 ศึกชายแดน | แนวทหารสองฝ่ายยืนห่างกันเท่าหอก ธงสองสีบนเนินเดียว NPC ผู้บัญชาการยืนหน้าสุด | กลองรบหนึ่งจังหวะ | ธงฝ่ายหนึ่งหนักเกินที่ควร ตกลงมาเกือบถึงพื้น | L |
| LT-2 คดีใหญ่ | ห้องพิจารณาตามระบอบของประเทศ (ศาล สภา บัญชี ศรัทธา พิธี) ผู้ถูกกล่าวหายืนกลางห้อง ผู้พิทักษ์ยืนข้าง | ค้อนหรือระฆังหนึ่งครั้ง | ที่นั่งผู้พิพากษาหนึ่งตัวว่างและฝุ่นบางเรียบ | L |
| LT-3 ปีขาดแคลน | ตลาดโล่งข้างโกดังปิด ผู้นำและพ่อค้ายืนห่างกัน เด็กถือถุงเปล่า | เสียงล้อเกวียนเปล่า | ราคาข้าวบนป้ายถูกขีดเขียนทับสามชั้น | C |
| LT-4 งานใหญ่ | ลานก่อสร้างหรือพิธีใหญ่ ช่าง นักบวช และผู้ปกครองยืนพร้อมหน้า หอคอยหรือสะพานครึ่งเสร็จ | เสียงค้อนไม้และระฆังเล็กสลับ | ช่องเสาหนึ่งช่องถูกเว้นว่างโดยไม่มีใครอธิบาย | L |
| LT-5 แขกต่างถิ่น | ทางเข้าตลาดมีขบวนต่างเผ่าถึงพร้อมของที่ไม่เคยเห็นในเมือง พ่อค้าและผู้ค้ำยืนรอ | เสียงกระดิ่งขบวน | ภาษาป้ายสองภาษาติดข้างกันแต่ไม่ตรงความหมาย | L |
| LT-6 ข่าวร้าย | ผู้ส่งข่าวมาถึงประตูเมือง ผู้ปกครองรับม้วนสารด้วยมือเดียว ผู้ที่มีญาติในที่ประสบภัยยืนห่าง | เสียงสารฉีกซองช้า | ม้วนสารที่เปิดแล้วยังมีซองปิดอีกหนึ่งชั้น | C |

**ปรับตามประเทศ** ใช้ชุดสีและทรงสถาปัตยกรรมของประเทศจาก [countries/](countries/README.md) ชื่อประเทศและชื่อแม่แบบอยู่บรรทัดบนของการ์ด NPC ที่บรรจบสามตัวตามแถวในไฟล์สร้างอัตโนมัติ
