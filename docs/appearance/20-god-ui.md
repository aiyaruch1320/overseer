# หน้าจอและเอฟเฟกต์ของพระเจ้า

ภาพรวม: [README.md](README.md) · ระบบ: [../systems/god/README.md](../systems/god/README.md) · โลกเปลี่ยนรูป: [11-world-changes.md](11-world-changes.md) · ภาพเหตุการณ์: [12-event-visuals.md](12-event-visuals.md) · กรอบระดับ: [05-weapons-rules.md](05-weapons-rules.md) หัวข้อ 4

ไฟล์นี้พรรณนาสิ่งที่ผู้เล่นเห็นและได้ยินเมื่อเป็นพระเจ้า ใช้สร้างภาพต้นแบบและวางหน้าจอ แต่ละหน้าจอมี ผัง สี การเคลื่อนไหว เสียง และข้อความ

## 1. น้ำเสียงภาพ

พระเจ้าในโลกนี้ไม่ใช่แสงสวยงามจากฟ้า เป็นพลังที่อ่อนแรงตั้งแต่มหาล่มสลาย มือของพระเจ้าบนจอจึงดูเหมือนแสงที่พยายามลอดผ่านเมฆหนา ไม่ใช่แสงที่สาดเต็มที่ ทุกเอฟเฟกต์ของพระเจ้ามีขอบที่สั่นเล็กน้อยเหมือนเปลวที่ถูกลม

| ชื่อสี | ใช้กับ | hex | ลักษณะ |
| --- | --- | --- | --- |
| แสงศรัทธา | พลังสายสร้าง พร ฝีมือ ของศักดิ์สิทธิ์ | #e8c36a | ทองอุ่นแบบเปลวเทียน ไม่ใช่ทองเหลืองมันวาว |
| ความหวาดกลัว | พลังสายทำลาย คำสาป ของต้องสาป | #8a2433 | แดงเลือดหมูที่ดำลงตรงกลาง ขอบเป็นควัน |
| ลิขิต | เบนเหตุการณ์ | #b8c0cc | เงินเย็นเหมือนเส้นด้าย |
| ฝัน | หน้าเข้าฝัน | #2e2a5a | น้ำเงินครามเข้มมีหมอกม่วงอ่อน #6a5a9a |
| พื้นหลังของพระเจ้า | แผงทุกแผง | #0e0f14 | ดำอมน้ำเงิน เนื้อผ้ากำมะหยี่ด้าน |
| ตัวอักษร | ข้อความทั่วไป | #e6e0d0 | ขาวกระดาษเก่า |

กรอบระดับของของในหีบใช้สีกรอบชุดเดียวกับอาวุธ (C #a0a0a8 · U #6aa05a · E #a05ac8 · L #d8a030 · R ตาม [05-weapons-rules.md](05-weapons-rules.md))

## 2. หน้าจอเฝ้ามอง

หน้าหลักตลอดชีวิต

| ส่วน | ที่ | หน้าตา |
| --- | --- | --- |
| ฉากชีวิต | กลางจอ เต็มความกว้าง | ฉากของตัวละครตอนนั้น (บ้าน ทาง ศึก) ตามภาพทวีปและประเทศ |
| เส้นชีวิต | ล่างสุด สูงหนึ่งในแปดของจอ | แถบเวลาจากเกิดถึงอายุเทียบ 75 จุดหยุดตามอายุเป็นหมุดหิน หน้าต่างพระเจ้าที่จะถึงเป็นจุดเรืองทองจาง ([13-storyline-scenes.md](13-storyline-scenes.md)) การแทรกแซงที่ทำไปแล้วเป็นรอยนิ้วมือทองหรือแดงบนแถบ |
| แผนที่เล็ก | มุมขวาบน | ทวีปที่ตัวละครอยู่ จุดของตัวละครกระพริบช้า ลางของเหตุการณ์โลกเป็นวงหมอกสีตามเหตุการณ์ |
| แผงพระเจ้า | ขอบขวา แคบ | ดวงไฟสองดวงซ้อนแนวตั้ง ดวงบนทอง (แสงศรัทธา) ดวงล่างแดงเลือดหมู (ความหวาดกลัว) ระดับเป็นของเหลวในแก้วทรงหยด ตัวเลขเล็กข้างดวง ใต้ดวงไฟคือปุ่มห้าปุ่ม: หีบ ฝัน กระซิบ ปาฏิหาริย์ พงศาวดาร |
| ศรัทธาเทพของตัวละคร | ใต้รูปตัวละครมุมซ้ายบน | เปลวเทียนเล็กหนึ่งเล่ม สูงตามศรัทธาเทพ สีเปลี่ยนจากทอง (ภักดี) ผ่านขาว (ลังเล) ถึงน้ำเงินเย็น (ชิงชัง) เมื่อค่าเปลี่ยน เปลวกระตุกขึ้นหรือหรี่ลงพร้อมตัวเลข +3 หรือ −2 ลอยขึ้นจาง ๆ |
| คำอธิษฐาน | ขอบซ้าย | การ์ดกระดาษสาม้วนลอยเข้ามาจากขอบ (หัวข้อ 6) |

**การเรียกผู้เล่น** ([../systems/experience/07-attention.md](../systems/experience/07-attention.md))

| ระดับ | หน้าตา | เสียง |
| --- | --- | --- |
| หยุด | ฉากชีวิตหรี่และช้าลงจนนิ่งในครึ่งวินาที แผงผ้าดำกลางจอ บนสุดเป็นเหตุที่หยุด (ช่วงอายุ หน้าต่าง ลาง) ใต้นั้นเป็นการ์ดที่รออยู่เรียงแนวนอน ปุ่ม "ให้ชีวิตเดินต่อ" มุมขวาล่าง | ระฆังหินหนึ่งเสียง |
| การ์ด | การ์ดเลื่อนจากขอบซ้าย ขอบการ์ดเป็นวงเวลาที่หดลงตามเวลาที่เหลือ บนจอไม่เกินสองใบ ใบใหม่ดันใบเก่าลง เวลาไม่หยุด | กระดาษถูกพลิก เบา |
| หน้าต่างที่ไม่หยุด | จุดบนเส้นชีวิตเรืองทองเข้มขึ้นและเต้นช้าสามครั้ง ปุ่มหีบและฝันบนแผงพระเจ้ามีขอบทองบาง ๆ จนหน้าต่างผ่านไป | ไม่มี |
| การ์ดที่ไม่ทันขึ้น | ไม่มีอะไรบนจอ บรรทัดในบันทึกเรื่องราวมีเครื่องหมายเทียนดับเล็ก ๆ หน้าบรรทัด | ไม่มี |

**ปุ่มที่ใช้ไม่ได้** (ถึงเพดานหรือพลังไม่พอ) เป็นสีเทาด้าน มีเส้นนาฬิกาทรายบอกเวลาที่ใช้ได้อีก ปุ่มไม่หายจากจอ เพื่อให้ผู้เล่นรู้ว่ามีอยู่

**เสียงพื้น** เสียงแวดล้อมของทวีป (ลม ไฟ น้ำ) เบา ๆ ทุกครั้งที่ดวงไฟเพิ่ม มีเสียงหยดน้ำหนึ่งหยด (ทอง: หยดใส · แดง: หยดหนัก)

## 3. หีบประทาน

| ช่วง | สิ่งที่เห็น |
| --- | --- |
| เปิด | ฉากชีวิตหรี่และเบลอ แผ่นผ้าดำกำมะหยี่คลี่ขึ้นจากล่างกลางจอ ฝาหีบไม้ดำสลักลายเส้นทองเปิดเอง ฝุ่นแสงลอยขึ้น |
| การ์ด | การ์ดหกใบเรียงเป็นสามคู่ ซ้ายถึงขวา: พร (ขอบทอง) · คำสาป (ขอบแดงเลือดหมู) · ฝีมือและของ (ขอบเงิน) ช่องว่างเป็นที่ว่างบนผ้า ไม่มีการ์ดเปล่า |
| การ์ดหนึ่งใบ | สูงเท่าสามในสิบของจอ บนสุดเป็นไอคอนของพร คำสาป หรือภาพของจริง กลางเป็นชื่อและระดับ (กรอบสีตามระดับ) ล่างเป็นผลหนึ่งบรรทัด มุมล่างขวาเป็นราคา: หยดทองหรือหยดแดงพร้อมตัวเลข ถ้าพลังไม่พอ ราคาเป็นสีเทาและการ์ดเอียงลงเล็กน้อย |
| วางเมาส์บนการ์ด | การ์ดยกขึ้น เงาเข้มขึ้น ช่องข้างการ์ดแสดง "เหตุที่ขึ้น" (เช่น ตรงกับสงครามที่จะถึง) และลูกศรศรัทธาเทพ (+11 ทอง หรือ −10 น้ำเงิน) |
| ทอยใหม่ | ปุ่มลูกเต๋ากระดูกมุมขวาล่าง ราคาโตตามครั้ง (5 → 10 → 20) กดแล้วการ์ดคว่ำพร้อมกัน สะบัดเป็นควันแล้วใบใหม่ลอยลง ใบที่ล็อกมีเชือกแดงพันมุม ไม่คว่ำ |
| เลือก | การ์ดที่เลือกลอยขึ้นตรงกลาง ใบอื่นจางลงเป็นทราย การ์ดแตกเป็นแสงสีของสายพลังแล้วพุ่งเข้าฉากชีวิต |
| ข้าม | ผ้าม้วนกลับ ไม่มีเสียงพิเศษ |

**ตัวละครได้รับ** ฉากสั้นสามวินาทีในฉากชีวิต ตามชนิด

| ชนิด | ฉาก |
| --- | --- |
| พร | แสงทองตกเป็นเส้นบางหนึ่งเส้นลงบนตัวละคร ตัวละครเงยหน้า (ถ้าศรัทธาเทพ ≥ 20) หรือไม่รู้ตัว (ถ้าต่ำกว่า) |
| คำสาป | เงาดำรูปมือผ่านตัวละครหนึ่งครั้ง ตัวละครหนาวสั่น แสงรอบตัวหม่นลงหนึ่งระดับ |
| ฝีมือ | มือของตัวละครเรืองจาง ทำงานตอนนั้นได้คล่องขึ้นเห็นได้ (ค้อนตกตรงจังหวะ ลูกธนูเข้าเป้า) |
| อาวุธศักดิ์สิทธิ์ | อาวุธตกลงจากฟ้าปักพื้นตรงหน้า ด้ามยังอุ่น มีเถ้าทองรอบรอยปัก |
| อาวุธต้องสาป | อาวุธโผล่จากเงาใต้เท้า ดึงขึ้นมาเองครึ่งหนึ่ง เย็นจนมีฝ้า |

**เสียง** เปิดหีบ: ไม้เก่าเสียดกัน · การ์ดลง: กระดาษหนาวางบนผ้า · ทอยใหม่: ลูกเต๋ากระดูกกลิ้งบนหิน · เลือกพร: ระฆังเล็กเสียงเดียว · เลือกคำสาป: เสียงลมดูดกลับ

## 4. เข้าฝัน

| ช่วง | สิ่งที่เห็น |
| --- | --- |
| เข้า | ฉากชีวิตเปลี่ยนเป็นกลางคืนไม่ว่าเวลาไหน ตัวละครนอนหลับเป็นเงาขาวด้านล่างจอ สีครามเข้มไหลเข้าจากขอบ หมอกม่วงลอยต่ำ |
| สามทาง | สามประตูหมอกยืนเหนือร่างที่หลับ เรียงซ้ายกลางขวา แต่ละประตูมีสัญลักษณ์ความฝันลอยอยู่กลาง (งู ไฟ แม่น้ำ ดาบ ดวงตา ดวงจันทร์ ดอกไม้ อีกา มงกุฎ ฯลฯ) วาดเป็นเส้นแสงสีตามสัญลักษณ์ ใต้ประตูมีชื่อทางหนึ่งบรรทัด และภาพฝันสองถึงสามบรรทัดตัวเอียง |
| ใจของเขา | ใต้แต่ละประตูมีเทียนหนึ่งเล่ม: เต็มใจ เปลวสูงนิ่ง · ลังเล เปลวไหวซ้ายขวา · ขัดขืน เปลวต่ำเกือบดับ ข้างเทียนมีเหตุผลหนึ่งถึงสองข้อ ตัวเล็กสีขาวกระดาษ เช่น "เขากลัวน้ำ" |
| เงาของผล | วางเมาส์บนประตู หมอกในประตูแสดงภาพเงาเลือนของที่ทางนั้นพาไป (ป่า เรือ คนที่รอ) และหนึ่งบรรทัดของเงาของผล |
| เลือก | ประตูที่เลือกเปิด แสงครามไหลเข้าร่างที่หลับ ประตูอื่นกลายเป็นหมอกแล้วหาย |
| ตื่น | ฉากกลับเป็นเวลาจริง ตัวละครลืมตา หนึ่งบรรทัดว่าเขาจำอะไรได้ (ตามผลภายหลัง ไม่บอกผลตอนนี้) |
| ผลตอนตัดสินใจ | เมื่อตัวละครถึงจังหวะตัดสินใจ การ์ดเล็กขึ้นมุมบน: ทำตาม (สัญลักษณ์เรืองทอง) · ตีความผิด (สัญลักษณ์เอียงและแตกเป็นสองภาพ) · ปฏิเสธ (สัญลักษณ์จางเป็นสีเทา) · ขัดขืน (สัญลักษณ์กลับหัวสีน้ำเงินเย็น) |

**เสียง** เข้า: เสียงลมหายใจช้าของผู้หลับ และเสียงสูงยาวหนึ่งเสียงแบบแก้วถูกลูบ · เลือก: ประตูไม้ไกล ๆ เปิด · ตื่น: นกเช้าหนึ่งตัว

**ภาระใจ** เมื่อภาระใจถึง 1 เปลวเทียนของศรัทธาเทพมีเงาสีเทาพันรอบ ถึง 2 เกิดฉากเหตุการณ์ภาระใจ ตัวละครนั่งคนเดียวในที่มืด แสงของพระเจ้าส่องไม่ถึงตัวเขาหนึ่งฉาก

## 5. กระซิบ

| ส่วน | หน้าตา |
| --- | --- |
| วงคำใบ้ | กดปุ่มกระซิบ วงกลมเก้าช่องคลี่รอบตัวละครในฉาก แต่ละช่องเป็นไอคอนเส้นเงิน: ระวัง (ตา) · กล้าเถิด (เปลว) · จงไป (ลูกศรตามเข็มทิศ) · จงอยู่ (ราก) · จุดอ่อนของศัตรู (รอยร้าว) · คนนั้นโกหก (หน้ากากครึ่งซีก) · ช่วย (มือยื่น) · สางเรื่อง (ปมเชือกคลาย) · ชี้ทายาท (ต้นกล้า) |
| คำใบ้ที่ชี้คนหรือที่ | หลังเลือก ตัวชี้เป็นเส้นด้ายเงินลากจากตัวละครไปที่ NPC ในฉากหรือทวีปบนแผนที่เล็ก |
| คำใบ้ที่หน้าต่างพระเจ้าแนะนำ | ช่องนั้นเรืองทองจางกว่าช่องอื่น |
| ส่ง | ไอคอนกลายเป็นลางในฉากหนึ่งอย่างตามคำใบ้ (นกบินผิดทาง ใบไม้ปลิวไปทิศเดียว แสงตกบนหน้า NPC ครึ่งซีก) |

**เสียง** เสียงกระซิบไม่มีคำ เบาจนเกือบไม่ได้ยิน และลมพัดผ่านใบไม้หนึ่งครั้ง

## 6. คำอธิษฐาน

| ส่วน | หน้าตา |
| --- | --- |
| การ์ด | กระดาษสาม้วนเล็กลอยเข้าจากขอบซ้าย คลี่ครึ่งหนึ่ง บนกระดาษเป็นถ้อยคำอธิษฐานลายมือของตัวละคร (ตามเผ่า: อักษรเหลี่ยมของคนแคระ ลายพู่กันของเอลฟ์ รอยกรงเล็บของเผ่าสัตว์) |
| เวลา | ขอบการ์ดเป็นเส้นไหม้ช้า ๆ จากปลายหนึ่ง เมื่อไหม้ถึงอีกปลาย การ์ดเป็นเถ้า (หมดเวลา) |
| ผู้อธิษฐานแทน | การ์ดมีรูปเล็กของผู้อธิษฐานที่มุม และเส้นด้ายแดงโยงไปหาตัวละคร |
| คำตอบ | ปุ่มสี่ปุ่มใต้การ์ด: ให้ (หยดทอง) · ให้แบบแปลก (หยดทองมีรูปดาว) · ปฏิเสธ (ฝ่ามือ) · ลงโทษ (หยดแดง) การนิ่งคือปล่อยให้ไหม้ |
| ผลให้ | การ์ดลุกเป็นไฟทองแล้วหาย ฉากชีวิตมีแสงทองตกตรงตัวผู้ขอ |
| ผลลงโทษ | การ์ดถูกขยำดำแล้วร่วง ฉากชีวิตมีเงาแดงผ่านตัวผู้ขอ |

## 7. ปาฏิหาริย์

### 7.1 เลือกและเล็ง

| ช่วง | สิ่งที่เห็น |
| --- | --- |
| เปิด | แผนที่โลกขยายเต็มจอ ฉากชีวิตย่อเป็นวงกลมมุมซ้ายล่าง แถบปาฏิหาริย์คลี่ด้านล่าง แบ่งสี่กลุ่มตามสาย (สร้าง ทำลาย มังกร ลิขิต) แต่ละแบบเป็นไอคอนกลมพร้อมราคาและนาฬิกาทรายถ้ายังรอ |
| เล็ง | เคอร์เซอร์เป็นวงแสงตามสาย (วงทองสำหรับสร้าง วงแดงเลือดหมูมีควันสำหรับทำลาย เส้นด้ายเงินสำหรับลิขิต) ขนาดวงตามเป้าหมาย (ประเทศ ทวีป) ประเทศใต้เคอร์เซอร์ยกขอบขึ้นเล็กน้อย |
| หมุดผนึก | ประเทศที่มีมังกรตำนานอาศัยและ AL-01 มีโล่โปร่งรูปเกล็ดสีของมังกรนั้น (AL-01 เป็นโล่ลายคำสัตย์สีทองหม่น) ครอบเมื่อเล็งด้วยปาฏิหาริย์สายทำลาย วงเคอร์เซอร์แตกเป็นสองชั้น ชั้นนอกคือแรงที่ผนึกรับไว้ ข้อความ "ผนึกของ<ชื่อมังกร>จะรับแรงนี้ไว้ และมันจะเจ็บ" แผงผลที่คาดแสดงผลที่ลดระดับ อารมณ์มังกรที่จะตก และการตอบกลับที่คาด (ปกป้อง คำราม ตื่นด้วยความเจ็บ) |
| ตัวละครอยู่ในเป้า | ป้ายเล็กกระพริบที่จุดตัวละคร: "เขาอยู่ที่นี่ จะรอดด้วยลาง แต่จะบาดเจ็บ" |
| ผลที่คาด | แผงข้างเคอร์เซอร์: ราคา ระยะรอ NPC ที่เสี่ยง (รูปเล็กเรียงพร้อมโอกาสตาย) เหตุการณ์ที่จะปิด (ขีดฆ่า) เหตุการณ์ที่จะเปิด (ไอคอนประตู) ศรัทธาและความหวาดกลัวที่จะเปลี่ยน ทั้งหมดเป็นผลที่คาด ไม่ใช่ผลทอย |
| ยืนยัน | กดค้าง 1.5 วินาที วงเคอร์เซอร์เต็มเป็นวงกลมตามเวลา ปล่อยก่อนเต็มคือยกเลิก ปาฏิหาริย์มหาต้องกดค้าง 3 วินาที และจอสั่นเบาตลอดการกด |

### 7.2 ลางของปาฏิหาริย์ใหญ่

หนึ่งฤดูก่อนเกิด บนแผนที่ประเทศเป้าหมายมีวงหมอกสีตามสายหมุนช้า ในฉากชีวิต (ถ้าตัวละครอยู่ใกล้) ผู้คนเห็นลาง: ดาวดวงใหม่ที่สว่างขึ้นทุกคืน (MR-17) พื้นดินมีรอยร้าวเป็นวง (MR-18) ปลาตายลอยเต็มฝั่ง (MR-19) ทะเลเดือดเป็นจุด (MR-20) ปุ่มยกเลิกเป็นวงหมอกที่แผงพระเจ้า กดแล้วคืนพลังครึ่งหนึ่ง

### 7.3 วันเกิดเหตุ

ปาฏิหาริย์ระดับเล็กเป็นฉากสั้น 3 ถึง 5 วินาทีบนแผนที่และในฉากชีวิตถ้าตัวละครอยู่ที่นั่น ระดับกลางขึ้นไปใช้ไวยากรณ์ห้าจังหวะของ [11-world-changes.md](11-world-changes.md) หัวข้อ 1.2 (20 ถึง 40 วินาที)

| --- | --- | --- | --- | --- |

| MR-08 แผ่นดินไหว | น้ำในบ่อสั่นเป็นวง | พื้นแยกเป็นรอยหยัก หอคอยเอนแล้วล้ม | ฝุ่นหินลอยค้าง | เสียงหินครางลึก |

| MR-14 ผู้พิทักษ์จากฟ้า | ขนนกหรือเกล็ดชิ้นเดียวตกกลางลาน | สัตว์วิเศษลงจากเมฆช้า ๆ ยืนบนกำแพง | ผู้คนวางเครื่องเซ่นหน้ากำแพง | เสียงร้องยาวของสัตว์นั้น |

| MR-20 ยกแผ่นดินใหม่ | ทะเลเดือดเป็นจุด ฟองขาวลอย | หินดำยกขึ้นจากน้ำ น้ำไหลออกจากไหล่หินเป็นน้ำตก | เกาะใหม่ควันขึ้น นกทะเลบินวนครั้งแรก | น้ำไหลจากหินที่เพิ่งพ้นทะเล |
| MR-21 ปาฏิหาริย์แห่งพระเจ้า | ทุกทวีปบนแผนที่สว่างขึ้นพร้อมกัน | ใช้ฉาก GD-04 ใน [12-event-visuals.md](12-event-visuals.md) | ดวงไฟทองของแผงพระเจ้าเปลี่ยนเป็นดวงอาทิตย์เล็ก | ความเงียบทั้งโลก แล้วเสียงคนนับล้านพูดคำเดียวกัน |

## 9. เสกตามใจ

| ช่วง | สิ่งที่เห็น |
| --- | --- |
| เปิด | ปุ่มเสกตามใจอยู่ท้ายแถบปาฏิหาริย์ เป็นวงกลมว่างมีจุดสามจุด ข้างปุ่มมีรอยนิ้วมือสามรอยบอกโควต้าที่เหลือในชีวิตนี้ รอยที่ใช้แล้วเป็นสีเถ้า |

| ปฏิกิริยา | ถ้าสภาพของเป้าหมายเปลี่ยนผล ภาพย่อมีกรอบเรืองสีของแก่น และแผงขึ้นบรรทัด "ที่นี่ ..." บอกว่าผลต่างจากปกติเพราะอะไร |
| ยืนยัน | เล็งบนแผนที่ แล้วกดค้างเหมือนปาฏิหาริย์อื่น วงแหวนสามชั้นหมุนรวมเป็นวงเดียวแล้วพุ่งลงเป้า |
| ชื่อ | หลังวันเกิดเหตุ ชื่อที่ตั้งเขียนด้วยลายมือทองหรือแดงลงบนแผนที่ตรงเป้า ค้างหนึ่งปีในเกม แล้วกลายเป็นตัวจางที่เห็นเมื่อวางเมาส์ |
| เงาสะท้อน | ถ้าเกิด ควันจากขอบวงไหลไปที่ข้างเคียงบนแผนที่ แล้วเกิดฉากเล็กของเงาสะท้อน |

**เสียง** หมุนวงแหวน: หินบดหินเสียงเบา · ช่องลงตัว: เสียงคลิกของกลไกโบราณ · ส่วนผสมที่เป็นปาฏิหาริย์ที่รู้จัก: ระฆังเงินหนึ่งเสียง

## 10. คำปฏิญาณและพงศาวดารสายตระกูล

| ส่วน | หน้าตา |
| --- | --- |
| เลือกคำปฏิญาณ | ตอนเกิด หลังการ์ดเกิด จอมีแผ่นหินสามแผ่นตั้งเรียงบนพื้นทราย แต่ละแผ่นสลักคำปฏิญาณหนึ่งข้อ แผ่นที่สี่ล้มอยู่ข้าง ๆ เขียนว่า "ไม่ปฏิญาณ" เลือกแล้วแผ่นนั้นเรืองทองที่ร่องสลัก แผ่นอื่นจมทราย |
| ระหว่างชีวิต | ข้อความคำปฏิญาณเป็นตัวเล็กใต้รูปตัวละคร มีไอคอนแผ่นหินเล็ก ไม่มีแถบความคืบหน้า |
| ตอนตาย | แผ่นหินขึ้นบนหน้าบันทึกชีวิต ถ้าสำเร็จ ร่องสลักเต็มด้วยทองหลอม ถ้าไม่สำเร็จ แผ่นร้าวกลาง แต่ยังตั้งอยู่ และมีหน้าพงศาวดารต่อ |
| ฉายาชีวิต | ป้ายผ้าหนึ่งถึงสามผืนห้อยจากป้ายหลุมศพในหน้าบันทึกชีวิต ผืนดีสีครีม ผืนร้ายสีเถ้า |
| พงศาวดารสายตระกูล | หน้าตำนานมีต้นไม้ของสายตระกูล ใบของแต่ละชีวิตมีสีตามฉายาของพระเจ้าในชีวิตนั้น ค่าสะสมเป็นวงแหวนรอบลำต้นที่หนาขึ้นเรื่อย ๆ ไม่มีตัวเลขใหญ่กลางจอ สิ่งที่เปิดใหม่ขึ้นเป็นผลไม้บนกิ่งพร้อมชื่อ |
| จังหวะชะตา | ตอนเริ่มโลก ถ้วยสี่ใบบนโต๊ะหิน น้ำในถ้วยต่างสี (ใส อุ่น เทา ม่วงหมุน) เลือกถ้วยแล้วน้ำไหลลงแผนที่โลก |

## 11. สั่งตัวละครและใบเกิด

| ส่วน | หน้าตา |
| --- | --- |
| ช่องคำขอ | ก่อนเกิด จอเป็นความมืดมีจุดแสงเล็กหนึ่งจุดกลางจอ (ชีวิตที่ยังไม่เกิด) ใต้จุดแสงมีช่องพิมพ์บนแผ่นกระดาษสาเก่า ข้อความนำว่า "อยากให้ชีวิตนี้เป็นอย่างไร" ใต้ช่องมีป้ายคำพร้อมใช้ (เผ่า ถิ่น ฐานะ นิสัย อาชีพ โทนชีวิต) แตะแล้วเติมลงช่อง และปุ่มสุ่มทั้งหมด |
| ระหว่างแปล | จุดแสงเต้นช้า ๆ คำในช่องลอยขึ้นเป็นเส้นแสงบางเข้าหาจุด ไม่มีวงโหลด |
| ใบเกิด | จุดแสงคลี่เป็นแผ่นหนังสัตว์สีครีม ขอบไหม้ แบ่งสี่แถว: ได้แน่นอน (หมึกดำ เครื่องหมายถูก) · แนวโน้ม (หมึกน้ำตาล เส้นคลื่น) · ทำไม่ได้ (หมึกแดงจาง ขีดฆ่า พร้อมเหตุผลตัวเล็ก) · ยังสุ่ม (เครื่องหมายคำถามจาง) มุมบนขวาเป็นวงแต้มชะตาสิบเม็ด เม็ดที่ใช้เป็นสีทอง เม็ดที่คืนจากชีวิตที่ยากเป็นสีเถ้า |
| คำบรรยาย | หนึ่งถึงสองประโยคตัวเอียงบนสุดของแผ่น |
| ปุ่ม | เริ่มชีวิต (ตราประทับขี้ผึ้ง) · แก้ใบคำขอ · สุ่มส่วนที่ยังสุ่มใหม่ |
| ไม่มี LLM | หน้าเดียวกัน ถ้าตัวแปลคำพ้องไม่เข้าใจ แผ่นเปิดเป็นหน้าเลือกเองทันที ไม่มีข้อความแจ้งข้อผิดพลาด |

**ช่องพิมพ์ในฝัน (ยังไม่ทำ เก็บเป็นไอเดีย)** ในหน้าเข้าฝัน (หัวข้อ 4) ใต้สามประตูมีเส้นหมอกบางที่แตะแล้วกลายเป็นช่องพิมพ์ ข้อความที่พิมพ์ลอยเป็นตัวอักษรแสงเข้าประตูที่ผู้แปลจับได้ ถ้าไม่ตรงประตูใด ตัวอักษรกระจายเป็นหมอกรอบร่างที่หลับ เมื่อไม่มี LLM เส้นหมอกนี้ไม่แสดง
