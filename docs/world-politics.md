## 3. ห่วงโซ่เหตุและผลระหว่างประเทศ

### 3.1 ห่วงโซ่ศิลาลอย
AZ-08 ขุดลึกขึ้นเพราะบรรณาการเพิ่ม → ขายผิดกฎให้ MK-09 → MK-09 สร้างกองเรือและวางแผนเมืองลอยฟ้า → AZ-01 ส่งกองปีกโจมตี → ศรัทธามังกรของคนไร้ปีกลดลงที่ AZ-07 และ AZ-09 → อารมณ์อีริดานและโอรัน-ซัลลดลง

### 3.2 ห่วงโซ่น้ำ
ปากเหว KD-08 ดูดน้ำใต้ดิน → ระดับน้ำที่ MH-08 ลดลง → ความหิวใน MH ขึ้น → MH-11 เตรียมข้ามทะเลไป NR และ AL → NR-01 ตั้งกำแพงภาษี → AL-17 ถูกกดดันให้ขึ้นราคาธัญพืช → MH-06 ได้ข้าวช้าลง

### 3.3 ห่วงโซ่ต้นไม้โลก
MK-14 ปล่อยควัน → SV-03 ใบเหลือง → น้ำเลี้ยงลดลง → SV-15 ขึ้นราคา → AL-26 และ SV-02 รับผู้ป่วยน้อยลง → ผู้ลี้ภัยโรคไปหา AL-19 → รากไม้กรองพิษหมอกอ่อนแรง → SV-06 รายงาน NB-08 → หมอกรุกชายแดน AL-20

### 3.4 ห่วงโซ่ตุ๊กตา
MK-08 ทดลองต่อเนื่อง → MK-02 เกิดจากผลผลิตรุ่นแรก ๆ → ผู้รอดชีวิตหนีสู่ NB-10, AL-13, MK-10 → ข้อมูลรั่วผ่าน NB-09 → MK-03 หุ่นผู้ตื่นเรียกร้องสิทธิ → MK-01 เริ่มปิดข่าว → การเปิดเผย MC-02 / MC-11

### 3.5 ห่วงโซ่ผู้กล้า
AL-02 อัญเชิญผู้กล้า → ฝึกที่ AL-18 → ไปทัพ KD-08 หรือล่าจอมมาร → ผู้กล้าบางคนผิดหวังและไป MH-07 (DM-05) → MH-07 ฝึกผู้กลับชาติ → อาจกลับมาท้าศาสนจักร → GD-02 ศาสนาแตก

### 3.6 ห่วงโซ่ฟอร์เทีย
AL-08 บุก AL-06 → AL-10 ปล่อยกู้ทั้งสองฝ่าย → MK-06 ขายอาวุธทั้งสองฝ่าย → AL-27 ส่งทองซื้ออาวุธ → AL-07 ขายข้าวให้ AL-08 ลับ ๆ → AL-02 ตำหนิ AL-07 → ศาสนากับแรงงานเป็นศัตรูกัน → ถ้าฟอร์เทียชนะ PO-05 จักรวรรดิทุ่งราบ

### 3.7 ห่วงโซ่ธุลีทิพย์
SH-01 ขายธุลีให้ SH-04 → ราคาธุลีขึ้น → SH-02 ฟาโรห์ขาดธุลี → ฟาโรห์ยึดเส้นทาง → สงครามธุลีทิพย์ → เส้นทางคาราวานหยุด → SH-15 ขายเหล็กไม่ได้ → KD-09 และ KD-12 ขาดตลาด → ทวีปไฟต้องหาตลาดใหม่ที่จักรกล

### 3.8 ห่วงโซ่หมอกกินคน
NB-09 ออกทุน → AL-20, MK-13, NB-12 ร่วมภารกิจเมฆา → เจาะประตูเมืองปฐมที่ NB-08 → รอยแยกเปิด หมอกทึบพาสิ่งมีชีวิตมา → NB-12 ล่มในคืนเดียว → NB-03 ปิดตายและขังคนนับร้อย → NB-07 แตกเป็นลัทธิคำพิพากษา → NB-01 ต้องเลือกระหว่างระฆังกับชีวิต → NB-14 และ NB-10 กลายเป็นผู้นำทางเดียว → รากต้นไม้โลกรับพิษเพิ่ม SV-06 รายงาน → AL-20 เรียกกำลังเสริม → ทุ่งราบหวาดกลัวโรคและสิ่งมีชีวิต
