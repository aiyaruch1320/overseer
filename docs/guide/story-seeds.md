# วิธีใส่ไอเดียเนื้อเรื่องลงโลก: เมล็ดเรื่อง แล้วขยาย

ภาพรวม: [../README.md](../README.md) · วิธีจัดเอกสาร: [organization.md](organization.md) · เหตุการณ์ท้องถิ่น: [../systems/events/local-events.md](../systems/events/local-events.md)

หน้านี้ตอบว่าเนื้อเรื่องในโลกนี้มาจากไหน ส่วนไหนแน่นและส่วนไหนยังบาง และเจ้าของโลกใส่ไอเดียของตัวเองอย่างไรให้ Claude ช่วยขยายได้ดีที่สุด

## 2. เมล็ดเรื่องคืออะไร

เมล็ดเรื่องคือประโยคเดียวที่ **เจ้าของโลกคิดเอง** ไม่ต้องรู้รหัสหรือรูปแบบตาราง ยิ่งแปลกหรือมีอารมณ์ยิ่งดี Claude มีหน้าที่ขยายเป็นแถวในไฟล์ ผูกกับ NPC และเหตุการณ์ที่มีอยู่ แล้วตรวจให้

ตัวอย่างเมล็ดเรื่อง (เขียนเพื่อแสดงรูปแบบ ไม่ได้เป็นเนื้อหาของโลก)

| ที่ | เมล็ดเรื่อง | ผูกได้กับ |
| --- | --- | --- |
| AL-02 ลูเมียร์ | นักบุญหญิงคนหนึ่งไม่เชื่อในพระเจ้า แต่ทุกปาฏิหาริย์ของเธอสำเร็จ | GD-04 GD-06, แคทเธอรีน (AL02-2), ฮารุโตะ (AL02-3) |
| NB-05 มอร์เนบ | เด็กคนหนึ่งซื้อเงาของตัวเองคืนจากนักฆ่า และจ่ายด้วยชื่อ | นิกซ์ (NB05-1), ผู้ไร้เงาใน NB-13 |
| SV-14 มอร์ธิล | ผู้ถือขวานโค่นโลกคือคนที่ต้นไม้โลกเรียกให้ตัดเอง | BIO-02, ผู้ถือขวาน (SV14-1) |

เมล็ดเรื่องที่ดีบอกอย่างน้อยหนึ่งข้อ: ใครอยากได้อะไร หรือมีอะไรผิดปกติ หรือสิ่งที่ใครซ่อน ไม่จำเป็นต้องบอกว่าจบอย่างไร

## 3. ช่องที่ใส่ได้ (ไม่บังคับ)

| ช่อง | ใช้ทำอะไร |
| --- | --- |
| ที่ (ประเทศหรือเมือง) | บอกว่าเรื่องนี้เกิดที่ไหน ถ้าไม่ระบุ Claude เสนอให้ |
| เมล็ดเรื่อง | ประโยคเดียว จำเป็นเท่านั้น |
| อารมณ์ที่อยากให้ผู้เล่นรู้สึก | เช่น สงสาร ขนลุก ขำขื่น Claude ใช้เลือกว่าจะให้ใครรอดหรือตาย |
| ห้ามเกิด | เช่น ห้ามให้ NPC ตัวนี้ตาย Claude จะไม่ใช้ทางเลือกนั้น |
| ต้องเกี่ยวกับ | NPC เหตุการณ์ หรือเผ่าที่อยากให้ผูก |
| แรงบันดาลใจ | อนิเมะ นิยาย ภาพยนตร์ ที่ได้กลิ่นคล้ายกัน Claude ยืมเฉพาะธีม ไม่ลอกเนื้อเรื่อง |

## 4. Claude ทำอะไรเมื่อได้เมล็ดเรื่อง

1. อ่านไฟล์ประเทศ NPC ของประเทศนั้น และเหตุการณ์โลกที่เกี่ยวข้อง
2. เสนอ **สองทางขยาย** สั้น ๆ (ผลสมมติ ใครเกี่ยวข้อง) ให้เลือกก่อนเขียนจริง ไม่เขียนยาวถ้ายังไม่ตรงใจ
3. เขียนเป็นแถวเหตุการณ์ท้องถิ่น `LC-` (เขียนมือ) และถ้าเรื่องใหญ่พอ เพิ่ม NPC หรือโหนดที่เกี่ยวข้อง
4. รันตัวตรวจ `npm run docs:verify` ตรวจรหัส น้ำหนัก ลิงก์ และดู [../_generated/country-links.md](../_generated/country-links.md) ว่าไม่เกิดความขัดแย้งใหม่ (ความสัมพันธ์ประเทศ ข้ามทวีป เผ่าไม่ตรง)
5. สรุปให้เจ้าของโลกอ่านรอบเดียว: เรื่องคืออะไร ผูกกับใคร เปลี่ยนอะไรในโลก มีอะไรที่ Claude เติมเองนอกเมล็ดเรื่อง (ให้ทักได้)

## 5. ลำดับที่แนะนำ

| ลำดับ | ที่ | เหตุผล |
| --- | --- | --- |
| 1 | เมืองหลวงหรือประเทศหลักของแต่ละทวีป (9 แห่ง) | ตัวละครหลักผ่านบ่อยที่สุด |
| 2 | ประเทศที่ยังเป็นแถวแม่แบบและ NPC โดดเดี่ยวมากสุด (ดู [../_generated/event-coverage.md](../_generated/event-coverage.md)) | ได้ผลต่อความหนาแน่นมากสุด |
| 3 | เผ่าที่ NPC น้อย | ถ่วงสมดุลกับมนุษย์ |
| 4 | เส้นตามอาชีพที่อยู่กับที่ที่ยังขาด (นักบวชวัด ทหารยาม ครู) | ขยายจาก cr md ld fm |

ไม่ต้องทำครบ ให้ 3 ถึง 5 เมล็ดเรื่องก่อน แล้วดูว่าคุณภาพที่ได้ตรงใจหรือไม่ ปรับวิธีก่อนทำต่อ

## 6. ตัวอย่างข้อความถึง Claude

> ที่ AL-02: นักบุญหญิงที่ไม่เชื่อในพระเจ้าแต่ปาฏิหาริย์ของเธอสำเร็จทุกครั้ง อยากให้รู้สึกอึดอัดแบบไม่รู้ว่าใครถูก ห้ามให้แคทเธอรีนตาย
