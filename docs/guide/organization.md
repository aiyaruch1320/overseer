# วิธีจัดเอกสาร: อะไรอยู่ด้วยกัน อะไรแยก

ภาพรวม: [../README.md](../README.md) · คู่มือ: [README.md](README.md) · รหัส: [id-glossary.md](id-glossary.md)

หน้านี้ตอบคำถามเมื่อมีข้อมูลใหม่ว่าจะวางตรงไหน และเมื่อไฟล์โตแล้วจะตัดตรงไหน

## 1. แบ่งตามคำถามที่ตอบ ไม่ใช่ตามหัวข้อ

เรื่องหนึ่งมีได้สามไฟล์ในสามชั้น เช่น ประเทศ `AZ-01` โอรันธาร์

| ชั้น | ไฟล์ | ใส่อะไร |
| --- | --- | --- |
| โลก | [../lore/countries/01-azgar.md](../lore/countries/01-azgar.md) | ปกครองอย่างไร เผ่าไหน ศัตรูใคร ปมเรื่อง |
| ระบบ | [../systems/economy/02-countries.md](../systems/economy/02-countries.md) | ความมั่งคั่ง W ความเหลื่อมล้ำ G การใช้เงิน M |
| ภาพ | [../appearance/countries/01-azgar.md](../appearance/countries/01-azgar.md) | สี ทรงหลังคา มุมสูง ผู้คน ค่า UI |

ผู้อ่านที่ทำงานหนึ่งอย่างอ่านหนึ่งชั้น ไม่ต้องดึงอีกสองชั้นมาเปลืองหน้าต่างอ่าน เมื่อต้องข้ามชั้นให้ตามรหัส

## 2. ถามสามข้อก่อนวางข้อมูลใหม่

| คำถาม | ถ้าใช่ |
| --- | --- |
| ถ้าเกมไม่มีโค้ดเลย ข้อนี้ยังเป็นจริงในโลกไหม | ชั้นโลก |
| โค้ดต้องอ่านค่าหรือเงื่อนไขนี้ไปคำนวณไหม | ชั้นระบบ |
| คนวาดต้องรู้ข้อนี้เพื่อวาดไหม | ชั้นภาพ |

ถ้าตอบใช่หลายข้อ ให้เขียนเต็มในชั้นที่เป็นเจ้าของข้อเท็จจริง อีกชั้นเขียนเฉพาะรหัสอ้างและสิ่งที่ชั้นนั้นเพิ่ม (เช่น ชั้นภาพเขียน สีของศาสนจักร ไม่เขียนว่าศาสนจักรทำอะไร)

## 3. เมื่อไหร่รวมในไฟล์เดียว

- **เรื่องเดียวกันในชั้นเดียวกัน** ประเทศในทวีปเดียวกันอยู่ไฟล์เดียว (9 ไฟล์ ไม่ใช่ 143) ผู้อ่านเห็นพันธมิตรและศัตรูข้างเคียงในที่เดียว
- **ตารางที่ตัวแถวอ้างถึงกัน** NPC ของกลุ่มประเทศเดียวกัน โหนดเส้นเรื่องของเผ่าเดียวกัน
- **ข้อมูลที่แก้พร้อมกัน** เงื่อนไขกับผลของเหตุการณ์เดียวกันอยู่แถวเดียวกัน ไม่แยกเป็นสองตาราง
- **ขนาดไม่เกินราว 60KB** ถ้าเกินและแบ่งเป็นกลุ่มที่ชัดเจนได้ ให้แบ่ง ถ้าแบ่งไม่ได้ (เช่น ตารางเหตุการณ์ 152 รายการ) ปล่อยไว้ไฟล์เดียวแล้วมีสารบัญหัวข้อ

## 4. เมื่อไหร่แยกไฟล์

| สัญญาณ | แยกเป็น | ตัวอย่างที่แยกแล้ว |
| --- | --- | --- |
| ผู้อ่านสองกลุ่มต้องการส่วนต่างกันของหน้าเดียว | ไฟล์ชั้นโลก + ไฟล์ชั้นระบบ ชื่อเดียวกัน | เผ่า: [lore/races/](../lore/races/README.md) + [systems/character/races/](../systems/character/races/README.md) · มังกร: [lore/dragons/](../lore/dragons/README.md) + [systems/simulation/dragon-mood.md](../systems/simulation/dragon-mood.md) |
| ไฟล์สร้างจากสคริปต์หรือโค้ด | `_generated/` | แคตตาล็อกอาวุธ แคตตาล็อกตัวละคร แผนที่ ดัชนี |
| ไฟล์ไม่ตรงกับโค้ดรุ่นใหม่แล้ว | `appearance/poc-visuals/` | เอกสารภาพเวกเตอร์ของ POC |
| ตารางใหญ่เกินไปจนหาไม่เจอ | แบ่งตามกลุ่มที่คนค้นจริง | อาวุธแยกเป็นของใช้ มาตรฐาน อาชีพ ประเทศ ทวีป โรงตี ตำนาน |
| ส่วนหนึ่งเปลี่ยนบ่อยและอีกส่วนไม่เปลี่ยน | สองไฟล์ | ตารางเหตุการณ์ vs กติกาการแสดงผลเหตุการณ์ |

เมื่อแยก ให้เหลือบรรทัดชี้หนึ่งบรรทัดใต้หัวเรื่องของแต่ละไฟล์ ไปหาอีกไฟล์

## 6. แบบฟอร์มของไฟล์ในแต่ละชั้น

หัวไฟล์ทุกไฟล์เหมือนกัน

1. `# ชื่อ` หนึ่งบรรทัด
2. บรรทัดลิงก์ ภาพรวม · ไฟล์ที่เกี่ยวข้อง (ใช้ลิงก์สัมพัทธ์)
3. ย่อหน้าสั้น ไฟล์นี้ตอบอะไร อ่านเมื่อไร
4. เนื้อหา หัวข้อ `##` ตามชนิด

| ชั้น | ชนิดไฟล์ | โครง |
| --- | --- | --- |
| โลก | ประเทศ | หัวข้อประเทศละหนึ่ง `#### XX-NN ชื่อ` ช่อง **รัฐ** **เรื่องราว** **ความสัมพันธ์** **ปมเรื่องหลัก** |
| โลก | เผ่า | ประวัติ · ที่อยู่ · สายเลือดย่อย · ความสัมพันธ์ · เรื่องราวที่ผูกกับเรื่องหลัก |
| โลก | NPC เส้นเรื่อง | ตาราง หนึ่งแถวหนึ่งรหัส |
| ระบบ | เผ่า | ช่วงค่าสถานะ · ความสามารถ · พร · คำสาป · สกิล |
| ระบบ | ตารางข้อมูล | ตาราง หนึ่งแถวหนึ่งรหัส ช่องเรียงเหมือนกันทุกไฟล์ในชุด |
| ภาพ | รายการ | มุมสูง · ระดับสายตา · วัสดุและสี · เสียงและกลิ่น · ผู้คน · จุดเด่น · ผิดปกติ · ค่า UI (ประเทศ) หรือตารางพร้อมช่อง ค่า UI (ศัตรู อาวุธ) |
| ภาพ | ฉากแอนิเมชัน | ห้าจังหวะ นิ่ง · ลางสุดท้าย · พัง · ฝุ่นตก · ชื่อใหม่ พร้อมเวลา |

## 7. ชื่อไฟล์และโฟลเดอร์

- ชื่อเป็นตัวพิมพ์เล็ก อังกฤษ คั่นด้วยขีด `01-azgar.md` เลขนำหน้าเรียงตามลำดับอ่าน ไม่ใช่ลำดับสำคัญ
- ทุกโฟลเดอร์มี `README.md` ที่เป็นดัชนี บอกว่าไฟล์ไหนตอบอะไร
- โฟลเดอร์ซ้อนไม่เกินสามระดับจาก `docs/` (เช่น `docs/systems/character/races/`)
- ไฟล์ชั้นโลกและชั้นระบบของเรื่องเดียวกันใช้ชื่อเดียวกัน (`04-dwarf.md`) เพื่อให้ตามกันได้ด้วยชื่อ

## 8. ก่อนส่งงาน

```bash
node scripts/check-docs.mjs
node scripts/build-docs-manifest.mjs
```

สองคำสั่งนี้ตรวจรหัสอ้างอิง ลิงก์ และโครงโฟลเดอร์ แล้วสร้างดัชนี ถ้าแก้ไฟล์ที่สคริปต์สร้างข้อมูลจาก (ดู [../_generated/README.md](../_generated/README.md)) ให้รันสคริปต์ที่เกี่ยวข้องด้วย
