# อาวุธจากชาติช่างตีเหล็ก

ระบบ: [README.md](README.md) · วัสดุ: [02-materials.md](02-materials.md) · ประเทศ: [../countries/03-kaz-durum.md](../countries/03-kaz-durum.md)

อาวุธในไฟล์นี้ไม่มีขายสำเร็จรูป ต้อง **สั่งตี** ที่โรงตีของชาตินั้น และมีเงื่อนไขของตัวเอง ขั้นตอนตามหาช่าง การทดสอบ และการทอยผลอยู่ใน [10-forging.md](10-forging.md)

| เงื่อนไขทั่วไป | รายละเอียด |
| --- | --- |
| ทอง | R 250 · E 800 พร้อมตัวคูณตาม [10-forging.md](10-forging.md) หัวข้อ 6 |
| วัสดุ | ตามคอลัมน์ในตาราง ตัวละครต้องหามาเอง |
| ไว้ใจ | ไว้ใจของช่างหรือโรงตีอย่างน้อย 2 (R) หรือ 4 (E) |
| เวลา | R หนึ่งฤดู · E หนึ่งปี ระหว่างนั้นตัวละครทำอย่างอื่นได้ |
| ช่าง | ถ้าตัวละครเป็น `smith` และมี `smithing` ระดับ 3 ตีเองได้ที่โรงตีนั้น ไม่ต้องจ่ายทอง |
