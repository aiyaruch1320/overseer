# อาวุธและไอเทม

อาวุธที่ตัวละครหลักใช้ได้ ตั้งแต่กิ่งไม้และมีดทำครัวที่หาได้ทุกประเทศ ไปจนถึงอาวุธตำนานที่ต้องผ่านเส้นเรื่องพิเศษ รวมมากกว่าหนึ่งพันชิ้น ทุกชิ้นมีระดับ พลัง ค่าสถานะ และความสามารถของตัวเอง อาวุธระดับหายากขึ้นไปมีเรื่องราว ส่วนไอเทมที่ไม่ใช่อาวุธ (เกราะ เครื่องประดับ เครื่องราง ของใช้ในศึก เครื่องมือชีวิตช้า วัสดุ และของสำคัญ) อยู่ในไฟล์ 11 ถึง 18 ใช้ระดับและคำสำคัญชุดเดียวกัน

ระบบต่อสู้: [../combat/README.md](../combat/README.md) · อาชีพ: [../character/08-jobs-overview.md](../character/08-jobs-overview.md) · ประเทศ: [../countries/README.md](../countries/README.md) · เส้นเรื่อง: [../storylines/README.md](../storylines/README.md)

## 1. ระดับความหายาก

ใช้ระดับและน้ำหนักเดียวกับโค้ด (`RARITY` ใน `src/sim/fortune.ts`)

| ระดับ | ชื่อ | น้ำหนักสุ่ม | พลัง | งบค่าสถานะ | งบความสามารถ | เรื่องราว |
| --- | --- | --- | --- | --- | --- | --- |
| ของใช้ | ของใช้ทั่วไป | — | 0 | 0 | ไม่มี หรือหนึ่งอย่างเล็ก | ไม่มี |
| C | ธรรมดา | 100 | 1 | ไม่เกิน +1 | ไม่เกินหนึ่งอย่างเล็ก | ไม่มี |
| U | ไม่ธรรมดา | 38 | 1–2 | +1 ถึง +2 | หนึ่งอย่าง | ไม่มี |
| R | หายาก | 11 | 2–3 | +2 ถึง +3 | หนึ่งถึงสองอย่าง | หนึ่งประโยค |
| E | มหากาพย์ | 2.6 | 3–4 | +3 ถึง +4 | สองอย่าง | สองถึงสามประโยค |
| L | ตำนาน | 0.5 | 5–6 | +4 ถึง +6 | สองถึงสามอย่าง รวมพลังเฉพาะตัวหนึ่งอย่าง | เรื่องเต็ม |

- **พลัง** บวกเข้าการทอยท่าทีปะทะ ยิง และเวท (เมื่ออาวุธเป็นสายเวท) เหมือน `weapon.power` ในโค้ด
- **ค่าสถานะ** ใช้ตัวย่อเดียวกับโค้ด `pow` กำลัง · `mag` เวท · `spd` เร็ว · `luk` โชค · `int` ปัญญา · `vit` ทน
- **ข้อเสีย** อาวุธที่มีค่าติดลบ (เช่น `spd-1`) ได้งบเพิ่มเท่ากับค่าที่ติดลบ
- ของใช้ทั่วไปเป็นระดับต่ำกว่า C ใช้ไม่เกิดโทษไม่ถนัด แต่พลัง 0

## 2. ประเภทและความถนัด

อาวุธแต่ละชิ้นมีประเภทที่ผูกกับความถนัด ความถนัดตรงกับประเภทให้โบนัสระดับ skill ตาม [../combat/01-core.md](../combat/01-core.md) ถ้าไม่มีความถนัดนั้น ทอยด้วยอาวุธนั้น −1 (ยกเว้นของใช้ทั่วไป)

| กลุ่ม | ความถนัด | แท็กการโจมตี |
| --- | --- | --- |
| ดาบ | `sword` | `blade` |
| ขวาน | `axe` | `blade` (บางชิ้น `blunt`) |
| หอก ทวน ง้าว | `spear` · บนหลังสัตว์ `mounted` | `pierce` |
| ธนู หน้าไม้ | `bow` | `pierce` `ranged` |
| มีดสั้น กริช | `dagger` | `blade` หรือ `pierce` |
| มวย สนับ กรงเล็บ | `unarmed` | `blunt` |
| โล่ | `shield` | `blunt` · ท่าทีตั้งรับ |
| ค้อน กระบอง | `hammer` | `blunt` |
| แส้ โซ่ | `whip` | `blade` (ระยะ) |
| หนังสติ๊ก ลูกขว้าง | `sling` | `blunt` `ranged` |
| ปืน | `bow` (การเล็ง) · +1 ถ้ามี `mechanics` | `pierce` `ranged` |
| คทา ไม้เท้า ตำรา เครื่องดนตรี | ความถนัดเวทของธาตุนั้น หรือ `music` | ธาตุของอาวุธ |
| เครื่องมือช่าง | ความถนัดอาชีพ (`smithing` `farming` ฯลฯ) | ตามรูปทรง |

แท็กการโจมตีและธาตุใช้ตารางการแพ้ทางใน [../combat/02-type-matrix.md](../combat/02-type-matrix.md) แท็กสังหาร (`#undead_bane` `#demon_bane` `#dragon_bane`) ให้ผล ★ และมีได้เฉพาะอาวุธระดับ E ขึ้นไป หรืออาวุธเงินกับชนิดที่แพ้เงิน

## 3. ความสามารถ

ความสามารถเขียนเป็นคำสั้นที่ใช้ซ้ำได้ทั้งเอกสาร

| คำ | ผล |
| --- | --- |
| `#แท็ก` | เพิ่มแท็กให้ตัวละครขณะถืออาวุธ (เหมือน `weapon.tags` ในโค้ด) ใช้กับเงื่อนไข `bonusTag` และความเข้ากับเรื่องราว |
| ท่าที X +N | ทอยท่าที X ได้ +N |
| ยาว | ได้จังหวะแรกก่อนศัตรูระยะประชิด (ศัตรูพลาดจังหวะแรกครึ่งหนึ่ง) |
| ปัด | ความเสียหายเมื่อแพ้จังหวะ −20% |
| สองมือ | ใช้กับโล่ไม่ได้ |
| ซ่อน | พกเข้าเมืองหรือสถานที่ที่ห้ามอาวุธได้ (สภา วัง งานเลี้ยง) |
| ไม่ทื่อ | ไม่โดน `c_dull` และไม่เสื่อม |
| เครื่องมือ | ใช้ในงานของอาชีพได้ ทอยงานอาชีพ +1 |
| พิษ | จังหวะที่ชนะเพิ่มแท็ก `poison` |
| ข่ม | ศัตรูระดับลูกกระจ๊อกและปกติทอยหนีหรือยอมแพ้ง่ายขึ้น (เจรจา +2) |
| ไล่ X | ศัตรูชนิด X ทอยเข้าใกล้ยาก (DC ของศัตรูนั้น −2) |
| สลักชื่อ | อาวุธจำชื่อศัตรูที่ฆ่า (ประวัติ `history` ในโค้ด) และได้ +1 กับศัตรูชนิดเดิมครั้งต่อไป |
| ผูกเจ้าของ | ใช้ได้เฉพาะเจ้าของหรือทายาท คนอื่นถือแล้วพลังเป็น 0 |

## 4. ทางที่ได้อาวุธ

| ทาง | ระดับที่ได้ | หมายเหตุ |
| --- | --- | --- |
| หยิบของใช้ใกล้ตัว | ของใช้ | ทุกที่ ทุกช่วงอายุ เด็กใช้ได้เฉพาะของใช้ |
| อาวุธเริ่มต้นของอาชีพ | C ของอาชีพนั้น | ได้เมื่อเข้าอาชีพ |
| ซื้อในร้าน | ของใช้ C U · รุ่นวัสดุที่ประเทศนั้นมี | ราคาและวัสดุตามประเทศ ประเทศอันตรายมีร้านอาวุธมากกว่า |
| ช่างตีให้ | U R · อาวุธชาติช่าง E | เรื่องราวการตามหาช่างและการทอยผลใน [10-forging.md](10-forging.md) |
| ดรอปจากศึก | ตาม [../combat/05-rewards.md](../combat/05-rewards.md) | อาวุธของ NPC ที่มีชื่อเป็นอาวุธประจำตัวของเขา |
| มรดก | ตามที่พ่อแม่ถือ | โค้ดส่งต่ออาวุธให้ทายาทอยู่แล้ว |
| ของขวัญจาก NPC | U ถึง R | คืนบุญจาก NPC ที่เคยช่วย |
| พระเจ้าประทาน | ศักดิ์สิทธิ์หรือต้องสาป (ระบบเดิม) | ดูหัวข้อ 6 |
| เส้นเรื่อง | R ถึง L | อาวุธประจำประเทศ อาวุธชาติช่าง และอาวุธตำนาน |

อาวุธระดับ R ของอาชีพและของประเทศหาซื้อไม่ได้ ได้จากงานของอาชีพ ภารกิจของ NPC ในประเทศนั้น หรือดรอปจากศัตรูที่มีชื่อ

## 5. ความทื่อและการซ่อม

- อาวุธ C และ U ใช้ในศึกครบ 10 ครั้งแล้วทอยความทื่อ 30% ทื่อแล้วพลัง −2 (เท่ากับ `c_dull` ในโค้ด) จนกว่าจะซ่อม
- ระดับ R และ E ทื่อได้ 10% ต้องให้ช่าง `smith` หรือ `rune_carver` ซ่อม
- ระดับ L ไม่ทื่อ
- คำสาป `c_dull` ทำให้อาวุธทุกชิ้นทื่อเสมอ ยกเว้นอาวุธที่มีความสามารถ "ไม่ทื่อ"

## 6. อาวุธที่พระเจ้าประทาน

ระบบเดิมในโค้ดสร้างอาวุธศักดิ์สิทธิ์ (ธาตุตามศาสนาของประเทศ) และอาวุธต้องสาป (ความมืดหรือเลือด) ยังใช้ต่อ โดยเลือกประเภทจากความถนัดของตัวละคร ตาม [01-everyday-and-standard.md](01-everyday-and-standard.md) หัวข้อ 2 แล้วใส่ธาตุและแท็ก `holy` หรือ `cursed_weapon` อาวุธที่ประทานมีค่าสถานะตามงบของระดับในหัวข้อ 1

## 7. ข้อเสนอสำหรับโค้ด

`Weapon` ในโค้ดตอนนี้มี `name kind rarity element power tags history kills` เสนอเพิ่ม

| ช่อง | ใช้ทำอะไร |
| --- | --- |
| `id` | รหัสในเอกสาร (เช่น `wj_farmer_c` `wl_sky_hammer`) |
| `type` | ประเภทจากไฟล์ 01 ใช้หาความถนัด |
| `stats` | ค่าสถานะที่บวกขณะถือ |
| `abilities` | ความสามารถตามหัวข้อ 3 |
| `source` | ทางที่ได้ ใช้แสดงในประวัติ |

`kind` เดิมเปลี่ยนเป็น `holy` `cursed` หรือ `mundane` (อาวุธจากเอกสารชุดนี้)
