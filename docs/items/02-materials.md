# วัสดุ

ระบบ: [README.md](README.md) · อาวุธมาตรฐาน: [01-everyday-and-standard.md](01-everyday-and-standard.md)

อาวุธมาตรฐานทุกประเภทที่มีคอลัมน์ "วัสดุ" เป็นโลหะหรือไม้ ตีด้วยวัสดุในไฟล์นี้ได้ อาวุธที่ได้เรียกว่า **รุ่นวัสดุ** มีรหัส `ws_<ประเภท>_<วัสดุ>` เช่น `ws_longsword_steel` ชื่อเป็นชื่อประเภทตามด้วยชื่อวัสดุ เช่น ดาบยาวเหล็กกล้า

## 1. กติกาการรวม

| ช่อง | ค่าของรุ่นวัสดุ |
| --- | --- |
| ระดับ | ระดับของวัสดุ |
| พลัง | C 1 · U 2 · R 3 |
| ค่าสถานะ | ค่าของประเภท + ค่าของวัสดุ (ค่าเดียวกันบวกกัน) |
| แท็ก | แท็กของประเภท + แท็กของวัสดุ |
| ความสามารถ | ความสามารถของประเภท + ความสามารถของวัสดุ |
| หาได้ | ประเทศที่มีวัสดุนั้น ซื้อได้เฉพาะระดับ C และ U ระดับ R ต้องให้ช่างตี |

วัสดุใช้ไม่ได้กับบางกลุ่ม ตามคอลัมน์ "ไม่ใช้กับ" เพราะไม่สมจริง (ปืนจากแก้ว โล่จากออบซิเดียน)

## 4. ความสอดคล้องกับโลก

- วัสดุที่ผูกกับเหตุการณ์มีหรือหายตามสถานะโลก: เหล็กเถ้าแพร่หลายหลัง DR-04 · ศิลาลอยกระจายหลัง DR-01 · ปะการังหายากหลัง BIO-07 · ไม้ป่าเหี่ยวมีมากหลัง BIO-02 · ไม้โคมกับตะเกียงขาดตลาดหลัง FG-13
- ภูตพรายถืออาวุธเหล็กกล้าไม่ได้ (CR-03 ใน [../combat/02-type-matrix.md](../combat/02-type-matrix.md)) ใช้สำริด ไม้ หรือแก้วแทน
- แวมไพร์ถืออาวุธเงินแล้วบาดตัวเอง (`silver` ▲ กับแวมไพร์) ทุกจังหวะที่แพ้เสีย hp เพิ่ม
- เอลฟ์ที่ใช้ไม้ที่ตัดจากต้นไม้ที่ยังมีชีวิตผิดกฎลำต้น ไม้มีชีวิตจึงมาจากกิ่งร่วงเท่านั้น
