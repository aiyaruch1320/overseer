# เส้นเรื่องของเครื่องราง

ระบบ: [11-item-system.md](11-item-system.md) · รายการ: [14-talismans.md](14-talismans.md) · ทายาท: [../heirs/README.md](../heirs/README.md) · ศัตรู: [../combat/03-enemies.md](../combat/03-enemies.md) · สัตว์คู่หู: [../character/13-companions-overview.md](../character/13-companions-overview.md)

เครื่องรางโบราณไม่ใช่แค่ของที่ให้ค่าสถานะ มี **ผู้สถิต** อยู่ในนั้น เมื่อตัวละครถือไว้นานพอ เรื่องจะเกิดตามห้าขั้น ตั้งแต่ลางแรกจนถึงการส่งต่อให้ทายาท เรื่องนี้เป็นเส้นเรื่องที่ **ไม่ผูกกับเผ่า** ใครถือก็เจอได้ จึงเป็นทั้งเรื่องผจญภัย (ไปเจอเครื่องรางในซาก) และเรื่องของมรดก (ได้เครื่องรางจากผู้ปกครอง) ของพื้นบ้านและของขลังที่ไม่มีผู้สถิตไม่เข้าเส้นเรื่องนี้

## 1. ห้าขั้น

| ขั้น | ชื่อ | เกิดเมื่อ | ผล |
| --- | --- | --- | --- |
| 0 | ได้ของ | ตัวละครได้เครื่องรางโบราณ (หัวข้อ 3) | ใช้ผลดีทันที ผลเสียเริ่มนับ |
| 1 | ลางแรก | ถือครบหนึ่งปีขึ้นไป ทอยตามหัวข้อ 2 | ผลเสียเล็ก ๆ ปรากฏ เสียงกระซิบ ฝัน ของหาย (`c_whisper` ชั่วคราว) ตัวละครรู้ว่ามีผู้สถิต |
| 2 | การสิง | หลังลางแรก ทอยตามหัวข้อ 2 | ผู้สถิตควบคุมการตัดสินใจ 1 ถึง 3 ฤดู (หัวข้อ 4) |
| 3 | ทางออก | ครบเวลาสิงหรือผู้สถิตได้สิ่งที่ต้องการ | ห้าทางเลือก (หัวข้อ 5) |
| 4 | มรดก | ตัวละครตายขณะถือ หรือส่งต่อ | ส่งต่อเป็นเรื่องค้างให้ทายาท (หัวข้อ 7) |

รหัสห่วงโซ่ (เสนอ ใช้แบบเดียวกับ `chain_forge_*` ใน [10-forging.md](10-forging.md)): `chain_talisman_omen` (ลางแรก) · `chain_talisman_possess` (การสิง) · `chain_talisman_exit` (ทางออก)

## 4. การสิง

ตัวละครมีผู้สถิตควบคุมการตัดสินใจ 1 ถึง 3 ฤดู (ทอยเท่าเทียม)

| ข้อ | กติกา |
| --- | --- |
| นิสัย | นิสัยชั่วคราวตามตารางหัวข้อ 3 แทนนิสัยเดิมหนึ่งอย่าง (สุ่ม) ระหว่างสิง |
| การตัดสินใจ | ทางเลือกของเหตุการณ์ใช้น้ำหนักตามนิสัยชั่วคราว ตัวละครจำเหตุการณ์ไม่ได้ครึ่งหนึ่ง |
| ค่าสถานะ | ค่าสถานะหนึ่งค่าที่ผู้สถิตถนัด +1 ระหว่างสิง (ไม่นับเป็นถาวร) |
| ความสัมพันธ์ | NPC ใกล้ตัวสังเกตได้ ไว้ใจ −1 ต่อเหตุการณ์ที่ตัวละครทำแปลก ๆ ยกเว้นเมื่อทางเลือกตรงกับนิสัยเดิม |
| ศึก | ผู้สถิตชนิดผู้กล้าเก่า ปีศาจผนึก ผู้สร้าง ทำให้เกิดศึกที่ไม่ได้เลือก (เพิ่มศึกสุ่มหนึ่งครั้งต่อฤดู) |
| อันตราย | ไม่ทำให้ตัวละครตายทันที ผู้สถิตต้องการให้ตัวละครรอดเพื่อทำสิ่งที่ต้องการให้สำเร็จ ยกเว้นปีศาจผนึก (เสี่ยงตายเอง 5% ต่อฤดู) |
| ต่อเนื่อง | ระหว่างสิง ตัวละครที่เป็นอาชีพชีวิตช้าอาจทิ้งงานครึ่งทาง (ผลผลิตของฤดูนั้น −50%) |

## 5. ทางออก

เมื่อครบเวลาสิงหรือผู้สถิตได้สิ่งที่ต้องการ ตัวละครเลือกหนึ่งในห้าทาง น้ำหนักด้านล่างเป็นค่ากลาง ปรับตามชนิดผู้สถิต (คอลัมน์ "ทางออกที่ถนัด" ×1.5)

| ทาง | น้ำหนัก | ผล |
| --- | --- | --- |
| ก) ขับไล่ | 25 | ต้องมีผู้ช่วย (อาชีพ `priest` `exorcist` `monk` หรือ skill ที่ระบุ) ทอย DC ตามระดับเครื่องราง (U 11 · R 14 · E 17 · L 20) สำเร็จ: เครื่องรางเสียพลังเหลือระดับ C ไม่มีผู้สถิต · พลาด: สิงต่ออีกหนึ่งฤดู `c_madness` 15% |
| ข) ปรองดอง | 30 | ทำสิ่งที่ผู้สถิตต้องการหนึ่งอย่าง (ส่งข่าว ดูแลที่ ปิดงาน ช่วยคน) แล้วผู้สถิตเป็นพวกพ้องเงียบ ๆ · ผลดีเต็ม ราคาลดครึ่ง · `b_spiritfriend` 15% |
| ค) ยอมรับ | 15 | ถูกสิงถาวร ได้นิสัยของผู้สถิตแทนนิสัยเดิมหนึ่งอย่างถาวร · ผลดีเต็ม ราคาเต็ม · ความสามารถของผู้สถิตหนึ่งอย่าง (พรชนิดที่ผู้สถิตถนัด) · บุคลิกเปลี่ยน NPC ที่สนิทเห็นชัด |
| ง) ส่งต่อ | 20 | ให้ผู้อื่น ขายให้พ่อค้า หรือมอบให้ทายาท · เรื่องค้างชนิดความลับหรือคำมั่น ([../heirs/03-open-threads.md](../heirs/03-open-threads.md)) · ผู้รับเป็นผู้ที่ผู้สถิตจะสิงต่อ (เส้นเรื่อง NPC) |
| จ) ฝังหรือทิ้ง | 10 | ฝังคืนที่เดิมหรือโยนทิ้ง · ผู้สถิตแค้น ตามหลอก 5 ปี (`c_ghost` 30%) หรือกลับมาในเหตุการณ์ใหญ่ถัดไป · ถ้าเป็นวิญญาณธรรมชาติและฝังคืนที่เดิม ผู้สถิตสงบ ไม่มีผลเสีย |

**ผลตามชนิด**

| ชนิด | ผลพิเศษของทางที่ถนัด |
| --- | --- |
| ผู้ตายค้างคา | ข: ส่งข่าวสำเร็จ ได้บุญคุณจากญาติของผู้ตาย (NPC) |
| บรรพบุรุษ | ข หรือ ค: ที่มั่นของตระกูลปลอดภัยในเหตุการณ์ใหญ่หนึ่งครั้ง |
| วิญญาณธรรมชาติ | จ ที่เดิม: ที่นั้นฟื้นเร็ว (ป่าที่ป่วยใน BIO-01 ฟื้น −1 ปีต่อทศวรรษ) |
| ภูต | ข: ได้พรเล็กหนึ่งอย่างที่ผู้สถิตเสนอ หนี้ล้าง |
| ปีศาจผนึก | ก: ผู้สถิตหนีไปเป็นศัตรูสุ่มหนึ่งตัว (`firedemon` หรือ `hellmouth_imps`) |
| ผู้กล้าเก่า | ข: งานที่ค้างปิด ได้ชื่อเสียง +10 |
| ความทรงจำมังกร | ข: ได้เห็นมังกรที่เหลือหนึ่งตัว ([../combat/06-dragon-encounters.md](../combat/06-dragon-encounters.md)) |
| ผู้สร้าง | ข: ได้ฝีมือของผู้สร้างถาวร +1 ระดับในความถนัดที่เกี่ยวข้อง |

## 6. ถือสองชิ้น

ช่องเครื่องรางมีหนึ่งช่อง ถ้าตัวละครถือเครื่องรางโบราณสองชิ้นพร้อมกัน (เช่น ได้ใบที่สองระหว่างถือใบแรก) ผู้สถิตขัดกัน

| กรณี | ผล |
| --- | --- |
| ผู้สถิตชนิดเดียวกัน | ปรองดองกันได้ ผลดีบวกกันครึ่งหนึ่งของใบที่สอง ราคาสองเท่า |
| ผู้สถิตต่างชนิด | ถูกสิงสลับ ทอยทุกฤดู `c_madness` 20% ต่อปี ต้องทิ้งหรือขายใบหนึ่ง |
| ของขลังพื้นบ้านกับเครื่องรางโบราณ | อยู่ด้วยกันได้ ของพื้นบ้านเปลี่ยนไปอยู่ช่องเครื่องประดับแทนไม่ได้ ใช้ได้เฉพาะเมื่อไม่มีเครื่องรางโบราณในช่อง |

## 7. ทายาทและมรดก

| ข้อ | กติกา |
| --- | --- |
| ส่งต่ออัตโนมัติ | เครื่องรางโบราณที่ถือขณะตายส่งต่อให้ทายาทเสมอ (ไม่นับเป็นอาวุธหนึ่งชิ้น เป็นของตระกูล) |
| เรื่องค้าง | ถ้าเครื่องรางยังมีผู้สถิตและตัวละครไม่เลือกทางออก ส่งต่อเป็นเรื่องค้างชนิดความลับ (ผู้สถิตคืออะไร) หรือคำมั่น (สิ่งที่ผู้สถิตต้องการ) |
| ผู้สถิตบรรพบุรุษ | ทายาทมีโอกาสถูกสิงสูงขึ้น (×2 เลือดเดียวกัน) แต่ขั้นแรกของทายาทเป็น "ผู้สถิตแนะนำตัว" ไม่ใช่การสิงทันที (ลางแรกมีข้อความจากผู้สถิต) |
| ทางออกของรุ่นก่อน | รุ่นก่อนเลือก ค (ยอมรับ) ผู้สถิตเป็นสมาชิกของตระกูล ทายาททางออกที่ถนัดคือ ข และไม่มีราคา · รุ่นก่อนเลือก จ (ฝัง) แล้วเครื่องรางกลับมา ผู้สถิตแค้น ×1.5 |
| สมุดตระกูล | จดทางออกที่รุ่นก่อนเลือก ([../heirs/02-no-repeat.md](../heirs/02-no-repeat.md) หัวข้อ 2) เครื่องรางไม่ซ้ำเรื่อง: เรื่องที่ผู้สถิตแก้แล้ว ไม่เกิดซ้ำ |

## 10. ตัวอย่าง

### 10.1 ผู้ตายค้างคาและทายาท

ตัวละครเรือ NR ได้ `tm_drowned_bell` จากซากเรือ ถือสองปี ลางแรก: ฝันถึงทะเลทุกคืน สิงหนึ่งฤดู: ตัวละครไม่ยอมลงเรือไปที่ที่ไม่ใช่ NR-05 เมื่อครบเวลา ตัวละครเลือก ข ปรองดอง ส่งข่าวไปถึงภรรยาของลูกเรือในหมู่บ้านชายทะเล ภรรยาให้ปลอกกระดิ่งเป็นบุญคุณ ผู้สถิตเป็นพวกพ้องเงียบ ๆ ตัวละครตายก่อนอายุ 60 ทายาทรับกระดิ่ง ผู้สถิตแนะนำตัวในลางแรก ไม่ต้องสิง ทายาทเลือกอยู่เป็นผู้ดูแลประภาคาร (`lighthouse_keeper`) ได้ลางพายุล่วงหน้า

### 10.2 ภูตกับลูกครึ่ง

ลูกภูต (fy ใน [../storylines/22-halfblood.md](../storylines/22-halfblood.md)) ได้ `tm_name_ribbon` จาก SV04-2 พิกซี่ ผลดี: ภาษาของเผ่าอื่นเข้าใจเร็ว ผลเสีย: ชื่อจริงรั่วครึ่งหนึ่ง เมื่อสิง ภูตทำสัญญากับ NPC ในชื่อของตัวละคร ผลคือหนี้ภูตและเรื่องค้างชนิดสัญญา ทายาทของลูกครึ่งต้องไปหาสัญญาเดิม

## 11. ตรวจความสอดคล้อง

- ผู้สถิตไม่ใช่ NPC ที่มีรหัส ไม่มีเส้นเรื่องของตัวเองในไฟล์ NPC ผู้สถิตเป็นเรื่องของเครื่องราง ตัวละครเข้าเรื่องผ่านเครื่องราง
- การสิงไม่เปลี่ยนเหตุการณ์ของโลก (ตัวละครที่ถูกสิงไม่ทำให้ DR หรือ WR เกิดหรือหาย) เปลี่ยนได้เฉพาะเรื่องส่วนตัวและ NPC
- ผู้สถิตทุกชนิดมีศัตรูของโลกคู่กันตาม [../combat/03-enemies.md](../combat/03-enemies.md) ไม่ใช้ศัตรูใหม่
- ผู้ตายที่ผู้สถิตค้างคามาจากสิ่งที่โลกมีอยู่แล้ว (ซากเรือ ทุ่งรบ สุสาน ปากเหว รังมังกร) ไม่สร้างสถานที่ใหม่
