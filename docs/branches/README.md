## หลักการ

### ที่ยึดของเหตุการณ์

เหตุการณ์ทุกอย่างผูกกับ **ที่ยึด** อย่างน้อยหนึ่งอย่าง

| ชนิดที่ยึด | ตัวอย่าง |
| --- | --- |
| ทวีป | คืนเกล็ดร่วง (อัซการ์), วันหมอกแหวก (เนบูเลีย) |
| ประเทศ | พิธีอัญเชิญผู้กล้า (ลูเมียร์), ศึกชิงมงกุฎกระดูก (ทรอนกาธ) |
| มังกร | DR-02 โอรัน-ซัลโคม่า, PL-05 อันดาร์ตื่น |
| ศาสนา | DR-11 พิธีสังเวยมหาศักดิ์สิทธิ์, FG-05 มารดาแห่งเสียง |
| เผ่า | การปฏิวัติหุ่นยนต์ (หุ่นวิญญาณ) |
| สิ่งของ | ค้อนทุบฟ้า, ไข่ใบที่สิบหก, ต้นกล้าต้นไม้โลก |

### สามการกระทำเมื่อที่ยึดเปลี่ยน

| การกระทำ | ความหมาย |
| --- | --- |
| **ปิด** | เหตุการณ์นั้นเป็นไปไม่ได้อีกตลอดไป |
| **แทนที่** | เหตุการณ์นั้นถูกปิด และมีเหตุการณ์สืบทอดที่เกิดในที่ยึดใหม่ซึ่งมีสาระเดียวกันแต่เป็นอีกเรื่อง |
| **เปิดใหม่** | เกิดเหตุการณ์ที่ก่อนหน้านี้ไม่มีทางเกิด |

### กฎ

1. ที่ยึดที่ไม่มีอยู่แล้ว **ห้าม** เกิดเหตุการณ์ของที่ยึดนั้นอีก (ทวีปมังกรหายแล้ว ห้ามมีคืนเกล็ดร่วง)
2. ทุกเหตุการณ์ที่ถูกปิดต้องระบุว่า **แทนที่ด้วยอะไร** หรือ **ไม่มีผู้สืบทอด** พร้อมเหตุผล
3. เหตุการณ์สืบทอดเปิดภายในสิบปีหลังการเปลี่ยน
4. เหตุการณ์ที่เกิดแล้วและจบแล้วไม่ถูกลบ ย้อนไปเป็นประวัติศาสตร์ ตัวละครที่ผ่านมันมี "ผู้ผ่านเหตุการณ์" ติดตัว
5. การเปลี่ยนซ้อนกัน (เช่น ทวีปมังกรหายแล้วตามด้วยอีริดานล้ม) ใช้ที่ยึดล่าสุดเสมอ

## ผลต่อเรื่องและตัวละครหลัก

- **เรื่องราวหลัก** แต่ละธงเปลี่ยนว่าจะมีสงครามอะไร ผู้กล้ามีเป้าหมายอะไร จอมมารเกิดจากเงื่อนไขไหน ดู [03-character-and-quests.md](03-character-and-quests.md)
- **ตัวละครหลัก** เกิดในโลกที่เป็นอยู่ ณ วันเกิด ที่เกิดได้ อาชีพ ชะตา และภารกิจของพระเจ้าเปลี่ยนตามธง
- **ผู้ที่เกิดก่อนเหตุการณ์** ผ่านเหตุการณ์ในชีวิตและได้ติดตัว **ผู้ผ่านเหตุการณ์**
- **ผู้ที่เกิดหลังเหตุการณ์** เกิดในโลกใหม่ ไม่เคยเห็นโลกก่อนหน้า มีมุมมองต่างกัน (เช่น ผู้ลี้ภัยรุ่นสองไม่เคยเห็นเกาะลอยฟ้า)
