# ผลถาวรเมื่อมังกรแต่ละตัวล้ม

ทุกการล้มเรียก DR-15 คลื่นไว้อาลัย (ผลรองทุกทวีป ดู [../dragons/README.md](../dragons/README.md)) ตารางนี้คือ **ผลถาวรเฉพาะตัว** ต่อเหตุการณ์ เรื่องราว และตัวละคร

**วิธีอ่าน** ปิด = เป็นไปไม่ได้อีก · แทนที่ = มีเหตุการณ์สืบทอดแทน · เปิด = เกิดได้เฉพาะหลังการล้ม

---

## 1. โอรัน-ซัล → สกายฟอลล์

| หัวข้อ | ผล |
| --- | --- |
| **ปิด** | เหตุการณ์ประจำถิ่นของอัซการ์ทั้งหมด (คืนเกล็ดร่วง, เกาะร่วง, พิธีเลือกผู้ขี่มังกร, ผู้ไม่ก้มหัว, เรือเหาะรุกล้ำ, ฝนเกล็ด), DR-02, MC-01, WR-01, WR-02, WR-18, GI-01, HP-03, PL-01 (อีริดานตื่นกลายเป็นผู้ปกป้อง) |
| **แทนที่** | WR-01 → WR-22 · WR-02 และ GI-01 → SF-04 · WR-18 → SF-09 · MC-01 → SF-05 · HP-03 → SF-10 · PL-01 → SF-02 · DR-11 → พิธีไว้อาลัยมหาศักดิ์สิทธิ์ (ทุกมังกรที่เหลือ) |
| **เปิด** | SF-01 ถึง SF-10 ดู [02-new-lands.md](02-new-lands.md) · DR-03 ถ้าไข่ยังอยู่ → SF-03 |
| **ศาสนา** | ลัทธิบูชามังกรแตกสามสาย: ผู้ปรนนิบัติไร้มังกร, ลัทธิรอยหาย, ผู้ไม่ก้มหัวรวมพลัง ศรัทธาช่อง A ของอัซการ์หายเกินครึ่ง |
| **ตัวละคร** | เกิดที่อัซการ์ไม่ได้อีก ผู้เกิดก่อนเหตุการณ์ที่รอดมี "ผู้รอดจากฟ้าถล่ม" อาชีพผู้ปรนนิบัติมังกรสูงสุดหาย อัศวินมังกรเหลือเพียงผู้ที่ขี่อีริดาน |

## 2. เพลิงนิรันดร์ → ทวีปเถ้า

| หัวข้อ | ผล |
| --- | --- |
| **ปิด** | ตะวันหลอมเหล็ก, ลาวาท่วมเมือง, ราชาเปลวไฟตื่น, GI-04 (จักรพรรดิเผ่าลาวา), WR-05 (สงครามปากเหวแย่งน้ำ), WR-12 (ขายเทคโนโลยีหลอม) |
| **แทนที่** | GI-04 → AS-03 · WR-05 → AS-02 · ตะวันหลอมเหล็ก → พิธีเถ้าไฟสุดท้าย (AS-01) · GI-05 → AS-04 |
| **เปิด** | AS-01 ถึง AS-05 (GI-09 → AS-05 มังกรลาวาเกิดจากเถ้า) · DM-07 (ปีศาจใต้พิภพไหลขึ้นเมื่อไม่มีลาวากัก) |
| **ศาสนา** | ศรัทธาเตาหลอมกลายเป็นศาสนาแห่งการคิดถึงไฟ ผู้ถ่ายทอดพยายามส่งศรัทธาผ่านคัลดราเพื่อชดเชย |
| **ตัวละคร** | เกิดเป็นเผ่าลาวาได้ยากขึ้น อาวุธธาตุไฟอ่อนลง ช่างตีไฟต้องเปลี่ยนไปตีอาวุธเย็น ชะตา "ถูกเนรเทศ" ของคนแคระแปรผัน |

## 3. สมุทรอาลัย → ทุ่งจม

| หัวข้อ | ผล |
| --- | --- |
| **ปิด** | เหตุการณ์ของเมืองท่าชายฝั่งที่จมแล้ว, PL-04 รูปแบบปกติ, สนธิสัญญากระแสน้ำเดิม (PO-03) |
| **แทนที่** | PO-03 → DW-04 · WR-06 → DW-04 · WR-20 → DW-03 · การค้าเรือ → เส้นทางใหม่ |
| **เปิด** | DW-01 ถึง DW-05 · CT-05 น้ำท่วมโลก · BIO-07 ปะการังตาย |
| **ศาสนา** | เทพแห่งสมุทรแตกเป็นสายไว้อาลัย (บูชาผู้ล้ม) กับสายทวงคืน (โทษมนุษย์) |
| **ตัวละคร** | ชายฝั่งหลายแห่งเกิดไม่ได้ เกิดบนเรือ (มนุษย์เรือ) เพิ่มขึ้น ผู้ลี้ภัยทางน้ำชุดใหม่ เงือกและนาคาขึ้นบก |

## 4. พายุไร้ทิศ → ยุคลมสุ่ม

| หัวข้อ | ผล |
| --- | --- |
| **ปิด** | การเดินเรือใบและเรือเหาะที่พึ่งลมประจำฤดู, ระบบแผนที่ลมของนูไอล์ (NR-15) เดิม |
| **แทนที่** | การเดินเรือปกติ → การเดินเรือกับลมสุ่ม (เหตุการณ์เรือหลงลมเกิดบ่อย) |
| **เปิด** | CT-04 ภัยแล้งร้อยปี (ฝนไม่ตามฤดู) · ลมแรงแบบไม่มีทิศ เหตุการณ์ใหม่ของนูไอล์: "เขียนแผนที่ใหม่" |
| **ศาสนา** | ลางนิยมแข็งแรงขึ้น (ชาวเรือเชื่อในลาง) |
| **ตัวละคร** | อาชีพลูกเรือและพ่อค้าเดินเรือเสี่ยงสูง ชะตา "เรืออับปาง" เกิดบ่อยกว่า เรือเหาะใช้ไม่ได้ในช่วงแรก |

## 5. ศิลาสะท้าน → ทุ่งแยก

| หัวข้อ | ผล |
| --- | --- |
| **ปิด** | สงครามรวมทุ่งราบ (WR-16) แบบเดิม, สภาเก้าทวีปที่คองคอร์เดียอยู่กลางทวีป |
| **แทนที่** | WR-16 → RF-03 · PO-05 → RF-04 |
| **เปิด** | RF-01 ถึง RF-05 · GI-02 ไททันตื่น |
| **ศาสนา** | ศรัทธาศิลากับลัทธิมังกรแยกกัน ผู้ศรัทธาศิลาอ้างว่าศิลาสะท้านตื่นมารักษาแผ่นดิน |
| **ตัวละคร** | เกิดฝั่งเหนือหรือฝั่งใต้ของหุบเหว มีผลต่อชะตา หุบเหวเป็นสถานที่ผจญภัยใหม่ ผู้เกิดบนปากเหวมีตำหนิ "คนขอบ" |

## 6. ราหู → วัน-คืนปั่นป่วน

| หัวข้อ | ผล |
| --- | --- |
| **ปิด** | วงจรกลางวัน-คืนปกติ, พิธีสุริยคราสร่วมของโคซาโมเรีย (AZ-05) |
| **แทนที่** | วันกับคืนเป็นช่วงสุ่มตามภูมิภาค |
| **เปิด** | CT-07 สุริยคราสร้อยปี · แวมไพร์เดินกลางแดดได้ (อ่อนแรง) · ลัทธิสุริยากับจันทราชิงอำนาจ |
| **ศาสนา** | จันทรากับสุริยากลายเป็นสองศาสนาแยกกันอย่างเด็ดขาด |
| **ตัวละคร** | เวลาของตัวละครไม่เท่ากันทุกประเทศ แวมไพร์ไม่ถูกจำกัดด้วยแสงแดงเหมือนเดิม |

## 7. อีริดาน → แกนฟ้าเปิด

| หัวข้อ | ผล |
| --- | --- |
| **ปิด** | พิธีเลือกผู้ขี่มังกร (ไม่มีมังกรให้ขี่), ไร่เมฆของ AZ-07 |
| **แทนที่** | อัศวินมังกรกลายเป็นผู้ขี่มังกรทั่วไป (ไวเวิร์นที่เหลือ) |
| **เปิด** | END-01 พื้นที่ฟ้ากลับหัวทั่วโลก · ถ้ามีสกายฟอลล์แล้ว ซากลอยบางส่วนกลับขึ้นฟ้า |
| **ศาสนา** | ครอบครัวนิยมสูญเสียผู้นำทางใจ |
| **ตัวละคร** | พื้นที่ฟ้ากลับหัวเป็นสถานที่เสี่ยงตาย ชะตา "ตกจากที่สูง" มีความหมายใหม่ |

## 8. ฮรอด-กาธ → แกนสงครามเปิด

| หัวข้อ | ผล |
| --- | --- |
| **ปิด** | ศึกชิงมงกุฎกระดูกแบบเดิม (ไม่มีมังกรเลือก), HP-07 ข้าวเถ้ารูปแบบเดิม |
| **แทนที่** | ศึกชิงมงกุฎ → สงครามไร้ขีดจำกัด (END-02) |
| **เปิด** | END-02 · DM-08 จอมมารเก้าตน |
| **ศาสนา** | เทพแห่งสงครามแปรเป็นลัทธิคลั่งสงคราม |
| **ตัวละคร** | ผู้ถืออาวุธทุกคนควบคุมตัวเองยากในรัศมีทวีปปีศาจ จอมมารตนใหม่เกิดจากสงคราม ไม่ใช่จากศึกชิงมงกุฎ |
