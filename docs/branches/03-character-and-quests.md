# ผลต่อตัวละครหลัก ชะตา และภารกิจ

ตัวละครหลักเกิดในโลกที่เป็นอยู่ ณ วันเกิด เหตุการณ์ที่เกิดระหว่างชีวิตเปลี่ยนเส้นทางที่เหลือ ภาพรวมระบบอยู่ที่ [README.md](README.md)

---

## 1. สถานะของตัวละครต่อเหตุการณ์

| สถานะ | เงื่อนไข | ผล |
| --- | --- | --- |
| **ผู้ผ่านเหตุการณ์** | มีชีวิตอยู่ตอนเหตุการณ์ใหญ่เกิด | ได้ความทรงจำของเหตุการณ์ ติดตัวตลอดชีวิต ดูตาราง §2 |
| **ผู้ลี้ภัยรุ่นหนึ่ง** | เคยอยู่ในดินแดนที่หาย | โหยหาบ้านเก่า ติดคำสาป "ถิ่นที่หาย" ได้ใจจากผู้ลี้ภัยด้วยกัน |
| **ผู้ลี้ภัยรุ่นสอง** | พ่อแม่เป็นผู้ลี้ภัยรุ่นหนึ่ง | ไม่เคยเห็นบ้านเก่า ผูกกับดินแดนใหม่ มีความขัดแย้งกับรุ่นแรก |
| **ผู้เกิดในโลกใหม่** | เกิดหลังเหตุการณ์ | ถือว่าทวีปใหม่เป็นบ้าน ไม่มีความทรงจำของโลกเดิม |

### ความทรงจำของเหตุการณ์ใหญ่

| เหตุการณ์ | สถานะผู้ผ่านเหตุการณ์ | ผลต่อตัวละคร |
| --- | --- | --- |
| DR-01 ฟ้าถล่ม | ผู้รอดจากฟ้าถล่ม | ทนต่อความกลัวความสูง ฝันถึงเกาะเก่า ผู้ที่เป็นเผ่าปีกอาจมีคำสาป "ปีกหัก" |
| DR-04 ฤดูหนาวเถ้า | ผู้รอดจากเถ้า | ทนหนาวและอดอยากได้ ฝึกการใช้เศษของ |
| DR-05 มหาน้ำขึ้น | ผู้รอดจากน้ำ | ว่ายน้ำและอ่านน้ำเก่ง กลัวที่ราบต่ำ |
| DR-07 แผ่นดินแยก | ผู้รอดจากรอยร้าว | รับรู้การสั่นไหวก่อนใคร ไม่ไว้ใจแผ่นดิน |
| BIO-02 ต้นไม้โลกตาย | ผู้รอดจากป่าเหี่ยว | ฟื้นตัวช้า แต่รู้จักสมุนไพรสำรอง |
| MC-04 เตาปฏิกรณ์ระเบิด | ผู้รอดจากคืนไฟดับ | ทนมลพิษได้บางส่วน ไม่เชื่อเครื่องจักร |
| BIO-05 วันหมอกแหวก | ผู้เห็นแสงแรก | ได้พรหรือคำสาปจากการเห็นแสงอาทิตย์ครั้งแรก |
| FG-01 หมอกกินคน | ผู้รอดจากหมอกทึบ | ใจนิ่งในความมืด ทนความกลัว แต่ฝันร้าย |
| DR-15 คลื่นไว้อาลัย | ผู้ได้ยินเสียงร้องไห้ | ดู §5 |

| DR-07 | ผู้นำสงครามรวมทุ่งราบ | ผู้สร้างสะพาน · ผู้สำรวจหุบเหว |

| MC-04 | วิศวกรบริษัท | นักเก็บสนิม · หุ่นผู้ตื่นที่ทำงานแทนมนุษย์ |
| BIO-05 | นักล่าในหมอก · ผู้นำทางด้วยเสียง | แวมไพร์ใต้ดิน · ผู้ปรับตัวต่อแสง |

## 4. ชะตาที่เปลี่ยนรูป

ชะตาเดิมที่ผูกกับดินแดนหรือมังกรที่หาย เกิดในรูปแบบใหม่

| ชะตาเดิม | หลังเหตุการณ์ | รูปแบบใหม่ |
| --- | --- | --- |
| เผชิญหน้ามังกร | DR-01 | พบมังกรที่รอดบนซาก (เพลิง พายุ ศิลา ราหู สมุทร ที่ยังอยู่) หรือเผชิญผู้ที่ล่ามังกรตัวสุดท้าย |
| เผชิญหน้ามังกร | DR-15 ครั้งที่ 3 ขึ้นไป | มังกรที่ขาดสติ คลั่ง สละตัว หรือหลับลึก |
| ถูกเนรเทศ | DR-01 / DR-05 / FG-11 | ผู้ลี้ภัยของดินแดนที่หาย |
| เรืออับปาง | DR-05 | เรือกลางน้ำท่วม ผู้รอดบนเสาเมือง |
| เรืออับปาง | DR-06 | เรือหลงลมสุ่ม |
| ค้นพบสมบัติโบราณ | DR-04 / RF-05 | ซากในเถ้า ซากในหุบเหว |
| ดันเจี้ยนเปิดใหม่ | DR-07 | หุบเหวใหม่ (RF-05) |
| ถูกอัญเชิญเป็นผู้กล้า | DR-01 | ผู้กล้าที่ปกป้องผู้ลี้ภัยแทนปราบจอมมาร |
| โรคระบาดมาเยือน | BIO-02 | โรคระบาดไม่มียารักษา (ไม่มีน้ำเลี้ยง) |
| ศึกสงคราม | WR-22, RF-03 | สงครามซาก สงครามสองทุ่งราบ |
| จอมมารคืนชีพ | END-02 | หนึ่งในเก้าจอมมาร (DM-08) |
| ความทรงจำจากชาติก่อน | END-05 | ฝันร้ายที่จำชาติก่อนได้ผิดพลาด |
| ปฏิวัติ | MC-03, FG-04 | ปฏิวัติหุ่น ตลาดโคมประกาศเอกราช |
| พบรักแท้ | ทุกเหตุการณ์ | คู่รักข้ามเผ่าที่พบกันในค่ายผู้ลี้ภัย |
| พบผู้เป็นอาจารย์ | DR-01 | อาจารย์ผู้ไร้มังกร นักบวชที่เสียศรัทธา |

## 5. รอยแห่งการไว้อาลัย

ทุกครั้งที่ DR-15 เกิด ทุกคนที่ยังมีชีวิตในโลกได้ยินเสียงร้องไห้ในความฝัน และได้ **รอยไว้อาลัย** หนึ่งรอย

| จำนวนรอย | ผลต่อตัวละคร |
| --- | --- |
| 1–2 | ฝันถึงมังกรที่ตาย ศรัทธาผันผวนขึ้นลง |
| 3–5 | บางคนได้พร **หูของพี่น้อง** (U) ได้ยินเศษเสียงมังกรในความฝัน ทำนายภัยตามธาตุได้เป็นครั้งคราว |
| 6–9 | ลูกที่เกิดใหม่หลายคนเกิดมาพร้อมพร **ลูกแห่งการไว้อาลัย** (R) ใกล้ชิดมังกรที่เหลือ หรือคำสาป **รอยแผลของพี่น้อง** (R) เศร้าง่ายและเปราะบาง |
| 10 ขึ้นไป | ผู้ที่ได้ยินเสียงของมังกรที่เหลือชัดที่สุด กลายเป็นผู้ถูกเลือก (L) ผู้สืบทอดความสัมพันธ์ของพี่น้องที่เหลือ |

รอยสะสมตามจำนวนมังกรที่ล้มก่อนตัวละครเกิด (DFC ตอนเกิด) และที่ล้มระหว่างชีวิต

## 6. ภารกิจของพระเจ้าที่เปลี่ยนไป

| ภารกิจ | การเปลี่ยนแปลงหลังมังกรล้มหรือทวีปเปลี่ยน |
| --- | --- |
| ศาสดาแห่งเรา | ผู้คนหวาดกลัวหลังมังกรล้ม ประกาศง่ายขึ้น แต่ต้องประกาศในดินแดนใหม่ (สกายฟอลล์ ทวีปเถ้า) และเผชิญลัทธิคำพิพากษาที่ชิงผู้ศรัทธา |
| ผู้ฆ่ามังกร | ฆ่ามังกรทั่วไปนับตามเดิม แต่ฆ่ามังกรตำนานนับเป็นการฆ่าพี่น้อง ผู้ทำรางวัลเปลี่ยนเป็นคำสาป "หนี้ต่อโลก" และเรียก DR-15 |
| จุดจบของจอมมาร | หลัง END-02 ไม่มีจอมมารเดียว ต้องปราบหนึ่งในเก้าจอมมาร หรือยุติการหิวของมอร์เฮเวน (เส้นทางสันติ HP-07) |
| ต้นราชวงศ์ | ถ้าตระกูลสูญเสียประเทศเดิม ต้องตั้งราชวงศ์ในดินแดนใหม่ (สกายฟอลล์ ทวีปเถ้า) ได้รางวัลพิเศษ |
| ตำนานแห่งยุค | ชื่อเสียงใหม่จากการพาผู้ลี้ภัยรอด ปิดรอยแยก ถ่วงสงครามซาก |
| เศรษฐีแห่งแผ่นดิน | สินค้าใหม่: ศิลาลอยเศษ น้ำเลี้ยงสุดท้าย ธุลีทิพย์ ซากสนิม ราคาพุ่งผันผวน |
| มารร้ายที่ทุกคนจดจำ | ทางใหม่: เอาเปรียบผู้ลี้ภัย เป็นผู้ประกาศคำพิพากษา เป็นผู้ฆ่ามังกรตัวสุดท้าย |
| ผู้ปลดผนึก (อาชีพลับ) | เปิดง่ายขึ้นหลัง DFC ≥ 3 แต่ผู้ที่ได้อาชีพนี้มักเกี่ยวกับการล้มของมังกร และเรียก DR-15 |
| ร้อยปีไม่สิ้นลม | ผู้ที่มีชีวิตผ่านหลายการล้มได้ "พยานแห่งการไว้อาลัย" เป็นรางวัลเพิ่ม |
| นักรบร้อยศึก | ศึกใหม่: สงครามซาก สงครามสองทุ่งราบ สงครามน้ำเลี้ยง สงครามหมอก |
| ผู้ไร้มลทิน | ช่วยผู้ลี้ภัยได้กรรมดีเร็วกว่าโลกปกติ |
| สหายของผู้กล้า | ผู้กล้ารุ่นหลัง DR-01 ไม่ปราบจอมมารอย่างเดียว แต่ปกป้องผู้ลี้ภัยและซากมังกร |
